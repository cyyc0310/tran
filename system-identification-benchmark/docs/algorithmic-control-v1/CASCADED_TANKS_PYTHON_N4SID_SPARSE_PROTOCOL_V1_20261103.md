# Cascaded Tanks 二状态 Python N4SID 稀疏输出协议 v1

协议日期：2026-11-03。此项补充状态空间基线。公开 `uVal/yVal` 标签已在早期开发工作中查看；本结果属于开发期复算，不能称盲测或独立确认。实验不会把此协议追溯描述成测试前冻结。

## 方法来源和命名

模型阶数固定为 2，依据 Forgione–Piga Cascaded Tanks MATLAB 示例中的 `n4sid(data_id, 2)`。由于本机没有 MATLAB/Octave，本实验使用独立 Python 包 NFourSID 1.0.2（固定上游提交 `1e306879f9e697cd275f17d01dc96182b74ac97d`）做 N4SID 子空间估计，并使用同包 Kalman 滤波器处理稀疏输出。实现、许可与源文件 SHA-256 见 [`external-source/nfoursid/README.md`](external-source/nfoursid/README.md)。所以结果称**二状态 Python N4SID**，不称 MATLAB 原样复现或 Forgione–Piga 原始基线分数。[作者 MATLAB 脚本](https://github.com/forgi86/sysid-neural-continuous/blob/956aa7ecd73061b0321c6f6098d74c9e4a7ce67a/examples/CTS/CTS_subspace_comparison.m)

## 源端拟合与选型

- 只用估计记录 `uEst/yEst`；时间顺序末段 20% 转移作选型。标准化均值/尺度只从前 80% 估计段计算。
- 状态阶数保持 2；候选 Hankel 块行数固定为 `2, 3, 4, 6, 8, 10, 12, 16`。以输出稀疏间隔等于预测跨度的 1、3、5 个转移，对每个候选计算源端验证 NRMSE，选择三种跨度的宏平均最低者；并列时取较小块行数。
- 对各候选，初始状态 `x0` 通过前最多 40 个源端样本的线性最小二乘估计；初始状态误差协方差取候选 N4SID 状态序列最初最多 100 列的样本协方差并加微小对角正则。源端验证时，先用完整训练前缀的观测推进 Kalman 状态，再只在验证块起点提供输出观测。
- 选定块行数后，用完整 `uEst/yEst` 重新拟合；重算初始状态与协方差。参数、矩阵和状态估计均写入机器可读模型回执。

## 目标稀疏预测

- 不用目标标签校准模型参数或筛选超参数。仅在第一个目标时刻读取 `yVal[0]` 更新状态；之后每隔 1、3、5 个转移（4、12、20 秒）读取块起点输出，块内不读取中间真实输出。
- 使用每个块中记录的完整泵输入路径，并用 NFourSID 发布的 Kalman filter 更新/传播状态和协方差。状态预测为 `x[k+1]=A x[k]+B u[k]`，观测为 `y[k]=C x[k]+D u[k]`；计算下一样本输出时把记录路径中的 `u[k+1]` 代入直接项 `D u[k+1]`。
- 整条官方估计记录作为源端训练；目标起始状态用源端模型从估计记录起点估计的 `x0` 初始化，然后由允许的 `yVal[0]` 更新。每个预测跨度单独按不重叠块评分；末尾不足完整块的样本不计分。
- 报告 RMSE、MAE、按完整源端输出标准差归一化的 RMSE、预测有限率、超出源观测范围比例、预测最小/最大值，以及识别矩阵的谱半径与噪声协方差诊断。

## 解释边界

这项对照测试线性二状态随机状态空间模型在一条公开水箱测试记录、已知记录输入和稀疏输出下的表现。Python N4SID 的 PO-MOESP 实现、块行参数、归一化、初始状态估计和 Kalman 稀疏观测合同都与 MATLAB 默认脚本不完全相同。测试标签已看过，数据只有一条目标运行；长跨度发散或物理越界应作为失败如实记录。该基线不提供硬件安全约束，也不能单独证明作者混合模型优于所有状态空间方法。
