# Cascaded Tanks 正则二阶 ARX 开发消融协议 v1

冻结日期：2026-11-03。此协议用于补充水箱稀疏输出任务中的线性动态基线。目标 `uVal/yVal` 已在早期数据准入和其他开发实验中查看，所以结果只用于开发期比较，不能称为盲测或独立确认。

## 模型和源端选型

模型固定为二阶输入输出 ARX：

```text
y[k+1] = c + a1*y[k] + a2*y[k-1] + b0*u[k] + b1*u[k-1]
```

参数仅用 4TU 官方估计记录 `uEst/yEst` 拟合。为减少共线回归下的系数不稳定，在估计记录的时间顺序末段留出 20% 转移作源端验证；候选岭惩罚 `alpha` 固定为 `0, 0.001, 0.01, 0.1, 1, 10, 100, 1000`。每个特征先按源端训练片段标准化，截距不惩罚。选取 1、3、5 个原生转移下平均 NRMSE 最低的 `alpha`；归一化分母只用源端训练片段的输出标准差。随后用全 `uEst/yEst` 和已选 `alpha` 重估冻结模型。

## 稀疏目标评测合同

- 只报告零目标校准预算。模型系数不使用 `uVal/yVal` 调整。
- 原生间隔 4 秒，已知每个预测块完整的记录泵输入路径。评测跨度为 1、3、5 个转移（4、12、20 秒）。
- 每个非重叠块起点只使用当时允许的输出 `yVal[start]`。将 ARX 当前输出状态替换为该观测；上一输出状态从前一块的模型预测延续。块内递归使用模型预测，不读入中间真实输出。第一个起点没有前一时刻输出，因此将上一输出状态初始化为 `yVal[0]`。
- 第一时刻没有 `uVal[-1]`，按预先固定的边界约定取 `uVal[0]`；其余时刻使用已知记录输入中的 `uVal[k-1]`。
- 指标按整个留出轨迹中所有完整块计算；末尾不足一个完整预测块的样本不计分。NRMSE 分母为完整估计记录 `yEst` 的标准差。

## 解释边界

这是作者水箱仓库 MATLAB 脚本中二状态 N4SID（`n4sid(data_id, 2)`）之外的独立 ARX 补充模型，不声称复现该 N4SID 结果。每块上一输出状态是由模型传播得到的预测量，并非实测的第二个输出样本。公开测试标签曾被查看，所有结果仍是开发证据。模型也未加入水箱硬件安全约束。
