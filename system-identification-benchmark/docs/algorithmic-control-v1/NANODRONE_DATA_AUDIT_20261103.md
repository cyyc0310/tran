# Nano-Drone 外部控制系统数据审计

审计日期：2026-11-03。这里只核验数据发布、字段、采样和评测合同；**没有训练或评分任何模型**。

## 数据收据

- 官方仓库：[`idsia-robotics/nanodrone-sysid-benchmark`](https://github.com/idsia-robotics/nanodrone-sysid-benchmark)，固定提交 `2d921b57d166fe2debe08a5d39bd07297c5abc39`。
- 仓库中的 CSV 是 Git LFS 指针。已取回 15 个对象，并逐个验证下载文件的 SHA-256 和字节数与该提交的 LFS 指针一致。逐文件路径、行数、字节数和哈希见[机器可读 manifest](nanodrone_data_manifest_20261103.json)。
- 文件实计：训练 12 条、55,599 行；测试 3 条 Melon 运行、19,497 行；总计 75,096 行。训练按轨迹为 Square 7,600、Random 23,999、Chirp 24,000 行。
- 论文写训练集 55,999 行、测试集 19,497 行，合计 75,496 行；与当前发布文件相比，训练部分少 400 行。原因尚未确定，可能是论文统计或发布快照差异，不能自行假定为无关紧要。
- 所有文件都是 21 列：时间、13 维状态（位置/速度/四元数/角速度）、4 路电机转速和 3 路机体系加速度。采样间隔实测约 0.01 秒；无缺失值；四元数范数接近 1。加速度不属于论文定义的 13 维预测状态。

## 适合研究什么

这是与本项目水箱、电机不同的真实物理系统，适合检验**模型选择/校准决策流程能否跨系统复用**。状态和输入维数完全不同，不能把水箱或电机的已训练参数直接迁到无人机；跨系统能迁移的是评测方法或决策规则。

作者的基准使用 Square、Random、Chirp 训练，Melon 测试；模型从一个真实起点状态和随后 50 步的实测电机转速，预测未来 0.5 秒状态。作者指标按滑动窗口汇总，窗口高度重叠。它衡量的是**已记录输入路径条件下的离线多步预测**，不等于在预测开始时就知道未来控制的线上预测，也不等于闭环控制表现。[论文](https://doi.org/10.1016/j.conengprac.2026.106871) · [官方基准页](https://www.nonlinearbenchmark.org/benchmarks/nano-drone)

这和本项目的稀疏状态预算并不完全一致：作者协议每个窗口都重新提供真实起点状态。若用 Nano-Drone 评估我们的研究问题，必须另行冻结协议，例如将 Melon 的稀疏前缀只用于选型/校准，并从后续运行的非重叠 0.5 秒窗口评分；报告三个飞行运行的单独结果，不能把数千个重叠窗口当作数千次独立重复。由于数据和原论文分数都公开，这属于**冻结方案后的外部复核**，不能称盲测。

实现还需固定状态表示：论文以四元数定义 13 维状态，作者数据加载器默认把四元数转成三维旋转向量，模型实际状态为 12 维；评估应统一表示，并用旋转测地误差评价姿态，避免直接比较四个四元数坐标。

## 准入结论和边界

| 项目 | 结论 |
|---|---|
| 文件可取回且可校验 | 通过；15 个 LFS 哈希全部匹配 |
| 真实 MIMO 控制系统和多步预测 | 通过；4 路电机转速输入、12/13 维状态、100 Hz、最高 0.5 秒公开协议 |
| 发布统计一致 | 有差异；当前 CSV 比论文训练样本统计少 400 行，需在复现中注明 |
| 独立系统 | 通过；可作为不同物理平台的外部复核，不是跨设备参数迁移 |
| 盲测和广泛泛化 | 不通过；测试数据和测试分数公开，且只有 Melon 一种留出轨迹、3 次运行 |
| 许可证 | 论文的 ETH 记录标注 CC BY 4.0；GitHub 根目录没有单独的代码/数据许可证文件，因此不能把论文许可自动当作代码和原始数据的明确许可。先引用、不再分发原始对象；若要发布衍生数据包，应先确认数据许可。[ETH 记录](https://www.research-collection.ethz.ch/items/5ef14ad7-431f-4c34-b34e-990ec04c3c60) |

**决定：** Nano-Drone 可作为“物理系统独立、数据公开、非盲、单一留出轨迹类型”的外部复核数据。它不能单独支持“普遍跨系统泛化”或“已经实现可靠控制预测”的主张。下一步先冻结目标观测预算、候选模型、状态表示、窗口抽样和评分规则，再算测试指标；本次数据审计不构成性能结论。
