# Cascaded Tanks 稀疏已知输入扩展任务协议 v1

冻结日期：2026-11-03。数据来自公开 4TU 数据集，目标输出已在准入审计中被查看。因此本协议及后续任何分数都属于**开发期公开数据结果**，不是盲测或独立确认。

## 目的与官方合同边界

用一个额外实体水箱系统核验固定稀疏输出观测和已知泵输入下的短时预测流程。官方数据把 `uEst/yEst` 用作估计记录、`uVal/yVal` 用作测试记录，并规定测试数据不能参与模型估计。这里保留官方训练/测试记录分离，但允许从 `uVal/yVal` 前缀拟合一个标量路径倍率作为**新的目标校准扩展任务**；因此校准结果不是官方 benchmark 原分数。测试后缀只用于评分，不选模型、特征或阈值。

该数据只有一条估计和一条测试记录。重叠/非重叠时间块只是同一次记录内的评分查询，不算独立重复，也不用于显著性检验或跨重复置信区间。

## 采样和预算

- 原生样本间隔固定为 4 秒；泵输入在每个 4 秒区间内零阶保持。
- 目标校准预算为 1、3、5 个原生间隔，即 4、12、20 秒。允许状态测量是测试前缀 `yVal[0:n+1]`，输入为同一前缀各区间的 `uVal[0:n]`。
- 预测跨度为 1、3、5 个原生间隔，即 4、12、20 秒。每个评分块只用块起点测得的输出初始化，之后滚动模型，并提供该块完整的已记录未来泵输入。
- 该评估是离线条件块预测：不代表未知未来输入预测、连续全程无重置自由滚动或闭环控制。

## 冻结方法

1. **零阶保持：** 预测输出维持块起点值。
2. **线性端点插值 oracle：** 线性连接该块真实起点和终点输出；使用未来标签，仅报告为离线下界，不参加因果预测排名。
3. **线性输入输出 ARX/状态更新：** 在 `uEst/yEst` 上拟合固定的一阶更新式 `y[k+1] = a*y[k] + b*u[k] + c`；不在目标前缀重新估计系数。
4. **二次多项式稀疏动态模型：** 拟合 `dy/dt` 对 `[y,u]` 的二次多项式库，包含常数、一次项、平方项和交互项；使用 STLSQ。稀疏阈值及其对应非零项集合，只从估计记录的前 80% 拟合、后 20% 按 1/3/5 步块评分中选择；冻结该支持集后，在完整估计记录重拟合系数。称为“SINDYc 风格离散观测实现”，不称为作者代码复现。
5. **有限目标校准：** 对每种冻结动力学模型只拟合一个路径倍率 `gamma`，应用 `yhat_gamma = y0 + gamma * (yhat - y0)`。`gamma` 由目标前缀连续滚动轨迹最小二乘得到；不重训模型权重，不依据测试后缀调整或拒绝校准。无有效分母时设为 1 并记录原因。预算 1/3/5 均分别拟合。

本数据包没有确认到与该数据精确对应的作者 Neural ODE/混合检查点；不为本系统伪造该基线。主项目的独立 Nano-Drone 任务另含作者 Phys+Residual 混合模型，结果与本任务分开报告。

## 报告指标与约束

- 报告每个模型/预算/跨度的 RMSE、MAE、以估计集输出标准差归一化的 RMSE、有限值比例、块数和失败块数；逐块误差另存 CSV。
- 对输入和特征矩阵报告秩、奇异值和条件数，分别计算估计集、目标前缀；这些是数据激励诊断，不是可辨识性保证。
- 不用任意截断隐藏发散或不合理值。输出观测出现 10.0 只称数据中的上端饱和/观测范围，未查实设备高度或安全边界；不把 10.0 当作经过认证的物理上限。
- 不把同一条记录的 1,024 点或评分块当作独立试验重复；不给出基于块数的显著性或跨重复不确定度结论。

## 停止与解释

若稀疏校准在该数据上改善，只报告这一条目标记录内的局部结果；不据此宣称跨设备算法成功。若校准变差，作为负迁移例证。无论结果如何，主论文算法创新仍需在 InTaSet 双向和 Nano-Drone 等独立系统上稳定胜过强基线并通过未参与规则制定的新整条运行确认。
