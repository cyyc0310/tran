# Nano-Drone 外部系统复核协议 v1（评分前冻结）

冻结日期：2026-11-03。数据固定为官方仓库提交 `2d921b57d166fe2debe08a5d39bd07297c5abc39` 的 Git LFS CSV；逐文件收据见[`NANODRONE_DATA_AUDIT_20261103.md`](NANODRONE_DATA_AUDIT_20261103.md)和[`nanodrone_data_manifest_20261103.json`](nanodrone_data_manifest_20261103.json)。v1 评分实现前进一步明确：报告源 run 4 全候选排名和源端选中模型；非零目标预算并列输出冻结模型与单标量校准模型；端点姿态插值按 SO(3) 最短测地线处理。本文件在本项目计算 Melon 测试分数前冻结。测试数据与作者论文分数公开，因此这是前瞻冻结的外部复核，不是盲测。

## 信息合同与切分

- **源训练：** `Square/Random/Chirp` 的 run 1–3，共 9 条完整轨迹；状态以 100 Hz 密集可见，训练 ARX 和 SINDYc 风格基线。作者已发布 MLP、LSTM、物理模型和物理—残差混合模型的 checkpoint 与训练 scaler，固定使用官方 checkpoint，不在 Melon 上重训这些模型。
- **源验证：** `Square/Random/Chirp` 的 run 4，3 条完整轨迹。在此选择 ARX Ridge 系数和 SINDYc 稀疏阈值，并按每运行等权的 h=50 归一化均方误差排序全部候选，记录源端选出的模型；此排序只用于比较“源端选型”策略。
- **目标评测：** Melon run 1–3。每条运行的 0.5 秒前缀只用于预算内适配；后缀评分。三个 Melon 运行分别汇报，不把时间窗口当成独立飞行重复。
- **输入：** 四个实测电机角速度通道，以 100 Hz 作为已记录外生输入路径。每次滚动给出随后最多 50 个真实电机转速；结论限于离线条件输入回放，不声称线上已知未来控制或闭环性能。
- **目标状态预算：** 目标状态只在 0.5 秒网格可见；预算为 0、1、3、5 秒，对应 0、2、6、10 个完整的 0.5 秒目标转移。预算前缀后冻结模型参数/适配系数；后续每个 0.5 秒预测窗的起点状态只用于初始化，不再校准。
- **滚动窗口：** 每条运行按 50 个样本为一步长取非重叠预测窗，最大预测时长 0.5 秒。评分时点为 h=1、10、50（10 ms、100 ms、500 ms）。模型在一个窗内不得读取窗中真实状态。

## 模型与目标校准

1. **端点插值：** 作为离线重建对照，允许使用该 0.5 秒区间的真实右端点；位置、速度和角速度线性插值，姿态沿 SO(3) 最短测地线插值；单独报告，不与给定未来输入下的因果模型混排。
2. **ARX/线性状态空间：** `x[t+1] = A x[t] + B u[t] + b`，输入状态均由训练源数据标准化；Ridge 系数只在源 run 4 选择。
3. **SINDYc 风格：** 对 12 维状态与 4 维输入建立总次数不超过 2 的多项式库，保留显式常数项；用 STLSQ 拟合一步状态导数；阈值只在源 run 4 选择。清楚标记为本项目离散数据实现，不称作者原始 SINDYc 复现。
4. **作者基线：** 官方 MLP/Residual、LSTM、PhysQuad 和 Phys+Residual checkpoint；保留其官方输入、标准化器、SO(3) 三维旋转向量表示及模型参数。运行前逐一核对作者仓库提交中的模型源码、scaler、checkpoint 文件与工作副本一致，并记录 SHA-256。已审阅到发布的 PhysQuad 实现将 `omega_dot` 乘以零，因此纯 PhysQuad 仅作为“作者发布实现”诊断，不解释为有效的角动力学物理基线；混合模型也须按该发布实现解释。
5. **目标校准：** 每个候选先按原模型自由滚动完整个 0.5 秒窗，再用同一个标量 `gamma∈[0,2]` 缩放整条状态轨迹相对起点的位移：`x̂_gamma(h)=x0+gamma·(x̂(h)-x0)`。校正后的状态不反馈到窗内后续递推，因此所有模型接受同一种输出路径校准。以目标前缀 0.5 秒转移终点的、按源训练尺度归一化的状态误差选 `gamma`。零预算固定 `gamma=1`。不按测试后缀调参，不单独拟合 12 个倍率。每个非零预算同时报告目标校准版本与 `gamma=1` 源模型冻结版本。报告每预算的目标转移数；两个转移的 1 秒条件必须标为极少校准信息。
6. **参考对照：** 零阶保持 `gamma=0` 单独列出。源模型冻结结果已按上条列出。

## 指标和诊断

- 逐模型、预算、运行、预测时距报告：位置 RMSE（m）、速度 RMSE（m/s）、姿态测地角误差（度）、角速度 RMSE（rad/s），以及对 12 个状态分量按源训练标准差归一化后等权宏平均的 NRMSE。
- 分别报告 h=1 的一步误差和 h=10/50 的自由滚动误差；报告有限值失败/发散率。某模型在某运行、某时距的任一评分窗产生非有限状态时，该时距的主误差记为无穷大，并同时报告失败比例，防止均值计算悄悄跳过失败窗。汇总先按每条飞行运行求平均，再对三条运行等权汇总，同时列出每条运行，避免将相邻窗口当作独立重复。
- **物理边界：** 只使用独立设备知识能确认的硬约束。若没有可追溯的硬边界，则不伪造边界；报告预测是否超出源训练状态包络、是否出现非有限值，并明确它们是分布外/数值诊断，不等于物理违法。姿态在 rotation-vector 表示下转回旋转后计算测地误差。
- **激励/可辨识：** 只用源训练数据报告四路电机输入协方差特征值、有效秩和条件数；报告 ARX 回归矩阵与 SINDYc 候选特征矩阵的秩/奇异值/条件数。秩或条件数不单独当作可迁移保证。
- **数据边界：** 训练行数与论文报告差异 400 行；论文许可和代码/数据许可分开注明；不重新分发作者原始数据或代码。完整差异在数据审计中说明。

## 解释边界

此数据集能检验固定评测流程能否在不同物理系统上复用，不能把 InTaSet 或电机的模型参数直接迁移到无人机的 12 维状态空间。测试轨迹类型、三条飞行、开放测试标签及作者公开结果限制了独立确认强度。Nano-Drone 没有作者 Neural ODE checkpoint；InTaSet 作者仓库也未提供其 Neural ODE 源码、权重或完整训练设置，因此这两项缺口必须继续明确列出，不能用其他模型代称。
