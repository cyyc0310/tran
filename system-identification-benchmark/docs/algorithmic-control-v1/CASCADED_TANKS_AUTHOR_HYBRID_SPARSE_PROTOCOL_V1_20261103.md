# Cascaded Tanks 作者连续时间神经状态空间模型：稀疏输出比较协议 v1

冻结日期：2026-11-03。该协议复用 4TU Cascaded Tanks 官方估计/测试切分，并将作者已发表的结构化连续时间神经状态空间模型接入本项目的稀疏输出合同。目标 `uVal/yVal` 已在早期数据准入和其他开发实验中查看；本轮及后续结果都是**开发期公开数据结果**，不属于盲测或独立确认。

## 作者模型来源与任务区别

Forgione 与 Piga 的 Apache-2.0 代码仓库提供 Cascaded Tanks 实验目录，数据文件与本项目 4TU 官方档案中的 `dataBenchmark.csv` 已逐字节核对一致。上游模型 `CascadedTanksOverflowNeuralStateSpaceModel` 有两个潜在状态：第一状态导数由 `(x1,u)` 的小型 ReLU 网络给出，第二状态导数由 `(x1,x2,u)` 的小型 ReLU 网络给出；第二状态对应观测水位。作者脚本将网络宽度设为 100，并用前向 Euler 积分，步长等于原生采样间隔 4 秒。

本扩展保留作者模型结构和其截断模拟误差训练配方的主要设置：估计记录 `uEst/yEst`、可学习的逐样本潜状态、序列长度 128、批大小 64、Adam 学习率 `1e-3`、10,000 次更新、前 1,001 次只优化输出拟合、其后加入权重为 1 的潜状态一致性项。为报告随机初始化影响，运行种子 0、1、2。相对上游原脚本，本实现去除了绘图、TensorBoard 和 GUI 依赖，并把训练与稀疏输出评测接入本项目接口；因此称为**作者结构/训练配方的代码复现与协议适配**，不能称作上游结果原样复现。

上游固定版本、源码、许可证和文件哈希见 [`external-source/forgione_piga_sysid_neural_continuous/README.md`](external-source/forgione_piga_sysid_neural_continuous/README.md)。原论文/上游完整测试分数与本扩展分开；本扩展不能替代 InTaSet 作者 Neural ODE 基线。

## 训练与信息预算

- 训练只用官方估计记录 `uEst/yEst`。整个 1,024 点估计记录都可用于作者模型训练；固定上游配置，不用测试记录选网络结构、正则、阈值或训练轮数。
- 测试记录为 `uVal/yVal`。原生采样间隔固定为 4 秒，泵电压在每个间隔内零阶保持；模型已知每个预测块的完整记录输入路径。
- 目标前缀预算为 0、1、3、5 个原生转移（0、4、12、20 秒）。预算 `b>0` 时，标量输出前缀为 `yVal[0:b+1]`，输入为 `uVal[0:b]`；只拟合一个无约束输出路径倍率 `gamma`，公式与 [`CASCADED_TANKS_SPARSE_INPUT_PROTOCOL_V1_20261103.md`](CASCADED_TANKS_SPARSE_INPUT_PROTOCOL_V1_20261103.md) 相同。`b=0` 时 `gamma=1`。
- 预测跨度和稀疏测量间隔同时取 1、3、5 个转移（4、12、20 秒）。每个块只在起点读取下水箱输出；块内滚动时不给模型真实中间输出。上水箱潜状态从源记录学习的初始估计开始，并沿已知泵输入连续传播；每个稀疏测量时刻只把可观测的下水箱状态替换为实测输出。这个潜状态延续/单通道重置规则固定应用于全部目标预算和跨度。
- 目标前缀只用于拟合 `gamma`，不改模型权重或优化潜初始状态。预测期间的观测重置只使用块起点的已允许稀疏输出。
- 端点插值 oracle 沿用已有协议单独报告；它不进入因果方法排名。

## 输出与边界

保存每个训练种子的模型参数和潜状态、训练收据、逐块逐步预测、分种子指标和种子汇总。报告 RMSE、MAE、按估计记录标准差归一化的 RMSE、有限值比例、负输出比例和超出估计记录观测范围比例。后两项是物理合理性/数据范围诊断，不是硬件安全边界；已知传感器未校准、存在噪声和饱和。

三种训练种子只描述模型初始化/优化方差，不是三条物理重复。预测块来自单一公开测试记录；不以块数或种子数计算独立物理显著性。报告作者结构的模型结果与 ARX、SINDYc 风格模型并列，但独立系统上只有一条估计记录和一条测试记录，不能据此提出普遍迁移或算法创新主张。

如修改模型、训练配方、状态重置规则、目标校准或预算，必须另建协议版本；若查看结果后发生修改，后续确认需要新的完整物理运行或新系统。
