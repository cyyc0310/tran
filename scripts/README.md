# 脚本与复现边界

当前研究主线与可支持的论文结论见[研究状态](../docs/RESEARCH_STATUS.md)。`scripts/` 中的版本化 runner 是研究过程产物，不代表当前推荐方法；不少脚本依赖被移至远程 [`pending` 归档分支](https://github.com/cyyc0310/tran/tree/pending)的配套协议、特定脚本版本和本地数据。

运行旧实验前应先从 `pending` 切到对应快照，核对同名协议、代码哈希、目标标签定义和输入 vintage。不能只因脚本仍在主线目录中，就把它解释为当前算法或可直接复现入口。

本分支不包含原始小时数据、大表和模型文件。完整近期 runner、实验文档和小型评分/哈希收据在 `pending`；原始/大型产物仅保留本地，没有上传。
