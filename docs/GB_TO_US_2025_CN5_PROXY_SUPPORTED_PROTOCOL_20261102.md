# 英国训练到美国：2025同标签CN5代理迁移（EIA支持子集协议）

冻结日期：2026-11-02，目标预测与方法分数查看前。它是[七BA全量协议](GB_TO_US_2025_CN5_PROXY_PROTOCOL_20261102.md)的数据质量后续版本，专为达到预先设定的小时标签支持门槛的BA队列执行；不取代全量质量失败记录，也不是盲地域确认。

## 预评分资格筛选

目标响应使用EIA-930 2025原生balance燃料记录，并遵循本项目`eia_proxy._proxy_rows`的全燃料列完整、发电量平衡、正代理分母、完整UTC日质量定义。逐BA仅以这些响应数据质量字段确定资格，不读取固定因子强度、预测误差或模型排名。资格规则冻结为：2025年有效完整小时至少占8,760个全年小时的80%。

该机械规则在目标强度评分前应用后，固定纳入 **BPAT、ERCO、FPL、MISO、NYIS**；**CISO、ISNE**分别只有4,632/8,760（52.88%）和4,872/8,760（55.62%）有效小时，故排除。其余五区分别有8,592、8,064、7,464、8,352、8,664有效小时，均通过。名单冻结后不得按模型误差替换BA。

该支持预检已读取原生燃料/平衡响应，并构造了固定因子代理的有效性掩码；因此本轮不是标签盲测。预检未计算可比较的目标CIF强度、预测残差或模型指标。

## 估计对象和信息合同

- GB源2022小时固定因子发电侧代理训练、2023源端校准；目标为美国上述五个BA的2025小时发电侧固定因子代理。固定映射顺序`coal, gas, oil, other, nuclear, hydro, wind, solar`，因子`1000, 400, 800, 400, 0, 0, 0, 0 gCO2/kWh`。
- 目标响应来自EIA-930 2025原生balance文件，按UTC结束时间减一小时；燃料映射、储能排除、负值截零和完整日质量规则遵循`eia_proxy`现有定义。标签不是官方/实测CIF。
- 目标输入为EIA-923按BA聚合的当前年度Final，精确`t−2`火、水、核、风、光月份额与目标BA当地日历。只用目标月`t−2`月份额，不用目标小时燃料、目标月或`t−1`月量、装机、负荷或天气。该年度终版晚于预测时点，属于严格滞后预算模拟，不是as-issued回放。
- 报告每个BA的EIA-923月输入与EIA-930小时目标代理在五类总量及结构上的差异；不以目标小时标签修正月报输入。

## 固定预测、评分与解释边界

复用`cross_country.py`的`anchor700`、`source_thermal_ef`、`calendar_ridge`、`coarse_ridge`、`coarse_boosting`和`coarse_recomposition`，所有方法仅见同一五类严格滞后月报与当地日历。校准仅用GB 2023源残差。先封存五BA逐小时预测、来源校准和输入/代码/协议哈希，再用已完成质量预检的目标代理评分；报告BA等权宏、逐BA和逐本地月MAE、形状MAE、CRPS、覆盖、宽度与Winkler。

这为US→GB 2025固定因子代理补充方向相反的同公式开发队列，但源目标空间支持不同：英国全国对五个美国BA，EIA-923最终值口径也与EIA-930响应边界不完全一致。不得将其称为跨国家独立样本推断、国家条件覆盖保证、中国小时准确度或消费侧证据。
