# 美国 BA 伪目标专家门控未迁移到英国官方消费强度

按[冻结协议](OFFICIAL_PSEUDOTARGET_BA_ENSEMBLE_PROTOCOL_20261101.md)完成 US→GB 开发回测。七个美国平衡区各自轮流作为源伪目标；专家仅用其他BA的2022官方消费强度标签训练，2023H1留区标签选组成门控温度，2023H2校准。GB 2024共8,784小时预测先写盘封存，再读取NESO消费强度标签。

## 结果

源端七BA等权伪目标选择为`tau=∞`，也就是**等权专家平均，不使用组成相似度门控**。温度验证MAE为：`∞` 113.83、5 113.89、2 114.07、1 114.51、0.5 116.33、0.25 122.08、0.1 130.05 gCO₂/kWh。组成门控越尖锐，源端留区表现越差；即使源端CV没有选择门控，GB留出目标也没有受益。

等权与门控结果完全相同，因为源端选出的门控温度为无穷大。相对粗月HGB，专家集成MAE高75%；相对强重组MAE高127%，区间分数也显著恶化。较窄区间对应极低覆盖，源端2023H2的尺度校准没有捕捉US到GB的消费侧误差转移。

## 对四项研究重点的影响

- **跨国小时实验：** 官方消费侧US→GB任务已接通，并可证明简单固定EF重组在此开发目标明显胜过粗月直接HGB和BA专家集成。但GB 2024已在此前实验中查看，此结果不是盲测。
- **中国信息条件模拟：** US留BA伪目标训练没有生成可迁移英国的专家混合；此前生成侧严格五组门控也没有超过强重组。停止在同一小型BA队列上继续扫相似度距离或温度。
- **燃料关系迁移：** 专家预测消费侧官方强度，仍混有EIA对跨区电力排放的消费侧分摊定义；不能把其误差解释成燃料内部发电响应迁移失败的单一证据。发电侧燃料关系应在固定EF一致标签轨道独立评价。
- **可靠性：** 该伪目标专家源校准区间在GB只覆盖16.6%。不得将源BA留区分数当作跨国覆盖保证，也不能以区间变窄称作效率改善。

中国基准继续维持用户确认的两条轨道：本地发电侧CIF以分类发电量为主输入；消费侧CIF需另列跨省交换量及来源碳强度的信息可得性。消费侧结果不能由发电侧代理替代。

## 隔离与复现

GB与七个美国BA的2024标签文件在磁盘上已由前序开发实验生成并查看。本轮启动审计记录了8个既有文件名；本轮预测代码没有在封存前读取其内容，标签仅在封存后进入评分。因此结果是已看目标上的开发回测，不是未看目标确认。预测封存哈希、源验证、代码/输入哈希和标签哈希均见[运行证据](evidence/official-pseudotarget-ba-ensemble-r1/README.md)。
