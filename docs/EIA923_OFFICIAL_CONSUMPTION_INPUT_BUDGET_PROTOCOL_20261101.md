# EIA-923月度输入与官方消费强度标签配对实验协议

冻结日期：2026-11-01，运行前。研究问题：把美国源区/目标区的小时回算粗月量替换为真实EIA-923 BA月统计后，跨国小时消费强度迁移是否改变？

## 配对设计

- 方向：US→GB、GB→US；美国七个BA，GB一个全国目标。
- 标签：EIA官方消费侧CO₂强度和NESO消费侧`CARBON_INTENSITY`小时平均。沿用官方强度轨道现有标签整理、单位及UTC对齐规则。
- 信息臂：`hourly_reconstruction`用EIA-930/NESO小时发电结构回算月组成；`eia923_monthly`在美国BA将其替换为EIA-923月度净发电粗组成。GB继续使用NESO月组成。预测时只用`t−2`及更早五类粗技术份额、日历和既有容量字段。
- 每个方向/信息臂单独在2022源小时响应拟合；2023响应作源端偏差/尺度校准；2024全年为开发目标。两臂共同支持小时上比较。
- 预测器保留官方消费强度均值、日历Ridge、粗组成Ridge/HGB、固定EF强重组和年度煤气容量条件Ridge/HGB。它们使用同一信息臂、相同源小时、校准窗口及目标小时；M+C模型作为装机参照，不将容量当硬约束。
- 预测先写盘并封存，之后读取2024目标标签评分。评价MAE、日内去均值形状MAE、Gaussian CRPS、90%覆盖、宽度与区间分数，逐月/逐区和宏观结果并列。

## 可见性与边界

EIA-923读取2020–2024现行年度最终档案，按`t−2`模拟；这不还原历史as-issued版本。EIA-930/NESO回算月量也是已修订小时源序列的月聚合。目标2024官方标签在此前开发工作中已打开，因此本轮是开发回测，不是盲测确认。EIA与NESO是各自机构的消费侧估算，定义及跨区排放处理不同，结果不应拼成统一真值。目标输入仅有粗月份额，不输入小时燃料、目标强度、目标响应或从目标标签估计的参数。

年度容量采用已有2020煤/气公开统计；该字段在中国省级公开表中未证实可获得，只作为单独扩展预算参考，不等价于中国可直接部署的年度技术类别装机表。

## 解释规则

真实月报在某一方向改善MAE，不足以证明整体可靠迁移；同时检查区间覆盖、宽度、最差区域和反向任务。若实际月报预算不能稳定优于小时回算，或容量头只改善点误差但恶化覆盖，应将其报告为失败/边界证据，不扫描目标专属参数。
