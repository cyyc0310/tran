# 意大利严格CN5燃料份额响应头顺序外部复核协议

冻结时间：2026-11-02，生成预测前。目的：检验既有严格CN5源端`fuelshare_history`能否在不同于AEMO的公共欧洲系统中，对固定因子小时发电代理提供点误差增量。该国的Carbon Monitor日尺度数据此前已使用，故本实验是**新小时代理上的顺序方法复核**，不是项目级盲国家确认。

## 目标系统、标签和输入合同

- 目标：意大利2023年3–12月；响应由Energy-Charts `public_power`小时发电量按冻结固定因子构造，不是官方或实测小时CIF。目标小时代理此前没有进入本项目小时预测评分。
- 来源：严格CN5开发面板九国NL、ES、BE、AT、SE、CZ、SK、HU、SI。2022源小时用于训练，2023年1–6月源域用于校准；不得纳入意大利作源训练或校准。
- 目标预测输入：目标当地日历及精确`t−2`到`t−7`的五组份额（火、水、核、风、光）；月份额从当前Energy-Charts修订小时量聚合，属于回算滞后模拟，非历史as-issued。
- 意大利燃料白名单在评分前冻结：硬煤→煤；天然气与`fossil_coal_derived_gas`→气；石油→油；生物质、废弃物、`others`→其他燃烧；河流/水库→水电；陆上/海上风→风电；太阳能→光伏；地热→`other_renewable`（EF=0）。未在API返回的核电、褐煤及明确缺失的类别作结构性零占位，仅指本代理映射口径；不把抽蓄、储能、跨境交易、负荷或派生比例计入发电代理。
- 仅在必需映射字段完整的小时评分；不可把字段内空值转零。2023年审计显示五类输入和代理标签所需主要映射完整；有效月份、支持小时在运行输出中再次核验。

## 模型与评分

- 候选冻结为既有严格CN5四头HGB燃料份额模型；训练样本、特征、树参数、非负单纯形归一和源小时粗形状均复用现成实现，不在意大利目标上训练或校准。
- 对照使用同一九国源训练、同一2023H1源校准的`anchor700`、`ratio_recomposition`、`macro_recomposition`、`ridge_history`、`direct_latest/history`和`factor_history`。采用与CN5实现相同的来源加权90%绝对残差半径。
- 目标预测先封存并核验SHA-256；之后才能读取意大利2023小时代理并评分。报告逐月、年度宏MAE、去日均形状MAE、90%覆盖、区间宽度、Winkler分数及全部方法配对样本数。
- 燃料组成候选只有在宏MAE相对`ratio_recomposition`与`factor_history`均至少改善5%、覆盖至少88%、Winkler不劣于最强同预算基线时才登记为值得进一步跨域确认的线索。无论成败，均不在意大利上调参。

## 可比性与停止规则

意大利日尺度CIF已在本项目出现；这是新小时标签/映射上的复核，不是盲地理确认。目标月量由当前修订小时响应回算，因而不检验as-issued输入；固定因子代理不等于真实或消费侧CIF。若燃料映射的缺失支持门槛未满足、标签闭合/唯一小时审计失败或预测哈希不通过，本轮标为无效而不改映射补救。若候选门槛失败，停止意大利上的调参，并将结果仅作为机制能否跨小时数据系统复现的证据。

Energy-Charts公开API及类别定义见[官方API](https://api.energy-charts.info/)，数据需署名Energy-Charts.info并遵守CC BY 4.0。输入原始响应用本地`data/energy-charts-v2-panel-r1/`副本及SHA清单固定。
