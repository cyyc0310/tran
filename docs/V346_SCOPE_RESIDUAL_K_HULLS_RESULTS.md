# V346：未覆盖电量大幅削弱月度类别与装机的小时风险约束

运行日期：2026-10-30。协议：[V346](V346_SCOPE_RESIDUAL_K_HULLS_PROTOCOL.md)。脚本：[v346_scope_residual_k_hulls.py](../scripts/v346_scope_residual_k_hulls.py)。首轮结果因残差装机臂混用2023总装机而作废；r2改为各容量臂匹配同年份装机和V345残差范围，结果与首轮汇总一致。采用r2省月结果和哈希：[结果目录](../results/v346-scope-residual-k-hulls-r2/)。

## 实验

在V341的330个完整省月上，把V345允许的规上覆盖残差加入V342五组小时K集合。残差月电量取0到该省年度全口径与月度规上总量差额之间；残差EF支持设为0–1000 g/kWh，热电EF保持400–1000，其它已报技术直接运行EF为0。2022装机作为滞后臂，2023装机作为回溯臂。残差范围和残差组装机上限按同一容量年份配对。残差组使用省级总装机作为单组小时上限，且与已报技术上限独立；这种约束允许各组同时超出总装机，因而给出保守外包络。

残差几乎不影响已经接近整月宽度的“仅月度”臂，但会明显抵消装机信息的收益。τ=300时，滞后装机原本把平均宽度从约796小时压到682小时；加入残差后回到约795小时，且328/330省月的外包络覆盖整个报告期。τ=100仍保留部分装机约束，但平均宽度增加约134小时。

## 结论边界

这是当前突破线索中最直接的负结果：若问题是全省全口径小时风险，规上月报与年度差额之间没有月度分配信息，容量约束无法补上这项信息；此前的小时K区间不能被解释成全口径风险保证。扩宽幅度是模型条件下的敏感性结果，不是实测覆盖率，也不是概率预测区间。残差EF `[0,1000]` 是宽支持情景而非实测范围；总装机独立上限使外包络更宽；真实官方接口值及历史修订版本仍待逐省核验。

论文判断随之收紧：可辩护贡献可能是**可观测统计口径、未观测残差与小时尾风险之间的信息可识别性基准**，而不是新预测算法。下一轮应寻找合法的全口径月度电量锚或残差技术拆分，测试在固定字段预算下能否恢复区间效率；若只能获得当前规上月度表，就应把“何时必须弃权”作为主要结论，并在独立小时标签上验证。
