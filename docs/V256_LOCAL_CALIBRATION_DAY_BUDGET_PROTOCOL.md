# V256 年度热耗率锚的本地小时校准日预算

## 问题与状态

V254来源区风险分布在已打开的10个目标BA上未达到90%整日覆盖。V256量化在年度热耗率中心固定时，需要多少目标本地完整日风险标签，才能校准小时区间；同时区分随机同月校准与按时间先后校准。目标小时标签已在V249–V254中使用，因此这是信息预算重分析，不是盲测。

## 冻结样本与中心

- 目标BA固定为FMPP、GVL、IID、JEA、PSCO、SC、SEC、TAL、TEC、TIDC；目标年2025，按BA-month评分。
- 仅使用V253保存的直接实测CEMS完整24小时日。全部120 BA-month均有28–31个完整日。
- 区间中心固定为V252年度热耗率迁移预测吨数除以V253目标月CEMS毛发电量，再乘`907.18474`换算为g/kWh。中心不随校准日预算变化。
- 每日分数为该日24小时内相对中心的最大绝对误差；区间为中心±有限样本90% split-quantile。

## 信息预算和拆分

比较本地校准预算`n={9,12,18,24}`个完整日。对每个n，有限样本次序统计量索引为`ceil(0.9(n+1))`（1-based）；n不足以得到有限90%分位数的更小预算不纳入有限区间比较。

1. **随机同月校准**：每个BA-month、每个预算重复200次随机日排列，前n日校准、其余日评分。各n复用同一排列，形成嵌套校准日集合。
2. **顺序校准**：将月内日期升序排列，最早n个完整日校准，之后所有完整日评分。它模拟月内前段观测后对后段作风险预测，但各月校准时长不同。
3. **外区零本地参照**：V254预先生成的2024来源风险q90和目标12日本地校准汇总，作为已报告参照，不参与V256选择。

主要指标为24小时整日覆盖、区间全宽和Winkler90，按BA等权汇总（先在BA内平均月份/重复）；另报告BA、BA-month层级差异与重复稳定性。整日覆盖目标为90%。不使用目标标签挑选预算，也不以平均值单独声称达标。

## 解释边界

目标中心依赖2025目标月发电量和2024目标BA年度热耗率；所以即使顺序校准，仍是月后信息条件下的小时风险预算实验，不是月初预测。随机校准属于同月回顾性信息价值分析。整日风险分数有强日间/月份依赖，有限样本分位数的分布无关解释要求交换性；顺序结果尤其用于检验时间漂移，不当作保证。所有标签为EPA CEMS筛选化石机组毛负荷强度，不是BA全网CIF；10个目标地区已打开，不能称外部验证。
