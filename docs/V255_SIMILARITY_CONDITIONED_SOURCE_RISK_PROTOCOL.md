# V255 相似地区条件化的零本地风险校准

## 问题与样本状态

V254的全来源风险q90对新BA平均较窄但整日覆盖不足，统一抬高q后仍有少数地区严重欠覆盖。本轮测试能否用目标可得的月燃料结构与年度热耗率，从源BA中选择更相似的风险分数，再在目标区没有小时校准标签的条件下形成区间。目标BA标签已在前序方法中打开，因此V255是开发重分析，不是盲测。

## 相似度定义

对BA-month，用逐燃料月毛发电份额 `s_f` 与上一年度逐燃料热耗率 `r_f` 形成特征。目标与源BA距离为：

`D = Hellinger(share_target, share_source) + 0.25 × RMS_target-share_weighted(log(r_target/r_source)) + unsupported_share`

其中 `unsupported_share` 是目标中源BA没有对应正热耗率的燃料发电份额；热耗率差只在双方都有正值的共同燃料上计算。距离公式和权重固定，不根据目标结果调整。

## 来源风险与K选择

- 每个源BA-month风险分数沿用V254：`max_h |CIF_hour - annual_heat_rate_center|`，只用2024来源日标签。
- 目标BA始终从可选源BA中排除。按上述距离选择 `K∈{5,10,20,全部}` 个源BA，再对这些BA同日历月的日风险分数取有限样本90%次序统计量作为目标半宽。
- 先在2024源BA上逐BA留一验证K。选择平均来源日分数覆盖不低于90%、且至少80%可评分BA-month覆盖不低于85%的K中平均半宽最小者；若没有K满足条件，选择平均来源覆盖最高的K，并明确报告筛选门槛失败。
- 锁定K后应用到2025目标BA。比较V254全源q90、相似源q90及V253的12日本地风险校准参照。相似源q不得用目标小时标签、目标月热输入或目标本地风险分数构造。

## 输出和边界

报告K选择过程、2024源BA交叉验证覆盖/宽度、2025目标BA整日覆盖/小时覆盖/宽度/Winkler90、逐BA失败情况，以及来源分数数量。分层/相似度加权校准已有一般统计方法先例，若有效也不能单独宣称新算法；创新判断需回到CIF可得字段预算和实测区域外覆盖。数据仍为EPA CEMS化石机组毛负荷强度，非全网CIF；2025目标月发电量是月后值。零本地小时风险标签并不等于零目标统计信息，年度热耗率与逐类月发电量仍被输入。
