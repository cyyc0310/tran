# V9文献边界与创新审查

2026-10-23，Sol，检索并核查以下原始出版页/作者预印本。此文只界定已有工作与待验证假设，不以搜索未发现相同标题证明原创。

- Katz与Maierhofer的[月度可再生能源组成ALR-BDARMA研究](https://arxiv.org/abs/2507.04087)（2025预印本）已经研究组成动态、联合密度和季节离散度，并使用滚动预测及季节朴素/变换空间VAR/随机游走对照。因此“在单纯形上预测燃料比例”及“给出组成概率分布”本身不能作为本项目核心创新。V9 harmonic ridge与季节Kalman是透明标准参考，没有复现该论文的Bayesian Dirichlet ARMA，不能宣称战胜全部组成预测前沿方法。
- El Halabi与Brandt的[延迟反馈自适应共形研究](https://arxiv.org/abs/2609.07251)（2026预印本）分析反馈延迟与残差记忆时间的关系。本文的反馈是相应预测目标的滞后真值；TransCIF却只有粗组成反馈、没有目标小时CIF误差。这一区别意味着不能直接挪用其覆盖论证，也意味着普通“按信息年龄放大区间”不足以成为新贡献。
- Retzlaff等人的[非平稳时间序列边际与条件覆盖检验](https://proceedings.mlr.press/v266/retzlaff25a.html)（COPA 2025）强调平均覆盖可能掩盖条件失配。本项目LGEE在总体改善下仍失效，要求逐地区、上下尾与路径诊断；这些评价思想也不是独有创新。当前六个月bootstrap仅为已见地区的描述，并未实施或声称通过论文的整套检验。
- Ge等人的[半bandit反馈在线共形预测](https://proceedings.mlr.press/v267/ge25a.html)（ICML 2025）在标签是否落入预测集合决定可见性的设置下研究在线预测集。其反馈机制与电网粗聚合观测不同，不能拿该理论给本项目背书，也不应因“有限反馈”关键词就视为可直接替代基线。

## 本轮候选具体研究什么

V8表明实际组成替换主要降低水平误差；LGEE的重组分布却仍过窄。V9将两者作为不同机制：合法预序列粗组成误差形成联合情景；给定粗组成仍未解释的小时风险由源地区内层留区误差估计。第二轮用平均燃料轨迹的粗情景传播加剩余误差，替代原donor路径散布，避免完整donor方差与完整残差双重计算。

这是一项可检验的组合机制，仍包含标准偏差校正、状态更新、残差bootstrap和条件核。最重要的假设是源跨区残差在粗组成/日历条件下可迁移；月组成相近不保证调度与小时风险相近。若普通global残差或标准Kalman即可取得相同收益，conditional或release_bridge不应被包装成核心算法贡献。即使有数值改善，也需精确消融才能判断来自动态点预测、粗分布校准、中心变更或条件剩余风险。

## 足以支持论文增量还缺什么

先明确一个本项目推导的观测恒等式（不是新颖性声明）。在同一完整月份和相同发电支持上，记每小时总发电量为G、小时强度为C，已知燃料能源份额给出的粗强度为A，则

`A = E_t[G C] / E_t[G] = E_t[C] + Cov_t(G,C) / E_t[G]`。

因此组成即使完全准确，也没有直接识别小时等权均值；未知的发电量—强度协方差仍留下水平歧义，更不用说小时形状。两燃料排放因子取1000和0、月能源份额各一半：若两者出力始终相等，小时强度恒为500；若前半月高碳燃料出力为2、后半月为0，而零碳燃料始终为1，月能源份额仍相同，小时强度却为前半月666.67、后半月0，等权月均333.33。另一个保持总发电量恒定的互补波动例子，则可在同样月份额和均值下任意改变日内振幅。

这个反例解释了为何V9必须评价“给定组成后的剩余风险”，而不能把组成预测或能源加权锚当成小时真值约束。它没有证明源端学到的协方差/路径分布可迁移；这一假设必须受真实数据检验。若方法只学会把区间变宽，反例也不能将其变成有竞争力的算法贡献。

1. 识别与可迁移性：说明聚合观测消除了哪些歧义、仍保留哪些小时路径；给出明确假设或可反驳的适用边界，而非声称月统计足以识别小时分布。
2. 实证独占增量：在相同输入、拟合时期与情景预算下，超越加性锚、标准动态方法和普通残差传播，且局部覆盖与区间效率同时合格。
3. 独立确认：达到预定开发门槛后，冻结唯一候选与参考，在真正未查看地区检验；当前六区不能再次当作首次泛化证据。
4. 外部效度：美国固定EF发电侧代理、回溯月表和假定发布日尚不支持中国年统计条件、真实发布版本或消费侧CIF的结论。

当前不因多轮运行次数或代码工作量判断论文成熟度。最终结论须以[V9协议](COARSE_DYNAMICS_V9_PROTOCOL.md)下的真实结果与失败模式为准。

## 补充核查：最接近的任务与理论边界

- Zhang等的[DGCFM，WWW 2026](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf)，DOI `10.1145/3774904.3793051`，已经提出跨地区通用碳强度预测，并结合元数据超图、时空电力流图与Chronos。其§3.2和式(10)明确把历史碳强度序列作为输入。因此本项目不能主张首次“通用、可迁移CIF预测”；应精确定义为**目标地区没有历史小时CIF输入、仅有滞后粗统计**。零样本微调与零小时观测不是同一信息预算。未运行其实现，不能声称性能超过它。
- Maji等的[CarbonX](https://arxiv.org/abs/2510.01521)（2025预印本）同样研究统一模型、跨网格零样本预测与区间，但输入历史碳强度。本项目若建立多信息预算基准，可将此类模型放在允许历史小时上下文的独立轨道；不能向模型暗中提供我们设定中不存在的上下文，再把结果混在同一排行榜。
- Girolimetto等的[跨时间概率预测协调](https://arxiv.org/abs/2303.17277)研究线性聚合约束、联合抽样与多步残差。因此“粗到细传播”“联合场景”“残差保留依赖”都已有先例。这里的燃料份额与小时强度是能源加权的非线性关系；不能直接把月度组成EF点积设为小时等权均值约束。可探索的区别是未知发电量—强度依赖与可观测信息不足，须通过方法和实验体现。
- Cauchois等的[JMLR 2024弱监督预测推断](https://www.jmlr.org/papers/v25/23-0253.html)引入弱标签集合及相应弱覆盖概念。该概念与真实小时标签的90%覆盖不同。粗统计相容的路径集合可以帮助界定识别边界，但“存在一条相容路径”不能替代“覆盖真实路径”。V9尚未实现这类集合方法，也没有弱监督共形保证。

以上补查不改变已经封存的V9方法、网格或门槛。后续方法若引入更多公开协变量或弱标签集合，应单独预注册新一轮信息预算和可反驳假设。
