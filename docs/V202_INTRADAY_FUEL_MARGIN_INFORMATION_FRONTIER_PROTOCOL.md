# V202 分时燃料边际的信息预算前沿协议

## 问题

V201显示少量逐日燃料总量对一般小时尾部范围收窄有限。V202在相同月度八类燃料总量之上，比较少数日的1段（日总量）、2段（12小时）、4段（6小时）八类燃料统计，检验增量价值来自增加报告天数还是增加日内时间分辨率。

## 固定设计

- 复用V86源数据准备、V201的25个EIA平衡区 roster、2024-07至2025-12时间窗、固定EF（煤1000、气400、油800、其他化石400、核/水/风/光0 gCO₂/kWh）。
- 只保留24小时完整日，月度总边际和小时真值使用相同完整日，部分识别集合对所有满足报告边际的小时配置取包络。
- 比较每个报告日 `B=1/2/4` 个连续等长时段，每段分别发布8个燃料发电量；报告天数 `k=1/3/7/14`，日期用均匀间隔、月初和50次随机抽样。字段成本 `8×B×k` 明示。
- 另报告仅月度边际与全部日期的分时边际端点。目标τ={100,300} gCO₂/kWh；尾部计数阈值频率={1%,5%,10%}。
- 主要终点：小时尾部计数可行集合宽度/小时数与正证书、负证书、无判定比例。随机策略先按区月汇总50个schedule，严禁随机schedule重复键。

## 解释界限

这是在模型代理小时序列上的部分识别和值前沿，不是预测器、概率覆盖实验或中国外部验证；燃料EF固定且无机组容量、爬坡、网络交换约束。分时统计是否能从中国公开表取得仍未知。报告的月度边际是同一月内小时真值的oracle聚合，不模拟发布时点。
