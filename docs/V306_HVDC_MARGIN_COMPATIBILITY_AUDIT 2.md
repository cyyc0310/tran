# V306：公开特高压年度电量能否补成 V305 的区域OD观测？

## 问题与判定

V305 提出的最小补充信息是西北→华东和西南→华东两条区域流量。本轮核查公开的2023年点对点特高压直流年度输电量，判断能否把线路电量直接聚合成这两项。结论：**目前不能。线路数据可作独立物理输送量代理，但与V304所用区域流量边际存在口径兼容性问题，不能把它们当作同口径OD观测。**

国家能源局电力可靠性报告列出18条点对点直流系统总输送量，合计5679.49亿kWh；其中复奉262.77、锦苏304.20、宾金238.17、建苏234.05亿kWh。复奉由四川向上海，锦苏由四川向江苏，宾金送端位于四川/云南并落点浙江，建苏由四川送至江苏。四条都可归为西南→华东的物理线路。相加为1039.19亿kWh。

V304录入论文给出的西南区域全年**全部方向**送出边际为10,197,007万kWh，即1019.7007亿kWh。四条直流线年度量已比西南总送出边际高19.49亿kWh（约1.9%）。该超额虽然不大，但在边际声称精确闭合、线路又只是西南送电子集的前提下，二者不可能同时是同口径同边界的流量。因此，至少有统计边界、计量点、年度定义或转录精度差异，不能由此宣称已观察到西南→华东区域OD量。

雅湖线2023年另输送183.20亿kWh，送端在四川、受端在江西。因江西所属区域要按论文使用的七区划分表判定，本轮不把它并入华东。若其被纳入华中，西南线路总量与区域边际的不兼容会更明显。

## 两类公开来源存在差异

国家能源局可靠性报告和2023年可再生能源监测评价报告对同一批线路的年度数值并不完全相同。例如复奉分别为262.77与268亿kWh，锦苏304.20与308，宾金238.17与251，灵绍486.67与494，吉泉620.06与625。可靠性报告统计18个点对点系统；监测评价表列20条直流线路且说明电网企业报送范围。故即使端点明确，年度电量的统计对象与计量规则也需要先统一。

西北→华东是更有希望的候选：吉泉（新疆→安徽）和灵绍（宁夏→浙江）两条可确认线路合计1106.73亿kWh，落在V305计算的西北→华东可行区间912.27–2008.04亿kWh内。但“落入可行区间”只表示不矛盾，不代表与论文边际同口径，也不能证明遗漏交流联络线后仍可视为完整区域流量。

## 对 V305 的影响

V305 的代数结论仍然成立于它所声明的条件数据集：给定该论文的边际和路径图，两条区域OD数值足以识别运输多面体中的来源因子函数。但本轮发现，目前找到的公开特高压年输送量**不能直接充当**这两条区域OD观测。因而“最小信息预算”仍是数学识别结果，尚未通过公开数据的可操作性验证；也尚未形成小时CIF预测改进。

下一步优先级应调整为：

1. 取得并核对该论文的区域划分表、边际数据原始引用及计量边界；
2. 对接同一统计口径的年度省间/区域交易或净受入流量，或从国家电网/南方电网公开数据中明确筛出同口径值；
3. 若仍只有线路物理送电量，则重新建立“线路量—区域净交换量”的含损耗和多路径映射，不再把前者直接塞入V305运输多面体；
4. 只有完成口径对齐后，才测试其能否收窄官方EF迁移误差或小时风险区间。

## 复现

运行 `python scripts/v306_hvdc_accounting_compatibility.py` 可复算西南四条线路和论文西南总送出边际的比较。手工转录线路值来自[国家能源局《2023年全国电力可靠性报告》](https://prpq.nea.gov.cn/uploads/file1/20240911/66e102e09bfea.pdf)。线路端点来源包括[国家能源局对复奉线的说明](https://www.nea.gov.cn/2011-11/28/c_131274566.htm)、[国家能源局对锦苏工程的说明](https://www.nea.gov.cn/2008-12/03/c_131056365.htm)、[白鹤滩—江苏工程竣工信息](https://wap.sasac.gov.cn/n2588025/n2588119/c25382747/content.html)、[雅中—江西工程端点](https://obor.nea.gov.cn/detail/10068.html)；宾金端点和更多线路总量的并列比对见[线路监测表](https://www.iyanbao.com/pdf/407f9-3b6a7d38-26b6-43ad-81b2-b44b888936ad.pdf)，后者为行业研究报告，端点只作交叉核验。

所有线路数按公开报告精度录入；本脚本是兼容性诊断，不估计置信区间，不宣称核算了全口径电力交换。
