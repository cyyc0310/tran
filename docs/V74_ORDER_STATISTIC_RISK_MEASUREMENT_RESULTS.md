# V74：按风险目标选次序统计量，可用四摘要逼近完整G认证（2026-10-28）

在V20冻结的七个EIA代理区、1000个2024H2完整UTC日和四阈值上，把四个6小时块各一个G-only统计量分配给不同风险目标，并与四个ΣG²外计数集和完整小时G锐集对比。没有打开新地区/日期。所有目标判断均以块H=ΣG·C及G总量为基线条件，因此这些是额外4个标量对**已有块级碳能量信息**的边际价值；月度中国公开表没有这类块级H/G。

## 主要结果

下表为先区内平均、再七区宏平均的目标认证比例；目标不同，不把行间比例当作同一个预测指标。

| 阈值及目标 | 风险定向摘要 | G2外界 | 完整G锐集 |
| --- | ---: | ---: | ---: |
| τ=300，K=0 | minG：7.06% | 4.44% | 7.06% |
| τ=300，K≤4/24h | S₂：14.29% | 14.21% | 14.29% |
| τ=100，K≥8/24h | L₁：29.27% | 23.28% | 29.89% |
| τ=900，K≤4/24h | **S₂：42.97%** | 36.91% | **43.36%** |
| τ=900，K=0 | minG：14.29% | 14.29% | 14.29% |

τ=900的 `K≤4` 目标中，四个S₂标量认证429.65/1000宏等效地区日，完整24小时G认证433.60/1000；S₂达到完整G认证比例的约99.1%，比G2外界多约60.6/1000。地区分布：BPAT 100%、CISO 63.5%（G2 43.1%）、ERCO 13.0%（相同）、FPL/MISO均0%、ISNE 46.2%（G2 34.6%）、NYIS 78.0%（G2 67.6%）。这不是单一地区驱动。

同样，τ=100下L₁的 `K≥8` 认证率为29.27%，接近完整G的29.89%，高于G2的23.28%；但高阈值τ=600/900时，L₁未能认证 `K≥8`。minG的τ=300零事件增益仍由BPAT贡献，不能据此作普遍无事件结论。所有三类证书在1000日实际小时轨迹上均为零反例；这只是有限样本一致性审计，数学保证仍条件于冻结的支持/块约束。

## 可作为方法候选的内容与限制

候选贡献不是“换一个统计量”本身，而是：给定尾事件计数决策 `K≤k` 或 `K≥k`，从解析不等式推导最具针对性的低维G摘要（S_k或L_k），再用信息预算/地区分布/测量误差系统评估它何时逼近完整小时输入的识别价值。τ=900、K≤4上接近完整G是首个值得继续的定量候选；仍需要独立源或另一个时间窗口复现，并证明摘要发布成本、数值误差与真实块级H/G可得性合理。

关键限制：块级H/G来自小时燃料时序，是oracle基线，当前用户确认的中国公开月/年统计不提供；S₂/L₁亦需小时G端计算。G2是必要外集而非sharp，所以S₂相对G2的增益部分可能来自外界保守性；与完整G锐集的接近程度是更重要参照。不能称未来预测、概率覆盖、可部署中国CIF或已有算法突破。
