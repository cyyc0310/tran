# V88：装机容量让月度尾风险界明显变窄，但容量口径仍是主要风险（2026-10-28）

V88把EIA-860机组夏季/冬季/nameplate容量按BA与燃料桶聚合，作为每小时每燃料最大输出，和同一BA月的小时代理峰值对齐审计。对完整日覆盖≥80%的589个地区月，只有368个月（62.5%）所有燃料观测峰值和月电量都不超过容量；其余221个月不使用硬容量结果。这一质量门槛直接利用同期小时标签，只是回溯机制实验，不是可部署筛选。

在这368个容量可行地区月上，容量约束解析界相对V66月度燃料边际锐集收紧，所有观测K均包含在集合内，且容量集合嵌套于V66集合。率按地区等权、月等权宏平均：

这是明确的物理信息增量候选：不拟合小时曲线，而由月燃料边际和每燃料小时上界直接识别风险集合。风险越高，容量越难认证。解析容量可行条件可按K枚举事件小时组与非事件组的月燃料总量；没有启停/爬坡/负荷耦合时，组内用相同平均小时分配可构造可行路径。

## 不能忽略的限制

- 约37.5%的质量合格BA月因容量与EIA-930燃料小时不匹配被排除；排除依赖小时标签，所以报告覆盖率有回溯选择。按全部BA月计，容量条件可用率还更低。
- 使用目标当年的年末EIA-860库存，不是月初可见容量。滞后年度结果见V89。机组年内新建、退役、停机、分布式资源遗漏和BA映射都会改变合法上界。
- EIA-860机组库存按主要/可用燃料把多燃料机组容量重复计入每个可用类别，避免对单类容量低估；但这不自动解决EIA-930统计桶和容量边界不一致。
- 这是固定EF代理下的同期逻辑识别，不是实际CIF验证或预测区间覆盖；25区全部已打开，不是盲留地区确认。
