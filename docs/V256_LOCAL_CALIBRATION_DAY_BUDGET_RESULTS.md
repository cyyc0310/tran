# V256 本地小时风险校准日预算：随机同月有效，顺序外推欠覆盖

## 设计

按[V256协议](V256_LOCAL_CALIBRATION_DAY_BUDGET_PROTOCOL.md)，固定V253年度热耗率中心，在10个已打开BA、120 BA-month上比较9、12、18、24个完整日校准风险半宽。每个BA-month有28–31个完整日。随机同月条件使用200次嵌套随机日期拆分；顺序条件用最早n日校准、后续日期评分。整日覆盖是每个评分日的24小时同时覆盖率；汇总先在BA内平均，再BA等权。表中95%区间为10个BA成簇bootstrap percentile区间。

有限样本90%次序统计量排名为`ceil(0.9(n+1))`：n=9、12、18分别取样本最大分数；n=24取第23顺位。由于样本数增加时名义秩相对变化，宽度不要求随n单调。24日随机方案的区间比12日窄8.45%，但每BA-month平均只剩6.4个测试日；这不能解释成多校准日必然更省数据或稳定性更好。

随机同月的9日方案平均覆盖几乎正好90%，但仅为汇总点估计：10区中4区低于90%，最低89.47%。随机12日方案10/10区的经验整日覆盖均高于90%，且其覆盖、宽度、Winkler与V253已报告的12日本地日校准结果（92.10%、259.87、268.07）接近。V254的零目标本地来源q90为87.77%整日覆盖、宽度233.51、Winkler291.05。因此当前样本里，约12个随机同月风险日比零本地源分位数可靠，代价是区间较宽。

关键压力结果是顺序拆分：月初连续12天校准后，后续日整日覆盖仅84.00%；即使前24天用于校准，剩余月末日期覆盖也只有84.99%。月初n=9/12/18/24时10区中分别有10/10、9/10、6/10、7/10区低于90%。覆盖不足不是靠更窄区间获得的有效效率提升：Winkler并未稳定改善，n=18反而达到296.90。该差异说明随机同月拆分的交换性对结果很关键，目标风险存在月内时间变化，随机预算不能直接代表“先收集n天、预测后续天”的在线冷启动。

## 判断

V256给出了一个可复现的**同月随机风险标定预算基线**：在本数据中12天可重现约92%平均整日覆盖，9天处于临界且存在BA级低覆盖。它没有给出可迁移的最小目标信息合同，因为顺序校准显著欠覆盖。年度热耗率改善小时区间中心/效率的证据仍在，但对“零目标小时历史的新地区可信风险区间”尚未解决；跨区风险池和相似度风险池分别在V254/V255失败。

下一步应直接测试滚动/在线风险更新：每经过一个完整日，以最新n日风险重新校准并预测下一日，逐日记录覆盖和宽度；与月初固定风险、全来源q和同月随机拆分并列。若滚动更新仍在目标区失败，就应把论文结论限定为月后重建的信息预算/覆盖基准，而不是冷启动小时预测方法。

重要边界：年度热耗率中心使用目标2025月发电量，整套实验仍不是月初前瞻预测；目标标签已打开；CEMS标签是化石机组毛负荷强度，不是BA全网CIF。区间在对称中心周围构造，风险分数依赖日内相关且日期有漂移；bootstrap仅10个BA簇，不能替代独立地区验证。
