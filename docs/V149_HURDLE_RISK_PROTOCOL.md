# V149：稀少重组失效的发生与幅度

在V148数值诊断后冻结；所有目标已用于开发，不作为盲确认。复用V147的源区逆位移标签、合法特征、V146的嵌套曲线与30拟合/12校准角色。目标为PACE18月、LGEE24月、SC24月，两seed、两alpha(.1/.2)、600/900阈值；不增加本地信息。

每个拟合月的响应标签/特征已排除其整个地区，仅用其余29拟合地区；校准和目标使用固定30地区响应库。模型不使用目标端点、factor floor、小时轨迹、容量或天气。复用的29→30教师变化是近似，必须披露。

对水平/纵向两种曲线各比较四种尺度：

1. 全样本Ridge(alpha=10)拟合log1p(256δ)，预测后expm1/256。
2. 两阶段hurdle：LogisticRegression(C=1,max_iter=2000)拟合δ>0概率，正样本Ridge(alpha=10)拟合同一对数幅度；尺度为概率×幅度。
3. 同一正样本幅度作为尺度，检验收益来自发生概率还是幅度。
4. V148严格tie分位数回归q90，150树、LR .05、深2、叶15、min_impurity_decrease=1e-10、seed20261028。

线性模型仅用拟合样本学习StandardScaler；均采用等地区总权重，归一到样本平均权重1。正幅度模型仅在正样本上重新作等地区权重。所有尺度裁剪[1/256,1]。不按目标结果选择方法/超参。若训练事件只有单类，事件概率使用其拟合加权比例；无正幅度时用0。

用12个校准地区评估发生模型的区域等权Brier/AP及常数拟合发生率基线，另保存逐月概率；这些指标为源区泛化诊断，不是目标小时预测性能。校准规则保持V147：每月实际联合逆位移/预测尺度，区内max，区域秩；不支持月为∞。目标乘积超过1或无限则回退完整物理界，否则向上取δ格点。保存全部fallback。

比较V146/V147原族和V145强基线，注明联合/逐阈值校准差别。完整报告全部目标月份、两个seed、两alpha的上下端点/联合覆盖、宽度和固定90%区间评分。检查数据哈希、完整分母、区域角色、特征白名单、物理包含、alpha嵌套。该实验检验普通强基线与源区可学性；hurdle、Ridge、分位数回归均不作为原创方法。小时CIF原始gate仍须另外验证。
