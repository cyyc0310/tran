# 2026上半年：水平与形状互补的评分前冻结验证

本约定写于2026-10-23、第一次读取2026预测评分之前。2025单组件结果已经查看：seasonal主要改善水平，analog_shape_half小幅改善形状，因此2025组合实验只能作为后续探索。2026上半年作为新的时间窗口，不能与完整全年结论混称。

## 固定主比较

`joint_0.5 = seasonal + 0.5 × (analog_shape - latest)` 对 `seasonal`。系数0.5在查看2025组合评分和2026任何评分之前固定，不由2026结果选择；其他0/0.25/1及仅源残差选择的source_alpha都报告为预先指定次要对照。latest、analog_shape_half、source_policy等保留。

所有形状差异按24小时去均值；组合保留seasonal的原始日均水平。源残差使用完全相同的源日期索引，按 `e_joint=e_seasonal+alpha×(e_analog_shape-e_latest)` 组合。这是对同一源真值的精确残差恒等式，不是任意拼接独立误差。若日期或源域身份不匹配应拒绝运行。

训练与超参数保持其他六区2022源小时参考；目标地区小时值不进入拟合、选择或推理。每个目标的source_alpha只在排除目标后的2022源残差中选择，存在选模与校准共用残差的乐观风险，不能视为跨域覆盖保证。

## 数据与封存

从EIA官方2026 Jan–Jun六个月文件构造固定EF代理；保留2022–2025粗统计以形成合法历史输入。只预测和评分2026-01-01至2026-06-30；月末后30/60/120天发布三轨道，源与目标延迟规则一致。原始数据为2026下载修订版本，没有真实发布时间档案。

各方法及组合的全部目标、全部延迟预测先封存，再打开2026小时参考计算评分。数据整理可读取native值进行schema/质量处理，但不先行计算CIF分布、预测误差或选优。运行前存代码、数据、协议hash及环境，结束后核对；失败运行保留，不能覆盖。

## 评价和表述

主指标为各地区等权CRPS；同步报告raw point/shape/level MAE、90%覆盖/宽度、原始点越界与分地区结果。主比较H1检验两类信息的互补，不能只因形状误差降低而宣布总概率预测变好。固定日期配对同步月份bootstrap仅描述这半年七区，六个月不构成长时间或独立地区统计保证。

若组合不能超过seasonal，保留此前已确认的“粗统计季节水平利用”作为最强优化方向，停止新增组合优势主张。若组合有收益，也只支持本候选的增量；加性分解、残差组合、相似日与收缩都已有基础，不能仅凭组合自称新理论或首创。

这轮以有限多轮试验定位最有价值的优化空间，不声称找到所有算法、地区与信息条件上的全局最优。2026结果不再用于本轮反复更改系数后重新称为确认。

评分前质量检查补充：2026上半年ISNE只有37个有效地区日且无合格月度观测，其他六区均超过170日。主结果仍保留预定七区；另报告“有效天数至少覆盖上半年一半（≥91日）”的质量敏感性子集。该阈值只依据预先质量mask，未查看预测评分，不按方法表现决定地区去留。
