# 无目标小时标签的CIF迁移：文献与创新边界补查

2026-10-31，Sol。天气小样本仍在采集，本记录未根据其目标分数选路线。目的在于限定下一轮要证明的内容，继续服务“外国训练，中国粗月报部署”的预测目标。

## 读到的相关工作及输入差异

| 一手来源 | 已核实的任务与方法 | 对本项目的实际含义 |
|---|---|---|
| [Zhang等，2026，CIF多频小波预印本](https://arxiv.org/html/2601.06530v1) | 澳大利亚四州；输入过去24小时的CIF、负荷、可再生/不可再生发电、温度，预测后续24小时；按州调参 | 小波/多频机制解决有小时历史时的预测，不解决中国无目标小时历史。不能原样套用后声称预算公平，也不能把其MAE与本项目直接排列 |
| [Weisser等，2026v2，气象聚类跨场站风电](https://arxiv.org/html/2601.19674v2) | ERA5和功率曲线生成的历史数据；气象簇GP；模型含功率及风速滞后，目标场站进行本地微调 | 气象条件决定可迁移性有参考价值，但其标签、再分析与少样本设定不同；不能引用其结果证明零目标小时标签成立 |
| [Zhang等，NeurIPS2020，聚合观测学习](https://proceedings.neurips.cc/paper_files/paper/2020/hash/5b0fa0e4c041548bb6289e15d865a696-Abstract.html) | 已有均值等聚合监督的概率学习框架及一致性分析 | “把月总量加入损失”本身不是新概念；必须证明发布滞后、跨国偏移和小时分布预测这一特定困难被解决 |

## 当前可以提出、尚不能宣称成立的贡献

框架贡献可清楚定义为：整国留出、源训练模拟中国粗分类和发布时滞、零目标小时标签部署、装机/天气独立预算、预测先封存再评分。它有实际价值，但评价协议严谨并不自动等于算法创新；三国开发亦不等于未知国家确认。

方法上值得保留的待检验假设，是让天气响应进入源学习的燃料运行模型，再用目标过去已发布的月量约束可适配参数。需要同时保留不能由月量确定的小时调度和水平风险。这里的目标仍是改善未来小时预测，而非改做区间可识别集合。

这只是待设计假设。聚合监督、形状归一化、气象簇、残差校准等组件都有前例。只有在同预算直接预测、简单重组、条件分位数和异方差参考之外出现可重复增量，且消融能定位到所提机制，才有依据讨论方法创新。现有Ridge/HGB/CQR与经验轨迹属于标准参考。

## 本轮判读与下一步条件

先固定有／无天气同模型比较，不根据目标误差挑选所谓主方法。分别报告MAE、日内形状误差、覆盖、宽度及区间分数；只缩窄而欠覆盖恶化不算成功，只加宽而覆盖提高也不能证明效率提高。完整源年轨迹用了更多小时标签，应单列为强参考。

若成对天气模型降低小时形状误差，同时区间分数改善，下一步才扩大固定季节样本和空间代表性，检查这种关系能否跨国保持；不立即堆深度模型。若直接模型有收益、重组残差头没有，先承认结构机制尚无证据。若所有天气模型失效，则区分样本过少、单点代表性不足、源目标响应不一致，不把负结果改写成天气无用。

后续若测试目标月报弱监督适配，只能使用预测起点以前已公开月份，不能令未来日轨迹服从尚未公布的当月总量。历史天气与未来预报的版本及分布差异也需单独检查。无目标小时校准时，不从源域经验覆盖推出目标90%保证。

当前三天开发样本只能支持是否扩大试验的判断，不能支撑投稿精度结论、稳定尾部覆盖或方法冻结。下一步以真实成对结果决定投入，不以模型名称或组件数量决定创新。

## 2026-11-01补查：CIF跨区研究已存在，贡献必须落在目标信息预算

后续检索到的相关一手工作进一步收窄了可主张空间：

- [CarbonCast（BuildSys 2022）](https://lass.cs.umass.edu/papers/pdf/buildsys2022-carboncast.pdf)用区域历史燃料发电、历史CIF和天气预测未来CIF，采用源发电预测再到CIF的两层架构；所以“分层重组+小时CIF预测”本身已有直接前例。
- [EnsembleCI（arXiv 2025）](https://arxiv.org/abs/2505.01959)在11个区域电网做CIF预测并使用自适应集成；因此多地区评估或集成结构本身不能成为新颖性主张。
- [TransCarbonNet（2026）](https://www.techscience.com/CMES/v146n1/65711/html)报告了UK与CAISO跨数据集测试，包括零样本方向。它进一步说明“跨区域CIF零样本”也不是足够精确的独占性贡献。该工作采用目标CIF历史序列窗口并以时间序列模型直接预测；与本项目目标端仅有滞后粗月统计的输入条件不同，性能数字不能直接对比。

因此更可辩护的差异不是“首次跨国预测”，而是一个更窄且可复现的设定：**在目标端没有历史小时CIF/燃料序列时，源国小时标签训练的模型能否只凭有发布时间合同的滞后粗月发电统计直接迁移；若加入年度装机，增量是多少；风险能否在整国留出下可信估计。**

当前五国开发证据不支持容量利用率算法：M比例重组MAE38.46、覆盖88.69%、区间分数292.70；M+C利用率火电因子头MAE39.89、覆盖86.22%、区间分数314.63；荷兰覆盖约55%。也不支持继续搜索伪目标门控、残差回归或普通条件区间。年度煤/气细分在发电侧固定因子代理上存在水平信息价值，但官方消费侧迁移未稳定复现；而中国现有省级年度表没有煤/气装机拆分。各轨道须分开呈现。

**投稿价值的现实判断：**若短期内没有新方法稳定超过强重组，主贡献应收敛为可复现的跨国、输入预算分层、整国冷启动基准和系统负迁移分析；需要公开数据清单/映射、as-issued可见性、预测封存、直接迁移与弱监督适配分轨、强点与概率基线及最差地区风险。它可以作为有价值的基准型研究，但是否足够支撑高水平方法论文取决于数据和协议是否能让第三方复用，以及是否找到至少一项跨多个外层国家稳定的算法增量。当前实验还未达到后一个条件。
