# 跨国家区间覆盖的有限样本门槛

更新：2026-11-01。该审计回答一个具体问题：现有多国留一国评测中，小时级90%区间能否支持“新国家可信覆盖”的结论。

## 一般共形校准的样本单位

若目标是对一个新国家的整段小时轨迹作同时覆盖，合理的校准分数单位应是国家。例如，先对每个校准国家计算其整段预测的最大绝对残差，再将国家作为可交换样本校准。把数万小时当作独立样本，得到的是小时层面的边际覆盖估计；它不会自动给出新国家层面的覆盖保证。

Split conformal在有`n`个可交换校准单位时，有限样本修正的分位数次序为

```text
k = ceil((n + 1) * (1 - alpha))
```

当`k > n`时，满足该有限样本保证的分位数是`+∞`。因此有限区间要求`n >= 1/alpha - 1`。这来自标准有限样本共形秩修正；相关原始方法与表述见[Conformalized Quantile Regression](https://papers.nips.cc/paper/8613-conformalized-quantile-regression.pdf)及[Conformal Prediction with Conditional Guarantees](https://academic.oup.com/jrsssb/article/87/4/1100/8058684)。

## 对当前TransCIF评测的含义

- 五国Energy-Charts整国留出每折最多只有4个其他国家；扩展到六国后，外层目标也只有5个其他国家。以国家为校准单位时，两者都不能给出有限的分布无关90%整国区间。
- 现有以2023H1数千小时计算的90%残差半径仍可作为**小时池化经验参考**，但其覆盖率不能解释为新国家的90%覆盖保证。荷兰、捷克、德国和塞尔维亚的显著欠覆盖已经提供了经验反例。
- 这个秩门槛不说明点预测无用，也不禁止有明确条件假设的模型；它说明若论文要主张分布无关的“新国家90%可信覆盖”，必须增加足够的独立校准国家，或把结论明确改成依赖源域可迁移假设的经验覆盖。
- 将一个国家拆成12个月或数千小时来增加`n`，会改变目标覆盖单位，不能补足国家样本数。若改用国家×月份分数，也必须另外论证不同国家/月份块的交换性，不能默认成立。

## 下一轮实验应如何推进

1. 继续保留同小时的90% pooled conformal、异方差和CQR作为经验强基线，同时把“最差留出国覆盖”与区间宽度、WIS并列，禁止把小时池化区间写成新国家保证。
2. 若要检验整国级无分布覆盖，先获取至少9个独立且口径可用的校准国家；这只是秩条件，真正部署仍要求新目标与校准国在国家分数上可交换。
3. 在国家数不足时，下一轮方法比较要明确采用哪条路径：跨国层级模型/可迁移性假设，或较低目标覆盖率的整国区间。通过嵌套留国实验评估其覆盖和宽度，不以重复小时或月份替代独立国家。

因此，当前区间瓶颈不只是“还没找到合适的半径模型”：独立域数量本身限制了能做出的有限样本覆盖声明。该结论把下一阶段优先级从继续扫描异方差/CQR参数转向**增加独立国家证据，或显式建模并验证跨国风险迁移假设**。
