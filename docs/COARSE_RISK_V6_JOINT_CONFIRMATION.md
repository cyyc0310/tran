# 两轮粗到细风险方法的联合确认规则

2026-10-23，Sol。本规则在六个新地区2026H1的任何模型评分之前固定，补充两轮各自协议，不改已冻结的源模型或历史产物。

两轮源开发仅用原七区2025，proper/bank同为2024H1/H2。第一轮22个概率配置、第二轮32个概率配置，各另有CQR；两轮预测每次都含3点方法×3延迟。目标为同一固定六区、同一2026H1。首轮粗倍率造成参考略超95%门槛的现象已公开，第二轮全模式共同细化；不存在按目标结果替换网格。

在两轮源分数完成、两轮全目标预测均已全局封存且两外部目录都尚无scores时，创建联合选择文件，冻结源JSON、两全局预测seal、实现及本协议hash。

- primary：只比较两轮源固定structured角色；如任一passed，仅在passed中选源CRPS最小；若都failed，按源gate_violation、CRPS选固定诊断并保留failed。
- baseline：同样从两轮源固定通用参考选，规则同上。每轮参考都允许global/loglinear/ExtraTrees和共同倍率，第二轮参考也拥有粗锚。
- unconstrained_baseline与historical_v5：分别取两轮各该角色中源CRPS最低，保留unconstrained含义。
- cqr：通过覆盖门槛者按源区间评分最小，否则最小违规诊断。没有集合预测与CRPS。
- anchor消融：固定第二轮源primary，并使用相同point、相同倍率的noanchor（`source2_noanchor`）；不根据目标或消融分数改配置。
- 简单锚定基线：固定第二轮源primary相同point、相同倍率的global锚定配置（`source2_simple_anchor`），保留其实际源覆盖门槛状态，不要求它在源上最优。它与第二轮主配置共享已发布粗反馈、锚定机制、拟合/残差bank分割、倍率和固定EF支持处理，仅不使用structured的条件剩余风险模型。此配对直接检验条件剩余风险模型相对简单锚定的增量；跨轮源选择最强baseline仍单独保留，不能因为该角色恰好来自第一轮就省略第二轮简单锚定比较。

平分时按variant/method/calibration稳定排序。冻结后两轮目标小时才可读取。每轮自身源固定主表均保留；联合版本也不能靠目标排名更换。

最终报告固定主与固定参考的CRPS、覆盖、宽度、区间评分、逐区最弱表现、尾部及路径覆盖；另分别报告第二轮主配置减去精确noanchor、第二轮主配置减去精确global简单锚定基线的配对差值，以及CQR区间比较。上述新增机制对照在任何新目标评分前固定，不按目标或该对照成绩选择point、倍率或版本。同步2026H1六个日历月bootstrap 5000次、seed17023，只作固定六地区的描述性差值区间，没有全球域泛化或多重比较保证。

本协议文件的原始SHA256与实现一起写入联合freeze，并复制到其snapshot目录；analyze前重核对协议、实现、快照及joint freeze的SHA256。冻结后修改本协议将拒绝沿原freeze分析。两轮源selection、两外部global seal及“两个scores目录尚不存在”的检查记录共同绑定评分前的版本选择；时间戳仅作补充证据。

联合配对还要求两外部run使用完全相同版本的确认输入：从各自已冻结prefit manifest中，按计划label_data取六份地区hourly CSV和monthly.csv的SHA256，按文件名逐一比较相同，并保存到联合freeze。此检查只读取manifest，不解析目标小时或成绩，防止相同地区日期实际对应不同修订真值或粗输入。analyze再核对这些数据绑定。

预先判据：相对同信息强参考，维持覆盖而缩短区间，并在proper score上无明确实质退步，才支持风险效率改进；若缩窄伴随严重欠覆盖，不算成功。若anchor-global同样或更优，贡献归于粗反馈/剩余误差结构，而不归于复杂方差模型的独占创新。实际外部覆盖未达目标应如实记录，不再用这批地区作调参后首次确认。
