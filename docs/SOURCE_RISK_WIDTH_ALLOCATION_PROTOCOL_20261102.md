# 固定区间宽度预算下的伪目标风险分配：冻结协议

日期：2026-11-02。

## 问题与假设

前一项研究显示，源伪目标Logistic在跨国家欠覆盖概率的总体proper score上优于常数模型，但国家内月份排序很弱。此实验检验其分数是否仍能在固定年度区间宽度预算下，把宽度重新分配到更需要的月份。

主假设：固定每个目标国、每个区间头的12个月总区间宽度，完整元数据风险分配比统一月宽在小时覆盖率不下降的同时，降低等权月平均90%区间分数。因为风险分数的国家内排序尚未证明有效，此为探索性检验。

## 冻结数据与方法

- 使用NL、ES、BE、AT、SE、CZ六国2024留国伪目标，所有国家此前均已查看；不得称作盲确认。
- 点预测、校准样本和全年度基准半径沿用已封存的六国Czech expansion r4。每个方法的基准半径来自其余五国2023上半年伪目标绝对残差加权90%分位数。
- 风险分数仅取 `source-pseudotarget-risk-meta-r2/nested_country_predictions.csv` 中 `full_meta_logistic` 的逐国外层留出概率；训练时不含对应目标国标签。
- 强基线是统一月宽（每国—方法全年采用同一个校准半径）；次基线为源事件率常数风险分数，按下述公式分配后等价于统一月宽。仅范围分数Logistic列作次要风险排序基线。
- 对每国、每区间头分别用 `s_m = exp(p_m - mean(p)) / mean(exp(p - mean(p)))` 作为冻结宽度倍率；该规则无可调参数且均值严格为1。区间月半径为 `r * s_m`，总宽度与统一月宽相同。90%区间分数为 `2*radius + 20*max(abs(error)-radius,0)`。
- 月度风险建模只用当期预测时可得的粗月输入及源伪目标结果；本实验小时真值仅用于最终评分。
- 主指标：宏平均小时覆盖率、宏平均等权国家—月区间分数、年度每月等权平均宽度、每个国家—方法覆盖率与区间分数。报告所有国家和方法，不筛选获益目标。

## 判据

有用增量要求：在固定平均宽度下，宏平均覆盖率不降低超过1个百分点，且宏平均区间分数至少改善2%；同时不允许任何目标国家的覆盖率下降超过5个百分点而未在结果中明确报告。未达到即判定本分配规则未证实价值，不继续调节指数系数或阈值；风险模型最多保留为域级诊断。
