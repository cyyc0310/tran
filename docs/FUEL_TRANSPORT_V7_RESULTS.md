# V7：从失效诊断到燃料轨迹重组

2026-10-23；实现、实验和独立审查使用 Sol。两轮源实验、六地区开发复测、路径诊断与数值核验均已完成。结论：燃料重组有可归因的部分改善，但尚未实现相对简单锚定维持覆盖同时缩窄区间，也未形成充分的方法新颖性证据。

## 研究问题与证据资格

目标是没有当地小时 CIF/发电/需求历史时，用预测起点前已发布的月度燃料组成和日历，生成未来一天的小时 CIF 概率路径。这里 CIF 是固定排放因子、发电侧的 EIA 非负已报发电代理，不是消费侧碳足迹，也未包含中国电网验证。粗月发布时间由回溯数据假设构造，不是真实版本档案。

V6 六目标已经用于失败诊断，所以本轮 **V7 是开发复测，不是新的独立确认**。仍坚持仅源选择、目标全配置先预测封存后评分，以防对新方法按目标成绩选型；这个流程不能消除已看目标带来的研究适应性。历史 V6 的确认身份和负结果保留。

## 为什么 PACE 等地区失败

详细证据在 [失败诊断](FAILURE_DIAGNOSIS_V7.md)。最关键的问题不是少一个区间倍率，而是点形状训练域、迁移方式和目标机制同时不匹配：

|额外延迟 0|PACE|AZPS|PSCO|
|---|---:|---:|---:|
|真实日内中心化 CIF RMS|140.42|114.26|72.07|
|旧原始点 RMS|12.99|12.84|12.22|
|旧情景均值 RMS|25.41|25.85|21.94|
|真实日 RMS 超出旧点轨迹库最大值的比例|64.44%|60.34%|12.22%|
|旧原始日均偏差（真值−预测）|−92.65|−112.17|−82.87|

旧点库实际上只包含四地区 2022 年数据；七地区 2024 数据进入后续残差模型，并不等于点库更新。PACE/AZPS/PSCO 的旧 32 邻居分别有 98.22%/99.97%/93.51% 权重落在 ERCO；邻居平均抵消形状，再与弱模板按 0.5 混合，进一步降低振幅。粗构成接近不保证小时联合路径接近。

原始点平均曲线低谷与真值相差约 11–12 小时，但完整情景均值已部分修正至相差 3 小时，不能把整套预测描述成纯粹错时区。即使非法使用真值只替换 PACE 的 shape 或 level，覆盖仍只有约 56.1% 或 47.4%；二者都需要改善。能量加权月 CIF 与等权小时均值的差确实存在，但量级不足以解释全部错误。PSCO 还出现半年粗统计空档，名义发布延迟低估实际信息年龄。

## 两轮方法与公平对照

冻结协议：[FUEL_TRANSPORT_V7_PROTOCOL](FUEL_TRANSPORT_V7_PROTOCOL.md)。源训练统一更新为七地区 2024H1；2024H2 给简单锚定、ExtraTrees 的配对整日残差 bank 和 HGB 分位回归的 CQR 校准。源 2025 留一地区同时排除该地区的训练及校准小时数据；只用 2025H1 选择，H2 单列压力测试。

首轮不再直接平移旧 CIF 曲线。将源月每种燃料的小时出力除以该燃料月均出力，保留整日联合路径 \(q\)，用合法预测的目标构成 \(\widehat m\) 重算

\[
T_{\widehat m}(q)_h=\frac{\sum_f e_f\widehat m_fq_{hf}}{\sum_f\widehat m_fq_{hf}}.
\]

该算子能改变日内形状与非对称性；它等价于用目标/源组成比例缩放燃料后重新计算 CIF，不是新最优传输算法。零源支持燃料采用显式平坦先验并报告其质量。核选择和有限采样不保证目标未来月份精确能量守恒。

第二轮在每个历史预测起点重建当时可用的粗统计，回测 latest、同季历史、年度漂移三个组成专家；比较先平均组成再重组，与分别重组后混合概率分布。温度、带宽和统一倍率网格在实验前固定。历史粗预测误差没有被当作目标小时校准标签。

所有新强基线获得相同合法组成预测特征、粗历史损失与偏差、信息年龄及日历。对照包括更新后的简单结构点＋粗锚、ExtraTrees＋残差 bank、HGB＋CQR；另有同 donor 权重和同抽样的直接 CIF 类比、逐燃料独立抽样、取消组成条件选择。主方法的三个精确消融沿用主的预测器、温度、带宽和倍率，不按消融目标成绩挑选。CQR 只有区间，不伪造 CRPS。

两轮共 34 个基础配置；32 个概率配置各有 4 个统一 spread 倍率，2 个 CQR 配置只有固定区间，共 130 个方法/倍率组合。源选择要求宏覆盖在 90%–95%、最差地区/延迟覆盖至少 85%；若全部失败，保留 failed 状态，再按门槛违反程度和 CRPS 排序，不能改门槛宣称通过。目标只报告源固定角色；额外分析明确标为开发归因。

## 新颖性的判断方式

[文献核查与假设](V7_LITERATURE_AND_HYPOTHESES.md) 已列出直接先例：UAI 2025 的源细标签＋目标聚合标签迁移，Deep Temporal Deaggregation 的聚合条件轨迹生成，Q-CODA 的区域化随机细化，以及经典联合重排与概率混合。因此“粗到细”“联合采样”“物理重组”都不能单独作为首创主张。

当前待检验的是特定信息条件下的机制增量：迟到粗构成经非线性能源比值作用于源联合轨迹，是否比同数据直接 CIF 迁移和普通条件预测更有效。只有在强基线与简单锚定前同时改善分布质量和覆盖—宽度取舍，并能由匹配消融归因，才值得继续升级为论文方法。仅胜过旧四源点模型、仅增加宽度、仅改善几个已见地区，都不足以证明创新成立。

## 收益归因与剩余瓶颈

**比值重组有作用，但还缺更严格的水平锚定消融。** 同 donor 权重/抽样的直接 CIF 类比到 R2 重组，CRPS 差 −70.3316、宽度差 −122.5770，说明改变能源组成映射比直接搬用不同地区 CIF 有效。不过该直接类比保留源水平，尚未与“相同 donor 路径＋目标/源粗 CIF 差的加性平移”比较；现有 fresh_anchor 是另一条结构点＋残差流程。故不能把这个巨大差值全归于新颖的非线性 shape 迁移。

**联合依赖不是已证实的核心贡献。** R2 joint−independent CRPS 差 −0.1905，描述区间 [−0.4855, 0.0872]；联合路径 ES 为 64.0860 对 64.2305，VS 为 11.7283 对 11.5600（joint 略差）。没有一致证据支持增加 copula 复杂度。

**粗专家分布混合是覆盖与宽度的取舍。** 匹配的 mean−mixture CRPS 差 −0.1738，[−0.7570, 0.3338]；先平均组成的覆盖低 5.51 个百分点、宽度小 40.21。不能称分布混合产生稳定 CRPS 增益。

[路径诊断](../results/fuel-transport-v7-path-diagnostics/region_delay_path_metrics.csv) 进一步说明不能只校正时钟：额外延迟 0 时，R2 的 PACE/PSCO 平均曲线低谷已与真值同为 UTC 19，AZPS 预测 UTC 18、真值 20；但 PACE 每日 RMS 的平均值仍只有 48.82，真值 128.66，PSCO 为 28.76 对 65.31。该表是 mean(daily RMS)，前述旧诊断 140.42/72.07 则是 sqrt(mean(all centered squared values))，两个聚合口径不能直接横比。PACE/PSCO 的 R2 日均预测−真值仍为 +44.04/+59.21，水平与幅度均未解决。

R2 的有效 donor 数量平均值约 198–687，零分母回退比例为 0；未支持燃料质量约 2.2%–6.5%。较多 donor 不等于正确的条件形状，因此不能把剩余失败仅解释为邻居数量不足。专家混合的 ESS 是加权组件摘要，不是精确混合 ESS。

## 下一步：先做能决定路线的试验

1. **最高优先级：同轨迹加性锚定对照。** 对同一 source donor、同组成专家、同采样权重和随机数，构造 \(y^{add}_{dh}=y^{source}_{dh}+e^\top(\widehat m-s_d)\)，其中 \(s_d\) 是 donor 所属源月的能源组成。与现有比值重组及直接类比比较，保持投影、倍率预算与源选择一致。它保留原日内形状，只替换粗能源水平；不是强制目标小时均值等于粗 CIF。新增实验尚未执行，不能登记为通过。如果它已解释大部分收益，应把重组保留为透明基线，降低算法新颖性主张。
2. **区分“未来组成预测错误”和“给定组成后的形状错误”。** 开发诊断可用事后实际目标月组成替换合法预测，其他部分冻结；必须标为非法 oracle，不能参加选型或部署。若该诊断改善大，下一轮聚焦发布时效、结构突变与组成预测误差；若 PACE 振幅仍不足，应研究形状对构成变化的响应与燃料补偿关系。只有新增合法信号或可检验的源迁移假设，才可能减小这种误差，换一个更深网络并不自动获得信息。
3. **方法研究主线：明确哪些小时风险能被粗统计约束。** 保持粗组成可识别的水平/组成部分，与粗观测无法区分的小时 shape 分开建模。一个重要边界是：若各燃料模板都被归一为同月均值 1，则无论 shape 混合权重如何变化，粗月能源组成相同；仅凭该粗标签不能识别这些权重。可研究比值算子与发布时效下的可识别集合、不可区分轨迹的风险边界及补充信息价值，但须与既有部分识别/稳健预测方法比较，不能将简单 LP、比例缩放或 delta method 重新命名为创新。

公开静态地理、资源分布或已发布天气预报可作为单独的信息预算扩展，用于约束太阳能幅度、风光组合和总发电分母；所有对照应得到相同输入。PACE 的新平均相位已经正确，故只加时区不是最优先项。禁止使用目标未来天气实况或通过目标小时真值选相位。

目前可以进入下一轮机制开发，并开始整理问题定义、数据合同与失败分析；还不能进入方法优势已成立的正式投稿阶段。下一次确认必须另留未查看的地区或年份，提前固定配置、选择、分析和覆盖非劣效标准；不能继续把本轮六地区称新 holdout。

## 复现、核验与研究边界

两阶段入口为 `scripts/run_fuel_transport_v7.py --phase source|target --output NEW_RUN`，源运行先创建新目录；目标阶段沿用该目录的源封存。分析入口为 `scripts/analyze_fuel_transport_v7.py --run RUN --output NEW_ANALYSIS`；路径入口为 `scripts/diagnose_paths_v7.py --run RUN --output NEW_DIAGNOSTICS`。结果分别位于 `results/fuel-transport-v7`、`results/fuel-transport-v7-analysis`、`results/fuel-transport-v7-path-diagnostics`。

源 714 份预测档案、822,900 条方法日评分；目标 612 份预测档案、421,200 条方法日评分，共 1,244,100 条重复配置评分，不是同等数量独立样本。目标只有 1,080 个唯一地区日；源 H1/H2 分别 1,145/965 个，其中 CISO H2 仅 15 日，季节压力测试并非完整齐备日历。
