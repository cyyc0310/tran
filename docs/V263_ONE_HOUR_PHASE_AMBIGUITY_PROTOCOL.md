# V263 冻结协议：一小时相位错位的本地邻点不确定包络

日期：2026-10-30。V239/V262已打开的EIA代理目标与500 gCO₂/kWh阈值；本实验不构成新地区盲测。样本固定为V262两端已证明的5个BA-month：PACE 4/7/10月、CPLE 7月、AZPS 4月。

## 问题与信息条件

V237–V239显示，准确小时总发电量可显著缩窄月度燃料边际下的整月超阈小时数锐界。但中国可公开得到的小时负荷通常是天气/典型曲线重建值，不是发电调度测量。V263测试小时曲线存在一小时相位错位时，风险集合还保留多少信息价值。

- 固定月度燃料边际、精确每日总量、固定因子`[1000,800,400,0]`和500 gCO₂/kWh事件阈值。
- 每天独立循环右移真实小时总量曲线1小时，形成观测`q_hat`。
- 对每小时允许真实值落在当日`q_hat[h−1], q_hat[h], q_hat[h+1]`三者最小值与最大值之间。按构造，原曲线逐点属于此集合，且日总量不变。
- 对照精确小时曲线，分别计算月内超阈计数`K=#hours(CIF≥500.0001)`的MILP锐界。

## 主要终点

报告每日-only宽度、精确小时界宽度、相位不确定界宽度、优化状态、实际固定EF尾数是否包含及信息集合嵌套。仅两端均证明最优的案例进入汇总；集合包含不称为预测覆盖。

若相邻点包络下仍明显优于每日-only，说明信息价值对一小时相位不确定具有稳定性；若收窄大幅消失，则真实时标同步是该测量合同的必要条件。固定EF EIA可行集只验证识别几何，不验证中国负荷可替代发电量，也不评估小时CIF预测准确率。

## 限制

所有目标都已打开，结果是敏感性复算而非外测。代理不含机组容量、爬坡、最小出力、机组状态、网络潮流与储能。
