# V232 解析结论：月度守恒不会额外收紧单小时边际

V231 使用月度燃料边际与小时总发电量，计算每小时的燃料可行集。随后拟用全月联立 LP 检查逐小时界是否过宽。重复求解在产生任何结果文件前被停止，因为两者的单小时投影可直接证明相同。

设目标小时总发电量为 `G_t`，各类燃料月总量为 `M_j`，目标小时燃料量为 `x_j`。单小时约束是：

`sum_j x_j = G_t`, 且 `0 ≤ x_j ≤ M_j`。

给定任何满足条件的 `x`，剩余小时的燃料供给为 `M_j-x_j≥0`；其总量等于剩余小时总需求：

`sum_j (M_j-x_j) = sum_j M_j-G_t = sum_{s≠t}G_s`。

对任意非负行供给和列需求，只要总量相等，就存在非负运输矩阵把燃料分配到剩余小时。因此每个单小时可行向量都能扩展为满足所有月度边际和小时总量的全月分配。反方向显然成立，所以全月联立约束在目标小时的投影恰等于 V231 单小时可行集；按线性 EF 计算的单小时 CIF 上下界已是该约束集合下的全局锐界。

这说明只含“非负燃料＋小时总量＋类别月边际”的模型里，加入其它小时总发电量不会额外识别当前小时燃料混合。要进一步收紧范围，需要类别逐小时可用出力/装机上限、爬坡、最小稳定出力、储能、进口、调度或天气驱动的可再生出力等额外约束。用户当前只有月度表，这些时序信息还未提供。

V231 的小时总量本身也是额外假设；用户给定数据只有月度值，因此 737.46 gCO₂/kWh 的平均区间宽度是偏乐观代理诊断，不能作为中国实际误差量级。V232 是解析证明；没有声称执行或完成重复 LP。[V232 说明](V232_JOINT_MONTH_MARGIN_LP_PROTOCOL.md)、[V231 结果](V231_MONTHLY_ONLY_HOURLY_IDENTIFIABILITY_RESULTS.md)。
