# V82：阶段性创新性与论文定位评估（2026-10-28）

## 到目前为止能支撑什么

当前候选不应再叫“L₁新算法”。V79/V81表明核心增量来自**使用地区-月已知活跃燃料支持上界**，而不是L₁；在同一上界下，普通G²必要外界已接近或达到完整小时G证书。未评分含气区AVRN在τ=300的本地M-G²认证率约15.8–22.0%，高于全局M完整G的0，但仍远低于完整局部G的19.0–26.2%；DEAA已到天花板。证据说明支持信息重要，也说明具体摘要创新弱。

## 与既有研究的边界

- 部分识别与生态推断早已研究“聚合边际下个体/细粒度量不可唯一恢复”、sharp identified sets，以及增加更细聚合信息后的收紧。2024年工作系统讨论用聚合数据、额外形状限制和更细层级聚合约束构造sharp bounds：[Partial Identification of Individual-Level Parameters Using Aggregate Data in a Nonparametric Model](https://arxiv.org/abs/2403.07236)。因此“月度边际下小时量不可识别”和“额外约束可收紧”本身不是新理论。
- CIF文献已探索低频排放/电量生成月度CIF、Denton分解与SVM预测；其参考时间序列提供额外高频形状：[Yan et al., 2025](https://onlinelibrary.wiley.com/doi/10.1155/etep/9159507)。这与用户的中国“月/年全燃料边际、无目标区小时CIF历史”约束不同，但说明要严肃比较低频到高频恢复法。
- 另有基于小时需求、可再生发电与CO₂数据估计消费侧月/小时边际排放因子的研究：[Zohrabian et al., 2023](https://www.sciencedirect.com/science/article/pii/S0959652623004547)。这不是平均燃料归属CIF，需在论文定义中区分平均/边际因子与发电侧/消费侧边界。
- 时空电力排放的异质性和小时核算价值已有实证研究，例如美国电力系统追踪：[PNAS (2020)](https://doi.org/10.1073/pnas.1912950116)。不能把“小时变化重要”本身作贡献。

## 目前最合理、但还未达到强方法创新的立意

较可信的目标是**有限公开数据预算下的电力CIF尾风险识别基准**：每种信息合同都公开定义；以全国/省级月燃料表作为中国目标情境，以有真实小时燃料混合的外部系统做遮蔽实验；比较(月度燃料边际)、(再加本地支持集合)、(再加日/6h H/G)、(再加G²/次序摘要)、(完整小时G oracle)的sharp/outer sets、风险决策前沿、弃权率、宽度和测量误差敏感度。可把“最小额外本地信息”定义为：在风险阈值K≥k下达到事前指定识别/决策效用所需的最小发布字段与时间粒度。

方法贡献必须由可复用算法/benchmark支撑，而不只是把标准不等式换名：给出多个目标k/阈值τ和局部支持M下的sharp/可计算界；证明适用条件与紧性；对“支持、总量、二阶矩、top/bottom order stats、日/6h粒度”的同预算组合做前瞻或封存地区评估；把实际仪表精度、统计发布滞后、EF不确定性纳入信息合同；至少有独立真实CIF标签验证预测覆盖。V81还只说明两个天然气结构相近区上的同期EIA固定EF代理，不足以支撑一般迁移方法。

## 决策

现阶段**没有确认足以支撑强算法论文的原创方法突破**。有价值且可继续做的研究贡献是信息预算/可识别性基准，且它与TransCIF“可信预测”初心可以衔接：当信息不够时给出风险范围与弃权，而不是伪造小时曲线。但要称“统一、可迁移CIF预测基准”，必须把预测任务、as-of信息集、地区边界、燃料映射、target标签、误差与区间指标分别标准化，且需独立中国小时CIF或明确声明只做代理基准。

更适合的下一轮不是继续搜索一个新统计量，而是：①形式化支持自适应锐界/风险决策；②跨区/跨燃料同预算审计每日与6h遥测的增量；③将公开月表字段映射到每项限制，区分月度本身可识别的部分与需要新增本地时序数据的部分；④先查新与复现再决定是否写成方法论文。本文档是有限范围定位，不是穷尽文献综述，也不声称优先权。
