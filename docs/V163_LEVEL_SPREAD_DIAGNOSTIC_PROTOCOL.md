# V163：剩余误差的水平、发电协方差和离散程度诊断

V162表明固定时钟偏移不足以恢复最差源覆盖。本轮在评分前冻结，只分解既定重组分布的误差，不开发新预测器。沿用V159的29源、六折、2024、两个预算、两个重组方法和固定校准半径；不打开2025目标或新地区。

V162的CPLE/AVRN/GVL三个贴边预检中，统一64×float_eps×max(1,|y|,|lo|,|hi|)容差没有增加任何覆盖小时；关键失覆盖暂不支持浮点解释。V163仍为全部查询保存严格及同一容差覆盖、左右漏盖和原CDF支持外比例，防止遗漏数值或单侧问题。容差不是可调超参。

## 同一生成器内的水平分解

每个查询的24个源联合活动分布已确定。对每钟点，按与CIF预测相同的混合权重、同一正总量条件化，计算相对发电G及排放E的期望。再按该查询实际有效钟点占比混合。

预测时间均值μ_pred=E_pred[C]，生成器能源锚A_pred=E_pred[E]/E_pred[G]，κ_pred=μ_pred−A_pred。实际A_true由该源查询月完整燃料能源计算，μ_true为实际小时CIF均值，κ_true=μ_true−A_true=−Cov(G,C)/E[G]。核验真实协方差身份和δA+δκ=μ_true−μ_pred。

A_pred依赖本生成器的相对发电尺度，不由CIF边际唯一识别。源活动的缩放规范是V159已有的月平均发电归一化；不能把该分解包装成任意预测CDF独有的物理量。A_true在asof是未来粗统计，κ_true/μ_true/σ_true需要本地小时标签，均为oracle。

## 七个全年诊断与四个H2诊断

全年：baseline；energy_anchor_oracle（δA平移）；generation_covariance_oracle（δκ平移）；monthly_location（δμ平移）；monthly_scale（围绕原μ以σ_true/σ_pred缩放）；monthly_location_scale；phase_location_scale（先用V162地区/预算/方法固定oracle相位，再基于移位分布计算δμ和σ比）。

所有变换为x′=μ_pred+δ+s(x−μ_pred)。当月原子裁到已知正能源燃料的EF最小/最大值；asof只能裁[0,1000]，历史零不得排除未来燃料。原校准半径不变，最终区间仍按V159裁[0,1000]，以便baseline复现。裁原子后不声称精确匹配真实矩，记录裁剪概率及变换后实际矩。

方差以围绕总体预测均值的加权平方差稳定计算。σ²≤1e−8视为数值退化；预测退化、实际不退化时比例无法生成缺失支持，s=1并显式记录，不伪造随机性；两者退化s=1；仅实际退化而预测非退化时s=0。这些是诊断定义，不是拟合超参。

平移小于64×float_eps×max(1,|μ_pred|,|μ_pred+δ|)视为数值0，尺度距1不超过64×float_eps视为1；恒等变换不重新裁原子，保证不因极小贴边舍入改变baseline的二元覆盖。其余变换仍报告严格及容差覆盖，避免把舍入误差当收益。

H2：H2_baseline、H1_location_H2、H1_scale_H2、H1_location_scale_H2。仅用该地区H1月内均值误差的小时加权平均作δ，真实/预测月内方差的小时加权均值比作s；H1缺失则δ=0、s=1并记录，H2全部可用月份保留。这些需要本地H1小时标签，仅测参数的时间稳定性，不是零本地小时方法。

baseline的2272条CRPS/MAE/覆盖/宽度/Winkler须复现V159≤1e−7。固定相位与矩规则均来源于已经查看源标签，任何正结果只说明剩余问题的性质；不算晋级，不用加宽后的覆盖宣称效率突破。完整报告两侧漏盖、宽度、CRPS、区间分数，以及模型定义的锚误差、κ误差和尺度比。只有明确可归因的空间后才设计可部署机制并查新。
