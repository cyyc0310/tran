# V176准备：只核查同预算虚拟聚合的元数据可行性

2026-10-29，Sol。此项不训练模型、不读取小时发电结果、不做CIF评分。V175正式评分已完成、审计进行中；本协议不修改任何冻结实验，不把库存核查称为性能突破。

新的可证伪问题是：现有逐地区活动law是否遗漏了聚合结构的影响？两个或四个系统同步发电量相加后，CIF是以各时刻发电量加权的比率，不能直接平均原CIF。只有同月粗统计、完整UTC日历及合法同月输入都能相加时，才有清晰的月度聚合语义。

本轮只使用V159六外折proper名单、原≤4096采样索引、canonical profile index和UTC timestamps，不加载generation或margin_fractions。穷举proper二元组合；四元组合按SHA256(`v176/`+排序父地区列表)固定选前64个/折。对每组和采样月份并集，记录父源月是否存在、当月与合法输入月是否覆盖完整UTC日历、各父最新合法输入是否同月、原采样时间交集数、24时钟覆盖数及交集原索引hash。

完整月必须小时数等于该UTC自然月且时间轴逐项等于每小时日历。输入发布日仍为下月月初+30天。库存“合法聚合月”定义为所有父源当月完整、各自最新合法输入同月且也完整；另外报告交集非空、24时钟齐全的数目。不按任何CIF结果选组合。交集只能使用每个父源已经抽到的小时，不扩大唯一小时预算。四元结果仅代表这64组的元数据可行性，不推广为所有四元组合的统计代表性。

尚未实现的后续价值实验必须比较：原数据、保持同一父样本多重集合的时钟内置换聚合、UTC同步聚合，以及只放大发电量/M但不增加独立组成的比例缩放控制。比例缩放保持CIF不变；与真实聚合不同，有助于检查模型是否把月发电量误当可识别的独立机组数。新增组合不是独立数据，不能将相互重叠的父源组合当成独立校准地区；所有父源必须服从外层和内层地区隔离。

聚合并不自动减弱尾部：[PRX Energy2026](https://journals.aps.org/prxenergy/abstract/10.1103/vms3-ng8z)在风场中研究共同、非线性相关和聚合后的间歇性，不能把独立CLT的1/√N套到CIF。普通聚合增强已有[COURAGE2021](https://www.nature.com/articles/s41598-021-93545-6)，同步聚合或mixup本身也不构成原创。此处文献只支持假设筛查，不是完整查新。

月度总量不能唯一识别机组数、空间相关、停机或调度。虚拟源相加仅表示代数生产组合，未核验真实地区/机组边界互不重叠，不称真实地理扩区。只有在同预算强控制下看到独立增量，才进一步设计聚合结构的迁移机制和理论；否则停止该支线。中国实表、真实发布时点、真实排放及独立地区确认均未完成。
