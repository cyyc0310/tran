# V151：小时CIF分布与月度信息时效

冻结于V150后、V151评分前。本轮回到小时CIF的原始任务，仅作强基线与风险支持诊断，不把标准重组称创新。

复用已打开的PACE/LGEE/SC、两个30-fit/12-cal来源划分。所有源小时形状、无条件分布及残差学习仅用拟合源2024年；校准用另12源2024年；目标为三个地区既有2025年质量合格月份。源小时输入与目标身份严格分离。

两个独立预算：同月完整逐燃料总量（事后重建上界）；最近可用的历史月总量，假设月末排他时刻+30天发布、在查询月初前可用（控制信息时效的预测探针）。没有历史已发布快照，月统计与质量筛选来自回顾性原始数据；不能称已验证中国真实发布时间。没有合格历史月的查询对全部方法共同排除并记录。预测器不按目标小时值决定月份。

四个同预算分布基线：源小时无条件分布；月度EF加权水平+proper源同预算残差分布；按查询组成重组源逐燃料形状的等区池；Hellinger条件池（带宽固定.3）。每个源区选择2024年中距查询日历月最近的两个有效月，平局按月份顺序；组成核权重固定于查询统计，不能读取目标小时。无燃料源形状取1，这是假设而非识别保证。源区/源月内小时均匀，同区总权重相等。

主要标签是名义固定EF的非负发电代理CIF（煤1000/气400/油800/其他400、非化石0）。不混合因子盒尾数覆盖与小时覆盖。重组分布保留完整源月小时原子，精确计算加权经验CRPS（排序前缀和，无粒子近似）。点预测取分布均值；初始90%区间为q05/q95。

每个预算/方法单独校准区间：计算每个校准小时距初始区间的非负误差，比较区域等权池q90与各区域q90的最大值；q90取左连续经验逆CDF。校准后区间裁剪[0,1000]。这是经验来源包络，不宣称任意目标区条件覆盖或分布无关跨国保证。区间校准不改变原始分布CRPS，明确报告此边界。

保存逐月样本分母、输入统计月份/年龄、供体身份与权重、缺失燃料质量、校准半径、逐区小时CRPS/MAE/覆盖/宽度/Winkler和宏/最差地区结果。检查源年度/身份、输入可用时间、共同分母、预测分布有限与权重、冻结哈希。整月CDF不刻画具体小时相位，本轮无法证明小时条件形状恢复；但可直接检验覆盖与分布支持，作为后续原创机制必须战胜的基线。没有打开新地区，原始CRPS/覆盖/区间效率gate保持不变。
