# EIA-923月报驱动的合法本地适配与区间比较

冻结：2026-11-01，运行前。目标是推进研究优先级4：只用预测月前已允许的粗月历史，检查简单本地月量适配能否改进未来小时强度，并评估覆盖与区间效率。它承接既有七种月报适配和三种风险参考，不增加新预测算法。

## 信息预算和成对输入臂

- `hourly_reconstructed`：沿用原适配实验，用EIA-930/NESO小时燃料数据回算五类月度份额。
- `eia923_us`：美国七BA改用EIA-923按报告BA聚合的官方月净发电统计；英国仍用NESO现有燃料月表。每一臂都只允许准确`t−2`及更早的月量。
- EIA-923使用2020–2024年度最终档案，其中2020/21为`Reported Fuel Type Code`旧表头、2022–24为`MER Fuel Type Code`。旧表常规水电代码`WAT`与新版`HYC/HPS`均映射到水电；旧表`WAT`且`Reported Prime Mover=PS`的抽蓄负净发电作为抽水耗电截为0，正净发电保留。月量映射到煤、气、油、其他热电、核、水、风、光八类后再合并为火、水、核、风、光份额。
- 美国各BA的历史月表和目标端本地月量适配切换到相应输入臂；月度变化预测器的训练月表与目标预测月表使用同一预算。固定EF重组的源小时平均轮廓和有效EF由相同源小时燃料监督估计，不读取月组成特征，也不随输入臂变化。小时燃料不作为目标输入。
- 月报预测器、源2022小时监督、2023H1/H2位置/风险拟合与校准划分、目标2024小时和评价月份（全月份及共同2/4/6月）与原实验一致。沿用此前美英适配实验的美国六BA源队列（不含BPAT）；GB→US目标仍评分七个美国BA。两臂共享相同目标行。

## 模型与风险

点预测候选固定为持久性、上一年同月、阻尼趋势、本地历史Ridge、源历史Ridge、源预测加本地回测偏置、收缩偏置。固定源有效火电EF和小时形状，不读目标小时标签，也不在目标小时数据上适配EF。区间固定比较全局绝对残差、异方差尺度和CQR；风险模型只在源2023H1拟合，在源2023H2校准，目标只读取日历和预测月粗组成。

所有两臂×方向×方法预测须先封存再读取目标响应评分。主要汇报同一共同月的MAE、日内形状误差、90%覆盖、宽度、区间分数和最差地区。点MAE改善不能代替可靠覆盖；不因覆盖更高而忽略区间过宽，也不因更窄而接受失覆盖。该合同测试月度预测器/适配器对官方月报口径的敏感性，不将固定EF重组包装成使用了新小时组成监督的模型。

## 时间版本和解释

当前EIA-923档案是各年最终修订版本，并非每个历史预测时点的发行快照。因此实验解释为“官方最终月量按精确`t−2`索引作滞后模拟”，不能声称as-issued历史回测或真实在线适配。GB使用当前NESO历史燃料表，沿用既有研究版本边界。标签是固定EF发电侧代理，不是中国实测小时CIF，也不与EIA/NESO消费侧标签混合。

两国、已查看2024目标是开发评测。只有成对适配在两方向/多个目标区域显示对强持久性和强重组有实际收益，并达到预定覆盖效率门槛，才值得设计未查看国家/时期确认。否则把结果用作输入预算和失败边界证据，不将适配器包装成论文创新。
