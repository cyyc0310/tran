# V56 本地去年同月 EF 季节性探针

日期：2026-10-27。开发探针，不是独立确认。针对 V55 的结论，比较目标区最新月度 EF 与目标区上一年同月 EF，检验季节匹配是否比“最新已发布月份”更重要。

数据窗固定为2025 H1校准、2026 H1前推评分；小时形状仅来自固定11个来源区的上一年同月，目标五类粗月量使用预测起点合法可得的上一年同月统计。候选 EF 为 donor 同月、目标区最新完整年度、目标区最新已发布月、目标区上一年同月、上一年同月与最新月的等权平均，以及连续3/6/12个月加权EF。所有目标本地月记录必须满足 `period_end <= origin` 与 `available_at <= origin`。只报告均有足够来源校准且可预测的月份，逐区报告有效月数；主要比较点 MAE、bias、pooled q90覆盖/Winkler及 max-source q90覆盖。

数据仍是 EIA 固定因子正部已报告发电代理。本探针使用已打开的2026 H1结果，任何优胜方案需要更新更晚年份或新地区做预注册确认后，才可称为泛化突破。
