# V204：完整月度电源分类后的可识别对象与研究决策

日期：2026-10-29。根据用户补充，手头月报含所有发电种类的月度电量；原始字段名、单位、口径、修订历史尚未提供。本记录把该信息条件映射到已有识别实验，避免把“类别全”误读成“小时 CIF 已观测”。

## 月度完整分类能识别什么

设月份内小时为`h=1,...,T`，类别`k`的发电量为`G_hk`，类别排放因子为已知常数`e_k`。月表给出`E_k=Σ_h G_hk`。若统计覆盖完整且类别、排放边界与目标一致，则可计算：

`C_month^energy = Σ_k E_k e_k / Σ_k E_k = Σ_h G_h C_h / Σ_h G_h`,

其中`G_h=Σ_k G_hk`，`C_h=Σ_k G_hk e_k/G_h`。因此完整月度分类可识别该月**发电量加权生产侧强度**，前提是类别EF已知且可比。若某类内部仍混有不同燃料/机组，或EF是区间，该量也只能得到相应范围。

这不等于等小时平均`mean_h(C_h)`。两者相差`Cov_h(G_h,C_h)/mean_h(G_h)`；月边际没有小时总发电量`G_h`与小时强度的协方差。月度分类还不识别消费侧因子所需的跨省输入碳流、净交换时序和损耗，也不识别小时排序、阈值超限频率、峰值或连续超限时长。

一个两小时反例足以说明最后一点：低、高强度两类的EF分别为0和1000，月总量各半。小时配置`[低,高]`与`[各半混合,各半混合]`具有相同全部月度类别总量及相同能量加权月均500，但小时CIF分别为`[0,1000]`与`[500,500]`，阈值600以上小时数分别为1和0。增加更多月度燃料类别不解除此时间分配歧义。

## 与已有实证的对应

- V87在固定EF、任意小时分配的模型类中，对13,392个地区月×阈值复核了尾计数锐集：逐燃料月边际对尾风险的作用可压缩为阈值两侧活跃支持和月度超额`D=Σ_k(EF_k−τ)E_k`。这是用户全类别月表最贴近的既有实验；不能把重复测试同一数学命题包装成新发现。
- V131/V132在同一EIA代理 cohort 上显示，阈值相关的日度三字段（总发电、阈值高侧发电、清洁发电）几乎保留了日度完整燃料分项对识别区间的收窄效果；三日稀疏报告比逐日字段成本低，但增益仅小幅且不等于概率区间校准。该结果是潜在的最低本地信息合同，不是中国公开数据可得性或中国效果证明。
- V199/V200用Ember月度八类结构做了中国投影数据探针。结构相似供体带来的形状收益小且不稳定，未转换成稳定覆盖—宽度增益；目标月均还是事后oracle，不能当月报可用预测。
- 因而，用户所持“所有电源种类”的月报值得作为**水平/组成输入臂**，但它不能单独解决目标研究最难的小时风险可迁移性。当前不应再把完全相同的月度分类接到另一个常见回归器上当作方法突破。

## 研究设计判断

可证伪的主问题应收窄为：在只有已发布月度全类别发电量的目标省，哪些小时CIF风险量可由物理约束识别，哪些只能由跨省源模型预测；最少增加哪种、多少本地时间信息，才能把选择性风险与区间效率改善到预先设定水平？

建议论文贡献拆成：

1. **信息预算识别曲线**：月度类别、月度净交换、稀疏日度/分时阈值风险统计分别对应的锐集合和弃答率；识别集合与预测区间分开评分。
2. **条件化迁移方法（候选而非既成贡献）**：从源省小时误差估计目标小时风险，只在物理支持和源域重叠条件满足时收缩区间；支持不足时保留部分识别范围或弃答。必须在同一目标覆盖下优于简单锚定、标准动态模型、异方差与条件分位数强基线。
3. **双层外测**：公开投影小时数据只作模拟压力测试；真实运行效果须有带时间戳、边界定义与版本的中国小时标签。未取得实测标签前，不能声称真实中国小时 CIF 准确度或可信覆盖。

## 下一步停止/继续规则

V87、V131、V132、V199、V200已覆盖月度分项识别和阈值侧时间补充的一大部分。继续跑同一EIA/Ember模拟数据上的边际变体不具备清晰新颖性。下一轮优先完成：

1. 把实际月表原始表头和定义写入字段合同，确认“全部种类”是否包含煤、气、油、生物质等独立行，是否存在跨省交易/全口径分母，以及数据何时首发、如何修订；在此之前不得称它为可用于历史回测的as-of输入。
2. 用该字段合同构造公开月度预算臂，并明确目标是发电侧还是消费侧。若只有用户所述月度字段，模型输出应包含可识别的月度强度/边界，而小时部分用迁移预测和风险拒答表达，不把点插值伪装成由月表识别。
3. 在公开数据可提供的范围内寻找合法的小时目标标签；若仍无标签，停止算法调参，把论文定位为识别/信息预算基准与模拟压力测试，并如实报告验证限制。

## 结论

“每种电源都有月度发电量”提高了月度组成与发电侧能量加权水平的可用性，但没有补上小时调度和消费侧交换信息。现有结果支持一个有价值的**最低信息量/可识别性研究问题**，尚不足以证明新的小时预测算法突破。潜在的论文新意来自严格的estimand、信息合同、锐界—迁移风险分解和真实源外验证组合；其方法增益和外部标签可得性仍未证实。

## 用户数据可用性补充（2026-10-30）

用户进一步确认，其持有的公开月报按月列出**各类发电量，包含可再生与不可再生类别**。这比前述“公开统计常见分类”的保守假设更完整，因此后续主信息臂应按用户提供的全部类别构建月边际，而不应预先把不可再生类别合并为火电总量。用户尚未贴出原始表头、计量单位、统计边界、发布时间/修订版本；因此暂不推定其中煤、气、油是否逐项独立，也不称其等同于Ember估算或EIA燃料口径。

这一补充改变的是可用**月度组成**分辨率，不改变小时可识别性边界：完整月度类别边际可支持月度能量加权生产侧强度的构造（需口径匹配的类别EF），仍不决定小时内燃料排序、小时分母、跨省电力碳流或小时风险。V262–V264进一步显示，若能合法获得小时总量曲线，其测量误差/时标误差下仍可能收窄全月尾风险锐界；但中国天气重建负荷不能直接视作发电量，且这些试验并非小时预测覆盖验证。
