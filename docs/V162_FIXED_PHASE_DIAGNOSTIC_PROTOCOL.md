# V162：既定重组分布的固定时钟相位诊断

在本轮评分前冻结。V159–V161没有形成小时覆盖与效率联合增量。本轮只量化既定重组分布是否存在可解释的时钟错位，不开发新预测器、不打开2025目标或新地区。

数据、29源六折proper/test角色、2024测试月份、两个统计预算、最多4096来源小时抽样，全部复用V159。只重建positive_recomposition及conditional_activity_recomposition，固定V159的pooled/max-region校准半径，不重新校准。两方法当月臂相同；不记为独立成功。

对查询UTC小时h、偏移k=0,…,23，使用原分布F_(h+k mod24)。所有燃料联合原子、概率及各小时分布宽度不变；仅改变与查询时钟的对应关系。每个完整月24个UTC钟点等频，因此均匀日历下的平均宽度必须严格不变。但缓存有效小时可能缺失，实际评分宽度可变化，须同时保存和报告，不把日历不变偷换为实际评分不变。偏移正号表示查询h使用原h+k分布，不直接解释成地理经度。

首先k=0全部五项指标必须复现V159对应方法（预计2272条），绝对差≤1e−7。CRPS用原预测分布，校准仅影响覆盖、宽度、Winkler。

三种相位只用于诊断：

1. region_budget_method_oracle：每地区、预算、方法全年只选一个k，使该地区按小时加权的全年CRPS最小。可用本地标签，显式oracle；不是可部署结果，更不是对任意未来方法的数学上界。
2. shared_region_oracle：每地区只选一个k，以conditional_activity在两预算下的地区CRPS等权平均为目标，然后同一k作用于两个方法、两预算。检查更接近固定物理时差的共享相位潜力。
3. H1_phase_H2：仅用该源1–6月标签选全年固定k，7–12月评价；H1没有可评价月份则k=0并记录。所有可用H2月份保留。仍需本地小时标签，只检查相位时间稳定性，不能称零本地小时方法。

平手（距最小CRPS≤1e−10）优先最小绝对偏移，再按有符号偏移排序，避免常数CIF源被数值噪声赋予伪相位。共享选择按两个预算分别小时加权后等权，不被当月更多月份重复计权。选择只用pooled记录，因为CRPS与校准无关。

额外保存每地区各k的最高可达覆盖，但不把CRPS最优与覆盖最优混作一个方案。用每月真实CIF边际与时钟独立的精确置换期望作对照：保留真实边际、钟点占比和原分布，计算每个相位在随机时钟配对下的期望CRPS；区分条件对齐收益与有效小时占比造成的表观变化。

按地区等权、区内有效小时加权，完整报告CRPS、覆盖、最差地区、实际/日历宽度和区间评分，以及H2稳定性与六折。后验收益只有在足够大且保留覆盖时才值得核查公开地理/时区元数据；即便如此，也必须另做无小时标签的同预算实际模型并与简单时区转换比较。oracle不计入原方法晋级或论文创新。
