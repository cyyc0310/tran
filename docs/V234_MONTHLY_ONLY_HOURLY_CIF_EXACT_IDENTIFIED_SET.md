# V234 解析结果：仅有月度分类电量时，单小时 CIF 的精确识别集

日期：2026-10-30。此项是解析推导，不是数值实验或模型性能结果。目标是将用户确认的“各发电种类均有月度电量”转成清晰的信息边界。

## 条件与目标量

一个月有 `T≥2` 个时段，发电类别 `k` 的月电量为 `M_k≥0`，固定类别排放因子为 `e_k`。真实但未观测的小时类别电量为 `g_{tk}≥0`，仅知 `Σ_t g_{tk}=M_k`。小时生产侧 CIF 为

`C_t = (Σ_k e_k g_{tk}) / (Σ_k g_{tk})`, 且目标小时总发电量为正。

不添加小时总量、机组可用率、爬坡、储能、进口/外送或调度约束。令活跃类别集合 `A={k:M_k>0}`。

## 命题：单小时的锐识别集

在以上信息条件下，任一指定小时的可行 CIF 集合恰为

`[min_{k∈A} e_k, max_{k∈A} e_k]`。

**上界与下界。** `C_t` 是活跃类别排放因子的非负加权平均，必在其最小值和最大值之间。

**可达性。** 任取该区间中的 `c`，存在一组仅使用因子端点类别的非负比例 `α_min, α_max`，使 `c=α_min e_min+α_max e_max` 且比例和为1。选足够小的 `λ>0`，令目标小时两端类别发电量为 `λ α_min, λ α_max`，其余类别在该小时为0；可因 `M_k>0` 而取到逐类月预算以内。将每类剩余月电量任意分到其余 `T−1` 个时段即可满足全部月度边际。因此每个区间内的 `c` 都能由某个满足月度表的全月发电分配实现。

所以，如果有多种排放因子不同的发电类别，类别齐全的月报虽然精确确定月能量加权均值 `Σ_k M_k e_k / Σ_k M_k`，但对任一未观测小时仍不能将 CIF 的识别集收缩到该月锚附近。识别宽度只由活跃类别的 EF 极差决定；加更多月度分项只有在它排除某些活跃 EF、或分项具有额外时间/出力约束时，才会缩窄该单小时集合。

## 多时段风险的边界

上述是**一个小时的边际投影**，不能直接将每小时集合的笛卡尔积称为全月联合可行集。不同小时的配置通过月度守恒相连；尾部小时个数、峰值持续时长等联合量需单独优化。项目 V87 已对有明确小时总量与阈值的受限条件做过尾计数锐界；V232 则证明在“给定每小时总量＋月燃料边际”的条件下，单小时边际界已是联立月约束的精确投影。两者均不能替代当前中国月报-only 的小时总量缺失。

## 对最低本地信息的直接推论

- **月度水平：** 各类别月电量与兼容 EF 足以给出该月发电侧能量加权锚。
- **单小时名义 CIF：** 至少需要关于该小时的分母（总发电量）及能识别排放分子的小时信息。固定 EF 时，V228 的因子向量行空间字段是精确、依活跃支持变化的最小线性测量合同；它需要小时观测，月边际不能替代。
- **未观测小时可信区间：** 除上述识别通道外，还需要目标地区具有代表性的时间样本或可验证的运行动态约束来校准剩余风险。V224–V226 的12个随机完整日证据来自 EIA 代理，不能直接外推中国。
- **消费侧 CIF：** 还需带碳属性的省际净交换及相应分母；省内发电月表不足以识别消费侧对象。

## 研究判断

V234 不是算法创新。它把“全类别月报是否足够”回答为严格的识别定理，并排除了仅靠换回归器来声称小时信息由月表获得的路线。可发表的潜在贡献应转向**按标签边界和信息预算报告的识别—预测前沿**：先给 sharp set，再单独比较迁移预测和风险覆盖；用公开月度表只支撑月锚，以公开运行代理作压力测试，并避免把估算产品构造形状当作独立验证。若论文必须主张可信的中国小时预测，仍需要至少一个独立运行侧小时数据源。

## 后续可证伪方向

对候选额外字段逐个求识别集收窄量：小时总发电量、火电/煤电/可再生小时合计、净交换、可再生实发、可用容量。按新增字段成本和锐界收缩构造预算前沿；对区间预测再单独评分覆盖与宽度。没有独立标签时，只报告结构性识别量，不调参宣称预测增量。
