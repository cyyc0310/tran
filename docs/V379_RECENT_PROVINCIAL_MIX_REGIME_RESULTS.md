# V379：近期省级发电结构与本地组成的阈值信息（2026-10-31）

## 问题

V378显示上海火电份额显著高于全国池化值，但上海单省不代表全国。V379把V364/V366完全相同的充分证书、EF支持和判断公式移到最近的17个单月报告期（2025年3–12月、2026年3–9月），检验省级混合结构在哪些地区、哪些阈值下会改变全国先验的风险判断，并据此挑选下一批需要直接从NBS入口复核的省份。

输入为V320 OREO转录的NBS规上工业面板，不是本轮用户上传的官方原始响应。排除1–2月累计报告期；31省×17期共527个省期。火电EF支持固定为`[400,1000] g/kWh`，非化石技术按运行期直接排放为0作粗组成情景。对份额`s`，阈值`τ`上的充分全宽证书为`400s ≤ τ < 1000s`。

## 主要结果

| 严格事件阈值 `τ` (g/kWh) | 全国池化证书省期 | 本地组成证书省期 | 全国证书被本地份额移除 | 本地新增证书 |
|---:|---:|---:|---:|---:|
| 100 | 0 | 30 | 0 | 30 |
| 200 | 0 | 58 | 0 | 58 |
| 300 | 527 | 278 | 249 | 0 |
| 400 | 527 | 446 | 81 | 0 |
| 500 | 527 | 412 | 115 | 0 |
| 600 | 527 | 328 | 199 | 0 |
| 700 | 0 | 248 | 0 | 248 |
| 800 | 0 | 120 | 0 | 120 |

在`τ=300`下，全国池化份额对527/527省期都触发证书；本地份额仅278/527触发，249期（47.2%）的全国池化证书不再适用，且没有本地新增证书。23省至少有一期脱离证书。脱离并非只发生在上海这种火电高份额地区：安徽、北京、天津等本地火电份额高的省份不触发；四川、云南、西藏等水电占比较高省份因热电份额远低于全国，也不触发。混合水平离开跨阈区间的原因有相反的物理组成，但都说明全国份额掩盖省际异质性。

**更重要的非单调发现：**本地信息不总是“减少风险/不确定性”。在低阈值100、200，本地混合份额新增30、58个证书，而全国份额没有证书；在高阈值700、800，本地份额新增248、120个证书，全国份额同样没有证书。原因是本地份额把部分区域从全国均值所在的阈值位置移到另一个可跨越阈值的位置。对冷启动基准，合理问题应是“本地统计是否改变该阈值下的可识别状态”，而不是把证书数量减少直接称为收益。

## 破局判断

这支持一个更有辨识力的论文候选：**省级粗组成驱动、阈值条件化的部分识别地图**。同一当地月度构成有时解除全国池化先验制造的虚假宽证书，有时则揭露全国平均掩盖的本地风险；方法输出应给出阈值特定的识别状态和信息来源，而非统一的“本地更好”分数。它可成为可迁移CIF基准的难度分层/信息预算协议。

但它仍只是规则层的部分识别充分条件，不是小时K锐界，不是预测模型，也没有实测覆盖证据。特别是2025–2026除上海上传的火/风/光原表外，其余地区仍是V320转录值；EF支持是情景设定；省间净输入和小时出力形状未知。故目前是**有实证数据形态支撑的基准创新候选**，不是已确认的算法突破。

## 下批直接数据核验省份

从V320的2026年9月省级结构中，按类别反差选：四川（水电86.3%）、吉林（风电27.3%）、福建（核电30.8%）、青海（太阳能32.3%）。这些份额只用于选样，不能代替NBS原始导出审计。和上海高火电样本合并后，才可检查“阈值特定的可识别状态图”是否跨资源结构、跨年份复现。
