# V81：天然气支持未评分地区中的月报支持上界确认

冻结日期：2026-10-28。V79显示月度燃料支持上界比L₁统计量更能收紧EPE/TIDC尾计数集合；V80质量合格区CHPD/DOPD/GCPD/TPWR在固定EF代理下只有EF=0燃料，不能检验尾事件。V81名单AVRN、DEAA由**标签盲**筛选确定：V52质量普查中2024和2025完整代理小时率都≥80%，年度活跃燃料列包含天然气；它们在整个TransCIF项目的结果/脚本/文档中仅出现于质量普查，不曾被评分。这两区是质量/燃料支持可用性筛选的全部候选，不看风险标签择优。

测试窗固定2024H2/2025H1/2025H2；每区半年的完整连续24小时UTC日覆盖须≥80%，否则只记质量失败、不换区域或窗口。τ=100/300，目标K≥8/24h。每地区-月支持M为V54冻结月表中正份额燃料固定EF的最大值；缺月表行回退1000。比较全局M=1000完整G锐集、本地M完整G锐集、本地M的G²必要外界、本地M L₁充分证书。L₁严格条件`H>τG +(M−τ)L₁`。若M≤τ，则风险事件不可能；这类情形需如实保留但不算尾部效用证据。

主看本地月度支持相对全球M能增加多少完整G风险识别；G²是否已收回大部分增益；L₁是否还有同预算增量。实际K必须包含于所有集合，L₁证书不得超出本地完整G锐集。此为固定EF EIA代理同期识别，不是前瞻预测、概率覆盖或中国小时验证。月度支持只是低频输入，H/G/L₁仍是额外小时信息。
