## 2. 精确基点及天气差分

**主结构方法关闭天气时，必须逐元素等于V11共同支持的原始native强重组**，包括原始路径、初次裁剪后路径、点预测、donor索引与日期。不得用经过另一种B形状回归修正的弱模型作为唯一消融基点。重新生成native并与原归档精确相等后，直接保留旧基点数值。简单加性锚亦重建核对。

将源月均归一化q分解为日幅度a与均值为1的燃料内形状s。两个固定V11 ExtraTrees形状预测器得到 `delta(x)=pred_W(x)−pred_B(x)`。对每条联合donor日：

`s_new = simplex_projection(s_donor + tau*(delta_query−delta_donor_LOSO))`

`q_new = a_donor*s_new`。

tau为天气强度，与情景放缩倍率kappa区分；固定tau∈{0,.25,.5,1}。tau=0或增量为零必须直接返回原q，不经过可能造成舍入变化的投影。源donor的delta由排除该donor地区的proper模型生成；校准地区与外层评估地区还分别从内层/外层全流程排除。保持各燃料日幅度、联合donor身份、全零日燃料及月不支持flat q=1；不保证小时结构零不变，需审计由零变正的数量和q质量。

保持燃料日能源不等于保持等权CIF日均，也不新增目标月组成精确协调。simplex会改变形状误差，记录投影量、负值比例及幅度误差，不能声称剩余方差原样不变。

形状预测器和所有参数复用冻结V11：每燃料64树、叶20、max_features=1、seed17023、单线程、拟合折中位数/缺失指示及等地区权重。不改旧生产代码。

## 3. 两轮顺序及固定网格

每配置128情景、seed17023、kappa∈{.75,1,1.25,1.5,2}，沿用先裁剪[0,1000]、围绕已裁剪情景均值放缩、再裁剪的发布口径。点预测为初次裁剪情景均值，倍率不重新定义点预测。

## 4. 风险与条件分位数强参考

结构donor方法使用谐波粗组成联合情景和共同联合donor，tau只作用于天气差分。端到端global/hetero/QRF参考使用合法组成点预测下的确定性中心，即先对全部增量q加权平均再比值重组；**不再叠加粗情景和随机donor方差**。其源2024H2误差已包含粗预测误差。

H2每个校准地区的中心由排除该地区及外层地区的模型/库生成，所有输入均按当日可用月统计构建，不使用未来真实月组成。两通道hetero复用V11：误差e拆为配对L=日均与D=e−L；标准ExtraTrees拟合log(L²+25)、log(mean(D²)+25)，尺度5至500。标准化误差采用按校准地区再留区的尺度预测，最终尺度拟合当前许可源全部H2误差；L与D保持同一个校准日索引。

QRF强参考是标准**联合整日分位数森林扩展**：RandomForestRegressor128树、叶20、max_features=.7、bootstrap=True、seed17023、单线程，以24小时误差作多输出平方误差分裂。源训练折中位数填补、缺失指示、等地区训练权重；明确不是逐小时各自独立拟合的24个原始scalar QRF，也不是以分布差异为分裂目标的Distributional RF，不声称穷尽全部条件分位数方法。

每树将全部风险训练行送入其已拟合叶，叶内按源地区平衡先验重新归一，平均各树权重得到w_cond。叶分布不再使用bootstrap重复次数，不要求其均值等于sklearn forest.predict；本机sklearn1.9加权bootstrap语义和环境随代码冻结。完整权重公式及原始文献见[V12设计审查](V12_DESIGN_AND_LITERATURE.md)。

第二轮p=.25/.5为分布收缩：`w=(1−p)*w_cond+p*w_equal_region_global`，p=0为普通条件森林；混合权重后抽一个完整校准日，不平均两条随机路径。p只用于QRF，不偷偷改动global/hetero或donor。保存条件误差索引、.05/.5/.95的原始条件分位数与水平，验证单调性；一并保存实际条件权重、源校准误差/地区/日期及共同uniform，供独立重算CDF、混合和路径身份。

各分支共享底层随机uniform，结构donor身份相同，global/hetero使用同一等地区残差日索引。QRF因条件CDF不同，B/W及不同p的残差日索引可以不同；不能伪称这些条件索引完全相同。抽中的每个日向量保留24小时依赖，但不提供跨域copula或覆盖定理。

主结构B分支精确为native。B global/hetero/QRF是另外的概率参考，使用同一未修改q中心加各自误差分布，**不声称这些不同风险合同的B参考也等于native完整分布**。其作用是识别风险建模与天气信息的贡献。

## 5. 源选择与评价

使用等地区宏平均、地区内有效日等权。源合格条件：宏90%覆盖处于[.90,.95]且最差地区≥.85。违约量为`max(.90−coverage,0)+max(coverage−.95,0)+max(.85−worst,0)`；合格者按CRPS、budget、model、factor升序，无合格者先按违约再按上述顺序，保留failed状态。逐分支选倍率；第一轮只在W donor强度中选tau；第二轮只在既定W网格中选主候选。选择从封存CSV重读，目标不参与。另报源纯CRPS最优诊断，不能据此事后改主候选。

主要报告小时CRPS、90%覆盖/宽度/区间评分、上下尾、路径覆盖、水平/形状MAE；另报告水平CRPS/覆盖、形状CRPS和中心化路径energy score。给出逐区及宏指标，特别是PACE/LGEE。覆盖增益同时检查区间宽度、CRPS和区间评分；不能靠单纯加宽宣布改进。

同步六个月配对bootstrap5000次seed17023仅作已查看开发数据的描述区间，所有配对须完整一致日支持；重复配置、粒子和两轮不是新增独立样本。source最优QRF只在源选择记录中排序，目标不得选最好的p/倍率。

## 6. 分开判断实用增量与原创性

实用增量gate：第二轮源主候选通过源门槛；目标宏覆盖≥.90、最差地区≥.85；相对native、简单锚及源选B参考均CRPS至少下降5%、描述区间上界<0、宽度不增加、区间评分降低。即使获胜者是普通QRF，也如实报告为标准方法带来的改进，不改称自创机制。

结构donor强参考gate：固定源选tau和donor倍率，另要求其达到同样覆盖条件，并相对native、简单锚、同天气hetero及源选最佳W QRF达到上述CRPS/效率要求。将这个gate与“主候选是QRF”分开，不能要求某方法比自身下降5%。即使通过，也只是值得进一步研究的证据，不自动证明原创性。

当前实现均为标准差分形状控制、异方差及QRF参考，custom_innovation_gate预设false。若存在明确实用增量，先冻结适用于当前天气代理、独立地区、可用性和缺失处理的确认合同，再进行未查看地区检验；本开发分析器不自动读取新地区。若未达标则保持未查看地区封存，报告失败收益来自中心、偏差、尾部或单纯风险补偿中的哪一部分。
