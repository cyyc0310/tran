# V65：省级模型负荷曲线的信息价值敏感性结果

日期：2026-10-27。脚本 `scripts/v65_load_shape_information_value.py`；冻结协议 `docs/V65_LOAD_SHAPE_INFORMATION_VALUE_PROTOCOL.md`；逐省月结果、汇总和输入哈希位于 `results/v65-load-shape-information-value-r3/`。

## 设计

对Ember 2016–2024省级月度八类发电边际，使用固定演示EF（煤1000、气400、其他化石400，其余为0 gCO₂e/kWh），计算24个小时-of-day槽的等槽平均CIF兼容界。对照臂为：(i) 仅月燃料边际；(ii) 24槽总发电量均匀；(iii) 按Yi等模型化逐小时负荷曲线的小时-of-day形状分配月发电量。2018另将Yi负荷曲线与Zenodo典型日模板逐省月配对。每个形状条件下用线性规划求锐界。

目标月的Ember边际已作为条件输入；实验是回顾性部分识别，不是预测。EF只是固定代理映射，曲线是重建需求而非观测发电。因而结果没有小时真值覆盖、校准或预测误差含义。

## 结果

- Yi曲线覆盖30省×108月，共3240个省月；Zenodo在2018覆盖31省×12月，共372个省月。模型负荷曲线臂中，月边际only平均界宽918.8 g/kWh，负荷形状条件界宽54.0，平均收窄94.1%；所有省月都比月边际only窄。这只说明“指定代理小时总量后”的约束会缩小数学可行集合。
- 等分24槽臂的界宽为数值零：由于小时总量被强设相等，等槽平均恰等于月度能量加权CIF，而后者已由燃料边际确定。因此负荷形状臂比等分臂多出约54.0 g/kWh的平均可行宽度。负荷曲线不是独立真值；其非平坦形状令等槽平均目标重新变得不可识别。这说明不能把相对“无小时总量”的94%收窄解释成负荷曲线提供了稳健、经验证的小时信息。
- 2018年同一360省月配对中，Yi天气重建曲线平均界宽50.3，Zenodo模板54.9 g/kWh；前者仅窄4.6 g/kWh，中位差−2.6，且只在61.4%的省月更窄。两种不同构造的区间宽度相关0.74，增量有限且代理假设未验证。
- 逐年平均代理界宽从2016年的46.8上升至2024年的60.8 g/kWh；这个变化来自月燃料组成与边际等数据变化，不能直接归因于负荷形状质量退化。

## 判断与下一步

V65没有产生可投稿算法增量。它提供的是信息预算边界：只凭月燃料总量，小时等槽均值极不确定；假定负荷时序代表发电可显著缩小兼容集合，但这是假设驱动的部分识别，不是可验证的精度提升。2018构造对照也没有显示足够大的、稳健的形状来源优势。

在用户确认的“只有公开月度或年度燃料统计”预算下，模型负荷不能进入主预测方法，除非未来获得真实小时发电验证或将该分支明确标为情景敏感性。更有论文价值的主线仍是：以真实小时发电区域做信息逐级遮蔽基准，量化月/年燃料边际分别识别什么，输出可行集合或风险拒绝边界；中国部分限定为公开月度数据as-of合规的低频任务，不声称小时CIF精确恢复。该主线仍需要独立标签支持和新的统一基准实现。
