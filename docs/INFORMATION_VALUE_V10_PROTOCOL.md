# V10：最小附加信息价值实验

2026-10-23，Sol。目的先检验信息价值，不命名或宣称新算法。V9封存文件保持原字节；六个目标地区仍为已查看开发集，不能再称盲测。

## 信息预算

基础I0：日历、按`period_end<=origin`和`available_at<=origin`过滤的历史月燃料组成、同表已发布`total_mwh/observed_hours`，以及固定13区代表点的经纬度。所有新模型都共享这些输入，包括固定V9谐波组成预测；原V9只作旧月信息参考，不将新增月总量或地理信息造成的收益归因于算法。代表点只作城市/粗区位代理，不是机组/需求加权天气。

R：原始EIA-930独立字段`Net Generation (MW)`的滞后28日正值分位范围、相对水平和变异统计。S：滞后28日完整总发电量日轨迹的归一化24小时形状，优先相同星期，缺失和回退显式编码。这是**过去总量遥测的新预算及其两种表征**，不是目标日真实范围或真实形状，也不是新发现的物理界。不得读取目标燃料分项/CIF来构造特征。原始净发电量带符号，与八燃料非负代理和不完全相同；有非正值/缺失时保留掩码，不自行当作物理正发电量。

主轨采用`hour_end+7d<=origin`，30日延迟为固定敏感性检查。EIA为修订快照，没有历史发布版本，故两者仅为**模拟可得性预算**；7日并非历史首发证明。原始数据解析仅接受七源及六个已查看目标的总量三列；不解析未查看地区数值。

W：独立历史预报档案的温度、风、短波等固定点天气；不能使用未来实际天气、ERA5或预测日起点以后初始化的产品。允许多个初始化周期，但每个有效小时的所有预报周期必须在共同origin之前，且满足预先声明的保守发布裕度。初始化与真正可用时刻不同：缺乏原始发布证据时，仅称“保守提前量的历史预报代理”，不能声称issued-public认证。具体API、模型、地点、提前量下界、发布裕度、支持和原始响应哈希须先写入天气获取合同并封存；不可在看到目标得分后更换天气来源、位置或缺失规则。天气完全无法取得时，明确记not-tested，不用实况填充。

无天气时固定四预算：I0、I0+R、I0+S、I0+RS。天气通过数据与时间闸门后，加入W、RW、SW、RSW，最多八预算；所有预算共享地理元数据（若使用）。同一轨道内所有预算与模型使用完全相同的训练/校准/评分日期；天气若只有子集，单独建立全预算共同支持轨道，不与全日G轨道的分数混比。所有缺失填补与变换只在源proper数据拟合；缺失本身不能据目标标签决定删日。

预评分数据核查选择的天气合同：Open-Meteo Previous Runs `gfs_global`，`temperature_2m_previous_day3`、`wind_speed_10m_previous_day3`、`shortwave_radiation_previous_day3`，UTC、m/s单位。固定72小时提前量的名义周期距共同日00UTC起点至少49小时，假定18小时公开裕度后至少31小时余量；API未给出每小时原始发布版本，所以这仍是受控预报代理。短波时间T为前一小时(T−1h,T]均值，CIF小时T为[T,T+1h)：本轮保留原API时间戳作为有一小时位移的预报轨迹协变量，不声称同时段物理约束，不用未来实况修正。2024年初有缺测，天气轨道所有八预算的proper统一2024-01-25起，calibration仍2024H2完整期，源2025H1和目标2026H1仍从1月1日起；保留预报缺失掩码，不因目标CIF删日。G主轨proper从2024-01-01起。天气地点、API参数、响应和数据合同在评分前哈希封存并绑定；旧版Jan25评估起点的预评分获取尝试保留为废弃证据，不与正式轨道混用。

## 模型、训练与选型

两个预先固定的直接参考：Ridge(alpha30)与ExtraTrees(150树、叶最少10、seed17023、单线程)。均预测相对合法谐波组成EF锚的24小时残差，输入所有同预算字段；源校准残差整日等地区重采样128情景，不声称跨域覆盖保证。缺失中位数只在源proper行估计，全缺列填0并保留缺失指示；标准化和模型拟合采用源proper等地区权重。两者共同的源校准、抽样种子、情景数、界限[0,1000]及倍率网格(.75,1,1.25,1.5,2)保持一致。普通残差用于信息价值筛查，不默认继承V9条件风险模块。

七源BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS。proper2024H1、校准2024H2、2025H1源外层LODO开发选型，评估地区从拟合、变换与校准中全部排除。2025H1用于开发选择，因此源汇总不是独立最终验证。每预算先按宏覆盖[90%,95%]及最差源地区>=85%筛选，再最小CRPS；无人通过按违反程度、CRPS和固定名称/倍率顺序选，并显式failed。主附加预算候选只能由源结果在非I0预算中选择，不能由目标结果决定。30日延迟压力检查复用7日选定方法及倍率，不重选。

目标AZPS/DUK/LGEE/PACE/PSCO/SRP，2026H1。全源2024H1/H2训练和校准不使用目标小时标签；在全部目标预测哈希封存后才读取对应目标CIF评分文件。输入总量与评分燃料列物理分离。预先固定源选择、输入哈希、代码闭包、环境和抽样参数；不覆盖旧实验。另比较同日、delay0的V9源固定谐波动态重组与简单锚参考，保留其原倍率，并披露新信息预算差异。

## 指标与决策

主要信息增量是同一模型、同源固定倍率下I0与增量预算的配对差；另报告每预算源选后的实际表现。分别报告CRPS、90%覆盖/宽度/区间评分、上下尾、水平和形状MAE，重点PACE、LGEE、AZPS、PSCO。等权地区宏平均；同步六日历月bootstrap5000次seed17023仅作已查看样本的描述，不含人工多轮选择不确定性。

只有源选唯一附加预算候选通过源gate，且目标宏覆盖>=90%、最差地区>=85%，相对I0源固定最佳模型及V9固定动态和简单锚均CRPS至少下降5%、区间评分降低、宽度不增加、六个月描述区间CRPS差上界<0，才触发另行冻结新地区确认方案。当前天气代理轨道只作信息价值开发，不单独触发地理确认；若天气出现明确增量，先另行冻结适用于该预报代理和地点的确认合同。未达标则保留未见数据，并区分“附加信息未显效”“模型未利用好信息”和“档案不可得”，不能一概声称该信息无价值。

本协议先定义目标和预算，具体执行闭包以首次真实V10评分前生成的冻结清单为准。任何预评分修订均留记录，不因目标分数改变规则。
