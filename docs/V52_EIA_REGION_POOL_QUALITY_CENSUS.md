# V52：扩大地区校准池的 EIA-930 质量审计

## 研究问题

V51 的新地区小时区间风险校准只有5–6个地区单位，90%地区级 conformal 阶数不足。检查已有 EIA-930 原始快照中是否存在足够多、完整度合格且此前未作性能评估的地区，可供后续冻结基线的源外验证。该审计只核时间戳、原生字段完整性和发电—净发电账差；不生成地区 CIF 分数、误差、形状统计或预测表现。

## 数据与筛选

使用项目已有六个2022–2024半年度文件、两个2025半年度文件及2026H1文件。按原生 UTC 小时结束时间减一小时重建 UTC 小时起点，并严格截取完整年界及`2026-01-01`至`2026-07-01`。对每个平衡区/年份要求原生记录覆盖至少80%，同时要求项目固定EF正发电代理质量门通过的完整UTC小时覆盖至少80%。代理质量沿用 EIA schema：当前文件中有报告的燃料字段必须完整，燃料净和与`Net Generation`差额不超过`max(10 MW, 1%)`，并排除不完整UTC日；未报告类别不能解释为真实零。

## 结果

共筛出66个具有时间记录的 EIA 平衡区，25个满足全部五个时段（2022、2023、2024、2025全年和2026H1）的双重80%门槛，未发现跨文件重复的地区小时。合格集合包括若干只有水电/低排放报告支持的区域，因此仅靠时间质量筛选会把退化零/近零排放序列误当作可比 CIF 校准组。进一步逐年检查活跃燃料种类后，20个区域每段至少有一个正固定EF燃料组；其中19个还至少有一个零EF发电类别，17个在每个时段都有至少两个不同正EF燃料组和一个零EF类别。这些是更适合后续多类别压力测试的候选规模，但仍存在组间类别与边界不同。

25个质量合格区中，12个属于项目此前开发/评估或V6确认区域；13个候选地区此前未作性能评估。按“每时段至少两个正EF组＋至少一个零EF组”收紧后，候选为17个，其中11个此前评估过、6个尚未评分（FMPP、GRID、IID、LDWP、PSEI、TEC）。因此最严格代理组池也超过了名义90%地区级 split-conformal 的9校准组有限阶数门槛。**这里的“未评估”只表示CIF表现尚未查看；并不证明这些BA与其他BA独立，也不证明它们代表中国省网。** EIA区可能共享互联电网、气象冲击和市场调度，故名义地区数不能直接等同独立交换组数。

## 对方法和论文的影响

1. V51`K=5–6`导致的90%组级校准阶数限制不是此数据栈的绝对上限：使用更多质量合格地区作为源，目标留出时有机会让校准源数达到9以上。
2. 这是一个可检验的增量机会，不是已经获得可信区间。**下一步先在已看开发区上冻结并评估一个同预算点预测器和地区级校准基线**，包括简单pooled q90、source-max q90及按地区打分的组级规则；记录最差区覆盖、均宽、区间分数和有效独立市场簇敏感性。
3. 若开发集合显示在覆盖门槛下有稳定效率收益，再按预先固定的数据完整度门槛与BA代码顺序冻结一批未评分区，封存全部预测后做一次2026H1确认。若开发阶段无明确增量，不打开未评分区CIF结果。
4. 即使增加源数，也不能忽略 EIA fixed-EF proxy 的统计构造限制：这是正部已报告燃料量×固定EF，缺失类别排除而非认证零，且未包括完整消费侧调入/调出和独立核算。该结果只能支撑源外代理 benchmark 的设计，不能作中国实测覆盖保证。

近期CIF方法也在继续强化多变量和多频率结构：AAAI 2026提出小波多尺度局部特征与动态跨变量依赖，并在澳大利亚四个市场评估。[论文](https://doi.org/10.1609/aaai.v40i46.41310) 这类设计本身不解决目标区没有小时历史、仅有低频统计的推理合同。因此 TransCIF 的算法/基准差异应以冷启动信息预算、区域级可靠性和失效边界为中心，而不是再把常见多频率分解命名为突破；论文需进一步核对原文输入窗口和可用标签后再定强基线。
