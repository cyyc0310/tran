# V208 江苏运行派生小时曲线：留一地市形状迁移试探

**状态：探索性，不是预注册确认实验。** 本轮只用来判断V206的小时形状信号能否在一组中国运行派生的分时分区电碳因子曲线上复现。由于输入是论文图表数字化值、样本仅13个同省地市×4个典型日，而且使用目标日均值oracle，本结果不能作为中国未见省份的部署性能或可信覆盖保证。

## 数据来源与数字化校验

来源为芦新波等发表于《中国工程科学》的江苏分时分区电碳因子案例。论文称使用2023-05-01、08-10、10-10、12-28四个季节典型日，为13个地级市逐小时计算电碳因子；方法基于发电、输电与电网拓扑运行数据。这里评估的是论文报告的**运行数据派生核算曲线**，不是小时排放的独立直接测量，也不是连续全年标签。原文：[期刊论文](https://www.engineering.org.cn/sscae/CN/1177188236516242258)，[PDF](https://www.engineering.org.cn/sscae/CN/PDF/10.15302/J-SSCAE-2025.06.026)。

从公开论文PDF第098页的矢量图提取14条曲线（13市＋全省），每条24个小时值。用表1中春季连云港、苏州和江苏全省的0–1、12–13、21–22时段数值校验：9个图表点最大绝对差为0.4 gCO₂/kWh，符合图中坐标映射和四舍五入精度。PDF SHA-256：`f0f175f256b243d2508755fe65e991d752c27a2acf1961dcf6e5a68ede159e9f`；临时矢量渲染SHA-256：`bf4e268914a8bf7f9d465059664bdc7ecce3a0b3c09c04b37827c7d9cbc2c5c3`。原始PDF与数字化逐小时值未纳入仓库或分发；论文图表许可需在任何公开复用前另行确认。

## 试探设计

- 分析单位：13个地级市分别留出；每折使用其余12市。全省曲线不作为一个地市，也不进入供体池。
- 每个目标日均值 `μ_target` 由该目标同一日24个目标小时反算，是比用户当前月度发电统计更强的**事后oracle**。所有方法共享这个锚，用于单独考察小时形状迁移。
- 点基线：常数日均锚；均值最近的单一供体形状；最近k个供体的中心化小时形状平均。所有形状均先减去各自日均，再加到目标日均上。
- 自适应k：对每个外层目标地市，仅在其余12个源市内做留一源市验证，按全部四季小时MAE选择k，再用该k预测目标市。目标市任一曲线都不参与选k。
- 区间比较：锚定区间用源市中心化绝对偏差的90%经验分位；形状区间用源市留一供体均值后的绝对残差90%经验分位。都采用同一目标日均和供体池；按小时算覆盖、平均宽度和Winkler90。
- 不确定性按13个留出地市聚类bootstrap评估点MAE差。小样本、同一电网和典型日选择会限制推断。

## 结果

| 方法 | 逐小时MAE（gCO₂/kWh） | 相对常数锚 |
| --- | ---: | ---: |
| 常数日均锚 | 34.296 | — |
| 均值最近单供体形状 | 37.018 | +2.722 |
| 全部12个源市等权形状 | 26.323 | −7.973 |
| 源市内LOCO选择k（每个目标k=6–8） | 25.735 | −8.561 |

全部12供体相对常数锚的城市簇bootstrap差为−7.973，95%区间[−12.260, −3.565]，13市中11市MAE下降；四季分别都下降（春：59.15→42.55；夏：39.31→32.61；秋：22.47→17.46；冬：16.26→12.66）。最近单供体没有改善证据，差值区间跨零。最近k点预测的探索性扫描在k=6–12形成平坦低误差区间，最小点约k=8；nested源内选择多数选7或8，在外层13市中10市改善，城市簇bootstrap差−8.561，95%区间[−13.406, −3.553]。该扫描和自适应规则尚未预注册，不能把本样本的k=8当成冻结的普适超参数。

| 区间方法 | 覆盖率 | 平均宽度（g/kWh） | Winkler90 |
| --- | ---: | ---: | ---: |
| 常数锚＋源中心化偏差90分位 | 88.46% | 158.96 | 219.79 |
| 全12形状＋源LOCO残差90分位 | 88.22% | 120.26 | 175.59 |

形状区间宽度比锚区间窄24.3%，Winkler低20.1%，聚合覆盖只低0.24个百分点。可是逐城市覆盖差异很大：形状区间在盐城69.8%、南通64.6%、宿迁54.2%、苏州70.8%；边际88.2%绝不等同可信的逐地区90%覆盖。该案例重复了项目一贯的判断：形状迁移有信号，异地尾部风险仍不能靠总体校准证明。

## 对“破局点”的更新

1. **获得了比同源规划模拟更接近真实运行核算的正向点形状证据。** 目标市日均后，广覆盖空间池有明显增量；选日均最相似的单一城市反而失败。这支持把“区域共同小时形状”和“本地水平/偏差”拆开研究，而非仅按均值近邻找一个城市。
2. **当前表现更像可检验的结构假设，不是新算法。** 全体/中等宽度供体平均、LOCO选k均是常规方法。若把它作为论文方法贡献，还要在多个省网/独立年份和真正未见地区上预先冻结后确认，并证明相较强层级/因子模型与动态基线有增量。
3. **区间问题没有解决。** 聚合区间效率提升伴随地市级严重欠覆盖；需要依据目标可观测的粗信息估计“共同形状可迁移部分”及“当地剩余风险”，不能使用所有目标小时的日均oracle来假装月报部署。
4. **用户的月度全类别发电量仍不提供这个目标日均。** 它能约束月总量或在排放因子/边界明确时约束能量加权月强度；它不等于24小时等权日均，也没有小时出力排序、净交换和小时排放流。故本试探只隔离形状机制，不能宣称用户信息预算可达到表中误差。

## 文献边界：小波和一般多变量预测不构成创新

- DACF已做跨六个欧美电网的日前CIF预测，但输入包括地区历史24小时各类电源发电量和天气预报，再逐类预测发电量并合成CIF；它回答有小时运行历史时的日前预测，不是新地区只见月报时的冷启动问题。[DACF论文](https://lass.cs.umass.edu/papers/pdf/eEnergy2022-dacf.pdf)
- Zhang等2026年预印本已把小波卷积核用于CIF多尺度局部时序，并在澳大利亚四个市场与跨变量关系联合建模。因此“给TransCIF加小波/多尺度卷积”已不是足够的新颖点；该工作同样是高频多变量forecasting，不等于解决月度统计下的未见地区可识别性。[2026预印本](https://arxiv.org/abs/2601.06530)
- 这意味着论文的差异不能只写“统一基准”或“跨区域迁移”，还需要严格的信息预算：训练区可用小时CIF与月类别边际，目标区只用目标月发布时可见的类别月电量；评估冷启动点形状、部分识别集合、逐地区风险覆盖和区间效率。V208并未满足该部署信息预算，因为它用了目标日均oracle，仅是共享形状机制的初步检验。

## 下一轮路线

优先把模型假设明确成“可迁移共享形状＋本地水平＋独立本地风险”，与层级因子分解、全部供体均值、最近k均值、直接点回归、pooled/异方差区间在**相同目标月报信息**下比较。训练侧可用目标以外地市/省份的历史曲线选择共享形状和k；目标侧只能输入事先可得的月度类别边际及其物理集合，不能使用目标日/月份小时CEF均值。必须至少增加独立电网/年份的授权小时标签，固定盲测折，并以地区覆盖和区间效率作为联合门槛。V208本身只支持继续验证这个分解，不足以声称已找到论文突破。
