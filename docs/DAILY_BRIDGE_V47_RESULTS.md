# V47：普通中心纠正在完整日期上仍有效，区间缩窄有限

2026-10-27，Sol。本轮将V46的32个月初日扩展到原七个开发地区的1145个有效日期。普通水平控制的覆盖改善仍然存在；对其中的Ridge水平，Keep相对匹配CenterOnly只缩窄约1.4%，同时覆盖略降。现有结果支持保留这些普通方法作为强基线，尚未显示新的风险迁移机制。方法不冻结，PACE、LGEE及真正未查看地区继续保留。

## 数据、信息预算与执行范围

2025年1至6月共181个UTC日，每个地区均预测全部181日，合计1267个query。评分支持只用旧V29日期可用性锁定：BPAT176、CISO178、ERCO180、FPL179、ISNE89、MISO166、NYIS177，共1145日，缺日不按新成绩调整。七个地区此前反复参与开发，V46的32日也包含在内；本轮扩大日期范围，不构成独立地区确认。

每天使用当时已完整发布的最近三个月粗统计，保留原字段和时间规则：离散月份相位、整数月龄、实际发布时间差。月度头训练数据与参数保持封存版本，六个月初的原始预测、EF、投影和15个CIF水平均重放最大差0；42个ET头确定性重建，42个Ridge头直接调用已封系数，没有新训练标签。月内的发布时间差可能超出月初监督时的范围，这仍是月度监督头每日调用，不是已接受日监督或风险校准的模型。

15个水平包括Legacy/Expanded六头各一组、Capacity-OP、旧CoalOilUpper及固定Mix。全部配齐Replace、Keep、CenterOnly、FlatKeep，加原三参考，共63臂：B0 18、B1 44、M8 1。B0只有合法粗月表，B1另用滞后登记装机代理；中国同口径完整B1尚未核实。M8拥有更细本地组成，只作高信息参考。CIF与EF均为固定燃料因子的发电侧代理，单位沿用gCO₂/kWh，不是实测排放或含进口的消费侧碳强度。

## 下一步与论文判断

完整日期使普通中心纠正的证据更扎实，也提高了后续方法必须超过的基线。继续搜月度水平门控或全局尺度缺少依据。下一步应在同预算下先比较最强小时架构，再用严格排除评估地区的源风险数据重估新中心下的尾部；所有候选都要面对CenterOnly、全局校准以及异方差/条件分位数强基线。风险训练还需防止其他teacher或小时bank间接包含被校准源的细标签。

候选创新仍需回答：哪些风险可由合法粗历史识别，哪些调度/内部燃料方向仍依赖未观测信息，以及分开处理后能否取得普通校准达不到的覆盖与效率增量。本轮没有证明这些条件，不更改总体任务为单纯的中心平移或选模，也不打开未知地区。区间聚合与无标签目标域效率优化已有先例，见另存文献记录；需要写清适用假设，不能仅给普通部件起新名字。
