# 严格CN5燃料组成响应头：逐燃料动态成分消融协议

冻结日期：2026-11-02，运行前。目的不是提出新的预测器，而是检验优先级3的机制命题：全动态燃料份额头相对比例重组/标量因子头的收益，是否由可迁移的煤、气、油或其他火电份额响应独立贡献，还是只来自整体正则化、单纯形归一化或固定源组成。

## 数据与隔离

- Energy-Charts严格CN5九国开发队列，整国外层留出；2022源小时训练、2023H1其他源国校准、2024外层目标评分。
- 目标标签与2024外层结果此前已用于开发；本轮是封存机制诊断，不是确认集、盲测或未查看国家外推。
- 输入严格为当地日历和预测时可见的`t−2…t−7`火、水、核、风、光份额/摘要。外层目标燃料小时量、热电因子和CIF仅在全部预测与半径封存后用于评分及响应机制诊断。
- 标签为细燃料小时序列与固定因子构造的发电侧代理，不是实测/官方CIF，不涉及消费侧。

## 固定预测头及逐燃料消融

每个外层折在其他八国2022源小时上拟合四个完全相同的HGB头，分别预测煤、气、油、其他火电在热电中的比例；非负截断后归一为四类单纯形。其他火电组按既有源标签映射处理。

- `fuelshare_history`：四项全部使用动态头。
- `fuelshare_fixed_prior`：四项均替换为该外层源训练集的国家等权热电加权平均份额。
- `ablate_<fuel>`：只有指定燃料项使用其动态预测，另外三项用同一固定源先验；四项合成向量按原方法非负截断和单纯形归一。固定EF换算及每小时热电形状完全不变。
- 强参照：`anchor700`、`ratio_recomposition`、`factor_history`、`direct_history`。

消融在固定单纯形中是条件机制诊断：替换一项后其余动态项仍按统一归一化投影，因此不能把各消融效应相加，也不称因果贡献。所有模型只使用外层源标签训练；消融不按2024结果选燃料。

## 区间和评分

每个外层目标使用与既有严格CN5响应头相同的2023H1源伪目标样本和国家等权q90绝对残差半径；不同方法分别用自身源残差校准。全部九国预测和半径先封存并验证哈希，然后才加载2024标签。报告国家×月份和宏观MAE、日内形状MAE、90%经验覆盖、宽度、Winkler，以及目标热电活动小时上的四类组成误差和有效火电因子误差。

宏观先逐月等权、后逐国等权；同时列最差国。不得把8760小时当作独立样本计算显著性。结论限于代理标签开发机制，不用于未见地域算法晋级。

## 判读规则

- 若全动态头优于`fuelshare_fixed_prior`，并且单燃料消融显示一项或数项稳定恢复大部分增益，可称“源监督携带了与该类燃料相关的预测信号”，不能称为目标燃料份额已被识别。
- 若固定先验已接近全动态头，或单项动态在多数外层国有害，则削弱“可迁移细燃料响应”的机制解释。
- 任何候选若相对强基线点预测有改善但覆盖、最差国或proper interval score恶化，只报告权衡；本轮不调参、不冻结、不打开新国家。

## 复现与完整性

脚本、协议、源数据及模型模块均记SHA-256；各外层点预测、四类份额、半径与投影审计封存后再评分。逐燃料份额需非负、行和为1；目标活跃热电小时使用同一支持；所有候选必须共用每外层同一预测小时集合。若任一哈希不匹配或预测行缺失则整轮不作有效评分。
