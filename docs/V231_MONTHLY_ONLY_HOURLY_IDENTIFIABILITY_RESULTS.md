# V231 结果：月度全燃料边际仍不能识别小时 CIF

日期：2026-10-30。使用 V226 已打开的 EIA 固定因子生成代理队列，26 个 BA、74 个 BA-month。此分析只研究可识别集合，不是盲测，也不是独立排放验证。

## 信息条件

用户说明中国公开月表可提供各发电类别的月度电量。V231 将这一信息映射为目标月燃料边际。为给“无目标小时燃料读数”最有利的条件，额外假定目标小时总发电量也已知；但用户当前只有月度数据，实际上连这个小时分母也没有。

在每个小时，约束燃料量非负、总和等于小时总发电量、每种燃料不超过当月边际。按 EF 从低到高/从高到低分配余量，得到这个逐小时可行多面体上的排放强度锐界。另计算若逐小时拿到 V228 最小因子行空间组通道，或拿到完整八类燃料小时量时的识别宽度。

## 结果

| 小时信息条件 | BA-month 平均小时可行区间宽度 | 中位数 | BA-month 平均 P90 | 代理标签落入可行集 |
|---|---:|---:|---:|---:|
| 月度燃料边际 + 小时总发电量（偏乐观） | 737.46 | 1000.00 | 739.10 | 100% |
| 月度边际 + 每小时最小因子行空间通道 | 0 | 0 | 0 | 100% |
| 月度边际 + 每小时完整八类燃料量 | 0 | 0 | 0 | 100% |

单位为该 EIA 代理的 gCO₂/kWh。月度边际+小时总量下，区间中位数达到 1000，说明该数据族里单靠月度构成不能排除某小时几乎由高 EF 类别供电，也不能确定小时混合。给小时总量已是对月度-only 场景的额外帮助；真实月表约束更弱，不能据此声称 737.46 是中国实际误差或真实预测区间。

V228 的每小时最小因子行空间通道在 74 个 BA-month 全部精确识别名义 CIF，最大重构误差 `4.55e-13 g/kWh`。所选组通道依当月活跃燃料而变；字段数（含小时总量）为2–4项。这里的零宽是“这些小时字段实际已观测到”的代数可识别性，不代表月报就能预测未知小时，也不等同于 V226 中仅抽取12个本地日校准后的预测区间宽度。

## 回答当前数据约束

- 月报的所有发电类别对**月度加权 CIF 水平**很有价值：给定口径一致的排放因子和分母，可直接构造月锚，并检验不同地区/月的能源结构变化。
- 它们不能单独识别**小时燃料混合或小时 CIF 风险**。还要依靠目标地区的小时读数、可验证的公开小时代理/时间形状，或明确报告宽的不确定区间。
- 在固定 EF 下，若能获得目标小时总发电量和 EF 向量所在行空间的最少小时聚合组，可精确得到名义小时 CIF。若只在少量完整日观测这些字段，V224–V226 显示它们可用于校准未观测日的边际风险，但需要12日×24小时的小时字段预算，尚不适用于纯月报直接部署。

## 论文判断与下一步

这项结果把方法命题收敛为：**月度燃料边际识别月度水平，最小本地因子行空间通道识别小时名义排放，稀疏本地日样本约束未观测小时的风险。**它提供了清晰的信息边界和可计算的本地字段预算，能支撑研究框架的核心定义；但一般线性可识别性和部分信息可行集已有成熟理论，算法新颖性仍有限。投稿价值取决于独立真实小时排放/运行侧数据、跨国家或跨电网复制，以及现实可获得的小时字段；缺少这些时，应定位为基准/信息价值研究，不能声称已解决中国月报-only 的小时预测。
