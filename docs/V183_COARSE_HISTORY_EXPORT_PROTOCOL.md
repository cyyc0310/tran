# V183准备：隔离导出更长粗历史，先复现canonical重叠

2026-10-29，Sol。V181配对实验仍在运行，未按其完整性能挑选新方法。本项只准备后续信息价值实验，不训练或评价新模型。

仅使用原V159的29源、2022–2024六个原始EIA半年度文件。文件内容hash必须与V144 canonical所记同名文件一致；不加载2025/2026文件或其他地区数值。只数值转换区域筛选后的原生燃料和net generation，需求/负荷预报不读取。原始文件是回顾性快照，不认证真实公开月报。

隔离导出器将UTC hour end减1小时，使用现有八桶映射与`_proxy_rows`质量规则：每个源、每个UTC年分别处理，遵循V144对2024的年度窗口，排除未观测类别而不认证物理不存在，原生负值只按既有proxy定义截0，保留完整且质量合格的UTC日。月有效小时比例至少80%、总量为正才导出。

月量是所有保留小时的精确十进制有理数和。导出每月八类margin字符串、月起止/合成month-end+30d发布时间、有效小时和覆盖元数据；不导出逐时数组、CIF、EF、天气/负荷或新小时特征。模型后续只能读取该月表。此处增加的是粗信息预算；不增加原≤4096小时的细训练预算。

2024按相同路径作重叠控制，对V144原29源已有每个profile的小时数和八类精确月量逐项复现，任何差异立即失败，不修改原canonical。仅2022/2023月量进入新增历史文件，2024新出现但原cohort未收录的月不得偷偷增加当前训练/评分样本。全部源年度质量审计保存，新增有效月数不能预认定696。

独立复核范围应包括所有月量/元数据重建、原2024重叠、月表字段白名单、输入输出hash和不含小时值；质量映射若共享核心辅助函数须明确。尚未证明历史月量真实当时可得、完整生产排放边界或中国表头可用，后续沿用synthetic发布合同，不能升级issued-public声明。

下一信息价值实验需事先固定基线与预算：原短历史和新增长历史分别提供给同样的粗持平、标准动态模型、森林及不确定性基线，逐折proper训练与合法query prefix隔离。只有粗层有清楚增量，才继续小时风险传播与专门机制；更多数据本身不算原创。
