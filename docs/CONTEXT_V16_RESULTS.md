# V16：粗统计能更新什么，仍缺什么本地信息

2026-10-25，Sol。两条源区筛查均完成，未找到满足现有门槛的机制突破。日燃料反馈改善部分日水平预测，但没有同时改善CRPS、覆盖、宽度和区间评分；给日组成创新配对小时形状也未超过普通重组。历史独立总发电形状的analog/IPF没有形成可晋级增量。这里只报告七个已查看源区的开发结果，没有新增目标/未知地区数值读取。

## 1. 信息识别与未来预测须分开

令非负燃料出力为a_hf，总量G_h=Σ_f a_hf，固定代理EF为e_f，小时CIF为C_h=Σ_f e_f a_hf/G_h。区间燃料总量M_f精确识别该区间的发电加权CIF：

`Σ_h G_h C_h / Σ_h G_h = e·M / Σ_f M_f`。

这不一般等于等权小时均值，更不决定极端小时的位置、峰值、超越概率或整日路径风险。知道每个小时G也仍允许燃料之间的跨小时替换：保持各小时总量及各燃料日总量的2×2循环，可改变CIF及其尾部。日总量更新正确，不意味着小时风险也被观测或校准。

合法滞后统计只直接约束过去。对未来更窄的概率区间，还需要组成动态、日内关系及风险分布可迁移的假设。历史信息不能排除任意未来调度改变；没有这样的限制，就不能从相同历史区分具有不同未来小时CIF的两个系统。这是本任务的信息边界，不是证明统计预测无效。

V15已封存的后验结构实验中，即使给真实小时G，目标日燃料总量的小时界宽仍为918.375g/kWh，真实3小时燃料量仍为646.511；相应日均界宽为66.082和15.589。它们是非负能量松弛集合的可行范围，不是概率区间，不表示真实波动一定这么大，也不能据此要求预测器机械加宽。[完整V15证据](IDENTIFIABILITY_V15_RESULTS.md)

### A：日燃料反馈与innovation条件形状

新增信息是八燃料日能量，模拟日末+7/30日才可见；它可以反算历史发电加权日CIF，不能称完全没有本地碳信息。隔离聚合器确实读取已查看源小时文件并压缩；预测模块仅接收粗表、proper源小时和原封存预测，63份完整预测归档封存后才进行2025小时CIF评分。[冻结协议](DAILY_CONTEXT_V16_PROTOCOL.md)

普通EWMA+日归一化重组相对native的CRPS下降4.67%，但宽度增加4.95%，区间评分上升1.97%。水平MAE从30.2076降至28.0317（约7.20%），形状MAE从19.9549降至19.6374（约1.59%）。这是新增日信息与构造变化一起的开发收益，不能全部归因于反馈频率，更不能称小时尾部已经校准。

同一EWMA/倍率下，innovation_full CRPS为25.54023；普通particle_analog为25.52443、forecast_analog为25.53563，原donor日重组为25.44776。完整创新配对没有胜过最强普通参考；打乱控制25.58662的微小差异也不能充当因果或原创性证据。源选择明确保留`source_pilot_gate=false`。[源选择](../results/daily-context-v16/source_choice.json)、[全部宏表](../results/daily-context-v16/macro_metrics.csv)

### B：原预算中的独立总发电历史形状

仍用原monthly+独立有符号netG预算；7/30日延迟、28/56日历史窗口，28份完整预测归档先封存。netG是软历史预测量，不等于八燃料正部和的真实分母。比较native、row-only负对照、普通analog、零/平滑prior的IPF、采样G形状和64/64路径混合。[冻结协议](GENERATION_CONTEXT_V16_PROTOCOL.md)

固定主设置中，analog CRPS约降1.26%、区间宽约降2.86%，但最差地区从85.23%降至82.91%，未维持覆盖。全部20个设置里analog和各rake方法均没有同时满足宏覆盖[90%,95%]与最差≥85%；混合只有两个30日设置满足，但CRPS/宽度/区间评分都差于native。较高倍率不是本轮的效率突破。[全宏表](../results/generation-context-v16/macro_metrics.csv)

row-only逐小时同时乘所有燃料，不改变同小时CIF；这是原理负对照，不是可改善碳强度的更新。IPF在保持日燃料列边际时通过相对燃料缩放改变CIF，仍是选择先验附近的一个重建，不识别真实调度。上述失败只否定这组实现和设置，不能推出总发电信息在所有模型中都无价值。

## 3. 目前可以明确的最小信息问题

不存在已被本项目证明、各地区通用的“最少两个字段”。需要先说明识别对象、允许误差、时效、统计口径与模型假设。

| 要约束的对象 | 粗统计已经给什么 | 剩余缺口/最小候选信息 |
| --- | --- | --- |
| 已观测区间的加权水平 | 同口径燃料总量+EF给精确加权CIF | 未来还需合法前推组成；日加权量不等于等权日量 |
| 日内高低时段及幅度 | 日总量没有时间定位；总G只给总量形状 | 少量固定时段的排放等效能量与同口径G，或可验证的时段燃料份额 |
| 给定排放燃料份额后的内部替代 | 仍可能在煤/气/油/other之间替换 | 煤份额和剩余燃料支持/EF限制；仅知“火电”一般不够 |
| 未识别的小时尾部 | 块中心、日量和过去均值均不唯一决定尾部 | 可认证容量/支持/爬坡约束，或明确单列的少量本地小时响应；概率迁移还需源验证 |
| 跨区小时覆盖 | 源校准能提供经验风险先验 | 目标无小时反馈时不能直接检验本地fine校准；须明示迁移假设并保留失败/拒绝规则 |

在本固定EF代理，`C=400t+600c+400o`，t是正EF燃料份额、c是煤份额、o是油份额。给t/c并不自动足够：若无真实当日油量或可信小时油上界，油可替代同组气/other。V15删除未来日/月真值后的目标小时界宽仍为105.798。历史零油不是未来物理零油证明；更换EF也会改变哪些通道足够。[V15去除oracle和EF压力对照](IDENTIFIABILITY_V15_RESULTS.md)

若合法份额预测误差界为eps_t、eps_c，且可信油份额上界为u，本代理下一个保守半宽是`400eps_t+600eps_c+400u`，还须另加EF和分母口径误差。它给出未来观测精度的规划问题，没有证明现有模型已达到该误差界。t/c各5个百分点、u=0时，仅这两项已对应50g/kWh半宽。

## 4. 下一轮只检验信息，不预造新机制

拟议V17先比较四个明确发布包：D2（日H/G）、D8（八燃料日能量）、T8（四个6小时块各H/G）、G5（日H及四块G）。`H=Σ(EF/1000)×fuel energy`。G5用于区分T8收益到底来自总发电时序，还是排放分子的时间定位。所有包一律日末+相同延迟，预测器拿不到未来块真值。

T8可反算历史六小时发电加权CIF，必须诚实称粗CIF监督，不能伪装零CIF信息。D8和T8各8个标量只表示固定维数发布包，不表示等Shannon信息、等采集难度或现实渠道已存在。现阶段未证明这类T8在中国可公开获得。

所有包先用相同直接Ridge/ET、异方差和条件整日分布参考测试。若普通模型就解释收益，结论是信息价值，而非我们发明了新的风险传播机制。精度量化/噪声、相位敏感性和真实发布渠道核查须在晋级前完成；exact源筛不是这些检查的替代。[具体设计与前沿文献](../results/breakthrough-search-v16/minimal-information-design.md)

现有文献已经研究部分标签的conformal和区间观测下的最短预测集合，不能把“保留未识别不确定性+校准”本身当新理论。其保证也不自动适用于跨区时序和本任务粗CIF信息：[Javanmardi等，COPA2023](https://proceedings.mlr.press/v204/javanmardi23a.html)、[Liu/de Paula/Tamer，2026修订作者论文](https://arxiv.org/abs/2501.10117)。容量候选可从[EIA-860官方库存](https://www.eia.gov/electricity/data/eia860/)核对，但装机、停运/备用状态和多燃料清单不等于未来小时可用出力，不能直接硬截预测。

目前最有依据的研究路线是：**验证什么发布信息能约束任务所需的小时风险，再设计对剩余自由度有明确作用的方法。**V16尚未达到论文算法创新门槛，未知地区保持关闭，持久研究目标继续active。
