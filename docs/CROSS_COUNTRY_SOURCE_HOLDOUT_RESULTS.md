# 源域留区筛选：国内收益没有跨国保持

2026-10-31。按[协议](CROSS_COUNTRY_SOURCE_HOLDOUT_PROTOCOL.md)完成六折源域地理留出，随后进行源选模型的两向开发评价。双方2024目标已查看，本轮不是新国家确认。

## 源选择

六个美国区分别作为2023H1伪目标，其余五区2022共同支持拟合原生重组及residual/factor/joint。每候选固定600步、seed412；共18个折内神经模型，另有一个最终美国模型。原生参数没有使用伪目标区数据。

以先等月后等区MAE筛选，要求相对native至少改善5%、至少4/6地区改善且宏形状MAE不恶化。全部条件同时成立才进入候选集合，取其中宏MAE最小者。结果选择joint、lambda=.5：

| 源伪目标 | Native MAE | 所选修正MAE |
|---|---:|---:|
| CISO | 139.69 | 94.81 |
| ERCO | 71.09 | 79.11 |
| FPL | 124.66 | 47.96 |
| ISNE | 81.14 | 63.83 |
| MISO | 119.67 | 104.86 |
| NYIS | 87.61 | 58.09 |
| 等区平均 | 103.98 | 74.78 |

宏MAE改善28.08%，5/6地区改善；形状MAE18.87→18.54。joint完整强度虽然点MAE更低，但形状变差，因此未通过门槛，不能事后换选。

GB只有一个源区，没有等价地理留出，按协议保持lambda0。不能把其原生分支称作经过相同国家级元验证的候选。

## 相同条件下的跨国复测

最终美国模型用全部六源区2022训练；各源2023H2绝对残差定90%半径，不做均值修正。先将全部目标预测落盘封存，再读小时代理标签评分。主结果共同2/4/6月等月后等地区。

原native对照在选型后由审计脚本补充，以相同源训练支持及H2校准计算；它没有参与改选候选或修改已封存预测。原始文件明确标记POST_SELECTION_REFERENCE_ONLY。

| 方向 | 方法 | 未加偏置MAE | 形状MAE | 90%覆盖 | 宽度 |
|---|---|---:|---:|---:|---:|
| US→GB | 原生重组 | 74.61 | 28.73 | 89.22% | 291.16 |
| US→GB | 源留区选择joint .5 | 95.69 | 29.56 | 55.46% | 204.69 |
| GB→US | 原生重组/协议回退 | 53.32 | 18.00 | 87.52% | 231.55 |

US→GB的MAE恶化约28.3%，区间更窄但覆盖严重降低。原生对照与所选分支使用各自源H2误差半径，不能将变窄单独算作效率收益。GB→US回退与native逐项相同，不产生算法增量。

本轮没有解决跨国泛化。更严格的源留区验证确实筛出了国内可用修正，但这仍不能替代真正的留整国验证。源区域与目标国之间的条件关系和核算差异仍可能参与失效，现有结果不能唯一归因。

不再仅根据相同美英目标误差调强度，也不因源筛选通过就冻结为论文方法。总体四项目标继续，尚无独立确认的新迁移机制。
