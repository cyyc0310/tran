# V288：目标年本地EF支持的oracle敏感性（事后诊断）

V286在PACE 2023未达预设日覆盖门槛；V287随后已读取目标年EIA `CO2 Factor`列并观察到目标煤因子越出上一年支持。本诊断进一步用目标年活跃小时因子min–max构造“current-year EF oracle support”，与CEMS及上一年本地支持对照，判断当前年因子信息是否足以修复失效。

- 目标仍为PACE/LGEE 2020–2023，目标中心、燃料边际和9日随机拆分复用V286的逐次样本（seed=286）。
- `target_year_oracle_ef`支持直接使用完整目标年的实际EIA因子列，因此是**不可部署的事后上界诊断**；不得用它宣称预测性能或确认。
- 同时报V286两种支持与source_loo作为比较；不据此修改V286结论，不做新方法调参。
- 重点查看PACE 2023的日覆盖、Winkler和宽度变化，以及其他BA-year的因子支持漂移响应。
