# V38：粗总量拟合改善，没有带来碳强度改善

2026-10-27，Sol。固定比较完成。两种前向利用率曲线、三种适配共六个普通对照，都没有超过V36简单门控。四燃料反演反而增大内部碳强度与CIF误差。本轮排除了一个具体候选：直接用跨区平均利用率曲线和普通非负反演，把过去火电总量误差解释成燃料倍率。

这不是所有前向模型或所有粗统计适配的否定。当前暴露的问题是：总量误差应分配给哪种燃料，不能仅由登记容量与平均利用率决定。

## 固定实验和信息预算

执行[预注册合同](COARSE_INVERSE_V38_PROTOCOL.md)，首次正式session32177退出0，prepare/predict/score为0/0/0。53项合成测试、独立代码与Python/数学预审通过。七个已查看源、42月初查询、原128个MG粒子、35个合格评分月不变；ISNE只有一个评分月。所有查询的完整预测先封存，再读评分标签。

源端保留原180个监督键；每outer仅其他六源的154例，FPL outer156例。新增的是相同源月的绝对总发电量响应，用以形成名义利用率，六个新臂共享。V36/V37没有这一绝对响应表示，因此是既有强参考；本轮相对它们的差别不能全部归于同响应预算算法。

目标历史只读总发电量和四类零因子能源的月份额，POS由补集得到。每查询取12条合法已发布记录；存在缺月和陈旧记录，不称连续一年。历史月份与查询分别按各自年份减二选OP库存。库存零不认证物理缺席，名义利用率可超过1；C=0/G=0的率无定义，按fuel明确排除，C>0/G=0的真零保留。各fuel有效源权重另行保存，不声称掩码后仍六源等质量。

Constant是源率加权均值；Month是固定一个权重单位向全局均值收缩的日历月曲线。适配None、Common和FuelRidge分别固定倍率1、共同非负倍率，以及λ=.01向1收缩的四燃料NNLS。14个多输出profile、84个Common与84个FuelRidge求解完成；其余84个None只计算目标。最大KKT违规1.3704315460216776e−16，低于预锁1e−8。优化收敛不能解释为识别或泛化。

## 失败定位：可以校正总量，仍可能校正错燃料

在原历史监督键的LO-source裸profile检查中，MISO月煤率真实均值.365635，源曲线预测.146097；气率真实.333729、预测.321176。四燃料反演得到的六查询平均倍率却是coal1.0852、gas1.2485。它更大幅提高了气的倍率，使已经偏低的EF继续降低。BPAT相反：历史煤率为0，源曲线约.237481；反演coal倍率约.8934、gas约.5490，更大幅降低气倍率，预测内部煤比重因而上升。

这些是固定预测和历史源外诊断之间的对应，不是对2025每个燃料真值的因果证明。它们说明普通反演主要沿可见总量方向修正，不能保证把误差分给实际偏移的燃料。源平均曲线本身的跨区偏差必须进入下一步设计。

Constant算子42查询的代数rank为1/2/3，各10/29/3次。重复12个月不等于得到12个独立燃料方向；库存变化才增加部分方向。Month有24次rank4、18次rank3，但所有查询最小奇异值除sqrt(12)与源外算子行误差RMS之比不超过.008721。满秩没有带来对学习误差的稳定性。

只看最小奇异值也不足以判断EF，因为gas/other使用相同因子。为此，另做了168行明确标为事后的功能敏感性诊断，不改变原方法或筛选规则：

\[
\nabla_\gamma EF={b\odot(e-EF\,\mathbf1)\over b^\top\gamma}.
\]

对B/sqrt(12)做SVD，以同源裸profile行误差RMS作为经验尺度，标记奇异值低于它的方向，计算梯度在这些方向的投影。所有84个profile/查询均有3个这样的经验弱方向。MISO Month-FuelRidge梯度的平均84.63%平方能量落在其中；弱方向梯度范数约93.65 gCO2/kWh每单位倍率L2。BPAT相应为66.67%、127.78。CISO/FPL虽也有弱方向，绝对梯度仅约1，说明比例本身不能代替碳影响大小。

经验阈值来自历史源外误差，既不是目标算子误差认证，也不是可部署选择规则。局部导数没有处理大幅非负扰动、未来算子误差或分母退化，不能转换为有限EF范围、概率区间或覆盖保证。CSV独立保存在`results/coarse-inverse-v38-functional-sensitivity.csv`，不冒充原runner输出。

## 论文位置与下一步

本轮没有找到可冻结的原创方法。普通聚合回归、NNLS、分式优化均不构成创新。直接识别功能而不恢复全部潜变量，也已有[Bennett等的COLT2023论文](https://proceedings.mlr.press/v195/bennett23a.html)和[2026年JRSSB期刊版本](https://academic.oup.com/jrsssb/article-abstract/88/3/998/8363931)；本轮核对了摘要与出版信息，未声称已全面审读期刊证明。

[LatentCP，2026年9月版本](https://arxiv.org/html/2608.03607)已通过响应空间校准反演潜在参数集合，并允许缺少潜在校准标签。其第2节要求可评估的已知forward family；我们的曲线由别区学习，存在跨区偏差，不能继承其保证。[Task-driven UQ](https://pmc.ncbi.nlm.nih.gov/articles/PMC12109201/)也已对重建后的任务标量做conformal区间，但第3节使用真实任务输出校准样本，并要求相应exchangeability。将这些思路改名用于CIF不足以形成贡献。

下一轮应先补一个普通强控制：从其他源的完整燃料监督学习区域持续误差的协方差，检查粗总量残差应分给煤、气还是共同水平；GLS、Gaussian更新和MinT式协调本身都属于已有工具。训练必须在outer以外再排被模拟目标的源，不能用它的细分标签生成自己的前向曲线或协方差。

若该控制也无增量，就停止这类反演扩展。若有增量，才进一步研究：过去和未来学得算子的联合误差下，哪些碳方向允许收缩，哪些方向必须保留风险；并与普通协方差更新作同预算比较。小时调度中不可由月报识别的剩余风险仍须独立保留。本轮没有评估CIF区间覆盖、宽度或小时风险，也没有打开旧目标或未知地区，长期目标保持active。
