# 伪目标整国留出模型选择协议

2026-11-01，拟合前冻结。该实验检验源域训练阶段模拟“目标整国没有小时标签、只有中国式t−2粗月输入”的能力，关注伪目标域验证是否能选出优于固定强重组的跨域模型。它评估训练流程和模型选择，不预称新学习算法。

## 数据与外层目标

使用Energy-Charts NL/ES/BE/AT/SE 2022–2024候选面板和既定九类固定因子发电代理。每次整国留一作为外层目标，其他四国为候选源。外层目标2024小时不进入特征工程、模型拟合、伪目标选择或校准；推理只读当地日历和t−2及更早粗月技术份额。月输入来自修订小时数据回算，不是历史as-issued月报。结果是开发留出，不是未查看国家确认或实测CIF验证。

## 内层伪目标任务

对每个外层目标的四个源国，逐个将一国作为伪目标。模型只用另外三个国家的2022小时标签及各自允许的粗月滞后特征训练；伪目标国2023H1仅以日历和合法粗月输入推理，小时标签只在内层选型评分时开启。重复四折，按伪目标国家等权汇总八种预先存在的参考（anchor700、macro/ratio重组、历史Ridge、直接CIF latest/history、火电有效因子latest/history）的MAE；均值最低者成为该外层目标的伪目标选择模型。

选型结束后，用全部四个源国2022样本重新拟合全部参考。2023H1作为源校准集，按每个方法独立估计加权90%绝对残差半径。目标2024预测写盘并封存后才评分。伪目标验证标签属于已知源国监督，用于选择流程；外层目标标签隔离。选择器不能改变目标信息预算、训练监督总量或小时分辨率。

## 主要比较与报告

比较伪目标选择的MAE、去日均形状MAE和区间分数，与固定`ratio_recomposition`、固定`macro_recomposition`、anchor700及逐国最优事后oracle。逐国oracle仅作上界，不是可部署方法。报告内层所选模型/评分、外层目标逐国分数、覆盖、宽度、最差国家和同一源校准规则。五国是外层单元，不把小时当独立重复。若伪目标选择不超过固定强重组或频繁选择不稳定，停止将“留国验证”单独包装为算法贡献，再推进显式伪目标训练机制。

此实验只回答模型选择这一项训练模拟能否带来迁移收益；不宣称完成伪目标元学习，也不改动已查看国家列表。数据口径、版本限制及归因边界见[多国粗月输入协议](ENERGY_CHARTS_LOCO_PROTOCOL_20261101.md)。
