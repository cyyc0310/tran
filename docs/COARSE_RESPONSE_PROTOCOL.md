源地区月m保留完整日的平均粗电量组成c_m，源训练时可见的t−2组成a_m，原源月均值归一化24小时形状q_d。新增变化向量r_d=c_m/a_m；a_m=0的类别明确使用倍率1先验，记录当前新出现的类别质量，不将零值认证为物理不存在。c_m来自源2022监督响应，目标未来月真值不接受。使用组成比而非绝对发电增长，可避免共同总量倍率在CIF比值中消去的混淆。

response_coupled使用同一供体成员的r_d*q_d；response_shuffled在同一128成员中整体置换六维r向量，精确保留r联合经验分布和q完整轨迹联合经验分布，仅打散二者配对。transition_only只使用r、不用q。所有方法再乘目标合法t−2组成、按小时归一化，分别使用源macroEF或独立目标装机EF。零总量退回可见火电份额，不能将结果称作目标未来月量守恒。
