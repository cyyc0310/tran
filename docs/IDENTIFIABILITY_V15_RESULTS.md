# V15：粗统计识别什么，什么本地信息值得获取

2026-10-25，Sol。完成七源2025H1、六个已查看目标2026H1，15个信息预算、两套固定EF的结构诊断。**粗统计能约束加权聚合量，但远未识别小时风险；最有价值的候选是小时排放燃料占比及其内部煤电结构，仍需要额外燃料支持/EF约束和真实可用性检验。未找到通过源区预设分辨率要求的最小通道组合，未打开新地区。**

这轮从已查看真值构造完美信息的后验oracle，不是预测实验。表中“界宽”是给定约束下最窄的可行值范围，**不是90%预测区间宽度**。真值包含属于构造检查，不是覆盖提高；没有新CRPS/覆盖收益。只有非负能量、燃料总量及小时组总量约束，未加入机组容量、爬坡或电网可行性；“sharp”只相对于这个明确的松弛集合。

## 1. 可识别性：加权水平和小时风险是两件事

令a_hf为非负燃料发电，G_h=Σ_f a_hf，E_h=Σ_f EF_f a_hf，C_h=E_h/G_h。已知同区间燃料总量M_f，必然识别：

`Σ_h G_h C_h / Σ_h G_h = EF·M / Σ_f M_f`。

份额已足以识别这个发电加权强度；另有总发电量才同时识别总排放。它不等于一般的等权小时均值L：`加权CIF = L + Cov(G,C)/mean(G)`。在本次目标日上两种均值的绝对差平均6.894g/kWh，PACE为10.435；这不是此前全部预测误差的归因。

固定每小时G也不能消除燃料分配歧义。例如两个小时G=[1,2]、煤/零排放能源总量=[1,2]、EF=[1000,0]：

| 同样的燃料总量与小时总发电 | 两小时CIF | 等权均值 | 最高CIF | 发电加权均值 |
| --- | --- | ---: | ---: | ---: |
| `[[1,0],[0,2]]` | `[1000,0]` | 500 | 1000 | 333.333 |
| `[[0,1],[1,1]]` | `[0,500]` | 250 | 500 | 333.333 |

G恒定时等权均值也固定，但均匀混合与燃料分离仍有不同峰值/尾部。整小时置换只能证明时间对齐不确定，不能单靠置换证明边际尾部不同；上述燃料-小时循环才保留G同时改变边际分布。严格构造与边界见[科学设计审查](../results/identifiability-v15/design-review.md)。

已发布的历史月量精确约束过去；在不加入迁移、平滑或稳定性假设时，它不能作为未来的守恒等式。当前EF支持下，没有任何未来观测的可行范围仍为[0,1000]。这不是说统计预测无效，而是说更窄的概率预测依赖额外规律，不能由粗总量单独保证。

## 2. 实验：即使完美日/分块统计也留下很宽的小时自由度

所有oracle预算都额外知道真实、同口径的每小时G，再比较不同时间分辨率的真实燃料量。月预算只聚合保留的完整有效日，未冒充官方整月表。日内块为UTC对齐，跨日缺测不插补。V10带符号净发电遥测不等于这里八燃料非负和，未拿它替代精确G。

| 真实燃料统计粒度，另给真实小时G | 源区小时平均界宽 | 目标小时平均界宽 | 目标等权日均界宽 |
| --- | ---: | ---: | ---: |
| 保留小时的月总量 | 726.307 | 984.342 | 937.736 |
| 日总量 | 594.815 | 918.375 | 66.082 |
| 12小时总量 | 576.789 | 887.941 | 46.434 |
| 6小时总量 | 531.488 | 824.228 | 29.665 |
| 3小时总量 | 448.779 | 646.511 | 15.589 |
| 1小时总量 | 0 | 0 | 约0 |

单位均为g/kWh；先在地区内日等权，再等地区平均。日均界单独联合优化，不是小时端点的平均。各小时边际极值一般由不同情景实现，不能把端点拼成一条可行整日轨迹。

目标日均水平的范围从日预算66.082降至3小时预算15.589，小时范围却仍为646.511。PACE更明显：日预算小时宽999.934/日均宽81.635；3小时预算仍为852.547/21.336。LGEE相应为755.414/45.142和436.817/9.538。这支持“约束水平不等于约束尾部”，也说明给粗误差加传播层并未自动补出目标调度信息。

这些宽界允许许多未必符合真实机组运行的分配；不能解释为真实随机波动一定有这么大，或已有预测区间必须扩大到这个尺度。要缩小保证范围，需要新的可靠约束；要缩小概率区间，需要可检验的分布/迁移假设。

## 3. 哪类本地信息价值更大

在共同的真实日燃料总量+真实小时G条件下，增加小时通道：

| 小时新增信息 | 源小时平均界宽 | 目标小时平均界宽 | 目标日均界宽 |
| --- | ---: | ---: | ---: |
| 无 | 594.815 | 918.375 | 66.082 |
| 煤电量 | 390.311 | 278.326 | 20.843 |
| 气电量 | 334.587 | 634.038 | 43.063 |
| 正EF燃料总量，源选单通道 | **120.710** | 325.772 | 26.597 |
| 煤电量+气电量 | 148.310 | 34.167 | 0.745 |
| 正EF燃料总量+煤电量，源选双通道 | **17.452** | **0.003397** | 0.000061 |

正EF组是本代理的煤/气/油/other，不等于已证明可取得的独立商业“火电”字段。源选单通道迁移到目标后，比煤电单通道更弱；LGEE的两种界宽分别587.431与82.540。不能看到目标后把主选择改为煤，也不能说所有地区都需要同一种最小观测。

预设规划分辨率要求每个源区至少95%小时界宽≤100且平均日均界宽≤25。虽然双通道源宏平均宽只有17.452，ISNE的≤100小时比例仅67.5094%，未满足95%。因此封存的`eligible_budgets=[]`、`smallest_tested_resolution_budget=null`保留不变。阈值只是本研究规划容忍度，不是90%概率覆盖要求或普适信息定理。

## 4. 必要对照：近乎精确的双通道结果依赖什么

设t为正EF燃料占G的份额，c为煤份额，o为油份额。本代理有精确代数式：

`C = 400t + 600c + 400o`。

因此只要当日真实油总量为零，所有小时o都被锁为零；再给每小时t/c，就几乎直接知道C。五个目标区的保留期油能量为零，PSCO油占总能量约0.000222%。这只是当前评分代理的记录，不认证现实未来不存在油机或未观测燃料。

去掉**所有当日/月燃料总量**，即使仍完美知道小时G、t/c，未观测油份额可以在[0,t−c]之间变化：

`C ∈ [400t+600c, 800t+200c]`，界宽为`400(t−c)`。

| 两个逐小时通道相同，仅去除日燃料真值 | 源小时平均界宽 | 目标小时平均界宽 | PACE | LGEE |
| --- | ---: | ---: | ---: | ---: |
| 保留真实日燃料量 | 17.452 | 0.003397 | 0 | 0 |
| 无任何当日/月燃料量 | 169.561 | **105.798** | **70.497** | **88.802** |

小时G仍是共同额外oracle；若给的直接是份额t/c，则已包含同口径分母归一化要求。

所以本轮没有证明“两条容易获得的数据就足够预测CIF”。更具体的候选信息是：**小时排放燃料份额、其内部煤份额，以及可信的剩余燃料支持/排放因子约束**。可靠机组清单或容量约束可能排除高排放替代分配，但本轮没有接入这类数据；历史某燃料为零不能自动成为未来硬上界。

压力EF将气/other改为500/600，保持其他定义。双通道+日燃料量的目标宽从0.003397升至6.764，源从17.452升至37.367；原来的气/other同EF使近零结果更特殊。此压力设置是固定代数实验，既不是真实EF估计，也没有覆盖零EF技术生命周期排放、机组效率或进口碳流误差。

可以给出下一轮可核查的误差预算。若合法预测份额误差满足`|t_hat−t|≤eps_t`、`|c_hat−c|≤eps_c`，且有可信的小时油份额上界u，则主EF下：

`|C−(400t_hat+600c_hat)| ≤ 400eps_t+600eps_c+400u`。

t/c各5个百分点误差对应50g/kWh，再加油项；这不是当前模型已达到的精度、概率保证或经验区间。预测分母若不同口径、额外EF不确定或进口口径改变，必须另外计入，不能继续套用此式。

信息预算还应包含可推导的信息：若取得历史t/c并额外知道o=0，在当前EF合同内就能反算历史CIF；即使没有名为“CIF”的原始字段，也不能继续称完全没有目标小时CIF信息。后续同预算直接CIF基线必须获准使用这些反算值；油/EF未知时则保留相应范围。不能通过更换字段名称获得不公平的零观测主张。

## 5. 论文路线和下一步

**比继续堆天气门控/耦合模块更有依据的路线，是信息预算驱动的可迁移CIF预测：明确识别对象、学习未识别部分、检验最小附加信息。**但普通聚合恒等式、运输LP、分数背包、EF线性重写本身都不是足够的新算法。

已有[NeurIPS2020聚合观测学习](https://papers.nips.cc/paper_files/paper/2020/hash/5b0fa0e4c041548bb6289e15d865a696-Abstract.html)研究由群体监督恢复个体规律，并讨论等价关系下的一致性；不能把“粗到细”当首次。新核查的[DGCFM，WWW2026](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf)直接研究跨区/低数据CIF，必须作为核心相关工作。其zero-data明确排除目标训练，而方法写有历史CIF推理输入；zero-data推理具体如何提供目标上下文，正文尚未澄清，不能直接等同或排除本项目的无目标小时观测合同。当前没有复现或击败该文。

用附加约束缩紧部分识别范围也已有研究，例如[ICML2025的协变量约束最优运输](https://proceedings.mlr.press/v267/lin25f.html)。其研究对象是因果效应，定理不能直接移植为CIF保证；同样不能把本轮普通运输界重新命名成新理论。

[Scientific Data2026中国2025–2060小时因子](https://www.nature.com/articles/s41597-026-07272-6)是规划与运行模型的情景投影；年度官方对照及模拟内部守恒不认证真实小时精度。不能拿这些输出充当中国小时实测验证标签。原文、其他理论依据和核查边界见[设计记录](../results/identifiability-v15/design-review.md)。

下一轮应优先检验以下三项，而不是宣称已经完成：

1. **现实字段核查与可用性。**找到带历史发布时刻的区域总发电/排放燃料/煤电计划或预报，以及能约束油/other的机组支持信息；中国场景也需核对省区边界、火电口径、进口和自备电。字段现实不可得时，不用当日真值替代。若只有历史数据，只能声明滞后信息预算。
2. **同预算的误差传播实验。**先预测排放活跃组成份额t/c及剩余EF组，而非默认完整八燃料形状都同等重要；把预报误差、EF误差和未识别调度风险分开。比较简单持久性/季节份额、线性结构模型和强条件分布模型，检验是否真的比直接预测CIF、原强重组更有效。此表示本身仍是标准代数，须用明确增量支持方法贡献。
3. **信息价值与拒绝规则。**在源区冻结“何时哪条本地观测最有价值”的选择，按合法信息预算画误差/覆盖/宽度前沿；信息不足时明确保留未识别范围或降低可支持的时间分辨率。若采用稀疏本地CIF历史，单列零标签/少标签预算，时间前推比较普通局部偏差和尺度校准，不能把收益算回零观测方法。

对中国公开信息做了初步字段核查：[国家统计局2026年9月能源生产发布](https://www.stats.gov.cn/sj/zxfbhjd/202610/t20261019_1965613.html)给出月度、规上工业范围的火/水/核/风/光发电统计；[国家能源局2026年上半年发布](https://www.nea.gov.cn/20260730/bb571bc20d7445e5ae7d9dc51c3f700d/c.html)给出装机及累计发电等指标。这两个已核页面不能提供本实验所需的省级逐小时煤/排放燃料预报，也不证明全国没有其他渠道。装机可作为后续约束候选，却不能当成小时出力或实际可用容量；规上范围也不能直接等同区域全口径G。

潜在论文贡献应是有可证边界且能复验的信息预算框架，以及在合法约束下确有收益的预测/信息选择机制。本轮提供识别性证据与候选字段，尚不足以支撑成熟原创算法。信息不足可以解释为什么粗统计本身不保证小时风险，但没有从本轮确定PACE/LGEE实际失效的唯一因果来源。新地区仍需等合法预测增量出现后再冻结确认。
