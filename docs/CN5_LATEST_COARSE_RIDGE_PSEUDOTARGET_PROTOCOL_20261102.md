# 严格五类预算下的粗Ridge伪目标复核协议

冻结日期：2026-11-02。此实验检验AEMO跨域回测中的`coarse_ridge`点误差信号，能否在已有Energy-Charts严格五类九国整国留出中重复。九国目标此前均进入开发分析；本实验不是未看地区确认。

## 预测任务与目标输入

- 外层目标：严格CN5队列AT、BE、CZ、ES、HU、NL、SE、SI、SK，逐国留一；其他八国为源。
- 训练：2022源小时；风险校准：2023H1其他八国伪目标；测试：目标国2024全年，先封存所有预测再打开目标小时标签。
- 目标公开特征严格使用已存在`LATEST`合同：预测日历、最近已可见的`t−2`火电/水电/核电/风电/太阳能月电量份额及其与小时相位交互。输入不得含目标小时燃料、CIF、标签内第六组`other_renewable`。
- 标签：既有严格CN5 Energy-Charts固定因子发电代理，其他可再生保留在标签分母。统计发布版本是当前修订小时序列回算，不是历史as-issued回测。

## 方法与公平比较

新增候选`ridge_latest`：对完全相同的`LATEST`列作加权标准化Ridge，`alpha=10`，地区/国家等权。它只用日历、滞后两个月的五类份额及小时相位交互；其他现有方法可使用更丰富的`HISTORY`信息，因此比较对Ridge较保守。所有系数和分层阈值在任何外层目标标签评分前冻结；不根据AEMO或本次折结果调参。

在每个相同外层折中同时评分：`anchor700`、强比例重组、宏重组、直接粗组成HGB、火电因子HGB和新增Ridge。所有方法使用相同训练小时、目标小时、源校准小时和目标信息预算；90%对称经验区间半径均取2023H1源伪目标国家/地区等权绝对残差q90，不加目标残差偏差修正。预测指标为MAE、日内形状MAE、90%覆盖、区间宽度与Winkler分数。

## 分层与晋级判断

除九国等权宏平均和逐国结果外，按目标输入中的`thermal`滞后份额≥0.5标记热电主导小时，否则为低热电小时。该阈值只依赖预测时可见输入，不按标签或误差选择。分别报告两层的误差、覆盖和区间分数；另报告各国整体覆盖，避免低强度国家抬高宏覆盖。

候选只在以下条件同时满足时进入后续冻结考虑：相对比例重组与anchor700的宏MAE有至少5%改善；至少6/9国MAE改善；高热电层覆盖不下降超过2个百分点且区间分数改善；不存在单国MAE恶化超过10%或覆盖下降超过5个百分点。未满足时记录为开发负结果，不打开未查看目标域、不调参追逐本队列。

## 复核材料

新runner复用既有九国数据装载及基线模型，只新增同`LATEST`输入的加权Ridge。写出独立启动哈希、逐国预测、源半径、目标输入分层信息和逐国/月/层指标。任何标签分层仅在预测封存后计算；热电层归属由封存的`input_thermal`值确定。
