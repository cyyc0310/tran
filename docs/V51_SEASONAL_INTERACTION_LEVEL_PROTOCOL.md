# V51：月度组成×季节交互是否改善源外日水平误差

2026-10-27，预注册后计算。TVA的冻结对照显示EF-only中心修正的aggregate表现好于简单锚定，但春季覆盖仍下降；先前源LOO只比较组成线性项与日历季节加性项，没有检验组成斜率的季节变化。本轮只检验这一明确的线性异质性假设，不能根据TVA结果拟合或评分。

## 数据与特征

- 严格复用V50的七outer×十external源、90日合法小时标签、原点路径以及外部月表hash；不读取任何目标角色、TVA/其它新区域或未知地区文件。
- 对每个源区日，使用预测起点可得的最近三条完整且已发布月份，计算项目固定EF向量`[1000,400,800,0,0,0,0,400]`加权的月度组成proxy `x_t`；使用同一日历年周期365.25的`sin(2π day/365.25), cos(...)`。
- 源响应是该日`truth−Scale-anchor raw path`的24小时等权平均；它是daily level error，不是小时形状风险标签。
- 各训练源总权重相同，区内eligible日等权。每outer×held-source均严格留整个held source，不将同源日期当独立区域。

## 匹配模型

1. `mix`: 截距＋`x`。
2. `mix+season`: 截距＋`x`＋sin＋cos；即V50已测试加性季节参考。
3. `mix×season`: 截距＋`x`＋sin＋cos＋`x·sin`＋`x·cos`；本轮唯一新增机制。

均为未调参加权OLS。不得挑季节频率、做支持门控、加非线性或按留出分数选择模型。对每个预测offset应用相同逐粒子level shift和`[0,1000]` clipping；沿用原factor-2逐日小时区间，故方法间信息与interval spread一致。

## 主结果与停止标准

主要比较`mix×season`对`mix+season`的源级等权日level MAE和hourly CRPS。同步报告每源、宏覆盖、宽度、区间评分、上下尾漏报和clip率；source是独立单位。交互只有在没有依赖单一区域、日level MAE与hourly CRPS均至少改善5%，且宏90–95%覆盖、worst source≥85%、IS改善、宽度不增时，才有资格进入下一轮同预算强概率基线；否则留作负诊断。旧十源为反复开发数据，因此即便全部通过也不能声称独立确认或原创性。

结果差异只表示此proxy、线性交互与七outer旧源预测条件下的源外关联，不识别燃料结构对调度的因果作用，也不证明中国月报的真实碳因子或发布vintage。
