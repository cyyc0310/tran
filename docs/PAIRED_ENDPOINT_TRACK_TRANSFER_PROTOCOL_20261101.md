# US↔GB双标签轨端到端小时迁移配对复验协议

冻结日期：2026-11-01，运行前。目标是按同一跨国小时队列分别评价发电侧强度与消费侧强度，不把二者合并成单一CIF响应。

## 设计

- 方向：US→GB与GB→US；目标年份2024，美国侧含七个BA。
- 标签轨：`generation_proxy`按EIA/NESO小时燃料发电量与固定燃料EF构造；`consumption_official`使用EIA/NESO发布的官方估算消费侧强度。两轨独立训练、校准和评分。
- 输入臂：`hourly_reconstruction`使用小时序列回算五类滞后月组成；`eia923_monthly`将美国BA的同类特征替换成EIA-923月报。月量按`t−2`滞后模拟，使用当前最终档案，不是历史as-issued版本。
- 拆分：2022源小时拟合，2023源小时残差校准，2024目标小时评分。每个标签轨、输入臂、迁移方向的模型都只用源国响应标签训练。预测文件先写盘并封存，再读取2024目标响应。
- 基线：源均值、日历Ridge、五类组成Ridge/HGB、固定EF小时重组、年度容量Ridge/HGB。后两种容量模型加入2020美国煤/气装机，作为单列M+C额外信息预算。该容量字段不是中国省级五类月报本身已验证可得的信息。
- 指标：按目标月计算MAE、日内形状MAE、Gaussian CRPS、90%覆盖、宽度及区间分数，再按月等权、按目标区等权宏平均。发电/消费、正反方向分表。

## 边界

目标2024响应此前已在研究过程中查看，因此该复验是可审计的开发回放，不是盲测确认。固定EF发电标签是代理响应，不等同于官方消费侧CIF；EIA与NESO消费标签定义也不完全相同。小时输入的统计支持与标签区域并非完全同域，因此结果用于跨国方法压力测试，不能直接当作中国省级精度保证。

该实验沿用既有强重组/直接模型基线，不把源伪目标残差实验的US→GB单向结果伪装成双向同队列方法。若残差基线需要纳入下一阶段，应在双向可识别的多源数据和预先固定的程序中重新开发。
