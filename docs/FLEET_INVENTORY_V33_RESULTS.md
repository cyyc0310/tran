# V33：七源装机库存整理结果

2026-10-26，Sol。七源2020—2023年库存整理和独立数值核验已完成，形成49519条非储能年度机组记录、1468条储能排除记录及两套各28行的年度容量表。本阶段只形成B1库存代理数据，没有读取CIF或训练模型，尚无预测、风险覆盖或方法改进结果。

## 范围与口径

按[固定合同](FLEET_INVENTORY_V33_PROTOCOL.md)，读取已获取的四个EIA-860年度档案，只在Plant登记BA为BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS时转换非储能nameplate容量。B0仍为原公开月报，B1另加库存信息；两种预算不能混作同一方法的进步。

主表仅Status=OP；敏感性表覆盖Operable中的OP／SB／OA／OS。每条机组按主能源一次分配到coal／gas／oil／nuclear／hydro／wind／solar／other，次能源及多燃料flag只保留审计，不另算容量。MWH及六种储能PM先排除，PS抽蓄和CP太阳能储热也在其中。RE、CC规划单元、未知主码、选中容量缺失或非法均会使attempt失败，没有补零或skipna。

49519是四年的记录总数，不是跨年去重后的物理机组数。年度内PlantCode＋GeneratorID唯一；同一机组可以在多个年度出现。unit表共用于两个政策口径，储能excluded只含metadata，没有已转换容量。

容量使用绝对1e−10加相对2e−12公差，期望零精确比较；计数、字符串、布尔及JSON类型严格核对。收尾阶段再次核573个当前文件哈希和封存表行数。完整哈希、原日志及独立重建范围见[数值审计摘要](../results/fleet-inventory-v33-numerical-audit.md)。本段PASS只描述数据整理一致性。

## 数据能支持什么

本轮确认冻结规则能从已登记BA库存中整理出可审查的结构代理。它没有验证登记边界覆盖完整发电辖区，也没有消除空BA、容量评级、停运／备用、多燃料能力与实际发电口径之间的差异。某组observed容量为0只指当前筛选集合，不能推断该地区实际不存在该燃料。

四年原ZIP是检索时版本，尚未认证为首发历史字节；官方旧码表已核对，仍不能代替历史vintage认证。后续origin按UTC年份减2取唯一库存年，并核发布日期≤origin；缺年不取最近年度补齐。不得以2025前已公开替代更早训练起点可得。

nameplate不是认证出力上限，本数据不用于硬截小时CIF。主能源归类也不能识别过去或未来的实际燃料用量；WH、BFG、OG及H2等研究聚合与B0同名组未必完全同口径。仅煤气分母对应包含油／other的POS量时，只能称部分容量归一化代理，不能自动clip大于1。

下一模型阶段仍需另立合同，在同B1预算与同队列下比较简单装机比例锚、普通模型及已有强参考。先分清附加信息增益，再判断专门风险机制的增量。本轮没有模型训练、CIF质量或概率覆盖结果，原始小时、旧目标和真正未知地区标签继续关闭，长期目标active。
