# 本地小时标签滚动校准预算：冻结分析合同

状态：回顾性预算诊断，目标标签此前已用于伪目标方法开发，因此不是预注册或盲测确认。

## 问题

在严格滞后五类月报、外国小时训练的固定因子重组预测上，最少需要多少目标区本地小时参考，才能让小时区间风险更可信？分别对固定EF发电代理和官方消费强度执行，结果不合并。

## 固定输入与队列

- 只使用已封存的 `local-monthly-adaptation-pseudotarget-r1` 七个US BA 伪目标预测；目标中心固定为 `local_ridge` 组成适配器下的 `fixed_ef_recomposition` 原始点预测。
- 本地参考标签按BA、轨道与UTC时间戳一一对齐：发电轨为固定EF生成代理，消费轨为官方BA消费强度。
- 源区基线偏差和小时级90%残差半径固定使用原伪目标实验封存的2023源校准，不重新估计。
- 预算为滚动最近18、24、28个连续完整UTC日，可跨月份。每个窗口前半段估计位置偏差，后半段按每日最大绝对小时残差估计90%风险半径；预算期后逐日预测下一完整UTC日，窗口前移一天。目标日标签不进入当日预测。跨月滚动用于模拟在线更新；它依赖误差过程局部稳定的假设，月季漂移要按BA和时段单独检查。
- 每个校准风险窗口至少9个日分数。90% split-conformal有限秩为`ceil(0.9*(m+1))`；若秩超过m，则不输出有限区间。18日预算为9日位置+9日风险分数，是本设计中最小有限预算。

## 指标与边界

分别报告日同时覆盖（当日全部小时落入区间）、小时边际覆盖、平均宽度、按日Winkler分数、有效校准/评分日数和BA逐项结果。对照包括零本地小时的源校准区间、本地位置修正加原源半径、本地位置修正加本地小时边际分位数，以及本地日同时风险半径。小时分位数是小时边际而非整日同时覆盖；逐小时依赖会使普通split-conformal的交换性保证不自动成立。

本地有限样本秩只在校准分数与未来日可交换的假设下有边际保证；逐日滚动窗口相互重叠，且月内风险可能漂移。18日不是对新国家的保证，也不等同于中国可得输入。该附加预算只测量本地小时参考的价值上限/成本，不改变零样本M主任务结论。

## 运行

`PYTHONPATH=src:scripts python scripts/run_local_hourly_label_budget.py --output results/local-hourly-label-budget-r3`

实现探索中曾运行同月内滚动的r1，因18–28日预算每月只剩少量末尾日期可评估，不作为主分析；r2为跨月滚动但只测整日最大残差。主分析r3在相同时间拆分下增加小时边际分位数臂。各版本都使用已打开的标签，均非独立确认。
