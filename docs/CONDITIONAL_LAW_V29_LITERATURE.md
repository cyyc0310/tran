# V29原始文献补充：弱监督与部分识别不是无条件小时保证

2026-10-26，Sol。针对性检索，不是系统综述或复现。QRF／多元DRF定位沿本轮设计稿；下列文献用于约束后续创新主张，不改变已锁V29方法、倍率或信息预算。

[Busa-Fekete等，Nearly Optimal Sample Complexity for Learning with Label Proportions，ICML2025，作者机构页](https://research.google/pubs/nearly-optimal-sample-complexity-for-learning-with-label-proportions/)及[原始预印本2505.05355](https://arxiv.org/abs/2505.05355)：本轮核机构原始摘要和作者原始版本页，未读全部证明／复现。其任务是在仅观察bag聚合标签的训练条件下学习个体预测，用平方损失讨论样本复杂度及ERM/SGD方差控制。因此“只用粗标签做细预测”并不新，更多粗标签也不能自行当新算法。对本任务的直接适用性仍未证明：粗电源能量统计不是小时CIF标签的普通等权平均，未来月量尚需预测，且本地小时协变量与隐藏燃料拆分的可用性不同。不能援引其样本复杂度结论来保证我们的跨区小时覆盖。

[Liu、de Paula与Tamer，Prediction Sets and Conformal Inference with Interval Outcomes，2501.10117v4](https://arxiv.org/html/2501.10117v4)：本轮核摘要、§1和§2设置／有效性定义，以及§1对§4校准的概述，未核完整证明、数值或代码复现；属于原始预印本，本轮未确认期刊录用。其观察每个样本的上下界，真实Y保证包含于该区间；处理部分识别、预测不确定性与有限样本校准，并以符合识别集合的最坏分布定义有效性。这是“识别不确定性单独保留”的近邻，不能把该分解本身当原创。我们的本地月统计没有直接给每个未来小时有效上下界，月袋约束还相互耦合；源区／跨时间亦未自动满足交换性，所以不能直接套定理。

## 对当前路线的约束

V29是必要的普通概率控制，不是上面论文的新应用即创新。若强控制仍失败，有价值的候选问题是：区域迁移误差与同区月份散布是否被混为同一种噪声？源粗统计能约束哪类组成失配，而哪些小时调度／相位风险只靠源假设保留？这些是待实验与理论支持的研究问题，不是本轮已经找到的机制。

后续若设计部分识别／支持约束，应先证明约束确由合法观测或明确源假设得到，分开报告数据识别范围和迁移先验范围，再与普通联合分布、组层随机效应、简单锚及常规校准比较；不能输出任意宽集合就称可信。V29本身仍不执行额外校准或打开未知地区。
