# V196 冻结协议：供体留一残差的小时位置分层区间校准

状态：**目标小时评分前冻结**。此为同一中国模型投影世界里的算法压力测试，不是真实小时数据确认。

## 问题

V194–V195 中小 k 的点预测较准但经验粒子区间严重欠覆盖；大 k 区间更宽，覆盖仍低于90%。测试一个不增加目标侧信息的区间估计：仅用每 query 的30条来源省小时形状做 leave-one-donor-out（LOO），以来源伪目标残差估计小时位置风险，再对目标省固定中心预测给出 pooled 或 hour-of-day 分层区间。若覆盖改善伴随明显宽度/Winkler恶化，则不算成功。

## 固定信息和方法

- 完全沿用 V194/V195 2025–2050完整年份、31个省级目标、oracle目标月均锚、同情景省份留一与跨情景省份+情景留出、固定30条供体预算、相同抽样seed。
- 中心预测固定为目标月均锚加最近 `k=10` 或 `k=15` 供体中心化形状的均值。k=10/15 是在 V195 探索比较后，本轮事前固定的两个点—区间折中对照；不以本轮小时评分选择。
- 对每个供体 i，按供体月均与 μ_i 的绝对距离，在其余29供体中选最近k个形状均值预测 i；绝对形状误差构成来源 LOO 残差。
- **pooled**：对本 query 所有供体×月内小时的绝对 LOO 残差取 `higher` 经验90%分位，目标预测使用中心 ± q。
- **hour-of-day**：对每个本地时钟小时0–23，汇集本 query 全部供体/日期该小时位置的绝对 LOO 残差，取 `higher` 90%分位；目标每小时使用对应中心 ± q(hour)。
- 作为对照，直接调用 V195 同查询固定 k=10、15经验形状粒子区间，以及 k=20/30的供体分布；按原 V195输出独立复算，不调参。

## 评分与停止判断

完整query报告90%经验覆盖、平均区间宽度、Winkler90、中心MAE和CRPS（分布对照）。汇总宏平均并按情景/年份/省报告。比较相同同/跨情景供体预算。任何区间都只是经验区间，不声称有限样本保证；LOO残差之间相关、区域不交换等可能破坏理论覆盖。

如果两种LOO校准均未提高覆盖、或只能用比固定 k=20/30 明显更宽区间换覆盖、或跨情景表现崩溃，则停止针对同一信息预算叠加边际校准器；转向寻找可用目标侧小时风险信息或承认部分识别/弃答边界。

## 封存与隔离

逐查询保存数据角色、抽样供体、LOO残差hash、q值hash、中心预测hash和区间端点hash。全量预测/区间摘要封存后才评分；评分重算hash必须相同。目标月内标签置换沿用同一封存精确oracle月均锚，逐值确认预测/区间不变。源文件、V194原协议/缺失性修订、V195/V196协议、脚本和所有输入工作簿SHA256写入seal。
