# 粗月报训练消融：第二轮开发协议

2026-10-31，运行前冻结。首轮目标国结果已查看，本轮是开发消融，不能称新国家确认。继续使用固定EF发电侧代理及原始数据/日历口径。

源2022训练、源2023校准、目标2024评分。训练小时取t−2/t−3/t−4粗输入全部有效的交集。对照复制t−2视图三次；增强组使用三个不同滞后视图。两组响应小时、样本数量、区域权重、随机种子和优化步数相同。推理均仅给t−2输入和统计年龄。不使用目标小时标签、目标细燃料或未公布月份。此实验只检验时效条件增强，未实现分类随机变化、按域元学习或所有预算变化。

拟合前数据预检修订：BPAT的2022三滞后共同支持为0，首个启动在训练前失败。后续所有组统一排除无共同训练小时的源区（本次为BPAT），但其目标区资格不变；美国源剩六区。修订仅依据输入可用性，未产生或查看本轮预测分数。

六个神经配置：固定/增强输入 × direct/mixture/fuel_aux。共享32→32 Tanh骨干；direct直接sigmoid输出CIF/1000；mixture输出八燃料softmax占比，经固定EF重组，仅监督CIF；fuel_aux再加八燃料真实小时占比的均方辅助损失，系数1。两个混合头参数数相同，direct少231参数，须披露，不能称参数严格完全一致。对比mixture和fuel_aux能隔离额外细燃料监督效果。

Adam学习率.001，固定600步、batch1024；seed412/413/414全部报告，不按目标选种子。区域均衡重采样和标准化。训练不含天气、目标月适配或目标校准。三种头都是常见方法参考，不预称新算法。

同交集重训首轮六个固定基线；神经组使用相同源监督小时，控制组三次重复不增加独立标签。全部模型源2023残差用于固定Gaussian均值/方差校准。全部方向和种子的目标预测写盘封存后，再读目标响应评分。

共同月份为首轮输入可用性决定的2024-02/04/06，所有国家和地区均有评分支持。主表按三个当地/来源月份分别评分后等月平均，再等地区汇总；同时保留全部可用月份。共同月份不是相同小时集合，也不能代表全年；不按误差筛选月份。保留raw_mae以区分原模型和源偏差校准贡献。国表hours为实际地区小时数之和，另报地区数。

主要比较增强对固定输入、fuel_aux对mixture、各候选对同预算重组。报告MAE、形状MAE、Gaussian CRPS、90%覆盖/宽度/区间分数、逐区结果，种子为计算稳定性重复，不是新增国家。无目标选型、无倍率调优。只有源内可复现增量才考虑进入后续按域任务训练或月量适配；本轮负结果同样保留。
