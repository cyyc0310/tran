# V53 本地滞后组内 thermal EF 锚开发协议

日期：2026-10-27。只用此前已评估的11个EIA区域，测试月度细类别能否提供小时模型缺失的目标区 thermal 组内水平。封存的新区域不读CIF结果。

## 固定预测结构

保持V52严格月度-only点模型的五类（thermal、nuclear、hydro、wind、solar）上一年同月总量、来源小时形状、月份、小时预测行完全不变。只替换thermal组有效排放因子的估计来源。标签仍为固定EF、正部已报告发电代理。

目标月五类总量继续使用合法as-of的上一年同月月报。每种热组EF输入单独作为同一预测时点前可得的信息预算；细燃料分项通过EIA月表八类正发电量和固定EF构造。这个EIA细类别实验只测信息价值，不能自动视作中国官方统计口径已核实。

## 热组EF比较

1. `donor_same_month`：除目标区外的源域上一年同月热组组内EF等源平均。
2. `local_same_month_lag`：目标区上一年同月细燃料量算出的热组EF，要求period_end和available_at均不晚于目标月。
3. `local_latest_asof_month`：目标区在预测月起点前最后一条已发布月度细燃料统计算出的EF。
4. `local_latest_complete_year_asof`：目标区截至起点最新完整、且12个月均已发布的自然年细燃料量加权热组EF；不完整年不当年因子使用。
5. 预先声明的跨源域凸组合补充：在每个外层目标留出后，只用其余区域2024校准预测，在 `alpha ∈ {0, .25, .5, .75, 1}` 上最小化区域等权点MAE，分别组合 donor EF 与 `local_latest_asof_month`、`local_latest_complete_year_asof`。冻结选出的alpha后，用同一批校准区残差建立区间，并只在外层区域2025标签评分。该操作不读取外层目标2025标签。

## 留区/时间前推与指标

每个外层区域留出，其他10个区域训练/校准；2024预测误差校准2025同月。校准区预测嵌套排除外层目标与其自身；外层目标小时仅在预测封存后评分。H1/H2分开。

固定比较每种EF头下的source-equal pooled q90与来源最大region q90。报告来源等权/最差源覆盖、区间宽、Winkler score、点MAE、偏差、校准组数和有效小时。区间分位经验结果不表述成严格有限样本地区覆盖保证。

## 晋级门槛

局部EF增量若要成为可用候选，至少需在两个半年都降低点MAE；区间版本还须在宏覆盖90–95%、最差源≥85%时改善Winkler分数，且没有靠显著扩宽获得。否则只保留信息价值结论，不测试未评分地区。即使达到开发门槛，也需先核实真实中国表格的类别列、统计范围、EF边界与发布时间，再冻结协议做独立确认。
