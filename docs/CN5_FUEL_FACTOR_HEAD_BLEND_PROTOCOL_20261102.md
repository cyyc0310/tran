# CN5燃料组成头与火电因子头的源端嵌套混合实验

冻结日期：2026-11-02，运行前。实验检验一个尚未直接测试的简单机制：源伪目标能否学会在`fuelshare_history`和`factor_history`之间选择凸混合权重，并在独立源伪目标时间块校准区间。

## 任务合同

- 数据：严格CN5九国Energy-Charts固定因子发电侧代理。各国2022小时标签用于模型拟合；2023H1仅用于权重选择；2023H2仅用于风险半径；2024整国留出仅用于评分。全部国家此前已属于开发集，本实验不称盲确认。
- 目标预算：滞后`t−2…t−7`火、水、核、风、光月份额和日历。细燃料只作为源监督/评分标签，不进入目标预测特征。月统计由当前修订小时数据回算，属于滞后模拟，不是as-issued回放。
- 每个外层目标国家`A`，每个伪目标国家`B`的两类候选头均用排除`A`和`B`后的七国训练；用2023H1所有`B`的等国MAE选择混合权重`alpha∈{0,.25,.5,.75,1}`，预测定义为`(1-alpha)*factor_history + alpha*fuelshare_history`。平分时选较小alpha，即优先回退到因子头。
- 对同一外层目标`A`，2023H2半径由排除`A`及各校准伪目标国`C`的双留国模型预测得到，按国等权绝对残差90分位校准；不使用A的标签。候选区间只用此源伪目标半径，不做目标区再校准。
- 最终`A`预测由排除A的八国2022模型拟合。先封存2024逐小时预测、权重、半径及哈希，之后评分。

## 比较与晋级门槛

与比例重组、`factor_history`、`fuelshare_history`在共同国家—月份支持上配对，报告MAE、日内形状MAE、90%覆盖、宽度、Winkler、逐国及逐月结果。

候选只有同时满足以下条件才保留为算法增量：对三种基线中最好的MAE至少改善5%；最差国MAE不比最强基线差5%以上；宏覆盖至少85%、无国低于60%；相对最佳基线Winkler至少改善5%，且不靠加宽区间达成。否则关闭混合权重路线，不在2024目标上改网格。

## 局限

该凸混合是标准模型组合，若有收益也只能证明“源端嵌套选择可提高本数据合同表现”，不能单独主张新组合算法。标签是固定因子代理；九国目标已被看过；发布版输入和中国小时独立标签仍缺失。
