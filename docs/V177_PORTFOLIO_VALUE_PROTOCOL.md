## 构造与控制

所有g为非负八燃料向量，T为当前完整月小时数，B(s)=.99s+.01π。

- sync：u=(g_a(t)+g_b(t))/(sum(M⁻)/T)/B(S⁻)。
- perm1/2：固定父a，仅在相同UTC小时×周末标记内，对共同采样集的父b日期作行置换，所有燃料联合移动；seed由`v177/perm/{父对}/{月}/{48state}/{1或2}`的SHA256前16位确定，不依赖fold或CIF。两种seed全量报告。它们保持每父每日历单元的燃料多重集合，破坏跨父同步。可把其余未抽小时视为不动，故不需读取它们来证明整月燃料和不变。
- pair_mixture：在同一组合metadata/上下文权重下，混合两个父的u_j=g_j/(sum(M⁻_j)/T)/B(S⁻)，父质量β_j=sum(M⁻_j)/sum(M⁻)。它与sync/perm在每个24状态的经验燃料一阶矩相同；是普通缩放父混合控制，不是每条路径都满足组合M的声明。
- selected_parent：同一父对/月/交集roster上保留两个父的原u_j=g_j/(sum(M⁻_j)/T)/B(S⁻_j)，每父先验1/2，分别用其自己的输入组成/当前粗锚做相同核更新。不求和，用于排除只是选择或重权原样本的收益。
- expanded_original：全部原采样源月，排除只是扩充月份库的收益。其取值仍来自原父源样本，未派生新信息。

query以B(S_query)映射u，所有原子CIF=EF·fuel/sum(fuel)，禁止直接平均两个CIF。输出混合后的sync/perm/parent-mixture逐状态燃料预测均值必须一致至相对2e−12（按该状态平均总量归一化），G>0且CIF在物理EF范围。

比例缩放作为精确代数负控制：每个原proper源月把g和M⁻同时乘2/4，活动u及其CIF不变。新世界权重本轮不使用总月量核，粗query模型也固定，因此此负控制不应产生另一个不同的预测臂。它检查表示的缩放不变性，**不是**检验从M总量识别实际机组数或聚合度。本轮只问源组合模板有没有独立风险价值。

同一原样本可以反复进入不同父对，不称新增独立信息。parent-mixture的两父原子数为2n，sync/perm为n；将后两者每原子重复两次可使表示数相等且law精确不变。无新学习器容量差异，不把不同压缩支持数误称额外监督。

## 审计和决策

正式评分前做同矩、联合置换、比例缩放、CIF比率/非线性及重复原子不变的toy；六折首尾合法query只构造law、不读held小时标签。保存每个源world的原索引/置换hash、metadata、clock计数和同矩证据；逐query保存所选world/上下文权重、混合燃料均值及误差。全部父源样本/世界库与law、半径、评分和汇总须全量重建，做12个未发布统计扰动，固定参考964评分复现。共享辅助函数的重建范围须明确，不能称第二套独立预测算法。

若sync不稳定优于两种perm及同矩parent-mixture，不发展复杂共同风险机制。若仅胜原参考而不胜selected-parent/expanded或强参考，收益归给普通库/样本组合；不包装创新。即使普通聚合有效，也已有[聚合增强](https://www.nature.com/articles/s41598-021-93545-6)先例；[PRX Energy2026](https://journals.aps.org/prxenergy/abstract/10.1103/vms3-ng8z)说明共同相关可保留或放大风电间歇性，不能预设聚合按1/√N缩窄，更不能将该风场结果当CIF定理。
