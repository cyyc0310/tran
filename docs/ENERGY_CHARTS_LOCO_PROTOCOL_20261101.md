# 多国粗月报冷启动：Energy-Charts整国留出协议

2026-11-01，运行前冻结。目标是扩大训练期伪目标域数量，补充“只用中国式滞后粗月量，国外小时标签能否跨国迁移”的开发证据。本轮仍是已查看来源数据上的开发评价，不作最终国家确认。

## 数据与候选国

使用Energy-Charts API v2 `public_power` 2022–2024原始响应，单位MW、当地时区；原始响应、服务端可用窗口、分辨率、许可、下载头和SHA保存在`data/energy-charts-v2-panel-r1/`。API许可为CC BY 4.0，需署名`energy-charts.info`。目前面板含FR、NL、ES、IT、BE、AT、PL、SE。只按响应完整性和类别字段审计预筛，不看CIF分数：首轮保留NL、ES、BE、AT、SE；FR、IT、PL因关键生产类别字段跨年缺失或未解析而暂缓。爱尔兰等未下载国家保留作后续冻结后确认候选。

候选源的原始更新时间不是历史as-issued版本。全部t−2月统计均由当前修订小时序列聚合，模拟月报时滞；报告只能称“滞后粗月输入模拟”，不得称真实历史发布回放。

## 小时类别合同

API返回的生产类型按候选国家的固定白名单映射至`coal, gas, oil, other, nuclear, hydro, wind, solar, other_renewable`。褐煤与硬煤归入coal；煤气化副产气进入other；`biomass/waste/others`进入other（EF=400）；geothermal和明确标注的other-renewables进入other_renewable（EF=0）；常规水电、风、光、核EF=0。火电因子沿用1000/400/800/400，单位g/kWh。抽水蓄能发电和抽水负荷、电池、跨境交易、负荷及API派生比例不进入本地发电CIF分母。

每国映射在代码常量中逐项列出。API未返回的技术按本轮映射明确记为零，同时在解释中保留“源接口未列此类别”的假设。对已列类别的空值不填零；只有所需生产类别完整的小时进入hourly标签和粗月量。15分钟序列先按UTC小时分组，以四个有效间隔的平均MW形成小时值；小时序列直接保留。之后再转为当地无时区日历键，保留DST重复小时。每月只在有效标签小时不少于当地实际小时数99%时提供粗月量。

该共同标签是跨源固定因子发电代理，不是机构CIF、实测排放或统一统计范围真值。API的public net generation与EIA/SMARD的总量、净额、工业自备电及分类边界有差异，故本轮仅单独评估Energy-Charts候选整国留出，避免把源口径差异混入美英旧排行榜。

## 外层评价与基线

对五个候选国逐个整国留出。目标国2024年小时响应不参与拟合、选型、校准或阈值设置；其模型输入仅为当地日历与`t−2`及更早五技术月发电份额。剩余四国按国家均衡权重，2022年训练，2023年1–6月源校准。目标评价覆盖2024可用月份；无共同滞后月或完整类别小时不填补、不前向替代。

固定比较`multicountry`既有八个参考：anchor700、macro/ratio重组、历史Ridge、直接CIF latest/history、火电有效因子 latest/history。所有模型获得相同源小时和输入预算；差别只来自已登记模型结构。每方法使用源2023H1绝对误差国家等权90%加权分位数生成对称区间。目标预测文件全部写盘哈希封存后再评分。

报告国家/区域/月份样本量、MAE、去日均形状MAE、90%覆盖、区间宽度、区间分数及逐国最差值。国家是外层独立单元；小时数不作独立重复。首轮不按目标结果调超参，也不声称已验证伪目标元学习增量；此运行先建立更多国家上的同预算迁移参照。

## 预先结论门槛

结果只用于决定是否值得加做伪目标任务训练。任何候选若仅胜过较弱直接头、只在个别国家获益、或靠加宽区间提升覆盖，都不算迁移增量。跨国伪目标训练的后续候选必须通过源国内层留国训练、外层留国评分；最终保留国家直到方法冻结后才可打开。
