# V51 跨区小时轮廓的时区对齐诊断

## 假设与对照

先前严格月度预算的 donor 轮廓以UTC小时聚合七个美国区域。若日内用电/调度形状跟随本地钟点，直接按UTC小时平均会把跨时区峰谷错开。此探索实验只改变 donor 形状与目标时刻的小时索引：

- `utc`：训练源和目标均按UTC小时分箱；
- `regional_clock`：各训练源按对应 IANA 时区分箱，目标时刻换算到目标区本地钟点，再用相同的24小时月轮廓预测。

两臂共用严格月度类别点预测合同：目标区只输入合法滞后五组月总量；小时形状和热组有效 EF 由留出区之外的源先验得到。对每个目标月按目标有效小时重新归一化五组轮廓，保证预测组量和月度锚一致。2025H1/H2均由上一年对应月份的源轮廓预测，目标小时仅评分。MISO跨多个时区，主分析暂以America/Chicago作为代表时区，需把该假设作为局限。

## 结果

|时间窗|对齐方式|来源数|源等权 MAE|源等权 RMSE|平均有符号偏差|
|---|---|---:|---:|---:|---:|
|2025H1|UTC|7|57.91|66.63|+9.97|
|2025H1|地区本地钟点|7|56.51|64.35|+9.95|
|2025H2|UTC|6|61.65|68.65|+10.37|
|2025H2|地区本地钟点|6|61.28|67.59|+10.40|

总体收益很小：H1 MAE/RMSE改善约2.4%/3.4%，H2改善约0.6%/1.5%。收益集中在CISO的H1 MAE（47.67→40.96）；MISO没有改善（H1 153.60→153.94，H2 157.87→158.07）。跨区宏平均bias几乎不变，说明调整时钟相位没有处理热组水平错配。

## 解释

本地钟点是需要纳入标准强基线的低成本日历对齐，但本轮没有支持其作为破局方法：总收益小、来源效果异质，且最严重的MISO偏差未动。它也不是新算法。MISO的大误差方向在两半年均为正（真实CIF高于预测），与本地热组水平信息的重要性一致；已有同源H1诊断显示加入目标区滞后thermal EF可显著降低MISO点误差，但这项数据在用户当前中国月表口径中未确认可得。

完整逐源逐月指标、输入哈希和输出哈希见`results/v51-timezone-profile-probe/`；复现脚本为`scripts/v51_timezone_shape_probe.py`。时区表与MISO代表时区是假设，不是官方区域边界核证。所有地区仍是重复开发的美国固定EF代理，结果不能外推成中国效度或独立确认。后续强基线可保留本地钟点对齐，但不要据此冻结新方法。
