# V200：月度组成近邻能否帮助小时风险区间？

状态：在 V199 已查看的2025中国模型投影集上做来源省留一开发探针，不是独立确认。固定 V199 的八类Ember份额Bray–Curtis排序和k=15；不扫描距离或k，不将标准尺度标准化/LOO分位数称作新算法。

## 目的

V199显示组成近邻在同情景形状误差上有小幅改善，跨情景点估计同向但簇区间跨零。本轮检验这点改进是否能转化为在近似90%覆盖下更窄、更低Winkler的区间，及是否胜过V197月均CIF近邻尺度化基线和全供体校准。

## 信息与分割

沿用V199数据合同：Ember2025八类月发电份额当前估算快照仅用于选择来源形状；不是可复原历史vintage。五个CEF 2025模型情景小时标签曾由V194打开。目标月均CIF继续作为共享oracle锚。每个外层省query排除目标省在该档案的全部小时形状；伪目标的source-LOO校准也移除该省在所有情景档案中的重复记录。该程序只隔离本轮算法预测阶段，不能把既往打开标签改称盲测。

同情景和跨情景档案与V194相同。所有校准/预测档案均在读入并评分目标小时之前生成hash seal。误差/覆盖只用于已查看目标集开发描述。

## 固定方法

1. `all30_law`：30供体形状经验粒子的逐小时中央90%区间。
2. `mix15_law`：组成Bray–Curtis最近15供体的逐小时中央90%经验粒子区间。
3. `mix15_pooled`：组成最近15形状均值中心；source-LOO绝对误差的全小时统一90%高阶分位半宽。
4. `mix15_scaled`：组成最近15形状均值中心；伪目标source-LOO绝对残差除以该伪目标15近邻逐小时样本标准差（下限1e−4），池化取90% higher分位；目标半宽为该因子乘以目标15供体逐小时标准差。
5. `level15_pooled`、`level15_scaled`：与3/4相同，但供体近邻按月均CIF oracle差值选择。它们是强上界参考，目标月均在真实部署不可用。
6. `all30_pooled`：30形状均值中心，使用相同30源档案的source-LOO绝对误差池化90%分位半宽。

对每个source-LOO伪目标，从供体候选中删除该伪目标省份在所有情景下的profile，再按对应固定规则选k=15；不足15即报错并停，不用降k。样本标准差、higher分位、区间闭端点固定。点预测、校准源和目标字段/供体预算逐query保存。

## 主评分

经验90覆盖、平均逐小时区间宽度与Winkler 90分数，另报点形状MAE。按省等权；配对bootstrap以省为簇。主要对比`mix15_scaled`相对`level15_scaled`、`all30_pooled`和`all30_law`。结果不能形成中国运行覆盖保证。若不能在近90%覆盖下改善Winkler或有效缩窄区间，停止“燃料组成近邻改善可信风险区间”分支。
