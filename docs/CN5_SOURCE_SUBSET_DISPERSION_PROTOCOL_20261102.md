# 严格CN5源子集分歧风险尺度实验协议

冻结时间：2026-11-02，评分前。问题：在目标只见`t−2…t−7`五类月度组成及日历时，留出来源子集模型对目标小时预测的分歧，能否作为跨国伪目标可迁移的风险尺度？

## 与已测分支的边界

严格CN5月均组成闭合与月锚定相对形状已作为点预测方法运行并未超过强基线；V194–V198的供体离散度校准则基于中国规划投影和目标月均CIF事后锚。本实验不重复改变月边际、锚点、模型深度或风险分箱，而是在Energy-Charts严格五类伪目标中，直接验证源国子集模型分歧是否能预报外层国误差尺度。

该假设使用的是成熟的子集集成/归一化区间构造，本身不视作原创算法。它回答的是方法迁移与风险信号是否从模拟投影世界转移到跨国固定因子小时代理。

## 队列与信息合同

- 九国Energy-Charts严格CN5固定因子发电侧小时代理；外层整国留出，目标2024。所有目标国均已打开，故本轮是机制开发，不是盲地理确认。
- 每个外层折有8个源国。每个两国排除对构成一个6国训练子集，共28个模型；训练只用2022小时标签。子集模型使用已有四头`fuelshare_history` HGB，并使用同一严格CN5目标特征。
- 对每个源伪目标国P，用不含P且再排除另一源国D的6国模型，在P的2023H1预测。对外层目标T，用同一批28个6国模型预测T的2024小时。
- 校准仅使用源国伪目标2023H1小时误差；外层2024目标标签必须在所有点预测和区间半径完成封存、哈希检查后才评分。
- 外层目标输入为严格CN5滞后月份额与日历；目标小时燃料标签只用于封存后的固定EF代理评分。

## 候选区间和强基线

对伪目标P或外层目标T，令两国排除模型的小时预测均值为`m(h)`，模型间样本标准差为`s(h)`。风险尺度使用`s(h)`的下限裁剪，固定下限为1 g/kWh。

- **候选：**在源伪目标2023H1上计算`|y(h)-m(h)|/max(s(h),1)`，以国家等权、国内小时等权的90%加权分位数`q_norm`校准；外层预测区间为`m(h) ± q_norm·max(s(h),1)`。
- **配对区间基线：**同一批伪目标的`|y(h)-m(h)|`国家等权90%分位数给出固定半径，中心不变。
- **部署强基线：**全8国2022训练的`fuelshare_history`模型，以同8源2023H1误差拟合的池化90%半径；另引用严格CN5原强比例重组和`anchor700`结果作为点预测/风险基线，不参与本候选调参。
- 所有区间端点裁剪至物理代理范围`[0,1000]` g/kWh。宏指标先国内小时聚合，再对国家等权；逐国均报告。

## 指标、晋级与停止

报告点MAE、日内中心化形状MAE、经验90%覆盖、平均宽度、Winkler-90，以及最差国MAE/覆盖/Winkler。目标国为统计单元，不把小时当成独立跨域样本。

相对同中心配对池化区间，只有在宏覆盖不低于基线超过2个百分点、Winkler改善至少5%、平均宽度不增加超过5%，且至少6/9国Winkler不恶化时，才保留风险尺度信号。另要求候选点MAE不比全8源`fuelshare_history`差5%以上。最差国覆盖和所有国家结果无论如何完整报告，不能由宏平均抵消。

若不通过，不继续调标准差、分位数、分层或HGB超参数；关闭“源子集分歧可迁移风险尺度”分支，优先整理任务基准与信息识别边界。即使通过，九国均已查看且为固定因子代理，仍须冻结方法后在未看过的目标/时间验证，方可讨论外部可迁移性。

## 可复现要求

执行脚本应将本协议、代码、全部输入清单的SHA-256写入独立输出目录；为每个外层国封存28个子集模型对应的预测矩阵、源校准半径、外层均值/分歧尺度及文件哈希。先核对封存完整、没有读取2024目标燃料标签，再运行评分。运行失败或哈希不匹配时不得引用分数。该协议没有要求运行测试套件。
