# 同地域EIA-923月报的跨域小时预测信息价值：方向性正结果，尚非前瞻确认

日期：2026-11-01。执行边界见[诊断协议](EIA923_ACTUAL_BA_INFORMATION_VALUE_PROTOCOL_20261101.md)。这轮把此前不可解释的“纽约州月量→NYIS平衡区”错配，替换为EIA-923 plant-month按BA映射后与同BA、同月份EIA-930小时序列严格配对。

## 任务与样本

- 源端：GB/NESO小时发电构成训练，2022拟合、2023源残差校准；目标：美国EIA-930 BA小时发电固定因子代理。
- 真实月报臂：EIA-923 2026年8月发布包中的Netgen，使用Plant ID×Month关联Page 6的BA；与五类目标输入一致归并为火、水、核、风、光。
- 同域oracle臂：目标BA该月完整EIA-930小时燃料量汇总份额。它含目标全月信息，只用于分辨月报组成误差与模型误差，不能部署。
- 本轮从原始发行ZIP及当前小时CSV重算后得到20个完整BA×月：BPAT 6、CISO 1、ERCO 2、FPL 7、NYIS 4，覆盖2026年1—8月；20个输入均无负分量。
- 标签是EIA-930当前版本构造的固定因子代理，不是真实测量CIF。相同源训练、源校准、候选方法和目标小时用于两个输入臂。

实际月报输入下，重组相对源火电EF锚MAE低9.97 g/kWh（约31.2%），形状MAE低11.14，区间分数低17.51；区间宽度窄7.37（约3.0%），宏覆盖高1.45个百分点。重组与同月oracle的MAE差仅0.17 g/kWh。这里覆盖仍约98.8%，明显超过名义90%，所以不能写成“区间校准良好”。普通日历Ridge、五类Ridge和五类HGB宏MAE分别为113.16、555.14和119.73，没有竞争力。

误差增益也不由单一BA完全决定：20个BA月中，重组MAE优于源火电EF锚的有13格；逐个排除一个BA后，其余BA月的平均MAE改善仍为3.99–14.35 g/kWh。不过排除FPL时改善最小，收益幅度受FPL贡献影响。按BA汇总的重组覆盖为BPAT 100%、CISO 100%、ERCO 87.5%、FPL 100%、NYIS 100%；ERCO只有两个月，且其覆盖低于90%目标。总体高覆盖掩盖了该局部失败，不能以宏平均代替最差域报告。

实际EIA-923与小时回算月量的总量比中位数为0.940；五类份额L1差中位数0.0666、均值0.0997、P90为0.1667。月报调查覆盖与分类差异仍存在，但该小样本中份额信息足以支撑重组达到接近同月小时oracle的点预测。

收益的区域结构不均匀。重组/源火电EF锚的BA内宏MAE（实际月报臂，g/kWh）为：BPAT 10.74/10.50、CISO 36.00/56.42、ERCO 62.08/78.28、FPL 15.33/36.41、NYIS 27.13/27.26。CISO只有1个月、ERCO只有2个月；收益集中在CISO、ERCO、FPL，BPAT及NYIS没有实质增益。

## 复现差异及研究解释

仓库此前的月报对齐报告记录18个完整格；但本轮核对发现，旧审计列出的输入文件及解析代码哈希与当前文件相同，重新运行却得到20个完整格，并有22/56个BA月的审计状态或统计量与旧表不同。当前无法从已存材料判定原因，旧审计结果因此属于**当前环境下不可重现**；不能把它归因于原始文件修订。本轮脚本直接重解析EIA-923 ZIP和小时文件，使用20格当前一致队列，并记录Python 3.12.13、pandas 3.0.3、NumPy 2.4.5、SciPy 1.17.1和scikit-learn 1.8.0。旧表仅作差异诊断，不作为当前结果的输入。

1. 这是跨国源小时监督在目标端粗月组成输入下可工作的直接方向证据；实际EIA-923月报燃料结构足以支撑源小时轮廓重组逼近同域小时组成oracle。
2. 它**不是**预测时可见输入的回测：2026年8月发行包于10月23日发布，晚于全部目标月份。EIA-923覆盖报告机组，不能假设其总量就是BA全量；统计误差仍需按燃料和BA审计。
3. 它**不是**新算法结果。重组是已有强基线；本轮验证真实官方月统计与同域小时标签的输入价值，尚不足以冻结新机制。
4. 20格上区间宏覆盖约98.8%、宽约235 g/kWh，但ERCO只有87.5%；总体覆盖偏高与局部欠覆盖并存。这不足以证明目标覆盖可靠或区间已有效缩窄。区间分数改善部分来自偏宽风险带，需有真正的前瞻发行序列才能检验。
