# V170：先区分燃料水平误差与小时边际误差

2026-10-29，Sol。协议先于本轮评分。V169完整合法预测的固定边际耦合控制没有明确增量；它不能证明所有耦合都不重要，也不能自动证明边际是主因。本轮只诊断两个既有强重组的燃料边际，不宣称预测创新或晋级。

## 队列与信息

固定V159的29源六折、241个2024 asof测试月、相同proper小时抽样；世界身份和conditional/Gaussian概率直接复用已完成V169的world_probabilities，不重拟合、不选世界、不读2025/新地区。合法预测燃料量为X_j=B_j u_j，按查询最近已发布月的总量/查询有效小时数归一化；真值也用同一尺度，因此CRPS是相对已发布平均总发电量的无量纲误差，不是g/kWh。

逐月/燃料/方法报告：边际CRPS、未校准90%覆盖、上下漏失、区间宽度、停机概率Brier、预测和真实零概率、预测/真实均值、绝对均值偏差。零为实际单燃料发电量0，不把月度不存在当作“无法取得的q标签”，本轮预测的是有定义的实际非负燃料量X。

## 事后月度水平对照

每个原合法方法另有oracle_month_mean分支，逐燃料将整月各钟点预测原子乘以真实当月均值/原预测均值。该分支使用未发布当月统计，是事后诊断，严禁作为asof预测输入。真月量0时边际退化为0；若预测均值0而真均值正则明确失败，不能临时加伪样本。确认同一燃料所有钟点的共同缩放保持零原子概率（缩放到0除外），并精确对齐时间占用加权月均值。

两参考×原始/事后对齐×八燃料×241月=7,712条记录。所有燃料和两个方法完整报告；全29源按地区等权，另报真实当月该燃料有发电的评估子集（这是事后分层，不是模型选择规则）。原始零概率Brier和月均值偏差有不同对象，不能以某一项改善替代CIF风险改善。

本轮没有重组新的CIF预测、没有区间校准或原gate测试。即使边际CRPS有明显oracle改善，也只给后续研究定位，不代表该改善可由合法月报历史预测，更不证明会转化为CIF覆盖/效率收益。V168已经表明q指标与CIF指标可能反向。

## 核验和解释边界

核验V169所有输入/输出哈希、每查询世界身份与概率、每列源响应、所有评分身份与7,712分母；检查归一化真均值与当月粗量恒等式、oracle均值对齐误差、数值有限、原分支与缩放分支的零概率关系。方法构造先于读取查询小时真值；oracle所需当前M只在明确的诊断分支使用。

主分析分别看均值预测错误、零概率错误、对齐后仍有的边际尾部错配。无法由本轮单独给出它们对CIF误差的因果贡献，不能据某燃料事后最差定制新地区规则。若没有可以用合法粗历史预测的稳定误差规律，就停止把“边际校准”当作新方法承诺。
