# 小时热组总量是否足够？联合月库存锐界的配对分辨率实验

2026-10-27，Sol。把目标月份逐燃料月总量、小时总发电量与正EF组总量放入同一线性规划，配对比较6小时块量和1小时量。样本为2024 H1七个已查看来源，每个来源月取月中完整日的00/06/12/18 UTC四个小时，共168个配对小时；每一小时上下界都由两个LP分别求解，且所有真值均落在界内。每月目标逐燃料总量和额外正组量均来自该月真实细数据，因此这是比用户实际预测预算更强的回顾性oracle。

| 正EF组额外信息分辨率 | 联合锐界平均宽度 | 小时总量+正组块量、忽略月库存的宽度 | 真值小时CIF标准差 |
| --- | ---: | ---: | ---: |
| 6小时 | 682.17 | 918.44 | 121.75 |
| 1小时 | 178.44 | 289.78 | 121.75 |

相同取样小时上，从6小时热组量细化到1小时，使联合平均边界宽度再下降73.8%。地区差异决定了剩余需要何种信息：

| 来源 | 6小时联合界宽 | 1小时联合界宽 | 1小时宽度/小时CIF标准差 |
| --- | ---: | ---: | ---: |
| BPAT | 172.70 | 0.00 | 0.00 |
| CISO | 800.00 | 162.85 | 2.42 |
| ERCO | 997.84 | 331.36 | 3.26 |
| FPL | 399.48 | 0.00 | 0.00 |
| ISNE | 686.83 | 193.29 | 6.61 |
| MISO | 1000.00 | 380.68 | 8.44 |
| NYIS | 718.31 | 180.91 | 6.46 |

BPAT/FPL在这组取样小时中，小时正组总量加逐燃料月库存足以锁定EF代理下的小时CIF。ERCO/MISO即使已知每小时正组总量仍留下331/381 g/kWh宽度：剩余集合来自正EF组内部煤、气、油、other的小时分配，不是总热组份额。CISO、ISNE、NYIS也有明显剩余不确定性。该试验由此把信息缺口分成两层：**需要时间定位的正组出力，以及正组内部燃料替代。** 只用“小时火电总量”无法普遍解决后者。

限制：小样本是每来源月四个固定钟点，且使用未来实际月总量作约束；结果不是校准预测区间。EF固定、统计边界为代理发电侧；没有爬坡/机组可用性等约束。BPAT/FPL宽度0只对这168个抽样小时和该EF代理成立，不能外推全年或中国地区。LP是成熟通用工具，创新主张不能是该优化器本身。

结果与哈希见`scripts/v51_joint_resolution_bounds.py`、`results/v51-joint-month-hour-bounds/`。这一发现可支持设计分层信息预算基准：分别扣除逐小时正组份额与组内燃料结构的不确定性，再评估预测误差和区间覆盖；目前尚未证明任何预测算法能达到这些物理上限。

## 与已有预测研究的边界

[DACF (Maji et al., e-Energy 2022)](https://doi.org/10.1145/3538637.3538849)将逐燃料小时历史、天气与各燃料发电预测组合成小时CIF预测；其设定已经有小时源mix，因此回答的是已取得高频输入后怎样预测。我们这里的问题是冷启动/低信息地区在缺少本地小时燃料结构时哪些部分可识别。另一方面，[区间观测下的预测集合与conformal推断](https://arxiv.org/abs/2501.10117)已有一般性方法，因此“锐界后再conformal”也不能单独作为原创点。可争取的贡献应是经过真实信息发布契约审计的跨区基准、双层燃料/时序不确定性诊断、和同预算下能否稳定提升覆盖—效率的经验结论，而不是把成熟优化或校准重新命名。
