# V5：可见粗统计创新归一化的分量残差迁移

2026-10-23。V4六新区2025确认已失败：主方法宏覆盖约60%，强基线约58%；保留全部结果，不在相同新区调完后再称确认。所有执行与复核继续只用Sol。

第三轮只针对一个失败机制：固定源残差尺度不能反映新地区粗统计的变化幅度。以已发布目标历史粗月的离散度、同月年度变化与近期/历史同月分歧构造预测前风险尺度，归一化源水平残差后在目标恢复；保持形状分量单独处理，不将水平风险直接注入形状。风险量是可观察启发式，不是未来误差界或已识别物理噪声。

## 固定数据与比较

点模型不重新拟合：直接复用V4第二轮2022四源拟合的原始模型字节，保留support_gp_medium、harmonic_ridge、softmax_moe三种点方法。输入仍仅日历和预测时已假定发布的粗月统计，30/60/120日总延迟。

重新校准使用原七源BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS的2023小时残差。它与预测模型2022按时间分离，**地区允许重叠**；不再宣称校准地区完全独立。所有基线和候选都得到相同七源校准信息，以排除仅增加校准地区造成的假方法收益。V4已查看六区不进入校准。

开发选择为原七区2024（均已查看）。对三个点方法比较五种分布：七源原始残差、七源原组件1.10、风险归一化组件1.10且β=.5/1/2。β同时作用源校准与目标恢复的水平尺度，形状尺度不变。统一全部延迟选择；覆盖筛选仍为宏90%±5个百分点、最弱地区×延迟≥85%，通过者中宏CRPS最小。无通过者明确失败，允许冻结最小违规配置仅作诊断，不能改称通过。

## 风险构造

每个origin仅筛 `period_end<=origin`、`available_at+extra_delay<=origin`。以最近至多24份合法月度强度 z，计算最近至多12份合法月的标准差、已发布相同月支持的年度差RMS幅度，以及最近粗水平与历史同月差异。缺少历史时不伪造波动估计，风险回退为零并保留原模型尺度。风险随观测年龄增大；不得读取目标小时值或未来月统计。

水平新尺度 `sqrt(old_level_sd²+(β*risk)²)`，形状原尺度保持。联合同源同日标准化水平/形状残差抽样，点模型不因风险改动。source/target使用完全相同的风险变换。有限情景与确定性完整bank区间都报告，无未见域覆盖保证。

所有V5基线和候选统一将概率情景与解析区间投影至已知固定EF代理支持[0,1000]，再封存与评分；原始点保持，以便单独评价水平/形状与越界。归档投影前概率质量，此公共处理不是候选独享的校准，也不作为新颖性。V4未作此处理，不能将V4→V5变化全部归因风险；V5内部相同七源、相同投影的基线才是主要对照。

## 验收与边界

报告固定比较CRPS、水平/形状误差、边际覆盖、区间宽度和interval score、低高尾失覆盖、整日覆盖、越界质量、分地区结果，以及同步月份配对区间。开发成绩、V4失败、V5新确认分开。若风险归一化不能优于相同七源校准基线，则原创候选优势未成立；若只是扩宽提高覆盖但概率/区间评分恶化，明确代价而非宣布成功。
