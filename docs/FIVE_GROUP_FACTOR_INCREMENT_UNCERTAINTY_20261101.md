# 五国火电因子头增量的配对块重抽样诊断

日期：2026-11-01。此分析在五类M预算的2024年整国留出结果已打开后完成，用来判断“火电因子HGB比五类强重组平均MAE低”对已测国家和月份的敏感程度。它没有重训模型、调整超参数或挑选目标配置，因此是**事后开发诊断**，不是独立验证。

## 方法

输入为封存实验的`monthly_metrics.csv`。对每个国家、每个月配对计算`M_factor − M_five_group_recomposition`，对国家簇有放回抽样，并以循环连续月块抽样保持部分时间邻接结构。报告1、2、3、4个月块长度，每种设置50,000次，固定基准seed 17023。每次仍对抽中的国家和月份等权平均。

这是对五个已见国家、2024单一年份的描述性敏感性范围。它没有纳入模型训练集抽样不确定性，也不能把这五国视为全球域的随机代表。连续月份块长仅有12个月可供估计，区间不能解释成对未见国家的正式置信区间。

## 结果

宏差值均为因子头减强重组；负数有利于因子头。覆盖差值用百分点表示。

| 指标 | 已观察宏差值 | 1—4月块重抽样95%范围（各块长度并集） | 解释 |
|---|---:|---:|---|
| MAE | −2.20 g/kWh | [−5.49, +0.83] | 点误差收益对目标国/月份重抽样敏感，范围包含零 |
| 日内形状MAE | +0.13 g/kWh | [−0.09, +0.44] | 未见稳定形状收益 |
| 90%覆盖 | −0.91 pp | [−3.45, +1.71] pp | 平均覆盖略降；范围也不显示明确补偿 |
| 区间宽度 | −7.80 g/kWh | [−15.64, +1.71] | 宽度平均缩短，但没有可信覆盖改善 |
| 区间分数 | −14.84 | [−58.70, +9.70] | 平均较好，重抽样范围包含零 |

因子头在五个已见国家的MAE点差都为负（AT −1.48、BE −2.84、ES −0.47、NL −4.87、SE −1.34 g/kWh），但并不能据此排除所选国家与目标年份造成的乐观偏差。荷兰90%覆盖仍约59.6%，与强重组约59.6%几乎一样；区间缩窄没有修复最差域欠覆盖。

## 研究决定

因子HGB保留为有竞争力的M预算强基线，不能冻结为“可信迁移”新方法。已有的独立2023H2时间检查也显示平均点误差改善没有改善荷兰覆盖。两项证据合并后，优先级应从继续微调普通火电因子头转向**训练时如何预先识别迁移失败和区间风险**，并要求风险规则只用源国伪目标可见特征、以完整国家/区域留出验证。若后续研究不能在源端外层留域重复降低最差域风险，论文应主打受限信息预算的统一基准与负迁移图谱。
