# 严格五类预算下的目标条件伪目标源贡献选择

冻结日期：2026-11-01。以[九国严格CN5留国协议](ENERGY_CHARTS_NINE_COUNTRY_CN5_PROTOCOL_20261101.md)和[无条件源贡献筛除协议](ENERGY_CHARTS_PSEUDOTARGET_SOURCE_DROP_CN5_PROTOCOL_20261101.md)为基础，只改变“如何把源伪目标成绩映射为目标域源选择”。

## 研究问题

无条件源筛除在8/9外层折剔除CZ，但总体改善很小并使覆盖/区间分数恶化。这里检验一项更窄的假设：**某个来源国是否有益，取决于伪目标与真正目标的可见CN5组成；用与目标月粗组成相近的伪目标任务来估计来源边际贡献，是否比跨伪目标平均更有用？** 这只是源选择机制的开发检验，不预设为新算法。

## 预测合同与数据

- 外层九国逐一留出；其余国家为源集。2022源小时响应训练，2023H1用于源伪目标选择，2023H2用于逐月交叉伪目标校准，2024为外层评分。
- 目标可见特征严格限于火、水、核、风、光的`t−2…t−7`月份额和日历；`other_renewable`不进入目标输入/形状参考，仅保留在固定因子响应的分母中。
- 响应仍是Energy-Charts修订小时序列构造的固定因子发电侧代理，不是实测CIF；月报由小时数据回算，属于滞后模拟而非as-issued回放。九国均为已查看开发域，结果不能称作盲区确认。

## 目标条件源贡献规则

对任一当前目标月，取其预测时可见的CN5最新粗份额均值向量`x`。对每个候选剔除来源`d`，在其它来源伪目标`p ≠ d`上计算配对边际贡献：

`Δ(p,d) = MAE(train(S\{p,d}) → p) − MAE(train(S\{p}) → p)`。

伪目标`p`的特征为其2023H1可见CN5组成月均值。按欧氏距离`||x−x_p||₂`选最近的3个可用伪目标；候选`d`的条件贡献为这3项`Δ(p,d)`等权平均。若最小条件贡献小于0，则逐月剔除该来源，否则保留全源。`k=3`、等权、欧氏距离及符号门槛在外层目标标签评分前固定，不扫描参数。来源训练器仍为同一五类比例重组；方法只改变来源集合。

外层2024按月用当月可见CN5特征重新选择来源，避免使用未来月份输入。2023H2校准对每个校准伪目标也逐月选择；该伪目标从选择和训练来源中排除。对照包括全源比例重组、无条件伪目标源剔除、anchor700和目标条件剔除。所有半径都在同一H2交叉拟合队列估计。

## 评价与晋级门槛

点误差、日内形状MAE、90%池化经验覆盖、区间宽度、Winkler区间分数按国—月评分、先月等权后国家等权汇总，同时报告逐国表现与最差国。方法只有在相对全源重组和无条件筛除都产生稳定点/概率增量、且最差域不出现严重恶化时才晋级；覆盖或区间分数改善不能只来自加宽。不得把池化小时覆盖解释成整国有限样本保证。

全部预测和H2半径在读取目标2024响应前先落盘哈希。实验结束复核代码、输入、协议和预测封存。若不达门槛，停止目标粗组成源筛选，不转而扫描距离、邻居数或剔除数量。
