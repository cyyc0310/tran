# 阈值侧不识别：月燃料边际下小时尾数的全宽锐界条件

## 设定

一个月有`H`个正总发电小时。令`G_h > 0`为已知小时总发电量，`M_f ≥ 0`为燃料`f`的月发电量，且总量守恒：

`Σ_h G_h = Σ_f M_f = M`。

小时燃料分配`x_{h,f}`未知，但非负，且满足：

`Σ_f x_{h,f} = G_h`, 对每个小时`h`；
`Σ_h x_{h,f} = M_f`, 对每种燃料`f`。

EF参数向量`e`来自不确定集合`E`。对阈值`τ*`，定义小时CIF
`C_h(e,x) = Σ_f e_f x_{h,f}/G_h`，以及超阈小时数
`K(e,x) = Σ_h 1{C_h(e,x) ≥ τ*}`。

## 命题

若存在`e⁻, e⁺ ∈ E`满足

`Σ_f e⁻_f M_f / M < τ*`，且
`Σ_f e⁺_f M_f / M ≥ τ*`，

则在只给定小时总量和月燃料边际的条件下，K的锐最小—最大识别区间必为`[0,H]`。因此精确小时总发电量仍不足以把阈值尾数界变窄。

## 证明

构造比例分配`x_{h,f}=G_h M_f/M`。其元素非负，并且

`Σ_f x_{h,f}=G_h Σ_f M_f/M=G_h`，
`Σ_h x_{h,f}=M_f Σ_h G_h/M=M_f`，

所以对任意观测到的正小时总量曲线，它都是月边际与小时总量的可行燃料分配。其每小时CIF为

`C_h(e,x)=Σ_f e_f (G_h M_f/M)/G_h=Σ_f e_f M_f/M`，

与小时`h`无关。在`e⁻`下该值严格低于`τ*`，从而`K=0`；在`e⁺`下该值不低于`τ*`，从而`K=H`。两端都可行，因此K的锐最小—最大区间为`[0,H]`。证毕。

## 解释边界

- 命题是充分条件：EF集合跨阈值时，小时总量对K的尖锐区间没有信息价值。
- EF集合不跨阈值并不保证小时总量一定有用；可行界还取决于各燃料边际、逐小时总量和阈值位置。
- 若EF全月共享未知参数，证明仍然成立，因为`e⁻`和`e⁺`分别对应两个可行全月参数情景，足以令识别区间两端达到0和H；不要求单个EF向量同时实现两端。
- 若允许EF逐小时独立在盒内变化，则可以对每小时分别选择`e⁻`或`e⁺`，比例分配可构造任意`K∈{0,…,H}`。
- 该结论是部分识别，不是概率覆盖率、因果结论或预测算法性能保证。

## V240数据复核

V240在16个EIA BA-month上使用八源月边际、固定EF±10%盒。比例构造数值守恒；16例中4例EF均值盒跨阈值，且MILP界恰为`[0,H]`；另12例不跨阈值，小时总量均额外收窄尾数界。详细逐例值与哈希见[`V240证书`](../results/v240-ef-uncertainty-temporal-risk-r1/threshold_side_certificate.csv)。
