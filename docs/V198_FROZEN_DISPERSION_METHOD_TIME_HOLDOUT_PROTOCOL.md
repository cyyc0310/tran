# V198 冻结协议：V197供体分歧区间的2055/2060时间外推

状态：**目标小时评分前冻结**。V197方法冻结后进行时间外推；不是新省份验证，不是真实运行验证。

## 目的和既往数据可见性

V197在2025–2050完整年发现同小时供体离散度可预测目标形状误差，尺度标准化区间降低Winkler。V198冻结使用相同V197 k=15和1e-4尺度下限，评估尚未评分的2055/2060投影年份。

2055/2060小时文件此前仅用于空值定位/完整性判断；缺值位置及省份已公开记录，但没有计算目标省小时误差、覆盖、均值/分位或相关性。因此本轮是**时间外推盲评分**，不能称地理未见省或新模型的全盲外部验证。

## 完整性和样本合同

- 五个情景、2055和2060、31个省级列。全国聚合列不作为目标/供体。
- 如果目标省某月任何小时为空，排除该 query；不填零、不插值。
- 供体月内有缺值则不进入供体池。`same_scenario`轨用同情景该月全部完整的非目标省，因缺失允许29或28个供体；最低要求16。
- `leave_scenario_out`轨仍从四个其他情景中按冻结8/8/7/7档案抽样，目标省跨情景全部排除，只从对应情景×月份的完整省份档案抽取；若任一情景不足计划档案数，则整条 query 排除并记录原因。
- 目标锚仍是事后oracle月均；该结果只对模型情景形状迁移可泛化性作压力测试。

## 固定方法和基线

1. `constant_anchor`：目标月均常数。
2. 最近15供体形状均值点预测、最近15供体经验粒子分布、全部可用供体均值/粒子分布。
3. `loo_pooled_k15`：最近15形状均值中心，来源 LOO k15 残差绝对值90% higher分位的统一半宽。
4. **冻结的 `v197_scaled_k15`**：每个伪目标的 k15 LOO 绝对残差除以其15个最近供体逐小时标准差，池化取90% higher分位，再乘目标 k15 供体逐小时标准差；因子小于 `1e-4` 时取该下限。

不按2055/2060任何目标小时结果选择 k、因子范围、供体、超参数或目标。所有点、分布/区间使用同一query/供体预算。

## 评分与判断

完整 query 分母、原因、每轨/情景/年份报告形状MAE/RMSE、小时MAE/RMSE、CRPS（粒子分布）、90经验覆盖、宽度、Winkler；同一省聚类 bootstrap 只作有限模拟集合的配对描述。确认信号要求V197区间相对 pooled k15 在情景、年份上多数不恶化Winkler、宽度增量有限，并且与2025–2050结果方向相符；如果增益消失或S4/S5等情景严重失效，则当前假设未通过时间外推确认，不再在相同数据上改method。
