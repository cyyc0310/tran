# V86：月度边际到最小日内摘要的同样本信息桥

冻结日期：2026-10-28。目的：在相同小时标签和相同地区月份内，比较只保留整月H/G、增加逐日H/G、再增加逐日Q=ΣG²时，月内超阈小时频率的逻辑决策前沿。固定使用V84/V85同一25区、完整UTC日、2024-07至2025-12，EF=(煤1000、气400、油800、其他400、核/水/风/光0) g/kWh代理，月度活跃支持M取V54燃料边际、缺月表回退1000，阈值τ=100/300。

目标依次为月内K/n≥1%、5%、10%，其中n是被评分完整日内小时数，所需尾事件数k*=ceil(r*n)。每个方法给出其可行/必要外计数集S，正证书min(S)≥k*，负证书max(S)<k*，否则弃权。错误正负证书或集合不满足嵌套关系时中止。

同样本三个信息集：
1. 月度H/G/M：对一个地区月内所选完整日的所有小时聚合H与G后，使用粗计数界；
2. 逐日H/G/M：按日分别求粗界并合并日计数集；
3. 逐日H/G/Q/M：在逐日H/G外增加当日Q=ΣG²，计算必要矩外集并合并。

第一档是从V84可用小时代理回聚合出的“同样本月度信息”反事实，不等于已验证的中国官方月报。为隔离时间聚合损失，三档都只用同一批完整UTC日小时；结果按同一组观测标签评分。完整日不足月日数80%的地区月仅用于主样本覆盖统计，并在敏感性中排除。按地区等权、月等权宏平均，不把region-month当独立电力系统。

分析为同期部分识别，非预测或概率覆盖。日/月H/G/Q在运行中需要何种发布时间和口径尚未计价；固定EF小时标签是合成代理。它不能证明中国月度公开数据足以识别小时CIF，也不能外推到未观察的地区。

规范输出位于`results/v86-monthly-daily-info-bridge-r2`。r1仅保留首次实现的主样本前沿；r2修正了质量敏感性筛选中的时区型月份键匹配，并作为正式结果。两轮使用相同输入、队列和主方法。
