# CN Deployment Layer（中国零遥测部署层）

> 状态：Phase A 已交付（2026-09-06）。代码：`src/transcif/data/cn_deploy.py`，
> 测试：`tests/test_cn_deploy.py`（14 通过），
> 演示：`scripts/experiments/demo_cn_province.py`（双场景）。

## 1. 定位与输入接口

面向国内**无逐小时遥测**的省级电网做日前（D+1）碳强度（CIF）预测。
模型只消费部署合法的公开输入：

| 输入 | 内容 | 来源 | 滞后 |
|---|---|---|---|
| 月度分燃料发电量表 | 12×{coal, gas, hydro, solar, wind, …} | 省统计公报 / 能源局月度数据 | ~1 月 |
| 省间受电月度表 | 送端身份 + 电量/占比 | 北京/广州电力交易中心月度结果 | ~1 月 |
| 天气 | 再分析历史 + 日前 NWP 预报 | ERA5 / CMA / Open-Meteo | 0 |
| 天文 | 精确未来量（太阳高度角/晴空辐照） | 内置解析式 | 0 |
| CN 日历 | 法定假日/调休/供暖季事实表 | 国务院办公厅通知、市供热条例 | 0 |

供热事实已核实：太原 11/1-次年 3/31（太原市供热管理条例），北京/天津 11/15-3/15；
2026 春节 2/15-2/23（国办发明电〔2025〕7号）。

## 2. Phase A 交付内容

### 2.1 CN 日历通道（输入空间重映射，不重训模型）

`cn_calendar_features()`：官方假日落在工作日 → 用周日 dow 通道替代；调休上班
日落在周末 → 用周一 dow 通道替代。模型无需认识"春节"，至少通过已知的
"周末形态"通道看到"假日形态"的一天。`flags` 二元通道 [is_holiday,
is_special_workday] 作为 advisory 返回，**永不静默**。

### 2.2 送端加权月度进口 EF（FD-18 部署化）

`import_ef_from_senders()`：进口轴的 EF 不再是常数 250，而是送端省份自身
月度结构的流加权平均 CIF（`monthly_cif_from_gen()`）。四川枯水期热电抬升
进口 EF，丰水期压低——把"来水季节性"从结构不可见变成水平可见。

### 2.3 CN 月度配置表

`cn_monthly_table()`：月度发电统计 → (12,16) FD-config 表 + 年度 config +
per-fuel EF 向量。要点：

- CN 可再生定义（生态环境部口径）：hydro/solar/wind/biomass 为可再生，
  nuclear 与 imports 为非可再生（进口计送端加权 CIF）
- 年度份额为**能源加权**（电量比），非月度份额的算术平均
- 进口 EF 无送端信息时回退常数 250，文档化、不静默

### 2.4 Proxy anchor-trust（无 CIF 观测的门控）

`proxy_anchor_trust()`：基准门控需要目标省 CIF 观测（零遥测省没有），
代理版用独立公开统计审计月度表：与火电电量指数/电煤日耗月均值的月度
相关性（形态门）+ 官方年度电网因子锚（水平惩罚）。**无任何代理 → 0.0**
（不可验证），月度表整体回退年度 config——保守而非猜测。

### 2.5 部署窗口构造器

`build_cn_windows()`：原始天气 + CN 日历 → 模型契约的完整输入
（18 通道 fut_exog / 10 通道天气栈 / 滞后月度 config）。修复了旧 demo 的
三个 bug（见 §4）。

## 3. 能力边界（诚实声明）

**以下效应未被源域训练覆盖，advisory 标注、不静默信任：**

1. **春节/黄金周负荷塌陷**：2023 西方源域无此形态。重映射让模型看到
   "周末形"的一天，但幅度未知 → 假期窗 shape 置信度调低
2. **北方供暖季 CHP 形态**：以热定电的日内基荷抬升未训练
3. **弃风弃光约束**：天气→实际出力映射可能断裂（甘肃/蒙东类）
4. **受端省日内进口结构**：月度送端加权是"平均"，日内联络线受电轨迹
   不可见 → 上海类消费侧 CIF 继承此不确定性
5. **火电不拆分**：公开口径多数只有"火电"，coal/gas 拆分靠装机结构假设，
   燃料质量/机组年龄未校准

**省分类适用性**（来自 FD-10/FD-30 的基准证据映射）：

| 省类型 | 代表 | 预期档位 |
|---|---|---jan|
| 煤主平稳省 | 山西、蒙西、陕西、宁夏 | 最优（基准同类 17-20 MAE） |
| 风光大省 | 甘肃、蒙东、新疆 | 勉强（弃电约束） |
| 水电省 | 云南、四川、湖北 | 中等（来水季节性经月度表进入，但年际波动大） |
| 东部受端省 | 上海、江苏、浙江、山东 | 结构最难（进口占比 20-35%，ISNE/UK_14 同构） |

## 4. 修复清单（相对旧 demo）

1. **fut_exog 通道数**：旧 demo 喂 10 通道，模型 future_input 期望 28
   （10 weather + 18 exog）——旧 demo 已无法运行（零张量实测报错）。
   新构造器输出完整 18 通道
2. **月度表滞后取行**：旧 demo `config=table[6]` 手工索引，绕过了
   `monthly_config_at` 的滞后逻辑；新窗口构造器统一走 `monthly_config_at`
3. **ef_nr 语义**：旧 demo 把"平均 EF"（分母含可再生）当 ef_nr；新表
   按基准约定（非可再生质量加权平均）计算，测试锁定
4. **进口 EF**：常数 250 → 送端加权月度 EF
5. **训练接口**：`target_name=None` 误用修复（空串走全源训练）
