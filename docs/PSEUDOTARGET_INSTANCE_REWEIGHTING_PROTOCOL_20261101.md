# 伪目标粗组成条件的源训练样本重加权

2026-11-01，拟合前冻结。上轮按目标粗组成门控国家专家有小幅点预测收益，但未达到点/风险门槛。本轮直接改变训练：把每个源国家轮流当作伪目标，用该伪目标当月公开粗组成对其余源国小时样本进行重要性加权，再训练有效火电因子头。

## 外层数据与输入预算

沿用Energy-Charts五国整国留出：NL/ES/BE/AT/SE；源2022训练，内层伪目标2023H1调带宽，源2023H2交叉校准区间，外层目标2024评分。目标输入只包含日历和精确`t−2`及更早的六类粗月发电份额。月量由当前修订小时序列回算，因此这是中国信息条件的时滞模拟，不是历史as-issued发布回放。标签是九类固定因子发电代理，不是实测CIF。

## 训练算法

预测器沿用标准`factor_history`火电有效因子HGB；小时形状继续由同一源训练期强重组profile给出。目标可见六维粗组成记为`g*`，每个源训练行的历史粗组成记为`g_i`。只用本折源训练输入计算每一维尺度`s_j=max(sd_j,0.02)`，定义`d_i²=mean_j[((g_ij−g*_j)/s_j)²]`。训练权重为国家/地区均衡基础权重乘`exp(−d_i²/(2τ²))`，再归一至相同总权重。`τ∈{0.25,0.5,1.0,2.0,∞}`；无穷大等于不重加权火电因子头。

每个外层源国家q轮流作伪目标。源模型只用其他源国2022小时监督；q的2023H1按月提供当时可见粗份额，用于拟合候选温度并预测该月小时代理标签。先按月计算MAE，再等月、等伪目标国选全折共同τ。整个选择过程不看外层目标标签。

选出τ后，外层最终模型使用所有源国2022训练样本。对目标2024每一个待预测月，依据该月合法可用的`t−2`粗份额重新计算源训练行权重并拟合一次因子头，仅预测该月查询小时。不能使用目标细燃料/小时发电。源H2区间校准采用同样的伪目标留国流程：各源国小时由其余国家训练模型预测，按国家均衡取绝对残差90%分位数。

## 比较与门槛

比较无重加权`factor_history`、`ratio_recomposition`、`macro_recomposition`、`anchor700`以及上一冻结候选`coarse_expert_gate`。若伪目标选择退回τ=∞，按无新增训练效果报告。报告宏/逐国MAE、去日均形状MAE、覆盖、宽度和区间分数，并保留每个目标月的训练有效样本量/来源权重审计。

不能只凭五个已查看国家上不足5%的点增益或较窄欠覆盖区间冻结方法。目标国预测全数哈希封存后再评分。仅当收益在国家层一致、宏点改善达到预设门槛且区间风险不恶化，才继续考虑未查看国家确认。该实验检验的是粗统计相似度加权的迁移训练，不声称它本身属于原创理论方法。
