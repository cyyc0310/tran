# V233 结果：Carbon Monitor China Power 日曲线在省内月尺度几乎是同一形状

日期：2026-10-30。审计对象首先是本机 2026-10-29 下载的 Carbon Monitor China 快照；随后于 2026-10-30 从官方 CSV API `https://datas.carbonmonitor.org/API/downloadFullDataset.php?source=carbon_china` 重新下载。两份文件字节完全一致，SHA-256 均为 `723709ff6cc610e121d502f0c0aa9adb55aa6531a616cb145109de4e12b0ae52`。分析对象是 `Power` 部门省级日 CO₂ 估算。该序列是可修订估算产品，不是直接计量的小时 CIF 标签。

## 覆盖与方法

快照含 2019-01-01 至 2026-06-30 数据。`Power` 有29个省级地区，逐日记录共79,402行；相对全表31个省级地区，内蒙古、黑龙江没有 `Power` 行。审计将每省每月日排放归一为和为1的日形状，再比较省间相关、归一化L1距离以及以“省月尺度×共同月日曲线”重构的误差。共有90个年-月块、29省；每月在28–31个共同日期上进行比较。输入SHA-256为 `723709ff6cc610e121d502f0c0aa9adb55aa6531a616cb145109de4e12b0ae52`。

## 结果

在全部90个省月块中：

- 省间归一化日形状平均相关系数均值为 `0.999999999`；90个月块中的最低值仍为 `0.999999954`。
- 平均两两归一化L1距离约 `1.4×10⁻⁶`。
- 将各省日排放写成“本省本月尺度 × 本月共同日形状”，相对RMSE约 `1.3×10⁻⁶`，每个月块的最大值小于 `1.8×10⁻⁶`。
- 在该快照里内蒙古和黑龙江完全没有Power行；故这一版本无法作为这两省的Power日排放留出标签。

这与既有方法披露一致，而非意外的新算法发现：CarbonMonitor-Power论文说明中国缺少可直接取得的高频发电数据，并以“省/源月发电量 × 八个沿海省份电厂日耗煤的月内比例”生成日序列，公式对源类别 `s` 没有额外地区下标。[Zhu et al., *Scientific Data*](https://www.nature.com/articles/s41597-023-02094-2)。该构造自然会让多地区、多电源共享日内模板。V233的新增证据是对当前Carbon Monitor China发布快照做定量复核，并确认其与已发表构造的后果一致；它不是首次识别该方法。基于此快照做省份留出，测试集日形状与训练省份共享近乎相同的月内模板；即使模型得分很好，也不能证明它学到了可推广的本地调度/燃料日变化。该快照不适合验证“未见省份的独立日形状迁移”。

## 与文献及TransCIF的关系

Carbon Monitor China官方页面明确说明其是持续更新、可修订的估算数据产品，并提供按发布版本的数据下载。[官方数据页](https://cn.carbonmonitor.org/)。相关2026年同行评审研究将2019年以来的省级日排放与年度清单衔接，说明其使用高频活动数据，但数据链条仍是估算/会计框架，而非逐小时实测标签。[Huang et al., *Advances in Applied Energy* (2026)](https://doi.org/10.1016/j.adapen.2025.100260)。V233只审计本地快照的数学结构，不推断该文所有历史版本或其他研究者手中数据文件必然相同。

这也限制了最近提出“月度燃料统计＋天气→日CEF”方法的外部验证空间。SSRN摘要称使用CarbonMonitor-China日CO₂作为ground truth，并主要报告内蒙古、江苏、云南三省时间序列评测；当前网页只提供摘要，未取得该稿全文独立核验其标签版本与生成方式。[SSRN摘要](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5917247)。由于当前本地快照缺少内蒙古Power行，且已发表的CarbonMonitor-Power方法使用共用日耗煤比例拆日，不能用当前快照独立证明其三省模型学到本地运行形状，也不能据此断言历史版本/其使用文件必然相同。

## 科学含义

这是**已知构造机制的当前版本数据审计**，不是新预测算法，也不应夸大成首次数据发现：当前发布快照的Power部门确实提供省月水平与共用日拆分模板，论文方法已披露这种拆日路径。研究价值在于把标签生成/地区覆盖审计变成benchmark门槛：(1)数据是否覆盖目标省；(2)目标形状是否由跨省共用模板构造；(3)模型预测是否依赖独立小时/日信息；(4)目标究竟是排放估算、发电侧强度还是消费侧CIF。

TransCIF的潜在研究破局方向更具体了：不是再证明跨省模型能拟合这一估算产品，而是制定**目标标签生成机制审计＋省份留出风险验证**的CIF benchmark合同，并在有真实独立高频标签的数据上检验算法。只有估算产品可用时，结果应标作“估算产品一致性重建”，不能等同电网真实CIF冷启动。
