# V154–V155：强基线的实现边界

这些基线用于评估V153日历重组，不主张算法原创。当前实验只使用来源地区2024小时标签和目标月度统计/日历输入；没有真实已发布快照或新的确认地区。

[Meinshausen，Quantile Regression Forests，JMLR 2006](https://www.jmlr.org/beta/papers/v7/meinshausen06a.html)已经通过森林叶内响应构造条件分布和分位数。V154保留源标签及其权重、对树叶分布等权混合，属于这一类常规经验分布思路；使用ExtraTrees分裂，并非原论文算法的逐项复现，也不应仅凭输出了分布就称新方法。

[Ćevid等，Distributional Random Forests，JMLR 2022](https://www.jmlr.org/beta/papers/v23/21-0585.html)针对联合条件分布设计森林。V154的树仍按标量CIF的均方误差分裂，没有实现该文的多变量分布分裂。因此`distribution_forest`仅描述预测分布，不表示复现了该文DRF，也不能把它泛称最强分布森林。后续如把燃料联合分布作为方法核心，必须再与针对联合分布的强参考比较。

V154异方差正态使用整区五折残差学习条件方差，避免直接用训练残差夸大确定性。正态分布以1,025点中分位离散后裁到物理范围；60组合成积分对照中CRPS最大差0.01542 g/kWh，这是已测试参数网格上的数值误差，不是所有未来预测的统一误差界。森林分布均值在20组合成查询中与点森林最大差7.11e-15。

V154默认HGB分位数与V155严格零残差子梯度须分开报告。合成非负响应约50%为0时，原q05预测全为0；严格tie控制能学习非零条件分位数。两者目标均为pinball损失，V155只选用零残差处另一个合法子梯度，不改源标签或添加随机噪声。该数值控制不属于领域算法创新。

三个分位点无法唯一确定完整CDF，因此两个分位数臂的CRPS必须为空；不能为了完整表格补成三个原子的伪CRPS。它们的点预测取q50，其他概率臂取分布均值，MAE的这一约定也须披露。

源抽样实际由`20261028/源身份/预算`哈希确定，每预算每源最多4,096小时、同预算各模型共用。预算包含不同可用时段，因此跨预算抽样也不同；比较预算变化不能视为只改一个输入字段的严格因果消融。全部抽样索引、源区域五折、特征和输入数据哈希随实验保存。

只有完整目标对照和源隔离核验完成后才能讨论优势；条件分布、异方差、森林或合法tie处理本身都不能作为原创方法贡献。V153相对整月CDF的收益也尚未证明优于所有同预算小时条件模型。
