# CN5燃料组成候选外部域：爱尔兰预测前数据门槛审计

日期：2026-11-01。目的仅为判断爱尔兰能否在不改变已冻结燃料组成头和目标标签定义的前提下，进入外部小时确认。没有生成预测、读取CIF误差或计算模型评分。

## 数据与盲测边界

从Energy-Charts API v2下载爱尔兰 `public_power` 2022-01-01至2025-01-01 响应，保留原始JSON、服务端响应头与SHA-256，见[证据包](evidence/cn5-fuel-resolved-ie-preflight-r1/README.md)。响应报告 `Europe/Dublin`、MW、PT30M，共52,656条记录；请求区间末端包含2025年边界记录，未来实验必须按预先固定的当地统计期过滤。

爱尔兰在本项目的Carbon Monitor日尺度实验中已出现。因此即使未来仅使用从未评分过的Energy-Charts小时代理，也只能称为“新的小时标签/数据域复核”，不能称为全项目从未观察的国家。

## 冻结方法的标签兼容性

已冻结的燃料组成头把火电内部响应分成煤、气、油、其他四类，并以既有固定EF构造发电侧代理标签。爱尔兰API的可见燃料类别包括 `fossil_peat` 和未分类的 `others`；当前模型没有泥炭专属头/EF，也没有`others`的可解释燃料映射。接口还没有报告核电和太阳能序列。对接口结构性缺失类别按零处理可以沿用既有合同；但把泥炭并入煤或把未分类发电并入某个热电类别会改变固定EF标签和模型目标，不能在确认集上临时决定。

因此爱尔兰**未通过冻结标签口径门槛**。本轮在任何预测前停止，不把标签重新编码成有利于方法的形式。30分钟数据可按固定时段聚合到小时，但这不能解决泥炭与`others`的EF/类别不可识别问题。

## 决策

1. 本候选不运行已冻结的燃料组成头，不用于调参或阈值选择。
2. 若将来单独研究爱尔兰，需先在独立于确认分数的依据下预注册泥炭、`others`及其他缺失类别的EF/标签合同；该新任务不能与目前法国确认直接合并。
3. 下一外部域优先选择：小时目标燃料字段可完全映射到既有固定EF标签、CN5滞后输入满足完整性合同、且目标预测窗口此前未用于方法选择的地区。筛选只看字段与时序可用性，不看目标误差。

这是一项候选拒收和研究流程审计，不是燃料组成模型失败，也不增加法国单国确认的证据强度。
