# V354 protocol: locate EF support relative to the CIF threshold

For each V352 province-month, recompute the Ember effective thermal EF interval under the same ±100% fuel-share simplex error set. Classify each province-month-threshold as (1) all thermal EF support at or below τ, (2) all support strictly above τ, or (3) crossing/touching τ. Join this classification to the exact K-width factorial.

Two declared-model implications are checked: if all technology factors are at or below τ (nonthermal direct operational factors are set to zero), the fuel-mix arm must have K width zero; and every negative mix-capacity interaction should occur in this saturated below-threshold class. The test explains set geometry under scenario assumptions; it cannot validate whether Ember EF support contains true Chinese values.
