# 粗统计对小时风险：能给范围，不能给唯一尾部

2026-10-25，Sol。此处补充标准矩不等式下的风险对象区分；不是新定理、预测实验或创新门槛通过。V16的实际负结果见[结果报告](CONTEXT_V16_RESULTS.md)。

**粗统计并非对所有小时风险毫无约束。它能给已观测区间的某些加权尾部范围，但不能仅凭该范围确定哪些小时危险、小时数占比或未来覆盖。**

## 1. 一个可直接由区间燃料量约束的风险

设已观测区间的有效小时满足G_h>0，固定代理支持为0≤C_h≤B（当前B=1000），定义能量权重w_h=G_h/ΣG。燃料总量识别加权平均µ=Σw_h C_h。对0<τ<B，定义：

`p_E(τ) = Σ_h w_h 1{C_h>τ}`。

这是“高CIF小时所对应发电能量的占比”，不是排放总量占比，也不是随机未来小时的模型预测概率。在已观测区间内将小时按发电能量抽样时，它才等于该抽样机制的超越概率。

由µ≥τ p_E及µ≤τ(1−p_E)+B p_E，得到有效闭范围：

`max(0,(µ−τ)/(B−τ)) ≤ p_E(τ) ≤ min(1,µ/τ)`。

严格超越与阈值恰好相等时，某些端点只能作为上/下确界，不能声称端点总能取到。给有限固定小时权重、更多燃料边际或机组约束时，这个仅用均值与支持的范围一般不是sharp可行范围。

| 已知加权CIF µ | 阈值τ | 能量加权超越占比的有效范围 |
| ---: | ---: | ---: |
| 200 | 600 | [0, 1/3] |
| 600 | 600 | [0, 1] |
| 800 | 600 | [1/2, 1] |

这些是代数例子，没有用目标成绩挑阈值。它们说明均值靠近阈值时，粗统计对该尾部很弱；远低于/高于阈值时，可以排除某些极端能量占比。仍不知道具体小时的位置和联合路径。

这是经典矩约束概率界的一阶特例；优化更高阶矩/支持下的事件概率也已有成熟研究，例如[Bertsimas和Popescu，SIAM J. Optimization 2005](https://epubs.siam.org/doi/10.1137/S1052623401399903)。不能将这条不等式重新命名为新CIF理论。

## 2. 能量占比为什么不能直接当小时占比

两小时G=[1,9]、C=[1000,0]时，µ=100，阈值600的p_E=.1，而危险小时数占比是.5。µ/τ=1/6是有效能量占比上界，却不是该小时数占比的上界。

若额外知道所有G_h和p_E∈[l,u]，可用G的排序给小时数n提供外界：n个危险小时对应的能量不会超过最大的n个G之和，也不会小于最小的n个G之和。因此n至少要大到“最大n个G之和/ΣG≥l”，最多只能大到“最小n个G之和/ΣG≤u”。这只是必要条件外界，未同时保证均值、燃料量和阈值限制可实现，不称sharp。

仅有独立有符号netG时，不能无条件用它替代这里同口径的正G。只有日总G而没有其小时分配时，也不能直接执行上述小时数转换。

## 3. 识别过去的风险范围，不等于给未来概率校准

已发布历史粗统计给过去µ，以上范围约束过去的p_E。用于未来时，µ本身仍需预测，调度和分母分配也需前推。即使正确预测未来µ，宽广的条件分布集合仍可对应不同小时超越、时序和尾部。

标准燃料重组若每个粒子严格保持预测的日燃料比例和正G，就已经自动满足该粒子相应的加权均值恒等式及上述不等式。再把相同约束加回模型，不会凭空带来独立信息或机制创新。需要约束的是它尚未识别的自由度，例如分时排放量、内部燃料替代和可靠支持上限。

小时预测90%覆盖是另一个对象：它涉及未来实际C_h与模型区间之间的关系，而不是某区间内高于τ的发电能量占比。不能把矩范围包含真实p_E、或聚合守恒成立，写成已校准小时覆盖。

## 4. “最小本地信息”应按风险对象定义

- 若目标是已观测区间的加权平均，一组同口径燃料份额和固定EF已经足够；预测未来仍需时效假设。
- 若目标是超过指定阈值的能量占比，均值与支持给部分界；需要更紧范围时，可增加真实高阶/时段矩或支持信息，须核查实际可得及测量误差。
- 若目标是何时出现高值或有多少个危险小时，需要时间定位、分母分布和燃料内部替代信息；更多无时间定位的总量不自动补齐。
- 若目标是未来小时概率区间，需要识别信息之外的概率迁移与风险验证。少量本地小时CIF可帮助校准，但必须单列少标签预算，不能计入严格零小时观测方法。

V17的T8针对第三项中的粗时间定位，G5检查是否只利用分母时序。它尚未解决第四项；只有未来实际实验与强参考比较，才能判断这种信息是否值得获取以及剩余风险如何处理。
