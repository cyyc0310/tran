# V236 冻结协议：省级负荷代理能否收窄全月 CIF 超阈小时数锐界

日期：2026-10-30。V235结果已知；本协议在构造风险计数前冻结。

## 科学问题

V235显示小时总量代理不收窄任一小时CIF边际集。本轮检验不同小时总量形状是否仍能通过月度守恒约束收窄**全月超阈小时计数**。响应不是预测误差，而是给定约束下 `K(τ)=#{h:C_h>τ}` 的精确可行最小/最大值。

## 固定数据和查询

- 年份：2024；输入版本、哈希继承V235。
- 省份：Inner Mongolia、Yunnan、Jiangsu、Guangdong、Sichuan、Xinjiang，覆盖煤电主导、水电主导和多元沿海等结构；名单不按本轮阈值结果筛选。
- 月份：1月与7月，覆盖冬季和夏季负荷形状。
- 月燃料边际：Ember八类源月电量，按煤、其他化石、气+生物质、非化石汇成EF相同的四组；此合并对指定EF是代数精确。
- EF：沿用V225 `[1000,400,800,400,0,0,0,0]` gCO₂/kWh。两个固定阈值 `τ=500,900 g/kWh`。
- 三种信息条件：仅月度边际（用V87解析锐集）；日负荷总量均分24小时并按月电量守恒；逐小时负荷曲线按月电量守恒。

## 锐界求解

在日平坦和逐小时负荷条件下，小时总量 `G_h` 是重建负荷的缩放代理。对四个EF组的非负小时分配 `x_hk`，施加 `Σ_k x_hk=G_h` 和 `Σ_h x_hk=M_k`。用混合整数线性规划最小化/最大化二元尾事件数。数值稳健事件阈值统一定义为 `τ*=τ+10⁻⁴ g/kWh`，事件为 `C_h≥τ*`，非事件为 `C_h≤τ*`，等号可以在两侧端点计数中择一；月度-only的V87解析基线也必须以同一 `τ*` 计算。每个端点必须由HiGHS证明最优；达到时限或未闭合gap的记录保留并标记，不混入已证明端点汇总。

比较每个省月的月度-only、日平坦和逐小时负荷的 `[K_min,K_max]` 及集合宽度。若小时曲线能缩窄，就进一步分解收窄来自日总量还是日内形状；不将负荷代理说成发电实测。

## 先验门槛与限制

- 24个固定省月×2阈值×2负荷条件，至少80%的MILP端点必须以最优状态求解，否则本轮只报求解覆盖，不作集合宽度结论。
- 记录输入、协议和代码SHA-256、求解器版本、逐端点状态及最优gap；拒绝覆盖输出目录。
- 数据没有真实小时发电/CIF标签；Ember为估算月边际，负荷为模型重建，EF为代理。结论仅对构造出的兼容多面体成立。
- 结果若无收窄，停止用“总量形状”作为中国燃料组成小时风险的主要信息源；转向最少**小时燃料侧**通道、净交换或代表性本地日采样。
