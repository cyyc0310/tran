# 严格CN5燃料组成迁移：正则化softmax伪目标协议

冻结日期：2026-11-01。目标是检验当前四个独立份额回归器的误差是否来自输出后截断/归一化，或严格CN5输入本身无法确定目标热电内部构成。本实验属于优先级3的机制开发，不预称TransCIF新算法。

## 数据和隔离

- 使用严格CN5九国固定因子发电侧小时代理。外层逐国留出；源训练2022、内层伪目标选择2023H1、独立区间校准2023H2、外层测试2024。
- 外层目标只输入`t−2…t−7`火、水、核、风、光月统计和日历；目标内部燃料份额只能在预测封存后作为机制评分标签读取。
- 输入月量由当前修订小时序列回算并模拟`t−2`，不是历史as-issued报告。九国此前均已查看，本轮不是盲区确认或中国实测。

## 候选模型

在源热电出力为正的小时上，用严格CN5历史特征预测煤、气、油、其他四份额。模型为带截距的多输出线性softmax；以燃料占比作分数响应，最小化加权交叉熵准似然与L2系数惩罚。训练权重按国家、统计区、小时平衡；`StandardScaler`只在当前源训练折拟合。候选正则强度固定为`α∈{0.01,0.1,1,10}`，没有目标侧调参。

softmax确保预测组成非负且和为1，固定燃料EF计算火电有效因子，再乘与比例重组、现有fuelshare HGB相同的源国热电小时形状。与现有四个独立HGB份额头的差异限于组成响应函数与损失，不改变目标输入、小时形状或燃料因子。

## 嵌套选择与对照

每个外层训练国集合中，逐国作为伪目标：其余国家2022训练，伪目标仅用同一CN5输入预测2023H1；以伪目标国家等权小时CIF MAE选择`α`。选中后用全部外层来源国2022重训。2023H2同源跨拟合校准90%半径，独立于H1模型选择。

固定配对参考：比例重组、标量火电因子HGB、现有四头fuelshare HGB、700锚。所有预测点和校准半径先封存并核验，再读取所有外层2024小时响应评分。

除了小时CIF MAE、日内形状MAE、覆盖、宽度、区间分数，还在评分后报告目标燃料占比MAE、预测热电有效因子MAE及各燃料份额误差。这些仅是目标标签上的机制诊断，不能进入选型。

## 晋级/停止

候选须在宏点误差或proper interval score上有跨目标国稳定改善，最差域不显著恶化；区间覆盖不得靠加宽取得。若只改善组成误差却不改善小时CIF，或嵌套选择频繁选不同`α`且外层收益不稳，就关闭这条函数形式搜索，不扩展到未查看国家。

组成数据的log-ratio回归、Dirichlet回归和softmax链接已有成熟方法；这类函数形式本身不是创新。[Van den Boogaart et al. (2021)](https://link.springer.com/article/10.1007/s11004-020-09895-w)总结了组成响应回归的log-ratio方法；2026年提出的ridge-penalized Dirichlet regression也采用softmax约束均值处于单纯形。[Nigri (2026)](https://onlinelibrary.wiley.com/doi/10.1002/sam.70062)。本实验只判断简单、协调的组成头能否改善跨域燃料响应。
