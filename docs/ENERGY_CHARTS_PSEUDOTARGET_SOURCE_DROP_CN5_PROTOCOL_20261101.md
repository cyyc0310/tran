# 严格中国五类输入下的伪目标源贡献筛除协议

冻结日期：2026-11-01。沿用[严格五类九国LOCO合同](ENERGY_CHARTS_NINE_COUNTRY_CN5_PROTOCOL_20261101.md)，只检验源端伪目标能否识别比例重组中的单个负迁移来源。

公开输入仅为火电、水电、核电、风电、太阳能五类月发电份额及日历；`other_renewable`不得参与份额归一、历史特征、来源形状参考或目标预测，只保留在小时标签的总发电量分母中。小时响应仍为固定因子生成侧代理；月量由修订小时序列回算模拟`t−2…t−7`，不是历史as-issued月报。

九国逐一外层留出。对每个目标，其他八国为源集S。源端H1按伪目标国`p`留一，比较用`S\{p}`与`S\{p,d}`拟合比例重组预测p的配对MAE；对每个候选来源d，汇总所有p≠d的目标国等权变化。只剔除平均改善最大的一个来源，若其平均MAE变化非负则保留全部来源。月误差在每个伪目标内等可用月加权。

区间用H2交叉拟合校准；校准目标国不得参与相应模型的训练或剔源选择。与全部源比例重组、anchor700相同测试小时配对比较。所有点预测与半径先哈希封存，之后才读目标2024标签。以MAE、去日均形状误差、90%经验覆盖、宽度及区间分数评价，不宣称有限样本国家级覆盖。九国均为开发域，不是最终确认集。
