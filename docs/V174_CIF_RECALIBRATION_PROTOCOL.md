# V174：源地区嵌套OOF的CIF再校准强对照

2026-10-29，Sol，新增CIF评分前冻结。动机来自V171–V173：燃料零事件预测改善没有形成足够的CIF收益。本轮直接学习CIF分布的普通再校准，不宣称原创，也不等同于复现2025论文的CRPS优化器。

## 合同和嵌套隔离

沿用V159固定29源六折、2024 asof_30d，每proper源相同≤4096原始小时，241校准月/241测试月，不打开新地区或2025。外折proper内部按SHA256(`v174/inner/`+region)排序再模5，逐组重建物理活动prior和Gaussian粗模型，训练地区与该组标签地区完全分离。每个标签只读取已固定采样小时；源月统计仅来自内部训练地区及查询已发布prefix。不复用可能含外折cal/test小时的全局OOF预测。保存每个样本的raw/profile/region/inner fold和基模型训练地区。

内部OOF只是共享2024时间的地区隔离，不是时间向前验证。内部基模型通常15/16地区，最终外折19/20地区，训练风险和部署风险可能有样本量差异，须在结果中保留。模型选择仍是已反复查看的源开发，不能用此轮描述范围作独立确认。

## 固定方法

两个原基础law：conditional_activity_recomposition/world_gaussian。每个基础law各比较全局PIT映射、20维条件PIT森林、43维条件PIT森林，强度α=.5/1，共12新方法+2原参考。43维为原20维+已发布历史的23维增量，沿用V171定义。32棵ExtraTrees、min_samples_leaf=64、max_features=1、seed20261028、地区等权，多输出共同叶，不为燃料/地区挑模型。

PIT网格固定为[0,.005,.01,.025,.05,.1,.2,.3,.4,.5,.6,.7,.8,.9,.95,.975,.99,.995,1]。对离散预测law和源观测y，计算L=F(y−)、R=F(y)。L<R时，训练标签为Uniform[L,R]的CDF在内网格的值；L=R时用该点PIT的CDF。两端固定0/1。标签向量单调，共同叶加权平均保持单调；全局映射为地区平衡平均。只为计算训练PIT，若y距最近原支持不超过tol=64eps×max(1,|x|,|y|)，把[y−tol,y+tol]内的近等原子视为同一数值峰，取该窗口的左右累计质量，记录相对严格单原子PIT的变动数；没有近支持时保留严格点PIT。正式CIF严格及ULP64评分不改变。

对每个预测state原子累计概率c_i，重校准权重为ΔC(c_i)。最终权重=(1−.95α)p+.95αΔC，保证原支持有正权，所有原CIF取值保持。恒等映射必须精确返回原law。该规则允许改变预测均值；不声称月报路径一致或目标覆盖保证。只重分配已有支持，不能生成支持外CIF取值。以辅助记录保存OOF支持外/命中峰值比例及预测前后均值/90%宽度变化。

每方法报原基础law固定半径/自身重校准，pooled/max_region，两参考只用自身重校准；每测试月52记录，总12,532评分。原964参考记录须复现。完整gate、29/24源、CRPS/Winkler/宽度/最差覆盖不变，比较V159标量、V160 MMD、V164组成/熵、V165异方差以及V173最佳新方法；有覆盖不等于效率增量。

## 执行和审计

先运行无held-CIF评分的代数预检和六折嵌套OOF归档，再拟合映射并完整评分。正式评分前固定代码/采样/协议/OOF归档哈希。OOF归档阶段未拟合最终映射、未读取外折cal/test小时标签；仅有诊断性训练PIT汇总，不据其选择网格/强度。保留源逐样本PIT、训练来源、legal prefix及输出哈希。所有预测先于对应外折观测的评分读取。

完整审计重拟合映射、重建校准与所有评分、检查物理支持/正权/映射单调和身份、未来粗量扰动。OOF所有样本身份、PIT标签独立向量化公式、全部来源隔离和哈希必须核验；内部基模型全量重拟合重建PIT才可称完整OOF重建，抽样须明确范围。继承的物理/评分辅助函数不是独立算法。

已有[PIT映射及CRPS再校准，Technometrics2025](https://www.tandfonline.com/doi/full/10.1080/00401706.2025.2464004)、[概率回归再校准，ICML2018](https://proceedings.mlr.press/v80/kuleshov18a.html)、[密度再校准，ICML2022](https://proceedings.mlr.press/v162/kuleshov22a.html)。本轮经验PIT-CDF多输出回归仅是普通强对照；若有增量，再与直接CRPS优化映射及同预算历史异方差/分位数控制比较，不能因此直接推进论文原创或未查看地区。
