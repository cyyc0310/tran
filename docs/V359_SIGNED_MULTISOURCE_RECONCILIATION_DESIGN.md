# V359设计：把来源间有符号技术差传播进CIF小时风险集合

状态：首轮联合LP已实现并完成河南单省探索；见[V359结果](V359_SIGNED_MULTISOURCE_RECONCILIATION_RESULTS.md)。由V358河南2024发现触发。研究问题不是再给一个非负残差组，而是：当两套公开来源对同一省月的技术分项不一致、且一部分差为负时，能否用透明的多源可行集合计算小时风险集合，并诚实传播来源不确定性？

## 经验动机

河南2024 NEA减NBS月分类的年差向量为（水、火、风、光）`(+0.797, -8.614, +7.809, +35.782) TWh`，净差`+35.774 TWh`。因为火电差为负，净差不等于一个物理上可解释的“缺失发电”组。V358通过加入净差仍缩窄集合，但单组假设掩盖了分类错位，尤其是太阳能来源差异。

## 候选信息集合

对每个地区/期t、技术g，令两来源分类为`a[t,g]`（NBS）与`b[t,g]`（监管月报），候选敏感性支持设为

`L[t,g] = min(a[t,g], b[t,g])`, `U[t,g] = max(a[t,g], b[t,g])`。

潜在同口径分类边际`x[t,g]`满足`L[t,g] ≤ x[t,g] ≤ U[t,g]`、`x[t,g] ≥ 0`，且`sum_g x[t,g]`落在独立监管总量的舍入带内。该盒区间只是一种“真值位于两来源间”的压力假设，不是统计置信区间或已证实覆盖带；至少还要报告围绕`[L,U]`按组扩张的敏感性、放宽总量锚及无总量锚版本。

V358原来的“净残差unresolved组”保留为对照臂。其他对照为纯NBS技术边际、纯监管技术边际及监管总量＋NBS分类边际。所有臂使用同样小时数、滞后装机、EF支持和目标阈值。

## 锐集合计算方向

固定风险小时数K和EF端点后，每组落在事件小时中的能量可行范围为

`lo_g(x)=max(0, x_g-(H-K)c_g)`, `hi_g(x)=min(x_g,K c_g)`。

V342通过各组EF相对阈值的符号，从`lo/hi`计算能否实现K。要对多源不确定的`x`仍给锐界，不能只把`L`和`U`各算一次：`lo/hi`在`x_g=K c_g`与`x_g=(H-K)c_g`有折点。候选算法是在这些折点将可行质量盒多面体分片，在每个线性片段上做精确有理数LP/顶点求解，确定是否存在一个合规的`x`和小时分配支持K；严格不等式与零产出边界沿用V342的处理。分别取可行K集合及端点，而非把几种source-run区间简单并起来。

实现`scipy.optimize.linprog`联合LP：同时选择合规技术边际x与事件小时质量e，施加来源区间、总量守恒、逐技术容量、`q·e > 0`和`q·(x−e) ≤ 0`。这绕开逐边际端点枚举，直接检验每个整数K是否存在联合可行配置；严格边界补充检查零超额但非事件小时仍有正发电的情况。求解的严格符号采用1e-7数值容差。12个小型塌缩来源区间交叉检查均与V342固定边际锐解完全一致；这支持实现正确，但还不是一般性形式证明或数值精度证明。

## 预设决策门槛

候选方法只有同时满足以下条件才继续作为论文方法：

1. 在源间误差盒扩大到至少`±25%`及`±50%`后，结论不会由单一窄盒驱动。
2. 在至少两个有完整月度独立总量与技术分项的省份上可复算；发布时点与口径差异有逐行账本。
3. 对τ=300，协调集合相对纯NBS、纯监管和V358净残差三类基线产生稳定的、非退化的信息增量；若只扩大而无预测价值，则只作为风险审计方法。
4. 最终用独立小时CIF标签检验名义覆盖和区间宽度。没有小时标签时不声称预测表现或覆盖校准。

## 当前判断

首轮河南结果没有显示可压窄性：协调K集合在±0来源间盒下等于NEA单源端点宽度，源间区间再扩±25%或±50%后τ300集合退化为所有期均全期宽。它没有通过原先“相对两单源基线稳定缩窄”的门槛；算法仍可作为来源不确定性的透明风险外包络，但不能作为提升预测效率的创新方法。是否值得保留，要看它能否揭示单源选择造成的危险漏覆盖，这必须有小时标签判断。

多源LP相对固定组锐界的增量仍未经文献查重。更可能的论文价值是可复核的数据口径基准/不确定性审计，而非独立新优化算法；后续应优先检索相邻的数据协调、集合识别和排放强度文献，并拓展第二省和小时标签。
