# 荷兰比例重组失效：滞后热电份额和内部因子都有限制

日期：2026-11-01。按[冻结诊断协议](NL_RATIO_RECOMPOSITION_ERROR_DECOMPOSITION_PROTOCOL_20261101.md)分解已查看五国LOCO开发回测中的NL比例重组误差。分析覆盖2024年的8,784小时，只解释既有预测，不据此选择或调整方法。

## 误差分解

NL比例重组使用其他四国2022小时标签估计共同热电有效因子，再以目标当地日历和t−2及更旧粗月组成预测2024小时强度。源热电因子为 **437.1**，NL目标2024年火电量加权实际有效因子为 **478.4**，低估约41.3；目标实际热电有效因子还随月份变化，均值从4月约435.9到12月约542.5。

| 预测/诊断 | 2024 MAE |
|---|---:|
| 完整比例重组 | 75.69 |
| 仅使用可见t−2月热电份额 × 源因子 | 76.53 |
| 替换成目标真实小时热电份额 × 源因子 | 43.29 |
| 预测热电份额 × 目标真实小时火电因子 | 59.39* |

*目标真实小时因子只在热电发电大于零的小时有定义，故该项仅对这些小时计算。

模型预测的小时热电份额与目标真实值MAE为 **0.126**；只用t−2月的份额，MAE为 **0.129**。来源小时模板带来的份额误差改进很小，对完整MAE也只比月份额直乘低约0.8。若把小时热电份额换成目标真值，MAE从75.69降到43.29；若只把源火电因子换成目标真实值，MAE降到59.39。两个oracle替换分别反映可见热电份额路径和不可见内部因子路径的重要性，误差差值不能相加，也不是可部署模型。

月度结果显示4—6月实际热电占比较高，源模板推断偏低；秋冬部分月份目标热电因子较高，使用源单一因子会产生系统偏差。预测输入中的总热电份额不能识别煤/气等热电内部构成，而外部地区学到的热电因子也不能直接刻画NL季节调度。

## 研究含义

1. 荷兰失败并非只因小时轮廓迁移差。以真实热电份额替换后仍有43.3的MAE，燃料内部因子错配仍明显；以真实因子替换后也仍有59.4的误差，粗月统计的时效和小时变化同样重要。
2. 仅在粗组成中添加源模板形状没有解决问题。对这个目标，重组器内的小时模板对总误差贡献有限，继续提高模板复杂度不应作为首选方向。
3. 这支持主线拆分误差来源：目标可见的粗组成水平与滞后、目标不可见的燃料内部火电因子、小时组成形状要分别建模和评分。下一轮应优先测试源端可学的内部因子/季节响应是否能跨国迁移，并与因子固定的强重组对照；任何目标oracle不能进入训练或调参。

以上来自已查看的能源发电固定因子代理和修订后小时序列，不是历史as-issued预测，也不是荷兰或中国实测CIF精度结论。
