# 伪目标小时监督学习粗组成条件预测器门控协议

冻结日期：2026-11-01，启动运行前。目的：区别于伪目标只用于选择已有模型、按组成距离混合专家或重加权样本，直接用整国伪目标小时标签训练一个只依赖粗月公开信息的条件堆叠器。当前五个Energy-Charts国家均已查看，因此这是机制开发回测，不是新国家确认。

## 外层任务与样本

- 五国逐一外层留出，目标国家2022—2024小时标签不进入训练、门控选型、区间校准或参数选择。
- 外层源国使用2022小时燃料标签训练八种固定预测器；目标输入只用当地日历和预测月t−2及更旧的火、水、核、风、光及其他可再生粗月份额。历史月量由修订小时序列回算，只模拟中国可见时滞，并非as-issued历史发布。
- 外层源国再逐一做内层伪目标。对伪目标c，八种候选模型只用其他外层源国的2022小时标签拟合；在c的2023H1公开粗月特征上推理。c的小时标签仅作为训练期查询结果，用于元门控拟合。
- 伪目标2023H1的交叉拟合预测和小时标签训练门控。之后在伪目标2023H2预测上估计各固定基线与门控的来源国等权90%对称区间半径。最终八个基线模型用所有外层源国2022小时数据重训，门控仅用粗组成条件权重组合其预测，生成外层目标2024预测。
- 全部五个外层目标预测先写盘封存，之后才读取目标标签评分。

## 门控方法与基线

八个专家是现成`multicountry.fit/predict`的`anchor700`、`macro_recomposition`、`ratio_recomposition`、`ridge_history`、`direct_latest`、`direct_history`、`factor_latest`、`factor_history`。门控输出对八个小时预测的凸组合，权重为粗统计特征的线性函数softmax：六个当前粗类别份额及其已有的火电历史均值、标准差、变化、总量变异和观测数；不输入国家ID、目标小时标签或目标细燃料。

岭惩罚只在伪目标内层源国折上从冻结网格`{0.01, 0.1, 1, 10, 100}`选择，优化评价按伪目标国家等权MAE；最终在所有外层源国伪目标H1预测上拟合门控。基线包括八个原模型、八模型等权平均、仅有全局固定权重的凸堆叠，以及伪目标内层选出的单一模型。所有方法使用相同预测行和2023H2源区间半径合同。

## 评分与解释

报告逐国/逐月MAE、日内形状MAE、90%覆盖、区间宽度和区间评分；国家为外层统计单位，不能把小时或训练随机性称作新增国家。任何门控增量必须超过比例重组、伪目标模型选择、简单凸堆叠及此前的粗组成距离专家门控，并在多数外层国家保持覆盖和区间效率，才值得继续。此方法属于可学习的跨域堆叠候选；一般stacking、mixture-of-experts或组合权重本身不构成原创性结论。
