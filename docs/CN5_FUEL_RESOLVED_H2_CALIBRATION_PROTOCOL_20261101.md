# 燃料组成响应头的H2源伪目标校准敏感性协议

冻结日期：2026-11-01。本轮只改变区间半径估计：保留已封存的CN5燃料组成响应头点预测，比较2023H2整国交叉拟合残差与原2023H1池化半径。由于r1点预测和2024目标标签已查看，本轮明确是**事后开发敏感性**，不作独立确认、不用于回写r1或盲区晋级。

## 目的与固定项

检验r1中火电组成响应头的点增益在更接近目标域校准的源伪目标半径下，能否维持区间效率并提高覆盖。r1的训练特征、2022源训练、严格五类预算、所有2024逐点预测及方法定义全部固定，不重新拟合外层目标点预测，不按目标覆盖挑模型或半径。

## H2交叉校准

对每个外层目标国，其他八国为源集。对每个校准伪目标国`p`：用其余七国2022数据训练所有基线与燃料组成头，只用`p`的2023H2五类特征预测，并以`p`的2023H2小时代理标签计算残差。每个伪目标从拟合和自身校准中排除。各方法使用相同八个伪目标及国家等权90%绝对误差分位数。由此得到的半径再应用于原r1已封存2024点预测。

比较相同方法的H1 pooled及H2 cross-fitted半径、小时池化覆盖、宽度、区间分数及逐国逐月风险。所有2024标签均在r1已打开，因此数字只作校准方法诊断，不能称作预注册性能或新地区验证。即使覆盖恢复，也须报告跨时间/国家数量不足以支持有限样本整国90%保证。
