# V290后的创新缺口：月度信息约束下的可信小时CIF

本记录结合V289/V290结果、用户确认的中国信息预算（公开月度/年度逐类发电量）及近期方法文献，判断算法增量边界。它是定向核查，不是系统综述，也不构成正式新颖性检索意见。

## 已知证据如何改变方法路线

V290显示，把本地风险校准从9个完整日增到12日，可使PACE/LGEE 2020–2023开发队列中滞后EF支持分支的96个BA-month重复均值全部跨过90%，但宽度上升3.50%、Winkler上升3.01%。18日下，单纯上一年EF支持也跨过全部月均门槛，且区间略窄。因此：

1. 月内局部风险信息有明显覆盖价值，但收益可由更多本地小时标签获得，不能归功于新风险传播算法。
2. EF漂移更新与小时形状尾风险是两种不同不确定性；在校准预算增加后，EF更新的独占增量更小。
3. 中国当前确认的逐类月度/年度发电量没有本地小时残差标签。因此V290在中国预算之外，只能报告信息价值，不能作部署方法。
4. 若未来只能拿月/年统计，应该直接量化月度构成对月均/加权水平的约束，并把小时形状和阈值尾数作为未识别或源迁移预测部分；报告可识别集合和预测分布，不能把后者缩窄伪装成前者识别。

## 已有文献排除了哪些“容易命名成创新”的点

- Gibbs与Candès的在线自适应共形方法已经处理任意分布漂移，并给出局部时间窗口regret；他们也讨论何时应快速减少历史分数权重。[JMLR 2024](https://www.jmlr.org/papers/v25/22-1218.html)
- Wu等人的ECI使用非覆盖误差的连续反馈调阈值，证明任意依赖和分布漂移下的长期覆盖，并报告比若干基线更紧区间。[ICLR 2025](https://proceedings.iclr.cc/paper_files/paper/2025/hash/cab5ae2704d3e01f06a92512a5376b87-Abstract-Conference.html)
- Ostermann等人已经对德国generation-based CO₂强度做区间forecast、walk-forward验证，并比较SARIMAX、树模型和神经网络。[Energy Informatics 2024](https://link.springer.com/article/10.1186/s42162-024-00303-9)
- 项目自身V9、V14、V25已经覆盖月粗预测、供体条件化、组成重组、源形状传播和匹配概率参考；近期Puffin等聚合解聚工作也表明“聚合守恒＋学习细节”不是独占新概念，且很多方法在校准阶段仍用细粒度验证标签（见[V25文献核查](V25_LITERATURE_UPDATE.md)）。

所以以下单项不能独立作为方法创新：滚动/在线共形；目标支持范围扩展；多频/小波分解；源加权或相似度门控；简单条件分位数；比值/燃料重组；将小时误差乘以粗误差尺度。

V291另核查了看似可用的GB区域小时源：NESO区域API历史返回`intensity.forecast`及模型生成的区域generation mix，没有独立`actual`字段；区域方法用模型预测和网络潮流估计消费侧因子。因此它不能充当跨系统真实标签盲测，最多可作为待归档的运营预测基线。该审计进一步表明：数据量/区域数看起来充足，并不等于有适合验证冷启动预测的独立标签。

## 目前仍有价值的研究空间

真正值得继续争取的是**统计时效与类别信息预算受限时，跨区小时CIF预测何时可识别、何时可校准、何时必须拒答**。潜在贡献可由三个耦合对象构成：

1. **口径和时点的可用信息schema**：各类月度/年度发电量、可推导的分母、有效发布时间/修订、煤电/火电类别边界、缺失及未覆盖源。用同一个统一benchmark合同复现M8/MG/YG等真实信息预算，不将当前修订版回填成当时可得。
2. **可识别粗水平集合**：在类别EF区间、统计误差和不同生成/消费估计对象下，求严格可行的月/年加权强度区间。该区间只表达字段本身能识别的部分；其宽度随燃料分组、EF精度、月/年频率变化。
3. **小时风险预测和条件拒答**：在识别集合之上单独加源端小时形状模型；对可迁移假设、分布漂移和区间覆盖作条件诊断。仅当源域信号能证明某类目标仍有支持时发布小时概率预测，否则输出未识别范围/弃答。方法必须胜过相同信息预算的简单月锚、源条件动态、location-scale/EMOS、QRF/条件分位数，以及ACI/ECI式顺序校准（若允许本地顺序标签），并在目标信息时间点严格合法。

这里最可能的算法增量不是“更聪明地恢复隐藏小时路径”，而是**把粗统计识别集、源模型预测不确定性和目标漂移/支持诊断组成一个可校准的选择性预测器**，并证明其在相同信息预算下能够缩短有效区间或减少错误发布，同时维持覆盖。V290并没有做出该预测器；现有拒答门控V277–V278也没有达到90%覆盖，不能继承为成功机制。

## 对论文价值和投稿层级的判断

- **有价值的问题**：是。只拿合法月/年公开发电统计时，跨地区小时CIF可信度和可识别边界有清晰的气候/电力调度应用价值；中国数据版本和统计边界本身也影响复现。
- **目前算法创新是否足够**：否。V289/V290是强诊断而非原创方法，V290增量来自新增目标本地小时校准日，且超出中国预算。
- **可形成论文的最低路径**：一个真实信息时点schema + 统一粗到细基准 + 可识别集合/明确失败门槛 + 多地区/多年份可靠性与强概率基线。若只能拿公开月/年粗数据而无小时目标标签，论文需定位为信息价值/benchmark/部分识别研究，不能称小时覆盖已被验证。
- **更高投稿层级的门槛**：必须有方法上不可被标准ACI/ECI、概率协调、QRF/EMOS或鲁棒集合预测替代的独占增量；有独立系统/时间外确认；并公开可复现数据合同。中国若没有合法连续小时CIF标签，可用真实公开月度数据展示低频任务，再用独立海外小时真值做严格“下采样信息预算”外测，清楚分开两类证据。

## 近期建议

暂停继续调PACE/LGEE的EF范围或日预算。下一项应回到只含月/年字段的实际预测比较：用同一真实历史月度分项，比较简单能量加权锚、标准动态月状态模型、细分/合并schema及年度-only回退；小时标签只作最终外部评分，不进入目标特征、调参或校准。若想检验小时覆盖，必须承认那是外部小时真值benchmark而非中国当前可观测输入。方法创新闸门要放在模型拟合之前冻结，至少要求相对完整普通概率基线：合格覆盖下CRPS与区间分数稳定改善、宽度不增、跨BA/year无单区崩溃，并在从未参与开发的地区或新系统确认。
