# V243 结果：能量归一化只增加一个最优端点

协议：[`V243_SCALED_MILP_THRESHOLD600_PROTOCOL.md`](V243_SCALED_MILP_THRESHOLD600_PROTOCOL.md)。脚本：`scripts/v243_scaled_threshold600.py`。输出：`results/v243-scaled-threshold600-r1/`。

把同一BA-month的逐小时量、逐日量和燃料月边际全部除以当月总发电量，其他MILP合同、阈值600、EF及30秒时间限与V242一致。64端点中54个最优（84.4%），比V242绝对MWh变量的53/64多一个；完整证明配对仍为8/16。两个尺度共同最优的53个端点上，整数K边界53/53完全相同；完整配对平均界宽也完全相同（日界726.6小时、小时界566.8小时、收窄159.9小时）。

求解总CPU时间约387秒；端点平均6.05秒（中位数0.11秒，慢端点30秒）。主要耗时来自10个达到时限的最大化端点。由此没有证据称变量缩放能实质改善阈值600的可证明率；当前结果是计算工程稳健性检查，不是科学创新。标签继续为固定EF代理，已证明配对只有8个。
