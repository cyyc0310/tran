# V244 冻结协议：阈值侧解析筛查能否精确保留界限并跳过MILP

日期：2026-10-30。沿用V240的16个完整BA-month、500阈值、EF±10%盒和(hour-varying)外包络。

## 算法

对月燃料组边际`M_g`先计算名义月均`μ0=Σ_g EF_g M_g/Σ_g M_g`。正EF组按共同相对半径`r=10%`扩展，零EF组保持0，因此EF盒的月均范围为`[μ0(1-r), μ0(1+r)]`。

若下端`< 500.0001`且上端`≥ 500.0001`，按阈值侧不识别命题直接返回日总量与小时总量下的`K∈[0,H]`，不运行MILP。其余案例按V240相同MILP求端点。

## 预注册成功判据

- 每个BA-month、每个信息条件的最小/最大端点须与V240完整MILP结果逐项完全相同。
- 所有解析案例都必须由比例分配构造并证明守恒；所有实际固定EF尾数见证保持包含。
- 记录解析跳过端点数、MILP调用数、墙钟和求解时间；报告时间节省为本次实测值，不假设线性外推。
- 若任何端点不一致，算法失败；本轮不是预测覆盖评估。
