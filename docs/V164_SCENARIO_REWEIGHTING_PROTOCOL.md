# V164：粗月度预测约束供体情景概率

本协议在新小时评分前冻结。仅V159既定29源、六折、2024、asof_30d预算；相同proper/calibration/test地区及每源≤4096已选小时。不打开2025目标或未查看地区。同月分支不改，完全等于原重组；本轮仅研究合法滞后预算。

## 预测与概率语义

用V161的13维base特征、proper地区可发布历史构建月度训练样本，ExtraTrees32棵、min_leaf4、seed20261028、地区均衡，预测当前月能源锚相对过去锚的增量。若输入月正份额燃料具有同一EF，则沿用已在V161检验的过去锚点回退。这是点预测控制，不限制未来燃料支持。相同配置另训八维份额增量森林，截负后归一，作为普通“预测组成再重组”控制。

供体为每proper源两个最近日历月份，延续V159。S为目标最新已发布组成，B=.99S+.01π；供体输入B_d同样定义。情景月组成比例a_d=B*S_d/B_d，情景能源锚A_d=(a_d·EF)/sum(a_d)。只使用proper供体的粗月统计；其未来相对于该供体预测起点的粗统计是源训练结果，不能读取目标查询当前月统计。

情景先验p_d沿用条件活动重组，以供体过去组成与S的Hellinger距离、带宽.3计算。约束对象是Σp_d A_d，即不同月世界的能源锚均值，不是ΣE/ΣG的跨世界规模加权比值。每个情景内的小时燃料活动和CIF取值完全保留。有限抽样小时不承诺精确实现完整源月能源边际。

冻结七臂：

1. positive_recomposition：原形状持平，精确复现。
2. conditional_activity_recomposition：原条件动态活动，精确复现。
3. forecast_affine：对条件动态分布平移Ahat−过去能源锚，裁[0,1000]；普通简单锚定控制。
4. forecast_composition：用八维预测组成，按供体当前组成距离重组原燃料形状。
5. world_entropy：最小KL(q||p)，令ΣqA_d接近Ahat；目标超出情景凸包时裁到凸包，记录残差，不伪造支持。
6. world_entropy_cap：同样熵方向，但KL上限固定0.1 nat；不按评分选择。
7. world_gaussian：p_d乘exp(−(A_d−Ahat)^2/(2σ²))。σ为proper地区按地区分组五折OOF月度锚预测误差的地区等权RMS，下限1g/kWh；OOF内独立重训，回退规则相同。

熵指数λ在标准化锚范围[-512,512]求解，log权重减最大值后最小指数−700防下溢，70次二分；KL cap也70次二分。记录未达约束、凸包裁剪、KL、有效情景数等。没有本地小时标签进入预测或超参。

所有臂各自用相同calibration地区、相同V159 pooled及max_region半径规则校准；不得沿用对新模型更有利的旧半径。先生成校准CDF再读校准小时标签，只用于半径。test的小时标签只用于评分。输出严格/ULP64覆盖、两侧漏盖、CRPS、宽、Winkler。两原重组482×2=964条五指标复现旧归档≤1e−7；月度锚预测在241个test月份复现V161的forest_base及既定回退。每折两个查询做未来粗统计扰动不变性检查。需核查所有情景来自proper且全是2024。

评价按地区小时加权再地区等权，同时保留非固定EF的24源子集。比较V159标量锚定森林、V160一般MMD等已冻结强参考，完整报告覆盖与宽度，原gate保持。此为可部署候选的源区筛查；源共享2024时段、合成发布滞后、固定EF代理等限制不变。普通熵预测更新已有长期文献，不以其本身声称创新；仅在出现稳定、可归因增量后才考虑专门机制和真正未查看地区。

参考：[Forecasting Using Relative Entropy, Robertson等](https://users.nber.org/~confer/2002/si2002/tallman.pdf)；[UAI2024概率协调](https://proceedings.mlr.press/v244/zambon24a.html)。后者研究线性聚合协调，并不直接解决本研究的比值、月世界权重和零本地小时迁移问题。
