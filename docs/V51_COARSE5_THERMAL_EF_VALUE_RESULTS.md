# V51 五类粗月报下火电内部有效 EF 的条件价值

## 结果

对 7 个已查看源 2025H1 中有月度标签的37个源区月，将煤、气、油、other 合并为代理 thermal，水、核、风、光分别保留；留出源逐月只用上一年同月已发布的五类总量。小时形状由其它六源 2024 同月训练。跨源火电因子是 donor 2024 同月火电内部能量加权 EF 的等源均值。

| 预测月总量信息 | 火电组内 EF 信息 | CIF MAE | RMSE | bias |
|---|---|---:|---:|---:|
| 合法上一年同月五类总量 | 跨源火电 EF | **57.53** | 66.52 | -9.21 |
| 合法上一年同月五类总量 | 目标区上一年同月火电 EF（合法滞后） | **34.93** | 43.61 | -3.37 |
| 合法上一年同月五类总量 | 目标月火电 EF oracle | **34.78** | 43.20 | +4.21 |
| 目标月五类总量 oracle | 跨源火电 EF | **56.74** | 65.82 | -11.81 |
| 目标月五类总量 oracle | 目标区上一年同月火电 EF（合法滞后） | **32.60** | 40.82 | -6.32 |
| 目标月五类总量 oracle | 目标月火电 EF oracle | **31.18** | 38.80 | +0.92 |

上表按37个配对源区月直接等权。按来源先求均值、再给七个来源等权，六种 MAE 依次为57.91、35.29、35.13、57.45、32.83、31.38 g/kWh；方向和量级一致。由于 ISNE 仅2个月、MISO 5个月，其余来源6个月，报告来源等权敏感性以避免月份多的来源取得更多宏权重。

37个配对源月上，单独提供目标月火电组有效 EF 的 oracle，跨源火电因子 MAE 下降约39.5%（来源等权下降约39.3%）；同时把五类月总量换成目标月真值，仅在使用跨源火电因子时，MAE 下降约1.4%（来源等权约0.8%）。更关键的是，目标区上一年同月火电 EF 可从 as-of 报告合法计算：它的 MAE 为34.93，接近目标月 oracle 的34.78；按来源等权为35.29 vs 35.13。若目标月五类总量和火电 EF 均 oracle，误差仍为31.18（来源等权31.38），说明小时形状及小时内火电组因子变化仍留下显著误差。目标月 oracle 只量化条件信息价值；上一年同月 EF 才是合法预测输入。

## 跨源收缩检查

事后用网格 `alpha∈{0,.25,.5,.75,1}` 混合 donor 火电 EF 与目标区上一年同月 EF，并为每个目标源用其余六源的来源等权 MAE 选择 alpha。七个外层都选 `alpha=1`。外层汇总等源 MAE/RMSE 为35.29/44.31，donor-only 为57.91/66.65，等同于合法本地滞后标量。该检查说明在这七源样本里，跨源收缩没有提供额外价值；测试是后验探索、2025 源和标签早已看过，不能当独立确认或超参数冻结。

相同37个源月上的既有逐燃料上年同月＋逐燃料气候形状基线，来源等权 MAE/RMSE 为39.93/49.42。本次五组小时形状＋合法本地热组 EF MAE/RMSE 为35.29/44.31，差异主要由MISO改善（76.18→51.61）；ERCO也改善，ISNE略微恶化。虽然基线拥有相同上年详细月报信息，小时模型结构不同，因此这是可复核的整体模型对照，不是单独归因于 scalar 的严格消融。按严格 matched 信息增量，donor EF→本地滞后 EF 的同形状消融才是主比较。

MISO 的源级 MAE 从跨源火电因子时约153.60，降至目标月火电 EF oracle 时约46.02（合法五类总量不变）；CISO、FPL、ERCO也有下降，但收益幅度不一。这个模式与 V25 已见的 MISO 隐藏组内水平超出源支持线索相呼应，仍不能据此断言因果机制已确认。

## 研究判断

这是当前最具体的最小本地信息候选：月度类别总量之外，获取目标区**月度火电内部能量加权因子**，或足以计算它的煤/气/油/生物质/其他发电分项，可能比把最近风光形状输入 CIF 模型更直接地解决地区水平失配。月度类别总量 oracle 对本例帮助小，火电组内 EF oracle 帮助大；但这里是固定 EF 的 EIA 类代理和已查看美国源，不是中国数据验证或可部署方法。

可行创新方向因此是“低频粗类别约束 + 最小组内标量监督下的水平/小时形状风险分离”，而不是再换一个小时天气函数。算法突破尚未成立：本轮以 oracle 做条件价值诊断，未提出能仅凭用户当前粗字段可靠预测目标火电 EF 的机制，也没有计算覆盖保持的预测区间。若中国月报只给火电合计，该 EF 仍不可从这些列识别；只有满足口径一致的内部分项或独立公开因子时才可计算。若用户可得煤电、气电等类别，则应先在同一统计边界下计算该 scalar，并保留燃料因子和范围不确定性；年度 scalar 也不得复制成每月已知值。

oracle 两项均不能宣称预测得分、区间覆盖或新地区增量。随后应先检查用户原始字段是否足以构造该组内标量；如字段可得，再做严格发布时点合法的前瞻模型，和简单年度/上一年锚、标准回归、异方差及条件分位数比较，并报告覆盖、宽度与区间分数。若 scalar 无法由实际字段计算，则应把火电组内水平作为不可识别维度，扩大识别集合而不伪造点值。
