# 留区伪目标风险校准：区间变宽，未改善强重组基线

运行：`results/crossfit-domain-risk-calibration-r2/`。按[预测前协议](CROSSFIT_DOMAIN_RISK_CALIBRATION_PROTOCOL_20261101.md)在US→GB已看目标上做机制开发。GB 2024小时标签已在此前工作中查看；本结果不是盲测或新国家确认。

## 设计

以美国七个BA作为伪目标，分别留出一个BA的2022小时标签训练模型，用留出BA的2023误差形成外样本源端校准；另比较全七BA训练、同BA下一年校准的普通时序做法。模型包括月报HGB（M）、月报加年度化石热耗HGB（M+H）和固定EF强重组。点中心偏差与风险半径分别取自普通时序校准或留BA校准，构成事后全因子诊断。所有预测先写盘并封存，再评分。

留BA偏差修正将两个HGB的GB MAE从约75–84降到约58，但这一校正来自七个美国BA的跨区均值，目标本身此前已看，不能解释为外部可迁移收益。与此同时，留BA pooled半径相对各自时序半径：M由121.9升至207.6，M+H由93.8升至303.1，固定EF由140.2升至165.7。M+H留BA最差地区半径进一步达到398.4，导致区间分数明显变差。

在这次已看GB回放中，固定EF强重组的时序校准区间分数302.92优于所有对应留BA校准配置。留BA半径让覆盖接近或超过90%，但宽度和区间分数没有形成优势；更保守的“最差BA q90”半径一律明显过宽。M+H中心配M的留BA半径可达到92.0%覆盖，宽度243.82、区间分数280.31，但它是目标已看后的交叉组合，且HGB中心存在较大的源端校准敏感性，只能作为后续可证伪候选，不能晋级或冻结。

## 研究判断

1. **中心校正与风险尺度必须分开估计。** 同BA时序残差和真正留BA残差给出非常不同的HGB偏差；把区间校准残差直接当作中心校正会混合两个问题。
2. **源端整区留出风险更保守，但不自动更有效。** 留BA q90提升覆盖，同时显著扩大区间；对本目标和强重组而言，区间分数没有改善。
3. **没有可信预测增量。** HGB的低MAE中心结果来自已看目标上的事后偏差来源比较；留BA区间的覆盖收益主要由明显加宽带来。当前不构成新算法证据，也不足以支持“覆盖下缩窄”。
4. **停止继续扫描偏差/半径组合。** 下一步回到中国可用信息预算的逐级比较：M月度技术发电统计、M+C年度装机、以及有煤/气细分国家的M+C+FG上限；同小时配对比较强重组与简单锚。年度装机结果是信息预算增量评估，不预设其为新算法。现有跨国装机结果已显示简单煤/气容量形状锚在Energy-Charts开发队列有收益，但官方消费侧EIA-923配对结果没有稳定正增量；两条标签轨道须分别报告。
