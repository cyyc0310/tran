# CN5整国最大残差区间代价诊断协议

冻结日期：2026-11-02，运行前。本轮继续优先级4，检验“以校准国家/地区为样本单位”的最保守简单区间，能否在外部域保持覆盖且不过度牺牲效率。该协议只作开发诊断：法国2024目标标签此前已在燃料组成确认中打开，因此不是盲测或新增确认。

## 固定数据与预测

- 标签：Energy-Charts五类固定因子发电侧小时代理；输入严格五类CN5，月量由当前修订小时值滞后`t−2…t−7`重算。
- 源伪目标：NL、ES、BE、AT、SE、CZ、SK、HU、SI；各用2022训练，留出单个国家的2023H2做源端校准。
- 外部目标诊断：FR 2024-03至12，共7344小时。该目标已在2026-11-01结果中评分；本次复用同一封存点预测，绝不重训后挑选结果。
- 中心仅比较冻结的`ratio_recomposition`、`factor_history`、`fuelshare_history`三种强结构方法。

## 两种半径

1. **小时池化q90：**复用九个源伪目标的国家等权90%绝对残差分位数，代表此前主报告使用的边际经验半径。
2. **源域最大残差：**每个源伪目标分别计算2023H2全体合格小时的最大绝对残差，再取九个国家最大值，作为FR整段诊断半径。该值是样本中的最坏源国，不作有限样本90%保证：九个来源、模型训练规模差异、跨国可交换性和FR口径差异均不足以支撑保证。

使用同一对称区间中心，计算月等权和小时池化的MAE、90%覆盖、全宽与Winkler分数；额外报告FR整段7344小时是否全部被覆盖。整段覆盖比逐小时边际覆盖更严格，不得把两者混写。

## 决策门槛

本轮没有晋级门槛可以把事后FR开发结果升级为确认。只作方法筛选：若最大残差半径并未覆盖FR整段，说明它也未解决跨域支持；若整段覆盖成立但宽度比小时q90增加超过25%且Winkler未改善，则关闭“裸域最大残差”路线，不按FR重调。任何复用都必须在未来从未查看的国家/时间窗重做。

## 防泄漏及证据

先验证源与FR输入/代码/既有预测封存哈希，再生成逐源最大分数，最后与既有FR已开标签作诊断评分。目标不参与模型、半径或门槛选择。输出包括九个伪目标的逐法最大分数、半径来源、FR逐法区间分数、代码/输入/封存预测哈希。
