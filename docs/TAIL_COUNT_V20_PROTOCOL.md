# V20A：粗信息能排除哪些超标小时数

2026-10-26，Sol。正式运行前冻结的同期历史识别诊断。它不训练预测模型，不给未来概率覆盖，不触发目标或未知地区测试。

## 固定对象与队列

沿用已封V19七源2024H2的完整有效UTC日mask，共1000地区日；不重新按效果选地区、日期、阈值。支持C∈[0,1000]，strict事件C>tau，四阈值事先固定为100、300、600、900 g/kWh。只使用四个UTC6h块的H/G及明确新增的G信息。这里H=ΣG*C（不是V17等效能量H除1000的单位），G是八燃料正总量，EF固定[1000,400,800,0,0,0,0,400]。

原CSV已记录的燃料十进制文本以Fraction逐项精确解析，再计算G和H，不先转float。这个exact是针对**记录的十进制代理数据**，不是无误差现实测量认证；也不把它与V19采用float和算术误差区间的数值模型说成逐位相同。timestamps/valid及完整日仍和V19相同。所有fine读取只在隔离源历史oracle提取器内，明确需要这些fine来模拟新增发布内容；没有获取真实发布vintage，没有假定未来真实G或H已知。

## 三个嵌套信息层级

1. **T8**：四块各有H、G；块内G_h仅要求严格正，C_h支持给定。每块可行K集合可精确计算：µ=H/G为0或B时全0/全n；其它情况下K0要求µ≤tau、Kn要求µ>tau，1..n−1均可行。各块G分配自由，结果sharp只针对该H/G/support简化模型。
2. **T8_G2**：另有每块ΣG_h²（共四新增G-only标量）。用总体c²=nΣG²/(ΣG)²−1、有限n均值外界与经典Cauchy/bounded-variance二次条件，求每个候选K的必要可行性。候选均值区间为(K*tau/n, tau+(B−tau)K/n]（K>0），K0为[0,tau]；与有限n界相交，保留开端点，以凸二次最小值精确判断。它是**outer count set**，没有证明存在同时满足全部G/C矩的路径，不称sharp。
3. **T8_G24**：给同口径全部24小时G。每块仅6小时，枚举64个超越集合S。S非空可行当且仅当 `tau*G_S < H <= tau*G_total+(B−tau)*G_S`；S空当且仅当H≤tau*G_total。由连续盒约束加权和得到sharp计数集合。它只含H/G、正G及C支持，不含完整八燃料边际、机组/容量/调度或跨块限制。

每层四块的K集合做Minkowski和，保留完整日K集合及孔洞，不能只存min/max便称所有中间K都可行。要求每块及每日 `T8_G24 ⊆ T8_G2 ⊆ T8`，实际记录的strict K在所有集合内。

相同原始H/G支持下增加信息的比较成立；标量数不是Shannon信息或取得成本。G2不含本地碳标签，但供应方仍需同口径小时G。G24也不唯一确定C或K，这正是待量化的风险歧义。

## 固定输出与核查

每地区日/阈值/层级输出可行K集合、上下端、span、cardinality、point_identified、可认证K0、必有超越及实际K；另输出每个6h块对应行。总12000日行、48000块行、84地区汇总行、12宏汇总行。统计先地区内平均，再七地区等权；完整披露各区天数，ISNE/ERCO缺失较多不能称完整半年。真K只做集合包含与描述，不用于选阈值/信息层级。

独立审查先用合成严格边界、open二次切点、mu0/B、极端G和同观测反例核查；实际产物审计重新核cohort/数值/嵌套/统计，并对每源首末有效日（固定14日）全部块/阈值，以独立max-margin LP核验fullG全部64子集，保留首attempt。LP仅作数值独立核，数学严格端点以有理数推导为准，不用LP epsilon重新定义strict事件。
