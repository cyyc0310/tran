# V70：月总发电规模的跨区尾频率信息价值

日期：2026-10-27。V69未发现全燃料比例或近三月比例相对热组EF的稳定增量。V68全特征树曾包含月发电总量对数，故V70隔离这一合法字段，测试它是否通过系统规模/地区类型与尾频率产生可迁移关联。

## 冻结设置

复用V69的17个既有开发区、合格的100个2026H1区域月、逐目标区留出、月度表period_end+30天发布时间、小时标签月末+30天假设、τ=300/600、相同地区权重和区域聚类bootstrap。ExtraTrees固定100棵树、叶节点12、max_features=.8、seed=68027。不得查看封存区。

## 配对特征臂

1. `ef_calendar`: 最新月热组EF及月份sin/cos（列16,18,19）。
2. `ef_scale_calendar`: 再加最新月总发电量log(1+MWh)（列16,17,18,19）。
3. `mix_calendar`: 最新月8燃料份额及月份（列0–7,18,19）。
4. `mix_scale_calendar`: 最新月8份额、总发电规模及月份（列0–7,17–19）。

关注规模相对EF树的增量，以及规模是否只在比例信息之外提供增量。主判据：τ=300/600至少一项相对基准MAE改善≥10%且地区聚类95%差值区间上界<0；否则关闭月度特征扩展，不再开发尾频率模型。所有判断为开发筛选，任何通过仍需要冻结后新地区确认。
