# 供体校准数据恢复：只改变报告范围与风险样本

2026-10-31。本文写于初次数据恢复之后、三国模型复跑之前；不是数据恢复前的预注册。复跑使用的原始字节已保存在两版repaired证据目录的code子目录。此项是数据合同修复，不是新方法。

旧LGEE小时代理把半年度文件中任一时刻出现的油电列视为该半年度全程active。2023H1油电1–4月全未报、5月43条为0、6月720条为0，导致早期月份即使其他已报告分项通过净发电平衡也被排除。原CSV和全部旧结果保留。

新版本按UTC月、原source_snapshot分别界定已报告列，复用原complete/balance/完整UTC日质量规则。整月未报告的类别仅排除出已报告燃料代理，不声明物理为0；月内active后零星缺失仍无效。不得用净发电余量给油电填0，不改变负值处理或平衡容差。原2022H2与2023H1原生文件共同提供边界UTC小时。

仅替换LGEE的2023-01-01T00Z至2023-07-01T00Z代理行，UTC窗口外数值不变，时间戳集合完全相同。窗口起点有5小时属于纽约本地2022-12-31，不能笼统声称当地2022原始行不变。独立复核确认：12月两版均未达到月量99%门槛，且追加供体训练12月匹配数为0；实际匹配训练的时间、特征和细/粗响应全部相同。输出到新目录，记录原生文件SHA、旧/新代理SHA、逐月active/unobserved审计。

在上一轮核电支持扩展两策略中使用新LGEE路径，四个供体重新计算2023H1共同可用校准数并按相同数量匹配。训练2022预算、训练输入、随机数、源权重与目标名单不变；目标24H预测原点值必须与相应上一轮逐元素相同，否则不能把差异归于校准。旧GB/DE、US原7目标数据不变。

模型与校准规则不调参，9配置×8方法照旧报告。评价恢复数据对覆盖、宽度、区间评分的影响；如果只通过变宽改善覆盖，不宣称风险效率或论文创新。两个策略都是已查看三国上的开发复测，没有独立新地区确认。
