# V376：共享系统装机约束下的省级组成信息价值

登记日期：2026-10-30。V374/V375为unresolved范围残差单独给予全省总装机上限；已报技术组也分别使用本地装机上限，小时总出力可能超过系统装机。本轮在相同月度边际、EF与残差信息预算下，加入所有组共享的全省总装机约束。

## 锐集合求解

对候选超阈小时数`K=k`，将每组月度电量拆为事件块`z_g`和非事件块`M_g-z_g`。组内上限给出逐组上下界；共享系统上限`C`另外给出事件块总量边界`max(0,M_total-(H-k)C) ≤ Σz_g ≤ min(M_total,kC)`。组别同质小时容量下，逐组上限与事件/非事件块总量界共同保证连续小时分配存在。

在这些盒约束与总量约束下，用有限维精确有理数贪心求`max Σ(e_g-τ)z_g`。`k`可行当且仅当事件块排放超额可为正且至少等于整月超额，同时非事件块保持正发电；严格事件边界与等号情形需单独处理。对单组因子盒按thermal和residual的单调端点求锐K集合外包络。脚本还会对`C=Σc_g`的退化情形与V342无共享总量约束解逐项相等，并检查共享集合包含于独立上限外包络。

## 数据与比较

复用V373全国/本地组成共同容量可行的262个2023省期、2022滞后装机、τ=300；用V345月度残差`[0,R_max]`，thermal EF `[400,1000]`、residual EF `[0,1000]`。系统总装机取V341对应该省年度总容量；已报组按CEC技术装机，范围外剩余组的单组上限取系统总装机，但所有小时出力之和再受同一个系统总装机上限限制。两臂同阈值、小时数、残差范围和容量版本。

主要指标是本地与全国组成两臂的共享容量锐K外包络、两者宽度差、全月宽集合数，以及相对V374独立上限外包络的收缩。若共享约束仍让τ300两臂均为全月宽，说明容量耦合不能恢复省级组成信息价值；若变窄，需解释收益是否本地组成特异，且仍不能称预测覆盖收益。

## 解释边界

CEC年度装机是代理，不是逐小时可用容量；容量映射对核电与范围外电量仍作宽松处理。月度类别与范围残差来自NBS/OREO转录和全厂年度减月规上量，未取得官方接口原始快照。此为部分识别模型敏感性，不是中国小时CIF标签验证。
