# V316：逐类月发电统计比月受电边际更直接地约束来源碳风险

> **更正：本结果已被V319取代，不可作为有效数值证据引用。** 复核发现旧脚本把进口来源技术的排放强度错误赋给受端省，而不是送端省。V319按正确的来源省×技术×月份强度重算，并比较月报式五类别与八类别。

## 消融结果

在同一个“路线×发电技术×月份”出口分配模型和同一个月度进口排放暴露目标下，只改变送端月发电约束，得到 31 省×12 月的最坏条件区间直径。之后再分别加入 341 个省级月受电数字。

| 送端信息 | 省级月受电字段 | 平均剩余区间宽度 | 中位剩余宽度 |
|---|---|---:|---:|
| 月总发电量上限 | 无 | 2.1037 | 1.4062 |
| 逐技术月发电量上限 | 无 | **1.2859** | **0.9120** |
| 月总发电量上限 | 341 | 2.1019 | 1.4034 |
| 逐技术月发电量上限 | 341 | **0.9516** | **0.6037** |

逐技术发电上限相对月总发电上限时，按省份月份逐格计算的保证缩窄平均为 **27.1%**、中位数为 **25.2%**；比较两组总体平均区间宽度，逐技术上限下宽度低 **38.9%**。只有总发电上限时，再增加省级月受电总量几乎没有保证性收益：逐格平均缩窄 **0.13%**，中位缩窄为 0。逐技术上限存在时，省级月受电边际再带来 **19.7%** 的逐格平均缩窄和 **5.3%** 的中位缩窄。两类字段同时加入后，相较“总发电上限+月受电”模型，逐格平均缩窄 **42.4%**、中位缩窄 **47.5%**。全体 372 个省份月份仍没有一个达到点识别。

这揭示了信息的互补关系：**总电量告诉我们“能外送多少”的约束太弱；逐技术发电统计限制高碳/低碳电源可供量；月受电总量随后才有助于把总量配置到受端。**不过，即使两者同时有，实际“哪种电源送给哪个省”仍未被观测，区间没有收敛为一点。

## 如何解释数据收益

V294 每省逐月逐技术发电量及排放是估计值；逐技术排放强度由同产品排放/发电得到。模型把这些发电量作为可用外送上限，不假设实际跨省输出按当地发电份额比例混合，也不使用小时调度标签。用户确认有逐类月发电量，但其原表单位、口径、地区覆盖尚未收到；V294 仅作为可复现替代输入。

因此本轮是**识别区间的结构性消融**，还不是预测表现或实际 CIF 的验证。指标分母为受端本地发电量，称为“进口碳暴露代理”而非标准 CIF；小本地发电地区的该比率会偏大。年度 OD 和排放数据的来源限制，以及缺少受端负荷、线路容量、损耗、储能、穿越流和小时标签，也限制了外推。

## 论文创新性评估

这比单纯比较字段数量更接近可投稿的研究问题：在没有本地小时标签时，公开逐类月度能源统计和粗尺度跨省边际分别能消除多少**来源碳强度不可识别性**，何种信息需要联合取得才能得到有用的界。结果提示逐类发电字段比受电总量更基础，也解释为什么只加全国交易量或月度受电总量仍不能恢复来源结构。

方法贡献目前仍属于线性部分识别和字段价值分析，优化算法本身不新；区域外推、独立物理流量验证、有效 CIF 分母和误差校准仍是论文强度的关键缺口。若这些不能补齐，应将论文定位为“公开信息约束下的可识别性/数据需求基准”，不声称提出了新的小时 CIF 预测器。
