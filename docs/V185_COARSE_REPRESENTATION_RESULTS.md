# V185：绝对组成响应与绝对支持均未带来增量

2026-10-29，Sol。16方法、241个test月的3,856条粗/30,848条燃料评分及全量审计结束。全部打包law、源矩阵、prefix、拟合指纹和四张聚合表重建通过；12个level森林重拟合、192次未来月量law干预、1,205/9,640条原V184粗/燃料评分复现。240项预定描述性比较已保存。独立loss最大差2.63e−12，零断言失败；树生长和精确分位数共享。

本轮只改变普通预测器的响应和支持，信息预算、proper名单及容量固定为V184 long_all。并非新算法。详见[冻结协议](V185_COARSE_REPRESENTATION_PROTOCOL.md)。

## 结果

29地区等权；覆盖、宽度均为**粗月度EF锚**，不是小时CIF。

|---|---:|---:|---:|---:|---:|
| base scalar8，增量支持 | 0.069448 | 20.1364 | 89.35% | 55.56% | 123.9345 |

最佳仍是原V184 base scalar8。新level响应中较好的history/increment相对它ES恶化5.4177%、锚CRPS恶化20.8844%、宽度多17.46%；地区配对ES差范围[0.000718, 0.007087]，10/29地区改善。去掉五常数EF地区后恶化6.5443%，范围仍为正。不能用宏覆盖超过90%掩盖最差地区覆盖下降和区间变宽。

固定base level8森林权重，仅把增量支持换成源绝对组成，ES恶化74.0197%、宽度多57.68%，29地区只有1个改善。Gaussian绝对支持相对同点预测/同sigma的增量版本，ES恶化80.5538%、宽度多41.03%，29地区均未改善。后者随支持重算了Gaussian后验，不能称纯固定权重因果消融。

绝对支持内level8相对scalar8有改善，但整体仍远弱于增量强基线；这不是可用于论文的独立机制收益。未来组成有强地区差异，直接迁移其分布在这组有限源/模型下表现较差；本实验不能唯一归因到模型容量、源地区支持或所有绝对响应方法失效。

## 路线决定

停止这一表示分支，不扩展更多树响应、支持混合比例或小时传播。V184/V185的证据不足以支撑原创算法，也没有解决覆盖保持下的效率问题；原小时gate不变，没有未查看地区晋级。

下一问题改为：更长月度燃料历史能否预测小时调度风险，而不经过“先把未来粗组成预测得更准”这一步？先在原小时监督预算内比较直接20维、短历史43维、长历史43维及长历史波动特征的标准风险模型，检验是否确有可学习的增量。已有V171直接零分类结果必须作为强控制；普通零分类/波动特征本身不构成原创。先验证信息价值，再考虑专门机制，不声称该候选已有效。
