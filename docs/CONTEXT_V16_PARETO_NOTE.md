# V16补充：普通加性基线有小幅效率收益，仍没有机制突破

2026-10-25，Sol。本补充只重新计算已封存源宏表/地区表中的匹配行，没有新预测、参数搜索或目标读取。[主结果报告](CONTEXT_V16_RESULTS.md)按预定最小CRPS选择汇报，不能据此忽略另一条普通参考的实际权衡。

固定lag7、EWMA、factor1.25，`additive`保留原native粒子的零日均小时形状，用新日组成EF锚替换其水平。其结果为：

| 方法 | CRPS | 小时覆盖% | 最差源覆盖% | 宽度 | 区间评分 |
| --- | ---: | ---: | ---: | ---: | ---: |
| native | 26.694362 | 92.9545 | 85.2273 | 176.272555 | 202.247558 |
| 普通additive | 25.685008 | 92.4288 | 87.5000 | 170.875452 | 197.820632 |

additive的CRPS下降3.7811%、宽度下降3.0618%、区间评分下降2.1889%；宏覆盖仍高于90%、最差仍高于85%，但宏覆盖比native少约0.526个百分点。不能描述为“所有简单方法都不能在满足覆盖门槛时缩窄区间”；主报告所述未突破指预定联合晋级门槛与自定义机制，并不否定这条普通基线的有限效率价值。

该基线的水平MAE从30.2076降至28.5968（约5.3322%），形状MAE仅从19.9549降至19.9465（约0.0420%）。这与其主要替换水平的构造一致，但不是新增日统计独立因果效应的证明：中心、粒子水平分布和锚的使用方式一起改变，且锚是发电加权日量，并非等权小时均值的恒等式。

最小CRPS选择仍按冻结协议保留`daily_native_ids`，其CRPS更低但宽/IS更差；不能事后更换选择函数声称新候选通过。additive未达到至少5%的CRPS改善，也没有超越所有同预算普通参考；它是已有简单构造，本身不提供方法原创性。没有为此补充独立确认、配对不确定区间或新地区结果。

因此应保留两条结论：**粗反馈可以有小幅、主要来自水平的实用价值；当前创新条件形状没有超过普通参考，小时剩余风险仍需要新的信息或可验证机制。**不能为了强调失败而抹去前者，也不能为了写论文将前者夸大为后者。
