# 九国伪目标源贡献筛除协议

**口径更正（2026-11-01）：**该版本通过六组`multicountry`特征执行，含`other_renewable`目标输入。严格五类 source-drop 协议见[CN5协议](ENERGY_CHARTS_PSEUDOTARGET_SOURCE_DROP_CN5_PROTOCOL_20261101.md)。

冻结日期：2026-11-01，预测前。问题：在九国扩展暴露负迁移后，源端可见的伪目标任务能否识别一个对其他域有害的训练国家，并在未知目标国上降低强比例重组误差？

## 任务和信息边界

沿用[九国LOCO数据协议](ENERGY_CHARTS_NINE_COUNTRY_LOCO_PROTOCOL_20261101.md)：NL、ES、BE、AT、SE、CZ、SK、HU、SI；2022源训练，2023H1源端伪目标选择，2023H2独立源端交叉校准，2024外层整国留出。目标输入仍为日历与`t−2…t−7`五类月发电份额。所有响应是固定因子生成侧小时代理；月量由当前修订小时序列回算，不是as-issued历史月报。

方法只选择训练源国家是否保留，不改变目标预测器、特征、小时标签定义或参数。禁止读取外层目标国任何小时响应。来源剔除候选及其验证，只使用其余已知源国家的伪目标2023H1响应。

## 冻结选择规则

对每个外层目标，令其余八国为源集合S。每个源国p轮流作伪目标：在2022年用`S\{p}`拟合强比例重组，预测p的2023H1；再对每个候选待剔除源d∈`S\{p}`，在`S\{p,d}`拟合并预测相同p和相同月份。对每个d，计算所有p≠d的等伪目标国平均配对MAE变化：`MAE(drop d)−MAE(all sources except pseudo target)`。选择平均变化最负的d；若最佳变化≥0，则不剔除。平分时按国家代码字典序选择。每个伪目标国家内部先按月等权、再对伪目标国家等权，保持与目标宏平均口径一致。

外层点预测使用全部源国家2022重新拟合，或按规则剔除唯一选中的d后拟合。输出`ratio_all`、`ratio_source_drop`及anchor700对照。该策略每个外层折最多删一个源，不能以目标标签二次选择。

## 区间和评分

为避免H1选择响应同时校准同一残差半径，所有方法用2023H2整国交叉拟合校准：校准国p的模型不含p；`ratio_source_drop`的剔源决策再以`S\{p}`中其他国家的H1伪目标增量选择，完全排除p的响应；随后用`S\{p,d}`训练并预测p的H2。以国等权小时残差池化估计每种方法90%对称绝对残差半径。该覆盖只作经验小时覆盖，不宣称国家级有限样本保证。

报告等目标国、等月份的MAE、去日均形状MAE、90%覆盖、区间宽度和区间分数；逐国给出选中剔除源、伪目标内层增量、目标外层结果。还报告事后最优单源剔除oracle作上界，但不作为可部署成绩。目标预测和区间半径均在打开2024响应前哈希封存。

若伪目标源筛选在外层目标上未优于全部源强重组，或宏收益集中在单一国家并恶化最差国/覆盖，则不继续扫描剔除数量、阈值或评分指标；将本结果作为负迁移诊断，重新评估研究贡献是否应收敛为预算受限基准。
