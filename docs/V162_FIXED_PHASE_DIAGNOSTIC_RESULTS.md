# V162：固定时差不是主要突破口

六折29个源区、两个信息预算的固定分布诊断完成，54,528条时差评分。2,272条零时差记录复现V159，独立审计r2核对策略、评分表和宏平均。所有非零相位选择均使用本地小时标签，不能部署到零小时标签地区。

每地区、预算、方法用全年标签选一个最优固定时差后，同月预算CRPS从22.538降至21.599（4.17%），最差覆盖从68.29%升至71.44%；滞后预算条件动态重组从32.813降至31.946（2.64%），最差覆盖从70.44%升至72.35%。区间宽度保持不变。即使单独按覆盖选相位，同月AVRN也只有71.59%，滞后CPLE的条件动态方法只有72.61%（形状参考73.20%）。时差不能解释主要欠覆盖。

H1选相位、H2评价的27源共同子集仍有约4.74%/2.58%的CRPS收益，但依赖本地H1小时标签。它是时间稳定性诊断，不能作为迁移方法，也不能与全年29源直接混比。

结论：地理时钟对齐可作为后续基准中的普通控制，当前证据不足以围绕它单独设计论文机制。没有晋级新地区。
