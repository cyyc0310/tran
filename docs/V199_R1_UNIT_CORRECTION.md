# V199 r1 退役说明

V199 r1 已完成形状评分，但报告文件内的辅助水平差异诊断存在单位错误：Ember 强度为 gCO₂e/kWh，投影 CIF 为 tCO₂/MWh，脚本将二者未经换算直接相减。该表及由其计算的 `mae`、`mean_signed_difference` 无效，不得引用。

V199 r1 的燃料组成形状排序和小时形状评分不使用 Ember 强度字段，也不涉及该转换；对应评分不受此单位错误影响。为保持输出可追溯，r1 文件保留，不覆盖。脚本现修正为 V199 r2 独立输出目录，统一将投影月均乘以1000后再做辅助水平差异计算。r2 结果为本探针唯一有效版本。
