# V243 冻结协议：能量归一化能否改善600阈值端点证明率

日期：2026-10-30。比较对象为V242阈值600结果；本轮只改变数值参数化，不改变识别集。

## 问题与固定条件

V242在同一2025年16个完整BA-month、600 gCO₂/kWh下有53/64端点证明最优，只有8/16 BA-month的日/小时配对两端均最优。V243检验EIA绝对发电量造成的尺度差是否拖慢MILP。

- 样本、燃料分组、EF、阈值、事件边界、约束、MIP gap目标、每端点30秒时限与V242完全相同。
- 唯一改变：把所有燃料量、小时总量、日总量按该月总发电量缩放为份额后建矩阵。该正比例缩放不改变可行分配、尾事件或K。
- 事后按(region,month,endpoint,regime)与V242逐行比较：最优解的计数端点应完全相同；记录求解时长、最优端点数和有完整证明的配对数。

若归一化导致端点不同，或其他协议项发生变化，实验失败。若同样时限下最优率没有增加，就不称为数值优化增量。
