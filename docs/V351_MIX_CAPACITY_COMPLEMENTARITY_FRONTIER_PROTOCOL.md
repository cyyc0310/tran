# V351 protocol: share-error sensitivity of mix-capacity complementarity

Compute the V350 2×2 information interaction on the identical 328 province-period keys for every V348 fuel-share perturbation band (relative error 0%, 10%, 25%, 50%, 100%). The outer thermal EF support remains [0,1100]; all arms use Ember 2023 generation margins, τ=300 g/kWh, and the same lagged-capacity vintage.

For each province-period and error band, define mix gain as the collapsed five-technology K width minus the fuel-mix K width, separately without and with effective capacity constraints. Complementarity is the with-capacity mix gain minus the no-capacity mix gain. This is a frozen-output robustness calculation, not a new empirical validation; error bands are not calibrated source error distributions.
