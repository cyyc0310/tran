# V4 候选方法：历史支持桥与分量残差迁移

本文描述实际代码中的方法，结果另见实验报告。方法是可检验的候选构造；以下常用高斯条件化、年度差分、混合和残差重采样都不被宣称为新理论。

## 1. 观测是什么

预测日为 t，可用粗观测 j 包含历史窗口 [a_j,b_j)、发布时间 r_j、燃料份额 p_j、完整性 c_j。只使用 r_j≤t 且 b_j≤t 的行，假定排放因子 f 固定，粗强度 z_j=p_jᵀf。

z_j 是发电量加权强度，而不是小时强度的均匀时间平均。因此使用工作观测模型

\[
z_j=\mathcal H_j \ell+\epsilon_j,\qquad
\mathcal H_j\ell=\frac1{b_j-a_j}\int_{a_j}^{b_j}\ell(u)\,du,
\]

其中 ε 包含能量加权与时间平均之间的偏差、粗统计噪声与模型误差。代码给定噪声地板，按覆盖率调整，并用独立源残差补偿；没有假定该观测模型精确无偏。未来月度统计不得用于更新当前预测。

## 2. 强对照：分量核条件化

设日均水平 ℓ(t)=μ+b+s(t)+d(t)。b 为地区长期偏置，s 为年周期及二倍频，d 为具有持续尺度 τ 的短期漂移。

\[
k(t,u)=\sigma_b^2+\sigma_s^2\phi(t)^\top\phi(u)
       +\sigma_d^2\exp(-|t-u|/\tau).
\]

四维周期特征按 √2 归一化，使 φ(t)ᵀφ(t)=1。观测协方差为 K_ij=H_i H_j k，交叉协方差为 k_tj=H_j k(t,·)，四点Gauss–Legendre节点近似窗口积分。标准条件均值/方差为

\[
\widehat\ell(t)=\mu+k_{tH}(K_{HH}+R)^{-1}(z-\mu\mathbf1),
\quad v(t)=k(t,t)-k_{tH}(K_{HH}+R)^{-1}k_{Ht}.
\]

永久偏置核不随观测年龄整体衰减；漂移核会随距离减弱。所有日期显式转为纳秒后换算天数，避免pandas版本造成微秒/纳秒混用。无合法观测时回退源先验，最多保留最近48个合法窗口。

这是标准GP思想的任务化实现，保留无季节的local-level、无漂移的harmonic ridge、窗口终点替代积分支持等对照，以检查复杂性是否必要。

## 3. 本项目候选：同支持年度创新桥

粗水平可能同时含不规则季节与结构漂移。仅用平滑周期核可能丢失不规则同月信息；仅复制去年的同月也无法适应变化。因此用已发布的同月历史作为锚 A(t)，另对相同历史支持之间的年度变化建模。

对于可配对的完整日历月，令 Δ_j=z_j−z_{j−12}；两个成员都必须在预测时已经发布，不能从未发布年度差取信息。在同支持比较下，稳定地区偏置和重复的月季节结构被抵消。设剩余创新过程具有常数漂移项与OU项，使用最近12个合法年度差的窗口条件化：

\[
\widehat\ell_{bridge}(t)=A(t)+k^\Delta_{tH}(K^\Delta_{HH}+R_\Delta)^{-1}\Delta.
\]

τ 预先固定90、365日两候选，只在源2024开发选择。锚自身保留20单位误差地板，不把历史同月当未来真值。缺乏合法年度配对时不凭空拟合漂移，回退锚与基础不确定性。

该构造要通过消融证明价值：比较单独季节锚、普通GP、无支持积分、固定加权与源监督专家组合。年度差分、季节naive和OU桥各自已有先例；本文尚未完成可宣称首创的充分文献排重。

## 4. 小时形状及其不确定性

预测路径写作 ŷ(t,h)=ℓ̂(t)+q̂(t,h)，Σ_h q̂=0。形状由源日历模板和32个合法粗特征相近的源日形状各取一半。两者均严格去日均，因此形状变化不偷偷更改水平。

第二轮对源邻居形状求加权散度，形状方差=0.5×全源方差+0.5×近邻方差。全源地板避免近邻稀疏时虚假确定；此尺度对所有点方法开放，不只给候选特殊校准。

源小时拟合只用四个训练地区2022。相似性只由日历、已发布燃料份额、支持和年龄等合法特征决定，不使用目标小时值。

## 5. 分量残差迁移

在独立的三个源校准地区2023，按日分解残差 e_i(h)=y_i(h)−ŷ_i(h)：

\[
e_i^L=\operatorname{mean}_h e_i(h),\qquad
e_i^S(h)=e_i(h)-e_i^L.
\]

标准化为 u_i=e_i^L/a_i，v_i(h)=e_i^S(h)/b_i，其中 a_i 为条件水平尺度，b_i 为源形状尺度的日内RMS标量。标量缩放保持形状零均值。

源地区等权、地区内日期等权，**联合抽取同一个 i**，在新目标恢复

\[
Y^{(i)}(t,h)=\widehat y(t,h)+\gamma\{a(t)u_i+b(t)v_i(h)\}.
\]

γ=1、1.10是评分前固定的两个候选。增加a(t)只扩张日均误差，不会机械地扩张形状；保留同日索引避免捏造两分量独立。有限128情景用于CRPS及经验区间，全部源路径加权分位用于确定性区间，分别评价。

这是残差迁移的工作模型，不是分布无关保形保证。源地区有限、模型错误、能源结构改变、时间依赖均可使区间失效；源端覆盖通过不能替代新区覆盖验证。对照包括raw residual、标准化pooled、地区等权和保守源月最大分位。

## 6. 原创性与直接先例

[一般线性约束下概率协调](https://link.springer.com/article/10.1007/s10260-023-00738-6)已建立一般协调框架；本任务不能把已知历史粗观测与未知未来聚合值混为同一约束。

[Conformal Prediction for Hierarchical Data](https://arxiv.org/abs/2411.13479)研究投影与层级保形区域；这里将水平/形状分开并不自动获得新的覆盖定理。[UAI 2024可解释分组校准](https://proceedings.mlr.press/v244/martinez-gil24a.html)已有输入条件分组思路，因此年龄分箱本身不是创新。

可发展的贡献在于：针对完全无目标小时遥测的CIF任务，把历史支持、发布年龄、年度创新和水平/形状不确定性联合做成可迁移条件化机制，并在独立新地区验证相对强对照的收益与失效。是否足以支撑方法论文，必须由最终对照、消融和进一步文献区分决定。

更直接的基础先例包括：[Hennig与Kiefel，JMLR 2013](https://www.jmlr.org/papers/volume14/hennig13a/hennig13a.pdf)已明确给出积分观测的GP推断；[Longi等，UAI 2020](https://proceedings.mlr.press/v124/longi20a/longi20a-supp.pdf)讨论积分观测的协方差与传感器选择；[Time series forecasting with Gaussian Processes needs priors](https://arxiv.org/abs/2009.08102)使用组合核作时序预测。因此本轮的窗口积分或常数/周期/漂移核，均只能作为严谨实现与强对照，不能单独声称方法首创。年度差与季节基线的关系也需对照[季节随机游走与漂移](https://people.duke.edu/~rnau/411searw.htm)。

路径依赖和相似日同样有直接先例：[Ensemble Copula Coupling](https://arxiv.org/abs/1302.7149)通过后处理边际与集合依赖结构形成多变量预测；[Schaake Shuffle](https://pubs.usgs.gov/publication/70027101)恢复历史时空相关；[Analog Ensemble](https://journals.ametsoc.org/abstract/journals/mwre/141/10/mwr-d-12-00281.1.xml)使用相近历史预测对应的观测构造情景。本实现不是这些方法的完整复现；同日抽样保持相关、相似日和残差重采样均不能单独作为新颖性。若进一步主张分量传输方法贡献，需在相同信息下补充上述标准后处理及异方差误差模型，证明“历史支持决定的分量尺度”提供额外价值。
