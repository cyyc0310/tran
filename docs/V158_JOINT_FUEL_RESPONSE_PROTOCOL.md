# V158：联合燃料残差与响应感知分裂

冻结于V156/V157后、V158评分前。复用V156 sampled全部源小时索引、20维合法输入、两预算/两源划分/36目标月和30/12身份分离；每源最多4,096小时。不打开新地区，不调目标超参。

来源监督：源小时燃料份额s=g/sum(g)，输入月能源燃料份额S，联合标签d=s−S。其元素和为0，d·EF等于标量CIF减能源锚，必须核验。目标小时无燃料遥测输入。

三种森林均32树、min_leaf64、max_features1、seed20261028、等源地区权重：标量残差森林（复现V156）；普通八维d森林；响应感知森林。后者以proper源输入月组成按煤占比排序，在0/25/50/75/100百分位选5个源组成原型v，以修复后CIF(v+d)形成五维响应字典，按proper源加权标准差标准化后作ExtraTrees分裂。不得读取校准或目标标签来定义原型/标准化。

五臂：scalar；joint_linear（普通联合树叶、线性CIF残差+锚并裁范围）；joint_nonnegative（普通联合叶、S+d负项截0后归一）；joint_budget（同前，再施加合法零燃料支持）；response_budget（响应感知叶，同一支持修复）。同一森林叶内保留联合d原子及相关结构，树等权混合，精确经验CRPS。

零燃料支持只在same_month完整非负月总量下使用：M_f=0意味着该燃料小时量为0。asof历史月的0不代表未来月为0，禁止硬屏蔽。修复为截断再归一，不是欧氏单纯形投影，也不保证重建完整月的能源总量。若分母≤1e−12回退输入S并记录。字典响应采用同样预算规则。这些假想响应不作因果干预解释，不增加独立源样本数。

标量臂的288条CRPS/MAE/覆盖/宽度/Winkler必须复现V156 sampled的森林。联合线性对照隔离联合监督分裂效应，nonnegative/budget对照隔离可行性和零支持效应，response_budget相对joint_budget才检验新分裂规则增量。所有模型均完整报告，不把普通森林、修复、特征响应字典的组合直接称论文创新。

预检更正：初次启动后、首个预算块完成前核对到V156未保存均值/绝对端点，不能声称逐项复现这些未归档字段。已停止该次试运行，仅将复现合同改为实际归档的上述五项；模型、超参与分析方法不变，本轮另存均值和端点供后续核验。

校准仍用独立12源2024误差的地区等权q90和max-region q90。保存抽样等价、原型身份、活跃字典维度、修复回退、逐区/宏CRPS覆盖宽度Winkler、哈希与完整分母。核心假设是来源联合燃料创新可迁移，不能由预算可行性自动推出。只有稳定胜过普通联合模型和小时重组，才值得进一步查新与冻结。
