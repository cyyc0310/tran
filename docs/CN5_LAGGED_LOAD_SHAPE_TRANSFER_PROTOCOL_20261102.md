# CN5同比滞后负荷形状迁移：冻结协议

冻结日期：2026-11-02。此项检验优先级2/3中的一个明确增量：源模型能否用目标区前一年同月的负荷日内形状，改善中国式滞后月发电统计下的小时发电侧CIF代理预测。

## 信息合同

- 主预算M：严格CN5既有`t−2…t−7`五类滞后月发电份额、历史统计和日历。
- 扩展预算M+L12：额外增加目标小时所属月份的**前一年同月**负荷形状。形状按目标本地时钟的工作日/周末×小时48格计算，以前一年同月平均负荷归一化，再映射到预测小时的相同日历格。
- 对源伪目标2023，新增特征仅使用2022负荷；对外层目标2024，仅使用2023负荷。当前Energy-Charts快照不是可复原的as-issued负荷版本；本实验是滞后历史输入信息价值测试，不是实时预测输入或中国公开可部署预算。不得使用目标月负荷、残余负荷、跨区流量或燃料/标签。
- 所有方法共享同一时间戳、可用标签行、国家权重与源国名单。目标国完整留出，2024小时标签只在预测、区间和哈希写盘后读取。

## 设计

- 九国严格CN5队列：NL、ES、BE、AT、SE、CZ、SK、HU、SI。目标年份2024，训练为其余八国2023年1–6月小时，校准为2023年7–12月小时。目标月发电统计沿用既有滞后五类预算。
- 响应为固定EF发电侧小时代理。源训练包含强比例重组及`factor_history`基线。唯一M+L12方法在同一`factor_history`训练样本、权重、HGB超参和初始化下，向因子模型增加单一数值特征`lag_load_shape`；最终CIF仍通过同一个源训练热电小时轮廓重组。M版本因子头与M+L12头使用同一个源热电轮廓。
- 90%误差半径来自2023H2源目标预测残差、国家等权；不得据2024目标覆盖调半径。报告覆盖、平均宽度、Winkler型区间分数以及点MAE、去日均形状MAE。
- 宏指标先逐目标国12月等权，再九国等权；另列每国结果。所有比较使用相同小时支持。

## 晋级门槛

M+L12只有同时满足下列条件才值得寻找同口径、中国预测时合法可得的负荷预算：至少6/9国MAE下降、国等权宏MAE至少改善5%、日内形状误差不恶化超过1%，90%宏覆盖下降不超过1个百分点且最差国家覆盖不下降超过5个百分点，区间分数不恶化。否则停止该机制路线；小幅或局部效果作为信息价值负结果记录，不作中国部署或算法创新主张。

## 复现

`PYTHONPATH=src python scripts/run_cn5_lagged_load_shape_transfer.py --output results/cn5-lagged-load-shape-r1`。输出保存每国封存预测、预测封条、逐月/逐国分数和输入哈希。九国均已在开发中查看，故这是内层开发评估，绝非新国家确认。
