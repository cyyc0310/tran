等省均值下阈值下降差异也为正：τ100−τ300 为103.38小时，95%区间[79.85,129.99]；τ300−τ500为139.62小时，[106.44,175.27]；30省中30省前者为正，26省后者为正。留一省极值说明交互均值没有被单一省份制造出来。

但异质性不可忽略：τ500有9个省月互补为负，均来自西藏；西藏该阈值下省月平均交互为−399.33小时，主要因为燃料mix臂在无容量时已比五技术宽EF臂窄约809.67小时，加入容量后该mix臂宽度仍为0，容量没有额外可缩窄空间。反向饱和使“正交互”在这个省变为负，并非算法失败。V353估计的是有限30省的集群组成敏感性，不应解释为随机抽样的全国总体推断。

## 结论

阈值衰减在省级配对bootstrap和留一省诊断下仍清楚，但τ500的异质性由西藏的“mix单独已饱和”揭示。更准确的机制表述是互补程度取决于各省、阈值和基线识别集是否已接近饱和；全体一刀切规则不成立。仍需真实mix误差与小时真值，不能把该结果当作预测覆盖证据。
