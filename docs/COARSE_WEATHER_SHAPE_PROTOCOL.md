# 强粗重组内的天气形状参考：开发协议

2026-10-31，Sol。在[已见小样本结果](WEATHER_TRANSFER_SEASONAL_RESULTS.md)之后固定本轮方法，属于自适应开发，不是新地区确认。沿用相同12个原生GFS窗口、9配置、两预算、1200/576/624小时及固定因子代理，不新增天气、标签或目标校准。

## 强基线与方法

以已封存的同标签联合轨迹银行为主干。全源年联合轨迹仍为额外源标签参考；本轮不冒称主干已经使用全源年监督。银行的供体选择、128粒子、月报条件和随机键保持不变。天气只改变各供体每日六类燃料的mean-one小时形状；每条供体的日燃料幅度、未支持类别q=1及零幅度保持原值。保持的是预测供体幅度，不是未知目标日或月能量真值；非线性重组后算术日均CIF可以变化。差分运输在投影前携带供体残差，但非负投影可以改变其尾部，不能声称完整残差分布或目标覆盖保证不变。

固定8个输出：joint_original、learned_zero、physical_solar、physical_wind_solar、head_no_weather、head_weather、delta_half、delta_full。learned_zero必须与joint_original逐值一致；其源校准半径及预测与上一轮封存joint_matched也须核对。普通head_no_weather是可改变基线的对照，不能冒充零增量分支。

物理参考将非负辐射及min(100m风速,25)^3归一化为mean-one日形状；太阳能单通道与风光双通道分别保留供体相对物理预测的形状残差。风速立方只是固定简单代理，不声称真实机组功率曲线；全日均值为0时用平坦形状，标记为形状先验而非实际发电非零。

普通回归头用源2022细燃料标签汇成六类，每个有发电的燃料日归一化为mean-one。B输入为当地日历及lag2粗组成/小时交互；W额外读取已签发的温度、风速及辐射。加入日内中心化温度/冷热度、日内中心化风速、归一化风速立方及辐射；整段24h天气在起点已知。Ridge alpha=10，源国/区域均衡；每燃料只在正幅度源小时训练，缺失支持不填物理零。输出逐燃料投影到非负且日和24。

delta使用V12已有差分运输：project(shape(q)+alpha*((query_W-query_B)-(donor_W-donor_B)))，alpha固定0、0.5、1，不用目标或源校准成绩选alpha。供体头预测按2022起点留一日期交叉拟合（同日期所有地区一起排除），最终查询头用全部源2022训练；禁止供体自身标签进入其头拟合。这是训练期交叉拟合，不当作2022年前瞻成绩。普通head参考用query_B或query_W减供体相应交叉拟合预测，保留残差。

源单国只有一地区时也能按日期交叉拟合；6个日期意味着样本仍很小，不能将其包装成充分的地理泛化校准。

## 概率对照与判读

所有方法共用源2023三日校准，对原始经验5/95分位施加非负CQR扩张，输出原始与校准指标。报告同粒子的原始CRPS，不能称它为校准后完整分布的CRPS。与上一轮同预算HGB、异方差、CQR及简单锚的冻结结果比较，避免只和弱直接回归头比。

所有配置与预算的成员和半径先封存再评分。报告MAE、日内形状MAE、覆盖、宽度、区间分数、最差地区；原月报预算单列。源校准不用来训练天气头或择优。零强度必须返回原银行，其他分支即便平均改善也不替代这个不变量。

物理变换、普通Ridge、simplex投影及V12差分运输都属于已有参考，六燃料接口本身不算创新。只有出现独立于物理参考和普通头的稳定增量，才继续研究专门的新机制；本轮仍不冻结方法或打开未知国家。静态装机年份/地域、月报模拟发行、单点天气和原公众可用性False的限制不变。
