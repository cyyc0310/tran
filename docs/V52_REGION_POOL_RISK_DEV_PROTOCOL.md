# V52 地区校准池扩展开发实验协议

日期：2026-10-27。只使用此前已经查看过预测/评分结果的11个 EIA-930 区域：`AVA, BANC, BPAT, FPL, JEA, MISO, NWMT, NYIS, SC, SCEG, SEC`。6个此前未评分且通过严格数据筛选的区域保持封存。

## 问题与数据预算

检验将源校准单位从既有5–6个区域增至10个后，严格月度类别-only条件下的区间效率与最差源覆盖是否改善。数据仍是固定EF、正部已报告发电代理；月度输入按当前EIA下载快照加月末30日的回溯可用性预算生成，不代表已认证历史发布vintage或完整电网CIF。

目标区输入仅使用预测月前已可得的上一年同月五类量（thermal、nuclear、hydro、wind、solar）。点预测固定为：上一年同月五类总量 × 排除目标区的上一年小时形状，thermal EF取其余源上一年同月平均。目标区小时历史、小时燃料形状及本地thermal EF不进点模型或风险模型。

区域集合来自2022–2025全年和2026H1逐时质量筛选中此前已看过结果的合格区域；进一步要求每期至少两个正固定EF活跃燃料字段及一个零EF类别。这是研究集成协议，不可拿未评分地区在新结果出来后重新筛选。

## 时间划分和外层留区

- 每个区域依次作外层目标，其余10区作donor和校准组。
- 校准窗：2023年目标月输入/源形状预测2024年同月目标小时标签。
- 评分窗：2024年目标月输入/源形状预测2025年同月目标小时标签。
- H1为1–6月，H2为7–12月。目标区小时记录只在产生预测后用于计算评分。
- 校准区的点预测使用嵌套留区：针对校准区域`c`的2024误差，小时形状/thermal EF donors同时排除外层目标`r`与`c`；外层目标2025点预测只排除`r`。

## 比较方法

1. **Pooled q90**：将每个校准源的绝对小时残差按来源等权后取90%分位，作为对称半宽。
2. **Max-region q90**：每个校准源先计算其校准小时绝对残差q90，再取来源最大值作为半宽。`K=10`时名义90%地区级split-conformal的有限秩为第10阶，因此该方法与地区q90的样本最大值对应；报告此有限样本阶数事实，但经验覆盖仍需单独验证。
3. **Monthly-mix conditional scale**：仅用目标上一年同月五类量计算thermal share及wind+solar share，以source-balanced Ridge预测校准期各source-month绝对残差q90；源外OOF尺度归一化后的残差按源等权pooled q90作校准。

三种区间完全共享点预测、标签行、小时权重、时间窗和90%名义水平。报告region-hour覆盖、来源等权宏覆盖、最差源覆盖、平均区间宽、90% Winkler区间分数、上下尾漏失、点MAE及有效区域数。

## 开发门槛与边界

开发候选至少须在H1/H2均达到宏覆盖90–95%、每个目标源覆盖不低于85%，且相对pooled q90降低Winkler分数并未靠明显增宽；两半年方向需一致。达门槛仍只晋级候选，需冻结后再评估封存的新区域；未达门槛不得用同一开发窗反复改模型宣称确认。

本轮仅在旧开发目标上做扩池压力实验，任何结果都不能证明新区域覆盖或中国迁移。地区可能在共享互联市场内相关，有限阶数仅是交换假设下的数学分辨率，不是该假设本身的证据。未评分区的目标小时标签在运行本实验前不得读取。
