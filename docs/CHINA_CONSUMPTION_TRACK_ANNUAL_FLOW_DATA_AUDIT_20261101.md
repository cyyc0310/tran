# 中国消费侧年度省际流量预算与可识别性

更新：2026-11-01。本文把既有V310–V319年度OD、流量信息价值和省级月统计实验整理到消费侧研究轨道。该年度OD不是本轮新发现；现有详细实验与原始产物以[INDEX](INDEX.md)所链协议/结果为准。这里回应双轨研究目标，统一登记可用信息预算。它不把生命周期碳足迹当作运行期CIF标签。

## 已审计的数据

清华团队在Zenodo公开的中国省级电力生命周期碳足迹支持数据集，记录于2026-05-22，含`5_interprovincial transfer matrix.xlsx`。数据说明显示矩阵为**2023年度省际电量转移（TWh）**，行是送出省、列是受电省，且与省级发电结构、技术级碳足迹、输配电基础设施足迹配套。[Zenodo数据集及文件清单](https://zenodo.org/records/20344652)、[数据README与矩阵口径](https://zenodo.org/records/20344652/preview/README.md)。V310已对文件哈希及31×31结构作过复核；本轮再次下载后，MD5与Zenodo清单中的`abce2bb93e559f1ec32daaedfe557068`一致。矩阵有116条记录路线、总量1834.23 TWh。

该数据提供消费侧**年尺度**来源结构分析的OD实例，但不等同于“预测起点已发布”：当前公开版本在2026年发布，不能回填成2023年预测当时可见的信息。它也不包含逐小时、逐月的历史潮流序列。

另一个开放目录列出2022年华东省际小时流量曲线，但页面说明该数据依据分时电价计划、月度外送总量、负荷曲线与网络约束**模拟生成**，并需申请访问。[OREO数据说明](https://oreo-data.org/dataset/cn-east-grid-simulated-hourly-flow-profiles)。如获取，仅能作显式标注的模型压力测试，不得充当真实历史潮流或独立小时消费标签。

既有研究也指出，公开省际输电矩阵不连续；一篇跨省隐含碳流研究依靠电网企业年度报告构建2006和2019年矩阵，并明确称没有公开的省际OD矩阵。[Ma et al., *Energies* (2022)](https://www.mdpi.com/1996-1073/15/1/176)。另一项2018–2022年消费排放核算研究依赖省际电力贸易数据，说明该信息可用于年度消费碳核算，但其统计期不是小时级。[*Energy Policy* 相关研究摘要/数据范围](https://www.sciencedirect.com/science/article/abs/pii/S0301421525004148)。

## 既有试验的增量结论

- V311在年度OD和逐省月发电上界下，对31省×12月共372格求锐界；每一省月的毛受电量下界仍为0。年度总路线量不能确定月度受电时序。
- V312/V314的LP中，若能额外观察341个省级月受电字段，按其直接进口暴露代理定义，最坏条件区间平均保证缩窄约85%；相同字段数的预设31条路线月观测约缩窄42%–47%。这是字段价值上界，不是公开可获得性或小时CIF覆盖。来源因子边界不同，不能混比绝对区间宽度。
- V313未找到公众可下载的完整逐省月受电/OD表。公开资料有全国跨省交易月总量；特定交易成员的成交/结算细节不能当作公众预测预算。
- V319在修正送端来源强度赋值后，五类月发电约束让同一声明可行域的进口暴露平均直径缩小21.5%；新增省级月受电总量在此基础上再缩小5.25%。这仍是结构可行域的部分识别结果，目标分母是本地发电而非标准消费量，不能解释成CIF MAE或预测区间覆盖。
- V318发现年度省际OD、重建用电和估算发电直接拼接仍有8省负向隐含损耗；统计地理和物理边界没有闭合，不能据此直接构造消费侧CIF真值。

## 目标与证据边界

| 消费侧数据层 | 可回答的问题 | 不能支持的结论 |
|---|---|---|
| 2023年度省际TWh矩阵 | 年度净输入/输出结构；给年度消费侧预算增加OD流量；与独立年度标签作低频关系/敏感性检查 | 预测时可见性、月/小时潮流、小时来源组合、小时消费CIF覆盖 |
| 省级生命周期CF及技术CF | 生命周期口径生产与交付足迹的年尺度比较、方法敏感性 | 运行期发电CIF或消费CIF；与固定燃烧EF标签直接拼接 |
| 2022华东模拟小时流量（如获准访问） | 特定模型假设下的消费流量压力测试 | 实测潮流验证、全国覆盖、独立的小时消费侧实证 |
| 官方省级年度电力因子 | 年尺度消费侧因子迁移参考 | 小时形状、小时尾风险和逐月区间校准 |

## 对统一迁移框架的修改

发电侧仍以省级滞后月火、水、核、风、光为M，年度装机单列M+C。消费侧建立不同的信息预算层级：

1. `C0`: 本地发电月量（只作为生产侧信息的消费侧基线）；
2. `C1`: `C0` + 预测时确实可见的年度省际OD电量/净输入预算；
3. `C2`: `C1` + 送端小时/月份额与来源强度；目前全国公开历史来源面板尚未具备；
4. 逐小时标签单独登记，当前中国公开数据不具备与`C2`同年同地域配对的独立实测验证。

2023年度矩阵已用于`C1`信息可识别性探索，但必须保留发布日期限制；当前不能用于声称可部署预测输入。新工作不应重复已有V310–V319分析。消费侧下一步应获得同口径、带发布时间版本的月度受电边际/来源强度，并与合法消费电量分母和独立目标核对；如果只获得年度OD，研究结论须停留在年尺度预算与月度/小时不可识别边界。小时主张仍需另一条数据获取与验证路径。发电侧与消费侧共享框架协议和评分设计，但不得共用标签列或互相代替。

## 当前决策

把年度OD矩阵保留为消费侧候选`C1`信息预算，不进入发电侧算法输入，也不纳入伪“as-issued”历史回测。生命周期足迹数据只作不同边界的参照。真实小时消费侧创新需要至少一种可信的来源/运行信息或目标标签；既有V311已证明单靠年度OD与逐类月发电无法保证任何省份月份存在正的受电下界。
