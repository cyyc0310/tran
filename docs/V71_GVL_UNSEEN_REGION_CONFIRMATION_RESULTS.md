# V71：GVL未见区未确认月规模的τ=600增量（2026-10-27）

严格按冻结协议，在此前未评分且V54/V68均未纳入的GVL上，用17个开发区训练，预测2026H1六个月小时固定EF代理超过600 g/kWh的比例。每月有效小时数648–720，均超过质量门槛；源训练区按时点有17区、715–797区月。目标预测全部使用起点前已发布月统计。V52质量筛选中GVL的选择不依赖其标签表现。

## 结果

GVL六个月实际τ=600超阈比例全部为0。热组EF+日历基线ExtraTrees的等月MAE/RMSE为0.0612/0.0639；加入log月总发电量后为0.0732/0.0737，MAE恶化19.6%。两模型均有正的非零预测，候选幅度更大，因此未见区没有复现V70开发期的规模收益。

这是一例真正未见地区的负向确认，但只有一个地区且目标全零，不能估计新地区总体提升率或覆盖率，也不能单凭它断言月规模毫无价值。它足以否定当前把V70的阈值特定统计信号当作已迁移方法增量；不应用这批结果再调模型后继续消费同一地区。

## 结论

关闭“热组EF×月规模ExtraTrees”作为当前论文算法候选。V68–V71合起来显示：树模型在已开区胜过简单季节均值，但额外组成/规模的来源依赖明显；组成增量经同预算消融后不稳，规模在τ=600开发区过门槛却在GVL反向。眼下更可支撑的论文主张是一个**信息合同明确、按阈值和地区报告风险、对月度边际不可识别的小时尾部允许拒答/报告锐界**的基准框架；不是某个已验证优越的小时预测算法。

数据仍是EIA固定EF正发电代理；小时标签首次发布时间没有归档，30天滞后为假设；不代表中国消费侧因子。若继续寻找预测算法增量，应先获得新的、合法且此前未接触小时标签的地区/年份，或现实高频计量合作数据；同一EIA地区集合已不足以提供无偏独立确认。协议、脚本及逐月结果见[V71协议](V71_GVL_UNSEEN_REGION_CONFIRMATION_PROTOCOL.md)、[脚本](../scripts/v71_gvl_unseen_confirmation.py)及[`results/v71-gvl-unseen-confirmation-r2`](../results/v71-gvl-unseen-confirmation-r2/)。
