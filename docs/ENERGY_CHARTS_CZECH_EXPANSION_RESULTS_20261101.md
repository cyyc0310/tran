## 捷克数据完整性

Energy-Charts API返回2022–2024年26,304个UTC连续小时：2022/2023各8,760小时，2024为8,784小时。褐煤、硬煤、天然气、煤气化副产气、油、biomass、waste、others、核电、河流/水库水电、陆上风电、太阳能和其他可再生的所需系列均存在，映射字段没有空值，12个月/年均满足至少99%完整小时。`t−2`六个月输入使2022训练特征可用7,344小时，2023及2024分别8,760和8,784小时。映射未把API缺失当作零；本地抽蓄、抽水、跨境、负荷和派生比例不进入发电代理。逐列审计、原始响应和接口元数据见[r4证据包](evidence/energy-charts-czech-expansion-r4/README.md)。

## 加入捷克作为来源的配对增量

在原五个目标上，用其他五国（包含CZ）训练，并与五国源封存基线配对：

| 方法 | 原五源 MAE / 覆盖 / 宽度 / 区间分数 | 加CZ源 MAE / 覆盖 / 宽度 / 区间分数 |
|---|---|---|
| 比例重组 | 38.48 / 88.67% / 192.10 / 292.42 | 43.33 / 96.65% / 294.08 / 318.55 |
| 宏观重组 | 38.53 / 87.54% / 191.19 / 313.36 | 40.76 / 97.65% / 299.25 / 313.00 |
| 直接最新头 | 91.00 / 69.01% / 185.95 / 941.83 | 54.29 / 89.19% / 216.52 / 323.86 |
| 火电因子历史头 | 39.37 / 86.02% / 174.69 / 315.80 | 96.45 / 64.50% / 197.30 / 1116.64 |

CZ源使直接预测头显著改善，但仍未超过比例重组的MAE或区间分数。比例重组的覆盖提高约8个百分点，同时平均宽度增加约102、区间分数变差；宏观重组也是覆盖升高伴随区间大幅变宽，点MAE变差。火电因子历史头出现强烈负迁移，主要由BE和NL退化驱动。由此可见，加入一个完整且煤电占比较高的欧洲来源可能改变不同模型的行为，但“更多源域”本身不能改善强基线或保证目标国覆盖。

## 对研究路线的影响

1. 新来源的评估必须分清点预测迁移与风险校准迁移：当前直接头获得的改善可作为后续伪目标模型的开发线索，比例/宏观重组和因子头的负结果则要求保留强重组并按最差国检验。
2. “CZ信息”只在源小时训练中增加；目标端字段、源时间切分和目标小时标签隔离相同。因此该差值是来源扩展增量，不是年度容量信息增量，也不是新算法效果。
3. 目标CZ失效意味着这项外部国家扩展只能说明一个开发域支持边界。六国都是已查看域，之后不能把其中任何一国重新称作最终盲测目标。
4. M+C煤/气装机预算仍作为独立基准轴；本轮不加入装机、不改模型，也不与容量实验合并计算。

完整逐国/逐月预测、封存哈希、数据映射审计及配对文件见[r4证据包](evidence/energy-charts-czech-expansion-r4/README.md)。首轮r2输出的一个宏汇总文件实际保存了逐国行，已保留并标注；r3因报告协议标题修订后未重新运行，最终采用r4聚合及预测封存。
