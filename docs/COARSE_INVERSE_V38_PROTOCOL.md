# V38：月度火电总量能否约束燃料内部碳强度

2026-10-27，Sol。小规模证伪实验，未宣称新算法。V37三个普通容量解码头均未超过V36简单门控。下一步检查目标区合法粗历史是否能提供内部组成信息，而非继续增加解码参数。

## 信息预算和范围

沿用七个已查看源、42个2025年1至6月月初查询、128个原MG粒子及35个评分月。旧目标、未知地区、原小时标签继续关闭。父V37证据清单SHA为`639d54297999aad035bedad5f9ba0795d9448af79be4ddda264637690aae62ad`。不修改父文件。

每outer仅用其他六源原V34训练键、四比例标签、均衡权重及2025-01-01截止；不扩大180个原源标签池。额外使用这些相同源月的`total_mwh`构造绝对发电响应，明确属于新增的源端响应表示。六个新臂都获得这份表示。V36/V37仅作已有强参考，不能把相对它们的变化全部算作同响应预算算法增益。

容量用V33的OP登记库存，月份m均用m.year−2年度，且登记公开时间不得晚于相应月份起点。它不是物理出力上限。名义利用率可超过1，不裁到[0,1]。四类顺序coal/gas/oil/other，因子[1000,400,800,400]。

目标历史只访问元数据、`total_mwh`、nuclear/hydro/wind/solar份额，POS为补集。每个查询选择2022年起、结束和发布均不晚于查询起点的最近12条月记录。必须满12条，不补缺月。已做元数据检查：42查询均满12条，但部分非连续，ISNE明显陈旧。保留日期、发布时点、跨度和最新记录年龄；不得把12条称为最近连续一年。

源模型在2025-01-01截止训练后用于所有查询及历史反演；历史A矩阵属于部署时点的回溯算子，不声称当年逐月预报。构造A只用月份、容量和源profile，不允许用该目标历史月的实现总量反向构造profile，防止A=y×预测比例的自洽假象。

## 两个固定普通前向profile

同源月响应为u_if = POS_MW_i × r_if / C_if。源y4与POS份额来自原训练记录，POS_MW额外读取相同键的总量及月时长。C=0且燃料发电>0明确报错；C=0且燃料发电=0为该fuel无定义率，显式排除该fuel的率均值，记录键和计数，不伪造率0或加epsilon。至少一个有效样本/燃料。

Constant：按原样本权重、在C>0样本内计算每个fuel的算术平均u。记录各fuel/源的有效样本数和权重；掩码后不声称各fuel仍有六源等质量。C>0且发电0的真零率保留。

Month：对每个fuel和日历月，使用`(sum(w*u)+global_mean)/(sum(w)+1)`，固定一个权重单位向全局均值收缩；无该月样本时正好全局均值。不搜索收缩强度。保存有效mask、全局均值及12×4曲线。该曲线不含目标当期或历史实现组成信息。

## 三个固定适配对照

历史A_mf=C_mf×u_f(month_m)，查询b_tf=C_tf×u_f(month_t)。拟合时按每月POS总容量归一：B_m=A_m/sum_f C_mf，z_m=POS_MW_m/sum_f C_mf。

1. None：gamma=1。
2. Common：非负最小二乘共同倍率alpha，最小化mean((B*1*alpha−z)^2)，gamma=alpha*1。B*1全零时alpha不可估，明确失败；B*1非零而估计alpha=0时，EF按None的比例定义，只记录总量归零。这是预先声明的归一化零质量边界，不新增燃料信息。
3. FuelRidge：gamma>=0，最小化`mean((B gamma−z)^2)+0.01*||gamma−1||²`。用增广NNLS `[B/sqrt(12); sqrt(.01)*I]`与`[z/sqrt(12); sqrt(.01)*ones]`，maxiter=10000。固定正则，不调参、不裁gamma。记录目标、残差、gamma、KKT梯度；梯度为`2*B.T@(B gamma−z)/12+.02*(gamma−1)`。活跃正坐标梯度绝对值及零坐标负梯度违规均<=1e−8，否则失败。SciPy1.17.1的nnls不使用atol参数，本实验不依赖它；1e−8是独立计算的KKT验收门限。

共2 profiles×3适配=6新臂。EF_t=sum_f e_f b_tf gamma_f / sum_f b_tf gamma_f，None分母必须为正；除上述Common零边界外零分母明确失败。Common的EF/CIF按None逐值复制，避免浮点误差伪装组成增益。CIF粒子始终为原MG_POS×该EF，不用反演总量替换MG偷加另一差异。适配总量预测仅作独立诊断。

## 诊断、评分与停止条件

全部七源预测先封存，再读取原35个未来评分标签。新臂均值/中位数全报，复制原V37的910参考case，共1330 case、266 region、38 macro、266去单源敏感性、42 support。逐源报告EF与CIF，不能只看误差抵消后的CIF。另报同35个合格评分月每臂总POS月均MW误差（42查询全部保留预测），与原MG月总量无关；不据此改变固定模型。

历史B每个查询保存4个奇异值、数值rank（固定rtol1e−10，仅代数诊断）、条件数和历史残差。正则唯一解、低残差或满秩都不代表识别。Common即使减小粗总量误差也应完全不改变EF/CIF。

预测封后，在原180个源监督键上检查LO-source前向profile的燃料绝对率误差；保存真实u、预测u和按容量归一的算子行误差。真实率在C=0处无定义；不补epsilon或计算无定义的相对率。再比较查询B最弱奇异值除以sqrt(12)与这些源外预测行误差RMS的尺度，明确只是脆弱性描述，不是目标算子误差认证、概率区间或覆盖保证。不扩大为2024下半年fine或2025隐藏fuel训练。这180键检查的是裸前向profile，不评价gamma适配，不能将其误差归因于适配。

若四燃料适配不能同时改善EF和CIF、收益只集中于少数源，或裸前向profile的源外误差已淹没弱方向，则不投入更复杂反演。适配效益只按原35未来月EF/CIF及粗总量外推判断，不以180键裸profile误差替代。即使有点增量，仍需学得算子误差下的碳泛函稳定性及小时未解释风险，不能据此冻结新方法或开启未知区。普通聚合回归、NNLS和线性分式优化均有成熟先例，不是原创点。
