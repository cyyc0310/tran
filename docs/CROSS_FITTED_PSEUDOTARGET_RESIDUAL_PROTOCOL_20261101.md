# 跨国伪目标交叉拟合残差传输协议

2026-11-01，运行前冻结。该实验推进研究目标第2项：让源端训练直接模拟“新国家没有小时CIF标签，只可见滞后粗月组成”的冷启动任务。它检验源国伪目标小时残差能否教会模型修正强比例重组，不称元学习，也不预设创新成立。

## 数据与外层任务

沿用Energy-Charts NL/ES/BE/AT/SE五国面板和九类固定EF发电代理。每国轮流作为外层目标，其2024响应仅在所有预测写盘封存后评分；其余四国为源。目标输入只包含当地日历和t−2及更早的火、水、核、风、光及其他可再生粗月份额。月份由修订小时数据回算，不是历史as-issued月报。五个已打开国家只作为方法开发集，不作为新国家确认。

## 基点和源任务生成

每个外层折内，对每个源国`c`依次作为伪目标：基点模型只用其余三个源国的2022小时数据拟合；在伪目标`c`的2023H1上，只读合法粗月特征，得到强`ratio_recomposition`预测`p0`；以伪目标小时固定EF代理响应`y`构成源任务监督残差`r=y−p0`。所有模型在评分中都按国家等权训练，伪目标国家是独立任务单元。

候选修正器接收可部署特征`[HISTORY, p0]`并预测`r`：

1. `residual_ridge`：先用等国权重标准化，再以固定alpha=10的Ridge拟合。
2. `residual_hgb`：HistGradientBoostingRegressor，固定`max_iter=80, max_leaf_nodes=15, min_samples_leaf=100, l2_regularization=10, random_state=417, early_stopping=False`。

响应`y`只用于训练源伪目标残差模型和最后的目标评分。目标国家/地区标签不能用于残差训练、模型选择或风险校准。输出裁剪至`[0,1000]` g/kWh。基点`alpha=0`必须精确复现比例重组。

## 选择、校准与目标预测

- 不调修正器超参数；Ridge与HGB均作为固定候选全量报告，避免五国样本上再嵌套扫描。
- 对源2023H2校准每个伪目标`c`时，修正器只由其他源国伪任务的2023H1残差训练；基点模型也排除`c`。源H2残差按伪目标国等权合并，形成各方法90%对称绝对残差半径。该交叉拟合评估防止模型用自己的伪目标标签校准。
- 最终目标预测使用全部四源国2022拟合的基点。修正器由四个源国的2023H1交叉拟合伪任务残差训练。预测先写盘并记录哈希，之后才读取外层2024标签评分。
- 报告MAE、日内形状MAE、Gaussian CRPS、90%覆盖、宽度和区间分数；分别与强比例重组、门控专家、固定火电因子/直接头作比较。对照必须同一国家留出与同一目标小时。

## 成功条件与解释

候选修正只有在伪目标源交叉验证与外层跨国结果方向一致，且比比例重组及既有门控专家取得至少5%宏MAE改善、形状不恶化，并且区间覆盖不低于88%、最差国家不低于85%且宽度不增加时，才进入冻结讨论。达不到时保留完整负结果，不按外层目标调参，也不解锁未查看国家。

该实验使用五个已看开发国家和固定EF代理，不能证明真实CIF或中国预测精度。固定EF代理受限于源数据分类、统计范围和该月回算的时间版本；后续仍需真实发布版月报和独立目标国家确认。
