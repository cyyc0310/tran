# V244 结果：阈值侧解析筛查精确保留锐界

协议：[`V244_THRESHOLD_SIDE_SCREENED_SOLVER_PROTOCOL.md`](V244_THRESHOLD_SIDE_SCREENED_SOLVER_PROTOCOL.md)。实现：`scripts/v244_threshold_side_screened_solver.py`。输出：`results/v244-threshold-side-screened-r1/`。

在V240相同16个BA-month、EF±10%小时变化外包络和500阈值上，先用阈值侧命题筛选月均EF盒跨阈值的BA-month。对4个跨阈值案例直接解析赋值`K=[0,H]`，验证比例分配的月边际与逐小时总量守恒；对其余12个案例仍运行原MILP。

结果与完整MILP基准V240在全部32个BA-month×信息条件上端点完全相同（`exact_endpoint_match_to_full_v240=true`）。64个端点全可证明，16个配对全完成，所有实际固定EF代理尾数见证均包含。解析筛查准确识别4个跨阈值案例，跳过16/64个MILP端点（25%）；仅48个端点运行MILP，平均1.76秒/端点，总MILP耗时84.5秒；从数据加载到全量输出的总运行时间112.2秒。

这是一个正确性已验证的计算剪枝：不改变任何识别端点，且省去已可解析确定为全宽的整数规划。由于V240未记录同一精度的端到端时间，当前只报告本轮运行时长和跳过端点数量，不虚报相对加速比例。

科学含义：在给定EF不确定盒时，算法可先识别“小时总量是否可能有任何尾数信息价值”。如果不可能，直接返回全宽区间并跳过MILP；否则才执行精确MILP。这比对所有案例盲目求解更高效，但逻辑剪枝依赖前述简单解析命题，尚不能单独支撑“新型优化算法”主张。需要在更多阈值、EF盒和真实物理约束下测量剪枝率与准确性。
