# V155：严格零残差控制改善优化机制，未解决跨区覆盖

本轮在V154目标汇总产生前冻结，288条区间预测完整完成。360条源抽样与V154逐条完全相同，所有目标月保留，源/校准身份相同。CRPS刻意为空，没有将三个分位数补成完整CDF。

合成非负响应约50%零标签时，默认HGB q05预测恒0；严格零残差子梯度在相同目标和参数下能学习非零条件分位数。梯度、loss_gradient、gradient_hessian、float32/64、权重与共享缓冲接口均已核对。该修正选择了pinball零点的合法子梯度端点，不改标签，也不加入随机扰动；属于数值强基线控制。

目标表现并未因此稳定改善：第一划分同月pooled覆盖48.16%、最差0.55%，而第二划分为77.86%、最差72.09%。第一划分的输入锚显著超出proper源范围。严格控制的失败不能外推为所有分位数模型失效，更不能据此跳过锚定残差控制。
