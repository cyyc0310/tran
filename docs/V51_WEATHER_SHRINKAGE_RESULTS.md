# V51 天气太阳能形状收缩结果与路线判断

## 结果

以每个来源作为一次外层留出源，另外六源选择天气混合权重。七次外层选择均为 `alpha=0`，即完全保留跨源月×小时太阳能形状，不引入本地天气形状。

| 方法 | 源宏 CIF MAE (g/kWh) | 源宏 CIF RMSE (g/kWh) | 源宏 bias (g/kWh) |
|---|---:|---:|---:|
| 外层跨源选权重 | 39.93 | 49.42 | -6.69 |
| 月×小时气候形状 (`alpha=0`) | 39.93 | 49.42 | -6.69 |
| 完全替换为天气形状 (`alpha=1`) | 46.50 | 57.45 | +7.41 |

各外层地区均选择 `alpha=0`。在 CISO、ERCO、FPL，完整天气分支的源级 MAE 分别从 39.51、67.72、28.17 上升到 58.24、82.32、41.72；BPAT、ISNE、MISO 的差异很小或略有改善；NYIS 没有有效太阳能预测增量。天气替换产生的整体偏高 bias 与太阳能时段分配导致的预测总发电分母变化一致。两方法月总量完全相同，因此此差异来自小时形状分配。

## 与 oracle 形状实验的关系

在目标月风、光真实总量已知的 oracle 条件下，太阳能天气形状与风电月×小时气候形状组合，在36个可评分源区月的 TVD 为0.2102、小时形状归一化 RMSE 为0.5436；月×小时气候基线分别为0.2369、0.6100。可是它只在4/7来源同时改善两项指标，且目标月总量在真实预测时不可得。更早的直接物理风速曲线也明显失败。oracle 形状优势没有传递成合法 as-of 端到端 CIF 收益。

## 结论

当前档案 weather→solar shape→CIF 机制不通过预定判据。跨源选择退回 `alpha=0`，没有跨地区可迁移的天气增量；不应冻结为论文方法或投入未查看地区确认。它仍提供一个有用的负结果：单个可再生发电小时形状指标的收益，并不保证合成强度的小时点预测改善。月度类别总量错误与非天气燃料形状误差也继续留在系统中。

目前较有价值的研究主线仍是：在明示低频数据合同下区分可识别的月度能量加权信息、不可识别的小时风险，以及源模型赋予的额外形状假设；以类别信息预算、部分识别边界和预测区间性能建立迁移基准。sharp bounds 是成熟的优化构造，不足以单独支撑算法创新。下一步应量化合法发布时点下月度类别预测误差如何传播到小时 CIF 误差，并与强预测/简单锚定基线比较；不要再把天气形状包装成已经验证的突破。
