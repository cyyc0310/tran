# V51 条件小时风险的跨半年前推检查

## 问题与设置

前一轮在同一合法滞后火电因子点预测上测试：用月度组组成和滞后水平预测月度小时绝对残差的 q90，再对标准化残差做等源校准，能否比 pooled q90 更有效地分配区间宽度。候选并非新算法，而是常见的异方差尺度回归加 split calibration。

为了检查候选是否只适用于上半年，将相同代码和特征集原样前推：2024H2六源提供风险模型和校准残差，2025H2逐源留出评分。仍用同一7个历史代理来源，按月和来源等权汇总；缺失支持月份不补值。H1实验为2024H1→2025H1。所有来源和年份此前均用于项目开发，两个半年结果都是探索性时间外诊断，不是未查看地区确认。

风险特征包括：

- `mix_only`：月度热组占比、风光占比；
- `level_mix`：滞后热组有效 EF、热组占比、风光占比；
- `all5`：再加入源间 EF 差及本地历史 EF 波动。

后两者的滞后热组 EF 需要煤、气、油等细分及一组固定 EF 假设。用户目前描述的中国公开月表只能确认发电类别月量，不能据此假定这些燃料细分或局部有效 EF 可计算。因此 `mix_only` 是最接近当前已知月表字段的风险特征集；然而其点预测仍继承本代理数据中的 lag-EF 水平锚，不能把整个流程说成只用类别月量可部署。

## 结果

区间名义目标为90%。

|前推窗|方案|宏覆盖|平均宽度|区间分数|最差来源覆盖|
|---|---|---:|---:|---:|---:|
|2024H1→2025H1|pooled q90|90.59%|177.14|232.95|69.40% (ERCO)|
|2024H1→2025H1|`mix_only` 条件尺度|92.69%|178.52|218.22|78.75% (ERCO)|
|2024H1→2025H1|`level_mix` 条件尺度|93.57%|179.24|215.44|79.22% (ERCO)|
|2024H1→2025H1|`all5` 条件尺度|94.40%|195.71|226.00|85.67% (ERCO)|
|2024H2→2025H2|pooled q90|92.26%|176.83|215.07|70.16% (ERCO)|
|2024H2→2025H2|`mix_only` 条件尺度|93.74%|174.70|200.35|81.66% (ERCO)|
|2024H2→2025H2|`level_mix` 条件尺度|91.50%|161.21|201.04|73.996% (ERCO)|
|2024H2→2025H2|`all5` 条件尺度|93.08%|190.03|221.05|80.03% (ERCO)|

`mix_only` 在两个半年都降低了来源宏平均区间分数，H2 还略微缩窄了宏平均宽度；但ERCO仍只有78.75%和81.66%覆盖。它的分数收益主要是来源间重新分配宽度，不是稳健解决了最坏来源。额外风险特征没有一致增益：H1 `level_mix` 的分数较好但 ERCO 覆盖79.22%；H2 `level_mix` 的分数201.04、宽161.21，ERCO覆盖进一步降至74.00%。完整来源×特征集结果与输入/输出哈希见两个结果目录的 `summary.json` 和 CSV。

## 解释与决策

1. **粗月度组成有有限的来源风险排序信息，但无法确定区间需要满足的最坏来源尾部。** `mix_only` 在两个半年平均层面均改善，却稳定遗漏 ERCO；均值收益不能代替区域可靠性。
2. **lagged thermal EF 在美国代理源上的点水平收益不等于中国当前数据预算下可部署。** 月度热/风/光等组量不能识别煤气油内部组成，更不能识别小时调度和尾部方向。不能用“所有非可再生总量”代替火电内部 EF。
3. **尚无保持区域覆盖同时收窄区间的稳健增量，也没有算法创新。** 条件异方差尺度是标准结构，且候选在已看数据上选择；不足以冻结并开启新地区测试。
4. 研究路线应转为严格的信息合同基准：把月度统计唯一识别的月能量加权量与不可识别的小时形状、排序和尾部风险分别报告；仅对真实公开字段建立预测；在同预算下比较简单锚定、标准动态重组和概率基线。若只给月度组量，针对小时风险应报告识别界/敏感性区间，而非暗示名义覆盖有跨域保证。
