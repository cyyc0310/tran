# V73：同预算比较块内最小G与二阶矩对超阈计数识别的价值

冻结日期：2026-10-28。V20解析推导提出：在固定块碳能量H和正小时总量G下，块内最小G直接决定能否认证K=0；四个6小时块各给一个min(G)，共四个新增标量，可能比四个ΣG²摘要更适合零事件风险。本轮对V20同一1000来源日、阈值和输入做事后精确复算，检验完整K集合与零事件认证。

## 数据、队列、估计量

- 只用V20冻结的BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS七源，2024-07至2024-12固定的1000完整UTC日；不加新地区/日期，不改变原始有效小时mask。
- 支持C∈[0,1000] g/kWh，严格事件C>τ，τ=100/300/600/900。
- 每日四个6小时块均有既定H=ΣG*C和ΣG。比较新增同为四标量的两种发布包：块内`min(G_h)`与块内`ΣG_h²`；另列V20既有`T8_G2`必要外计数集、T8粗集和T8_G24完整G锐集作参照。T8_G2并非已证明的sharp集合，因此包间跨度差只能描述当前界算法下的识别结果，不能全部归因于纯信息量差。
- 对已知块总G、H、最小g=m的候选超越集合大小k>0，超越集合总量s须满足 `τs < H ≤ τG+(1000−τ)s`，同时 `km ≤ s ≤ G−(6−k)m`。在该可行区间存在实数s时k可行；空集k=0当且仅当`H≤τG`。逐块集合以精确Fraction计算并Minkowski合并为整日K集合。

## 固定输出与有效性检查

逐日逐阈值输出T8_Gmin的完整K集合与span；和V20原始T8_G2、T8_G24比较。必须验证实际小时K属于每个集合、`T8_G24 ⊆ T8_Gmin ⊆ T8`；不得假定Gmin与T8_G2集合互相包含。主比较为地区内等权平均后七源宏平均的零事件认证比例、任意事件强制比例、K span和基数；另给1000个来源日的配对宽度差分布。严格按原V20有效日mask，所有输出写入新目录。

## 解释边界

两个四标量包分别是小时G的极值与二阶矩摘要，不等价于同一采集成本、传输成本或信息熵。min(G)通常要求采集块内小时G后计算，未必比ΣG²更容易公开。V73是同期oracle识别诊断，不是未来预测、覆盖校准、因果价值或新地区确认。即便minG在此类内胜出，也只支持该块内K风险的信息选择价值；中国月度公开统计场景仍没有这些本地小时G摘要。
