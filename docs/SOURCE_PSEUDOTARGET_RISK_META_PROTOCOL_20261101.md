# 源伪目标欠覆盖风险学习：国家外层交叉拟合协议

冻结日期：2026-11-01，在拟合风险模型和查看本轮风险分数前。目标是评估能否只从源国伪目标学习：哪些目标月报输入可能导致小时区间欠覆盖。

## 数据与估计对象

主队列为NL、ES、BE、AT、SE、CZ六个Energy-Charts域，使用已封存的六国留一国预测结果`energy-charts-czech-expansion-r4`。每个目标域模型都只用其余五域2022小时监督和2023H1源端风险校准，目标2024区间覆盖只用于相应外层折评分。固定因子生成侧小时代理、修订小时数据回算的滞后`t−2...t−7`五类月报，均为开发代理，不是官方CIF或中国历史as-issued回测。

主要风险事件为单个目标国月份的源校准90%区间覆盖低于85%。85%作为预先使用的地区最弱覆盖筛选线，非名义90%保证。每个预测月贡献一个风险样本，共72个国家—月份；小时数不作为独立风险训练样本。

## 外层隔离

固定国家顺序AT、BE、CZ、ES、NL、SE，逐一留出一个国家。风险模型的训练响应只能读取其他五个国家各自LOCO折的2024月份覆盖事件，共最多60条伪目标样本；不能用外层目标的标签、预测误差或覆盖挑特征、阈值、模型及正则强度。目标预测输入只能读取其`2024`预测前的五类月报历史和可见统计字段状态。

风险特征固定为：35个五类`t−2...t−7`月份额/历史统计、日历月份正余弦、四个无监督源支持分数（最近源月距离、收缩Mahalanobis、坐标范围外推均幅、范围外坐标数），以及原始发电映射中缺失的粗类别数。每个外层目标的支持分数只相对本折其余五个国家的2022源月特征计算。模型不接收国家名、目标小时或任何目标误差。

在每个外层目标折内比较：

1. 源伪目标欠覆盖率常数基线。
2. 只用`mean_range_excursion_z`的标准化L2 Logistic风险模型。
3. 使用以上全部特征的标准化L2 Logistic风险模型，固定`C=0.05`、最大迭代2000；不调参。

风险输出截断在[0.01, 0.99]只为数值稳定。主指标为跨外层预测的Brier分数、对数损失、ROC-AUC、平均精确率；同时报告六国逐国事件数、平均预测风险、实际事件率和风险排序。区间本身不做后处理、不加宽也不收窄，避免把风险打分增益与区间操作混为一谈。

## 缺失字段压力检查

RS不进入六国训练/主评分，因为其原始响应未报告若干燃料类别，旧扩源实验将部分类别以零占位且排除了不完整小时。仅把RS作为冻结风险模型的输入状态压力检查：给定同一份已记录的RS 2024留出指标，检查schema缺失数能否推高风险分数。该项不是可比的独立确认，也不纳入AUC或总体评分。

## 决策门槛与解释

只有完整风险特征模型相较恒定风险率及范围分数基线在外层Brier/对数损失上有实际改善，且多数逐国外层方向一致，才保留进一步新国家确认。AUC或区间覆盖改善不能替代proper score；也不得因一个极端国家而声称泛化成功。若无增量，则停止基于当前样本训练risk model，只把支持距离作为描述性外推标签。

所有六国结果此前都已查看，本轮是嵌套交叉拟合的开发评估，不能称真正盲测。任何新增国家确认都必须先冻结本协议、模型代码和风险输出，再首次打开标签。RS字段缺失语义和任何中国省级覆盖率结论均单列。
