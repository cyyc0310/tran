# 双标签伪目标残差：同队列、同H2校准下未超过强重组

日期：2026-11-01。按[冻结协议](PAIRED_PSEUDOTARGET_ENDPOINT_TRACK_PROTOCOL_20261101.md)复评分此前封存的US→GB伪目标预测。每个分支含GB 2024完整年的8,784个小时，伪目标源端训练2022，2023H1选择，2023H2留BA校准。发电侧固定EF代理和NESO官方消费侧标签分轨比较。

EIA-923伪目标残差分支在两条标签轨上都发生明显负迁移：发电代理MAE增加72.96、消费侧MAE增加76.92 g/kWh，区间覆盖分别降低24.71和42.47个百分点。它没有通过点误差或概率评分门槛。

小时回算分支也没有稳定增量。发电代理MAE增加0.41、覆盖降低1.03个百分点，区间窄约3.3%，区间分数虽改善5.59，但CRPS略差；这只是轻微概率效率折中。消费侧MAE增加26.89、CRPS增加16.48，覆盖降低9.44个百分点；区间窄约4.4%不足以抵消整体损失。

## 同队列强基线检查

所有直接、容量与重组基线也在本次H2口径下重评分。消费侧直接粗HGB在MAE上比强重组低（小时回算68.99对76.08；EIA-923为62.48对72.03），但形状误差更高、区间分数更差，且区间明显更宽。容量HGB的EIA-923消费分支MAE为61.73，但区间宽529.79、区间分数529.79，也差于强重组。发电代理中强重组优于直接HGB的MAE及区间分数。故伪目标残差未能超过同一输入和同一H2校准下的强重组；单看某个MAE数字会掩盖形状与概率性能。

## 审计与研究判断

- 四组封存预测均与双轨配对回放具有完全相同的8,784行、UTC时戳和观测月；source mean、日历/粗组成预测、M+C和重组七个基线列逐值相同。
- 伪目标实验用2023H2留BA校准参数重评分后，指标与原逐月结果最大差异小于`3×10⁻¹⁴`。代码、协议、输入预测、校准、标签和原始指标均记录哈希。
- GB 2024及相关开发实验此前已查看，因此是封存产物的同合同审计，不是盲测。
- 伪目标几何交叉拟合只在US→GB运行。GB只有一个全国源系统，没有地理伪目标源折；不将时间切片伪装成地理伪目标，也不推断GB→US的对称结论。

对优先级2的结论：在当前EIA/NESO任务中，用源BA留出学习“相对重组的小时残差”，源内选择没有迁移到GB，EIA-923更明显地恶化。该机制不冻结为创新方法，也不打开新目标确认。下一步若继续伪目标研究，应扩展具有多个源区域的国家/平台，并以国家或电力系统为外层折；同时把可迁移点误差、小时形状与不确定性分开检验。
