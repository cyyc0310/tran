# V79：月报燃料支持上界恢复尾部识别，但 L₁ 未胜过 G²（2026-10-28）

V79在已开启的EPE/TIDC做支持上界开发性消融，使用2024H2/2025H1/2025H2完整日共1081个地区日、τ=100/300。月度支持M定义为当月正份额燃料的最大固定EF；若冻结月表缺行（EPE 2025H1共16个有效日）则严格退回全局M=1000。月表在V54代理中假定月末+30日可用。所有局部M基线和锐集合都使用同一M。

## 支持信息改变了识别边界

在τ=100、K≥8下，统一全局M=1000的L₁/完整G只认证862/1081天；使用月度支持M后，完整G锐集认证1066天，局部M-G²外界认证1062天，局部M-L₁认证1059天。月度支持让识别集合显著收紧；在此条件下，额外L₁并没有超过简单G²基线。

τ=300下，全局M=1000的完整G和L₁均为0/1081天。局部月度M令完整G认证858/1081天、同M的G²外界829天、L₁仅466天；L₁仍弱于普通二阶矩外界。所有L₁证书都包含于局部完整G决策集合，零假证。

## 对研究路线的影响

V79否定了“L₁是跨τ更优摘要”的宽泛版本。更有价值的发现是：**已知地区-月活跃燃料支持上界M可消除全球支持造成的保守性；用普通ΣG²外界在该局部支持下，已经追近完整G锐集，且超过L₁。**因此下一步应优先评估“最低限度公开月报字段（燃料类别与月量/活跃支持）+少量合法时间摘要”的识别边界，而不是继续优化L₁。对τ=300尤其如此：改善主要来自M从1000降到400，不能归因于次序统计创新。

这仍不是中国月度-only小时预测。L₁/G²比较输入同样使用小时H和块G；月度M仅是支持信息。需在真正未评分地区冻结验证局部M是否稳定可得、G²增益是否跨燃料支持成立，并检查中国省级月表燃料映射及EF不确定性。协议和产物：[V79协议](V79_MONTHLY_SUPPORT_ENVELOPE_PROTOCOL.md)、[实现](../scripts/v79_monthly_support_envelope.py)、[`results/v79-monthly-support-envelope-r1`](../results/v79-monthly-support-envelope-r1/)。
