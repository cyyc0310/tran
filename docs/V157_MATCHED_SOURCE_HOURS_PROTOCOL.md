# V157：小时重组的来源记录匹配

冻结于V154/V155后、V157目标评分前。只比较普通UTC小时条件重组，不加入新机制。所有查询输入、地区角色、核带宽、源校准规则与V153相同。

从V154的每源最多4,096小时索引，确定2024可用源月。sampled臂只读这些源小时的发电标签；matched_full臂读取同一源月的全部有效小时。两个臂使用完全相同的近月供体名单与组成权重（每源两个最近日历月），因此差异归于小时数量。另与V153原全源月结果比较时，必须说明asof暖启动排除也改变了可选源月份，不能把两种差异混为一谈。

形状归一分母保持公开/缓存源月总量除完整源月有效小时数，与V153一致；不从未抽中小时读逐小时发电值。单元若为空只退回该源月已选中的样本，不用全量标签补齐。源月总量、时间索引和计数是共用输入元数据，不等同于额外小时标签。

记录每源抽样索引等价、每查询供体/权重、源月名单、缺单元回退及完整分母。目标仍为36个2025开发月，两seed/两预算/两校准。保存CRPS、点MAE、小时覆盖、最差覆盖、宽度、Winkler和哈希。该实验只控制数据量混杂，不主张算法创新、不打开新目标。
