# V53 本地月度 thermal EF 锚开发结果

日期：2026-10-27。结果只来自11个此前已评估的 EIA 区域，属于开发集；六个尚未评估的区域没有读取 CIF 标签或分数。

## 设计与复现

固定五类上一年同月粗月总量、迁移小时形状、目标点预测日历和小时标签。仅更换热电组有效排放因子（EF）的信息来源：捐赠区上一年同月、目标区上一年同月、目标区最新已发布月度记录、目标区最新完整已发布自然年。所有本地月表都检查 `period_end <= origin` 且 `available_at <= origin`。再增加一个严格外层留区的组合试验：使用其余区域2024误差，在五个候选权重中选择 donor EF 与本地 EF 的组合，2025只评估外层目标。

脚本：`scripts/v53_local_thermal_ef_anchor_dev.py`。结果与输入哈希：`results/v53-local-thermal-ef-anchor-dev-r4/summary.json`；逐目标月、区域和半年度表也在同一目录。协议：`docs/V53_LOCAL_THERMAL_EF_ANCHOR_DEV_PROTOCOL.md`。数据是 EIA 固定排放因子代理，不等于电网实测全生命周期 CIF。

本地完整年 EF 相对 donor EF 的点 MAE 在 H1/H2 分别下降约50%/58%，Winkler 分别下降约48%/55%，区间也分别窄约25%/47%。这是当前实验中明确的增量。V52 的月度 mix 条件异方差基线宏覆盖为85.11%/86.25%，最差区12.22%/21.59%，平均宽468.60/552.70，Winkler 786.41/792.99；在这个11区开发协议下，本地 EF 锚在宏观效率和覆盖上更好，但最差地区仍远低于85%目标。

本地锚与捐赠锚的差异主要是热电排放水平，不会凭空识别小时调度/燃料切换风险。对最差地区，H1 的 NWMT 完整年锚覆盖60.84%，H2 的 NWMT 覆盖67.44%；SEC、JEA、SCEG也出现部分本地因子方法覆盖不足。把最大区域 q90 用作统一半径虽显著增加宽度，仍不能在每个半年度都达到最差区85%覆盖，因此不能将其称为可信的地区级区间保证。

## 组合权重试验

只用其余10区的2024误差，按区域等权MAE从 `alpha ∈ {0, .25, .5, .75, 1}` 选择 donor/local EF 组合；外层目标的2025标签未参与调权。对“最新已发布月”和“最新完整年”两种锚，H1平均选中权重分别为0.954和0.977，H2均为1.0。组合点MAE为 H1 62.08/60.03、H2 51.51/49.99（依次对应月锚/完整年锚）；没有超过直接本地 EF。当前样本支持直接本地统计作为水平锚，不支持增加一个复杂门控算法作为贡献。

## 科学判断与下一步

这是值得保留的可迁移信息预算结论，不足以单独支撑算法创新论文。实验说明：公开的目标区细月度燃料组成可以强烈修正 CIF 的热电水平偏差；但即使覆盖率整体提升，最差区仍失效，小时形状偏差、调度变化和剩余尾部风险未被月度构成识别。当前提升也来自可解释的信息条件变化，不能包装成新模型机制。

下一步应先按中国公开统计表逐列核验：统计边界是否一致、煤/气/油等细分是否真实存在、月度数据发布时间、供电量与发电量口径、热电排放因子来源。用户已确认月报按月列出可再生和不可再生发电量，但尚未确认燃料级热电分项和对应 EF；只有总火电量时，本实验的本地热组 EF 锚不可直接复现。若中国可取得的只有各能源大类月度总量，则应另做“本地水平锚的部分识别界限”，并将 NWMT/SEC/JEA 类型的失效作为核心问题。只有在这批已见地区内另一个预先规定的机制能同时维持覆盖并改善效率，才冻结方法并开启六个未评估区的独立确认。
