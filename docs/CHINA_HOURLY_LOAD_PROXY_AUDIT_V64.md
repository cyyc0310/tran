# V64：中国公开逐小时负荷曲线能否充当CIF分母信息？

日期：2026-10-27。审计两份声称提供中国省级逐小时负荷的数据集，问题是它们是否带来可用于CIF冷启动的新信息。审计代码为`scripts/audit_china_hourly_load_dataset_v64.py`；原文件、元数据、哈希、逐省变化量位于`results/china-hourly-load-dataset-audit-v64-r1/`。

## 2026年31省小时负荷重建数据

Yi et al.于2026年在 *Scientific Data* 发布31省2015–2024逐小时负荷曲线；原始Excel通过Figshare公开，记录版本为v3，CC BY 4.0，文件约41.9 MB、MD5 `bf730a545bc297b20d6a7ff93571992a`。[论文和方法](https://doi.org/10.1038/s41597-026-07327-8)、[Figshare数据记录](https://doi.org/10.6084/m9.figshare.29832701.v3)。

这不是31省实测逐小时发电或负荷标签。论文方法从NDRC公开的2018典型工作日/周末曲线和每日高低负荷出发，结合年度用电量、空调保有量及逐小时MERRA-2天气变量，生成负荷曲线；作者明确指出中国缺少公开高频负荷数据，真实日内形状只能重建，短时突变和非天气因素不能充分捕捉。2026年扩展曲线的形状因此包含天气驱动模型假设，而非独立小时观测。

本地审计检查了10个年度工作表：31省、310省份-年份的小时索引均完整，闰年8784小时、平年8760小时；无重复时间戳、缺失或负值。归一化日曲线相关性中位数为0.957，第10百分位中位数为0.715；跨日小时形状CV中位数为4.48%，说明模型重建曲线确实包含天气/日期驱动的日内差异，但这只能证明生成数据内部存在变化，不能证明其等于实测供电分母。

把重建负荷总量与V60冻结的Ember省级月发电快照对齐后，2016–2024共匹配30省3240省月。负荷/发电比的省月中位数1.025、第10–90百分位0.662–1.457；每省月比值的时间变异CV中位数9.95%。这两个来源分别是模型化负荷与Ember估算发电，故该比率只是口径兼容性诊断，不是实测损耗或净交换估计。它足以否定“负荷曲线可直接视作发电总量”的默认等式。

## 2018年Zenodo逐小时曲线

Wu与Kan的[Zenodo数据](https://zenodo.org/records/8322210)包含2018年31省8760小时负荷。随附方法说明指出，其输入是NDRC每日最大/最小需求和典型工作日/节假日负荷曲线；逐日曲线通过仿射缩放典型模板以匹配当天高低值生成。原始CSV实查为8760行×31省；MD5与Zenodo一致（`8066da6f9f86a68f3a35633c5eb2029c`），SHA-256为`d8f5c26f3d8b4f639c64ecebf732ff360a303780252a8f498956833c9b4d6059`。

将每天每省曲线归一到该日最小—最大范围后，与年内平均日形状的相关系数中位数为0.986、省份间第10百分位相关中位数为0.920。方法构造表明它大部分只是少量典型日形状按日高低值缩放，并非每天独立测得的小时轨迹。它可作为负荷形状重建资料，不能作为省级小时发电或小时CIF真值。

## 对TransCIF数据预算的影响

这两份资源提供的是**负荷侧**小时模板；V59识别界中能大幅收窄CIF集合的是**发电侧逐小时总量**。省负荷与省发电之间受跨省输入/输出、厂用电、输配损耗、储能和分布式电源影响。把重建负荷直接放进发电LP会产生一个额外假设，而不是合法硬约束。它可以作为明确标注的“月度燃料统计 + 模型负荷形状”敏感性预算，检验该假设下识别界能缩到多少；不能作为hourly CIF验证标签或覆盖率证据。

目前突破机会不是把高时间分辨率文件字段当真值，而是**分层信息预算与有效分辨率审计**：分别比较月度燃料边际、天气重建负荷、真实/预测发电分母和少量本地燃料活动，说明每层究竟增加了什么可识别量，以及引入的代理误差。就中国真正的小时CIF准确率与覆盖而言，公开数据仍缺少独立的省级小时发电燃料分解或CIF真值。
