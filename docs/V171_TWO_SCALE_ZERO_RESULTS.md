# V171：直接零分类有收益，两级hurdle没有普遍增量

2026-10-29，Sol。29源六折、240个森林、241测试月完成。15,424条小时零事件、9,640条月零事件和2,272条正月条件分量评分均完成全量审计；482个cal/test查询的全部概率重建一致，最大概率误差0。Brier独立展开重算最大误差1.02×10⁻¹⁵。没有新的CIF预测、覆盖结果或原gate通过。

两级历史模型的煤Brier略低于直接43维，但差−0.00298、描述范围[-0.02062,0.01129]跨0；气、核、风都没有胜过直接43维。核电的简单月状态持平控制更强，直接43维也不能把对旧世界混合的收益全部称为新增结构价值。不能以原世界混合的较差零概率作为弱对照宣布创新。

其余四燃料也完整报告：Gaussian/直接43维的水电Brier为0.133416/0.119369，油0.112717/0.069762，其他0.171097/0.162815，光0.109370/0.104491；两级模型并非全胜。完整八方法、八燃料、两分层均在归档的macro/region表。

## 两级分量说明了什么

月历史森林较月基础森林改善煤/核/风月事件Brier，但在最近月为正的分层，气、核、光的月零持平恰好为0损失。煤则相反：月历史森林0.028093，持平0.109016，不能普遍用硬持平替代月事件预测。

在明确条件任务M_current,f>0内，正月内43维零森林相对clock，煤Brier从0.091825降至0.074221；核从0.004876升至0.005640，风从0.086641升至0.098369。条件森林也不是当然更强。这里评价的是r=P(hour_zero|month_positive,X)，不是将无条件预测按事后状态筛选后裁定失准，更不意味着预测时已知当前月状态。

困难地区没有修复：CPLE煤真实小时零比例16.15%，直接43维预测8.81%，历史两级却预测37.80%；其Brier为0.14786/0.19476，原Gaussian0.15317。AVRN风真实零比例6.87%，直接43维预测2.02%，20维预测5.04%，历史两级9.92%。整体改善不能替代这些地区的CIF验证。

## 核验和下一步

训练小时仍为V159同一抽样，direct43和conditional43同43维合法输入；条件森林只过滤源正月，没有增加小时。月模型只读proper2024的合法前缀，cal地区没有参与拟合或调参。每折首尾查询的未发布月统计和评估地区小时值干预通过，原两参考3,856条零事件评分复现。

初次审计因CSV重复解析的至多5.30×10⁻²³差异触发逐浮点精确等值断言，未得到审计结果。最终改为逐字节验证“解析各块再按producer规则序列化”的完整根表绑定，再重建全部模型/概率和独立Brier。初次日志保留。源数据、模型代码和正式预测没有因此修改。

该结果支持先把直接零分类当作强控制，否定了“两级hurdle天然带来独立增量”的预期。普通分类和hurdle都不构成论文创新；零事件评分也不能代替完整CIF风险。

V172已在新CIF评分前固定：四个零预测控制、两种固定赔率强度、两种原CIF基础law，只调整原有物理样本概率。原取值和G>0保留，比较原半径/重新校准，完整测覆盖、最差地区、宽度、CRPS、Winkler。单次赔率乘积不保证多燃料边际精确满足，也会改变燃料期望，必须记录这些变化来归因。尚无V172性能结论，原gate及未查看地区要求不变。
