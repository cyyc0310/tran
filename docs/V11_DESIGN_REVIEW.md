# V11 科学设计审查：天气形状与剩余风险

2026-10-23，Sol。状态：运行前设计建议；不是实验结果，也不替代最终冻结的执行协议。本审查只读取 V9/V10 文档及现有方法实现，未读取未查看地区小时标签，未修改生产代码。研究起点是 [V10 结果](INFORMATION_VALUE_V10_RESULTS.md)：ExtraTrees 的 W 使形状 MAE 降低 1.799，但 CRPS 增加 2.055、覆盖下降 6.22 个百分点；最强同日 V9 谐波动态重组仍更好。因而下一步不是把天气拼进另一个弱点模型，而是检验它在强重组结构内的独立作用。

## 1. 可被否定的假设

**H1：**在相同合法月组成、时间、静态区位及同一预报代理预算下，只让天气修正燃料内归一化小时形状，保留燃料日幅度及未解释的 CIF 水平/调度路径，可改善概率预测。形状变好而水平风险或覆盖变差，即否定“当前天气修正已形成概率效率增量”，不能以形状指标单独宣布成功。

**H2：**若收益可由标准条件尺度/分位数模型解释，则不需要自定义风险传播机制。先完成同架构 B/B+W 消融及同预算异方差强参考，再决定是否存在值得研究的剩余问题。V11 本阶段无需命名新算法。

“分别保留”是模块和诊断层面的区分，不是统计独立假设。燃料幅度、小时形状、CIF 水平与调度误差可以相关；抽样应保留这种关联。

## 2. 三种量必须分清

现有 `FuelTrajectoryBank` 保存的是源地区**月观测支持**均值归一化的燃料轨迹 q，不是每日归一化形状。对完整 donor 日 d、燃料 f 定义：

`a_df = mean_h(q_dhf)`；若 `a_df>0`，`s_dhf=q_dhf/a_df`，于是 `mean_h(s_df)=1`。

a 是相对月均的燃料日幅度；s 是燃料内小时形状。天气处理必须显式拆开这两者，不能将原 q 直接归一为均值一后丢失 a。一个最小操作是：

`q'_dhf = a_df * s_dhf * exp(delta_hf) / mean_k[s_dkf*exp(delta_kf)]`。

delta 是源 proper 数据拟合的 B+W 相对 B 的形状预测差；固定模型/正则参数后，只开关 W。所有 donor 燃料幅度和原联合 donor 索引不变。无 W 或修正为零须精确恢复 q。`a_df=0` 保持整条零轨迹；月不支持燃料按既有显式 flat-prior/support=False 回退，不从天气创造支持。指数数值截断、零支持和缺失回退在评分前固定。训练 log 目标如用 epsilon，只是数值定义，不得把夜间太阳能结构零强行改成正发电。

由此保持的是各 donor 的燃料日总量，**不是目标月份能源份额的精确协调，也不是 CIF 的等权日均值**。重组

`C_h = sum_f(EF_f*m_f*q_hf) / sum_f(m_f*q_hf)`

含逐小时随机分母；即使每种燃料日总量不变，改变形状仍能改变 `mean_h(C_h)`。原 V7/V9 的加权 donor q 本来也不保证目标月组成精确守恒。只有在同一完整月与同一发电支持下，才有 `A=E[GC]/E[G]=E[C]+Cov(G,C)/E[G]`。不能把 `m@EF` 强制设成小时等权均值。

对任意确定性中心 c 与真值 C，另定义精确的 CIF 误差分解：

`e=C-c`；`L=mean_h(e)`；`D_h=e_h-L`，因此 `mean_h(D)=0`。

L 是未解释的 CIF 日水平误差，D 是中心化小时路径误差；后者包含调度、天气代表性、模型误差等，不能直接称为已识别的因果调度扰动。保留整日 `(L,D)` 配对记录；两者向量正交于不同时间子空间不代表随机独立。天气版和无天气版都分别诊断 L、D，不能因 D 变小就把 L 一同缩小。

## 3. 最小比较矩阵

仅 B 与 B+W 两预算；R/S 在 V10 未形成明确收益，本轮不再开八预算搜索。B 完全复用 V10 天气轨道合法字段，W 完全复用封存的 GFS `_previous_day3` 代理、13 点、缺失掩码和时间错位解释。两预算共享所有日期、拟合、变换、情景数及超参数搜索预算。若 B 架构没有实际使用某字段，也明确披露，不能因“可见字段相同”声称该字段已被有效利用。

| 参考 | B 与 B+W 内的匹配实现 | 回答的问题 |
|---|---|---|
| 强 donor 重组 | 固定谐波组成预测/同一粗情景、路由、donor 随机数；仅 W 形状修正开关 | 天气在最强 V9 架构内是否有效；幅度和 donor 风险是否被保留 |
| 均值重组 + 全局整日误差 | 同一确定性粗组成点预测与平均燃料中心；B/B+W 各自源外推误差，等地区整日抽样 | 普通剩余风险是否已解释收益 |
| 均值重组 + 标准异方差误差 | 与全局行完全相同中心；源交叉拟合分别学 L 的条件尺度和 D 的条件尺度，标准化后成对整日抽样 | 只需标准条件方差是否足够 |
| 同预算条件分位数强参考 | 以同一重组中心为 offset，标准树分位数回归估计条件误差分位数；共享源校准与路径依赖恢复规则 | 参数尺度模型之外，标准非对称条件分布是否已足够 |

前六项（前三行 × 两预算）是最小机制试验；后两项是提出自定义传播方法之前必须完成的强参考。若执行资源不足，先完成前六项并明确标注未完成强参考，不能据此宣称新方法胜过标准概率学习。最小异方差实现可用固定 ExtraTrees/Ridge 预测交叉拟合绝对误差或平方误差；这属于标准 location-scale 回归。至少另有分位数 boosting/quantile forest 一类标准非对称强参考，不能将仅一个自写方差模型等同全部强基线。模型和小网格须在源评分前冻结。

分位数参考用足够密的固定分位数网格、预定单调重排与尾部插值生成共同 128 情景；若只输出 5%/95% 区间，则只比较覆盖/宽度/IS，不能虚构完整分布 CRPS。逐小时独立抽样会损坏日水平与斜率的联合风险，应以源校准整日残差的经验秩或冻结的 Gaussian copula 恢复小时依赖；这是标准参考组件，不是创新。路径依赖参数不得用目标小时残差拟合。

为使“未解释风险保留”可单独核查，另输出一项不参与选型的共同风险反事实：端到端合同中 B 与 B+W 使用同一套 B 校准 `(L,D)` 记录、相同抽样索引及尺度，只改变重组中心。它只估计中心修正效应，不声称是天气条件下已重新校准的最优分布；若重新拟合天气误差库后风险收缩导致失败，可据此定位。并记录天气前后每条 donor 的 a 完全相等及共同抽样身份。

同一模型的主要 W 效应，采用 B 源选定的模型/尺度参数同时用于 B+W 的固定参数配对；另报两预算各自 source-only 选型的实际决策结果。两种估计目标不可混在一条优势叙述里。使用旧 V9 文件作背景参考时须注明天气轨道共同支持差异；本轮强 donor 行应在相同日期重新生成匹配预测，而不直接跨实验减分数。

## 4. 避免风险重复计算

明确二选一的生成合同，不允许隐式混用：

1. **结构情景合同**：保留粗组成情景和完整 donor 日联合幅度/形状，W 只替换形状部分。不得额外叠加一个完整 CIF 源残差分布，再声称增加的是独立未解释风险。
2. **端到端剩余误差合同**：使用合法粗组成**点**预测与确定性重组中心；对源地区按同一合法信息做地区交叉拟合，误差包含粗组成预测误差和小时剩余风险，再用 global/heteroscedastic/quantile 估计完整误差。此合同不另加完整粗情景或 donor 方差。不同方法均保持中心与误差训练的合同一致。

若选择“真实源组成条件剩余误差 + 目标粗情景”，应单列为 V9 式额外假设：真实组成条件下的误差可迁移到预测组成条件，而不能称端到端正确校准。精确风险分解并不会自动证明条件独立或该假设成立。

异方差参考中，L 和 D 的尺度模型来自不含被评估地区的 proper 交叉拟合误差，校准期只提供标准化误差/统一尺度校准；不要用同一误差同时训练尺度并作为未经折外处理的校准样本。D 若用一个日尺度乘整个路径，均值零自动保留；若使用逐小时尺度，乘后必须再次中心化，且按变换后联合分布评价。源训练偏差中心与尺度分别学习、记录，不能暗中把目标残差均值作为修正。

## 5. 冻结、评价与停止条件

- 七源及六个已查看目标沿用 V10，不读取新地区。天气轨道 proper 统一 2024-01-25 起至 2024H1 末，校准 2024H2，2025H1 外层留区选型；2025H2 仅冻结后的季节压力检查，若源模型只有 H1 donor，要明确季节外推限制。目标 2026H1 仍是反复查看的开发复测，不称盲测。
- 外层评估源地区从 donor、形状拟合、尺度模型、缺失填补/标准化、误差库、copula 和校准全部排除。源 proper 内层按地区交叉拟合；可取得的源月标签只作训练监督，所有伪预测特征必须遵守该日发布合同。源 2025H1 可以用于选择，不能反过来进入 proper 风险拟合。
- 共 128 情景、seed17023，先冻结源选型与全目标预测哈希，再评分已查看目标。保留未投影与 `[0,1000]` 投影后的裁剪比例；投影改变 L/D 分解，主指标评价最终发布情景，辅助报告投影前后均值/方差变化。
- 主要指标：小时 CRPS、90%覆盖/宽度/IS、上下尾和最差地区；联合 energy score、固定 p=0.5 variogram score、整日路径覆盖另列。后者不等于小时边际覆盖。L 的 MAE/CRPS/90%覆盖、中心化 D 的 MAE/energy score 及日内 ramp 误差明确分报。燃料内 s 误差与 a 分布变化作为机制核查，不能替代 CIF proper scores。
- 等地区宏平均与逐区表必须同时报告，重点 PACE/LGEE。天气温度/风/短波强度及源拟合的天气缺失/离群分层阈值只由 proper 数据定义；这些分层用于诊断，不能在目标分数后重新选阈值。六个月同步配对 bootstrap5000 次 seed17023 只作重复开发样本的描述。
- 源选择沿用宏覆盖[90%,95%]、最差地区≥85%，合格者 CRPS 最小，无人合格显式 failed，并保留 CRPS 最优的未过覆盖模型作为诊断参考，防止重演 V10 覆盖筛选掩盖大量点误差。目标结果不得改变方法、倍率、天气来源或选区规则。
- 是否值得另开确认仍要求唯一源选候选通过源 gate，开发目标宏覆盖≥90%、最差地区≥85%，相对匹配无 W 强重组及同预算异方差/分位数强参考 CRPS 至少下降5%、IS降低、宽度不增加，配对月描述区间 CRPS 差上界<0；旧简单锚也应保留。若只是标准参考获胜，应把它作为最终优选方法而非强造自定义创新。天气代理本轮不直接触发新地区开启；先冻结适用于此代理、地点和缺失合同的独立确认方案。

若 W 只改善 D 而 L 不变或更差，结论是存在形状信号但当前总体概率目标未实现；若异方差模型恢复覆盖但变宽且 CRPS/IS 不改进，则只是风险补偿；若同架构 W 无收益，则现有单点代理/表示不支持该假设，不推断天气本身无用。上述任何失败均保持新地区封存。

## 7. 新颖性结论

天气燃料形状修正、单独水平/形状风险、整日残差抽样、异方差回归、分位数/copula 相关性恢复与概率协调均不能单独作为新颖性。现有 [V9 创新审查](V9_LITERATURE_AND_NOVELTY.md) 对 DGCFM/CarbonX 的任务边界继续有效：可研究的是**目标没有历史小时 CIF、仅有合法滞后粗统计与受控预报代理时，什么能识别、什么必须依赖源迁移假设**。

只有在统一信息预算、强架构和标准条件概率学习之上取得独占、稳定、可独立确认的收益，才有理由研究新的传播方法或理论。若最优结果来自现成强参考，诚实产出应是信息预算明确的基准与负结果/条件效应分析。当前尚无证据把 V11 预先写成成熟算法论文。
