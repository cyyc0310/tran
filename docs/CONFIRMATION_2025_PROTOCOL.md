# 新年份2025验证：评分前冻结约定

2026-10-23。先完成2023探索与三轮受控推断搜索，再执行本验证。2025来自EIA官方六个月CSV，本会话首次下载；准备数据时只核对schema、完整性与时间边界，没有查看2025预测准确率或CIF统计。原始CSV为2026修订快照，不是原始签发版本。

## 冻结对象与选择来源

- 模型：`structural_v3.py` 与 `run_structural_search_v3.py` 当前通过Sol复核的版本及全部直接/间接科学依赖；运行入口保存并复核源码与数据hash。
- 训练：其他六区2022小时源参考，完全排除目标地区小时数据。每个目标、每种延迟的模型选择和误差银行只用2022的留源地区与时间划分；不因2023或2025目标表现改变选择。
- 主比较：`seasonal` 对 `latest`。这是根据已完成2023探索选出的最有希望优化方向，故2023不能再用于该假设的确认。`source_policy`仍按先前冻结的源域选择规则，作为独立候选报告。
- 全部11个固定组件与source_policy均运行；不得只展示主比较胜出的地区或只挑最好延迟。半强度shape、完整shape、level与analog分布均保留。
- 输入：日历、预测时刻已经完成且达到假定发布日期的历史月度燃料份额；保留2023–2024粗统计以形成2025真实可用的历史。目标2022–2024小时标签不进入模型拟合或推理。
- 延迟：在月末后30天基本发布日期上额外加0/30/90天，合计30/60/120天。对源域模拟与目标输入一致施加；不提前使用未达到原release-prefix质量边界的资料。

## 预先指定的判断

H1：保留地区长期结构、利用已发布同季节历史粗统计，可比最新月水平复制降低未来小时强度误差；延迟较大时差异可能更明显。

H2：在同一结构水平上添加源域形状信息，是否仍有额外收益；重点对照 `analog_shape_half` 与 `latest` 的去日均形状MAE、原始点MAE以及CRPS，不以形状单一指标获益代替总预测收益。

H3：只依靠源域选择的方法能否稳定迁移；若source_policy不及固定seasonal，不把“自适应”描述成已验证创新。

主指标为七区等权CRPS，同时报告每区、每延迟、raw point/shape/level MAE、90%覆盖与宽度，以及原始点越界率。简单基线不是精确校准参考；模型加源域误差银行不提供跨域覆盖保证。

月份区间使用同步重采样完整日历月，保留各地区月内有效天数，按每区总差/天数再等权汇总；区间描述本年度七区，不解释为独立全球地区的统计保证。13方法/多情景搜索带来的选择不确定性仍需披露。

2025评分仅在全部延迟预测封存后打开。评分后不得再改算法、超参数或区域范围并继续称为本次确认；若修复实现错误，保留旧运行并给出差异及重跑理由。

## 可以与不能支持的主张

若H1成立，支持的是“低信息迁移的主要优化空间可能在历史粗统计与季节结构的利用”，不是季节预测这一成熟原理首次提出。新方法创新需要额外机制、可归因消融和强基线后的增量。

本验证仍为固定EF的非负已报发电代理，同七个美国平衡区、一个新年份；不能据此声称已验证中国小时CO2、真实issued-public部署或完整电网核算。小波不是本轮必选组件。
