# 严格中国五类输入下的九国留出结果

2026-11-01。按[严格五类协议](ENERGY_CHARTS_NINE_COUNTRY_CN5_PROTOCOL_20261101.md)，仅让目标输入使用火电、水电、核电、风电、太阳能月份额及日历；第六组`other_renewable`已从公开输入、月份额归一、历史特征和小时形状参考中移除。它保留在小时代理标签的总量分母内，因固定EF为0而不贡献排放。这样与国家统计局五类月报字段相符。

九个外层国家仍使用2022源训练、2023H1源端池化半径、2024留国测试。目标月量来自当前修订小时数据的聚合，仅模拟两个月发布滞后；标签是统一固定因子发电侧代理而非实测CIF。九国均为开发域。

严格五类结果与先前六组结果接近，但并不相同：比例重组MAE由62.85变为62.16；直接头和火电因子头的MAE、覆盖也有变化。差异总体不大，不能据此保留错误的信息预算说法；以前六组实验作为“额外可见其他可再生”敏感性分析，而不是中国可部署证据。

国家风险仍不均匀。比例重组MAE在CZ为163.34、SI为119.31、NL为82.32；factor_history在HU为97.14。anchor700宏覆盖达到90.9%，宽度337.80；比例重组只有85.2%。严格输入没有解决最差域和覆盖问题。

## 判断

在严格的中国五类输入下，强比例重组仍是当前点预测参考，因子学习没有超过它。主结论“外国小时经验可训练统一跨域基线，但还没有经验证的稳定创新算法”保持成立。后续算法实验必须统一使用[`multicountry_cn5`](../src/transcif/research/multicountry_cn5.py)，禁止无意把`other_renewable`加回目标输入。
