# V78：EPE/TIDC 的 L₁ 证书在小误差下保留增量，较大误差时不再优于 G²（2026-10-28）

V78固定V77已评分的EPE/TIDC、三个半年、τ=100/300和K≥8目标，不调阈值/摘要。对块H、G和L₁施加独立最坏相对误差盒，按保守不等式认证。零误差逐日完全复现V77完整G决策；所有误差水平下没有超出精确完整G集合的假证书；误差增加时证书单调不增。

## τ=100、K≥8的合并敏感性

合并六个“地区×半年”描述性区间，完整G可认证862区间日，G²基线认证660日。下表保留率以862个完整G认证日为分母，增量是稳健L₁减G²的证书数。区间互有时间/区域相关，不应把这些日数当成独立样本置信度。

τ=300在完整G下本来就没有K≥8证书，因而没有可解释的保留率，也不能算稳健性成功。逐“地区×半年”结果保存在`summary.csv`。

## 对候选贡献的判断

结果把候选的有效测量区间收窄到精度合同足够严格的条件：假设误差上界≤2%时，未评分的EPE/TIDC仍在完整G的基础上保留91.0%已可认证日，并累计比G²基线多124个认证日；到5%时，候选反而少于G²基线。误差水平是人为压力场景，不是EIA或中国现场仪表精度调查，因此不能据此承诺实际覆盖或部署收益。

这使当前最具体的研究主张成为：**对特定高尾阈值，解析风险证书可能由每6小时一个最大燃料加权小时G摘要实现；其相对通用二阶矩外界的认证效率收益，依赖可验证的测量精度合同。**这比“迁移得到可信小时CIF预测”更窄，也更诚实。发表前仍需做解析充分条件/适用域刻画、对现实计量分辨率与系统误差实测、扩展独立网格/燃料支持、真实CIF标签验证及针对性文献查新。当前结果仍不是月/年数据可直接运行的方法。
