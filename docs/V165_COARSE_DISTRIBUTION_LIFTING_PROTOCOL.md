# V165：传播完整粗层分布，保留世界内小时风险

在新评分前冻结。V164点约束与Gaussian似然有CRPS收益，最差覆盖未过门槛。本轮仍使用V159的29源六折、2024、asof_30d、相同proper小时抽样和校准地区；不打开目标2025或新地区。所有新增本地量仅取当前已发布月报及可回测的过去月度结果。

## 粗层分布与世界概率

沿用V164的月度锚点预测与过去相同EF回退。全局粗层残差分布使用proper地区五折OOF误差的相反数（真值−预测），地区等权；平移到当前点预测并裁[0,1000]。局部残差仅来自当前已发布的过去月：在那个过去月的预测起点，用当时已发布前缀生成同一proper模型的预测，再与现已发布结果比较。没有可用回测时用全局分布；有n个时，局部经验分布权重n/(n+5)，其余全局。5是预先固定的收缩常数，不按评分选择，不宣称最优。

条件分布森林：V164锚森林的同一32棵树、min_leaf4，叶内proper月度锚增量经验分布，地区均衡叶权、各树等权；先减去该查询叶混合分布的期望，再加同一锚点预测并裁[0,1000]。过去恒EF回退只改变粗层位置，不把分布强制收成单点。异方差控制：用proper月度分组OOF误差平方训练32树、min_leaf4的风险森林，输入V161合法36维历史；预测σ²下限1。将全局OOF残差按预测σ/全局RMS缩放，位置仍用原点预测。这些属于标准条件密度/异方差参考。

以V164相同供体及世界锚A_d为承接空间，保留每个世界内原始小时活动。将粗分布原子z裁到世界锚凸包：

- nearest控制：投到最近锚，等距离取较低锚。
- barycentric：在相邻不同锚之间线性分配质量，使内点投影的条件均值仍为z。

相邻锚差≤1e−10 g/kWh视为数值同锚，组代表为先验加权锚；多个世界按原先验在该锚组内分配。记录凸包外质量、投影前后锚均值、有效情景数；不为凸包外粗风险虚构小时支持。为避免数值零，最终混入1e−12的原先验，此项只用于有限计算，记录约束残差。投影属于普通概率更新控制，不以插值/残差混合本身声称创新。

冻结九臂：原positive、原conditional_activity、V164 world_gaussian；global_residual_nearest；global_residual_barycentric；local_residual_barycentric；qrf_barycentric；hetero_history_barycentric；local_gaussian。最后一臂仍用V164 Gaussian似然，但σ替换为局部/全局残差混合的RMS，位置保持原点预测，用来区分本地尺度与完整分布传播。

所有臂使用相同calibration源，各自重新计算V159 pooled/max_region半径。前两臂复现964条原评分；Gaussian另外482条复现V164。原241个月度点预测仍复现V161。未发布目标粗月统计扰动检查每折两例。月度模型包括五个OOF模型，预测时固定单任务求和顺序，避免并行累加约1e−14的舍入差干扰严格不变性检查或影响后续风险树的平手分裂；OOF真值用逐行dot，训练配置不变。另核验局部残差每个结果发布时间≤当前预测起点，且其预测特征只来自该历史起点可见前缀。报告粗分布90%覆盖/CRPS作为辅助，不把它替代小时结果。

原始小时gate不变。完整比较V164普通组成预测、熵更新、Gaussian及V159标量/V160MMD强参考，保留24非固定EF子集。源区多次试验已用于开发，置信区间仅作描述；明确增量后才冻结方法测试真正未查看地区。固定EF、合成发布滞后及共享时间开发限制不变。
