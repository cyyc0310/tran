# V66：月度燃料边际对小时超阈计数的锐识别界

日期：2026-10-27。仅使用Ember 2016–2024省级月度八类燃料发电边际，回答在不假设小时负荷、容量、最小出力、爬坡、日配额或其它小时约束时，月报能识别当月多少小时满足严格事件 `C_h > tau`。这是条件性识别分析，不是预测或验证。

固定EF演示映射同V65：煤1000、气400、其他化石400、生物质/核/水/风/光为0 gCO₂e/kWh。对每省月设 `M_f` 为观测月燃料发电量，`T=24×当月天数`，小时变量 `P_fh>=0`，满足 `Σ_h P_fh=M_f` 且每小时总发电量 `G_h=Σ_f P_fh>0`。`C_h=Σ_f EF_f P_fh/G_h`。逐月四个阈值为100/300/600/900，严格大于。燃料总量是事后发布统计；不称其为月初预测可用输入。

对 `q_f=EF_f−tau`，事件等价于 `Σ_f q_f P_fh>0`。若任一高于阈值类燃料月量为0，则K=0。若正、负两侧均有能量，令 `D=Σ_f q_f M_f`：D>0时锐K集合为{1,…,T}；D<=0时为{0,…,T−1}。若只有正侧加恰等于阈值的中性燃料，锐集为{1,…,T}；没有负侧/中性侧可支撑非事件小时则K=T。仅有负侧和中性侧时K=0。脚本对所有燃料支持组合及等号边界实现该分类，并保存每条判定依据。

主要指标：K集合的精确端点与宽度、归一化月小时占比边界、仅月统计可认证 `K=0` / `K>=1` 的月份比例、完整fuel support类别分层。预期它会显示“月度能量加权均值已识别”与“小时尾计数未识别”之间的差距。此理想化锐界不包括真实市场的物理约束；加约束只可使用同时具来源、精度、口径和as-of证明的合法本地信息。
