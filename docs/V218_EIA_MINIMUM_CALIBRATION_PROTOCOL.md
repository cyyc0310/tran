# V218 EIA最小本地风险校准预算协议

V218沿用[V215数据和模型](V215_EIA_SPARSE_LOCAL_ANCHOR_PROTOCOL.md)，不改变2025训练、2026H1整区留出、水平模型、k=10供体形状、EIA固定EF代理、嵌套源残差和评分。它固定本地split-conformal校准数为9，比较中心拟合锚数`0,1,3,5,7,9,15`，共9–24个目标区月小时锚；另用48点24/24作为预算上界。每个设置重复200次随机无放回抽样。

拟合锚数为0时，点中心完全沿用目标月信息与跨区模型；9个本地目标小时只用来计算围绕既有中心的非符合分数。拟合锚数大于0时，使用独立的一组小时残差估计偏差，剩余9个锚校准绝对残差。有限90%秩为9，因此9个校准分数取最大值。指标及地区bootstrap沿用V215/V216。

本轮针对一个具体问题：在能由目标区自有锚校准风险的前提下，额外小时点首先应投入中心修正还是尾部半径估计？此协议不测试将目标中心重估本身作为新算法，也不声称现实中国公开月报包含这些锚。

执行脚本：[v218_eia_minimum_calibration_budget.py](../scripts/v218_eia_minimum_calibration_budget.py)。
