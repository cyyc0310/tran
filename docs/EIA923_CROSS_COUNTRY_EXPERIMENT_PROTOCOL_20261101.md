# EIA-923 BA月报特征的美英跨国迁移开发实验协议

冻结日期：2026-11-01，评分前。目的：在相同五类粗月信息和同一小时标签任务下，比较美国BA月特征来自官方EIA-923月度报告还是从小时数据回算，观察真实官方统计口径是否改变跨国模型行为。

## 研究问题和范围

方向为 US→GB 与 GB→US；这是已查看的美英开发实验，不是新国家确认。只替换美国地区的月统计输入：

- **H：小时回算参考。** 美国和英国的月组成均由现有小时燃料系列重算。
- **EIA923-US：官方统计特征。** 所有美国源/目标BA的月组成从 EIA-923 2022、2023、2024 Final plant-month表聚合到其报告BA；英国仍用现有 NESO小时历史月聚合。

两臂使用同样的 `thermal, hydro, nuclear, wind, solar` 输入、t−2 时滞、地区权重、源训练小时、静态源因子与小时轮廓、风险训练/校准样本和七种历史月量预测器。EIA-923中的煤、气、油及未分配到水/核/风/太阳的其余燃料并入 `thermal`，与现有五类合同相同；EIA923值按来源文件的最终历史版本读取。

## 训练、预测、隔离

- 2022源小时监督拟合小时模型与内部小时轮廓；粗月Ridge只用源2022月度数据训练。
- 2023源小时H1训练位置/异方差/CQR风险模型，H2校准区间。目标国小时标签不进入拟合、校准或模型选择。
- 2024目标小时预测一次性写入；两臂和两方向全部落盘、哈希封存后，才加载目标小时标签评分。
- 预测月p只读取该地区截至p−2的月组成。若准确目标月t−2缺失，沿用既定排除，不用较新月替补。
- 强基线是持久性、季节重复、阻尼趋势、本地Ridge、源Ridge及两种历史月误差修正；点与风险分别报告，不选目标地区参数。

## 主要指标与诊断

共同2024年2、4、6月为主表；其余可用月份完整列出。报告每地区和等地区国家宏平均的偏差修正MAE、原始MAE、日内去均值形状MAE、90%覆盖、宽度和区间评分；与持久性及强重组比较。报告美国月统计来源切换对US→GB训练关系和GB→US目标输入的方向差异，并列出官方月量与小时回算月量配对的组成偏差及EIA-930完整小时覆盖。

## 可解释范围

EIA-923 Final数据的统计BA标签可与小时BA键连接；它们不是可证实的2022—2024各预测原点as-issued版本。NESO历史值也没有本实验所需的原始发布vintage链。结果须称“官方统计最终值、滞后模拟输入”的开发回测；不声称严格历史发布时间回放、中国精度，或新算法已获外部确认。固定EF标签是统一发电侧代理，不是官方机构CIF真值。

若官方特征臂未优于同预算小时回算臂，停止把输入来源本身写成增益；下一轮回到源任务设计与目标地区完全留出的训练机制。若某方向改善，先检查数据口径误差、地区支持和完整季节后再决定是否保留。
