# V71：冻结的 τ=600 月规模特征单个未见区确认

冻结日期：2026-10-27。V70在已开发17区的2026H1留区中，预设阈值τ=600下，热组EF+月总规模ExtraTrees相对仅热组EF树MAE改善13.5%，地区聚类差值95%区间低于零；τ=300则恶化。故本确认只针对τ=600的窄假设，不声称跨阈值增益。

## 目标区及选择

唯一目标为GVL。选择只依据V52事前质量普查：它在2022、2023、2024、2025全年及2026H1的原生与固定EF代理完整小时覆盖均≥80%；其公开类别包含煤、气、其他发电，能形成非恒定的高阈值小时代理。GVL不属于V54/V68已评分17区，也不属于此前报告的六个严格候选确认区。GVL是一个地区，无法据此估计新地区总体覆盖或地区聚类置信区间；本轮是单区确认案例。

## 预测任务与数据时点

- 只评2026-01至06；每月第一天00:00 UTC为预测起点，预测该月有效小时中固定EF正发电代理CIF严格大于600 g/kWh的比例。
- 输入目标GVL最近一个完整月的八燃料份额、由份额计算的热组EF、月总发电量log(1+MWh)及月份sin/cos；月信息必须按V54完整月末+30天发布规则在预测起点前可用。
- 源训练区严格是V68/V70已开发17区。目标区小时标签完全从训练排除。仅使用预测起点前已结束且按月末+30天假设可用的来源区标签。小时标签实际首次发布时间没有vintage档案，故可部署性时间仍是假设。
- 标签采用V54固定EF（煤1000、气400、油800、其他400、核/水/风/光0）乘正部已报告生成量的生成侧代理，不是全网消费侧CIF。

## 冻结方法与基线

候选：ExtraTreesRegressor，100棵树、min_samples_leaf=12、max_features=.8、seed=68027，地区均衡样本权重；输入最新热组EF、log月总发电量、月份sin/cos（V70列16,17,18,19）。

对照：同一ExtraTrees参数、训练行、样本权重及种子，只用热组EF和月份sin/cos（列16,18,19）。预测截断至[0,1]。不得在看到GVL标签后改变算法、阈值、超参数或月份。

## 报告与判定

逐月报告实际事件频率、两种预测、绝对误差、月总发电量可用时点。六个月宏MAE是描述性主比较；候选低于基线记为单区案例方向一致，但不计算地区bootstrap/p值、不作总体泛化结论。无论结果正负，都不得据此宣称可信区间覆盖或中国验证。数据发布时点、标签质量和输入快照哈希随结果保存。
