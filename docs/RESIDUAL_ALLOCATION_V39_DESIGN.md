# V39草案：先检验区域燃料偏差能否持续，再做粗量适配

2026-10-27，Sol。设计草案，未实现、拟合或登记为最终执行合同。V38实际结果否定了当前平均profile加普通倍率反演：粗总量有改善，内部EF反而变差。下一轮先检查误差分配的源端依据，不按MISO/BPAT的已见错误手调方向。

## 两个必须先过的检查

外层留出T后，其他六源逐一再留出s，以另五源的原训练键形成profile，计算s原训练键的燃料率残差。不得复用全七源LOO残差，否则T会进入其他源的前向模型。仍只用原180键及同键总发电量，截止2025-01-01；原35未来评分月不用于训练或选择。

先以固定日历分界2023-07-01比较每个源的前后残差方向，报告源/燃料支持、量级与符号。它是部署截止时点的回溯稳定性诊断，不是当年逐月前推。若前半段误差不能帮助约束后半段的碳方向，就不要用全部月当独立样本估计很有信心的区域先验。

同时检查每个源是否有定义完整的四维持续偏差向量。C>0/G=0是有效真零；C=0/G=0的率无定义，C=0/G>0明确失败。不将缺失率补0，不使用可能非PSD的逐对拼接协方差。独立区域样本最多六个，月份再多也不能充当更多区域。先报告完整向量数和各半段有效月份，再固定协方差臂的可执行条件。

## 若支持允许，只比较普通小模型

优先使用加性名义利用率偏差：u=profile+mu+delta_region+monthly_noise。不使用u/profile的倍率标签，以免预测零率时无定义。源端均值、持续偏差协方差与月内噪声分开估计；六源最终profile与五源交叉拟合残差有训练规模差异，需要记录。

目标历史h_m=C_m/sum(C_m)，d_m=z_m−h_m·(profile_m+mu)。普通Gaussian更新、GLS或协方差协调作为强对照。保持同profile、mu、噪声估计与预算，最少比较mu-only、isotropic、diagonal和预定强收缩full covariance。full与diagonal必须使用相同的协方差样本支持；full若不可估则明确停该臂，不能偷填。

任何正则、收缩、噪声处理及有效支持门限都应在实际拟合前写最终合同。非负率若作为约束，需直接求相同二次目标的约束解，并覆盖历史和已知查询月份；不能先Gaussian更新再clip却仍称同一posterior。Source proxy率可>1，不施加物理上限。

只有更新优于mu-only，才支持目标粗历史提供额外预测价值；只有full优于同支持diagonal，才支持跨燃料相关有价值。继续使用七源逐源结果、mean/median、原35 EF/CIF与粗量外推，保留V38和V36参考。不把仅粗量改善或误差抵消称为突破。

## 仍待解决的原创问题

协方差更新把源先验带入原粗数据的弱/零方向，没有让它们被目标数据识别。必须区分源端假设驱动的预测收缩与目标粗证据支持的收缩。GLS、Gaussian更新、MinT、任务泛函识别和已知前向族下的latent conformal都已有先例。

可能值得继续研究的是：联合过去/未来前向误差下，历史粗残差与未来碳方向残差的关系何时可迁移；这个关系如何约束可收缩方向，并把未解释月度水平风险与小时调度风险留在区间内。当前尚无定理、稳定实证或区间效率增量。若普通对照也无收益，就停止本类反演扩展，不能继续靠加宽区间或堆模型维持路线。

本草案不授权未知地区或小时标签，不声明已选定新方法。下一轮先实现上述嵌套源残差及支持/持续性检查，再固定是否运行四臂比较。

## 已完成的支持预查，尚未拟合

只用V38封存训练键和容量mask，按上述2023-07分界检查“每个fuel在两半段至少各一个C>0样本”。这只是定义域存在性，不是最终建模门限。外层BPAT/FPL/NYIS各有4个完整燃料率源向量，其余四个outer只有3个。表和输入hash收据见`results/residual-allocation-v39-support-preflight.csv/json`。没有新fine值、profile或协方差拟合。

这比“最多六源”更受限。下一步不应直接投入完整四维燃料率协方差模型；三四个源不足以有力检验跨燃料相关，更不能拿月份扩充样本量。先检查较低维的碳方向持续性；若要比较所有六源，可另定义完整发电贡献残差`G_f/C_POS − q_f*profile_f`。它在C_f=0/G_f=0时是有定义的真实零贡献，不等于把无定义的G_f/C_f率填0。这是另一种普通误差表示，必须单列为同预算对照并锁定其尺度、非负与库存支持处理；不能静默替换本草案的率模型或声称增加了信息。
