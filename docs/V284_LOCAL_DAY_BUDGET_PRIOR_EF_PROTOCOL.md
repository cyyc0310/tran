# V284：上一年本地EF先验下的小时校准日数前沿（探索性）

V280已打开的PACE/LGEE 2025 EIA标签作为开发样本；不是外区确认。问题是V282候选方法需要多少个当年完整日，才能校准90%日最大风险。

## 冻结对比

- 目标、oracle月均中心、数据清理、LP和燃料映射沿用V280。
- 因子支持为 `cems_support`（V269季度支持）与V282的 `prior_year_local_ef`（上一年EIA本地活跃小时因子范围）。
- 基线为 `source_loo`：V280七个供体的同月2025每日名义偏差分数。
- 本地风险校准预算为9、12、15个完整日，100次重复，seed=284。每次先随机抽15日，以同一顺序的前9/12/15日做嵌套校准，保证预算间配对。
- 每个抽样集用每日最大逐小时LP端点偏差做90%有限样本分位数。少于9日时有限样本90%分位数为无穷，因此不试低于9日的split-conformal预算。
- 汇报小时覆盖、日同时覆盖、宽度、Winkler；测试日全小时EF集合包含仅为事后诊断。

该试验是在标签已打开、方向由V282开发结果触发后形成，不能作独立确认。目标月均值仍为oracle。不得按本轮结果选择最佳月份或区域。
