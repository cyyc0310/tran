# 五国外层火电因子头迁移误差分解协议

冻结日期：2026-11-01，诊断计算前。目的：解释比例重组和因子历史头在已查看五国LOCO外层任务中为何胜负不同。此项只分解已经评分的2024预测，不训练或选择新模型。

## 重建与核验

- 对每个外层目标，严格按原LOCO合同用其他四国2022小时燃料标签训练`multicountry.fit`，目标端只使用原公开粗月特征和日历。
- 重算的比例重组、因子历史头、macro重组和直接CIF历史头必须与已封存预测文件逐行一致；若不一致则停止诊断。
- 对目标小时标签计算实际粗热电份额`q_true`、实际小时代理强度`y_true`和有热电发电时的实际因子`EF_true`。模型热电份额为`q_hat`，月报`t−2`热电份额为`q_month`；因子头产生`EF_hat`，比例重组使用源统计火电因子`EF_source`。

## 诊断分解

逐国和逐月报告MAE、日内去均值形状MAE、覆盖（沿用既有封存预测区间）、`q_hat/q_month`对`q_true`的误差，以及`EF_hat`对`EF_true`的活跃热电小时误差。另列诊断oracle：`q_true×EF_source`、`q_hat×EF_true`、`q_hat×EF_hat`。目标真值替换只用于解释可见粗份额和不可见内部因子各自的潜在误差，不能作为候选模型、输入或调参信号。两种oracle改进不可相加。

月份结果按月分别计分，国家宏平均等月、等国；另保留小时能量权重指标并明确区分。国家仍是独立评价单位，五国均已查看。本分析不能被称作确认测试或中国实测验证。
