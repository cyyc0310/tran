# V52-R1：仅开发区的残差中心迁移追加协议

日期：2026-10-27。此追加假设是在查看V52 2025开发结果后提出，只允许在相同11个旧开发区进行；不读取或评分封存的新区域。原V52协议和结果原样保留，以下属于自适应开发，不能作为独立确认。

## 假设

SC/NWMT的主要失败呈大幅正有符号残差，说明局部月度组成也许能帮助预测“区域水平偏差的中心”，而不仅仅预测残差宽度。固定原V52点预测形状和输入预算；只改变源校准残差中心估计。

## 方法和对照

对每个外层留出目标区`r`，2024校准期每个来源月`(s,m)`产生校准小时误差`e_{s,m,h}`及中心`c_{s,m}=mean_h(e)`。预测2025目标区时比较：

1. **No-center**：原V52点预测与未中心化pooled q90。
2. **Seasonal source-center**：目标月中心取其他校准源同一月份`c_{s,m}`的等源平均；每个校准源的中心用同月其余源交叉拟合，中心化后按源等权校准对称q90。
3. **Monthly-mix Ridge center**：用目标可得的thermal share和wind+solar share，以来源平衡Ridge拟合来源月中心；校准预测按整源交叉拟合，中心化残差再按源等权校准对称q90。

点误差和区间都以相同2025标签行计算。报告H1/H2来源等权宏覆盖、最差源覆盖、宽度、Winkler分数、点MAE和剩余中心偏差。不得用2025目标残差拟合或调中心。

## 判定

只有中心预测在H1与H2点MAE均低于no-center，且对应区间同时改善覆盖/分数、不靠增加平均宽度和仍不低于85%的最差源覆盖，才记作开发候选。该门槛无法单独证明算法新颖性；若通过，先审查强基线和论文重合度，再冻结全协议后测试未评分区域。该探索有明确数据驱动假设，不能冒充预注册或新区域确认。
