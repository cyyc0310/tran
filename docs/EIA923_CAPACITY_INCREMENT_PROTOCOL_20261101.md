# 官方月统计上的年度煤气装机独立增量协议

冻结日期：2026-11-01，预测运行前。研究问题是：在EIA-923 BA月量已作为公开粗月预算时，再添加公开年度煤/气装机份额，是否对US↔GB小时发电强度代理有增量？该实验属于美英开发回测，不是未查看地区确认。

## 同预算配对

从既有EIA923月统计实验复制唯一的数据/时间合同：美国月量来自EIA-923 2022—2024年度最终文件并按BA聚合；GB月量来自原NESO小时表回算；预测只使用精确t−2及更旧的五类粗组成。源小时监督为2022，源风险拟合为2023H1、校准为2023H2，目标为2024共同2、4、6月。目标小时标签直到预测文件写完并哈希封存后才读取。

比较两臂：

- **M**：EIA-923月组成模型，原有源端固定因子/小时形状重组和历史月预测器。
- **M+C**：相同模型、相同月量与样本，额外使用预测时已公开的年度煤/气装机结构；装机不做小时硬上限。

装机锚把热电因子替换为`EF_thermal=400+600×coal_capacity/(coal_capacity+gas_capacity)`，与已有年度容量形状锚定义一致。每个源和目标地区都按登记地区容量计算。美国BA使用EIA-860 2020 OP登记BA聚合值；GB使用DUKES统计的UK全境代理（含北爱尔兰）。装机统计年和可用时间来自[冻结输入清单](../data/capacity-public/annual-2021/annual-coal-gas-budget-2020.json)。这是静态信息预算，不作为动态容量预测，也不把其统计口径当作小时运行份额。

两个臂分别在同一源小时样本上重建风险模型，避免沿用未考虑新点预测偏移的区间。保留七种月预测方法及全局、异方差、CQR区间。主指标是共同月份逐地区和等地区宏平均的MAE、日内形状MAE、90%覆盖、区间宽度和区间评分，并报告MISO等最差区。

## 边界和判读

此处发电侧固定因子标签是数据集代理，不是官方CIF真值。EIA-923历史值为当前Final，不是各历史预测时点的as-issued版本。月报和装机均不是中国数据；GB容量统计范围略宽于标签区域。装机若仅改善平均水平、未保持覆盖或收益不能在最强月量基线上复现，只能称预算信息价值，不能据此宣称新算法。不要以本开发集挑一个目标专属乘数。
