# V63 按低频组成相似度加权逐燃料小时形状池

日期：2026-10-27。针对V62“最新本地全燃料构成有点价值、等权来源形状未修风险”的开发信号，检验目标与来源的预测时可见月度全燃料构成相似度，能否选择更合适的来源小时形状。所有17个区域已开过标签，因此本实验仅作来源内开发，不构成独立确认。

## 预测构造

- 目标月使用最新可得月度八燃料份额（`period_end <= origin`且`available_at <= origin`），和V62候选相同。
- 每个来源的候选小时形状取预测年上一年、相同历月的UTC逐燃料平均曲线，各燃料独立归一为24小时份额。目标逐小时燃料权重为“目标最新份额×来源形状”，再按V54固定EF计算CIF。
- 距离用八燃料份额间Bray–Curtis距离 `d=Σ|p_t−p_s|/Σ(p_t+p_s)`。来源核权重 `w_s ∝ exp(−d/τ)`，所有权重归一；不添加目标标签、不用目标区历史小时形状。
- 比较等权池 `τ=∞` 与 `τ∈{0.05,0.10,0.20,0.40,0.80}`。每个外层地区的τ只由2024H1整区留出点MAE最小确定；评估验证源时，来源形状与距离均排除被留出验证区。并列时选较大的τ（较接近等权）。

## 时间嵌套与区间评分

- 2024H1：仅选核带宽；2025H1：独立校准；2026H1：时间前推评估。目标外层源不参与τ选择或校准。外层若属于11源校准池，则各交叉拟合阶段都排除它。
- 2025H1每个校准区预测均从形状源池排除外层区和该校准区；固定τ后，以来源等权的绝对误差90分位产生pooled区间，并报告来源最大q90对照。2026测试不再调整τ、q、方法或数据门槛。
- 主要指标：点MAE、pooled覆盖、最差区覆盖、平均宽、Winkler、各区选择τ与月份完整性；对照V62等权最新构成形状、V62滞后同比形状、V53型本地最新热组EF强锚、平铺最新全燃料CIF。
- 只有点MAE较V62等权和V53型热组锚均下降≥5%、至少12/17区改善、pooled覆盖90–95%、最差区≥85%、且Winkler下降并且区间不变宽，才有方法晋级信号。否则判定低频组成距离不能解决形状/风险迁移。

## 限制

相似度加权是标准迁移基线，不预称算法新颖。测试的是EIA固定EF代理，不等同中国口径；模拟月表发布时间继承已审计V54的月末+30天。负结果关闭本轮月组成选形状支路；正结果也只能支持新信息价值或后续方法设计，不能用已开17区宣称独立域确认。
