# V89：滞后一年容量是否仍能收紧月度小时尾界

冻结日期：2026-10-28。沿V88解析容量界继续检验as-of信息：2024评分月份使用2023年末EIA-860容量，2025评分月份使用2024年末容量，模拟目标年度开始前已发布的年度容量，作为各BA×燃料的每小时发电上界，是否能收紧V66月度K锐集。研究队列固定V84 25个EIA BA，窗口2024–2025每月，阈值100/300 g/kWh；小时标签沿用V54/V84固定EF代理。

容量由官方EIA-860 Plant表的Balancing Authority Code和Generator表合并。对operable inventory中OP/OS/SB机组，按每个generator已列明的任一燃料类别分配其`max(nameplate, summer, winter capacity)`；多燃料机组全容量重复记入每个可用类别，以保持容量上界保守。燃料代码映射为V54八组；未映射源归到other。使用滞后年末快照，降低同年容量发布泄漏；年内新投运会令滞后容量不足，任何小时观测超过容量的BA月仍排除并报告。机组容量与BA小时生成边界可能不完全匹配，故逐BA月燃料检查观测小时峰值是否都不超过映射容量；任何一类违反的BA月不进入容量收益评分，并单独报告占比。此排除使用观测小时，是回溯机制审计，绝不能解释为前瞻筛选规则。

在可行BA月，按容量聚合的必要外集与V66无容量锐集比较。若高/低阈值两组分别含K个事件小时及T−K个非事件小时，组内月燃料总量必须受`K*C_f`、`(T−K)*C_f`容量约束；并检查事件组净超额为正、非事件组非正。因为每组小时共享相同容量且无跨小时耦合，组总量按事件/非事件小时均分可行；解析可行性检查同时要求两组小时总发电为正。由此得到在所声明容量约束模型下的锐K集合；需验证它包含实际K且嵌套于V66。决策目标为月内K/T≥1%、5%、10%。任何不包含观测K、V88界比V66更宽、或硬容量与小时观察冲突时均停止或作为不可用边界报告。

所有容量来自回溯年末库存，不是小时可用容量/强迫停运/辅助服务数据；不使用启停、爬坡、负荷或电力交换约束。EIA BA结果只能验证物理机制，不能转为中国省级部署主张。源文件SHA256和逐BA月容量质量表必须随结果发布。
