# V168：源内掩蔽燃料形状的信息价值

评分前冻结。本轮只做条件补全的源区诊断，不是零本地小时CIF预测，也不能据此通过原预测gate。条件输入含被当作供体世界的已观测其他燃料小时形状；未来部署只能把这些输入取自proper源供体，绝不能取自真实目标未来小时。

人工掩蔽隐藏的是原本有定义的正月量燃料q；自然零月量燃料的q则没有被观测定义，两者不等同。即使这项任务成功，也不能据此识别源区燃料出现后的真实反事实，或套用随机缺失保证；之后必须检验实际跨组成迁移及完整预测。条件采样补全本身已有研究，例如[MissARF](https://onlinelibrary.wiley.com/doi/10.1002/sim.70379)、[非参数copula补全](https://link.springer.com/article/10.1007/s10182-026-00561-w)，本轮普通森林控制不作为新颖性主张。

## 固定数据和掩蔽

沿用V159的29源六折、2024、asof_30d每源≤4096小时抽样及proper/test地区。calibration地区本轮不参与拟合或评分。proper标签只来自同一抽样小时，源月正燃料的q_j=g_j/(M_j/Tvalid)有定义；源月为0时q=1仅是输入占位，不能作为被预测形状的标签。

每个原241个test月，从其既定源小时抽样中等距选择64个小时，全部月份都有足够样本，合计最多40896个小时×mask查询。每月掩蔽最大正EF燃料、最大零EF燃料，以及两者的组合；没有相应组则跳过，重复mask合并。选择只用粗月组成，不看小时标签，共639个profile/mask案例、14种mask模式。其他燃料仅在该月有正量且不被掩蔽时可见，其q取log1p并附可见性标记。

训练每种mask时，仅保留proper源月中所有被掩蔽燃料均有正量的既定小时。输入base为原20维current-month粗组成/总量/日历特征（age=0）；完整条件输入另加8个可见q与8个可见标记，共36维。条件风险需要源世界内小时值，不等于只用20维粗输入的完整预测任务。每类训练样本按地区均衡；不获取更多源小时。

## 八个普通控制

1. flat：所有掩蔽q=1。
2. clock_independent：同钟点proper源经验q边际，地区均衡；不同燃料独立组合。
3. coarse_joint：仅20维base的经验叶联合分布森林。
4. conditional_mean：36维条件森林叶分布的精确均值，点补全。
5. conditional_independent：完整条件raw-q森林的边际独立组合。
6. conditional_joint：同一个完整条件raw-q森林的联合叶原子。
7. conditional_joint_log：同配置森林以log1p(q)作分裂响应，叶预测仍保留原始非负q联合观测。
8. conditional_joint_imputed：同36维raw-q森林，但保留全部proper小时，把源月零燃料的q=1占位也当作标签，用于审计旧填补约定。它没有获得更多真实标签；新增的是伪标签。

森林统一32棵、min_leaf64、全特征、seed20261028，经验叶按地区权重、树等权，沿用V159的索引精确混合。clock控制也使用同一mask的可观测训练行，再拆边际。每mask/proper为1～127小时或不足2源时，不拟合森林，显式回退同钟点经验分布并记录；完全没有可观测训练行则拒绝实验，不借用test补足。粗统计库存预检表明本轮48个fold/mask块均至少15951小时、5个proper源，不触发回退。

联合叶原子按原索引顺序、累计权重的1024个等距中点作确定重采样。conditional_independent对同一批1024个联合样本的列做4组固定种子的独立排列后混合；重排前每燃料边际与conditional_joint完全相同。单燃料mask两者必须完全相同，不能当作两项独立增量。clock边际用相同1024点加权分位数与4组独立排列。条件均值采用未重采样的精确叶权均值。报告重采样均值偏差；在固定的每月/模式第一个查询，对conditional联合及独立两臂用4096粒子做数值敏感性对照，不按分数选择粒子数。共639×8=5112条profile/mask/方法评分记录。

有限次重排是独立乘积分布的数值近似，并不构成精确乘积；各边际相等则是精确性质。若联合收益与重采样/重排压力差异同量级，不能认定耦合有明确增量。

## 评分与约束

用掩蔽世界已知的组成、其他燃料q和预测q补全重建CIF。所有方法都在G>0条件化，记录拒绝概率；若整项提案均为0，则回退flat并记录。当前月已知正燃料限定EF凸包，真实及预测CIF仅对该物理范围作数值裁剪；真实裁剪误差必须≤1e−9。报告严格及64eps容差覆盖，不将贴边舍入算创新。

每masked燃料q的CRPS在正G条件化之前评分，条件联合/独立的边际q分数必须一致。CIF报CRPS、均值MAE、原始90%区间覆盖、宽度、Winkler；本轮不以新校准加宽掩盖补全质量。按profile/mask先对所选小时均值、再同profile各mask等权、再地区内月份等权、最后等地区。另报混合EF月份子集及双燃料mask子集。所有子集由粗月组成/mask定义，不能按结果选。

同时保存病例数、训练mask可观测样本数、proper地区、原索引摘要、回退、正G拒绝率和重采样数值误差。预测特征隐藏性干预：修改被掩蔽q标签，输入必须完全不变。原始g重建真实CIF的身份、单mask联合/独立相等、双mask边际相等都需预检。

若条件联合不能稳定胜过条件均值、粗输入联合和相同边际独立控制，不开发专门copula机制。若只恢复q而没有CIF风险收益，不视为论文突破。源区已多轮查看、当前粗量/未掩蔽小时值在这项诊断中已知，任何正结果只表示补全有潜力；之后仍须完整合法asof预测、同预算强参考、原覆盖/效率gate及真正未查看地区确认。固定EF代理、合成发布日和共享2024时段限制保留。
