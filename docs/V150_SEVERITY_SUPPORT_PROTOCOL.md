# V150：正误差幅度的维度与源区影响

在V149结果后、V150评分前冻结。复用相同的完整月度信息预算、30拟合/12校准地区、两seed、两alpha和PACE/LGEE/SC完整目标月份，没有新确认地区。

水平/纵向两族各比较五种正误差幅度尺度：V149全部56特征Ridge；11维月度组成/总量/月份Ridge；9维响应几何Ridge；几何模型逐个剔除正误差源地区后的对数预测均值；正误差区域等权对数均值常数。Ridge均alpha=10，输入标准化只拟合proper源月，正误差拟合权重为等正误差地区总权重。所有尺度按expm1(log1p(256δ))/256转换并裁剪[1/256,1]。不挑选目标表现最佳模型作为部署规则。

几何特征预定为：煤占比，600低响应q05/高响应q95，900高响应q95，600低/高响应标准差，900高响应标准差，缺失燃料质量、有效源地区数（后两项用600处固定条件权重）。组成特征为八燃料份额、log总量、month sin/cos。

对全部特征与几何模型逐个删除正误差源地区重拟合，保存查询尺度范围；此处保留原来的响应教师，故只是拟合影响诊断，不是完全排除该地区的外部验证。几何jackknife在对数空间平均。无正样本则常数0，再按尺度下限处理。

仅以独立12校准源区的正误差月份评估对数幅度MAE，同时报告每折正误差地区数与最大拟合影响。这个诊断不用于选模/调参，校准依然在同一12区作区域max/rank，不改V149规则。对目标同样评估月度因子盒尾数端点的覆盖/宽度/评分/fallback，非小时预测覆盖。全部特征模型必须复现V149 positive_severity的1,056条目标端点。检查冻结哈希、完整分母、角色、alpha嵌套及物理包含。

常数、降维Ridge与jackknife都是强基线/归因对照，尚不主张方法创新。局部改善只有在跨区、跨划分稳定并超过同预算强基线后才有晋级价值。
