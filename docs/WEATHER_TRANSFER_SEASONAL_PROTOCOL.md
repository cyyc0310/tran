# 跨国原生天气小样本信息价值协议

日期：2026-10-31。此协议在下载本批天气、训练模型和查看本批预测误差之前固定。

目标是检验：国外源监督和中国式滞后粗月报条件下，预测起点以前生成的天气能否减少跨国小时误差。单列月报和月报加公开静态装机代理两种预算，延续此前装机版本与范围限制。本轮不是新算法确认，也不打开新国家。

## 日期、空间与可见性

训练起点为2022年5、6、8、9、11、12月15日；源校准为2023年1、3、5月15日；开发目标为2023年7、9、11月15日。共12个UTC00起点，GFS初始化为起点前24h，提取lead24至72共49个原生时次，构成48h天气窗。模型预测各地区起点之后首个完整当地24小时日；并非统一的下一UTC自然日。

美国7区使用既有V10预设单点；GB(54,-2)、DE(51,10)，上海(31.25,121.5)仅解码部署探针。单点不代表区域或电源加权天气。坐标、日期与来源假设冻结在plan.json，先按标签完整性和原点月报可用性生成cohort及SHA封存，不按误差筛日期。英国维持原始UTC日历：[NESO字段说明](https://www.neso.energy/data-portal/historic-generation-mix/historic_gb_generation_mix)明确DATETIME为UTC。美国和德国按原始地区日历，逐日检查唯一性，保留全年DST数据。

月报严格冻结为预测起点当地月份减2及更早历史，仍是修订后小时档案模拟发布延迟，不是原始月报发行版。天气逐对象核验LastModified早于起点，保留ETag、字节范围与SHA；原始公众可用性尚未认证，不能将结果称作已认证真实部署。原生框架的eligible_for_issued_public=False保持不变。

## 公平对照与评分

主比较沿用9种单国/双国源配置、完全留出目标国家。每个配置所有主方法共享所选2022源小时标签、源2023三天校准及目标三个开发日；每个地区最多144训练小时、72校准小时、72开发小时。缺失按共同交集处理并保留记录。只对已有开发地区评分。

预设普通参考：固定火电因子锚、同源标签形状锚、同源标签联合轨迹、直接Ridge/HGB的无天气和有天气配对，以及形状锚残差Ridge的无天气/有天气配对。天气使用同样的温度、100m风速、辐射及固定非线性变换/组成交互，禁止目标标签调参。超参数沿用简单固定值。完整2022源银行联合轨迹可作为额外强参考，但显式标注其额外小时监督，不纳入等标签预算的天气归因。

主区间比较包括源校准的全局残差区间与标准异方差归一化残差区间；联合轨迹保持经验5/95分位加非负校准扩张。报告原始和校准覆盖、宽度、区间分数及最差地区，点预测报告MAE和日内中心化形状MAE。全部目标预测及训练/校准文件先封存再评分。国家等权、国家内地区等权；重复配置不是独立国家样本。不用少量校准日宣称目标域90%覆盖保证。

同标签联合轨迹仅用抽样日归一化，因此部分月份只有一天，其形状不包含完整月内日际变化。完整源银行额外参考用于显示这个抽样损失，不能隐瞒。

## 解释和后续

每区只有三个开发日，日期相关性和季节稀疏性限制很大。若天气有一致增量，再扩大预设日期与空间采样、检查GFS版本变化，并比较条件分位数等更强参考；若没有，分别检查单点空间代表性、源样本量与机制失配，不能据此断言天气无价值。任一结果都不构成创新成立或方法冻结的充分条件。

原始GRIB只在本批拥有的临时目录处理，完成逐点重解码验证后留下紧凑数据及完整来源描述；完成日窗为恢复检查点。中断的未完成日窗需要重取。历史原生试验缓存不删除。
