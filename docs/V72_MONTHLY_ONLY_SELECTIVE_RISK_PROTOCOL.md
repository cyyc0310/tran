# V72：月度边际下的小时风险选择性决策前沿

日期：2026-10-27。V66给出31省2016–2024共3348省月、固定EF下严格超阈小时数K的sharp集合。V72将同一集合转换为选择性风险决策：月报可否认证未来决策目标，或必须弃权。此处是事后识别/决策可行性，不是概率预测或实测小时覆盖。

## 冻结数据与目标

只读取`results/v66-monthly-margin-tail-identifiability-r2/province_month_tail_bounds.csv`；不重算、不调参、不访问其他标签。保留阈值τ=100/300/600/900，及原先相同的Ember月燃料边际、演示EF、小时分配兼容类和31省3348省月。分别判断严格超阈小时数K是否满足：

- 任意事件：`K >= 1`。
- 频率目标：`K/T >= r`，r取1%、5%、10%、25%、50%、90%、100%；整数目标转成`K >= ceil(r*T)`，T为该月真实小时数。

如果sharp下界`K_min >= k*`，认证“达到风险目标”；如果上界`K_max < k*`，认证“未达到”；否则选择弃权。这样接受的任何判断都在既定兼容集合下逻辑正确。每个τ×目标同时报告认证事件、省月无事件、弃权率、接受率及平均sharp比例区间宽。统计单位省月等权；不把相邻省月当独立样本，不报告p值或预测coverage。

## 解释与边界

这条前沿量化现有公开月报可以支持的决策分辨率，以及高比例尾风险何时不可识别。它不能说明这些风险的实际频率，也不能证明策略收益；若真实EF、月边际或可行集合假设偏离，逻辑认证随之失效。选择性弃权是决策输出，不代表模型知道被弃权案例的概率。与无条件阈值点分类比较时，只比较逻辑保证与决策覆盖；没有小时标签就不计算经验误分类率。

V72通过标准：结果必须展示“至少1次事件”的有限认证率，与>=1%/5%等更强频率目标的认证率差别。如果月报只能支持偶发存在性、不能支持实质频率风险，则后续创新应把最小可补充的本地小时信息预算作为研究对象；不继续把低频月边际包装成尾风险预测器。
