# 历史资源参照与日幅度：天气有信息，风险仍未学好

2026-10-31，Sol。按[开发协议](RESOURCE_REFERENCE_DEVELOPMENT_PROTOCOL.md)完成9个跨国配置、两条源标签轨道、两预算和10个固定参考，运行退出码0。协议保留预测前状态；当前状态以本报告和`completion.json`为准。这仍是已见开发集的自适应实验，不是冻结后的新国家确认。

本轮比只修正小时形状更有价值：太阳能比例在装机预算下改善点误差，并在宏平均上略增覆盖、缩窄区间；风光比例的完整源年参考也有点误差及CRPS收益。但英国仍失效，风光的高覆盖伴随明显加宽。**没有建立跨国稳定的“保持可信覆盖并缩窄区间”方法，也没有建立算法原创性。**

## 数据、比较和核验

新增W2历史天气参照由10个原地理点、2016–2020五年、600个完整本地年月组成。原JSON、请求、单位、格点和SHA均保留；每月严格验证绝对小时支持，处理DST、闰月和短波前一小时区间，年度月均再等年平均。参照不包含2022/2023开发日事后天气。原公众可用性仍为False，不能把今天取得的修订ERA5当成认证的历史发布版。最初采集代码已归档，审查后补强传输重试和receipt校验，第二次运行仅恢复并验证全部50个缓存，退出0。

GFS使用既有12个已签发窗口。沿用1200个源训练小时、576个源校准小时和624个唯一目标小时；后者仅德国72、英国72、美国480小时。小银行使用匹配的源标签；完整源年银行单列额外源标签轨道，不能把轨道差值归给天气。两轨道共用九个源2022幅度头，源2023校准日期仅计算区间扩张，目标标签不拟合模型或半径。

源日幅度训练目标为实际日均发电功率／该源在起点允许的t−2月平均功率。月功率直接由合法粗月电量除以预期本地月小时数；200份训练凭证保留月份、起点、绝对电量、小时数和功率。风光之外燃料不改；源未支持的燃料保留q=1。原银行的kernel/RNG不变。气候零值、非有限资源或整行缺失回退，不用未来月量守恒。

新增11项测试通过，另18项相关测试在本轮开发中通过；原有合成常数特征触发的48条sklearn警告保留。独立Sol复核验证2642项输入/代码、374项预测/凭证/环境、9项模型SHA；149760行预测、360个粒子文件复算2160组地区、720组配置和80行宏指标，最大差不超过4.55×10⁻¹³。36项父基线源半径及预测端点核验误差0；12项非零源CQR半径抽查误差0；200份源月功率凭证误差0。

## 源区诊断：天气有排序信息，幅度映射很粗

评分后的源校准诊断不拟合新模型，不用于本轮选参数。23个风电源日中，简单风天气比例对实际日幅度的log1p相关约0.746，地区去均值后约0.741；纯季节比例约0.184。可是log1p绝对误差为0.331，高于纯季节0.264。这提示天气包含日变化信息，同时比例幅度失真；23天不能证明跨国稳定性或因果机制。

例如GB的2023-01-15，天气风比例3.66、实际日幅度1.18；DE的2023-01-16为4.68与1.60。单点天气、GFS/ERA5差异、额定功率饱和、真实滞后月天气和运行结构都可能参与，当前没有分离其原因。

另做普通固定功率曲线的**源区事后诊断**：100m风3m/s切入、12m/s额定、25m/s切出，中间立方增长。用同一原始五年气候计算参照，23日log1p误差0.301、相关约0.754，较裸立方比例改善，但仍不及季节比例的绝对误差。没有用该曲线重新生成目标CIF成绩，也未调这些数值。应将饱和功率曲线作为下一轮强参考，不能据此称新机制或宣称它解决了目标风险。

Ridge还出现严重幅度外推：开发日无天气风乘子最大约9755，有天气约467。没有事后截掉这些负例，也不把Ridge当作已穷尽强学习基线。下一轮需要同预算有界非线性参考，并扩大国外源天气—发电配对训练；不能在三天目标窗口上搜索截断值或强度。

## 论文判断与下一步

已有研究覆盖气候校正、天气到风光输出及概率天气集合。28国物理能源模型已使用天气偏差校正和发电转换；所以“气候参照＋天气比例＋重组”不能单独成为原创方法。[Bloomfield等，ESSD 2021](https://essd.copernicus.org/articles/13/2259/2021/essd-13-2259-2021.html)

WindFM已报告跨地理零微调风电预测，但问题定义中的历史向量包含当地风电输出。本项目仍有明确的输入条件差异：目标没有小时发电/CIF历史，仅给滞后粗月报。不能将这种差异写成“首次跨域预测”，也不能直接给WindFM补当地小时序列后称同预算对照。[WindFM，2025预印本§II-A](https://arxiv.org/html/2509.06311v1)

一篇2026-10-29预印本比较天气到发电的建模选择，强调资源异质性和低发电尾部；这是风险建模的参考，而非对本项目机制的验证。其研究是长期系统设计，也不能直接替代小时前瞻结果。[Karkossa等，2026预印本](https://arxiv.org/abs/2610.39859)

下一步先补两项：固定饱和功率曲线及有界非线性同预算参考；增加外国源区天气—发电配对，区分资源预测误差与天气到电量的响应误差。目标国仍只读取合法粗月报、历史气候及起点前预报。不再只增加确定性风比例或CQR半径。

可争取的方法贡献应落在**无目标小时历史时，怎样从源国迁移日发电幅度的条件分布，同时保留天气解释不了的调度与水平风险**。这需要超越上述普通参考，并检验更完整开发日期、不同国家及相同信息预算下的增量；当前只是得到值得继续的证据，还没有得到原创方法。未知国家继续封存。
