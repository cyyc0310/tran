# 严格五类月报预算下的伪目标条件门控协议

冻结日期：2026-11-01。研究问题是：海外小时标签能否训练一个只依赖中国预测端可见的五类粗月统计的条件组合器，并在真正整国留出中改善强基线？本实验是九国开发回测，不是盲区确认。

## 输入与外层切分

- 外层国家为AT、BE、CZ、ES、HU、NL、SE、SI、SK；逐国留出。
- 源专家仅用2022小时燃料代理训练。目标端只允许火、水、核、风、光五组的t−2至t−7月统计份额、日历与由这些月量构造的历史特征。`other_renewable`保留在小时代理标签的分母中，但不进入月报、形状参考、专家或门控。
- 目标2024小时标签在所有目标预测文件写盘封存前不参与拟合、特征、模型/惩罚选择或校准。
- 伪目标跨拟合：每个外层源国轮流留出；该伪目标的2023H1/H2小时标签只用于源侧元学习与校准。伪目标专家仅由其余国家2022标签训练。
- H1拟合门控，H2估计来源国等权90%绝对残差半径；在目标预测封存后才读取目标标签评分。

## 方法与强对照

专家固定为严格CN5 `multicountry_cn5`中的anchor700、macro重组、ratio重组、ridge历史、direct最新/历史、factor最新/历史八种方法。门控对八个预测器做凸组合，权重为五个当前粗月份额及既有火电均值、标准差、变化、总量变异和观测数的线性softmax。

岭惩罚从{0.01, 0.1, 1, 10, 100}中选择，内层按伪目标国家等权MAE。比较八种专家、等权平均、固定全局凸堆叠、条件门控、伪目标内层选择单模型；所有方法按相同来源H2残差约定校准。

报告国家、月份等权的MAE、日内形状MAE、经验覆盖、区间宽度和区间评分。门控只有在宏平均不劣于ratio重组和伪目标选择、且多数留出国不牺牲覆盖与区间分数时才考虑进入新域确认。小时数不是独立国家样本，不能用小时级显著性宣称泛化。

## 适用范围

Energy-Charts小时序列派生的固定因子发电侧代理；粗月量由修订小时序列重算，模拟统计滞后，不是历史as-issued月报回测。没有中国小时CIF真值。实验的结论仅回答严格五类信息预算下的海外整国代理迁移表现。
