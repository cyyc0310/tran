# CN5模型分歧风险映射：严格双重整国留出协议

冻结日期：2026-11-01，r2运行前。r1的单层伪目标校准发现一个模拟边界不足：评估伪目标`T`时，虽然T自己的预测模型排除了T，但校准集其他伪目标模型可能把T的2022小时标签用于训练。r2在每个外层T折中同时从校准预测模型与伪目标训练模型排除T，严格模拟一个未提供任何年份小时标签的新目标。

## 外层/内层数据边界

- 九国严格CN5输入；2022细燃料小时代理只用于源训练，2023H2只用于伪目标风险验证；标签是固定EF发电侧代理，月报由修订小时值严格滞后模拟。
- 对每个外层伪目标国`T`：最终测试预测器只在另外八国2022标签上训练，并仅向T输入2023H2合法CN5特征。
- 为给T构造风险校准集，对每个校准伪目标国`C != T`，重训预测器时排除T和C；模型只使用余下七国2022标签，并预测C的2023H2。这样T的历史小时标签不进入风险映射所见的任何预测器。
- 两个风险信号固定为`|factor_history − ratio_recomposition|`与三模型（ratio、factor、fuelshare）的逐小时预测范围；风险目标固定为比例重组绝对残差。
- 每个T折分别以其余八国双重留出伪目标预测构造：(a)国家等权全局q90；(b)分歧合并三分位数分档的条件q90。每档须有至少4个不同校准国，否则回退全局半径。每个校准国总权重相同，每国档内小时等权。
- 逐T评价区间覆盖、宽度、Winkler分数、最差国覆盖和日级误差风险Spearman。所有九个外层T均参与同一规则，无2024标签调参。

## 通过门槛

候选相对全局半径须同时降低国等权宏区间分数至少5%、宏覆盖不低于88%，且无外层伪目标国覆盖下降超过10个百分点。未通过则关闭分歧条件风险映射，不再扫描分档数/分位点。
