# 伪目标训练的火电因子响应收缩协议

冻结日期：2026-11-01，模型拟合前。前一轮误差分解显示，源域固定火电因子难以覆盖荷兰的季节性内部燃料结构；自由预测因子头在一些外层国家也不稳。本轮检验由伪目标国小时监督学得的单一收缩系数，是否能保留固定因子重组的稳定性并利用因子历史头的信息。

## 任务与模型

- 仍使用已查看的Energy-Charts五国留一国开发回测、2022源小时拟合、2023H1伪目标任务训练、2023H2来源误差校准、2024目标小时评分；月组成只用t−2及更旧的六类粗月统计。
- 每个外层目标T中，源国轮流做伪目标c。基模型仅在其他外层源国的2022标签拟合，分别输出固定比例重组`p_ratio`和历史条件火电因子头`p_factor`。伪目标2023H1小时标签是门控/收缩训练监督。
- 候选输出为`p_alpha=p_ratio+alpha*(p_factor-p_ratio)`，`alpha`只从`{0,0.25,0.5,0.75,1}`选择；每个源伪目标等权，以MAE最小选择最终alpha。`alpha=0`即强比例重组，`alpha=1`即未经收缩的因子历史头。
- 通过leave-one-pseudo-country-out重新选择alpha并预测被留出伪目标H1，报告内层泛化误差与所选alpha，检查系数是否由单一伪目标驱动。最终外层alpha仍只用全部源伪目标H1训练。
- 使用相同cross-fitted源模型预测2023H2，分别为比例重组、因子历史头和收缩方法估计源域等权90%对称残差半径。外层2024预测全部写盘哈希后才读取目标小时标签。

## 比较与判据

保留比例重组、macro重组、因子历史头、直接CIF历史头及收缩候选；报告五国等权MAE、日内形状MAE、90%覆盖、平均宽度、区间评分和逐国结果。所有目标国均已查看，因此只是开发评价。只有收缩在多数外层国家保持或改善覆盖、超过强比例重组的MAE/区间评分，并在不同留源组合下稳定选择非零alpha，才继续；单个目标改善、只缩窄区间或接近已有因子头都不构成方法增量。

这是已有因子预测头与物理基线之间的源端收缩，不预先声称新算法。历史月量仍从修订小时序列回算，结果不是严格as-issued发布重放或中国真实CIF验证。
