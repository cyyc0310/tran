# V144：规范 EF 与源月组成响应缓存

## 范围与数值契约

本轮只整理此前已检查的 43 个地区、2024—2025 年的 936 个有效地区月（677,928 个有效小时）；没有新增地区、时段或独立验证。每个地区月在两个阈值（600、900）和 EF 盒两个端点各有一个计数。沿用旧浮点 EF 时，缓存逐一复现了全部 3,744 个归档端点计数；月度燃料边际量和小时原始值也保存在缓存中。

规范 EF 按既定八类燃料顺序（煤、气、油、核、水、风、光、其他）使用**整数常量**：名义值 `(1000, 400, 800, 0, 0, 0, 0, 400)`，低端点 `(900, 360, 720, 0, 0, 0, 0, 360)`，高端点 `(1100, 440, 880, 0, 0, 0, 0, 440)`。旧浮点契约的高端点中，气和其他为 `440.00000000000006`，油为 `880.0000000000001`。在严格大于阈值的判断下，改用整数常量后仅下列六项各减少 1 小时；其余 3,738 项不变。这是标签数值契约的修正，不能计作预测方法收益。

| 地区月 | 阈值 | 端点 | 旧计数 → 规范计数 |
|---|---:|---|---:|
| FMPP 2025-08 | 600 | 高 | 205 → 204 |
| JEA 2024-09 | 600 | 高 | 632 → 631 |
| NWMT 2025-03 | 600 | 高 | 407 → 406 |
| SEC 2025-05 | 600 | 高 | 151 → 150 |
| SEC 2025-07 | 600 | 高 | 208 → 207 |
| TEPC 2024-09 | 600 | 高 | 75 → 74 |

## 源月组成响应与核验

对一个源月的逐燃料完整小时形状，先按该源月的月度燃料总量归一化；再乘以查询月的燃料边际量，用规范 EF 计算假设组成下的严格超阈小时比例。源月没有某燃料时，按平坦小时形状补足。这一响应假设源月形状在组成变化后仍可迁移；它不是因果干预结果，也不是物理上尖锐的识别集合。完整源月均匀抽样保持时间归一化后的月度边际量；当源月和查询月有效小时数不同，不保证能还原查询月实际小时序列。

缓存包含 936 个查询月 × 936 个源月 × 2 个 EF 端点 × 2 个阈值，共 **3,504,384** 个响应计数。每个源月在自身组成下的 3,744 个端点响应均与规范标签相符；另有 96 个跨地区源月／查询月组合经过独立的完整有理数复核。17 个近浮点边界的符号判定转入精确算术，实际浮点符号纠错为 0；全部审核的 assertion failure 为 0。输入、脚本、缓存哈希与逐项跨地区审计均随结果保存。

缓存只供后续预测器读取源地区响应。查询月可输入完整月度燃料发电类别及边际量，但目标与校准地区的小时形状不能作为供体；目标自身的 EF 盒端点和 V143 的 oracle factor floor 只能用于评估。用户已确认全部月度燃料发电类别可得，容量和天气不属于本轮主信息预算。规范整数 EF 仍是**假设的代理 EF 盒**，不是实测中国排放因子不确定性；本轮也没有打开未知地区或完成小时 CIF 预测检验。
