# 粗组成参与解码：受限增量对照

2026-10-31，拟合前固定。本轮仍为已查看美英国家上的开发实验。

沿用上一轮2022共同训练小时、六美国源区/英国源、2023源校准、2024目标评分。共同月份2/4/6等月后等区；全部可用月份另存。固定t−2视图三次重复；不再增加时效视图。首轮六个参考在同训练支持上重训。

五候选共用32×32 Tanh骨干、九输出、零初始化输出层；600步、batch1024、Adam .001，seed412/413/414。相同输入、源监督小时、采样和参数数。固定粗组基点q0=滞后份额×源小时轮廓；CIF0=源火电EF×q0火电占比。

- residual：CIF0加±150g/kWh受限残差，裁剪0–1000。
- factor：只学习火电内四燃料logits修正，幅度±1.5，经固定EF换算变化，再相对源火电EF修正，裁剪400–1000。
- shape：只学习五粗组小时倍率exp(±.5)，以q0重组。
- joint：factor与shape同时学习。
- joint_aux：同joint，另加源小时火电内部占比MSE，系数.1，零火电小时不贡献辅助项。

只有factor/joint/joint_aux使用可学习火电因子；没有任何目标细分或小时观测。训练prior为源区域均衡权重下火电细分量之和归一化；无新增本地信息。关闭学习增量的推理分支逐元素返回相同预算强重组；零输出神经实现因float32只承诺数值容差。辅助占比不宣称被中国月表识别。

Gaussian均值方差仅由源2023残差计算，所有方向预测先写盘封存后评分。报告raw与源偏差修正后的MAE、形状MAE、CRPS、覆盖宽度和区间分数。启动即封存代码/协议哈希，退出时检查未改变。各参考仅训练成本不同，不给额外响应小时；候选五组训练步数与参数数相同。

比较结构候选与普通受限残差、强重组，及joint_aux与joint。强重组身份/受限残差/物理重组都是已有机制，不能单独命名为创新。若优势只来自均值修正或宽区间，候选不晋级；若仍不稳定，先补多国源支持与训练期留域证据，再决定下一机制。
