# V262 冻结协议：小时总量误差对尾风险识别的敏感性

日期：2026-10-30。V239 的16个已打开 EIA BA-month 与500 gCO₂/kWh阈值；本实验不构成新地区盲测。

## 问题

V237–V239显示，准确小时总发电量可显著缩窄月度燃料边际下的整月超阈小时数锐界。但中国可公开得到的小时负荷通常是天气/典型曲线重建值，不是发电调度测量。V262检验小时总量观测存在相对误差时，风险集合还保留多少信息价值。

## 冻结输入与信息预算

- 固定 V239 的已开数据中的6个2025 BA-month：PACE 4/7/10月，CPLE 7月，ERCO 10月，AZPS 4月。该压力样本刻意覆盖PACE三个季节，并加入三个对照BA/月；选择不使用本轮尾数结果。月度燃料边际、每日总量、固定因子 `[1000, 800, 400, 0]` 和500 gCO₂/kWh阈值与V239一致。
- 参照是精确每日总量条件，不改变月边际或每日信息预算。
- 将真实小时总量乘以交替正负的 `ε/2` 形成带偏观测曲线；其后计算所有满足逐小时盒约束 `q_hat(1−ε) ≤ q ≤ q_hat(1+ε)`、精确每日总量与月度燃料边际的可行调度。
- 预设 `ε∈{0.05, 0.10}`。按构造，真实小时曲线必在观测盒内；不抽取标签驱动误差，也不挑选有利BA。
- 对每个盒约束可行集，用MILP最小化/最大化全月 `K=#hours(CIF≥500.0001)`。仅两端均证明最优的案例进入汇总。

## 主要终点与判定

逐案例报告每日-only宽度、带误差小时曲线宽度、绝对和相对收窄、优化状态、实际固定EF尾数是否被包含、以及从精确小时曲线到带误差曲线的效率损失。信息集合须满足：月边际→每日总量→误差小时曲线的嵌套；所有实际尾数见证都在锐界中。不得把集合包含率称作预测覆盖率。

这项压力测试只有在5%–10%误差下，多数BA-month仍显著优于每日-only，才支持“可容忍误差的小时总量摘要是有价值的最小本地信息”。本轮是重点压力样本而非全体外推。即使成立，也只证明固定EF EIA生成结构上的识别机制；不证明中国天气重建负荷等于发电量，不评估小时CIF预测精度，也不构成算法创新本身。

## 停止规则与限制

若小时总量轻微误差使可行集回到每日-only宽度附近，则停止将重建负荷视为可部署替代量；研究结论只保留实测逐小时总发电量的信息价值。固定因子代理不含机组热耗差异、网络潮流、进口强度与储能。所有V239目标区都已打开，结果是敏感性复算而非外测。
