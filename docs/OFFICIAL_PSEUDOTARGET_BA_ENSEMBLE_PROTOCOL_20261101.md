# EIA 官方消费侧标签：留 BA 伪目标专家与组成相似门控协议

2026-11-01，运行前冻结。实验只推进 US→GB 官方消费侧小时强度迁移，回答多 BA 源端模拟“新目标区没有小时标签、只给滞后粗月报”是否有助于跨国冷启动。GB 2024目标结果已在前序官方标签实验中查看；本轮属于已知目标上的方法开发，不能称独立或未查看确认。

## 目标预算与数据隔离

- 训练标签：美国7个EIA balancing authorities的2022消费侧官方估算强度。校准标签：美国同7个BA的2023H2强度。训练和推理输入均只包含当地日历、t−2及更早的五类粗技术月份额；不输入小时燃料、负荷、交换流或目标CIF。
- 伪目标标签：每个美国BA的2023H1消费侧强度，只用于源内门控温度选择。目标GB所有2024标签在本轮预测文件全部封存前不得由本轮代码读取。由于旧实验已生成并读取过GB 2024标签，磁盘上文件存在不代表本轮盲测；运行审计需同时记录预封存文件名，并明确本轮属于开发集评价。
- 目标发电粗月量来自NESO燃料序列，以t−2及以前构造；统计来自修订序列，不是历史as-issued月报。NESO消费侧响应是修订官方估算，不是直接测量。
- 只评US→GB。GB→US只有一个GB源区，无法训练多源伪目标专家，不把该方向伪装成同构任务。

## 方法与冻结比较

1. `pooled_direct`: 全部7个美国BA 2022标签拟合的同预算粗特征HistGradientBoostingRegressor。固定参数：100轮、15叶、最小叶样本100、L2=10、random_state=412、关闭早停。
2. `pseudo_uniform`: 7个留一BA专家的等权平均。专家j以其他6个BA的2022标签训练。
3. `pseudo_gated`: 使用同一7个专家；对每个预测时刻，比较目标当前粗组成向量与专家被留出BA按2022日历月份聚合的粗组成原型，按标准化均方距离的softmax权重合并预测。它不读取目标小时标签或未来月统计。
4. `fixed_ef_recomposition`: 当前强重组参考；另报告粗特征Ridge、calendar Ridge和源均值直接参考。

门控温度集合固定为`{0.1,0.25,0.5,1,2,5,+∞}`；`+∞`对应等权。每个源BA r作为伪目标时，先排除r，再逐个排除其余BA j拟合内层专家（训练集只含剩余5个BA），在r的2023H1样本上评分。对7个伪目标BA等权汇总MAE后选唯一温度；目标GB标签绝不参与选型。伪目标和正式专家使用相同输入、标签定义和HGB容量。

最终正式专家分别留出一个美国BA、用其余6个BA的2022数据拟合。源2023H2对 pooled、uniform、gated 和其他参考分别估计源区等权Gaussian偏差/尺度；目标覆盖不参与乘数或模型选择。

## 评分与停止判断

所有模型共享GB 2024共同小时。预测写盘并哈希封存后，才从EIA/NESO原始源分别提取GB 2024响应。按月评分并报MAE、日内形状MAE、Gaussian CRPS、90%覆盖、宽度和区间分数；同时报告留BA的伪目标折表现、门控温度、逐月结果和最差月。若门控未超过pooled与固定EF重组，或覆盖收益只靠变宽，保留其为基准实验，不主张方法创新。小时数不当作独立地区重复。

这不是严格元学习：没有梯度式任务优化或目标训练，只是跨拟目标留区的集成与输入相似门控。已有跨国粗组成条件专家实验和伪目标LOCO模型选择是相关先验结果；本轮价值在于检验同一类思想能否迁移到官方消费侧小时标签。
