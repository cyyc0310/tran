# US→GB 2025官方发电强度迁移结果

更新：2026-11-02。按[预测前冻结协议](CROSS_COUNTRY_2025_US_TO_GB_OFFICIAL_GENERATION_PROTOCOL_20261102.md)完成，补齐US↔GB官方发电强度2025开发矩阵中的反向方向。GB是已反复分析过的国家，2025强度为当前API历史值；这是同域时间留出，不是盲地域确认或真实as-issued回放。

## 数据与预测

- 源：EIA-930七BA的官方生成CO₂强度，lb/kWh转g/kWh；2022–2023训练、2024来源校准。七BA等权进入模型与校准。
- 目标：NESO 2025国家`intensity.actual`，官方API记录17,520/17,520个半小时区间，实际强度缺失0个。每个小时由两个半小时值取均值得到，共8,760小时，无缺标签。
- 目标输入：NESO历史燃料生成序列只转换为火、水、核、风、光五类月度份额，严格滞后`t−2`。2025年每月的来源月为2024-11至2025-10。英国月量来自当前修订燃料序列，不是逐月as-issued档案。
- 六种冻结方法：700火电份额锚、源热电有效因子锚、日历Ridge、CN5 Ridge、CN5 HGB及源燃料响应/小时轮廓重组。来源90%区间的误差偏差与半径只由2024 EIA校准数据决定，不使用GB目标结果。

## 2025结果

单位gCO₂/kWh，所有方法在相同8,760小时上评分。

`anchor700`的MAE比源燃料重组低35.9%，区间宽度也窄27.7%，Winkler分数低23.4%。重组达到100%覆盖是以约437 g/kWh的宽度换来的，没有同时满足“保持覆盖并缩窄区间”。直接CN5 Ridge/HGB都没有优于简单锚；Ridge仅覆盖2.5%，是严重负迁移。

月度拆分中，锚点误差在3月最高（MAE101.92，覆盖79.8%），在7月最低（MAE36.42，覆盖100%）。重组仅1月和3月MAE低于锚点，其他10个月均更差；重组固定宽区间在全部月份100%覆盖，反映宽度不足以定位误差月份。

## 与GB→US 2025官方结果的并列判断

| 方向 | anchor700 MAE / 覆盖 / 宽度 | 源燃料重组 MAE / 覆盖 / 宽度 | 简单判断 |
|---|---|---|---|
| US→GB：EIA监督→NESO `intensity.actual` | **68.34 / 96.15% / 315.82** | 106.65 / 100% / 436.81 | 锚同时更准、更窄，区间分数更低 |
| GB→US：NESO监督→EIA `CO2.GER` | **81.88 / 71.13% / 211.66** | 87.06 / 66.86% / 183.23 | 锚更准且覆盖更高；重组更窄是失覆盖 |

两边均未证明源燃料重组优于简单锚；锚点两边点误差更低。区间也都没有呈现可双向迁移的可靠机制：US→GB锚在此目标年覆盖高于90%，反向GB→US仅71%。两个机构使用不同排放因子、机组/BA边界与标签构造方式，不能把两行合成同口径统计估计或声称严格对称复现。结果仍足以说明：仅给t−2 CN5月度份额时，复杂小时燃料头并不会自然胜过热电水平锚。

## 路线结论

1. **优先级1取得更完整的官方估算双向开发对照，但尚未完成地理外部确认。**US→GB固定因子代理既有2024/2025时间复核，现新增2025官方强度响应；反向GB→US也已有2025 EIA官方`CO2.GER`结果。2025目标输入仍是修订月量回算，非发行版预测回放。
2. **优先级2的训练模拟仍未证明机制增益。**这轮完全按中国式五类滞后信息预测；直接粗回归和源小时重组均败于700锚。下一轮不应增加模型复杂度扫描，而应在源国伪目标中检验哪些关系能跨估计制度/燃料组合保留。
3. **优先级3目前没有独立燃料运行收益。**源端燃料响应带来的小时形状在本GB目标中未转化为更低MAE；在其他方向也没有复制成功。
4. **优先级4仍未解决双向可靠性。**US→GB source-recomposition靠大宽度达到覆盖；GB→US锚本身欠覆盖。后续可靠性方法必须在源域整国嵌套伪目标训练，且要同时与点误差、Winkler和强锚比较。

机器预测在打开NESO 2025目标值前已封存。官方标签17,520半小时记录无间断，完整8,760小时均可评分。哈希和运行信息见[证据包](evidence/us-to-gb-2025-official-generation-r1/README.md)。最终可复现运行是r4；它只清理未使用的runner局部变量，冻结预测和分数未变。NESO API官方定义及数据边界见[此前标签审计](CROSS_COUNTRY_2025_OFFICIAL_EIA_LABEL_AUDIT_20261102.md)。
