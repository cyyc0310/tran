> 日期：2026-07-24（已按"纯零样本 config-only 为目标"重定向）
> 依据：`2026-07-24-文献锚定gap分析-可发论文方向.md`（D1 配置驱动零样本 / D2 概率保形 / D7 开放基准）+ `TransCIF-方法设计与实验总结.md`（现状与 SA1 实验证据）+ `../experiments/2026-07-24-zeroshot-physics-foundation.md`（真实 SA1 机制验证）。
> 目的：把 gap 分析结论落回 TransCIF，明确**砍掉哪些、保留强化哪些、新增改造哪些**，并给出重定位后的论文故事与优先级。
> **核心目标（不可退让）：真正的零样本 / 免重训——目标域仅提供跨域不变量 + config，主干权重零改动。少样本微调仅作附录上界对照，不作主张。**

## 0. 一句话诊断（为什么必须改，但方向不变）

**目标始终是零样本 config-only；现在失败 ≠ 此路不通，而是当前实现没真正做到 config-only 零样本。**

此前 SA1 "近零样本"变体全输持久性（`physics_only_mae` 69–84 > 持久性 67.6），根因是：①物理层只预测二元占比、②共享编码器**未被 config 条件化**（实则记住了源域 QLD/NSW/VIC 的低可再生分布）、③残差依赖目标标签。这是"域适应路线"的失败，不是零样本目标的失败。

**2026-07-24 真实 SA1 机制验证（`docs/experiments/2026-07-24-zeroshot-physics-foundation.md`）给出正面证据：**
- **E1**：给定**真实结构** + SA1 config，config-only 物理合成 MAE=**16.9**，比持久性 **72.1** 好约 **4 倍** → 零样本合成基础成立；
- **E2**：仅换 config（ef），SA1 结构合成 CIF 从 104→247，**config 干净地控制量级** → "改 config 即改域"机制被证实；
- **关键推论**：**真正瓶颈是"跨域结构预测"，不是物理层**。此前失败是模型把 SA1 结构预测错了。

结论：坚持零样本 config-only 目标，把重构火力**首先集中在"让共享结构预测器在目标域也准"**（config 条件化 + 多样源域池），而非纠结物理层粒度。

## 2. 舍弃清单（附证据，别心疼）

1. **创新4：CV-DWCC 主导变量重加权校准句柄**
   - 证据：`reweight_lt_mwkc_alpha` 曾因固定平均融合近乎空操作（输出变化 ≤1.4e-4）；`recompute_dominant_variable` 存在真实索引空间 bug；即便修复，20-seed 只 25–45% 可靠。SA1 里一切重加权类"表层"手段均未跑赢基线。
   - 判断：高复杂度、强脆弱、与"配置驱动零样本"主线无关。**整块移除**（`calibration/dominant_reweight.py` 及其在 encoder 的耦合）。

2. **MLDG 域自适应加权**（`training/train_multi_source.py` 的域权重逻辑）
   - 证据：+15.9%，比不加任何手段（+13.6%）和朴素拼接都差。
   - 判断：**移除域加权**，保留"多源联合训练"这一朴素形式即可。

3. **REG/NEG 绝对发电量通道、门控条件化(A)**
   - 证据：REG/NEG +21.3%（最差）；门控 +13.7%（中性）。
   - 判断：绝对量通道违背"尺度不变"初衷，**砍**；门控条件化**降级**为消融项，不进主线。

4. **"近零样本、免重训"作为核心主张**
   - 判断：改为**"物理零样本下界 + 少样本增益"**的双模式诚实表述（见 §5）。

> Deep CORAL 不完全删除：作为**可选特征正则**保留在代码里，但**不在论文里当卖点**。

## 3. 保留并强化（TransCIF 真正的资产）

### 3.1 创新2 CIF 物理层 → 提升为"config-only 主干"
- **真实实验结论（E1）**：二元物理层在"结构已知"时 MAE 仅 16.9（远超持久性 72）——说明**物理层不是短板**，真正短板是跨域结构预测。
- **优先级修正**：首要任务是把共享编码器**用 config 条件化**（见 §4.2），让它预测目标域应有的结构，而非源域结构。
- **二元→多电源 `ŝ_g` 降为二阶精修**：E1 残差主来自非可再生常数因子偏差（数据反推 610 vs config 490）；升级多电源 `ŝ_g(t)` 可把 16.9 再压小，但属精度打磨，**不是成败关键**，可在结构预测打通后再做。
- 文件：`physics/cif.py`、`physics/residual.py`、`models/encoder.py`。

### 3.2 创新5 保形预测 → 提升为主卖点（= D2）
- 升级为**自适应/在线保形**以应对碳序列非平稳；报可靠性图 + CRPS + 区间宽度，而非只报覆盖率。当迁移不可靠时区间自动变宽——正是诚实性卖点。
- 文件：`calibration/conformal.py`。

### 3.3 创新1 重参数化 & 创新3 一致性正则 → 保留
- 重参数化是输入侧域不变基础；一致性正则在多源真实域下降级为数据增强/正则，仍有价值。

### 3.4 理论 theorem1 / theorem2 → 连到"迁移误差随 config 距离的界"
- 现有 `theory/2026-07-14-theorem1-error-bound-draft.md`、`theory/2026-07-22-theorem2-share-transfer-bound.md` 重新表述为 **D1 的理论卖点**：`目标域误差 ≤ 源域经验误差 + C·d(c_src,c_tgt) + 残差项`，其中 `d` 用结构占比距离/ef 向量差定义，给出"何时零样本可靠、何时须少样本"的判据。

## 4. 新增改造（补齐 D1+D2+D7 的缺口）

1. **config 形式化为三层域描述子**（结构层 `ef_g`/装机；拓扑层 联络线邻居；情景层 气候/时区/接口映射）——落到 `config/region_config.py`、`config/deploy.py`，把"工程配置"升级为**形式化域描述子**。
2. **FiLM / HyperNetwork 域条件残差**：用 config 向量条件化残差网络 `Δ(t)`，替代"靠抹除域身份"的重编码器思路。换域=喂新 `c_d`，主干 `θ` 冻结。
3. **多 ISO 数据**：跳出仅 AEMO——接入 Electricity Maps / CAISO(EIA-930) / ENTSO-E / NESO，构成异构源域池。这是 D1 泛化说服力与 D7 基准的前提。
4. **全量 LORO 基准（= D7）**：留一区域零样本评测，覆盖多个目标域，**不要只用 SA1 单点**（SA1 是对抗性最难点，单点会低估方法）。
5. **审稿人必备基线**：复现 **CarbonCast** + 跑 **DLinear / PatchTST / TFT** + EnsembleCI + persistence。缺 DLinear 类简单强基线会被直接质疑。
6. **部署模式（零样本为主线）**：主线 = **纯零样本 config-only**（目标域仅供跨域不变量 + config，残差 Δ≡0，主干冻结）；少样本监督微调（现有唯一有效的 D）**仅作附录上界对照 / 消融**，回答"若恰好有目标数据能多好"，**不入主张**。

## 5. 重定位后的论文故事

> **标题**：*Config-Driven Cross-Region Carbon Intensity Forecasting: A Physics-Decomposed Model with Calibrated Uncertainty and Provable Transfer Bounds*

**四点贡献**（一次性对标 CarbonCast / GNN-CIF / AAAI'26）：
1. **形式化域描述子(config) + 物理分解主干**：换 config 即换域的多电源结构合成；
2. **迁移误差随 config 距离的可证界**（theorem1/2 重述）；
3. **自适应保形不确定性**（D2）：区间随迁移可靠度自适应；
4. **多 ISO 的 LORO 开放基准**（D7）：统一零样本/少样本协议 + SOTA 对比。

**零样本为主的诚实叙事**：主张纯零样本 config-only——目标域仅供跨域不变量 + config，主干冻结（E1/E2 已证实合成基础与 config 控制力）。用 **多 ISO 的 LORO 全景**替代 SA1 单点，证明"多数目标域零样本已稳于 persistence、最难区 graceful degradation"。少样本微调仅作**上界对照附录**（SA1 已验证方向正确 −2.3%），不抬为主张。

## 7. 诚实性红线（必须守住）

- **不得**再宣称"零样本免重训已成功"——除非 LORO 全景零样本确实稳于 persistence；否则如实用"物理下界 + 少样本增益"叙事。
- **不得**只报 SA1 单区、单种子——多区 LORO + 多种子均值方差是底线。
- **不得**回避 DLinear 类简单基线。
- 负面结果（表层手段失败）应作为"消融证据"如实写入，反而增强物理分解+少样本这条主线的说服力。
