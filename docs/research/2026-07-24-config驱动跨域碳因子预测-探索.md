# 碳排放因子预测 —— 研究探索（独立思考，以发论文为目标）

> 日期：2026-07-24
> 说明：本文档为**从零独立探索**，不预设任何既有项目实现。目标是找到"能发论文"的清晰创新点与可行技术路线。
> 术语：CIF = Carbon Intensity Factor（单位电量碳排放，gCO₂/kWh）；平均因子 AEF；边际因子 MEF；碳排放流 CEF。

---

## 0. 问题界定

**任务**：日前（day-ahead，未来 24–48h、通常 30min/1h 分辨率）预测某电网区域的碳排放因子序列 CIF(t)。

**跨域含义**：训练用若干"源域"（源区域 / 源电网，数据充足），部署到"目标域"（新区域，数据稀缺甚至零样本），要求**尽量不重训**、仅提供目标域的少量描述信息即可预测。

**为什么难**：不同区域在①能源结构（火/气/水/风/光/核占比）、②机组排放系数、③联络线进出口、④气候与负荷模式、⑤市场调度规则上都不同，导致 CIF 的量级、日内形状、波动性差异巨大。传统做法"一地一模型"（如 EnsembleCI 思路）无法跨域。

# 任务 1：仅修改 config 即可跨域预测碳因子的模型设计

## 1.1 核心洞察：CIF 本身是可分解的物理量

按定义，任一时刻平均碳因子：

```
CIF(t) = Σ_g [ P_g(t) · ef_g ] / Σ_g P_g(t)
```

- `P_g(t)`：第 g 类电源在 t 时刻的出力（发电功率）
- `ef_g`：第 g 类电源的单位发电碳排放系数（gCO₂/kWh）

再考虑联络线进口：

```
CIF(t) = [ Σ_g P_g(t)·ef_g + Σ_j I_j(t)·CIF_j(t) ] / [ Σ_g P_g(t) + Σ_j I_j(t) ]
```

- `I_j(t)`：从邻区 j 的净进口功率；`CIF_j(t)`：邻区碳因子

**关键结论**：CIF 的跨域差异几乎全部来自 **{电源类型集合、ef_g、联络线拓扑}** 这些**结构性、可枚举、变化缓慢**的量；而 `P_g(t)` 的**动态规律**（如何随天气、日历、负荷变化）在物理上是跨域高度共享的（风机出力∝风速³、光伏∝辐照、火电follow净负荷……）。

→ 这正是"**把域相关的东西塞进 config、把域无关的动力学交给共享模型**"的物理依据。

## 1.2 什么才算"config"：域描述子（Domain Descriptor）的形式化

要让"只改 config"成立，config 必须是一个域的**充分统计量**——它要携带足够信息，使得共享模型 `f_θ` 满足：

```
CIF_d(t) = f_θ( 动态输入 x(t) ; c_d )
```

其中 `c_d` 是域 d 的 config，`θ` 跨域共享、训练后冻结。

**建议的 config 模式（schema）**——分三层：

| 层级 | 字段 | 例子 | 是否随时间 |
|---|---|---|---|
| ① 结构层 | 电源类型清单、装机容量、各类 `ef_g`、核/水/储能比例 | `coal: {cap: 5GW, ef: 900}` | 静态 / 年更新 |
| ② 拓扑层 | 联络线邻居列表、进口上限、邻区 CIF 数据源 | `neighbors: [VIC, NSW]` | 静态 |
| ③ 情景层 | 气候区、时区、典型负荷曲线先验、数据接口映射（气象/发电 API 字段名） | `climate: Cfa, tz: +10` | 部署时给定 |

**创新性关键**：把"config"从工程配置提升为**形式化的域描述子**，并研究"**config 需要多完整/多精确，才能保证目标域预测误差可控**"——这本身就是一个可发的理论+实证问题。

## 1.3 三条候选技术路线

### 路线 A：物理分解式（Physics-decomposed，最贴合"config-only"）
1. 共享模型只预测**归一化发电结构** `ŝ_g(t) = P_g(t)/ΣP`（域无关动力学，输入=天气+日历+负荷预测）；
2. config 提供 `ef_g` 与联络线信息；
3. 用 §1.1 物理公式**解析合成** CIF。

- 优点：换域=换 config 里的 `ef_g`/电源清单，模型零改动；可解释；零样本能力强。
- 难点：不同区域**调度/merit-order 不同**导致 `ŝ_g(t)` 仍非完全域无关 → 需在 config 里补充"边际成本序 / 容量"让一个**可微经济调度代理层**解析出力顺序，或用路线 B 的条件化补偿。

### 路线 B：域条件化共享网络（Domain-conditioned，最贴合深度学习范式）
- 一个共享编码器处理动态输入；用 config 生成的**条件向量 c_d** 通过 **FiLM 层**（逐层仿射调制）或 **HyperNetwork**（用 c_d 生成区域专属权重）来调制网络。
- 换域=把新 `c_d` 喂进条件通路，`θ` 不变。
- 优点：端到端、表达力强；缺点：可解释性与零样本外推弱于 A，需要多源域训练避免过拟合。

### 路线 C：检索 / 混合式（Retrieval / Mixture，最稳、工程友好）
- 训练一组源域模型；config 描述目标域 → 计算与各源域的**描述子距离**，做加权融合（贝叶斯/门控），类似"config 驱动的 EnsembleCI"。
- 优点：实现简单、鲁棒；缺点：创新性偏工程，需要配合 A/B 才有理论深度。

## 1.4 推荐架构：A 为主干 + B 做残差补偿（"物理解析 + 学习残差"）

```
天气/日历/负荷 ──► 共享编码器 ──► 归一化发电结构 ŝ_g(t)   ┐
config(ef_g, 拓扑) ─────────────────────────────────────┼─► 物理合成层 ─► CIF_phys(t)
config(域描述子 c_d) ──► FiLM/Hyper ──► 残差网络 Δ(t) ───┘                         └─► CIF = CIF_phys + Δ
```

- **物理合成层**保证换 config 即换域、可解释、量级正确；
- **残差网络**吸收调度规则、机组老化、数据噪声等 config 未覆盖的域差异；
- 训练时对残差加**小幅正则**（约束 |Δ| 小），保证物理项主导 → 零样本时即便关掉残差也能给出合理预测。

这套"**物理引导两段式 + 域条件残差**"结构，配合概率化输出（见任务 2），足以支撑一篇方法型论文。

## 1.5 训练与部署

- **多源域联合训练**（multi-domain / meta-learning）：跨多个区域采样，学习域无关 `θ` + 域条件通路；可用 domain-invariant 表征（对抗/MMD）强化编码器不含域身份信息。
- **零样本部署**：只给目标域 config → 直接推理。
- **少样本微调**：目标域有少量历史时，只微调 FiLM/残差的小参数（低成本）。
- **在线校准**：部署后用最新真值做保形/分位数在线重校准，纠正系统偏差。

## 1.6 可放进论文的理论卖点

**命题（迁移误差随 config 距离的界，示意）**：目标域预测误差 ≤ 源域经验误差 + C·d(c_source, c_target) + 残差项。其中 `d(·,·)` 是域描述子距离（如结构占比的 Wasserstein / ef 向量差）。
→ 说明"config 越接近、外推越准"，并给出**何时零样本可靠、何时必须微调**的判据。这类可证明的迁移界是顶会/顶刊青睐的贡献点。

## 1.7 评测协议（跨域留一法）

- **LORO（Leave-One-Region-Out）**：留一个区域完全不参与训练，测零样本；
- 指标：MAE / RMSE / MAPE（点）、Pinball loss / CRPS / 覆盖率（概率）、以及下游**碳感知调度的减排收益**（decision-focused 指标）；
- 数据源见 §3。

## 1.8 一句话总结任务 1

> **把"域"编码成一个物理可解释的 config（域描述子），让共享网络只学跨域不变的发电动力学，再用物理公式把 config 合成为 CIF、用轻量条件残差补偿差异——换域即换 config，并给出迁移误差随 config 距离的可证界。**

# 任务 2：碳排放因子预测的可行研究方向（候选清单）

每条含：研究空白 / 核心方法 / 数据 / 目标 venue / 风险。优先级见 §4。

### 方向 1 ⭐ 配置驱动 / 零样本跨域 CIF 预测（= 任务 1）
- **空白**：现有几乎都是"一地一模型"，跨域需重训；缺少形式化域描述子与迁移理论。
- **方法**：物理分解 + 域条件残差 + 迁移误差界（§1）。
- **数据**：Electricity Maps、AEMO(澳)、NESO(英)、CAISO、欧洲 ENTSO-E 多区域。
- **Venue**：ACM e-Energy / NeurIPS(Climate) / Applied Energy / IEEE TPWRS。
- **风险**：调度规则差异难被 config 完全刻画 → 靠残差项与少样本兜底。

### 方向 2 ⭐ 概率化 / 不确定性校准的日前 CIF 预测
- **空白**：主流 A/D 类工作多为**点预测**；碳感知调度其实更需要区间/分布。
- **方法**：分位数回归 / 深度分布预测 + **保形预测（Conformal Prediction）**做有限样本覆盖保证；评估 CRPS、可靠性图。
- **数据**：同上。
- **Venue**：Applied Energy / IEEE TSG / Int. J. Forecasting。
- **风险**：碳序列非平稳 → 需自适应/在线保形。

### 方向 3 物理约束 / 碳流守恒的 PINN 建模
- **空白**：数据模型（E 类）与物理核算（B 类 CEF）割裂。
- **方法**：把 CEF 守恒（节点碳流入=流出）作为**软约束**嵌入损失；在电网图上做 GNN，预测**节点级/线路级**边际 CIF。
- **数据**：带拓扑的系统（IEEE 测试系统 + 真实 ISO 拓扑）。
- **Venue**：IEEE TPWRS / PRX Energy / Applied Energy。
- **风险**：真实拓扑与潮流数据获取难。

### 方向 4 平均因子 + 边际因子（AEF & MEF）联合预测
- **空白**：两者分别研究；但决策（是否增加一度电）真正关心 MEF，而 AEF 更易得。
- **方法**：多任务学习共享表征，联合输出 AEF/MEF 并约束两者物理一致性。
- **Venue**：Journal of Cleaner Production / Applied Energy。
- **风险**：MEF 真值标注困难（需调度模型或计量法）。

### 方向 5 ⭐ 决策导向（Decision-focused）碳预测
- **空白**：几乎所有工作以 MSE 为目标，而非**下游减排收益**；预测误差与调度收益并不线性对应。
- **方法**：端到端可微优化（predict-then-optimize / SPO+ 损失），直接以"碳感知调度/负荷转移后的实际减排量"为训练目标。
- **Venue**：NeurIPS / ICLR / ACM e-Energy。
- **风险**：需搭一个可微的下游调度仿真环境。

### 方向 6 时空 GNN + 联络线耦合的多区域联合预测
- **空白**：进出口对边界区域 CIF 影响大，但多被当外生量。
- **方法**：把区域作节点、联络线作边，时空 GNN 同时预测多区域 CIF 与净交换。
- **Venue**：IEEE TSG / e-Energy。
- **风险**：跨 ISO 数据对齐（时区、口径）。

### 方向 7 数据稀缺电网的少样本 / 仿真到真实（Sim-to-Real）
- **空白**：发展中地区缺公开碳数据。
- **方法**：用生产成本模型/调度仿真生成合成 CIF 预训练，再少样本迁移到真实区域（呼应方向 1）。
- **Venue**：NeurIPS Climate / Environmental Data Science。
- **风险**：仿真-真实分布差。

### 方向 8 极端/机制切换下的鲁棒性
- **空白**：高比例可再生带来的爬坡、极端天气、负电价时段预测崩溃。
- **方法**：分布鲁棒优化 / regime-switching / 极值处理；报告尾部误差。
- **Venue**：Applied Energy / IEEE TPWRS。

### 方向 9 ⭐ 开放基准与数据集（Benchmark 论文）
- **空白**：日前 CIF 领域**没有统一、可复现的跨区域基准**，各文各测各的。
- **方法**：整合多 ISO 公开数据，定义统一任务/划分/指标（含零样本 LORO、概率指标），开源基线。
- **Venue**：NeurIPS Datasets & Benchmarks / Scientific Data。
- **价值**：领域引用磁石，配合方向 1/2 打包成"数据+方法"双贡献。

### 方向 10 时序基础模型（Foundation Model）微调用于 CIF
- **空白**：TimesFM/Chronos 等时序大模型尚未系统用于碳因子。
- **方法**：预训练时序基础模型 + 轻量 adapter/prompt（config 作 covariate）做零/少样本。
- **Venue**：ICLR / NeurIPS / e-Energy。
- **风险**：基础模型对能源协变量适配不足。

## 3. 数据与可复现资源

- **Electricity Maps**：全球实时+历史 CIF、发电结构、进出口（跨域首选）。
- **NESO / carbonintensity.org.uk**：英国国家+区域碳强度预测（自带官方预测可对标）。
- **AEMO (NEM)**：澳大利亚各州发电与排放。
- **CAISO / EIA-930 (美)**、**ENTSO-E (欧)**：发电结构、交换、负荷。
- 气象协变量：ERA5 / ECMWF / 各国气象局（辐照、风速、温度）。

## 4. 推荐优先级（发论文性价比）

1. **方向 1 + 方向 2 组合**（配置驱动零样本 + 概率校准）——新颖性、故事性、理论性俱全，是最可能出高质量方法论文的组合。
2. **方向 9 基准**——与 1/2 打包，显著提升影响力与可复现性。
3. **方向 5 决策导向**——若能搭起可微调度环境，创新度最高（偏 ML 顶会）。
4. 方向 3/6（物理约束/时空 GNN）——适合电力工程侧期刊（TPWRS/TSG）。

## 5. 建议的论文骨架（若走方向 1+2）

- 标题方向：*Config-Driven Zero-Shot Carbon Intensity Forecasting with Calibrated Uncertainty*
- 贡献：①形式化域描述子(config) + 物理分解架构；②迁移误差随 config 距离的界；③保形不确定性；④多区域 LORO 基准与 SOTA 对比。
- 实验：零样本跨域、少样本微调、消融（物理项/残差/条件化）、概率校准、下游减排收益。
