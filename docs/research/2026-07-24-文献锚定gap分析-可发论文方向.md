# 文献锚定的 Gap 分析 —— 可发论文的可行方向

> 日期：2026-07-24
> 方法：针对你调研的 50 篇文献，逐篇/逐类回答"**它做了什么 / 它缺什么**"，再由 gap 反推**可发论文的方向**，并把每个方向**锚定到被它超越的具体 baseline**。
> 说明：独立探索、以发论文为目标；术语 CIF=碳强度因子，AEF=平均因子，MEF=边际因子，CEF=碳排放流。
> 配套文档：`2026-07-24-config驱动跨域碳因子预测-探索.md`（10 个方向的候选清单与架构）；本文档聚焦"**从具体论文推 gap**"。

---

## 0. 怎么读这份分析

一个方向要"能发"，需要同时满足三件事：
1. **有明确对标**：能指出"哪几篇是我要超越/补全的基准"；
2. **有清晰 delta**：能一句话说清"它们没做、我做了"的那件事；
3. **可验证**：有公开数据 + 可复现的评测协议能证明 delta 成立。

下面每个 gap 都按此三件事组织。

---

## 1. 逐类 Gap 分析（做了什么 / 缺什么）

### A 类 · 碳强度日前/多日预测（核心对标）

| 论文 | 做了什么 | 关键局限（= 你的机会） |
|---|---|---|
| **CarbonCast** (e-Energy'22) | 两级结构：一级 CNN-LSTM 预测各电源出力，二级用固定 `ef_g` 折算 CIF；多日(96h)；覆盖十余区域 | ① **点预测**，无不确定性；② 二级用**固定排放系数**，不处理进口碳；③ 一级需各区**实测发电历史**训练，未形式化"域描述子"，**非零样本**；④ 只做 AEF |
| **GNN-CIF** (e-Energy'23) | 用 GNN 显式建模跨区/跨境**电力交换**做日前 CIF | ① 需**所有区域联合训练**，新区域要重训，**无法零样本外推**；② 点预测；③ 未给迁移/泛化理论 |
| **AAAI'26** (Improving Day-Ahead CIF) | 残差/特征增强的深度模型，提升日前精度 | ① 仍是**单域精度**故事，跨域迁移与概率化未覆盖；② 无 config 机制 |
| **DACF** (2022) | 特征工程 + ML 回归 | 传统 ML，无深度时序、无跨域、无概率 |
| **TransCarbonNet** (2026) | 自注意力 + 混合深度多日预测 | 单域、点预测、无迁移理论 |
| **Leerbeck** (Applied Energy'20, 148+) | 正则化线性/ML，**同时预测平均与边际** | 线性为主、短期、无深度时空、无跨域 |
| **Aryai** (EAAI'23) | PSO-ERT 回归做区域日前 | 单域、点预测、树模型无时序结构 |
| **B. Zhang 随机方法对比** (2024) | SDA vs SAA 两种随机近似对比 | 偏方法论对比，非端到端可部署预测器 |
| **Zhao** (Machines'25) | ML 实时碳排放 + 方法综述 | 实时而非日前；综述性 |

**A 类整体三大空白**：
- **空白-1｜零样本跨域**：几乎全是"一地一模型"或"多地联合重训"，**没有"只给目标域配置即可预测"**的范式。
- **空白-2｜概率化**：绝大多数是点预测；下游碳感知调度其实需要区间/分布。
- **空白-3｜可证明的泛化保证**：没有一篇给出"迁移误差随域差异变化"的理论界。

---

### B 类 · 碳排放流（CEF）理论与建模

- **做了什么**：Kang/N. Zhang 奠基 CEF 理论（用电侧实时碳计量）；GCN-LSTM 建 CEF；Sun 等做**概率碳流**；Hu 做碳流追踪与责任分摊。
- **缺什么**：CEF 系工作强在**物理核算/潮流**，但**预测能力弱**——多为给定潮流下的核算或短时评估，**不做日前预测**，也**不与深度时序预测器耦合**。
- **机会**：把 **CEF 守恒作为物理约束**注入日前预测器（PINN 式），或用 CEF 生成**节点级/边际 CIF 的物理标签**来监督学习。数据模型（E 类）与物理核算（B 类）之间是**割裂**的——桥接它们本身就是贡献。

---

### C 类 · 边际排放因子（MEF）预测

- **做了什么**：Mayes（CAISO，MLP→线性复合）、W. Wang（节点 MEF，FFN+混合）。仅 2 篇，方法较浅。
- **缺什么**：① MEF 与 AEF **分开做**，无联合一致性建模；② 无深度时序/概率；③ 真值标注困难（依赖调度模型）。
- **机会**：**AEF+MEF 多任务联合预测 + 物理一致性约束**，这是明显欠拥挤（under-crowded）的赛道，容易做出对比优势。

---

### D 类 · 组合/分解混合模型（CNN-LSTM、TCN-LSTM、CEEMDAN/VMD+LSTM）

- **做了什么**：各种"信号分解 + 深度网络"堆叠，刷单序列精度。
- **缺什么**：**创新度低、同质化严重**，几乎无跨域、无概率、无理论；本质是特征工程竞赛。
- **定位**：**不要以此为主线**——只作为你论文里的**消融对照基线**（证明"分解堆叠不如物理分解+条件化"）。

---

### E 类 · 通用时序深度模型（Informer/Autoformer/TFT/PatchTST/TimesNet/DLinear）

- **做了什么**：SOTA 长序列预测主干与强基线（含 DLinear 这种"线性打败 Transformer"的警示基线）。
- **缺什么**：与碳领域无关，**未针对能源协变量/物理结构定制**。
- **定位**：作为你的**主干候选与必须对比的基线组**。⚠️ **务必包含 DLinear/PatchTST**——审稿人一定会问"你比简单线性强吗"。

---

### F 类 · 时空 GNN（负荷/新能源）

- **做了什么**：STGNN 捕捉空间依赖做负荷预测。
- **缺什么**：用在**碳**上的少（只有 GNN-CIF）；**联络线进出口**多被当外生量。
- **机会**：区域为节点、联络线为边的**多区域联合 CIF + 净交换**时空图预测（方向 6）。

---

### G 类 · 风光/电价日前预测（方法学同源）

- **做了什么**：TFT/Transformer/分解混合用于风、光、电价日前预测，方法成熟。
- **缺什么**：与碳无直接关系。
- **定位**：**方法迁移来源**——TFT 的变量选择/可解释、保形 PV（Renkema）的概率思路都可搬到 CIF。是"借力"而非"对标"。

---

### H 类 · 迁移/域适应/概率（⭐ 与你最相关）

- **做了什么**：跨建筑能耗的**源域选择**（Q. Zhang）、**不确定性感知迁移**（TFT）、**保形 PV**（Renkema）、在线分位数负荷（P. Zhao）。
- **缺什么**：这些都在**建筑能耗/PV/负荷**领域，**没人把"配置驱动零样本 + 保形校准"系统地用到电网 CIF 上**。
- **机会（最关键）**：把 H 类成熟工具**首次系统性移植到日前 CIF**，并加上**物理分解 + 域描述子形式化**——这是"方法成熟但应用域空白"的典型可发点。

---

### I 类 · 物理约束/混合建模

- **做了什么**：PINN 用于电网频率动态（Kruse）、可再生系统物理引导 ML 综述（Parsa）。
- **缺什么**：**没用在碳流/CIF 预测**上。
- **机会**：物理引导两段式（物理合成 + 学习残差）与 CEF 守恒 PINN（方向 3）。

---

### J 类 · 碳感知计算（下游动机）

- **做了什么**：Google 数据中心碳感知调度（Radovanovic，555 引）证明**日前碳预测有真实价值**。
- **缺什么**：它们**假设有一个好的碳预测**，但预测误差如何影响调度收益少有人量化。
- **机会**：**决策导向学习**（方向 5）——直接以"调度减排收益"为训练目标；并用 J 类作为**研究动机与下游评测指标来源**。

---

### K 类 · 中文核算/预测

- **定位**：本土化数据/方法支撑（省级电网排放因子），可作**中国区域数据源**与本地化案例，不作主要创新对标。

---

## 2. 由 Gap 推导的可发论文方向（锚定 baseline）

按"创新度 × 可行性"排序。每个方向标注：**对标谁 / 你的 delta / 创新度 / venue / 风险 / 难度**。

### ★D1 配置驱动零样本跨域 CIF 预测（最强故事）
- **对标**：CarbonCast、GNN-CIF、AAAI'26（都需要目标域数据重训）。
- **Delta**：形式化**域描述子(config)** + **物理分解合成** + 域条件残差 → **目标域零/少样本**，换域即换 config。
- **创新度**：★★★★★｜**venue**：e-Energy / Applied Energy / TPWRS / NeurIPS-Climate｜**难度**：中高
- **风险**：调度规则差异难被 config 完全刻画 → 残差项 + 少样本兜底。

### ★D2 概率化 + 保形校准的日前 CIF（最稳、最易落地）
- **对标**：A 类几乎全部（点预测）+ 借 Renkema/ P. Zhao 的概率工具。
- **Delta**：把**保形预测 / 分位数**首次系统用于日前 CIF，给**有限样本覆盖保证**；报 CRPS、可靠性图、区间宽度。
- **创新度**：★★★★｜**venue**：Applied Energy / IEEE TSG / Int. J. Forecasting｜**难度**：中
- **风险**：碳序列非平稳 → 需自适应/在线保形。

### ★D3 决策导向（Decision-focused）碳预测（创新度最高）
- **对标**：所有以 MSE 为目标的 A/D 类 + Radovanovic 的下游场景。
- **Delta**：端到端可微优化（predict-then-optimize / SPO+），直接优化**碳感知调度减排收益**而非预测 MSE。
- **创新度**：★★★★★｜**venue**：NeurIPS / ICLR / e-Energy｜**难度**：高
- **风险**：需搭可微下游调度仿真环境。

### D4 CEF 守恒的物理约束 GNN（工程侧顶刊友好）
- **对标**：B 类（会核算不会预测）+ E 类（会预测无物理）。
- **Delta**：把**碳流守恒**作为软约束嵌入损失，在电网图上预测**节点级/边际 CIF**，桥接"物理核算 ↔ 数据预测"。
- **创新度**：★★★★｜**venue**：IEEE TPWRS / PRX Energy / Applied Energy｜**难度**：高（需拓扑/潮流数据）

### D5 AEF & MEF 联合预测（欠拥挤赛道）
- **对标**：C 类仅 2 篇、Leerbeck。
- **Delta**：多任务共享表征联合输出 AEF/MEF + 物理一致性约束；决策真正关心 MEF 但更难得。
- **创新度**：★★★★（因赛道空）｜**venue**：J. Cleaner Production / Applied Energy｜**难度**：中（MEF 真值标注难）

### D6 多区域时空 GNN + 联络线耦合
- **对标**：GNN-CIF（可扩展但仍需重训）、F 类 STGNN。
- **Delta**：区域为节点、联络线为边，**联合预测多区域 CIF 与净交换**，把进出口从外生量变内生。
- **创新度**：★★★｜**venue**：IEEE TSG / e-Energy｜**难度**：中高（跨 ISO 数据对齐）

### ★D7 开放跨域基准（引用磁石，与 D1/D2 打包）
- **对标**：整个 A 领域"各文各测各的"，无统一基准。
- **Delta**：整合多 ISO 公开数据，定义统一任务/划分/指标（零样本 LORO + 概率指标），开源基线。
- **创新度**：★★★★（社区价值）｜**venue**：NeurIPS Datasets & Benchmarks / Scientific Data｜**难度**：中（工程量大）

### D8 时序基础模型微调用于 CIF
- **对标**：E 类深度模型 + TimesFM/Chronos 未系统用于碳。
- **Delta**：时序基础模型 + 轻量 adapter/prompt（config 作 covariate）做零/少样本。
- **创新度**：★★★（蹭热点，易被质疑增量）｜**venue**：ICLR/NeurIPS/e-Energy｜**难度**：中

## 4. 最推荐落子（给发论文性价比排序）

1. **D1 + D2 + D7 打包成一篇"数据 + 方法"重磅**：
   *Config-Driven Zero-Shot Carbon Intensity Forecasting with Calibrated Uncertainty*
   - 贡献 = ①域描述子+物理分解架构 ②迁移误差随 config 距离的界 ③保形不确定性 ④多区域 LORO 开放基准。
   - 对标 CarbonCast/GNN-CIF/AAAI'26 一次性拉满 delta，故事最完整、审稿人最难挑"增量"。
2. **D3 决策导向**：若能搭可微调度环境，冲 ML 顶会（创新度最高，但工程重）。
3. **D5 AEF+MEF**：赛道空、易做出对比优势，适合快速产出一篇期刊。
4. **D4/D6**：走电力工程侧期刊（TPWRS/TSG），偏物理与拓扑。

## 5. 落地前必须锁死的 3 个实验前提（审稿人必问）

1. **基线必须含 DLinear/PatchTST/TFT + CarbonCast 复现**——否则"深度模型有效性"站不住。
2. **零样本评测必须 LORO（留一区域）**——不能有目标域数据泄漏进训练。
3. **概率评测必须报可靠性图 + CRPS + 区间宽度**——只报覆盖率不够。
