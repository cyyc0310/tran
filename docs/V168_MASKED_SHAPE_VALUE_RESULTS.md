# V168：条件信息有用，联合补全没有独立增量

本轮完成29源六折、241月、639个燃料掩蔽案例，共5,112条案例/方法评分。条件输入给出同一源世界未掩蔽燃料的小时q和当前粗组成，因此这是条件补全诊断，不是零本地小时预测。没有打开2025目标或新地区，也没有通过原预测gate。

## 核验范围

48个fold/mask块、192个森林拟合完成。审计核验全部评分身份、192条训练来源、639项隐藏特征干预，以及地区和24条宏汇总；重新拟合全部192个森林，只对每块库存首尾共93个案例、744条评分重算，最大差2.27×10⁻¹³。其余4,368条评分未逐条重算。模型及评分重建沿用冻结辅助函数，不是第二套独立算法。

每个被预测的燃料q只在源月该燃料为正时作为真实标签；另有保留q=1伪标签的legacy控制。原始g与q重建CIF一致，单燃料mask联合/独立完全相同，所有案例的联合/独立边际q评分相同。

常数和条件均值在给定源世界其他小时值后只是点补全，零宽区间不能当作可信概率区间。相对这些弱点控制的显著收益，不足以说明联合机制成立。

联合相对仅钟点边际CRPS改善5.26%、宽度缩小8.48%；但对粗量/日历联合控制仅改善2.77%，地区配对差值描述区间[-1.073,0.046]跨0，宽度反而增加7.21%。相对同一条件模型的独立组合，联合CRPS恶化0.33%、宽度增加2.27%，24源只有8源更好。当前证据没有支持额外保留联合结构的价值。

原始联合与独立的边际q CRPS均为0.184581，所以该差异并非给联合模型更多边际信息。G>0条件化之前边际完全一致；条件化后不声称边际仍严格一致。两者的平均拒绝概率约0.0120%/0.0164%，全部提案拒绝后的flat回退均为0。

## q学得更好不等于CIF更好

全部29源中，去掉伪标签的条件联合q CRPS为0.198159，legacy为0.202605；但CIF CRPS为10.441/10.202，反而较差。对应宽度75.84/66.95，严格覆盖92.86%/90.77%。在双燃料子集，两者CIF几乎相同，配对差值描述区间跨0。

因此不能把“排除占位标签改善q评分”写成已经解决CIF风险，也不能据legacy某项评分更好就把占位解释为真实观测。燃料q损失、CIF非线性功能及覆盖/效率需要分别验证。人工掩蔽的是有定义的正月量q，也不能由此证明自然零月量下的反事实形状可恢复。

## 粒子和贴边数值

预锁的639个首查询上，1024→4096粒子的单模型CRPS平均绝对变化约0.106g/kWh，联合最多有2个、独立有1个查询的原始覆盖变化。只看199个双燃料首查询，联合减独立的平均CRPS差为+0.06006（1024）和+0.05999（4096），没有出现联合优势；个别查询的耦合差会改变方向，不能据小幅差开发新机制。

严格与64eps覆盖均保留。双燃料联合/独立容差覆盖为92.39%/92.11%，结论未变。混合EF及全29源中，400等内部峰值的舍入影响更明显，不将其当作真实概率收益。

## 方法判断

目前有证据支持条件分布比常数或条件均值更合适，但没有支持专门联合补全、更复杂copula网络或去伪标签本身形成CIF创新增量。条件分布补全已有研究：[MissARF](https://onlinelibrary.wiley.com/doi/10.1002/sim.70379)、[非参数copula补全](https://link.springer.com/article/10.1007/s10182-026-00561-w)、[miceDRF项目](https://krystynagrzesiak.github.io/miceDRF/)，这些普通组件不能改名作为新颖性。

下一轮V169回到完整合法asof任务：在固定燃料边际、粗层预测和世界先验下，只扰动源耦合，并保持每个生成行G>0。它检验“源相关性是否值得迁移”，不由本轮阴性结果预认定相关性有害。若没有明确收益，就不继续开发复杂copula迁移，而应检查燃料边际风险和粗预测的失配。
