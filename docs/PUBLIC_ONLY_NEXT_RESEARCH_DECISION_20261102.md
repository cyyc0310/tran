# 仅公众数据约束下的下一阶段研究决策

更新：2026-11-02。根据用户确认的访问条件，以及现有公开输入审计、严格CN5跨域实验和小时信息LP结果，确定下一阶段范围。本文是研究路线决策，不代表新模型实验已经完成。

## 用户确认与当前数据合同

研究目前只能使用公众数据，没有上海/浙江电力交易平台市场成员账号。因此：

- 发电侧主预算为预测时点可核验的省级滞后月度火、水、核、风、光发电量`M`；公开年度装机单独列为`M+C`。
- 消费侧保持独立。年度省际OD只能作为受限信息预算；没有逐时受/送电量、送端强度和一致的消费分母时，不报告中国小时消费CIF预测精度。
- 成员披露页面上的预测曲线、负荷或联络线数据，不进入当前预算。今后只有无需成员身份即可公开下载、且能保留签发时点和历史版本的资料，才重新审计`M+F`或`C1+Fflow`。

这与[中国公众预测访问预检](CHINA_PUBLIC_FORECAST_ACCESS_PREFLIGHT_20261102.md)一致。国家统计局的公开月报按月发布分电源类型发电统计，但统计范围是规上工业，且公布/修订口径需随每次预测起点记录；它不是小时调度曲线。[国家统计局月度能源生产说明](https://www.stats.gov.cn/sj/zxfb/202609/t20260915_1965312.html)

## 已有结果给出的最小信息边界

严格CN5信息LP以九国2024固定EF小时代理作诊断，结果不是概率覆盖或中国精度验证：

| 可见信息（LP中的oracle诊断） | 平均部分识别界宽 | 说明 |
|---|---:|---|
| 月度类别能量 + 小时总发电量 | 1000.0 g/kWh | 仍不能识别小时火电份额及火电有效强度 |
| 再给小时风光实况 | 808.2 g/kWh | 风光两类单独增加的信息有限 |
| 再给小时水核风光实况 | 233.6 g/kWh | 多类非火电小时组成共同约束时明显收窄 |
| 再给全部非火电小时实况 | 175.6 g/kWh | 剩余主要不确定性转为热电小时量与热电EF范围 |

粗装机加入LP后平均界宽为830.38 g/kWh，且其历史装机上界有支持超界，不能解释成可靠部署边界。由此得出的可检验判断是：**中国现有M/M+C只能约束月度边际；小时可信度仍依赖未观测的小时技术组合，特别是火电内部结构和火电小时有效EF。** 具体数值与限制见[LP信息阶梯结果](CN5_MONTHLY_BUDGET_LP_INFORMATION_RESULTS_20261102.md)。

对于消费侧，缺口不同：本地发电统计不能确定受电来源和分摊。年度OD部分识别不能替代月/小时电力流和送端排放强度；见[中国消费侧流量审计](CHINA_CONSUMPTION_TRACK_ANNUAL_FLOW_DATA_AUDIT_20261101.md)。

## 文献定位与创新边界

相邻研究已经覆盖了多种看似直接的架构：2026年组件感知概率负荷迁移将季节和趋势分别对齐，但任务有区域负荷历史；2025年跨洲光伏迁移比较零样本、探测和微调，依赖高频站点数据；2024年概率碳流研究用p-box刻画负荷和可再生不确定性，着眼系统运行模型。这些工作支持把分解迁移、分位数、p-box等作为比较基线，但也意味着“用小波/注意力/域对齐预测CIF”本身不足以构成项目的主要新意。[组件感知负荷迁移](https://www.sciencedirect.com/science/article/pii/S2213138826005424)、[跨洲光伏迁移](https://ieeexplore.ieee.org/document/11086606/)、[概率碳排放流](https://doi.org/10.1016/j.energy.2024.130768)

当前证据尚未支持一个胜过强重组、简单热电锚且同时改善最差域可靠性的原创预测器。更可信的论文立意是：建立面向**目标小时标签缺失、预测时公开粗统计有限**的双估计目标迁移基准，提出可复现的输入/发布时点合同，量化能量守恒粗统计对小时强度的部分识别边界，并报告跨域负迁移与最差域区间失效。是否足以成为高水平论文，取决于是否有多个独立源/目标系统、公开复现和预先冻结的外部时间/地区队列，而不是基准名称本身。

## 下一项可证伪实验：月能量闭合的源形状集合迁移

此前点预测和残差区间已分别尝试，但没有系统回答一个更窄的问题：**把源国学到的小时技术形状作为集合，而非单一中心，再用目标月分类电量强制闭合，能否在LOCO伪目标上同时提高覆盖并减少区间浪费？** 该设计不能让目标小时标签进入预测输入。

建议的冻结设计：

1. 用严格CN5源国小时代理，按整国留出构造源形状集合；目标只提供`t−2…t−7`五类月量和日历。
2. 对每个源形状情景，先按月分类总量归一化，保证预测月能量闭合；只在训练国内伪目标层估计源间形状包络和区间校准，不使用外层国标签选择源、窗口或宽度。
3. 同一外层折上与`fuelshare_history`、比例重组、`anchor700`及强因子头比较；中心误差、形状误差、90%覆盖、区间宽度、Winkler和逐国最差值全部报告。
4. 晋级门槛同时要求区间分数优于最强同预算基线、覆盖不低于目标容差、平均宽度不靠退化扩大，且至少多数外层国有收益；否则停止此方法分支，论文回归基准/部分识别贡献。
5. 若源内整国伪目标通过，冻结代码和阈值后才评分未看过的时间或国家。中国端目前没有小时标签，故只能提供公开输入无标签推理，不能用于中国覆盖确认。

这项实验是一条待验证路线，不预先称为算法创新，也不声称能补齐火电内部EF。若月能量闭合的集合仍过宽或欠覆盖，最小信息结论将更明确：对发电侧需公开、可追溯的目标小时技术出力或能约束火电有效EF的合法本地观测；对消费侧需另有可追溯省际流量与来源强度。

## 暂停条件

如上述集合实验仅重复已关闭的源残差扩宽、不能超过`fuelshare_history`，不再换模型搜索同一输入；优先整理完整双轨benchmark论文与公开数据/代码包，并把中国结论限定为“输入可接入、迁移风险可诊断、真实小时精度尚未验证”。

## 2026-11-02后续实验：源子集分歧风险尺度未晋级

复查仓库后发现，一般的“月边际闭合＋来源小时形状”此前已在严格CN5组成闭合、月锚定相对形状、EIA分燃料边际形状和模拟CIF供体集合中测试，不能再把该宽泛思路登记为未做过的实验。本轮因此转为严格CN5的来源子集分歧验证：每折两国排除、六国训练的28模型集合，同训练规模地为伪目标和外层目标生成均值/离散度。

区间覆盖从固定池化版本的89.63%升到94.76%，最差国从58.80%升到77.69%；但平均宽度增加70.5%、Winkler恶化33.2%，只有4/9国Winkler改善，未通过预设门槛。结论和逐国证据见[实验报告](CN5_SOURCE_SUBSET_DISPERSION_RESULTS_20261102.md)。**停止源子集离散度、普通月边际闭合和整体加宽的变体搜索。**仍未完成的是有足够的真实as-issued跨国输入与未查看小时响应的独立双向确认；当前Nov 2026预测保持未评分，成熟前不据此报告效果。
