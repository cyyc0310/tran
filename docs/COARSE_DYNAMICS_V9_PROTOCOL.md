# V9：合法粗组成动态预测与小时剩余风险

2026-10-23，Sol。本协议在任何V9真实小时评分前固定。目标是检验V8实际组成诊断提示的优化空间，以及LGEE条件区间过窄能否由源端可学习风险修复；不预设方法原创或成功。不覆盖V7/V8代码、拟合、预测或评分。

## 数据与选型边界

沿用七源BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS、六个已查看目标AZPS/DUK/LGEE/PACE/PSCO/SRP。源轨迹bank仅2024H1，21个外层留源bank和3个全源bank复用原V7字节；源2025H1选型、H2压力检查，目标2026H1开发复测。源评估地区从轨迹和所有内层风险训练中排除。合法目标只用日历及`period_end<=origin`且`available_at+extra_delay<=origin`的月度组成，额外延迟0/30/90天。数据仍是回溯月表与假定发布日，不能称真实发布版本。

本轮不使用实际目标月组成oracle。完整预测grid封存后才能读取对应小时真值及当前月粗评分标签。代码、输入、旧拟合和完整预测/评分/选择均哈希校验；后阶段检查前阶段完成状态。新增预测使用128情景、seed17023，所有方法统一[0,1000]投影及倍率.75/1/1.25/1.5。

## 第一轮：六种粗预测与两种小时映射

所有方法都能看到相同的合法月表；不新增天气或地理信息。固定方法如下：

1. `latest`：最近已发布月组成。
2. `seasonal`：最近已发布同历月，缺失时回退最近月。
3. `v7_mixture`：V7温度.03的专家加权**均值**；其情景法改为本轮共享历史误差抽样，不等同于V7原三专家情景分布。
4. `harmonic_ridge`：最近60个已发布月，七维Helmert线性组成坐标；截距、年趋势和一/二阶Fourier，惩罚[0,6,2,2,4,4]；不足12月回退季节。
5. `seasonal_kalman`：最近60月，月份模板向全局均值收缩3个观测等价量，加局部水平Kalman更新；Q=.0025/月，R=.01，初始P=.02，按缺月跨度推进状态方差；不足12月回退季节。预测分布与其他方法共享下面的误差抽样，不能声称是完整Kalman后验。
6. `release_bridge`研究候选：V7均值加历史同预测跨度误差的收缩偏差；最多24个误差，跨度差核`exp(-abs(delta)/1.5)`、观测序号近期核`exp(-age/12)`，偏差收缩`n_eff/(n_eff+4)`。这是待检验的预序列偏差桥，不因命名而构成新方法。

每条误差用历史目标月相同日号（短月截断）构造伪预测时点，只用当时已发布数据；其真实组成仅在现在已发布后才进入误差库。最多60个历史伪目标构造递归偏差，最后24个生成联合八燃料残差情景，保留燃料之间关联。所有方法共享同一误差月份权重和抽样索引；点＋对应方法的历史误差投影到可观测燃料支持的单纯形。空历史有明确冷启动回退，不假造新燃料支持。历史误差不被误称为独立校准样本。

每种粗预测比较同一中心组成路由与同一donor随机数的两种映射：`additive`为源CIF加EF点积组成差；`recompose`为燃料小时出力的排放/发电比值。每个情景使用一个联合粗组成抽样。中心组成决定邻居权重，组成情景只进入映射，避免把路由变化混入传播对照。第一轮12配置。

## 第二轮：源留区剩余风险替代

第一轮全部12配置继续作同信息参考；对v7_mixture、harmonic_ridge、seasonal_kalman、release_bridge再比较两种风险模块，共20配置。两轮合计32配置，20个唯一预测。

对当前外层bank中的每个源地区，内层排除此地区，用其他源的轨迹按其真实源月组成和历月加权得到平均燃料路径，经比值映射得到中心；其实际每日CIF减去此中心，形成整日剩余风险。外层排除的评估地区不可能通过内层bank返回。只用2024H1训练资料，不用2025选型标签或目标小时残差拟合。

预测时，将目标合法粗组成情景通过中心组成路由得到的平均燃料路径，再加一条源跨区剩余误差：

- `residual_global`：等源地区先验抽样，是普通残差迁移强参考。
- `residual_conditional`：用与中心映射相同的组成Hellinger＋历月核抽样，带宽.3、季节带宽.5，保留整日水平/形状残差关联，是条件风险候选。

两者都**替代**原donor情景波动，避免将完整donor方差与完整残差重复叠加。两者共同改变中心/误差结构，比较它们才能归因条件化作用；不能把它们对原重组的差异都归为条件核。此机制假设真实组成条件下的源跨地区误差能迁移到目标的预测组成情景，没有任意域偏移覆盖保证。LGEE不使用独立参数或目标残差规则。

## 比较、门槛与新地区

每轮及跨轮source-only选择：`primary`为release_bridge或conditional候选；`baseline`为标准方法；`simple_anchor`为全部加性锚；`standard_dynamic`为harmonic_ridge/seasonal_kalman标准方法。要求源H1宏覆盖[.90,.95]、最差地区×延迟>=.85，合格者最小CRPS；无人合格按违反程度、CRPS和固定名称顺序选并显式记failed。H2不选型。保留标准动态及全局残差参考，不能只对弱基线宣称创新。

逐区/延迟报告CRPS、90%覆盖/宽度/区间评分、上下尾、每日水平/形状误差，重点LGEE以及PACE/AZPS/PSCO。月组成单独报告组成点MAE、边际CRPS、固定32条情景子样本的联合energy score及粗EF强度点MAE/情景CRPS；先汇总地区×延迟×方法×月内预测日，再各地区/延迟内等权汇总可评分月份，最后等权汇总地区/延迟，重复日预测不是独立月标签。32条子样本是控制联合评分成本的预定有限情景估计，不等同于完整128条联合分布积分。只有粗指标和小时proper score均改善，才能声称粗预测帮助小时风险。区分陈旧水平修复与条件分布修复，并保留负结果。

运行前仅检查月表键发现，源2025年84个地区月中只有69个粗标签（H1 37/42，H2 32/42；ISNE仅1、2、8月），目标2026H1为36/36。粗预测仍生成所有日期；缺少实际月标签的评分行显式记未评分和缺失指标，另存可评分/缺失支持，不插值、不伪造月标签，所有方法共享同一评分掩码。粗宏指标只描述有标签月份，尤其ISNE季节代表性有限；小时评分不因粗标签缺失删日或删区。此规则在V9真实评分前固定。

目标均为已查看开发数据；六日历月同步bootstrap5000次、seed17023仅作描述。触发真正新地区确认须：源完整gate通过；合法开发目标宏覆盖>=.90、最差单元>=.85；相对源固定simple_anchor、standard_dynamic及既有V8固定主方法均CRPS至少下降5%、IS降低、宽度不增加，CRPS差月份描述区间上界<0。此为资源决策门槛，不是统计定理。达标后再固定单一方法、参考、代码和选区规则；新地区仅按元数据选取并首次开启小时标签。未达标则保留未见数据、报告瓶颈，不扩大区间或换倍率追求表面达标。

本轮固定网格用于多机制实验，不等于32项独立创新。预序列残差校准、组成动态模型、条件bootstrap和源域交叉拟合已有方法基础。潜在贡献需要证明合法粗观测如何约束细风险、哪些剩余风险必须依赖迁移假设，以及该分解相对简单锚和通用动态模型的额外价值。中国/年度-only与真实发布档案不在本轮已验证范围。
