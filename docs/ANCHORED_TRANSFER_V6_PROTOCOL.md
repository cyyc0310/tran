# V6第二轮：可观测粗偏差锚与细尺度剩余误差

2026-10-23，Sol。首轮与受控诊断保留，第二轮真实拟合前冻结本协议；六个新目标未查看任何模型评分。

## 迭代依据与命题

首轮结构模型直接从粗回测特征回归完整小时水平误差。人工线性漂移诊断中，粗误差与细日均误差的映射保持一致，但新域漂移超出两个源域范围时，模型过校正：预测偏差约37/44，真实残差约30/35，尺度又不足。该负结果不能通过重新挑人工参数隐藏。

第二轮检验另一种结构：将目标本身可验证的粗有符号误差作为位置锚，源域只学习fine-minus-coarse剩余误差。希望减少对“完整小时偏差映射在新地区可外推”的依赖；这仍要求剩余误差可迁移，不能认为单位系数由物理定律保证。

给定合法特征x，anchor A(x)优先取有效seasonal_hindcast_bias，否则取有效harmonic_hindcast_bias，否则有效latest_hindcast_bias，无支持为0。只用已发布粗记录，所有回测仍严格重建历史前缀。拟合时把源truth路径减去同日标量A，按首轮同样的proper/bank划分拟合模型；预测时把目标A加回情景、区间和偏差修正。原始点不变，形状误差定义不变。

\[
 e^L=A(x)+d^L,\quad b_{new}(x)=A(x)+b_d(x).
\]

这是一种带可观测锚的剩余误差建模，现有offset回归与残差迁移本身不是首创。粗月加权与日均不同、过去误差与未来误差不同，A不是小时真值或已认证偏差。

## 公平对照、干净消融与固定参数

global/loglinear/extratrees/structured四种模式都使用相同锚，所有原特征、分量尺度、2024H1拟合/2024H2 bank和超参数不变。这样，主方法不能把只有自己能用的额外粗监督当成结构优势。`noanchor`模式则严格使用原structured及全部同样特征，只不减/加A；它应与首轮structured数值一致，作为锚机制的干净消融。

三个原点方法、额外发布延迟0/30/90日、128情景、seed17023及公开范围投影保持。第二轮全部五模式共同采用六倍率1/1.1/1.2/1.25/1.5/2。首轮全局参考1.25因宏覆盖95.484%略超过95%上界而失败，细化所有方法的共同网格，以减少离散倍率人为造成的门槛差异；不只为候选单独追加参数。V5两种2023历史参考与同2024信息CQR仍保留。CQR不使用新锚，但已获得其全部原始粗回测特征；其条件分位建模是标准独立强对照，只评区间、不伪造CRPS。

源2025主选择只从structured中取；基线从同样已锚的global/loglinear/extratrees中取；无约束最强、V5历史和CQR各保留源固定选择。源宏90%±5pp、最弱地区×延迟≥85%的门槛和failed诊断状态处理均不变，不能为新方法放宽。

新增代码为`scripts/coarse_bridge_v6.py`与`scripts/run_anchored_transfer_v6.py`，独立冻结，两脚本及bridge_policy/source环境均须在外部复用前核验；使用脚本层原型是为保持首轮冻结包字节，尚未将探索假设改写成生产接口。原条件模型、首轮runner和首轮协议不改。

## 确认和解释

仍为固定六区AZPS/DUK/LGEE/PACE/PSCO/SRP的2026H1，不另按性能选地区。两轮源开发都在打开任何新目标评分之前完成。每轮完整目标网格均先全局封存，且两轮预测封存完成前不得读取六区2026小时评分标签。

两轮的同信息强基线都报告；最终若比较跨轮优选，只能按源端固定规则在目标评分前冻结来源与配置，不能用目标排行榜选版本。至少报告锚structured、同样锚通用强基线、无锚相同structured、首轮源固定主及CQR。若收益主要由简单anchor_global或anchor_ExtraTrees实现，应将贡献归于可用粗反馈/锚建模，而不能声称非负方差算法独占优势。

重点看维持边际覆盖和最弱地区覆盖时的宽度、区间评分、CRPS，同时报告方向性错误和长延迟失败。人工试验只是机制诊断；真实六区同属美国、只有六个月，不能证明中国小时准确率、年度-only条件或任意域偏移的覆盖。

原创性判断还须结合[独立文献审查](V6_NOVELTY_REVIEW.md)：多步误差、offset、条件回归与弱监督均已有先例。可能的新贡献是，在发布受限、目标小时不可见且算子不一致的任务中，对可观测粗误差和不可观测剩余风险建立有辨识度、可复现且胜过标准对照的传输机制；本协议不预判成功。
