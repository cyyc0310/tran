# V51 月度组成与小时 CIF 的部分识别边界

## 问题

月度分燃料发电量可以识别什么小时风险？若目标地区缺少小时 CIF，最少增加哪种本地小时信息才能收紧物理可行范围？本审计分两个层次：先写明月度信息下的代数识别结果，再用已查看的源区完整月份，量化增加小时总发电量和小时正排放因子燃料组发电量的边界收缩。它是回顾性物理边界实验，不是预测模型比较或新源区确认。

## 定义与信息层级

对燃料组 `f` 使用固定项目代理因子 `EF_f`，小时发电量为 `g_fh ≥ 0`，小时总发电量为 `G_h = Σ_f g_fh`，发电侧平均 CIF 为

`C_h = Σ_f (EF_f g_fh) / G_h`。

月内燃料总量为 `M_f = Σ_h g_fh`。月度信息唯一直接识别的强度是发电量加权月均值 `z_m = Σ_f EF_f M_f / Σ_f M_f`，条件是统计范围完整一致且组别 EF 已明确。它不是普通小时均值、小时序列、小时方差、超阈小时数、尾部方向或未来风险。固定 `M_f` 也不固定这些量；已有严格反例见`results/source-aggregation-bias-v4/diagnostic_brief.md`，它还保持每小时总发电量不变，仍让时间均值 CIF 变化。

每小时单点的可行边界按信息逐步增加：

1. **只知道月燃料总量**：小时总发电量未知时，目标小时可行 CIF 的边界为当月有正发电量燃料的最小与最大 EF。可把该小时完全分配给任一活跃燃料，其余燃料分配到其他小时。
2. **再知道小时总发电量 `G_h`**：对当小时做带月度燃料库存上限的连续背包分配，最小/最大化 `Σ_f EF_f g_fh`。其他小时可承接所有剩余月量，故每个小时的两个端点在本信息集和假设下分别是 sharp。不同小时的边界集合不一定能同时达到所有端点。
3. **再知道小时正 EF 燃料组总量 `P_h`**：对项目因子中 `EF>0` 的燃料子集，在 `Σ_positive g_fh=P_h` 下分别最小/最大化排放分子；零 EF 组补齐 `G_h-P_h`。这测量的是小时“排放正组”的总量，不等同中国统计表中的“火电”或一般的“非可再生”分类。

本审计使用项目固定 EF `[1000, 400, 800, 0, 0, 0, 0, 400]` g/kWh，对应 coal/gas/oil/nuclear/hydro/wind/solar/other；正 EF 组为 coal/gas/oil/other。

## 样本与限制

使用已查看的 BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS 2022—2024 小时燃料数据，只保留完整日历月以及有效、有限、非负且总发电量为正的小时。共 203 个地区月、148,104 小时。每月燃料总量由该完整月的小时源数据聚合，因此此处是同口径 oracle 试验；不能把它说成中国公开月报字段的真实效果。`G_h` 和 `P_h` 都从小时燃料记录直接观测，是信息价值上界，不是当前中国场景已确认可获得的数据。

每小时区间只施加月总量和相应小时组总量约束，不含逐机组容量、爬坡、启停、储能、进口电力或电网潮流约束。EF 为项目代理因子，不是完整生命周期或中国官方因子。区间覆盖描述真实源区代理序列的可行性；不表示对真实排放或未来小时 CIF 的统计覆盖保证。

## 参考研究定位

相关 hourly average-intensity 工作通常直接使用小时各燃料发电量及燃料 EF；例如[Pereira & Posen (2020)](https://doi.org/10.1016/j.jclepro.2020.122514)研究不同时间分辨率，[Burguillo et al. (2022)](https://doi.org/10.1016/j.scitotenv.2022.156963)同时构造西班牙小时平均和边际 mix。对**边际**排放率，研究还需要小时需求、可变可再生发电和/或小时排放数据；例如[Zohrabian et al. (2023)](https://doi.org/10.1016/j.jclepro.2023.136296)使用历史小时级电力/排放变量。平均 CIF 与边际 CIF 是不同 estimand，不能互换。

中国统计定义限制映射：国家统计局月度规上工业表按火、水、核、风、太阳能报告；其定义中的火电包括煤、油、气、生物质及余热/余压/余气等。2026年9月公报还说明统计范围按规上工业口径，企业范围会逐年变化。因此用户的实际表头、边界和时间戳必须先与项目燃料组逐列映射，不能把“火电”“不可再生”直接等同正 EF 组。[国家统计局月报](https://www.stats.gov.cn/sj/zxfbhjd/202610/t20261019_1965613.html)、[火力发电指标解释](https://www.stats.gov.cn/sj/pcsj/jjpc/4jp/zk/html/zb0201.htm)。
