## 判断

1. **强重组是当前可复现的主基线，但不能称为新方法突破。**它在两个标签轨、两个方向的点误差和区间分数上都优于五类直接HGB。发电侧GB→US覆盖仍只有85%上下，消费侧GB→US约70%–73%；跨域区间可靠性未解决。
2. **真实月统计的收益是方向和标签依赖的。**US→GB中，EIA-923将发电代理M的MAE由80.61降至67.35、消费侧M由88.26降至81.58；但GB→US的M几乎无变化或略差。重组在US→GB也有小幅收益，消费区间覆盖仍欠拟合的直接模型则未过90%。
3. **年度装机预算不能单独晋级。**US→GB的M+C有时降低MAE，却总伴随较低覆盖，且没有稳定优于重组。GB为单一源域时，M与M+C完全相同，模型无法从源域容量变化中识别增量。2020煤/气装机只是额外预算对照，不是中国省级场景已确认的可用输入。
4. **两条目标轨必须保持分开。**例如同一US→GB EIA-923重组，发电代理MAE 61.50、覆盖92.1%，消费强度MAE 66.28、覆盖95.0%；这些差异来自响应定义和标签数据，不能合成一个“CIF性能”。消费侧省际强度还依赖跨省电量流向和送端强度，仅有省级发电结构月报无法确定。
5. 既有源伪目标残差结果仅覆盖US→GB，且EIA-923输入臂迁移失效；本轮不把它伪装为双向同队列基线。其结论见[生成侧代理复验](PSEUDOTARGET_RECOMPOSITION_RESIDUAL_GENERATION_PROXY_RESULTS_20261101.md)及[官方消费侧结果](OFFICIAL_PSEUDOTARGET_RECOMPOSITION_RESIDUAL_RESULTS_20261101.md)。

### 域级覆盖警报

GB→US强重组的宏观覆盖掩盖了重尾区域。固定EF发电代理的MISO覆盖仅32%（小时回算）和35%（EIA-923），ERCO为71%和78%；消费侧MISO仅12%和14%，ERCO为42%和50%。所以“区间分数优于直接模型”不意味着逐域可靠，不能将该模型报告为已校准的90%迁移区间。

## 对中国研究主线的下一步

先建立两个不同的中国基准任务。**发电侧**以省级月度火、水、核、风、光发电量作为严格M预算，评价各省小时本地生成侧强度；源国小时燃料标签负责训练，目标中国省份小时标签只用于最终评价。**消费侧**作为独立轨道，明确需要的最小跨省净受电量/来源数据与时间可见性，比较M、M+流量、M+C，不把发电侧代理替代消费侧真值。年度装机增量单列，只有在发布时间早于预测起点且统计口径匹配时才算合法预算。

当前跨国实验仍是方法压力测试：EIA-923使用现行最终档案模拟`t−2`，目标2024已被此前开发查看，统计地域也与小时响应区域不完全同域。尚无结果足以宣称新算法在中国冷启动已验证。更可信的论文增量方向是把“公开粗月统计的可迁移小时重组 + 预测起点信息预算 + 发电/消费双估计对象 + 目标支持失败审计”做成统一、可复现基准；方法贡献需要新的国家/年份盲测稳定改善强重组，并维持最差目标区覆盖。
