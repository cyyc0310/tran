# 丹麦目标域小时迁移压力测试协议

冻结：2026-11-02。该实验扩展优先级1的跨国小时迁移验证，不替代US↔GB主队列。丹麦2024小时发电数据此前为潮流/能量平衡审计而被查看，故本实验属于**已查看目标数据上的新任务开发压力测试**，不是盲确认或新国确认。

## 估计对象与输入合同

- 标签：Energy-Charts可见本地发电类别按项目固定EF计算的小时发电侧代理。煤1000、气400、油800、biomass+waste合并other并取400，核/水/风/光取0 g/kWh。它不是官方消费CIF或实测排放。
- 目标输入M：丹麦本地小时类别发电量聚合成精确`t−2`的火、水、核、风、光月份额；测试小时仅预测时钟与M。月量由现有小时序列回算，是滞后模拟，不是历史发行版。
- 水电/核电：Energy-Charts接口没有给出这两类序列。丹麦核电为结构零；水电未报告不能等同于严格零。丹麦官方统计显示2024水电约占发电量0.1%，因此主代理暂将未报告小时水电置零，并明确报告其有限标签影响；不得把此映射推广到水电占比较高的国家。水电按零EF，遗漏水电只会使当前代理分母略低、强度略高。
- 源：美国七个EIA平衡区；2022训练，2023源内校准。预测方法、超参数和火电因子沿用固定跨国实现。
- 时钟：目标预测特征按`Europe/Copenhagen`当地小时和月份构造；保留原UTC时间戳一对一评分，避免秋季重复小时误配。

## 固定比较

`anchor700`、`source_thermal_ef`、`coarse_boosting`和`coarse_recomposition`使用相同的日历、合法`t−2`五类组成和共同小时支持。重组方法是主结构基线；点/区间不根据丹麦2024标签调参。区间使用各方法相应的美国2023源残差偏差和Gaussian标准差，仅作经验迁移诊断，不作为新国家覆盖保证。

2024目标时间轴有8,784个小时；此前数据质量审计发现只有8,779小时同时具有完整生成类别、负荷与流量字段。本实验沿用类别完整性过滤，故主评分目标为8,779个可用小时，而非填补缺失5小时。预测CSV及哈希先落盘，再读取2024标签评分；报小时/形状MAE、90%经验覆盖、宽度、Winkler和逐月结果，并配对比较重组对源因子锚。缺失粗月量不以前向/后向填充。若当月有效完整小时不足，不进入共同评分。

## 解释边界

本实验只增加一个公开小时标签域；目标国家曾在项目中以Carbon Monitor日数据出现，且Energy-Charts小时数据曾用于潮流审计。任何结果只能说明固定源模型在一个额外发电代理任务中的可迁移表现，不构成独立国家层面的统计确认。水电未报告、接口修订历史、月报版本滞后和标签代理均须留在论文限制中。消费侧必须另有来源流量与来源强度，不能用本结果代替。
