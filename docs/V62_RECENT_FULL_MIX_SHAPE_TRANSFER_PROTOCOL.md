# V62 最近可得全燃料构成 × 来源小时形状迁移

日期：2026-10-27。此为已看区域的开发实验，不打开未评分地区。检验一个尚未直接对照的组合：用目标区最新已发布月度八燃料构成更新水平/燃料角色，再用来源区按燃料分解的同历月小时曲线给出形状。目标是验证公开低频全燃料构成是否比旧的上一年同月构成更适合冷启动小时点预测，并观察该收益是否会破坏区间覆盖。

## 数据与发布时间

- 地区取V57已评分的11个来源区与V54中6个已评分区。目标标签为EIA固定因子、已报告正部发电小时代理，不等同全网实测或中国口径。
- `latest_asof`只使用`period_end <= origin`且`available_at <= origin`的最新月记录；数据源的模拟发布时间沿用V54的月末+30天。不能使用目标月或未来月统计。
- 目标月份为2025H1和2026H1。预测2025H1时，小时形状只来自2024对应月份；预测2026H1时只来自2025对应月份。每个外层地区和校准地区的来源曲线均排除二者，防止被校准标签直接进入形状池。
- 逐燃料源曲线在UTC小时内按发电均值计算并归一为日内份额；目标区最新可得八燃料份额乘以这些份额，逐小时按固定EF重组。若某燃料在全部合法源形状中无正样本，则均匀24小时回退并逐预测记录，禁止静默插值。

## 冻结比较臂

1. `local_latest_fullmix_shape`（唯一新候选）：目标区最新as-of全燃料月份额 × 留区源逐燃料、同历月小时形状。
2. `local_yoy_fullmix_shape`：目标区上一年同月全燃料份额 × 相同来源形状，直接复用V57的信息构造作新协议下的对照。
3. `local_latest_thermal_ef_coarse`：目标区最新as-of热组EF × 上一年同月五类边际和五类来源小时形状，复现V53强水平锚作强对照。
4. `flat_latest_fullmix`：目标最新全燃料固定EF能量加权均值平铺24小时；作为低复杂度锚，不声称它识别小时变化。

各臂使用同一来源区、目标月、EF、小时标签过滤和外层拆分。源形状等权平均，不根据外层目标误差选源或选形状。若某方法输入/有效小时不足，按预定门槛记录缺失，不换臂补齐。

## 校准与指标

- 以2025H1作为逐来源区历史校准窗，2026H1作为时间前推评分窗。每个外层目标的每个校准区均由来源池排除目标区与校准区重算；使用校准源等权、小时等权的绝对残差90分位做统一对称半宽。
- 同时报告校准源最大区90分位宽度作为保守对照，但不称有限样本新区域保证。
- 逐区等权报告点MAE（确定性预测下等于绝对误差score）、宏/最差区覆盖、区间宽度、Winkler/interval score、燃料缺失回退率、地区/月完整性。
- 晋级信号必须同时满足：新候选相对`local_yoy_fullmix_shape`及`local_latest_thermal_ef_coarse`的宏MAE至少下降5%，至少12/17区改善； pooled覆盖90–95%、最差区≥85%；区间分数下降且宽度不增加。若只改善点估计、风险失败或收益集中于少数区，只记录为信息价值，不冻结方法或打开新数据。

## 解释边界

最新月全燃料份额与逐燃料历史形状乘积是标准重组基线，不预先宣称新算法。阳性只能说明低频信息时效和燃料分辨率在该代理benchmark中组合有用；不能直接推出中国小时真实CIF效果。因所有17区都已进入旧开发/确认，V62无独立地区确认资格。任何正结果后都须找到新的、未评分且质量合格的地区，或新的冻结时间窗，才能做独立确认。
