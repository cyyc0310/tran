# V35候选：先检验粗组成分布与条件模型的假设

2026-10-26，Sol。V34正式输出和独立49fit审计已完成；本文件是下一轮的候选设计，尚未运行V35，不把它写成已验证方法。

## 积分本身并非测量错误

V34的学习模型训练输入包含已实现的currentG5，查询时对MG潜在组成粒子积分，装机锚不使用currentG5。此前曾考虑将这个差别解释为测量错配；经独立数学反驳，该解释不成立为一般结论。

令H为部署时全部已知信息，包括使用的过去月报与容量。若MG分布q等于目标条件分布p(G|H)，且head估计目标关系f(G,H)=E[EF|G,H]，则全期望给出：

\[
E[CIF|H]=\int G_{POS}f(G,H)p(G|H)\,dG.
\]

真实G训练加潜在G粒子查询正是合法plug-in。需要检验的是q是否适合实际H、head是否充分且可跨区迁移，以及有限模型是否拟合准确；若MG使用了head省略的额外信息，还需额外条件独立假设。单凭本轮排名不能区分这些原因。

七源现有训练标签未见严格的“该燃料OP容量为0但对应细比例为正”矛盾；这不证明库存完整，但意味着不能直接以零支持缺失解释本轮退化。

## 先做不训练新模型的诊断

在同35月上先检查MG的POS偏差、固定分位覆盖及观测rank，并对G5用联合proper score作描述。地区等权，ISNE仅一个月不单独下结论。均值准确或边际覆盖接近名义值，不认证联合/条件校准；35月也不足以给出强跨区保证。

对固定head另查在实际G5下的EF残差及源区/时间/组成支持。oracle会提供额外未来信息，其增益不能直接证明部署输入失配；真实G下仍有系统偏差，也只能提示条件head、支持或迁移组合假设存在问题。要单独归因源→外区迁移，还需要与独立源内时间留出对照，训练残差不能替代。

已有点预测取粒子均值，而主指标MAE的Bayes解是条件中位数。应同步报告MSE/RMSE，并把已有粒子中位数作为普通零训练对照，避免把损失目标差异写成新机制。

## 可选的普通复杂度消融

沿用B1及同六源训练cohort、权重、库存year−2和发布时间规则，保留原42查询、128粒子和35评分月。只做四臂：PastCap-Ridge／ET预测四比例，PastDirectEF-Ridge／ET预测标量。它们从原SizeCap／DirectEF的36特征中移除前5个currentG5，剩余31维由month phase、三个月合法过去组成、时效、规模和趋势、OP容量比例及过去压力组成。既定Ridge／ET参数、scaler、投影或标量clip不变，共28个新fit。

排放因子在同一起点的粒子间相同；CIF仍逐粒子乘原MG_POS后平均。对照使用封存V34原Size两头、Capacity-OP、Utilization-OP、SizeCap和DirectEF两头，不重训，不因新模型改变支持。它是必要的普通消融，不能以删除当前特征本身宣称创新。

主要检验四个匹配比较是否同时改善EF和CIF，而非只降低CIF并加剧EF误差。past-only同时移除当前信号、降低维度并删除粒子协方差，因此收益只能说明这次删除策略有净价值，不能确定测量差异原因。任何V35真实拟合前，先固定对照及筛选；实验参数与判定尚待固定，V35还未开始。本设计不事后给V34改门槛，也不打开未知地区。

## 必须保留的反例与边界

设EF=a+bG、G=POS，MG与head均完全正确，令μ=E[G|H]、σ²=Var(G|H)。正确CIF均值为aμ+b(μ²+σ²)，past-only均值乘积为aμ+bμ²，丢掉bσ²；同时oracle真G可使EF误差为0。因此，“oracle更好”不蕴含“原积分错配”。head对G平坦时oracle不改善，也不能反证MG分布正确。

若把真实EF标签重复配给独立抽取的forecast粒子，给定H时两者可能独立，平方损失会学到E[EF|H]，而非所需的E[EF|G_true,H]。因此滚动预报粒子训练不是天然修复。未来若采用滚动预报，应明确是forecast-summary到最终响应的普通部署回归，或以完整粒子积分后的CIF预测作损失，不能把独立粒子当成与真实细标签配对的潜在真值。

仅把head输入换为真实G而CIF乘子仍用预报G，是混合oracle，不能当作一致的部署CIF估计。若保留此敏感性分析，应与真实G下的EF残差分开解释，并始终标记为额外未来信息诊断，不列入B1方法排名。

小时风险、区间覆盖和宽度仍是后续独立问题；本轮不以预报粒子分散度代替校准。真正未知地区继续关闭，所有七源结果仍是探索性证据。
