# 严格五类预算下的伪目标火电因子响应协议

冻结日期：2026-11-01，训练和目标评分前。问题：源端有细分燃料小时标签、目标推理仅有严格五类滞后月统计时，国家留出伪目标能否学出可迁移的火电因子响应收缩，并超过固定比例重组？

## 数据与嵌套切分

- 数据：Energy-Charts/SMARD严格五类九国小时发电代理；外层逐国留一。目标公开输入为火、水、核、风、光`t−2…t−7`月份额和日历；内部细燃料小时标签只用于源域监督。`other_renewable`不进入目标特征、目标份额归一或小时形状基线，仅按已有标签协议留在固定EF代理的分母中。
- 训练：外层目标国完全从训练和伪目标选择中排除。其余八国2022小时标签拟合普通比例重组`p_ratio`与火电因子HGB`p_factor`。
- 伪目标：对每个源国c，基模型在其余源国拟合，只给c严格五类历史输入，预测c的2023H1/H2。H1只选择收缩系数`α∈{0,0.25,0.5,0.75,1}`，预测为`p_ratio + α(p_factor−p_ratio)`。国家等权选择；附加leave-one-pseudocountry-out诊断系数是否由单个国家驱动。
- 校准：用同一留伪目标交叉拟合预测的2023H2残差，为重组、因子、直接CIF及选定收缩预测构造国家等权90%经验半径。
- 外层测试：在八个源国2022拟合最终预测器，预测被留出的2024完整小时。所有方法预测先写盘封存，之后读取外层标签评分。

## 比较与晋级门槛

同一目标队列比较比例重组、macro重组、火电因子头、直接CIF历史头和伪目标收缩因子。报告逐月、逐国、宏MAE、日内去均值形状MAE、90%经验覆盖、宽度和区间分数。

候选只有同时满足以下条件才晋级：九国外层宏MAE或proper interval score稳定优于比例重组；形状误差不恶化；90%覆盖改善不能靠单纯扩宽；荷兰、捷克、斯洛文尼亚、匈牙利等已知困难域的欠覆盖不加重；多数外层折的伪目标内层选择非零且nested伪目标CV支持该选择。否则停止收缩模型搜索，不打开未查看目标域。

## 边界

九国、数据、2024目标都在既往开发中使用过，属于嵌套开发回测而非盲测确认。月报由现行修订小时序列聚合并模拟`t−2`，不等于as-issued历史月报。响应为统一固定EF发电侧代理，不等于官方或实测消费侧CIF。该实验只测试火电因子响应收缩，不声称煤/气内部构成在目标中国可观测。
