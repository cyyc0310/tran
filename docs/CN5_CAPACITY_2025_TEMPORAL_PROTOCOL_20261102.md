# 严格CN5年度装机增量：2025时间留出协议

冻结日期：2026-11-02，在本轮拟合前固定。目标是检验此前2024 M+C消融在一个后续目标年是否保持同预算增量；不把已查看过的Energy-Charts九国重新命名为盲测。

## 任务与数据合同

- 九国严格五类开发集：NL、ES、BE、AT、SE、CZ、SK、HU、SI；2022源训练、2023年7–12月源校准、2025目标年份评分。各国2025数据已参与本项目其他开发实验，因此本轮属于**冻结方法后的时间外开发复核**，不是新地理确认。
- M输入是严格CN5历史月量/日历特征，沿用九国2025因子轨迹实验共同小时和能源映射。标签仍是Energy-Charts小时发电量经统一固定因子构造的发电侧代理，不是实测CIF或消费侧标签。
- M+C仅新增Eurostat 2022年度宽口径热电`CF/TOTAL`装机份额，九国使用同一统计年值作为静态、保守滞后预算；不得将它解释为每国2025预测起点的as-issued版本。该选择避免把仅五国存在的2023行强行补入九国样本。当前数据为修订快照，发布历史未能逐国复原，故仅报告静态年度信息增量。
- 目标只获得自身五类滞后月量、日历及该静态M+C容量份额；小时燃料/强度用于源训练、校准和封存后的评分。目标标签不得进入拟合、校准或选模。

## 冻结比较

在相同外层留国、源训练/校准时间、预测小时和容量预算下，比较：

1. M简单`anchor700`与五类比例重组；
2. 三种M学习头：直接HGB、Ridge、热电有效因子HGB；
3. 三种M+C同结构头：容量直接HGB、容量Ridge、容量热电因子HGB。

目标年2025；容量来源固定为九国面板2022统计年。HGB、Ridge结构、随机种子和M+C特征合同沿用`multicountry_cn5`既有容量消融。校准半径对每折每方法单独用八个源国2023H2误差的国家等权加权90%分位数拟合。

逐国预测与来源区间全部写盘并封存SHA后才评分。报告逐国、逐月和先等月再等国宏指标：MAE、去日均形状MAE、90%经验覆盖、区间宽、interval score；另报告M+C−M配对变化及逐国胜负。hours不作为独立国家样本。

## 判读门槛

仅当容量方法相对同结构M头在宏点误差或proper score有稳定改善、最差域不恶化，且覆盖保持且区间不靠加宽时，才认为年度容量在2025增加了预测价值。否则停止扩展容量头，不做年份/模型网格搜索。无论结果如何，不宣称这项时间复核证明中国精度或发布时点可用。
