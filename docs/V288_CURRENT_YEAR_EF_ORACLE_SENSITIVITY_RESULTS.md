# V288结果：目标年EF oracle修复PACE 2023覆盖，但不降低区间

使用目标年完整EIA燃料因子min–max作为不可部署oracle边界，复用V286完全相同的样本拆分。V288中的CEMS、上一年本地EF及source_loo分支与V286逐重复差异均为0。

| 方法 | 宏日覆盖 | 宽度 | Winkler-90 |
|---|---:|---:|---:|
| 上一年本地EF | 92.73% | 344.54 | 351.46 |
| 目标年EF oracle | 92.82% | 342.81 | 349.76 |
| CEMS支持 | 98.25% | 448.81 | 450.24 |
| source_loo | 54.55% | 228.31 | 404.71 |

PACE 2023 BA-year：上一年EF支持日覆盖89.30%、宽539.40、Winkler548.05；目标年oracle支持日覆盖91.15%、宽546.53、Winkler553.35。当前年因子把冻结门槛的覆盖缺口补上了，但区间稍宽、Winkler更差。这支持“EF年度漂移造成部分欠覆盖”，也显示因子修正不能消除PACE本身很大的小时形状尾风险。

目标年因子取自完整测试年，仅是事后上界诊断；不能把91.15%当作可部署模型成绩。具体因子支持漂移见[V287时间漂移审计](V287_TEMPORAL_EF_SUPPORT_DRIFT_RESULTS.md)与结果CSV。
