# V285：严格未查看BA外测候选盘点

目的：判断V282/V284候选能否按先前约定在一个真正未查看、且对燃料EF机制有识别力的BA上确认。只盘点仓库已有2025 EIA-930燃料活动量及项目历史文件；未打开任何新EIA官方小时CO₂工作簿。

## 判定规则

“信息性外区候选”需同时满足：
1. 2025有至少10个完整月份的正发电数据；
2. 燃料分项总量足以覆盖总发电量，且活跃类别至少两种（用于检验EF/组成异质性）；
3. 未出现在既有CIF预测、风险校准、CEMS或V273–V284官方标签目标/供体队列；
4. 对2025有可用的上一年活动或因子信息，能按冻结V282规则构造先验。

## 盘点结果

仓库2025 EIA-930共有62个BA代码。满足全年覆盖且至少4个活跃燃料类别的主要候选为：ISNE（10类）、NEVP（7类）、WACM（5类）、PACW（5类）、AECI（4类）。它们均已有先前风险/CIF或外部数据实验记录：ISNE进入V20/V46/V51/V74等；NEVP进入V246/V247/V248/V252/V254/V255/V260/V261结果；WACM进入V41/V42/V5结果；PACW进入External V6候选协议；AECI进入V246/V247/V252/V254/V260结果。因此不能把它们称为真正未查看BA。

剩余在既有CIF风险文档中未见、且达到10月以上的数据主要是单燃料或零碳型BA：GWA仅风电、SEPA/YAD/WAUW仅水电。它们能评估某些边界情况，但几乎没有活跃煤气油EF组成变化，无法有效确认V282的燃料因子支持机制。SIKE为单煤、2025仅7个月，而且已进入V279代理压力队列；HST仅2个月，WWA仅9个月。

## 结论

目前仓库没有同时满足“真正未查看 + 全年多燃料 + 既有本地EF输入可构造”的外部BA。V283的SIKE未通过月数门槛，也不应替换或称作盲测。下一次有效外区验证需要：
- 用户提供一个未参与先前实验的区域及其2024–2025公开逐类月发电/本地EF统计和小时标签；或
- 新增一个具有小时独立CIF标签、且本项目未曾用于开发/校准的系统级数据源。

可以继续做已知BA上的标签源压力试验，但应单独标为外部标签复制，不得声称未查看区域确认。
