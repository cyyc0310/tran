# 伪目标重组残差：生成侧一致标签配对复验协议

冻结日期：2026-11-01，运行前。该实验与[官方消费强度残差实验](OFFICIAL_PSEUDOTARGET_RECOMPOSITION_RESIDUAL_PROTOCOL_20261101.md)共享相同的US→GB伪目标训练、模型候选、收缩网格、分折、输入臂、源校准和评分代码；唯一响应差异是将EIA/NESO消费侧强度换为项目统一EF的小时发电侧代理。

## 目的与响应定义

检验官方消费侧残差修正失效究竟能否在同口径生成侧标签中复现。美国和GB每小时代理定义为已发布小时燃料发电量按固定燃料因子加权后除以总发电量。它是可控一致的发电侧平均强度代理，不是官方测量的真实CIF，也不是边际排放率。该标签仅作为源训练响应和预测封存后的GB评分响应。

## 保持不变的实验合同

- US七BA伪目标源，GB单一全国外层目标；2022源训练、2023H1留BA选择、2023H2独立留BA校准、2024 GB评分。
- 小时回算与EIA-923两个t−2粗月输入臂；目标预测仅使用粗月份额、日历和源区适配的年度信息。
- 强重组固定EF点预测基线；残差HGB/Ridge及收缩`{0,.1,.25,.5,.75,1}`。模型和收缩率只由US留BA验证确定。
- 所有目标预测先写盘并封存，之后才读取GB 2024小时燃料响应并计算发电侧代理标签。

## 判读

若同一残差修正在发电侧也恶化，而消费侧同样恶化，当前失败更符合源域到GB的残差不可迁移；若生成侧改善、消费侧恶化，则标签估计边界是重要解释。单次GB仍是已查看开发目标，不可称盲测或最终因果诊断。统一固定因子标签本身有代理限制，最终算法主张仍须在新国家/区域以及中国可部署月报时效下复现。
