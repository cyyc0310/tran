# 伪目标学习官方月报覆盖偏差校正：冻结协议

冻结日期：2026-11-01。承接[英国官方ET 5.4输入敏感性实验](GB_OFFICIAL_MONTHLY_INPUT_TRANSFER_RESULTS_20261101.md)，回答源区丰富小时监督能否学习“报告子集月五类构成→完整小时统计月构成”的跨地区映射，并迁移到GB官方月报。

## 观测映射任务

- 美国训练观测：同一BA×月的EIA-923公开电厂月净发电组成（输入）及EIA-930完整小时汇总后得到的五类组成（伪标签）。按既有固定映射：thermal=coal+gas+oil+other，另有hydro/nuclear/wind/solar。
- 美国外层伪目标：每个BA依次留出，以其2022–2023 BA-month拟合输入映射；在该BA 2024 EIA-923月结构上预测EIA-930完整月结构。只比较两个来源都有有限、完整、正值五类组成的共同BA-month。目标BA的2024标签不进入训练和超参选择。
- 内层选择：在外层剩余BA上做按BA分组的leave-one-BA-out CV，选择ILR空间Ridge正则`alpha∈{0.1,1,10,100}`，按留BA等权的五类份额L1最小化；`identity`是必须报告的零学习基线，若所有校正候选未改善源内CV则最终选identity。
- 变换：对输入组成先做零值平滑（总和为1后逐类下限`1e-4`并重新闭合），映射到五维组成的四维ILR坐标；拟合Ridge；逆变换后softmax/闭合为非负、和为1的五类组成。

## GB迁移外显

- 最终映射只用七个US BA在2022–2023的EIA-923/EIA-930配对，alpha按内层留BA CV冻结。
- 将此映射用于2024 GB目标实际预测时可见的ET 5.4 MPP五类月组成（`t−2`月），比较`raw ET54`与`corrected ET54`；NESO全GB小时回算五类份额仅作为事后组成oracle参考。
- 同一2022 US小时监督、2023源残差校准、小时队列、固定EF、形状模板和强重组模型均保持原值。仅以校正后CN5组成替换ET54输入，再比较源均值、700锚、源因子锚、日历Ridge、粗Ridge、粗HGB和强重组。目标英国为已查看开发区，不能称新域确认。
- 目标小时分数只用于评估冻结映射；不回调alpha、映射、源模型、风险或校准。预测文件和哈希必须在英国2024小时燃料列用于评分前写盘。

## 主指标与晋级判断

1. 美国外层2024伪目标：五类份额L1/总变差距离，按BA等权、BA内月份等权报告，并逐BA展示。
2. GB外显：小时固定EF代理MAE、日内形状MAE、源Gaussian CRPS、90%覆盖、宽度、interval score；同时报五类组成L1及其月份分布。
3. 只有伪目标外层组成误差稳定下降，且GB强重组/小时表现相对原ET54不恶化、区间风险不靠改宽才保留映射。若只有美国LOCO改善、GB变差，则解释为测量映射不能跨国，不宣称创新。

## 信息与结论边界

- EIA-923 2022–2024为当前最终档案，按月索引模拟`t−2`，不是as-issued历史快照。EIA-930是源端完整月组成代理，不能视作测量无误的绝对真值。
- 英国ET 5.4为2026-10-29当前修订版，月度MPP统计；NESO GB完整燃料组合用于后验参照，UK/MPP与GB/全量边界不同。
- 全部美国BA和英国2024均已用于此前开发；本实验只提供严格分组的源内方法验证和已见跨国外显，不构成盲测地理确认或中国有效度结论。
