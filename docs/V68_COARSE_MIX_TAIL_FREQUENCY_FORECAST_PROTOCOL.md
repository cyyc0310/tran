# V68：合法月度构成能否跨区预测下一月小时超阈频率

日期：2026-10-27。新预测目标：下一完整月份小时固定EF-CIF超过阈值的小时比例（不是区间误差风险）。此问题不同于V50的“哪类地区预测误差更大”、V20的同期oracle识别及V66的事后sharp bound。它直接检验月度燃料信息能否迁移小时尾频率。

## 队列与时序

- 使用V54同一17个EIA BA代理区、2022-01至2026-06冻结原生快照。逐月真值由小时燃料量和同一代理EF算出；每月每阈值一个目标 `event_rate = count(C_h > tau)/valid_hours`。
- 仅评估2026H1，月份起点00:00 UTC为forecast origin。目标区此前小时标签全部排除训练。其它16区仅用目标月之前已结束至少30天的小时标签训练；月度特征必须是origin前可用且已经完整发布（V54规则为月末+30天）的燃料统计。该标签30天滞后是保守回顾性约定，小时标签没有真实首次发布日期档案，因此不可声称真实逐日部署时点认证。
- 分析单位为区域月；不把小时当独立样本。17区都已在之前研究打开，属于新目标的开发性整区留出，不是新地区独立确认，不触发任何冻结新方法的结论。

## 预定比较

1. 同月份训练区平均 `seasonal_source_mean`。
2. 只用最新合法月度热组EF及日历的标准化Ridge。
3. 最新完整8燃料份额、前三月能量加权燃料份额及日历特征的source-balanced Ridge。
4. 相同全燃料特征的ExtraTrees（100棵树、叶节点12、max_features=.8、seed=68027），作非线性强基线。

主指标为阈值分层的区域月等权MAE/RMSE，另报地区宏平均、最低风险区增量和按地区配对bootstrap区间。阈值100/300/600/900固定；若某高阈值的测试目标近乎全零，明确其缺少正尾检验力。候选失败标准：全燃料Ridge在τ=300的区域等权MAE相对季节基线改善不足10%，或地区bootstrap改善区间跨零，则关闭“月燃料组成可有效迁移小时尾频率”的算法方向。任何结果都不得称小时概率覆盖或中国验证。

因十七地区都已用于过往开发，这轮无论结果如何都不能打开未查看地区，也不能把外层区域留出称作独立盲测。所有固定EF仍是生成侧报告燃料代理。
