# V24：仅公开月年统计时，先识别燃料分组损失

2026-10-26，Sol。用户已确认本地只能取得公开月度或年度燃料统计。已完成一次源区月表诊断，首次独立实际数值审计exit0/PASS。**本项发现了值得优先核实的字段缺口，尚未得到小时预测或原创算法突破。**

## 结果改变了下一步优先级

同样是月度统计，八燃料发电分项与合并火电类并不等价。当前八燃料代理把煤／气／油及other区分开来；现实公开表是否提供这些字段尚未确认。如果先补造细分再做精细小时重组，算法面对的信息条件就变了。

只在已有七源的月表做受控合并，不读取任何小时文件或新地区：2022–2024共242个源区月；固定主队列为2023完整七源84个月；完整十二条月记录可聚合18个proxy地区年度，另外3个源年因缺月不聚合。这些是已多轮查看源上的回顾诊断，不是独立确认集或中国验证。

同分母、固定EF、已知分组总能量且组内没有额外限制时，过去聚合强度的sharp识别区间为：

`[Σ_g share_g min(EF_g), Σ_g share_g max(EF_g)]`。

组内能量全部放在最小／最大EF燃料即可达到端点。这里的EF仍是项目固定代理`[1000,400,800,0,0,0,0,400]`，并非真实中国排放因子。

| 已知的月度字段 | 2023主队列平均识别宽度，g/kWh ↓ |
| --- | ---: |
| 原八类发电份额 | 0.000 |
| 合并coal/gas/oil，其余包括other分别保留 | 295.870 |
| 在上行基础上另给coal份额 | 173.136 |
| 在同一基础上另给gas份额 | 12.775 |
| 在同一基础上另给oil份额 | 293.710 |
| 全部正EF代理项连同other合并 | 322.079 |

宏统计先地区内等月、再等地区。这是**过去月度能量加权代理水平的识别宽度**，不是小时预测区间。原八类宽度0来自本代理EF和分项被视为已知，不表示真实碳强度无测量误差；包含原八类值只是代数检查，不是90%覆盖验证。

CGO+gas的结果只相对于**other仍单独已知的CGO基线**，不是从最后一行仅加gas就得到12.775。新字段的信息收益来自揭示真实细分，不能归功于新算法。所有分支使用同一发电总分母，没有额外小时G。

这一源区结果提示优先核实公开分项的语义和可得性，而不能直接推广成“中国应优先收集燃气”。其原因可以解析说明：设coal/gas/oil份额为c/g/o，合并后的宽度600(c+g+o)；分别揭示coal、gas、oil后，宽度为400(g+o)、200(c+o)、600(c+g)。字段价值依赖真实组成和EF。这里的美国源区组成不代表中国省份，CGO及正EF组也都不是已认证的官方火电分类。

## 年度统计缺失的是年内分配

年度聚合严格按各月`total_mwh`加权，未对月份额等权平均，未填缺月，未复制成十二条“月观测”。完整十二条月记录仍可能缺小时，年度对象仅覆盖原月表eligible小时，不能称为全年发电普查。

固定schema的上下界和宽度都是份额的线性函数。因此同一个完整地区年度满足：

`L_year=Σ_m w_m L_m; U_year=Σ_m w_m U_m; W_year=Σ_m w_m W_m`，其中`w_m=energy_m/energy_year`。

年度CGO主队列平均宽度297.821，CGO+gas为12.835 g/kWh；与月等权结果的差别来自权重及预测对象不同，**不能解释成年份额比月份额更有用或时间聚合损失很小**。年度没有提供逐月如何分配这些能量。

在2023七源共同队列，原八燃料月代理强度的年内最大值减最小值，等地区平均为91.171 g/kWh；月值相对全年加权值的等月绝对差平均22.913 g/kWh。这只是观测到的季节变化，展示把年水平复制给每个月会丢失什么，不是年度约束给出的sharp逐月界，更不是未来季节可预测性的证明。

本合成年包的available_at取year_end与各月模拟available_at的最大值，只表示按这些输入派生年包的时点。月表仍是修订EIA代理、模拟月末+30日发布；没有认证中国月报或年报原始发布时间。

## 月年数据能支持的研究问题

过去完整分项可给同口径、固定EF下的能量加权强度`ΣGC/ΣG`；仅合并组则先得到这个粗函数的集合。二者均不自动识别等小时均值、小时排序、尾部持续时间或未来风险。即使完全知道月加权强度，也仍有`A=mean(C)+Cov(G,C)/mean(G)`的未知协方差项。

如果实际公开表是燃料产量或耗用量，现有发电份额接口不能直接使用。热值、转换效率、热电联产分配和区域统计边界需要另立转换合同。国家统计局[2026年9月能源生产报告](https://www.stats.gov.cn/sj/zxfb/202610/t20261019_1965613.html)示例披露的是火电／水核风光等发电类别及规上范围，亦说明同比统计范围调整；这一全国示例不认证具体省份的全口径历史档案。

下一预测实验应先固定M8与合并组MG两种月度预算，各自比较简单锚、全局源先验重组、标准条件源先验重组，检验隐藏燃料分配与小时形状联合迁移的普通基线。MG的动态模型、距离、权重、校准和选型均只能看MG可见信息，不能先调用当地八燃料预报再合并。年度-only还需要独立的年度状态与年内分配层，当前并无已验证接口。

这组基线还不足以证明超过强概率模型；有希望后仍须同预算直接回归、异方差和条件分位数控制。沿用覆盖、宽度、CRPS和区间评分联合标准；先在源区出现明确可归因增量，再冻结真正未查看地区的确认合同。V23日／块包草稿已经显式暂停，不能为了结果更好绕回当地日统计或小时遥测。

## 论文判断和证据边界

有价值的任务是**公开统计的字段粒度、时间粒度和发布时效共同受限时，哪些粗水平可识别，哪些小时风险只能依赖可检验的源迁移假设**。本项把第一层燃料语义歧义从小时调度歧义中分开了，但它使用经典线性界，不是原创算法。

[聚合观测学习，NeurIPS2020](https://proceedings.neurips.cc/paper/2020/file/5b0fa0e4c041548bb6289e15d865a696-Paper.pdf)已经讨论聚合监督与等价类一致性；[含协变量偏移源监督的聚合标签学习，UAI2025](https://proceedings.mlr.press/v286/singh25b.html)也已研究细源监督与粗目标监督结合，后者任务主要是标签比例学习，不能直接当作本CIF回归的现成保证。仅把“粗目标＋细源”重新命名不足以构成创新。

真正方法贡献仍须回答：相对于同预算普通源条件先验，能否用可用粗历史区分组内燃料和调度状态，并在保持覆盖的同时更窄、更准？月约束对已经强制重标到同一个月总量的所有小时形状可能完全相同，不能将这种聚合相容性当作目标区验证。完整分析及后续六臂建议见[独立月年预算科学审查](MONTHLY_ANNUAL_RESEARCH_REVIEW.md)。目前没有证据满足新算法论文的增量门槛。
