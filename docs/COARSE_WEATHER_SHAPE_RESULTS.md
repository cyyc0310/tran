# 强粗重组内天气形状：恒等检查通过，收益仍不足

2026-10-31，Sol。按[开发协议](COARSE_WEATHER_SHAPE_PROTOCOL.md)完成9配置、两预算、8个固定参考，进程退出码0。复用前轮相同624个唯一目标小时，属于已见开发集上的自适应试验；没有未知国家确认。**没有建立保持覆盖并缩窄区间的稳定增量，也不据此宣称创新。**

## 本轮确实验证了什么

18项相关测试通过，包括与旧V12补dummy燃料后的逐值数学一致、缺查询天气的恒等分支、源日期OOF扰动检验、未支持燃料和零幅度保护、源输入不得偷用小时混合。真实运行18对银行粒子中learned_zero与joint_original逐值相同，36条恒等分支源校准半径与前轮joint_matched一致；9个审计共54个OOF折均整起点排除所有地区。

2529项输入、146项预测/成员/校准封存及9个源头模型由独立复核验证。864组区域指标、32行宏均值从原始标签复算最大差约9.09×10⁻¹³；另核对原始粒子CRPS与一个非零delta源CQR半径。没有让源校准或目标成绩选择强度。所有方法的日燃料幅度保持，但这不意味着算术日均CIF或投影后的残差尾部不变。
