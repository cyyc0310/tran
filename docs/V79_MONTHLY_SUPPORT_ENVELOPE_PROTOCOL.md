# V79：使用月度燃料支持上界的 L₁ 风险证书开发消融

冻结日期：2026-10-28。V77/V78的EPE/TIDC确认使用全域EF上界M=1000；误差分析后发现目标区燃料月报只含EF为0/400的活跃类别。V79在**已开启的同一EPE/TIDC区和同一三个时期**做开发性机制消融，检验月度燃料表可知的地区-月活跃支持上界M，是否能在相同H/G/L₁摘要上恢复τ=300的K≥8证书并相对同M的G²基线有增量。V79不是盲测/独立确认。

对每个地区-月，从V54冻结月表的全燃料份额取所有正份额燃料对应EF的最大值M；这是一项地区-月级低频信息。若对应月行因覆盖不足而缺失，按冻结保守规则退回全局M=1000，不用邻月或小时目标标签填补。每个6h块已有`H=ΣG·EF`、总`G`与一个追加G摘要`L₁=max(G_h)`。风险下界证书为`H > τG +(M−τ)L₁`；其逻辑是，若最多一个小时超τ，则全部超额碳能量至多由最大G小时承载。对照包括全局M=1000的V77 L₁、使用同一局部M的G²必要外界，以及同M完整小时G锐集。τ=100/300、K≥8、2024H2/2025H1/2025H2及目标地区均固定。

必须验证实际K在所有集合内、集合嵌套、L₁无超出完整G的假证书。报告逐区、逐期、逐τ，分母为完整UTC日。V54月表由历史EIA快照代理重建，发布时间设定为月末+30天，且并非中国省级官方统计；此消融只测试“如果只有月度燃料支持上界比全球上界更紧，证书会怎样”，不构成中国小时预测。若局部上界增加τ=300的有效证书，下一轮才在未评分且支持相似的新区域冻结确认。
