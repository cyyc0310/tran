# V54 未见 EIA 区域本地 EF 锚独立确认协议

冻结日期：2026-10-27。仅使用在此前质量普查中通过所有时期质量门槛、且此前未计算 CIF 分数的 `FMPP, GRID, IID, LDWP, PSEI, TEC` 六区。数据选择只依据 V52 质量普查冻结名单，不依据表现。

## 冻结候选

点预测结构冻结为 V52 五类上一年同月粗总量、此前已评估11区的上一年同月小时形状等权迁移、小时 CIF 计算定义不变；thermal EF 唯一候选为目标区预测起点前可得的最新完整自然年本地月燃料统计加权值（每月 `period_end <= origin` 且 `available_at <= origin`，要求12个月全有）。点/区间预测仅使用预测起点时已经可得的月信息。不得据确认结果改权重、切换因子窗口、筛区域或重调区间。

## 测试集与校准

只评分2025 H1/H2。2024作为校准年。每个校准区用其余已见11区迁移小时形状，校准区排除自身；热 EF 使用其本地区完整历史年。待测六区的来源小时形状来自固定11个已见区，目标本地月燃料分项只提供 thermal EF。对 donor EF 基线同样保持其他输入完全相同，仅替换 EF 为11个已见区上一年同月 EF 等源平均。

固定区间比较：source-equal pooled q90；以及已见地区 q90 最大值半径作为简单稳健锚。以区域等权报告点 MAE、偏差、宏覆盖、最差区域覆盖、平均区间宽和90% Winkler分数；按 H1/H2分别汇报。标签只用于最终评分，不参与区域筛选、EF计算、小时形状或区间校准。

## 判定

主判据是六区中每个半年最差区覆盖是否达到85%，同时 pooled 区间的宏覆盖在90–95%且 Winkler 优于 donor baseline。若宏指标改善而最差地区未达门槛，结论为“独立点预测增量得到确认、可信区间主张未确认”；不得事后扩宽区间后称为通过。

## 数据与解释限制

小时标签为 EIA 固定因子正部已报告发电代理，不是实际全电网排放。重叠 BA 与统计边界相关；下载版本没有原始发布 vintage，历史月报采用预设月末+30天可得时点。数据实现使用每个 BA-hour 的最早快照、按快照燃料列做一次 proxy 质量处理，再按月份聚合；因发布时点晚于整月结束，这与逐月重放月末+30天前缀在同一冻结快照上的月值等价，避免重复扫描全历史。结果只能确认此固定 EIA 代理上的未见区迁移，不足以证明中国目标场景有效。运行前记录全部原始快照、数据导出逻辑、本协议哈希；运行后保留哈希和每区明细。
