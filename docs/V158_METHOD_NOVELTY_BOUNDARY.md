# V158：运行结果之外的方法边界

本页在V158评分完成前写入，不根据目标结果选择论点。它记录代数检查和原论文核对；性能结论另见结果报告。

## 响应字典分裂仍属于嵌入响应的森林

设源小时创新为d，物理修复后碳响应为R(v,d)，五个proper源组成原型为v₁,…,v₅。实际标签是各响应按proper源加权标准差缩放后的向量ψ(d)。对任何节点，以样本权重定义左右子节点总权重W_L、W_R、父节点W，平方误差分裂增益（忽略固定输出维数因子）为

Δ = (W_L W_R / W²) ‖mean_L ψ − mean_R ψ‖²。

这恰好是有限特征核k(d,d′)=ψ(d)·ψ(d′)下的经验均值嵌入距离。V158不是一种脱离既有分布森林的新分裂原理；它试探的是物理响应是否提供更合适的有限特征。该核维数至多5，不具有任意分布辨识保证。即使结果好，也要增加普通分布森林和其他响应字典对照，才能判断碳响应字典是否必要。

[Cevid等，JMLR 2022](https://www.jmlr.org/beta/papers/v23/21-0585.html)已用MMD分裂学习多变量条件分布；[Koemen，2026预印本](https://arxiv.org/html/2607.23721v1)进一步用响应嵌入统一解释CART/MMD分裂，研究了分布结构收益与估计噪声的权衡。后者是预印本，不能当作已审稿结论。我们使用ExtraTrees现成平方误差分裂，也没有实现原版DRF的MMD或honesty机制。

## 非负修复的收益必须单独归因

当S+d已非负、总和为1，且没有被合法零支持删除时，R(S,d)=(S+d)·EF=S·EF+d·EF。因此，在可行区域内联合创新映射与标量锚定残差完全相同；预测差异只能来自森林权重。越界后的截负再归一会改变响应，其收益应记为修复效果，不能统称联合结构创新。它也不保证月度能源总量一致。

月总量为0可排除当月燃料，但过往月为0不能排除未来出现。硬支持预算仅适用于完整当月的事后重建。不能以same_month改善证明asof预测已经解决。

## “缺数据地区迁移”已有直接相关工作

[Zhang等，WWW 2026：DGCFM](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf)明确研究跨地区CIF，报告zero-data与low-data设置。§5.1.2将zero-data描述为训练时排除目标地区；§3.2和式(10)仍写有历史CIF与电力流输入。因此，不能笼统宣称前人没有零样本地区预测，也不能仅根据“zero-data”词语判定其满足本研究的“无目标小时CIF输入”。其推理输入如何处理缺测，需要代码或作者进一步核验。该文点预测指标与本研究概率覆盖目标亦有区别，不能直接横比数字。

可争取的差异应落实为：清楚的发布时点信息合同、目标零小时CIF、月度燃料组成下的可识别量与剩余风险、同预算概率强基线、跨地区冻结确认。上述差异能形成问题价值；它们本身还不等于新算法，更不能替代有效实验证据。
