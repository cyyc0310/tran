# 荷兰比例重组误差来源分解协议

冻结日期：2026-11-01，事后计算前。只解释既有五国留国开发回测中NL比例重组的误差，不调参、不选方法，也不把结果作为独立确认。

对NL外层目标，使用另外四国2022小时标签拟合原比例重组基线，保留NL预测时可见的t−2粗月组成及原小时模板。对2024小时标签计算实际粗热电份额`q_true`、实际小时总固定因子强度`y_true`，并由定义得到实际热电有效因子`EF_true=y_true/q_true`（热电份额为零时记缺失）。预测分解为`yhat= q_hat × EF_source`，并加入仅使用目标t−2粗月热电份额的部署基线`q_month × EF_source`，报告：

- 完整比例重组`q_hat × EF_source`；
- 只用可见t−2月热电份额的基线`q_month × EF_source`；
- 只把小时热电份额换成目标真实值的诊断`q_true × EF_source`；
- 只把源热电因子换成目标真实值的诊断`q_hat × EF_true`。

逐月计算误差、目标热电有效因子、粗月外推/形状误差及覆盖，分别检查小时因子水平和时间变化。oracle替换项使用目标2024小时标签，仅作误差归因上界；不属于可部署输入、不比较为候选算法。所有结果限于已查看的Energy-Charts代理数据。
