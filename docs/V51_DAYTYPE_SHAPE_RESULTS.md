# V51 日类型×小时形状基线结果

## 问题与实验

在严格月度类别预算下，上一轮本地钟点对齐带来的整体增益很小。此轮检查额外加入weekday/weekend或一周七天差异，能否让源先验更接近目标地区小时轮廓。

三种 donor 形状只用留出区以外的上一年同月小时燃料发电：

- `hour24_local`：地区本地钟点24格；
- `daytype_hour48`：本地weekday/weekend×24小时；
- `weekday_hour168`：本地星期几×24小时。

目标区只提供合法滞后五类月总量；各组小时shape与thermal EF都来自其它源。所有预测按目标有效小时数归一化，使预测月类别总量回到已知月锚。2025H1、H2目标小时只评分。该次为探索性强基线诊断，未预注册；来源和结果此前均已查看。

## 结果

|窗口|形状|有效源|源等权 MAE|源等权 RMSE|
|---|---|---:|---:|---:|
|H1|24小时本地钟点|7|56.515|64.351|
|H1|weekday/weekend×小时|7|56.413|64.201|
|H1|星期几×小时|7|56.515|64.409|
|H2|24小时本地钟点|6|61.280|67.591|
|H2|weekday/weekend×小时|6|61.313|67.722|
|H2|星期几×小时|6|61.409|67.962|

H1 weekday/weekend细分仅带来约0.18% MAE、0.23% RMSE改善；H2反而略差。星期几×小时没有稳定增益。MISO的巨大偏差完全没改善：MAE从24小时基线153.94→154.15→154.22（H1）、158.07→158.15→158.21（H2），三个数依次为24、48、168格。

## 结论

更细的日历小时模板不能修复主要错误。H1最佳只比基线低0.21 g/kWh，H2最简24格最好；MISO仍有约+154至+158 g/kWh的正偏差。结合此前“增加目标区滞后热组EF后MISO点误差大幅下降”，证据支持MISO主要是水平/热组内部强度失配，而非weekend或weekday小时形状。该解释是代理集诊断，不是因果识别。

因此，日类型模板作为标准基线可保留，但不冻结为候选创新。更值得的突破空间是：在无法取得细分燃料时，对热组内部有效EF给出由年度统计/合理因子范围导出的可识别集合；若拿得到额外年度/本地信息，则检验它是否只修复平均水平，还是也约束小时尾部。不能再把“增加hour、wavelet、weekend特征”作为默认优化方向。

详细来源×月结果与哈希见`results/v51-daytype-shape-probe/summary.json`及CSV；复现脚本为`scripts/v51_daytype_shape_probe.py`。MISO按America/Chicago代表时区，仍需对其多时区结构作敏感性分析。所有源均为重复开发的美国固定EF代理，不能作中国或未看地区确认。
