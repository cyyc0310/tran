# V87：逐燃料月边际对尾计数的最小充分压缩（2026-10-28）

V87把V66结果写成目标阈值相关的解析分类，并逐行在31省、2016–2024、13,392个省月×阈值上复核。由`(高于阈值EF的活跃燃料是否存在，低于阈值EF的活跃燃料是否存在，等于阈值EF的活跃燃料是否存在，月度超额D=Σ(EF_f−τ)M_f的符号)`重构出的K锐集与V66所有行完全相同：0/13,392不一致。

因此，在“燃料可任意跨小时分配、无容量/爬坡/日配额、每小时总发电为正、EF固定”的模型下，完整逐燃料月总量对小时尾计数的辨识作用被压缩为：

- 是否存在任何高于阈值的活跃燃料；若没有，K恒为0。
- 若同时存在阈值两侧燃料：D>0时K∈{1,…,T}；D≤0时K∈{0,…,T−1}。
- 只有高于阈值和恰等于阈值的活跃燃料时，K∈{1,…,T}；只有高侧时K=T。

这不是说月度燃料数据无用：它精确确定D，也决定燃料支持是否跨阈值。结论是更窄的：精确分配到煤、气、水、风等各类的月量，除其压缩得到的D和阈值两侧支持外，不再收窄小时计数锐集。若目标阈值下高侧/低侧划分改变，支持信息也改变。

## 论文创新性判断

此定理给出信息审计和测量设计的理论核心：只增加更细的月度燃料分类，不能在该兼容类中打破小时分配不可识别；要获得非平凡尾频率界，必须带入小时容量、每日能源边际、小时总发电、运行/调度约束，或直接时间摘要。定理/全样本复核本身仍偏基础，尚不足以独立支撑强方法论文。更有价值的后续是检验哪类真实可得物理约束能有效且安全地缩界；当前在试年度机组容量，但需逐时验证容量映射没有低估EIA 930观测。
