# V363：官方技术碳足迹因子是邻近任务，不是小时CIF替代标签（2026-10-30）

## 新发现

生态环境部、国家统计局、国家能源局已发布2023与2024年全国电力碳足迹因子，并按煤电、气电、水电、核电、风电、光伏、光热、生物质及输配电给出技术因子。官方2024附件数值为：全国平均0.5777 kgCO₂e/kWh，燃煤0.9240、燃气0.4503、水电0.0141、核电0.0065、风电0.0324、光伏0.0520、光热0.0312、生物质0.0404、输配电（含线损）0.0327 kgCO₂e/kWh。

2023方法说明定义全国平均因子为各技术生命周期排放总和加输配电生命周期排放，再除全国用电量；各技术项包括上游、建设、运行维护和退役等不同阶段。故它是生命周期CO₂e消费足迹，和本项目主目标的运行期、小时级、地点/发电边际CO₂/kWh不同。不能把这些技术因子当作小时边际排放因子，也不能仅凭月度电量份额把它们线性拼成省级运行期CIF。

## 对可创新空间的影响

这组数据提供了可研究的**邻近验证任务**：公开月度/年度技术组成能否迁移预测低频生命周期用电足迹，且技术足迹因子更新后跨年偏移有多大。它不能直接补足小时CIF最关键的小时调度和净输入电力隐含碳信息。官方目前只发布全国平均生命周期足迹；检索到的安徽2024省级足迹报道仍待原始省厅PDF与边界逐项核验，因此本轮不把它加入可复算数据集。

以TransCIF当前目标看，此线索不推翻既有判断：

1. 用它可以新增一条独立定义的年度碳足迹预测轨，但需与年度运行期CO₂因子完全分开。
2. 若省份来源端只有“火电合计”，煤/气/生物质内部份额仍不可辨；即便有所有发电大类，也不能单独确定跨省净调入量和逐时调度。
3. 只有2023–2024全国平均标签不足以训练与检验跨区模型；省级安徽因子需取得官方原文并确认生命周期边界、全省分母、输配电处理和实际发布时点后才可作为新目标。

## 研究决策

不要把生命周期因子混进TransCIF标准小时CIF。先保留为单独的数据机会，优先拿到安徽省厅原始附件和官方国家统计局省级月度响应，再评估它是否可形成“年度消费足迹跨区冷启动”副任务。主线仍需真实小时标签；目前没有新预测器、经验覆盖结果或方法突破。
