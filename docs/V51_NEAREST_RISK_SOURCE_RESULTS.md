# 最近风险来源路由不能稳定解决低频-only区间失覆盖

在月度-only点预测不变、4特征歧义宽度风险尺度不变的条件下，将normalized q90校准从跨源池化改成“选择校准来源中风险特征中心最近者的source-specific q90”。距离在每次外层剩余来源的特征标准差下计算；选源只用合法粗量和donor预测特征。该实验沿用2024→2025 H1/H2已有开发窗，属于探索。

| 窗口 | pooled normalized q90 | 最近来源 q90 | max-source q90 |
| --- | ---: | ---: | ---: |
| H1 覆盖 / 宽 / IS | 91.83% / 275.74 / 335.11 | 94.22% / 290.30 / 320.22 | 96.45% / 363.66 / 384.15 |
| H2 覆盖 / 宽 / IS | 93.38% / 322.69 / 355.26 | 90.00% / 313.95 / 366.85 | 97.65% / 494.46 / 506.79 |

H1最近来源的宏分数最好，但最差MISO仍77.20%；H2最近来源最差FPL仅58.37%，且宏区间分数反而高于pooled normalized尺度。对应来源特征距离不能稳定指示哪一个校准尾分位可迁移。最近来源比max-source窄，但风险方向在半年间换向；当前不保留为可靠风险路由方法。

结果：`scripts/v51_nearest_source_risk.py`、`results/v51-nearest-source-risk-h1/`、`...-h2/`。点MAE与其他风险臂一致，因此变化均来自风险校准。
