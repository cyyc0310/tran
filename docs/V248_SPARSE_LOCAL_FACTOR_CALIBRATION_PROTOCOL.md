# V248 协议：稀疏本地实测日校准燃料CO₂/热输入率

## 目标

检验V247里DUK/WALC煤电等跨区供体失效，是否能由少量目标区本地实测信息修复。V247的2024同月、同燃料、leave-one-BA-out CO₂/热输入系数作为零日先验；目标地随机取若干2025本地日的实测 CO₂/热输入比，预测目标月份总CO₂。

## 目标和样本

- donor: 2024 EPA CEMS；target: 2025 EPA CEMS。
- 源标签：各年份EIA-860 Plant Code→BA。过滤CO₂及Heat Input measurement indicator=`Measured`/`MEASURE`、正运行时间、正毛负荷、正CO₂、正热输入，并排除多燃料主标签。
- 时间粒度：按BA×日历月×主燃料×本地日聚合运行时长加权的CO₂吨、毛发电MWh、热输入mmBtu。
- target月热输入总量视为已知的本地粗统计。对每种燃料用目标本地随机`k`天的`ΣCO₂/Σheat input`替换2024跨区供体因子，以估目标整月排放；k∈{0,1,3,7,12}。随机抽日无放回，固定RNG种子2472026，50次重复。
- k天不足的燃料格继续使用donor EF，保留完整配对BA-month，显式输出燃料覆盖数。

## 结果指标

报告按BA-month宏平均的中位/均值绝对百分误差、总排放WAPE、绝对强度误差；按燃料类别及BA拆分。WAPE定义为全样本绝对总CO₂预测误差之和除以实测总CO₂之和。

## 解释边界

目标热输入来自目标月全量小时数据的聚合；抽样本地CO₂也是同月回顾性实测。因此该试验是稀疏本地信息价值/月份重建，不是月初未来预测。目标标签与目标热输入共享CEMS来源，但样本之外的CO₂不参与目标系数；仍不能当成中国公开字段或全电网CIF验证。新样本预算只校准月度转换率，不能说明小时曲线形状已经识别。
