# 中国省级公开月报预测起点审计

日期：2026-11-01。审计既有31省无标签推理所使用的NBS面板，确认指定预测起点的公开月报预算是否在时间上可见、字段可用，并按生产输入合同选择正确的滞后月份。审计没有读取中国小时目标或重训模型。

## 预先固定的起点与检查

- 预测起点：`2026-11-01 00:00 +08:00`。
- 依照严格`t−2`规则，最后允许的统计期是`2026-09`。
- 核验面板、来源清单与seal哈希；确认来源API检索与输入seal时间均早于预测起点。
- 核验31省2026年9月总发电量及火、水、核、风、光五类当前值；五类合计与总量差不超过输入合同的`0.3亿千瓦时`容差。
- 逐省重新运行生产函数`nbs_months`，检查它确实选择2026年9月，并确认2026年4—9月连续窗口。
- 将上海原始用户导出中的火电、风电、太阳能9月当期值与官方长面板核对，并核实水电、核电在面板中为零。

国家统计局于2026年10月19日发布9月份能源生产情况。官方说明中的发电统计口径为规上工业，故该证据支持“在起点前已发布并可获取”，不支持把它解释为全社会发电总量或完整电网碳强度。见[NBS 2026年9月份能源生产情况](https://www.stats.gov.cn/zwfwck/sjfb/202610/t20261019_1965613.html)。

## 能支持与不能支持的结论

此审计将中国演示从“当前修订面板的滞后模拟”向前推进为一次有明确起点、检索时间和封存时间的前向可见性审计。所有省份在起点前确有可用的`t−2`月报，现有模型也能据此执行推理。

它仍不是历史as-issued版本重建：封存的是2026年10月30日取得的当前API快照，并非每条历史月份首次发布时的版本。NBS的“火电”仍是合计项，没有煤、气、油细分；上海用户导出目前覆盖火、风、光，不含其余两类。四舍五入造成的小额闭合差按既定政策处理。以上均不产生小时真值，不能证明中国点误差、预测技能或区间覆盖。
