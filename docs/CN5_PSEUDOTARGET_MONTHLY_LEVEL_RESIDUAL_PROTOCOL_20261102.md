# CN5嵌套伪目标的月度水平残差迁移协议

冻结日期：2026-11-02，运行和读取本实验新增评分前。该实验检验：滞后中国式五类月统计能否从源国伪目标中学习小时CIF代理的**月均水平偏移**，而不是只迁移日内形状。此处2024九国已用于其他项目开发，因此结果是新方法的开发筛查，不能称独立确认。

## 固定信息与标签合同

- 地域固定为Energy-Charts严格CN5既有九国：NL、ES、BE、AT、SE、CZ、SK、HU、SI；逐国外层留出。地区不重新挑选。
- 目标预测只使用预测月`t−2…t−7`内已存在的五类（火、水、核、风、光）月发电份额和目标月份季节项。不得使用目标年小时燃料、目标年CIF、目标月实际总量、天气或目标国家历史小时CIF。
- 源小时监督为2022固定因子发电侧代理；伪目标和外层测试为2023/2024。燃料因子、数据映射、源小时模型和月量时滞沿用严格CN5既有实现。
- 输出不是实测CIF、消费侧CIF或中国小时精度结论。月量由修订小时序列模拟得到，不是历史as-issued版本。

## 候选与交叉拟合

1. 每个外层目标国`T`，先将其排除在所有训练和来源校准流程之外。
2. 每个来源伪目标国`P`，小时基础模型只用其他来源国（同时排除`T`、`P`）的2022小时标签训练，预测`P`的2023H1、H2，计算各伪目标国家—月份平均误差。每条训练残差因此来自跨国留出预测。
3. `2023H1`伪目标月误差拟合两种候选：
   - `season_only`：目标月份正余弦季节项预测月平均残差；
   - `cn5_monthly`：严格五类滞后份额、六个月份额摘要（均值/波动/变化/总量CV/观测覆盖）及目标月份季节项预测月平均残差。
   使用国家等权、国内月份等权Ridge；固定alpha网格`{1, 10, 100}`。alpha在每个训练折内用来源国留一伪目标H1误差选择，选择目标为各国月残差MAE等权平均。评价月报特征增量时，再套一层外留伪目标国家`H`：除了不把`H`的残差行用于训练或alpha选择，生成所有其他伪目标残差行的小时基础模型也必须排除`H`的2022标签。单纯从已生成的全源LOO残差表中删掉`H`的行不满足该合同。`zero_correction`作为零残差对照。
4. 小时形状仍来自冻结的`fuelshare_hgb`。月度修正为对该预测月所有小时加同一个预测残差；不改小时内形状、不重新归一化、不改燃料份额。
5. 独立来源风险校准使用2023H2：对每个校准伪目标`P`，重新生成全部H1伪目标残差记录，并确保生成每个训练残差的小时基础模型都排除`P`的2022标签；月度误差模型只用`P`以外记录拟合，配置也只在该无`P`集合上选择。然后预测`P`的H2，计算校正后小时绝对残差的国家等权q90。强基线`anchor700`、`ratio_recomposition`、未修正`fuelshare_hgb`使用相同H2交叉拟合预测集校准。
6. 用全体来源H1伪目标记录选择外层修正模型配置并拟合；每个T的2024外层预测先写盘并哈希，再读取T的2024小时燃料标签评分。

## 强基线、指标与晋级门槛

同一共同目标小时比较`anchor700`、强`ratio_recomposition`、`fuelshare_hgb`、`season_only`修正及`cn5_monthly`修正。报告嵌套来源伪目标月残差MAE、外层逐国/逐月MAE、日内形状MAE、90%覆盖、宽度、Winkler、最差国家及修正方向。

保留CN5学习的必要条件：双层留国H1伪目标外层验证（每个评价国的alpha只由其余来源国内层CV选择）月残差MAE较相同双层验证的`season_only`至少下降5%，至少6/8外层折都不出现超过5%的退化；2024开发回放不得使相对未修正fuelshare头的宏MAE或Winkler恶化超过2%，并不得靠增加宽度换覆盖。alpha最终部署值才可在全部可用伪目标上重新以内层CV选择。即便通过，也仅为候选，因九国2024已查看，不能触发未查看地域确认。

若不通过，停止此类月度水平回归搜索，把月际水平残差作为现有公开月量下未可靠识别的风险来源；保留强重组、锚定及显式部分识别，不用真值Oracle改善包装算法。

## 可复核性

运行前冻结本协议、runner、源输入和公共映射代码SHA-256；每个外层目标点预测及来源半径独立封存。所有方法共用相同外层目标小时和来源训练标签。不得据2024国别结果改特征、alpha网格、支持范围或晋级门槛。
