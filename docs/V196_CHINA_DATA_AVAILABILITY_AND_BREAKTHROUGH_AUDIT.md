# V196：中国低频统计与小时 CIF 公开数据可得性及创新空间审计

日期：2026-10-29。此审计用于决定 V194–V195 之后是否还能在公开数据上验证“中国月度发电统计 → 未见省份小时 CIF”方法。没有运行新的预测实验；没有从新闻或图表反推小时标签。

## 本轮新增证据

### 1. 中国公开月度统计的主缺口仍是火电燃料拆分

国家统计局按月发布的省级电力数据常见分类是火电、水电、核电、风电、太阳能。中电联还有月度按技术/省级电量，但公开透明度审计指出：月度可燃燃料发电拆分并不完整；煤、气等更细燃料分项主要出现在滞后的年度统计。Ember 的中国省级月度发电/排放数据虽覆盖31省且按月更新，但它综合多来源和估算，不能等同逐台计量数据。项目既有 V51、V60、V99 已审计这些字段和估算问题；用户所持表格尚未提供原始表头，不能推断其分类等于公开 NBS/CEC schema。

### 2. 中国已有小时级因子计算能力，但目前不是公开历史真值

- 国网江苏在 2025 年底投入使用省级电碳因子数据库，新闻称可按不同时间、区域和电压等级在线计算小时级因子。公开报道没有提供批量历史导出、样本级版本、可访问API或可独立复算的序列。
- 国网江苏/华能等作者在 2025 年的同行评审论文中，使用实时发电、输电和省际/市际交换数据，计算江苏省及13个城市的时空因子；论文展示四个季节典型日，不是覆盖全年或多个省份的公开小时数据集，也不是月报驱动的预测评测。
- 国网安徽研究基于电网和发电企业的实时电源出力、火电机组煤耗计算2022年地级市因子并作聚类，摘要报告月均变化580–687 g/kWh；原始小时标签和煤耗时序未作为公开重现数据给出。
- 已有 V67 已审计国家标准、山东/宁夏/江苏业务平台和小时数据未公开的问题。本轮的江苏部署与公开研究进一步确认：**小时标签可能真实存在于业务系统，但其可获得性与匿名公开下载是两个不同问题。**

### 3. 新增 IEA 产品无法直接填补省级历史验证

IEA 在 2026 年开放了 Real-Time Emissions Factors 产品，约每国每天100个数据点，基于公开的运行/需求数据与年度排放统计计算，按日刷新。但产品面向**国家级**、提供 up-to-hourly 信息；历史周数据无明确版本锁定，IEA 提醒源数据会追溯修订且不保证完整/正确。页面使用非 Creative Commons 条款，文件访问需账户，API须联系 IEA 开通。因此它可作国家层近期外部对照线索，暂不能作为开放、可版本化、覆盖省域留出的中国小时基准。

### 4. 与 V194–V195 的边界

V194–V195 使用的2026 Figshare五情景小时 CIF 是规划/调度模型输出，目标月均也是事后oracle。它在本轮证明了一定的同情景/跨情景小时形状迁移信号，但无法验证用户月度技术发电量作为输入，也不能代替国网计量序列。V194最近5源区间覆盖59%–64%；V195来源留一自适应k没有胜过固定k=10，覆盖问题仍在。V51/V67/V106 已经说明月统计的物理识别信息和适用边界，不能再把同一问题作为新发现。

### 5. 与 TransCIF 最接近的新增研究：月燃料与天气下推中国日 CEF

检索发现2025-12发布的SSRN预印本[《A Machine Learning Framework for High-Resolution Provincial Carbon Emission Factors in China’s Power Sector》](https://papers.ssrn.com/sol3/papers.cfm?abstract_id=5960745)。其摘要明确使用月度分燃料发电量、温度/风/光/降水等权重下推日发电，使用CarbonMonitor-China日CO₂排放，比较RF/GB/XGBoost/LightGBM并作情景Monte Carlo；摘要展示内蒙古、江苏、云南三个省的时序交叉验证。该预印本与“月度统计+天气→高频中国省级CEF”直接重叠，不能声称TransCIF首次解决低频统计驱动的高频因子构造。SSRN页面只足以确认摘要和所报三省范围；本次未能取得PDF，尚未独立审查其公式、特征发布时间、目标构造是否循环、完整代码/数据可复现性或省份外推设计，因此这些点不能当作对该研究的批评结论。

它和本项目目标的潜在差别在评测任务而非“再换一个树”：TransCIF想做小时CIF、整省目标域不参与训练的冷启动迁移，并要求严格按首次可用信息建区间、报告逐省覆盖/弃答及强概率基线。该差异只有真实小时标签和统一的中国数据合同才能验证；目前V194模型小时、V196数据源审计尚未构成对该预印本的实证优越性。

另有2026预印本[GHGbench](https://arxiv.org/abs/2605.13743)已将跨地区/城市迁移、时间留出和配对bootstrap纳入跨实体排放预测基准，但主要任务是企业与建筑排放，不是小时电力CIF。它提示“做统一benchmark并加入region holdout”也不是足够具体的创新点；TransCIF需要凸显电网CIF的物理定义、月报可用信息合同、小时风险预测及地区条件覆盖，而不是仅扩展通用的split/model排行榜。

补充核实了[CarbonMonitor-China数据页](https://cn.carbonmonitor.org/)和2026-10-29当日下载接口：文件提供省级逐日多部门排放估算，当前覆盖到2026-06，但页面声明这是持续更新、可能改方法/追溯修订的数据。它可作带版本快照的日排放估算研究对象，不能直接冒充小时CIF标签或历史首次发布版本。本地只在`/tmp`检查了API样本结构，没有将这个易变快照纳入TransCIF输入或结果。

## 对创新空间的重新判断

### 不应作为主要贡献的方向

1. **再造简单供体选择器。**V195的 source-LOO 自适应k未胜过固定k，且区间更欠覆盖。
2. **声称月度发电量本身识别小时CIF。**总量约束不含小时顺序、净交换和系统调度；V51/V106已通过识别集合/反例说明这个边界。
3. **声称中国真实小时预测精度。**V194是模拟，业务平台数据不可得，IEA目前是国家层且非开放历史序列。
4. **将生产侧混合排放强度与消费侧CIF互换。**消费侧因子需要跨区输入碳流；仅本省月度发电结构不含它。
5. **声称首次从月度燃料统计和天气生成中国日/高频CEF。**上述2025年SSRN预印本已经提出这条构造路径；需将创新论证转向小时冷启动评测、识别边界、可信区间或可审计数据合同，并用头对头实验验证。
6. **仅以“统一跨区域benchmark”作为贡献。**GHGbench已在企业/建筑GHE预测中提供跨实体/区域split框架；必须把benchmark定义为电力CIF专属、物理与信息合同严格、且有真实标签支持的问题。

### 尚有价值、且必须可证伪的研究主线

**面向缺少本地小时计量的新地区，构造“信息条件明确的省份留出小时CIF评测”：**

1. 把任务拆成目标月水平和小时形状/风险两个估计量；提供生产侧与消费侧因子的独立标签合同。
2. 以目标省可得的月度燃料结构作为可用信息，逐步增加公开滞后容量、月度交换、天气/可再生条件等字段，测量每种增量的辨识与预测价值；使用当时可得版本，禁止事后月均oracle冒充月报输入。
3. 先以真实高频数据域训练和封存迁移/分布风险算法，再用模拟投影做机制压力测试；最终至少通过一个真实中国小时源的授权留区测试。公开信息不足时，输出识别集合或拒绝决策，而非伪精确小时曲线。
4. 方法上的潜在原创点应落在**源风险可迁移时的条件化区间压缩**：小时形状只在源域提供支持的月份/小时风险区域内收缩，源支持外保留风险并允许弃答。要证明它在同一目标覆盖约束下同时缩窄区间、优于普通 split conformal/CQR/简单锚定；若只靠扩大区间抬覆盖，不算增量。

该路线与既有 V106 的月粗统计部分识别、V193 的统一评测合同、V194 的中国投影形状压力测试相接；它不是已证实创新。模型的下一次大改前，应优先获取带首次可用时刻和修订版本的真实中国小时数据。如果没有这类标签，算法效果无法对论文的主要真实世界主张作确认。

## 推荐的下一动作

1. 继续使用 V194/V195 的公开情景数据只做压力测试，不把它作为新地区真实验证；新增算法必须预注册并通过省份/情景双留出。
2. 请求项目方/合作方确认是否可以合法获得江苏、安徽、山东或宁夏业务数据中的任意一个区域、连续至少一个季节的历史小时/15分钟因子及对应首发时刻、区划和生成口径。若获批，做小范围盲外测即可先回答算法增量是否真实。
3. 若只能用公开数据，论文应收窄为“公开粗统计条件下的可识别性/迁移风险基准”，并明确模型世界与实测标签的证据层级；不能宣称解决了中国真实小时CIF冷启动。
