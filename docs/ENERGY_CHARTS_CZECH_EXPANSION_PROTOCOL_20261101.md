# 捷克源域扩展：多类别映射下的六国整国留出协议

冻结日期：2026-11-01，运行和查看目标评分前。研究问题是：加入一个关键类别完整的捷克小时源域，能否改善中国式滞后粗月预算下的跨国小时强度预测？本轮是既有五国开发队列的扩展，不是盲测确认或真实CIF验证。

## 面板、输入与标签

- 原五国：NL、ES、BE、AT、SE。新增捷克（CZ），使用Energy-Charts API v2 `public_power`在2022-01-01至2025-01-01返回的响应；当地时区`Europe/Prague`，单位MW，接口报告`PT1H`。保存原始响应、下载清单和SHA-256。
- 按本国白名单把褐煤与硬煤映射到coal；天然气和煤气化副产气映射到gas；燃油映射到oil；biomass、waste、others映射到other；nuclear映射到nuclear；常规河流水库映射到hydro；wind_onshore、solar、other_renewables分别映射。抽蓄、抽水、跨境、电力负荷和API派生比例不进入本地发电分母。
- 只要求接口明确列出的分类；映射类别的空值保留缺失，不能按零填补。按前一版冻结协议的规则，15分钟数据须四分位都完整才能形成小时；月份至少99%当地小时完整才生成粗月统计。CZ映射到九个固定代理类别的因子和原五国一致。未观测火电类别或接口口径仍可能造成标签遗漏，输出是固定因子发电代理，不是实测或官方CIF。
- `t−2`及更旧月量从当前修订小时序列回算，模拟公开延迟，不称历史as-issued月报。

## 整国留出和配对增量

- 外层目标为NL、ES、BE、AT、SE、CZ逐国留出。每折只用其他国家2022小时监督训练，其他国家2023年1–6月估计90%经验误差半径；目标只输入日历和当地可见的滞后粗月量，2024小时真值在所有预测封存后用于评分。
- 模型集合沿用原五国LOCO：`anchor700`、`macro_recomposition`、`ratio_recomposition`、`ridge_history`、`direct_latest/history`、`factor_latest/history`。所有方法共用样本、训练期、校准期及月/国等权评分。
- 主增量是同一目标队列上，对原五个目标比较原五国封存基线与“其他五国含CZ”的六源模型；另报告CZ作为新外层目标时的表现。采用相同输入、训练年份和风险校准，不根据CZ结果选模型或超参数。
- 逐目标报告MAE、去日均形状MAE、90%覆盖、区间宽度及区间评分；同时报告国家宏平均和最差目标。国家是独立外层单元，小时不作为独立重复。

## 判读边界

只有点误差、形状和覆盖/区间效率共同改善，才将CZ视为对该代理队列有用的额外源域。更宽区间提高覆盖、只改善CZ自身、或只扩大中国输入的坐标范围不算跨国预测增量。任何收益都不能单独证明煤气运行关系可迁移或中国预测准确。六国都进入开发评估后，不能再把任何一个称为项目未查看的确认国家。
