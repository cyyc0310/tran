# V298 protocol: precision required for a one-number monthly CIF anchor

Frozen 2026-10-30 after V297. Reuse V297's 358 BA-month V97 cohort, lagged coarse capacities, proxy factors, two-block sharp-set derivation, and τ=600/900. Do not tune regions or months.

Sweep symmetric absolute monthly-mean-CIF error bands of ±0, 0.25, 0.5, 1, 2, 3, 5, and 10 gCO₂/kWh. Compare each anchored set with V297's exact-anchor set, threshold-side-MWh set, and detailed-monthly-fuel set. Report width, ≤1/5/10% tail selective frontier, set nesting, and the fraction of BA-months where the anchored width is no greater than the detailed and threshold-side sets.

The precision sweep is an information-value stress test. The anchor remains oracle-derived from the EIA proxy. The error bands are not empirical measurement-error claims for China or any public emissions source. If useful compression requires sub-1 g/kWh accuracy, treat that as a high bar for any proposed low-cost local field and identify a different observable measurement.
