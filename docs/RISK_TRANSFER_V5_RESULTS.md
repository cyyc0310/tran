# 第三轮：粗统计创新风险与水平—形状校准

2026-10-23，所有实现、执行与独立复核使用Sol。

## 为什么继续第三轮

[V4两轮结果](TRANSFER_V4_RESULTS.md)在源开发中看似改善覆盖，但六个新地区的固定主方法仅约60%边际覆盖，最强参考约58%。这次失败完整保留。第三轮不把相同六区调参后重新称确认，而另留SCL、WACM、SEC、SCEG四区2025全年，原六区只用于诊断失败机制。

本候选只改不确定性，不重新拟合点模型。用预测时已发布粗月的变化幅度，避免把源地区的固定误差尺度直接搬到新地区。

## 实际方法及强对照

从V4封存文件精确复用2022四源拟合模型，保留三个点方法：支持窗口GP、周期回归、softmax专家。快速预测实现已与原代码在三个源日期核对，各点与尺度最大差值均为0。

每个预测时点，先依照假定发布时间筛选历史粗月，再取至多24份合法统计。定义

\[
r(t)^2=\bigl\{0.5\,\mathrm{SD}(z_{last12})^2
 +\mathrm{RMS}(z_j-z_{j-12})^2
 +0.25(z_{latest}-z_{same\ month})^2\bigr\}
 (1+age/60).
\]

年度差只配对两份均已发布的同月统计；没有足够历史时风险回退0，并保留原模型尺度与缺失标记。r是预测前的风险代理，不是未来误差的确定界。

水平尺度由a改为 `sqrt(a²+(βr)²)`，β=.5/1/2在新四区评分前固定，源校准与目标恢复都采用同一变换。形状尺度不因r直接变化，同源同日的水平/零均值形状误差联合抽样。三种风险方案与七源普通残差、七源普通分量1.10共五种分布，所有三个点方法都使用同样信息。

校准改用原七区2023小时残差，与2022点模型按时间分离；**地区允许重叠**，不能声称与V4相同的独立校准域设计。源选模为原七区2024。所有方法共同将概率情景与解析区间限制到已知固定EF代理的[0,1000]；原始点不裁剪，投影前概率质量另存。这是公共工程处理，不是原创贡献。水平/形状严格分离的代数性质仅在投影前成立，非线性裁剪可同时改变最终情景的均值与形状。

主方法和非风险强参考均由源端固定；覆盖筛选为宏90%±5个百分点、最弱地区×延迟≥85%，合格者中CRPS最低。参考只能从七源普通残差/普通分量校准选取，不可将风险方案偷偷列作自己的基线。所有延迟选择统一配置，外部不再挑β。

## 开发与新四区结果

源七区2024共2,266个有效地区日，3点方法×5分布×3延迟，共101,970条方法日评分。原始预测模型字节、风险配置、β、输入和环境完整性检查均通过。

| 源端固定配置 | CRPS | 90%覆盖 | 最弱地区×延迟覆盖 | 宽度 |
| --- | ---: | ---: | ---: | ---: |
| 主方法：周期回归＋风险β=.5 | 25.664 | 94.74% | 85.24% | 174.067 |
| 最小违规非风险参考：softmax＋七源分量 | 26.337 | 92.57% | 76.84% | 165.521 |
| 无覆盖约束最强非风险参考：GP＋七源分量 | 25.237 | 92.38% | 75.35% | 159.636 |

全部非风险参考均未通过局部覆盖筛选，基线冻结文件明确为`constraint_failed`，不把最小违规参考伪装合格。主方法牺牲部分尖锐度，并未在无约束CRPS上胜过GP；通过筛选也不是新地区覆盖保证。

source-only主方法、两种非风险参考及其hash/冻结时间在打开新四区分数之前封存。源排名、风险消融与逐区图见[源分析](../results/risk-transfer-v5-source-analysis/)。本轮源校准和开发地区数不同于V4，不能直接将两个版本的源宏平均作单因素算法提升。

新四区1,424个有效地区日×3点方法×5分布×3延迟，共64,080条方法日评分；所有180份预测文件整体封存后才评分。原模型、重新校准产物、输入、候选配置与β、runner、基线副本均核验通过，外部没有重新调参。

| 总发布延迟 | 固定风险方法CRPS | 最小违规参考CRPS | 风险方法90%覆盖 | 参考90%覆盖 | 风险方法宽度 | 参考宽度 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 30日 | 40.171 | 38.215 | 91.94% | 76.70% | 229.339 | 145.475 |
| 60日 | 40.405 | 37.563 | 94.66% | 78.02% | 258.249 | 150.094 |
| 120日 | 40.286 | 38.256 | 97.50% | 77.17% | 327.842 | 150.602 |

**覆盖不足明显缓解，但尚未形成全面更优、足够尖锐的概率预测。** 宏平均覆盖94.70%对77.30%，增加17.40个百分点；同步月份描述性95%差值区间[13.43,21.57]个百分点。风险方法全部12个地区×延迟组合覆盖至少87.12%，相对原来的局部欠覆盖已有改善；但120日97.50%的宏覆盖明显过保守，不能写成精确90%校准。

代价同样明确：宏区间宽度271.810对148.724，增加82.76%；CRPS40.287对38.012，均值恶化5.99%，差值+2.276的月份区间[−2.782,7.703]跨零。区间评分311.720对328.984虽均值改善，差值区间[−71.345,26.496]也跨零。因此未建立同时改善覆盖、CRPS和尖锐度的优势。

另一个预先固定的、按源端无约束CRPS最强参考为GP＋七源分量校准，外部宏CRPS约40.090、覆盖75.36%、宽度140.207。主方法CRPS与它接近，但更宽；同样不能忽略此强参考。

在相同周期点预测的预先包含消融中，风险归一化相对普通七源分量将CRPS约44.063降至40.287、覆盖约73.13%升至94.70%。这支持该风险信号具有实证作用，却不替代与更强点预测参考的比较。raw点不变，因此这项消融不是原始点预测及其去日均形状的改进；最终分布的均值仍可能随残差传输与投影变化。源端也归一化，最终目标区间并非逐地区必然扩宽，例如SCL平均宽度由同点非风险的59.46降至41.82。

以上结果只来自这四个新地区；不可把V4另外六区约60%与这里94.7%的跨数据集差异称为算法提升34.7个百分点。V5内部相同数据、相同七源校准、相同投影才可归因风险方案。

## 本轮结论与后续优化空间

本轮已经设计并实现自己的可检验候选，并完成三轮源开发、两个独立新地区测试块，保留了年度创新桥未胜出、V4覆盖崩溃和V5过宽的证据。当前支持继续研究“可观察风险驱动分量不确定性”，不支持已经形成成熟的新算法或普适可信预测框架。

优先需要解决的是**风险预算的分配与条件尺度估计**：长期延迟的风险不能一律按同一个年龄公式扩张；需要区别长期结构变化与可重复季节波动，在高风险地区保留覆盖，在稳定或低碳地区缩短区间。下一方法应与标准异方差误差回归、source-only全局膨胀、局部归一化/CQR及已有概率后处理比较。若它们能实现同样收益，应收紧原创性主张。

进一步开发时，本轮十个新地区均已查看，不能再当最终未见测试。需要新的地区或时间，且明确其是否仍有目标历史小时误差介入设计。方法论文仍需更有辨识度的机制/假设、重复外部增量和覆盖—宽度的实际效益；基准论文则需独立的跨国数据协议与资源贡献。

## 如何解释创新与可信性

本轮的具体新候选是历史粗创新驱动的**水平**风险尺度与分量误差传输，而非泛泛添加小波或新核。归一化残差、异方差模型和局部自适应区间已有直接先例，例如[Lei等2018](https://www.stat.cmu.edu/~ryantibs/papers/conformal-jasa.pdf)、[Localized conformal prediction](https://academic.oup.com/biomet/article/110/1/33/6647831)。因此“用输入预测尺度”本身不能宣称首次，本实现也不是这些保形算法的完整复现，不继承其覆盖定理。

要形成方法论文，仍需证明观测支持/时效风险提供超越标准误差尺度回归、状态模型和概率后处理的可重复价值；也需将可迁移的误差分量与未知域偏移分开。目前r的系数与加法结构是固定候选构造，不是新理论或严格误差界。

V4→V5同时增加校准地区、采用公共边界投影并引入风险候选，跨版本变化不能归因于单一创新。主要证据必须来自V5内同信息、同投影的固定对照。

所有数据仍为回溯修订的EIA发电侧固定EF代理，假设月末后30/60/120日发布，没有真实历史发布版本或中国小时参考。新四区共有1,424个有效地区日；它们属于同一国家并可能相关，月份bootstrap只描述这些观察地区的时间变化，不是全球泛化保证。年度-only或没有历史月度信息的条件仍未验证。

## 复现与审计

协议：[RISK_TRANSFER_V5_PROTOCOL](RISK_TRANSFER_V5_PROTOCOL.md)。入口：`scripts/run_risk_transfer_v5.py`；风险变换：`src/transcif/research/risk_transfer_v5.py`；新数据：`scripts/prepare_external_v5.py`；固定比较：`scripts/analyze_risk_transfer_v5.py`。

```bash
python scripts/run_risk_transfer_v5.py --output results/my-v5-source --n-samples 128
python scripts/analyze_risk_transfer_v5.py --source results/my-v5-source --output results/my-v5-source-analysis
python scripts/run_risk_transfer_v5.py --study holdout \
  --external-data results/external-v5-data --output results/my-v5-external \
  --selection results/my-v5-source/scores/selected_config_with_baselines.json --n-samples 128
```

选择副本需先将源分析的完整基线对象、hash、冻结时间嵌入原选择副本；原选择保留。外部复用源拟合/校准字节并核对完整网格、β及runner哈希；同名参数变化会被拒绝。所有新四区/方法/延迟整体封存后才计算目标小时分数。审查覆盖时间分辨率、未来发布隔离、风险不能改点/形状、分量同日配对、源/目标同变换和全局封存。完整测试366项通过，3项既有警告。
