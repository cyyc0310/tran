# V375：省级组成收益随未覆盖电量月度上界收紧的前沿

登记日期：2026-10-30。V374显示宽范围残差让τ=300本地/全国组成hull都成整月。本轮只研究一个可操作的信息缺口：若能把每期未覆盖电量限定在V345年度范围差的某一比例内，省级组成何时重新产生可见K宽度差？

## 固定设计

- V373两臂共同可行的2023省期配对队列，CEC 2022滞后容量。
- 主阈值固定`τ=300 g/kWh`；已报组EF支持thermal `[400,1000]`、其他组为0；范围残差EF `[0,1000]`。
- 逐期残差区间设为`[0, α·R_max]`，`R_max`取V345年度全口径—月规上差额的可行上界；`α∈{0,0.1,0.25,0.5,0.75,1}`。两臂使用同一组残差质量、容量上界、因子端点和小时数。
- 结果是对每个端点可行K集的保守外包络宽度；按V346做法，端点外包络不是经验覆盖区间。

报告Local、National-mix的平均宽度、差值、整月宽度计数和不可行计数。`α`只是人为压力网格，不表示观测到的残差误差或政策上可得的字段精度。该分析只能给出“需要把未知范围约束到多窄”的条件前沿，不能声称模型预测或验证成功。
