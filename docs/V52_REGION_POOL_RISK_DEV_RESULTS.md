# V52 地区级风险校准扩池开发结果

2026-10-27。结果来自已反复用于开发的11个 EIA-930 区域，**不是未查看地区确认**。预测目标为固定EF正部已报告发电代理。所有方法共享严格月度五类输入、同一源小时形状点头及同一标签；每个外层目标有10个校准地区，预测2025H1/H2。2024校准预测对校准源做嵌套留区，同时排除外层目标源和被预测的校准源。

## 失效定位

- SC是主要的水平迁移失效。H1点MAE/有符号偏差约299/ +299 gCO₂/kWh，目标绝对残差q90约366，而校准源最大q90约338；最大组半宽不足以容纳该正偏差，覆盖74.56%。月度组成条件尺度给SC的区间更窄，覆盖仅12.22%。H2 SC偏差仍约+272，但目标q90约334，校准最大q90约382，最大区间覆盖96.09%。同一地区跨半年一成一败，暴露了时间漂移与地区偏差共同作用。
- NWMT两个半年都存在大正偏差：H1/H2约+231/+256 gCO₂/kWh。校准最大q90能够覆盖H1（95.90%），H2以宽度836、来源最大q90约418取得90.67%覆盖；月度条件尺度的覆盖只有31.38%/33.13%。
- 更大的名义校准区数解决了有限秩是否存在的问题，却未使跨区尾分布可交换；在相同点预测下，最大组q90仍靠大幅扩宽换取大部分地区过覆盖，并不能抵御SC的时变系统偏差。

## 研究判断

本轮否定“将校准地区简单扩到10个就能得到有效窄90%小时区间”这一假设，也否定当前两特征（月thermal share、风光share）尺度头能识别区域尾风险的说法。新的证据把核心问题进一步缩窄到**点头的地区级水平偏差及其跨期变化**，而不只是小时残差尺度。SC、NWMT的严重误差是成片有符号偏差，按对称半宽校准主要导致区间极宽。

当前没有达到方法门槛，不冻结候选，不查看6个封存地区。本轮用到的地区此前均已评分；最终未评分区仍为FMPP、GRID、IID、LDWP、PSEI、TEC。下一轮开发应先针对可合法获得的本地粗统计能否预测**残差中心/水平漂移**做严格同预算消融，并与上一年锚、全国/源池水平锚及强动态点基线比较；若中心无法预测，评估可验证的拒答/宽区间代价，而非继续微调异方差尺度。
