# V389：上海官方目标口径差异大于近期年度漂移

日期：2026-10-31。本轮将上海2020—2024公共电网年度因子与2021—2023 MEE/NBS省级年度平均因子做量级比较，并复核上海官方公共电网因子的方法来源。此为标签与信息合同审计，不是预测实验。

## 数值量级

上海官方公共电网年度因子为2020—2024年的0.4220、0.4736、0.4850、0.4783、0.4701 kgCO₂/kWh。较近四个年份（2021—2024）的跨度为0.0149 kgCO₂/kWh。与MEE/NBS省级因子同年匹配（2021—2023）后，上海本地公告值低0.1098、0.0999、0.0954 kgCO₂/kWh，平均绝对差0.1017 kgCO₂/kWh；该差约为上海2021—2024自身年度跨度的6.8倍。

这个比值描述的是**两个官方口径之间的差异相对于本地年度变化的量级**，不是模型误差。上海本地公告的消费边界、绿色权益扣除方式、系统数据来源，与MEE/NBS省级平均因子的具体方法和版本没有被证明完全同口径。因此不能据此宣布任何一方错误，也不能把另一方当作同目标的预测真值。

## 官方消费因子的可追溯来源链

上海生态环境局、统计局的方法说明明确：公共电网因子是自然年消费侧平均因子，包含本地公用电厂化石燃料排放和市外净调入化石电力隐含排放，分母是公共电网供电量。分子本地部分按燃料品种逐项计算，燃料投入来自能源平衡表中“加工转换投入—火力发电”部分；市外净调入化石电量及区域供电量等项来自电网企业统计。剩余组合因子进一步从分母扣除已声明使用的非化石电量。

这比只给出一个年度因子更重要：它证实上海官方年核算背后存在“本地燃料投入、跨区电量、绿色属性、公共供电量”几类分开的数据合同。但公开附件目前提供的是最终年度因子和公式，没有公开逐月的这些分项，也没有小时标签。用户手头NBS五类月发电量仅覆盖本地发电结构，无法重建消费侧分子或小时输入碳流。

## 方法结论

1. 下一阶段不应将本地NBS月发电量直接回归到任一官方年度省级因子后，再把所得残差解释成小时预测误差；首先必须固定生产/消费边界、因子类型、发布时间和版本。
2. 若论文目标是生产侧小时强度，现有NBS月边际仍是低频组成输入，仍需独立小时燃料/排放标签来验证尾风险。
3. 若目标是上海公共电网消费侧年度强度，可将年因子作为独立年标签，但预测至少要有本地燃料×发电投入、市外净调入排放与供电量；2020—2024五个年度观测不足以证明跨区通用性。
4. 因此当前最有论文价值的框架候选仍是双estimand、分层信息预算和部分识别边界。把口径差异量化到年际变化尺度提高了该框架的必要性，但还没有形成新的预测算法或小时风险突破。
