# V159：活动坐标与正发电条件化的贡献边界

在V159完整结果写出前记录。源区筛查用于决定是否值得继续，不构成原创性证明。

V159的CIF映射R(B,u)只取决于u的正射线：R(B,cu)=R(B,u)，c>0。以u/Σu作森林分裂标签可以删除公共尺度，但归一化、组成几何、比率模型本身均非新理论。[Tsagris等，Statistics and Computing 2023](https://link.springer.com/article/10.1007/s11222-023-10277-5)已研究带零值的组成响应及非参数回归。其方法不等于本项目活动传输，但足以否定“处理组成和零值本身是全新方向”的笼统论点。

把零总量假想状态与真正零碳正发电状态分开，是定义域处理。随后对正总量事件条件化是标准概率操作，不是新的校准原理，也不保证预测正确或满足完整月度能源总量。[Zambon等，Statistics and Computing 2024](https://link.springer.com/article/10.1007/s11222-023-10343-y)已有基于条件化的概率一致化；[UAI 2024混合层级工作](https://proceedings.mlr.press/v244/zambon24a.html)进一步处理离散/连续混合预测。它们的线性层级约束与本研究非线性比值定义域不同，但不能把一般“条件化到可行域”当作新贡献。

响应感知森林继续属于有限嵌入响应上的平方误差森林，见[V158代数边界](V158_METHOD_NOVELTY_BOUNDARY.md)。V159增加的正总量指示用于区分嵌入中未定义与实际零CIF，不应称为识别出目标地区停机概率。

真正值得追踪的经验命题是：在无目标小时标签、明确统计时效和组成支持缺口的条件下，什么非负活动规律能跨区迁移，以及按碳响应而非无关活动尺度学习是否稳定改善完整概率分布。若只有标准动态analog有收益，应归因于动态条件匹配；若仅剔除未定义状态有收益，应归因于定义域修正。只有进一步超过这些普通参考，才有讨论专门任务机制的基础。

本轮源训练、校准和测试地区共享2024时间跨度，因此是跨地区开发筛查，不是训练截止点严格早于每个源查询时刻的前瞻回测。asof约束保证本地输入月的模拟发布时点；不能据此说全部模型训练数据在该2024查询时刻已经可得。最终2025目标评价仍需只使用冻结的2024源模型和独立源校准；中国发布版本及小时标签亦未接入。
