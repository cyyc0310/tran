# 九国严格中国五类粗月输入协议

冻结日期：2026-11-01，预测前。此前九国实验使用了代码中的第六个`other_renewable`粗输入列，尽管协议写的是中国可见的火、水、核、风、光五类。本协议重新建立严格五类输入合同；旧六组输出保留为探索性敏感性结果，不作为中国五类信息预算的证据。

## 输入与标签

国家固定为NL、ES、BE、AT、SE、CZ、SK、HU、SI。目标公开输入只能包括日历和五个滞后粗月份额：火电、水电、核电、风电、太阳能。每个来源月的五类份额以这五类已报告电量之和归一；`other_renewable`不得进入月份额、历史特征、形状原型或预测特征。它仍留在源小时响应的总发电量分母中，且固定排放因子为0，代表目标输入未观察到该类型。

小时响应是固定因子生成侧代理（煤1000、气400、油800、其他燃烧400、核/水/风/光/其他可再生0 g/kWh），不是实测CIF。粗月量由当前修订小时序列聚合并模拟`t−2…t−7`，不是as-issued历史发布版。SK未单列waste、SI未单列other_renewables的标签映射缺口需明示。

## 整国留出

2022年其余八国训练，2023H1其余八国源端小时池化90%残差校准，目标国2024预测。固定方法为anchor700、宏/比例重组、Ridge history、直接latest/history、火电有效因子latest/history。方法结构与既有多国基线相同，但所有输入特征、组成分母、形状参考均严格限于五类。可选年度装机实验沿用相同队列，容量作为单独额外特征预算。

每国的点预测及校准半径先写盘并计算SHA哈希；全部九国封存且核对代码/输入哈希后，才读取2024响应评分。报告目标国等权、目标月等权MAE、去日均形状MAE、经验小时覆盖、宽度和区间分数，以及逐国最差结果。目标标签仍为代理；小时池化源残差覆盖不等于新国家保证。所有九国均为开发域，不是最终盲测。
