# 双轨小时预测输入可得性审计

更新：2026-11-02。目标是判断是否存在能进入中国跨国冷启动迁移的公开预测时信息预算。该审计只确认规则和公开数据入口，不代表已经取得各省历史预测版本，更不是预测效果实验。

## 结论

1. **发电侧主预算不变。** 用户确认的预测输入仍是可追溯发布时间的省级火、水、核、风、光月发电量；公开年度装机仍单列M+C。国家统计局发布制度记载电力统计按月、季、年形成，相关电力数据约每月14日对外发布。因此每个回测月必须用实际发布日期确定最后可见月份，不能假定目标月数据已知。[国家统计局《电力行业统计调查制度》](https://www.stats.gov.cn/fw/bmdcxmsp/bmzd/202302/t20230215_1907062.html)
2. **中国存在合法的小时预测扩展预算候选。** 国家能源局2024年《电力市场信息披露基本规则》把系统负荷、发电总出力、新能源分电源类型总出力、水电出力等预测列为公开披露信息；表格也规定按日/周、交易时间单元等频率披露。[国家能源局规则原文](https://zfxxgk.nea.gov.cn/2024-01/31/c_1310763726.htm) 但规则允许地区在不能满足披露要求时向监管机构报备；规则存在不等于每省都有开放API、历史归档、可下载发布时间戳或稳定的数据口径。故先登记为候选`M+F`，在逐省验证历史版本、覆盖和字段之前不进入主结果。
3. **消费侧有独立的流量信息候选，但来源碳强度仍缺。** 同一规则列有省间联络线输电曲线预测、实际省间联络线输电情况等公开字段；这可能支持消费侧`C1+Fflow`信息层。它不等于毛受电OD全覆盖，也不提供每小时送端来源分配、送端碳强度、损耗和消费分摊核算。消费侧准确度实验仍需这些量与独立标签，不能用本省发电侧预测结果补齐。
4. **不能把运行规则误写成历史数据集。** 较早的调度信息披露文件规定部分次日预测通过电力生产调度系统披露给发电企业；这反映了特定运行信息的受众限制。新规则扩展了电力市场范围内的公众披露条目，但须按实际省份和市场平台检查执行情况，不能将旧规或新规单独当作数据可访问性的证明。[较早调度披露办法](https://xjb.nea.gov.cn/xxgk/zcfg/202309/t20230924_119605.html)

## 海外回测输入的版本限制

- 英国NESO“Demand Data Update”页面提供截至当前日的历史负荷、联络线、风光实况，以及未来7天嵌入式风光预测；页面说明通常每日08:30 UTC更新。当前页面说明支持近期运行使用，没有因此证明多年历史预测vintage可取。[NESO数据页](https://www.neso.energy/data-portal/daily-demand-update/demand_data_update)
- 美国EIA-930按小时收集平衡区运行数据，平衡文件含需求预测、实际需求、净发电与燃料发电；EIA说明有历史提交记录，但同时说明历史值会因运营机构纠错而修订。因此对历史预测的回测必须固定具体提交/归档快照及其时点，不能把最新修订接口默认视作as-issued预测档案。[EIA-930数据说明](https://www.eia.gov/electricity/930-content/about.html)
- 因而本项目的M+F不是把实况或最新修订序列回填到历史，而是只接收带目标时点、发布时间、预测时距、版本号和统计边界的快照。缺少这些字段的小时实况只能作oracle信息价值分析。

### 新增：NESO已有可追溯的逐年预测签发档案

进一步核查发现，NESO另有独立的[Embedded Wind and Solar Forecasts年度档案](https://www.neso.energy/data-portal/embedded-wind-and-solar-forecasts)，不应与只提供近期预报的Demand Data Update混为一谈。官方页面列出2019–2026档案，并说明数据包含半小时、0–14日前已发布的嵌入式风光预测；字段包括目标日期/时刻、预测发布时间`Forecast_Datetime`及风光预测MW。2024 archive可直接从NESO CKAN下载。[2024档案说明](https://www.neso.energy/data-portal/embedded-wind-and-solar-forecasts/embedded_solar_and_wind_forecast_archive_2024)

对2024档案做了一轮严格origin预检：固定取每个UTC交付日前一日09:12 UTC发布版本，不用交付日后的更新；按结算日期与半小时period配对官方嵌入式风光实况，并独立确认目标时间戳可一对一接入项目NESO面板。选中362个交付日、17,376个半小时，覆盖2024已配对目标序列98.9%；仅1月1日、2月2日、7月25日、9月27日四日缺该签发快照。预测时距14.8–38.3小时。风预报与嵌入式风实况相关系数0.981、MAE 178 MW；太阳预报与对应实况相关系数0.983、MAE 244 MW。此结果只证明有覆盖较广、时间戳明确且包含信号的目标侧输入，**没有证明M+F改善CIF预测**。页面定义该预测是输电系统看不到的嵌入式风光估计，不代表风光全量；必须先审计与项目发电代理/消费侧标签边界的关系。

固定时点特征快照、缺日、误差指标和输入哈希见[证据包](evidence/neso-embedded-forecast-vintage-r1/README.md)。原始年度CSV为512,049,380字节，SHA-256=`f9a3fba4223924d913413732fcc82fe7482de055b3d257ba1257b8478ba2e6a6`；仅保留了可配对的紧凑预报特征，不重复存放512MB原文件。

## 双轨预算与执行门槛

| 轨道 | 主预算 | 可审计扩展候选 | 不得混用的缺失项 |
|---|---|---|---|
| 发电侧G | 滞后月度五类发电量`M` | 年度公开装机`M+C`；逐省as-issued小时新能源/水电/总出力预测`M+F` | 目标小时实际燃料结构、未经封存的目标小时实况 |
| 消费侧C | `C0`：本地发电信息只作弱基线 | `C1`：可见省际交易/联络线预测与运行量；另列年度OD | 毛受电及送端逐时来源分配、来源碳强度、损耗和消费侧独立小时标签 |

每个候选平台先做只读预检：公开网址/API、访问权限、历史覆盖、目标时点前最后更新时间、预测签发时刻/时距、修订快照、燃料/电源分类、空间边界、MW或MWh单位、夏令时/时区。预检失败的省份不通过数据插补伪造M+F输入。只有通过预检的省份进入共同样本；主结果仍同时报告M、M+C、简单锚和强重组，扩展预算单独列示增量。

## 下一步执行顺序

1. **已完成NESO发电侧M+F开发消融。** 2024共同样本上的已签发风光形状使MAE降低3.8%、日形状误差降低16.2%，但未达到5% MAE门槛，Winkler略差；2025仅风形状时间外回测MAE改善2.23%，也未过门槛。两项结果都不支持把M+F升为中国主输入或创新方法，且GB是已查看的单一目标。见[2024风光结果](NESO_AS_ISSUED_VRE_SHAPE_TRANSFER_RESULTS_20261102.md)与[2025风电结果](NESO_WIND_FORECAST_SHAPE_2025_TEMPORAL_RESULTS_20261102.md)。
2. 并行对上海及公开平台可定位的中国省份做具体历史预测快照预检，记录链接、抓取时间、覆盖月数和文件哈希。NESO结果只说明实验路线可执行，不能代替中国实际平台的可得性。
3. 消费侧先检查C1+Fflow流量信息是否存在且统计口径闭合，再决定是否可训练和评分；送端强度缺失时只做部分识别，不把M+F发电结果搬到消费侧。
4. 若历史快照不存在或覆盖太少，保留预测时输入为信息缺口，主论文仍以滞后月报迁移基准和可识别性边界为核心；消费侧维持部分识别/数据需求结论。

该审计未训练模型、未运行代码测试，也没有新增实验分数。它为下一步收窄了数据预检目标，不改变已有算法结论。
