# Strict-CN5 组成加权共形区间协议

冻结：2026-11-01，运行前。目标是给优先级4增加一个不同于调大半径的候选：用预测时可见的滞后CN5月组成，对跨国伪目标校准残差作局部加权，检验能否在区间覆盖不明显下降时缩窄强重组区间。

## 队列和估计对象

- 外层按AT、BE、CZ、ES、HU、NL、SE、SI、SK逐国留出；目标标签为2024固定EF发电侧小时代理。所有国家此前已用于开发，本轮是严格嵌套的开发回放，不是盲测。
- 输入只有预测时已构造的`t−2…t−7`火、水、核、风、光月份额特征（用于目标月条件权重时只取目标月CN5向量）及固定日历结构。`other_renewable`不进入加权距离。
- 目标中心固定为跨国强比例重组；中心模型与训练数据不得根据区间结果变化。
- 目标CN5份额与源伪目标残差来自Energy-Charts修订小时序列回算，滞后模拟不等同历史as-issued月报；标签为固定EF代理，不是实测CIF。

## 伪目标训练/校准与防泄漏

对每个外层目标国`T`：

1. 只用其他8国2022小时标签拟合强重组中心。
2. 对每个源伪目标国`C`，只用剩余6个源国训练该折模型，预测`C`的2023H2，保存绝对残差和预测时CN5份额；这样风险样本均为跨国外样本残差。
3. 在每个`C`的2023H1伪目标调参时，校准集排除`C`，且外层目标`T`始终不进入训练、调参或校准。
4. 用2023H1跨国伪目标区间分数选择唯一核带宽；仅在宏覆盖不低于无加权基线2个百分点以上、且逐伪目标国覆盖不低于75%的候选中选Winkler分数最低者；无候选时退回无加权。
5. 以所选带宽在全部来源伪目标2023H2残差上构造`T`的2024按月90%区间。所有外层预测先封存哈希，再读取对应2024目标标签评分。

## 预先固定的权重和对照

- 距离：五维CN5月份额逐坐标按外层源2022标准差标准化后的均方距离。
- 候选带宽`h ∈ {0.25, 0.5, 1, 2, ∞}`，权重`exp(−d²/(2h²))`；`∞`为等权校准。核权重归一化至均值1，并在加权分位数中给测试点单位权重。
- 主要对照为同一外层源集合、同一中心、同一2023H2校准残差的等权90%区间。另报告现有CN5源校准区间，核带宽若只比旧输出宽度窄但不比同折等权窄，不算增量。
- 指标：逐国家、逐月覆盖、宽度、Winkler interval score；宏指标先月份等权、再国家等权，并报告最差国。小时数和种子不能当独立国家样本。

## 晋级/停止门槛

候选只有在外层宏Winkler至少改善2%、宏覆盖不低于等权基线2个百分点以上、没有国家覆盖下降超过10个百分点，且宽度改善不是由校准样本有效量异常减少或少数区域驱动时，才进入冻结讨论。覆盖或区间分数不达标就停止带宽优化，不尝试事后目标专属半径。

## 范围限制

这检验的是区间校准能否利用可见粗组成识别伪目标误差条件，不更新强重组点预测，不证明中国小时覆盖，也不构成未见国家确认。源月数据是当前修订小时数据回算，统计口径与正式公开月报可能不一致。
