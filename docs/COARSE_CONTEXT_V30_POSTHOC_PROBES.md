## 复制规模压力

设已经验证的Size-Ridge未投影输出为u，最后一维特征logMW0的系数向量为β、训练标准差s。把同一case过去三个月全部generation量乘k，MG份额、两个log趋势和所有年龄均不变，只有最后一维增加logk。因此冻结模型的反事实输出为`u_k=u+β/s·log(k)`，再原simplex投影并乘EF。系数和模型不重拟合；k=1逐case复现原EF至1e−12。

若物理上复制一个相同发电系统，总量与排放同比增加，真实强度可以不变。本探针据此保持原标签，测试模型对边界／尺度假设的敏感性。它**不是实际复制观测，也不是统计预测器必须在全部干预下无偏的证明**；可见规模作为观测代理仍可能有价值，但不能仅据关联宣称因果或跨边界稳健迁移。

| k | 七区平均EF MAE | 平均预测变化 |
| --- | ---: | ---: |
| 0.5 | 36.046 | −26.524 |
| 1 | 27.326 | 0 |
| 2 | 85.432 | +70.852 |

k=2时ERCO、FPL、NYIS平均预测分别增加约99.967、103.297、108.090；MISO增加33.838且误差反而减小。整体误差变大不能替代真实跨域测试，地区差异也不能只挑正面。原V30大小效应与全部十四规则false的判断保持。

逐区21行见`results/coarse-context-v30-size-stress.csv`。真实EF由同case已封预测减已封signed error还原，不重读原月表隐藏标签。
