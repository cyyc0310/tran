# V384：滞后年度燃料结构与同预算条件风险强基线

日期：2026-10-31。源区开发试验；不打开新地区。目标是检验年度燃料结构能否给MG月度合并组预测带来覆盖保持的区间效率增量，并判断它是否超过普通异方差和条件分位数模型。

## 固定任务与数据合同

- 七个既有EIA BA代理源：BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS。query留一区，供体/风险模型训练仅用其余六区。
- 目标标签：2025-01-01至2025-07-01的既有24小时EIA燃料混合CIF代理。所有目标已属V25已查看开发区；本轮只能称重复开发确认，不能称盲测。
- 合并月度发电量预算：V25已有as-of MG 128粒子预测。年度新增预算：V24冻结完整年度八燃料proxy质量，按`available_at<=origin`选择正EF组(coal/gas/oil/other)内部组成。目标及源上下文均按报告发布时点选择；缺失即显式缺失标记，不能读未来完整年。
- 小时训练响应：仅使用六个源区2024有效小时。Jan–Jun为模型拟合；Jul–Dec为独立时间校准。目标留一区的任何小时响应不进入训练、尺度估计或校准。
- V25冻结档案、V24年度表和所用source文件在prepare时哈希锁定。predict阶段先拟合并写出完整七区档案并一次性seal；score只有看到完整seal后才能解析目标2025小时值。
- 年度比例是基于EIA完整年度小时proxy的附加信息预算，不声称它等价于真实中国年鉴中的派生供电量，也不将结果外推为中国覆盖率。

## 方法与强基线

1. `MG conditional recompose`：V25原已封存的五组月结构/源形状预测，作为无年度细分背景。
2. `AY fixed`：把合法最近年度POS内部比例替换MG粒子的POS内部比例；保留同一MG总POS抽样、供体小时形状与零排放组。
3. `AY source residual`：年度目标比例加有效POS供体自身月比例减供体时点合法年度比例，经simplex投影；同一供体身份绑定比例、年度时点和形状支持。该迁移是普通残差基线，不冠以原创。
4. `MG conditional M8`：V25严格留一区的八燃料月结构强参考，信息更多，报告为上限/参考，不与MG同预算混称。
5. `AY-CQR90`：在其他六区2024 Jan–Jun拟合5/95%梯度提升分位数，并用Jul–Dec跨区小时有符号CQR分数作加权90%修正。
6. `AY-HET90`：用ExtraTrees条件均值，按留一源区交叉拟合残差训练尺度模型，再用Jul–Dec标准化绝对残差的加权90%分位数校准。两风险基线使用同一目标特征：合法MG月份额粒子的均值/标准差、合法年度POS比例与缺失标记、日期谐波和小时谐波。源小时拟合权重按地区等权。

分位数/异方差方法输出区间，不伪造CRPS或128粒子。年度重组方法沿用原128条源条件路径与V25的五个扩散倍率，并报告CRPS、覆盖、区间评分和宽度。

## 评分与门槛

- 主目标：90%小时区间，宏覆盖`[90%,95%]`、最差地区覆盖`≥85%`。每个方法若有多个预注册倍率，在门槛内按区间评分最小选择；无合格配置则明示失败，不通过扩大门槛挽救。
- 同时报宏区间评分、覆盖、宽度、上下尾漏覆盖、逐区指标。路径臂另报CRPS、日水平MAE及中心化形状MAE。CQR/异方差只报告区间指标。
- 年度信息层：AY-fixed相对MG同源概率先验。方法层：AY-sourceResidual相对AY-fixed。对照层：AY-CQR90与AY-HET90为同一年度/MG特征预算下的标准条件风险强基线；M8为更丰富月信息参考。
- 配对差异以七地区为cluster作bootstrap描述区间，同时逐区报告；七簇样本的推断有限，不能冒称跨系统总体保证。

## 解释与停止规则

- 年度组分即使改善CIF水平，也必须在覆盖合格且区间评分下降、宽度不增加时才支持有效风险增量。
- 若AY-CQR90或AY-HET90与年度重组相当/更好，收益归因为普通条件风险模型或附加年度信息，不称TransCIF原创算法。
- 若AY fixed优于MG而sourceResidual无独占收益，结论是年度信息价值，不是新迁移机制。
- 若缺失年度、统计边界/代理残差或支持不足导致极端地区欠覆盖，本轮不按目标区调参；将其作为机制失败证据。
- 无论结果如何，本轮不授权未查看地区确认，也不改变原V25/V26文件。下一轮只在出现明确增量后另行冻结确认。

## 复现

MG原路径重算时以绝对误差 `1e-10` 检查数值一致性，容纳等价浮点求和顺序造成的机器精度差异；审计仍记录实际最大偏差。
