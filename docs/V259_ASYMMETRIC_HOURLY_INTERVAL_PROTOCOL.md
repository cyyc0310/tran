# V259 最近24日滚动的非对称小时区间

## 研究问题

V257/V258表明滚动风险可改善部分地区，但GVL、SEC仍欠覆盖。V259检验小时风险偏斜能否解释区间效率损失：固定V253年度热耗率中心和最近24日风险窗口，比较一个对称日max-absolute score区间，与分别校准日内上/下尾极值的非对称区间。

## 冻结计算

- 目标BA、年份、完整日和中心沿用V256–V258，仍为已打开的2025数据。
- 每个预测日只用此前最近24个完整日作为校准。上尾日分数为`max_h(y_h-center)`；下尾为`max_h(center-y_h)`；对称分数为`max_h|y_h-center|`。
- 非对称上、下分位数各取24个校准日的最大值，对应单尾有限样本覆盖秩24/25；由并集界联合名义下界约92%。对称基线取24个绝对分数中的第23顺位，对应秩23/25=92%。
- 两方法在完全相同的月内第25日以后预测日期上配对。非对称区间为`[center-q_low, center+q_upper]`。
- 报告24小时整日覆盖、小时覆盖、区间宽和90% interval score/Winkler。汇总先月/BA，再BA等权；按BA成簇bootstrap估计非对称减对称的差异。

## 限制

24日校准后平均只剩约6个测试日；每个方向分位数又由窗口最大值决定，估计方差较大。滚动序列不保证交换性，Bonferroni有限样本解释不自动适用于时序漂移。目标月中心继续使用整月毛发电量，不能称月初预测；目的仅为已打开样本上的区间几何/尾偏诊断，不作方法创新声明。
