# 严格五类粗月报下的跨国火电因子专家迁移

冻结合同：2026-11-01。目的：复核已在六类输入上出现的小幅组成条件专家收益，确认将输入严格压缩到中国可用的火、水、核、风、光后，基于不同国家训练的小时火电因子专家是否仍有增量。

## 外层与目标预算

- 外层按AT、BE、CZ、ES、HU、NL、SE、SI、SK逐国留出；2022源小时监督训练，2023H1伪目标调温，2023H2伪目标跨国残差校准，2024外层评分。
- 目标输入只含严格CN5滞后`t−2…t−7`份额、由这些统计构造的历史摘要和日历。`other_renewable`保留在固定因子小时代理的排放分母，但不进入目标统计、专家输入或源小时形状。
- 标签为固定排放因子发电侧代理，月输入为修订小时序列回算滞后值；不是历史as-issued月报或实测CIF。

## 候选方法

在每个外层折中，每个源国单独拟合一个既有`factor_history`火电有效因子头。源专家原型为其2022训练期五类平均份额，标准化尺度仅由外层源训练数据计算。对合法目标月份额，按五类标准化均方距离以softmax温度`τ∈{0.05,0.10,0.20,0.40,0.80,∞}`混合各源专家；`τ=∞`为均匀专家对照。温度按源国轮流伪目标的2023H1月等权MAE选择。

90%区间使用源2023H2的伪目标整国交叉预测残差、按国家等权的加权分位数。相同留国数据用于校准比例重组、macro重组及全源因子头。比较点MAE、去日均形状MAE、覆盖、宽度及区间分数；同时报告九国逐国结果、最差域和相对CN5比例重组/等权专家的配对变化。

所有2024外层预测文件须在读取对应标签前写盘并哈希封存。此实验检验严格目标schema上的外层代理迁移，不是盲区确认；不得因宏平均小幅变好而忽略最差国家覆盖。
