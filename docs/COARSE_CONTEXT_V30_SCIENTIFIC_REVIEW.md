## 绝对规模的科学边界

Size 是允许的过去公开量，不因与地区相关而自动成为泄漏。但绝对 MW 可以同时代理地区身份、区域边界、系统类型或训练库特有结构；本轮尚未区分这些解释。派生训练／query 特征显示，最新 log 平均 MW 超出对应六源训练边际范围的 query 为 BPAT **12/26**、MISO **15/26**，其余地区为零。此处仅检查单列 min/max，不能据此声称联合特征支持充分，也不能把外推范围单独认定为误差原因。

一个需要未来预注册的数学边界压力测试是：将同一发电系统的全部燃料量和各期总量同时乘正数 k，保持组成、月份及发布 metadata 不变。作为完全复制同一系统的理想化反事实，真实 r4 与按本轮系数计算的真实 EF 应不变；历史组成、年龄和 Trend 对数比也不变，Size 则增加 log(k)。当前模型没有强制此不变性。这个思想实验不表示真实观测已经发生，也不证明规模变量没有预测价值；它说明从现有行政规模关联外推到中国不同聚合边界时，需要额外证据。未在本轮运行该压力测试或重拟合模型。

可作为另立合同候选的是：固定现有方法与规则进行时间确认、边界／复制规模压力测试，再在合法 MG forecast 粒子上评估未来输入；不得回改 V30 门槛、抹掉失败或立即打开小时／未知地区。真实 release vintage 与中国分类映射仍未认证。

[V30 文献核查](COARSE_CONTEXT_V30_LITERATURE.md)已列出上下文、层级模型与连续域泛化近邻；本审查不重复原文核查或主张与其同预算性能比较。普通 Ridge／ET 加入规模后的收益只能先保留为强参考信息价值，不能直接命名为原创迁移机制。
