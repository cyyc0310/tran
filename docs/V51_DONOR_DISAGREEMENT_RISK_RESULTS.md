# donor 形状分歧未能稳定修复月度-only尾部风险

在上一候选“月度组成＋预测诱导热组重排宽度”的风险尺度上，再增加六个source-excluded donor预测的小时CIF轮廓分歧均值/p90。每个donor的小时形状、EF均只来自允许源数据；目标月滞后粗量将它们映射成可比较的CIF profile。点预测保持逐值不变。该扩展是在已查看H1结果后提出的事后探索，H2同特征不调参延伸。

| 窗口 | 歧义宽度头(前轮)覆盖/宽/IS | 加 donor 分歧后覆盖/宽/IS | 后者最差覆盖 |
| --- | ---: | ---: | ---: |
| H1 | 91.83% / 275.74 / 335.11 | 89.23% / 285.09 / 402.57 | 32.76% MISO |
| H2 | 93.38% / 322.69 / 355.26 | 96.79% / 392.90 / 408.56 | 88.61% FPL |

H1的宏覆盖、宽度、区间分数和最差地区均退步；H2提高覆盖但明显加宽并恶化区间分数。max-source标准化q90更宽（H1 430、H2 618），也不能修复H1 MISO。donor间预测分歧在两半年产生相反效果，不能作为稳定的风险路由器；不保留为主方法组件，也不据此继续叠模型特征。

结果来自已看七源、严格月度-only同点预测器，仍非独立确认。脚本和完整结果见`scripts/v51_shape_disagreement_risk.py`、`results/v51-shape-disagreement-risk-h1/`和`...-h2/`。这条支线被否决；前轮歧义宽度特征仍仅作为未过可信覆盖门槛的候选。
