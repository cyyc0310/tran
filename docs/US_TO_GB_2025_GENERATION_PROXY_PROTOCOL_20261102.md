# 美国训练到英国：2025同口径发电侧代理时间留出协议

冻结日期：2026-11-02，运行前。目标是补充US→GB真正小时迁移的第二个时间窗，并与2024已做的US→GB固定因子发电侧代理保持同一响应定义。此为已见国家上的时间外开发，不是新国家确认或as-issued实时回测。

## 估计对象与数据

- 目标：英国本地发电侧小时固定因子强度代理，固定燃料顺序`coal, gas, oil, other, nuclear, hydro, wind, solar`，因子为`1000, 400, 800, 400, 0, 0, 0, 0 g/kWh`。
- 源训练：EIA区域小时燃料发电文件中的美国七BA（BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS）。2022小时标签训练；2023源BA校准。
- 目标：NESO `df_fuel_ckan.csv`中的GB国家小时燃料序列，2025全年评分。两个半小时发电率取算术均值形成小时响应，GB `BIOMASS + OTHER`映射到`other`，oil为0；不含进口及储能。
- 当前NESO历史修订快照是回顾性数据，不代表2025预测当时可见版本。数据预检显示2025为17,520条无重复、无负值/缺失的半小时记录，恰为8,760个双半小时小时；目标标签依然只是上述固定因子代理。

## 目标输入合同

- 只用当地日历和预测小时所属月之前至少两个月的五类月发电份额：`thermal, hydro, nuclear, wind, solar`。每个目标小时所用的最近月份严格为`t−2`；不可回填至目标月、用当月总量、燃料内部构成或目标小时强度。对于2025目标，t−2输入由NESO当前修订快照中的2023-11至2025-10月量构造；逐目标月截断，绝不读取晚于该目标月t−2的统计值。
- 月份至少99%小时覆盖才可进入特征；缺失不以更新月份替换。该份额由NESO同一历史序列重建，表示中国五类预算模拟，不是英国正式月报历史vintage，也不与中国NBS统计范围等同。
- 源端只使用源国家小时数据训练和2023校准；不访问2025目标标签参与拟合、特征选择或区间校准。

## 模型与评估

- 复用冻结的`cross_country.py`参数、方法、区域等权样本权重及2023源域偏差/尺度校准，不扫超参数；对照包括700锚、源热电有效因子锚、日历Ridge、粗输入Ridge、粗输入提升树、粗类别小时轮廓重组。
- 先封存全部2025目标预测、校准值和SHA-256；随后评分。报告宏及逐月MAE、日内去均值形状MAE、Gaussian CRPS、90%覆盖/宽度/区间分数、逐月小时完整率。Gaussian区间仅是源残差基线，不作覆盖保证。
- 配对参考为同一美国源训练/校准、同一固定燃料EF定义下已完成的US→GB 2024开发实验；只作跨时间复核，2024已看过且不作为新确认样本。

## 解释边界

无论分数如何，本实验只支持US→GB发电侧代理的时间外描述，不可用英国单一目标推断中国准确度、国家条件覆盖或消费侧CIF。若不能优于简单锚/重组，保留为负的时间复制结果；若有所改善，也需其他独立目标系统和as-issued输入版本验证后才可称可迁移。

## 复现要求

运行必须记录协议、代码、源EIA输入及NESO原始CSV的哈希；每个被评分小时先随预测文件封存，之后才读取目标小时燃料生成标签。机器结果保存逐小时预测、来源校准、逐月指标、封存清单、覆盖审计和环境信息。
