# EIA-923真实BA月统计的信息价值诊断协议

更新：2026-11-01。该诊断回答：在统计区域和月份严格一致时，实际发布的EIA-923月度燃料发电量与同BA小时回算月量，作为目标端粗组成输入时，源端跨国小时模型输出有何差异？它不是as-issued前瞻回测，也不是未查看地区确认。

## 预先固定的样本与比较

- 样本只取EIA-923 2026年8月发布包中，BA月燃料行完整且EIA-930同BA同月小时完整的配对单元。对原始ZIP和当前小时CSV独立重解析后固定为20个BA×月：BPAT 6、CISO 1、ERCO 2、FPL 7、NYIS 4，覆盖2026年1—8月；不得放宽完整性条件以增加样本。
- 标签为EIA-930当前版本的同BA小时发电固定因子代理。所有预测臂使用完全相同的小时、源训练、源校准、模型和EF标签定义。
- `eia923_actual_release_mix`臂使用EIA-923按Plant ID×Month连接Page 6 BA后的月度Netgen燃料量，映射到火、水、核、风、光五组并归一化。仅保留审计认定完整、正总量且没有负燃料值的单元。
- `eia930_same_month_oracle_mix`臂使用相同BA目标月的完整EIA-930小时燃料量汇总成五类份额。这是目标月已知后的oracle，不能作为预测时输入，只用来区分月量统计误差与模型/源域迁移误差。
- 源模型为GB/NESO 2022小时训练、2023小时残差校准；候选为700锚、源火电有效EF、日历Ridge、五类Ridge、五类HGB、五类小时轮廓重组。此定义沿用既有实现，不在20个目标单元上调参。

## 报告指标与解释

按每个BA×月报告MAE、去日均形状MAE、源校准高斯CRPS、90%覆盖、宽度和区间分数。总体同时报告等权BA月宏平均和小时池化结果，避免长月份主导宏观结论。配对差异以相同BA×月为单位，不把小时作为独立样本计算显著性。

2026年8月EIA-923发行版于10月23日发布，晚于所评月份；因此所谓“actual release”只指数据来自官方发行文件，不代表这些数在目标月预测起点已经可见。EIA-923是报告机组集合，不能视为BA完整发电量。EIA-930标签是当前修订的固定EF代理，不是测得CIF。20个单元结果只能决定该数据合同是否值得扩展，不支持广义跨国结论或目标区间覆盖保证。

**既有审计的复现漂移：**仓库已有的实时EIA-923审计表记录18个完整配对格；本协议脚本使用相同SHA-256的小时文件、解析源代码和EIA-923原始ZIP重算后得到20格，56格中22格的旧/新审计状态或统计量不一致。工作区记录的原始文件哈希相同，因此这不是已证实的数据版本变更；旧审计输出在当前运行环境下无法复现。新实验不沿用旧审计表作为真值，而在每次运行时直接解析ZIP和小时原始文件，记录包版本及Python/pandas/NumPy/SciPy/scikit-learn版本。旧审计差异留作数据工程问题，不能选择性地挑对结果有利的样本。

## 复现

```bash
python scripts/run_eia923_actual_ba_information_value.py
```

机器输出写入`results/eia923-actual-ba-information-value-r1/`，包含逐BA月指标、宏/池化摘要、逐小时预测与标签、输入和代码哈希。脚本拒绝覆盖已有目录，输入审计必须仍然恰有20个配对单元；对旧表的复现差异同时比较各燃料月发电量。
