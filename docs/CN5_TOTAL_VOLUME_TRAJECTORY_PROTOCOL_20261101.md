# 严格CN5月总发电量轨迹信息价值协议

冻结日期：2026-11-01。研究问题：在目标国家只有中国可得的火、水、核、风、光滞后月发电统计时，六个月内系统总发电的相对升降，是否能提供现有份额特征和总量CV之外的跨国可迁移小时响应信息？

## 假设与固定特征

现有`multicountry_cn5.HISTORY`已经包含六个月火、水、核、风、光组成以及总发电月量的六个月变异系数，但没有总发电量近期趋势。本实验仅增加两个输入：

1. `log_total_slope6`：六个月月平均总发电量（五类月总量除以当月小时数）的对数对月份序号线性斜率；
2. `log_total_recent_shift3`：最近三个月对数平均总发电量均值减去较早三个月均值。

对数变化抵消国家间固定量纲/规模，目标月特征严格由`t−7…t−2`构造。两个特征仅检验总量趋势，不加入绝对系统规模，不利用目标小时负荷或未来月总量。

## 训练、校准、评分

- 严格CN5九国LOCO；每折其余八国2022源小时训练，2023H2来源校准，目标国2024评分。
- 两个增量特征完整时才纳入该时刻；所有基线和增量模型在每折共用完全相同的源训练/校准小时及目标评分小时。
- HGB树参数、国家均衡权重、时段、目标、热电小时形状和区间半径计算固定。候选只给热电因子HGB、四头燃料份额HGB加入两个总量变化特征；同时报告现有强重组、因子历史HGB、份额HGB。
- 生成并封存逐国预测及来源半径、校验输入/代码哈希后，才读取目标2024细燃料标签评分MAE、去日均形状误差、池化经验90%覆盖、宽度、Winkler分数及预测后组成机制误差。

## 晋级与边界

必须相对现有强基线取得跨国一致的点误差或proper score增量，覆盖不能靠明显加宽获得，且CZ/NL/HU/SI等困难域不退化，才考虑独立完整燃料标签确认。本实验是九国已查看开发回放，不是盲测；标签是固定EF发电侧代理，不是中国实测小时CIF或消费侧标签。无论结果如何，单独的总量趋势摘要都不构成原创算法证明。
