冻结日期：2026-10-28。V85不是新地区确认，也不改变方法或信息预算；它仅补齐V84正证书率未呈现的选择性决策。目标是在24小时日尺度上判断尾事件`K>=8`，阈值τ=100/300。

严格沿用V84的25区名单、2024H2/2025H1/2025H2窗口、小时源与固定EF代理、月度活跃燃料支持M（缺月表回退M=1000）、质量门槛、时间块24/6/3/1小时、H/G/Q构造及粗界/矩外界/full-G集合算法。输出目录独立为`results/v85-census-selective-frontier-r1`。V84算法代码与冻结输入逻辑保持不变；V85另行计算并逐日保留上下界。

每一种信息集的可行尾计数集合记为S=[Kmin,Kmax]（内部保留集合孔洞，不影响下列二元阈值决策）：
- 正向证书：Kmin>=8，断言事件必发生；
- 负向证书：Kmax<8，断言事件不发生；
- 弃权：两种证书均不满足。

每个非弃权断言须与观测固定EF小时代理的实际K一致，否则中止。弃权不是错误，也不计“正确决策率”；主效率量为决策率=正向率+负向率，并分开报告正向、负向、弃权率。按地区-半年先求率、对半年等权、再对地区等权，避免把日当成独立电力系统。另按V84事先规则剔除完整日覆盖低于80%的地区-半年作敏感性。
