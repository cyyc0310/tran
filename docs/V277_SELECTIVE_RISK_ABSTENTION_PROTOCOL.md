# V277：用粗信息风险尺度决定何时预测、何时弃答

冻结日期：2026-10-30。V275消费侧月燃料构成风险模型虽在6/7 BA达到90%日覆盖，但宏覆盖仅85.8%，ERCO只有35%。V277不另调风险阈值，而测试一个预先确定的决策规则：**若自适应区间半宽小于简单来源q90半宽，发布自适应区间；否则整个月弃答。** 规则只比较两个预测前可算出的半宽，不查看测试目标小时标签。

## 数据隔离

继续使用七BA的EIA消费侧估算CIF，目标月均值oracle中心，2019–2023训练、2024来源校准、2025评分。对每个目标区，预测模型与校准都排除该区所有年份目标标签。另对每个2024伪目标BA逐区留一复核相同门控。

## 门控及指标

在每个BA-month上，若`conditional_risk_radius < pooled_source_radius`，门控接受；相等或更宽则弃答。报告2024来源域接受率/接受集日覆盖，以及冻结后2025接受的BA-month占比、完整日占比、accepted-only日同时覆盖、区间宽度/Winkler和每区接受覆盖。拒答的样本不得计为覆盖，也不得从总接受比例的分母中删除。

该门控即使在已打开的2025开发队列表现良好，也只能晋级为下一轮验证候选；2025标签曾用于V275分析，确认性窗口必须冻结规则后再用未参与调参的时段或新可用BA评估。由于当前项目对大多数高质量BA已有开发暴露，新的时间段确认不等于新地区泛化。
