# V69：固定非线性模型下的全构成增量消融协议

日期：2026-10-27。V68在17个已开发EIA代理区的2026H1整区留出中发现全构成ExtraTrees优于季节均值，但未区分收益来自模型族还是组成信息。V69冻结相同留区/月份/目标及ExtraTrees超参数，只消融合法月度特征。开发数据仍是EIA生成侧固定EF代理，不是新地区确认。

## 切分与可用性

- 复用V68冻结的V54原生快照、2026-01至06、17个地区；逐目标地区移除该区所有小时标签，训练标签只取其他地区、目标月起点前已结束且按月末+30天假设可用的数据。
- 月度输入必须满足V54完整月发布规则（period_end+30d不晚于预测起点）；小时标签初发时点没有vintage档案，30天仍是假设。
- 同一目标区/月/阈值在所有模型中完全配对；仅包含V68质量门槛后实际合格的100个区域月（17×6中有2个地区月因有效小时不足被排除），只评 τ=300、600 g/kWh（V68对应正尾区域月分别79/31）。

## 固定模型与三臂

ExtraTreesRegressor：100棵树、min_samples_leaf=12、max_features=0.8、seed=68027、n_jobs=1；同一地区均衡样本权重、相同训练行和预测裁剪[0,1]。

1. `latest_ef_calendar`: 最近月固定EF + 月份sin/cos；特征列16,18,19。
2. `latest_mix_calendar`: 最近月8燃料份额 + 月份sin/cos；列0–7,18,19。燃料EF是份额的线性组合，故这是对热组EF非线性的富信息控制。
3. `latest_plus_3m_mix`: 最近月8份额 + 最近三月能量加权8份额 + 月份sin/cos；列0–15,18,19。

不包含月总发电量特征，以免靠区域规模或标签代理增加维度。核心配对增量为臂2−臂1与臂3−臂2的MAE差；地区为bootstrap簇（5000次，seed=68027），区域月等权。所有4阈值仍输出，但主判据只看 τ=300 和600：组成增量必须在对应配对差95%区间上界低于0，且至少一个主阈值MAE相对前臂改善≥10%，才认为存在开发增量。若不满足，停止“小时尾频率可由月度全组成非线性迁移”的方法支路，不查看封存地区。

## 解释边界

即使通过，V69也仅是开发筛选；17区早已被查看，不能称独立泛化。新增价值可能是非线性固定EF尾频率预测，而非完整小时CIF、区间覆盖或中国实证。小时EF标签的首次发布日期未核实，预测可用性仍依赖保守30天假设。通过后必须先冻结所有选择，再打开真正未评分地区，并单独报告每区结果。
