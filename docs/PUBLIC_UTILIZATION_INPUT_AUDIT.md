# 尚未充分利用的公开输入：月电量与名义煤气装机的联合尺度

2026-11-01，Sol。只做输入与实现核对，不拟合新模型，不使用当前目标小时真值，不声称预测增益。完整天气比较和原模型参数保持冻结。

`multicountry.public_months`保留各粗技术的月电量；`public_features`主要输出份额、变化、波动与观察数。当前R5小时HGB和日幅度特征没有联合使用目标过去月电量的绝对水平与煤/气装机的绝对MW。日幅度以过去月平均功率归一化标签，但没有将上述联合尺度作为条件特征。

早期`capacity_transfer.nominal_rates`已经用过源端煤/气发电除以名义装机的全局率，`capacity_source_rate`也是既有基线，不能把常数利用率改名成新方法。尚待检验的是：合法月量与库存联合形成的条件描述，是否能帮助源国学到更可迁移的内部运行关系；更强HGB/条件分位数必须获得相同字段后再比较。

本地`results/public-utilization-input-audit-r1/legal_monthly_descriptors.csv`核对150个已可用地区月（49源训练地区月、101校准/开发地区月）。按本地时区的实际月小时数，把公开火电月电量转为月平均功率，再除以报告煤气MW之和。该比值不是已认证容量因子：

| 数据角色 | DE范围 | GB范围 | US范围 |
|---|---:|---:|---:|
| 2022源训练的合法历史月 | 0.339–0.505 | 0.262–0.407 | 0.061–0.616 |
| 2023校准/开发的合法历史月 | 0.265–0.489 | 0.241–0.369 | 0.059–0.606 |

这些数值有限且没有超过1，只能排除一部分明显单位异常，不能证明物理上界成立。火电中还有油/other/生物质，库存仅煤气；US是2020登记BA而非同时期运行BA，UK/GB地域不同，WRI年份未明且可能存在退役或覆盖差异。不能用`煤MW×小时`硬约束真实煤电量，更不能把装机占比当发电占比。

可列入后续同预算消融的是这些带口径/陈旧标记的软描述，不是额外本地小时信息，也不是已证明的物理限制。源全球率、直接有效因子、条件利用率与原强重组都需要比较；若普通特征增强已解释收益，就不归为专门机制创新。
