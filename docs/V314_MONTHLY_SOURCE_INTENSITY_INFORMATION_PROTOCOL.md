# V314：时变省级运营排放强度下的信息价值敏感性

## 研究问题

V312 使用固定年度生命周期因子，比较全国月受电、省级月受电和路线月流量的信息价值。公开月度数据还包含省份×月份×发电类别的估计发电量及排放。本轮将来源因子改为时变的省级月度运营排放强度，检验 V312 的信息设计结果是否依赖“源因子全年固定”。

## 目标量

每个受端省份 `j`、月份 `m`，定义来源加权进口碳暴露代理：

`R_jm = [Σ_i x_ijm · e_im] / G_jm`

其中 `x_ijm` 是月度路线流量，`G_jm` 是 V311 的本地月发电量，`e_im` 是 Ember 2023 年省份月度运营排放量除以发电量。目标量是“估计运营排放强度加权的进口量 / 本地发电量”，**不是**标准省级 CIF，也不是小时尾部风险。该敏感性更贴近用户描述的逐类月度发电统计，但使用公开估算值而非用户原表，也不代表生命周期因子。

## 可行集及稳健条件区间宽度

沿用 V311：`x_ijm ≥ 0`、`Σ_m x_ijm=T_ij`、`Σ_j x_ijm≤G_im`。为计算某个已公布信息集合 `H x` 后的最坏剩余区间宽度，建立两份独立可行流量 `x` 和 `x'`，加入相同信息约束 `H x=H x'`，然后最大化 `R_jm(x)−R_jm(x')`。这个两副本 LP 等于对所有可能观测值取最坏条件区间直径，不需指定或伪造实际月度流量真值。

## 相同预算设计

年度路线总量已知，所以某组月值中最后一个月可由年度总量推出，不计为独立新字段。

| 信息方案 | 实际测量 | 新增独立数字 |
|---|---|---:|
| 年度 OD 基线 | 无 | 0 |
| 全国月受电量 | 11个月，12月由全年总量推出 | 11 |
| 省级月受电量 | 31省 × 11个月 | 341 |
| 31条大流量路线的月流量 | 每条11个月，路线按年度 TWh 排序 | 341 |
| 31条大估计碳量路线的月流量 | 每条11个月，路线按年度 TWh × 源因子排序 | 341 |

省级月受电量与两种路线方案是预算匹配的主比较（每种341字段）；全国月受电量只有11个独立数字，作为低预算对照。

路线选择规则事前由年度 OD 和 V310 年 CF 确定，不看本 LP 的输出。它们是清晰的强启发式，但不是对所有可能路线子集的组合最优化。

## 输入来源与限制

- 路线总量：V310 Zenodo 2023 年矩阵。
- 月发电上界：V294 Ember 估算月度总量，只用于送端容量；不用其排放或强度列。
- 源因子：V294 Ember 2023 年 province-month 运营排放强度，来源于其技术分类月排放估计。
- Ember 同时给出发电量和估计排放，因此源强度与发电字段并非独立测量。本实验用于敏感性检验，不是外部小时真值预测评价。
- 路线总量仍是 V310 年度矩阵；月容量仍来自 Ember；没有月 OD/受端负荷、线路约束和潮流核验。因此只解释信息预算下的月度直接进口代理风险。
- 未知月度受端需求、线路月容量、输电损耗、穿越流和调度过程；因而目标是粗粒度**直接进口**风险代理，不是物理全网碳流，更不是小时 CIF。

已有流量追踪研究将比例共享等作为成熟机制，且要求时空电力流、发电和负荷等运行信息。因此论文创新机会不能是“再做一个流追踪算法”，而应检验公开粗统计下的可识别性、最小观测设计和风险区间。[Chen et al., 2024](https://doi.org/10.1049/enc2.12134)。
