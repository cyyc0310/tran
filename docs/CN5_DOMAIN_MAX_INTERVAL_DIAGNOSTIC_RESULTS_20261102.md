# CN5整国最大残差区间：FR已看目标上的保守性代价

结果日期：2026-11-02。按[冻结诊断协议](CN5_DOMAIN_MAX_INTERVAL_DIAGNOSTIC_PROTOCOL_20261102.md)完成。目标法国2024已于此前实验打开，本结果是事后方法诊断，不是盲测或新增确认。

## 结果

九个源伪目标分别使用其他八国2022小时标签训练，在各自2023H2计算残差。比较国家等权小时池化q90半径与九国最大单小时绝对残差半径。两者使用同一份此前封存的FR点预测；主比较包括燃料响应头、标量因子头和比例重组。

| 中心 | 校准规则 | 半径 | 全宽 | FR小时覆盖 | FR全段无漏覆盖 | Winkler90 |
|---|---|---:|---:|---:|---|---:|
| 比例重组 | 源小时池化q90 | 195.94 | 391.88 | 100% | 是 | 391.88 |
| 比例重组 | 源国最大残差 | 725.10 | 1,450.20 | 100% | 是 | 1,450.20 |
| 标量因子头 | 源小时池化q90 | 176.68 | 353.36 | 100% | 是 | 353.36 |
| 标量因子头 | 源国最大残差 | 721.74 | 1,443.48 | 100% | 是 | 1,443.48 |
| 燃料组成响应头 | 源小时池化q90 | 162.72 | 325.44 | 100% | 是 | 325.44 |
| 燃料组成响应头 | 源国最大残差 | 713.10 | 1,426.19 | 100% | 是 | 1,426.19 |

法国在原小时池化区间下已是100%经验覆盖；整国最大残差没有增加覆盖，只把三个方法的区间宽度都扩大到原来的3.7–4.4倍。燃料组成响应头的半径从162.72增至713.10 g/kWh，最大值由斯洛文尼亚伪目标贡献（713.10）；该国残差尾部支配了所有目标域的半径。

## 判断

1. **停止裸最大残差作为迁移区间路线。** 它没有修复本诊断目标上的欠覆盖，因为目标本来就过覆盖，却付出极大的区间代价；也未证明新域可交换性或有限样本保证。
2. **不能把“全段覆盖”当成方法晋级。** 这是一个已看过的低强度目标，所有原区间已覆盖；极大扩宽后全段仍覆盖不能说明在高风险新域中有实用效率。
3. **下一步不再用全局最坏源域残差给所有目标统一扩区间。** 继续报告经验池化覆盖、最差国家覆盖及宽度；若要对整国给出有限样本保证，独立校准国家数量和交换性不足的问题必须正面处理，不能用小时数替代域数。

本轮没有产生新算法或中国精度结论。它给优先级4增加了一个强压力基线，并关闭“取源国最大残差即可兼顾可信与窄区间”的简单路线。
