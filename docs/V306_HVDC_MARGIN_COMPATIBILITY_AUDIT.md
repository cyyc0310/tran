# V306：公开特高压年度电量能否补成 V305 的区域OD观测？

## 问题与判定

V305提出的最小补充信息是西北→华东和西南→华东两条区域流量。本轮核查公开的2023年点对点特高压直流年度输电量，判断能否直接聚合成这两项。结论：**目前不能完整还原。线路数据可作为部分物理输送观测，但未证明它与V304论文边际采用相同计量边界。**

国家能源局电力可靠性报告列出18条点对点直流系统总输送量，合计5679.49亿kWh；其中复奉262.77、锦苏304.20、宾金238.17、建苏234.05亿kWh。复奉由四川向上海，锦苏由四川向江苏，建苏由四川送至江苏；这三条可以明确归为西南→华东，合计801.02亿kWh。宾金落点浙江，但送端电源跨四川、云南，不能把整条线路量全部记入西南。按MEE七区域因子对应的分区，四川/重庆属西南，云南属南方。雅湖线送端在四川、受端在江西，也不能未经论文区域映射就并入华东。

V304录入论文给出的西南区域全年**全部方向**送出边际为10,197,007万kWh，即1019.7007亿kWh。三条明确四川起点的直流线占该总量约78.6%，没有超过总边际，故这组数据没有证明两个来源边际口径不兼容。剩余差额可能包含其他直流/交流交换及统计边界差异。它仍只是西南→华东物理输送量的部分观测，不能替代V305需要的完整区域OD总量。

回看论文PDF后，确认表1/2的区域间、省间电力交换量来自《中国电力统计年鉴》。这与国家能源局可靠性报告的点对点线路统计是不同发布表和数据流程。表1/2只列区域聚合的允许目的地区域及汇总量，没有披露13条区域OD各自电量；表3另给省级送出/受入总量，也没有提供省对省矩阵。因而只能把UHVDC线量作为异源的部分线路观测候选，不能假装它已是该年鉴中的一条路线分项。[论文PDF及表1–3](https://base4zgdl.xml-journal.net/cn/article/pdf/preview/10.11930.j.issn.1004-9649.202504020.pdf)

## 两类公开来源存在差异

国家能源局可靠性报告和2023年可再生能源监测评价报告对同一批线路的年度数值并不完全相同。例如复奉分别为262.77与268亿kWh，锦苏304.20与308，宾金238.17与251，灵绍486.67与494，吉泉620.06与625。可靠性报告统计18个点对点系统；监测评价表列20条直流线路并说明电网企业报送范围。因此，即使端点明确，年度电量的统计对象与计量规则也需要先统一。[可再生能源监测评价报告](https://www.nmgxny.com/static/upload/file/20241111/1731295097597648.pdf)

西北→华东是更有希望的候选：吉泉（新疆→安徽）和灵绍（宁夏→浙江）两条可确认线路合计1106.73亿kWh，落在V305计算的西北→华东可行区间912.27–2008.04亿kWh内。但“落入可行区间”只表示不矛盾，不代表与论文边际同口径，也不能证明遗漏交流联络线后仍可视为完整区域流量。西南→华东三条明确四川起点线路总量801.02亿kWh，可作为部分通道信息；仍要核实计量点和论文区域图。

## 对 V305 的影响

V305代数结论仍成立于其声明的条件数据集：给定该论文的边际和路径图，两条区域OD数值足以识别运输多面体中的来源因子函数。但本轮找到的公开特高压年输送量**还不能直接充当**这两条区域OD观测。宾金整条线路量缺少四川/云南拆分，论文也未公开省际矩阵将线路映射到区域边；不同统计源的线路年量亦有差异。因而“最小信息预算”仍是数学识别结果，尚未通过公开数据的可操作性验证；也尚未形成小时CIF预测改进。

下一步优先级应调整为：

1. 取得并核对该论文的区域划分表、边际数据原始引用及计量边界；
2. 对接同一统计口径的年度省间/区域交易或净受入流量，或从电网公开数据中明确筛出同口径值；
3. 若仍只有线路物理送电量，则重新建立“线路量—区域净交换量”的含损耗和多路径映射，不把前者直接塞入V305运输多面体；
4. 只有完成口径对齐后，才测试其能否收窄官方EF迁移误差或小时风险区间。

## 复现

运行 `python scripts/v306_hvdc_accounting_compatibility.py` 可复算已明确四川起点线路与论文西南总送出边际的比较。手工转录线路值来自[国家能源局《2023年全国电力可靠性报告》](https://prpq.nea.gov.cn/uploads/file1/20240911/66e102e09bfea.pdf)。端点来源包括[国家能源局对复奉线的说明](https://www.nea.gov.cn/2011-11/28/c_131274566.htm)、[国家能源局对锦苏工程的说明](https://www.nea.gov.cn/2008-12/03/c_131056365.htm)、[白鹤滩—江苏工程竣工信息](https://wap.sasac.gov.cn/n2588025/n2588119/c25382747/content.html)、[雅中—江西工程端点](https://obor.nea.gov.cn/detail/10068.html)；宾金端点和更多线路总量的并列比对见[线路监测表](https://file.iyanbao.com/pdf/407f9-3b6a7d38-26b6-43ad-81b2-b44b888936ad.pdf)，后者为行业研究报告，仅作交叉核验。区域划分须服从论文实际定义；国家统计局地理分区、MEE区域因子区和电网经营区不能混为一套。

线路值按公开报告精度录入。本脚本是兼容性诊断，不估计置信区间，不宣称核算了全口径电力交换。
