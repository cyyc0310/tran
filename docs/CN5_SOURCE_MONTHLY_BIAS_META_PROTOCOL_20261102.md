# CN5源伪目标月均偏差迁移实验

冻结：2026-11-02，运行前。本实验承接`CN5_FUEL_FACTOR_HEAD_BLEND`结果及`CN5_LEVEL_SHAPE_ORACLE`事后诊断，检验能否仅凭合法粗月组成和日历，从源国伪目标学习小时预测的月均水平误差并迁移到整国留出。

## 假设与范围

- 可证伪假设：来源燃料组成响应头的国家—月份平均残差，能由预测时可见的滞后火、水、核、风、光月份额与日历预测；加该修正可同时降低2024外层国家的MAE和区间分数，而不以欠覆盖换窄区间。
- 仅做发电侧固定因子代理。该结果不代表消费侧CIF；消费侧必须单独建模和评分。
- 数据仍是Energy-Charts九国当前修订小时数据，滞后月份额由小时数据回算，不是历史as-issued。九国2024标签均已进入开发史，本结果为嵌套留国开发实验，不是未查看地域确认。

## 冻结设计

1. 外层每次留一国A。基础预测是此前封存的严格CN5燃料组成头、火电因子头及比例重组预测；不读取A的标签训练偏差模型。
2. 对A以外每个伪目标国B，偏差训练/校准预测来自同时排除A、B的七国模型。预测使用B的2023月特征；仅用2023H1每个伪目标国每月真实减预测均值训练校正器。
3. 校正器固定为标准化后的`Ridge(alpha=10, fit_intercept=True)`，输入为五类当前合法滞后月份额及月份的正弦/余弦季节项。不得把逐小时小时/星期周期当作月度特征。每个伪目标国六个H1月份的样本权重各为`1/6`，因而每国总权重为1。保留该固定权重尺度，避免权重归一化改变Ridge正则强度。不给目标标签调参。另保留来源H1全局常数偏差作为弱校正对照。
4. 2023H2为独立区间校准段。校正器只由H1拟合；对八个B的H2逐小时残差按伪目标国等权计算90%绝对误差分位半径。基线方法也用同一伪目标H2目标队列及各自半径。
5. 目标A的2024小时点预测加上由H1源伪目标训练、按A 2024可见粗组成和日历计算的月偏差。目标月真实均值不参与拟合、选择、校准或预测。
6. 预测和校准参数先封存并校验哈希，之后计算MAE、去日均形状MAE、90%经验覆盖、宽度、Winkler；报告九国宏平均、各国/月份以及最差国。

## 晋级门槛

校正候选须相对`fuelshare_history`至少改善5%宏MAE和5%宏Winkler，90%宏覆盖不低于85%，任一外层国MAE不得恶化超过5%，且最差国覆盖不得下降超过2个百分点。若未同时满足，停止源伪目标月均偏差Ridge路线，不扫描正则网格、不以2024结果改模型。

## 解释边界

这是标准正则化残差校正，不凭模型形式本身主张算法原创性。即便通过门槛，也只可进入真正未查看国家/时间确认；若失败，则说明Oracle月均水平可修正并不意味着目标可见的粗月组成足以预测该修正。小时消费侧仍不由本实验背书。
