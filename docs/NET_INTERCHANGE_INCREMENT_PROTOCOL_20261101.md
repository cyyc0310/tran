# 滞后净受电信息对消费侧 CIF 的增量：预注册式开发协议

更新：2026-11-01。此协议只评估消费侧标签，发电侧保持独立。它是开发实验，不是盲测。

## 问题

在中国可见的滞后 CN5 月度发电构成之外，加入滞后两个月的月度净受电占需求比，能否改善外国源模型对目标区小时消费侧碳强度的点预测和区间？

## 样本与信息预算

- 来源和目标：US→GB、GB→US；美国七个 EIA 平衡区与英国 NESO 全国系统。
- 训练年份 2022，源区校准年份 2023，目标评分年份 2024。
- M：日历特征与严格 `t−2` CN5 月度发电占比。
- M+X：M 加一项严格 `t−2` 月度净受电电量 / 月度需求电量。US 使用 EIA-930 `-Total interchange / Demand`；GB 汇总 NESO 各互联线带符号流量并除以 `TSD`。
- 两支模型使用完全相同的源训练行、源校准行和目标区评分小时。流量字段或 CN5 缺失的月对两支共同排除。月完整率至少 99%。
- 各方向都对比粗组成 Ridge 与 HistGradientBoosting。偏差和高斯残差尺度仅由源区 2023 数据估计；报告 MAE、日内形状 MAE、CRPS、90%覆盖、区间宽度和 interval score。

## 预先解释边界

美国 EIA `Demand` 和英国 NESO `TSD` 的统计范围不完全相同；两者都用于构造系统净受电相对系统需求的月度尺度量，但跨国系数不能解释为完全同口径物理量。NESO 的 `IMPORTS` 只记录进口分量，故本实验不用该列，改用官方历史需求表中所有带符号互联线流量。数据为当前可下载的修订历史值，滞后只模拟信息可见性，不构成历史 as-issued 回测。

目标标签在此前开发工作中已查看，2024 结果不得称为未查看地区/年份确认。不得据本实验宣称中国消费侧 CIF 已可部署；省级跨省电力流和来源排放强度仍是额外信息需求。

## 晋级门槛

只有当 M+X 在两个迁移方向的强基线下稳定降低点误差或 CRPS，同时不恶化最差区覆盖、且区间覆盖接近名义值时，才值得冻结为新增机制。只缩窄区间而覆盖下降不算成功。
