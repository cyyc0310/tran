# 严格CN5输入下的燃料组成响应头：九国留出协议

冻结日期：2026-11-01。问题：源国小时燃料标签能否通过**预测火电内部燃料组成**，在目标只见火、水、核、风、光滞后月报时改善小时发电侧CIF代理？此前因子历史头直接预测一个标量热电有效因子；本方法改为分别预测煤、气、油、其他火电小时份额，约束到非负单纯形后再由固定燃料EF计算热电有效因子。

## 数据合同

- 使用Energy-Charts/SMARD严格CN5九国开发数据；外层逐国留出。2022源小时数据训练；2023H1同源池化校准；2024目标预测先封存再评分。
- 目标输入只有火电、水电、核电、风电、太阳能月度份额`t−2…t−7`和日历。`other_renewable`不进入输入、历史特征或小时形状参考；只按既有固定因子标签定义保留在总发电分母。
- 小时响应是修订小时序列构造的固定因子发电强度代理，不是实测或官方CIF。月报由小时值回算，属滞后模拟，不是历史as-issued回放。九国和2024已被查看，不能称为盲区确认。

## 预测头

训练时只用源国小时标签。对每个源小时，四个热电组份额为`fuel_k / sum(thermal fuels)`，只在热电出力为正的小时拟合。对四个份额各拟合一棵与`factor_history`同特征、同结构、同正则、同随机种子的HGB回归头。推理时将负预测截为0并将四份额归一；若四头全为0，回退到源训练期等权平均燃料份额。热电有效因子为四个份额与固定EF的内积，再乘与强比例重组完全相同的源国等权热电小时形状。

不使用目标小时标签、目标燃料、目标同期月份额、年度煤气结构或消费侧流量。固定EF下该组份头的有效因子被限制在热电燃料EF的凸包内；它是受结构约束的预测器，不声称EF本身经中国校准。

## 比较与晋级门槛

同一外层小时队列、相同H1国家等权源半径，配对比较`ratio_recomposition`、`macro_recomposition`、`factor_history`、`direct_history`、`anchor700`与`fuelshare_history`。指标为逐国/逐月MAE、去日均形状MAE、90%池化经验覆盖、宽度与区间分数。

只有在宏点误差或区间分数相对强重组有稳定增量、形状误差不退化、覆盖不靠额外加宽维持，且CZ/NL/SI/HU等难域不出现更严重负迁移时才晋级。若只改善分解可解释性、未改善外层预测，不称算法突破。无晋级时不调燃料EF、树参数或单纯形回退，再转向真正新增的合法运行观测或收敛到基准贡献。
