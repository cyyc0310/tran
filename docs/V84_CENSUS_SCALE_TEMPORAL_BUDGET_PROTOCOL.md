# V84：质量普查全队列上的时间信息预算扩展

冻结日期：2026-10-28。V83在四个已开含气电区发现本地燃料支持M下的H/G/Q证书随时间粒度改善，但地区数不足。V84固定使用V52质量普查中2022–2026H1每个年度均≥80%完整代理小时的全部25区：AVA/BANC/BPAT/CHPD/DOPD/EPE/FMPP/FPL/GCPD/GRID/GVL/IID/JEA/LDWP/MISO/NWMT/NYIS/PSEI/SC/SCEG/SCL/SEC/TEC/TIDC/TPWR。名单直接来自冻结quality_census.json；其中不全是含化石燃料区，零活跃EF支持保留为退化对照。

窗口固定2024H2/2025H1/2025H2，τ=100/300，事件目标K≥8/24h。每个完整UTC日使用该地区-月V54燃料份额给出活跃支持M；缺月表行回退1000。时间块b固定为24/6/3/1小时。各块比较粗(H/G/M)与矩(H/G/Q/M)的K计数外集；对b≤6另用固定小时G计算sharp full-G集。b=1直接由逐小时H/G判事件，Q是G平方的派生值，不另计采集标量。检查实际K包含、粗⊇矩⊇full-G、支持内无错误证书。

主报告四分位/地区-窗口分层和地区宏平均；样本量为完整地区日，不作地区独立同分布假设。额外敏感性只按事前质量规则剔除完整日覆盖<80%的地区-窗口，名单与窗口固定。所有地区此前已在项目其他分析打开，因此这是普查尺度机制/预算扩展，不是新的留区确认。EIA固定EF发电代理、同期识别而非概率预测；额外日内H/G/Q字段不在中国月/年公开表中。
