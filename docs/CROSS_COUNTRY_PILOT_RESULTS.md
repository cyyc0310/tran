# 美英跨国小时冷启动：第一轮开发结果

2026-10-31。按照[协议](CROSS_COUNTRY_PILOT_PROTOCOL.md)，实际完成US→GB和GB→US两个方向的小时预测。研究主线保持[国外训练、中国无小时标签迁移](CROSS_DOMAIN_TRANSFER_RESEARCH_PLAN_20261031.md)。这是第1项的开发起点，第2–4项尚未完成。

## 本轮回答了什么

没有目标国小时标签参与模型训练、校准或选型，模型只读取日历和t−2粗技术月份额。源2022训练、2023校准；2024目标预测全部落盘封存后评分。六方法共享同一目标样本。两国此前均有其他开发记录，不能称项目首次未知国家确认。

真正接通了两向流程，但结果不支持通用回归已经可靠跨国泛化。粗预算小时轮廓重组是本轮最有竞争力的基线；英国源对美国煤气结构不同地区的迁移，仍存在明显水平偏差和失覆盖。

GB为8,784小时。美国各区并不覆盖相同月份：例如ERCO、ISNE主要为1–6月。缺失来自小时有效性和t−2月覆盖至少99%的共同输入条件；没有用未来月份替补。因此表中为可用样本条件下的结果，不是完整2024国级成绩，双向均值也不能直接当作等季节对比。完整逐月小时数保存在事后队列诊断中。

原始`country_metrics.csv`的`hours`列随其他数值取了地区均值，美国显示6075.57，不能当作样本数。实际为42,529地区小时、7区；该原始表保留以维持r1记录，计数以逐区表和[队列诊断](evidence/cross-country-pilot-r1/posthoc_support_and_cohort.json)为准。

## 事后诊断：下一步应解决什么

以下只用于解释已打开结果，未用于重选本轮模型：

1. 英国2022源火电电量加权有效因子约416.2，目标MISO实际约636.8、ERCO约527.6；这提示火电内部煤气结构的迁移偏差。目标有效因子来自小时细分，仅作事后诊断，部署时不可见。该对照不是对失效原因的因果证明。
2. 英国单国源的粗组成支持狭窄，所有美国目标都至少有一个粗技术份额坐标越界；但BPAT等区仍预测较好。简单越界规则既不能解释全部错误，也不能替代预测方法。
3. 粗月报Ridge严重负迁移，表明相同输入下的条件关系需要跨域训练和结构保护；不能认为添加月报特征就自然改善任何模型。

下一轮先在源内部构造留域任务，比较固定粗合同pooled训练、信息条件变化训练及按域任务训练。随后检验同容量直接CIF头、粗技术固定因子与潜在细燃料重组。模型容量、监督预算和可见输入保持匹配。需要补齐多季节数据和第三国支持；不根据本轮目标误差拟合某个目标专属火电因子，也不先增加残差倍率来掩盖偏差。

## 科学边界与软件验证

标签是统一固定EF的本地发电代理，非机构CIF或实测排放；GB biomass/other并组及EF=400是显式假设。进口、储能不进入该核算对象。GB来源naive时钟未擅自推断时区，美国使用明确当地时区。月输入由修订后小时数据聚合并模拟发布时滞，尚非真实月报vintage；与中国NBS规上范围仍有差异。上述限制在进入真实中国精度结论前仍需处理。

运行：

```bash
python scripts/run_cross_country.py --output results/cross-country-pilot-new
python scripts/audit_cross_country.py --run results/cross-country-pilot-new
```

本轮结果：`results/cross-country-pilot-r1/`。八个目标预测文件哈希核验通过。5项新测试覆盖未来/当期数据变动不改变合法输入、缺月不替补、细燃料不可见性、仅特征推理及Gaussian CRPS已知值；与既有EIA/NESO适配器测试合计19项通过。数据、脚本和协议哈希见[紧凑证据](evidence/cross-country-pilot-r1/provenance.json)，完整指标见[国家表](evidence/cross-country-pilot-r1/country_metrics.csv)、[逐区表](evidence/cross-country-pilot-r1/region_metrics.csv)。本轮未运行全仓库测试。
