# 仅公开月度／年度统计下的下一步科学合同建议

2026-10-26，Sol。依据最新用户硬预算：本地只能使用实际公开可得的月度或年度燃料统计。本文是只读设计审查和可证伪建议，不是已冻结实验协议，不授权正式运行。未读取新的 fine、目标或未知区数值；未改旧封存文件。V23 的日／块包方案不得因已有草稿或旧父 PASS 自动继续。本文采用 mle-workflow 的字段、时点、同预算参考和失败关闭检查，未引入部署流程。

**优先建议：先验证统计字段和分组粒度，再做月信息下的源迁移。** 最小源区实验应把八燃料月发电量降为合并热电／非排放组，比较粗燃料内部不确定性和普通源形状先验；不要继续默认中国公开表提供精确月 coal/gas 比例，也不要首先增加低秩风险传播层。若最终只有耗煤等燃料消耗量，现有 generation-share 任务需先停在转换合同，不能偷偷按发电量使用。

## 1. “同为月统计”不代表同一信息

当前没有收到具体中国表头、单位、公开档案和发布日期。因此以下是条件分支，不是已确认字段。所谓最小字段是使任务可定义的语义要求，不是已证明普适最少的标量数。

| 实际可得表 | 合法推断／处理 | 不允许的替代 |
| --- | --- | --- |
| 月度各燃料发电量，分项穷尽且同口径 | 由分项之和得到同月总发电量及份额；同分母固定EF下计算过去月发电加权CIF | 把总量之和当作另一个独立信息通道；推得本地小时G或当前真实月份额 |

所有分支至少登记：统计对象是发电还是消耗；分组定义与未覆盖项；单位和毛／净／上网、规上／全口径边界；对应期间；原始发布及修订时刻。总量若未公开且无法从穷尽分项合法求和，不借用小时遥测补分母。消费侧碳强度还涉及交换电量和进口碳，当前固定EF发电侧代理不能顺带解决。

本地日燃料、独立小时netG、Gmin、CV、T8、过去小时CIF、由这些字段反算的小时CIF均不在此主预算。天气不作为最低预算主实验输入；已有GFS只能在另行允许的匹配副轨作历史预报代理，不能声称逐小时 publication 认证，也不能充当硬发电支持约束。旧[V10合同](INFORMATION_VALUE_V10_PROTOCOL.md)已有这些区别。

## 2. 可识别的是哪个函数

设同一完整统计期间P内燃料发电量为E_f，小时正部总发电量G_h>0，固定发电EF为e_f，C_h为同口径小时强度。若全部分项已知，则

`A_P = Σ_f e_f E_f / Σ_f E_f = Σ_h G_h C_h / Σ_h G_h`

且

`A_P = mean_h(C_h) + Cov_h(G_h,C_h)/mean_h(G_h)`。

这是过去该月／年的发电加权强度，不是等权小时均值、等权日水平或未来目标。缺少小时G及其与C的关联，协方差项未知。仅把月总量按小时数均分，或令Σ_h C_h/n=A_P，是新增模型假设，不是统计约束。年度等式只约束整年，不能逐月应用。

两个可检验反例足以约束论文措辞：

- 两小时同G、煤／水各半能源：C=(500,500)和(1000,0)有相同燃料总量及加权均值，但strict600的超越数分别0和1。再交换两个小时，尾部数量不变而发生时刻变化。
- 固定G=(1,9)，煤总量1、水总量9：C=(1000,0)和(100,100)均有A=100，等小时均值却是500和100。连完整的月燃料总量及总G都不识别等小时水平。

若只知道分组E_g，固定EF模型下的过去粗强度通常只满足

`Σ_g min_{f∈g}(e_f) E_g / T ≤ A_P ≤ Σ_g max_{f∈g}(e_f) E_g / T`，`T=Σ_g E_g`。

例如**仅在本项目代理内**把全部正EF燃料合并成一组，份额p、其余EF0，则A∈[400p,1000p]。这不是官方“火电”的认证排放区间；真实组内燃料、发电EF、零排放类别、进口和计账误差需另核。过去月某燃料量为0不证明未来永远无该燃料。

因此分组粒度可能先损失粗碳水平识别，随后才是小时分配不识别。V15–22的同期日／块／G统计结果只能解释这些缺口；其oracle收缩、尾部证书和峰值区间不能当成当前月年预算的合法输入或预测增益。

## 3. 源端究竟可以迁移什么

源监督仍可学习：给定合法粗历史和日历的组成动态；组成条件下的燃料归一化日内形状；整日残差向量的水平／形状相关；季节与星期模式；未知分组内部的煤／气／油分配先验。它们都可能有预测价值，但属于概率迁移假设。

可反驳的关键假设是：在已披露组份额、历史粗动态和日历相近时，未观测组内份额及G–C依赖、小时调度／尾部具有足够稳定的跨源条件规律。仅匹配月份额没有验证这一假设。月观测不能凭空识别零空间中的小时排序、持续时间或极端共现；没有本地fine反馈，也不能直接校正目标小时残差分布。

更隐蔽的无效适应：若每个源形状q都已按燃料月总量重标，使其聚合必然等于同一输入E，那么月聚合似然对q完全相同。再用同一个月约束做IPF、KL匹配或“局部适应”，不产生区分这些q的证据。算法权重只能来自额外的源结构假设或有变化的粗预测关系，不能声称是本地统计识别了小时形状。

对于未来月份，应预测联合粗状态后再传播不确定性；输入的是粗预报，不是未来真实月量。即使每条潜在能量路径精确匹配其抽中的预测月量，也只说明模型内一致，不能将真实未来路径排除在模型外，更不构成小时90%覆盖证明。

## 4. 最小可证伪源区实验：先做分组粒度消融

### 先冻结字段分支，后看任何新分数

仅在七个已有源做开发；不读新的目标／未知区。沿用已有源评分日期与共同缺失掩码；这批源已多轮查看，仍是自适应开发。先按元数据决定如下分支：

- **M8**：合法月八燃料发电分项及同表可推导总量，作为精确信息参考。
- **MG**：从同一月表确定性合并分项。第一合成消融可合并本代理所有正EF项，保留其它公开组；明确这是受控proxy分组，不先称真实中国火电表。真实字段落实后另冻结相应映射，不按分数选最好分组。
- **YG**：仅在有完整、同口径、带可用时间的年度记录时执行同一分组。缺年度资料或vintage时记未测试；不得用不完整月表补成假年度，更不得复制12月。若未来另做假定年发布延迟，须标模拟并在评分前锁定，不能称中国已可得档案。

MG的预测、路由、模型选择和校准只能见MG及其可推导信息；未公开细分不能从文件名、预先算好的8燃料预测或native权重旁路返回。源proper监督可使用其它允许源的fine，但外层评估源的fine及隐藏细分不参与拟合。M8原native只能在M8轨作精确信息参考，不能把它当作MG同预算baseline。

### 第一轮：固定六种ordinary参考，不增加自定义风险层

建议先只做M8和MG，固定每轨三种同预算方法，128粒子、相同已定factor网格和完整源评估支持：

1. **简单粗锚＋源整日误差**。M8使用合法粗动态EF锚；MG使用源proper估计的组内分配先验得到粗强度分布，不取当地被隐藏的煤气真值。沿用整日而非逐小时独立抽误差。
2. **全局源先验重组**。组内份额／源形状从地区等权proper库抽取，与合法分组预报组成后做燃料能量比值映射；保留G为潜在源过程，不插入当地小时G。
3. **标准条件源先验重组**。同一proper库、粗预报、随机数、128粒子和比值映射，仅用该轨可见的分组粗历史／预测和日历条件化。MG的邻居距离不得使用隐藏燃料；条件组内份额与fine形状联合抽样，和全局版本作唯一匹配差别。可沿V9既有核，不为此起新机制名。

M8条件重组应先检查与既有V9固定谐波/native基准的可比性；若新增总量、窗口或抽样改变，单列变化并重算同预算控制，不宣称无条件旧数组身份。粗预测方法不再次扫描六种旧动态模型：优先固定V9已胜出的标准谐波；MG在可见分组坐标拟合，不能先预测隐藏八项再合并。点／路径裁边、粗预报误差和fine散布分别记录，避免重复叠加完整风险。

这六臂回答“损失燃料粒度是否已使可迁移先验失配”和“简单条件先验是否足以利用剩余信息”，不是完整概率方法竞赛。若后续要宣称超过强模型，必须另补同预算直接Ridge／ET、完整预算location-scale／QRF或EMOS式控制；不能只打败简单锚。尚无必要同时开发新weather gate、低秩covariance或rank transport。

### 评分与失败标准

- 先评粗函数：组总量／份额概率质量；在有合法细分真值的源监督评分侧评隐藏组内份额、过去粗A及预测A。真值只进评分，不回流MG特征。报告独立地区月数，不能将同月每日重复标签当数百个独立粗样本。
- 再评小时：CRPS、90%覆盖／宽／IS、逐源worst覆盖、上下尾，以及等小时水平和中心化形状误差／CRPS。若关心尾事件，冻结阈值和源only事件评分；高阈值无正事件不宣称尾识别有效。
- 全部源预测先封存后读评分标签。固定factor匹配对比与source-only选型分开；覆盖宏90–95%、worst≥85%。若无人合格，fallback保持failed。月块CI只作描述，不覆盖此前人工多轮选择。
- **第一轮失败也有明确含义**：MG劣于M8说明该具体模型对分组不确定性敏感，不证明所有MG方法不可能；条件先验不胜全局先验则停止把此核条件化称新机制；仅缩宽但失覆盖或IS恶化不晋级；只改善粗A而小时不改善则不能声称粗预测改善小时风险。
- **进一步方法开发门槛**：合法MG候选需在同预算强普通参考之上，在覆盖合格时达到至少5%CRPS下降、宽不增、IS下降，并在同粗预测／同factor下显示条件机制独立增量。否则保留普通模型与识别限制，不转移到不同信息预算寻找“成功”。源通过也只允许提出下一合同，不自动打开目标／未知区。

若M8本身无法满足覆盖效率，优先诊断源季节／支持失配和标准校准，而非期待MG或YG因信息更少自然变好。年度轨一旦执行要单独报告：没有新年度发布时，本地状态不更新；月内／年内季节起伏均来自源模型。月度轨成功不替代年度-only验证。

## 5. 与旧实验的实际差别和潜在论文空间

[V9](COARSE_DYNAMICS_V9_PROTOCOL.md)已经用月组成、谐波／Kalman、联合粗误差、global／conditional源残差及比值重组；自定义桥和条件风险未超过强标准参考。因此重复“月粗预报＋源细残差”不是新路线。

[V14](WEATHER_COARSE_V14_RESULTS.md)已经试了coarse/fine误差分解、物理比值传播、rank配对和多种条件概率模型；物理和rank的匹配增量为负。更换命名或再做一次月粗创新协方差传输不是已证突破。其同粗真值响应队列也少于全部可用fine监督，不能拿它代替完整预算强模型。

本建议新增的可检验对象是**现实可公开分组导致的隐燃料歧义、与小时调度歧义的分离及其源迁移代价**，而不是假定中国月表等价于EIA8燃料。它可形成有价值的信息预算／基准结果。真正方法机会则需要：在严格可用字段下对不可识别组内及fine风险给出诚实条件假设，显示超越普通条件先验／概率协调的独占增量；最好能给模型不适用时的可验证拒绝／风险界。没有新增本地fine真值时，任意目标域偏移下紧区间覆盖不可能靠月约束自动获得。经典行空间／零空间、矩界、LP、重要性抽样、MinT、IPF和共形包装均不自动构成原创性。

## 6. 原始文献核查与适用边界

以下是针对性核查，不是系统综述；均未运行或声称复现／超过论文。

- [Zhang等，NeurIPS2020，Learning from Aggregate Observations](https://proceedings.neurips.cc/paper/2020/file/5b0fa0e4c041548bb6289e15d865a696-Paper.pdf)：核到全文问题设定与等价类一致性讨论。聚合似然学习依赖所给模型及聚合映射；不能将模型可学习性替换为本任务的无条件小时识别。此处latent G和能源加权必须进入映射。
- [Agarwal等，UAI2025，Aggregating Data for Optimal Learning](https://proceedings.mlr.press/v286/agarwal25a.html)：本次仅核原始出版页摘要。研究MIR/LLP下bagging与学习效用，结论依赖任务及模型，不给“每月若干标量普适足够”的定理。
- [Cauchois等，JMLR2024，Predictive Inference with Weak Supervision](https://www.jmlr.org/papers/v25/23-0253.html)：本次核摘要；此前项目已记录其弱覆盖区别。弱标签相容性与真实小时边际90%覆盖不相同，不能用聚合相容路径替代真实路径覆盖。
- [Hollyman等，Scaleable Dynamic Forecast Reconciliation，2024预印本](https://arxiv.org/abs/2409.12856)：本次核摘要、此前核过相关全文；动态权重与样本外预测误差已是已有机制。目标仅月粗反馈时，并未获得其所需的目标fine误差。
- [Biswas等，Nonlinear Probabilistic Forecast Reconciliation，v3，2026-09-17](https://arxiv.org/html/2604.26668v3)：核到全文框架及非线性projection/conditioning、UKF和比值应用。不能再以H/G非线性重组或coarse条件化本身主张新颖；应用假设、信息不足和独占实证仍须另证。
- [Panagiotelis等，EJOR2023，Probabilistic forecast reconciliation](https://1www.robjhyndman.com/publications/coherentprob/index.html)：本次核作者原始出版页；已存在概率协调与评分优化。能量和与CIF比值的统计口径必须区别于直接对CIF做等权时间求和。

针对具体中国表，在字段和真实发布档案未明确前，只能称美国已查看源上的受控分组／频率模拟，不能称中国年度预测验证。此前[中国字段核查](CHINA_LOCAL_INFORMATION_FIELDS.md)证明的是披露类别与访问边界，不是匿名可下载的既有数据vintage，更不改变本轮用户的月年-only约束。

## 7. 对拟议V24月表字段诊断的有限预审

根代理另拟仅使用已锁七源2022–2024月表的V24：M8、合并coal/gas/oil而保留other的六类表、合并全部正EF项的五类表；CGO表再分别揭示一个月coal/gas/oil标量。**此计划比先跑新预测机制更适合当前字段尚不明确的问题，可有限批准为源only、回顾性统计语义诊断。** 本文未读取其月表数值、未核定行数、未运行V24；正式代码与时点合同仍需另审。

在固定代理EF、分组能量非负且组内没有其它限制的类内，组EF最小／最大界确为sharp：把该组全部能量放在最小／最大EF燃料即可达端点，各组独立相加。真实M8点应包含在其两个合并组区间中，两个合并区间也按分组粗化关系嵌套。这里不施加组内历史支持，以免把被隐藏燃料真值或零值重新偷渡进粗表。

令c/g/o为煤／气／油的同月总发电份额，p=c+g+o，other单独保持EF400。CGO粗表初始区间宽为600p；分别揭示一个标量后的宽为：

| 揭示字段 | 剩余sharp宽度 |
| --- | --- |
| coal份额c | 400(g+o) |
| gas份额g | 200(c+o) |
