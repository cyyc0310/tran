# CN5按目标粗组成相似度选择燃料预测头：源内嵌套诊断

冻结日期：2026-11-02，计算本轮门控指标前。该探索由上一轮全局混合权重在源伪目标上随外层折变化、但未优于单头引出的假设；上一轮2024结果已打开，因此此轮仍属已看开发集上的次级探索，不是确认实验。

## 假设与目标可见特征

全局源伪目标选alpha可能掩盖目标组成差异。使用每个目标预测月之前`t−2…t−7`窗口内实际可用的五类月份额均值作为目标签名，以Hellinger距离寻找最相似的源伪目标；必须有最近`t−2`月份，较早月份按真实缺失状态缺位。复用该伪目标在2023H1源端选择的`alpha∈{0,.25,.5,.75,1}`。alpha定义为`(1-alpha)*factor_history + alpha*fuelshare_history`。不使用目标燃料细分、小时CIF或区间标签路由。

## 双重源伪目标评估

对每个外层源伪目标排除`A`、内层伪目标`B`：选择器只可从其它源国`C`的H1得分学习其alpha，再以`B`的可见月份额签名找最近`C`并预测B的H1误差。与同一训练折中仅用其它C选出的全局alpha配对。此项评估门控是否在未参与alpha选择的源伪目标上有增量。

外层目标A的2024路由alpha从A以外各源伪目标`C`的H1最优alpha中，按A的预测输入签名最近邻选择。2023H2半径用排除A和对应校准伪目标C的模型产生；C的alpha也由排除C的H1伪目标签名最近邻路由。然后只对已看2024外层标签做评分。

## 固定细节与对照

- 特征：t−2至t−7窗口内可用月份均值的五类比例；距离：Hellinger；单最近邻；相同距离并列按国家代码排序。无阈值、无按2024结果调参。
- 对照：最佳单头、上一轮全局伪目标alpha混合、逐折LOPO全局alpha，以及比例重组。源H1嵌套验证报告MAE及等国平均；2024外层报告MAE、日内形状MAE、覆盖、宽度、Winkler及最差国。
- 对照头和混合头都以2023H2双重排除源伪目标误差构造等国加权q90区间；H1只选alpha，不参与半径。

## 停止门槛

若最近邻alpha路由在源内双重伪目标H1验证不能较LOPO全局alpha将MAE至少降低5%，则门控不晋级；即便源内通过，若已看2024开发回放未同时改善最佳单头点/区间表现，也不冻结、不对未查看国家测试。2024重复使用只能报告为开发性敏感性，不能算独立确认。
