# 乌克兰小时目标外部确认候选预检：因数据仅至2022年2月拒收

预检日期：2026-11-01。目标只检验已经冻结的总发电量趋势候选能否在真正未查看的国家作一次固定EF发电侧确认；不做拟合、预测、数值标签审阅或评分。

## 元数据检查结果

Energy-Charts API v2回报国家`ua`、`Europe/Kiev`、MW、PT1H，共1,336条记录，服务端生成时间为2026-11-01，实际数据时间范围只到2022-02-25 15:00。虽请求2022-01-01至2025-01-01，响应没有2024目标年，亦没有完整2022来源/输入年。

响应列出的系列为核电、硬煤、天然气、水库水电、抽蓄、其他、陆上风电和太阳能；系列名不足以弥补样本期不足。原响应及只读元数据、HTTP头和SHA-256保存在[`data/energy-charts-ua-blind-r1/`](../data/energy-charts-ua-blind-r1/)。预检代码只解析并输出日期/分辨率/类别元数据，没有查看小时MW数值或派生标签。

## 决策

UA不满足已冻结协议的训练/校准历史及2024目标覆盖要求，故在评分前拒收。不根据已有1,336条数据扩展日期、换预测年或调整模型；这既不算算法失败，也不计为外部确认。

对当前Energy-Charts API国家清单作项目级目标可用性检索后，UA是没有出现在本项目75国Carbon Monitor日尺度目标结果中的国家；其余有可选国家数据的地区已在该日尺度项目目标结果出现过，或是欧洲/DE聚合项。因此现有Energy-Charts国家库里没有同时满足“项目未看过”与完整2022–2024小时燃料标签的数据域。下一步采用全新2025目标年作为时间外复核，并严格标记它不是新国家确认。API国家与数据窗口详见[Energy-Charts官方API](https://api.energy-charts.info/)；该API默认CC BY 4.0，需署名Energy-Charts.info。
