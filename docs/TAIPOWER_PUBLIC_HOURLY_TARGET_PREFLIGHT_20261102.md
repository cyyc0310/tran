# 台电公开小时发电数据候选预检

日期：2026-11-02。目的：判断是否存在一个不依赖市场成员账号、可用于冻结跨域方法外部压力测试的公开小时响应源。本轮只做数据与口径预检，不拟合、不评分，也不将该来源登记为盲地理确认。

## 已核实的公开入口

- 台湾电力公司“各机组过去发电量”在政府资料开放平台标注为原始数据、免费、政府开放资料授权第1版；字段是`FUEL_TYPE`、`UNIT_NAME`、`DATETIME`、`NET_P`，10分钟净出力，官方说明每月更新一次并回补三个月前的数据。平台说明数据从EMS摘取，可能因系统维护、设置或传输与实值有差异。[官方数据集](https://data.gov.tw/en/datasets/37331)
- 其资源端点在2026-11-02返回`Last-Modified: 2026-11-01`、`Content-Length: 194,124,659`、支持Range请求。仅从响应头及文件开头确认当前档案标注覆盖2026-04-01至2026-06-30、单位MW、PT10M。为确认JSON字段结构，读取了响应开头的少量记录；因此后续即使评分，也应称外部压力测试，不称严格盲确认。
- 台湾能源署“发电量月资料”公开字段覆盖全国、台电、民营电厂与自用发电设备，包含煤、油、气、核、水电及再生能源分类，近20年、月更新、开放授权第1版。[官方数据集](https://data.gov.tw/dataset/112650)
- `data.gov.tw`链接的静态CSV端点对本机请求返回403；继续查到能源统计专区公开JSON API `https://www.esist.org.tw/a0303/02/api/v1/zone/monthly/3/2`，无需账号可读，并返回全国、台电、民营电厂、自用发电设备四个统计层级。当前月表包含2025年和2026年1–8月；官方月报说明每月底发布上月数据。[能源统计专区月报](https://www.esist.org.tw/a0303/02/publication/monthly/?tab=%E9%9B%BB%E5%8A%9B)、[发电量API说明页](https://www.esist.org.tw/a0303/02/database/api/)

## 进入建模前仍须通过的门槛

1. **响应支持对齐。** 高频响应是机组级净功率，而月统计覆盖全国/台电/IPP/自用设备的毛发电量；必须由机组映射或官方汇总核实两者重叠范围。不能把统计范围不一致的月量直接当作目标可见输入。
2. **月输入实际可取。** 已通过官方能源统计JSON API取得分类月表结构及月份索引，当前修订表足以构造目标期的`t−2…t−7`历史月输入；但没有历史API快照，不能证明每个特征值与预测起点当日首发版本相同。后续只能称修订快照上的滞后输入回放，不能称严格as-issued回放。
3. **燃料映射与标签合同。** 高频表的完整`FUEL_TYPE`类别、未知/混合类别、IPP覆盖及抽蓄处理必须在锁定固定EF映射前审计。台湾月报的煤/油/气细分只能用于月量输入支持审计；中国主预算仍需先合并为火电五类输入，不能把月度煤气拆分偷渡到模型特征。
4. **时间支持。** 当前已确认的小时档只有2026年4–6月一个季度。须核对目标时区、重复/缺失时点、10分钟转小时规则和归档是否完整；单季度只能作为时间/系统压力测试，不能支持全年或季节泛化结论。
5. **盲测状态。** 预检已读取少量响应记录，后续实验需单独声明为“预检看过数据结构的冻结方法外部压力测试”。是否曾在项目更早的日尺度结果里出现台湾，也须在正式评分前审计；当前仓库文本搜索未发现台湾条目，但这不足以证明项目历史上从未查看。

## 当前决定

这是一个有价值的公开数据候选，尤其可补充“美国/欧洲训练→亚洲电力系统”的外部系统检验。月输入已经有匿名公开API入口，但全国月报与机组级净出力的覆盖范围仍须核对，燃料枚举也须先完成白名单审计。只有统计范围对齐后才准入正式跨域评分；否则停止候选而不更换月报层级追逐较好分数。

后续找到能源统计专区公开API后，已提取仅供目标预测使用的2025-09至2026-04月度五类输入份额，并保存原始API快照、输入月份表与滞后合同哈希；目标小时响应仍未解封、未评分，也未修改已封存的既有预测。预测运行器为[台电CN5外部迁移脚本](../scripts/run_taipower_cn5_external_transfer.py)。
