# 细燃料水平与小时形状的发电/消费双轨配对实验

冻结时间：2026-11-01，评分前。目的：补齐此前细燃料M+F小时曲线只在固定EF发电代理上评估的缺口，检验在同一美英双向队列中，其增量是否也出现在官方消费侧估算标签。

## 轨道、输入与对照

- 方向：US→GB及GB→US七个BA；源小时训练2022年、源端残差校准2023年，目标评分2024年2、4、6月，与既有M+F双向实验主配对月相同。
- 标签分别为固定燃料EF回算的本地发电强度代理，以及EIA/NESO官方消费侧小时估算强度。不得合并轨道或用一个轨道的校准参数给另一个轨道。
- M：目标`t−2`五类月组成，强参考为源燃料小时曲线比例重组；同列anchor700、source thermal-EF及粗特征直接模型。
- M+F-upper：在M上增加目标八燃料月份额（由已有目标小时燃料序列回算，仅用于机制上界对照）。分成固定EF静态水平锚和源区等权燃料专属小时轮廓重组，区分增益来自更细水平信息还是燃料内小时曲线。
- 两标签轨对每个方向使用相同的源/目标、月、目标小时队列。官方消费侧响应模型仅用对应源端2022标签拟合；固定EF重组与M+F构造保持相同，不因消费标签更换公式。所有方法使用各自2023源残差偏差/尺度校准。

## 执行及评分

- 目标2024预测逐文件封存后，才读取目标小时响应做评分；M/M+F预测时只用目标`t−2`及更早输入。生成侧目标组合来自同一公开小时序列，属于事后上界开发回测，不能声称历史as-issued冷启动。
- 同时报告逐地区×月MAE、去日历/逐日内形状MAE、Gaussian CRPS、90%覆盖、区间宽度、interval score；按BA月等权，并分开列GB单目标与七BA目标。
- 主增量问题：M+F燃料曲线相对M强重组，及相对M+F静态EF，是否在两条标签轨都改善点误差/CRPS和形状，并在覆盖不降、宽度不增前提下改善区间分数。消费标签若只因跨区交换而改变风险/误差，作为不同估计对象解释，不视为发电侧模型失败或成功。
- 若M+F仅改善发电轨或静态M+F已解释全部点增益，不能宣称小时调度曲线具有跨标签可迁移增量；若只有来源形状扩宽区间才提高覆盖，也不晋级。

## 边界

目标国、地区与2024均已在此前开发中查看；八燃料目标月组成并非中国月报预算，且由小时回算；官方消费强度含跨区消费分配。该实验只补双轨上的机制对照，不构成盲测或中国精度/覆盖验证。
