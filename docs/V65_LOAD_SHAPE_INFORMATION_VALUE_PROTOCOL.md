# V65 模型负荷日内形状对月燃料CIF均值识别界的敏感性

日期：2026-10-27。测试问题：若公开模型化省级小时负荷被额外假定为“月内发电总量时序的比例代理”，它能把月度燃料边际下的等小时CIF兼容范围收窄多少？这是信息预算敏感性分析，不是小时CIF预测或负荷代理准确性验证。

## 固定输入和LP

- 仅对已下载的Ember 8类省级月发电快照与Yi et al. 2015–2024省级小时负荷曲线有匹配数据的省月计算；实际覆盖、缺省来源和全部文件哈希输出。
- EFs沿用TransCIF项目代理 `[coal=1000, gas=400, other fossil=400, nuclear=0, hydro=0, wind=0, solar=0, bioenergy=0]` g/kWh。该代理仅用于信息边界演示，不宣称中国核算因子。
- 将每月全部逐小时负荷按小时-of-day汇总成24个时段，再按Ember当月总发电量归一，得到24个假设的 `G_h`。这等价于假设月内发电总量沿负荷的日内形状分布；不假设负荷水平等于发电水平。
- 对同一24时段表示计算月燃料边际only的V58锐界（T=24）、加平坦等分24时段总量后的LP锐界、加上述负荷形状固定`G_h`后的LP锐界；燃料总量守恒、时段总量守恒、非负。平坦等分臂用于分离“知道24个时段总量”与“负荷曲线形状”的贡献。记录每月月度能量加权CIF（可直接识别）和各臂等时段均值边界。
- 2018年额外同时以旧Zenodo典型日负荷形状、2026天气重建负荷形状作为两种不同代理构造的配对敏感性对照；均压缩为24个小时-of-day槽。两份曲线都不是生成真值。

## 预先限定的结论范围

主要报告兼容区间宽度的均值/分位数及按省分解，并分别对比月边际only与平坦时段总量、负荷代理时段总量。负荷代理相对于平坦臂的增量才是时序形状的条件性识别价值；代理相对于月边际only的总差异不能全归因于形状。若负荷形状显著收窄界，只能说该**假设代理形状**增加了形式识别信息；不能说真实小时CIF被覆盖、预测更准或区间具校准。若旧模板与天气重建代理得到明显不同的界，说明界限结论对负荷形状来源敏感。负荷/发电口径差及月比率波动仍须单独披露。

禁止把目标月全量燃料边际称为月初预测输入；此实验条件于目标月事后公开的Ember统计，estimand是“给定月边际的小时分解”。所有预测类解释均排除。
