# 真实首发EPM月量变旧时的双轨迁移表现

完成日期：2026-11-02。按[冻结协议](LOWER48_ASISSUED_MONTHLY_AGE_PROTOCOL_20261102.md)完成发行年龄敏感性实验，作为优先级4的输入时效性诊断。预测按2024各目标月当时可用的EPM首发档案构造；发电侧和消费侧官方EIA-930小时强度分别评分。

## 设计与封存

- 每个目标月以原`lower48-actual-issue-dual-track-r4`中当时最近已发布EPM档案为起点，取该期最新公布月份；另取再旧一个月、再旧两个月的**历史首发版本**。旧值来自对应观察月首次公布的EPM发行包，脚本核验其发布时间早于目标月起点，没有用后续修订版本填补历史。
- 目标月与输入月相距：最新档案年龄3–4个月；旧一个月臂4–5个月；旧两个月臂5–6个月。这里按跨越的自然月计数。
- 同一GB 2022训练、2023源校准、粗分类映射、小时样本和预测器；只改变可见的月发电量观察期。七个既有方法先预测并封存，再评分两条官方标签轨道。
- 最新输入臂逐值复现原封存首发预测，最大点预测差为0。封存预测SHA-256：`b4d9c49101b730210be2469aee280e0bb28590ef90768ba1c647e8f2385372e0`；输入档案SHA-256：`cd262656d55006f65616e65597cead25466bb1c2719f1a91157ba1373f7c2bea`。逐月双轨分数见[完整机器表](../results/lower48-asissued-monthly-age-r1/monthly_dual_track_scores.csv)，年度汇总见[方法总表](../results/lower48-asissued-monthly-age-r1/dual_track_scores.csv)。

## 最差月份揭示的可靠性边界

对强重组，旧两个月臂在2024年9月最差：生成侧该月覆盖由70.6%降至13.3%，消费侧由69.4%降至12.8%。同月`source_thermal_ef`分别由71.4%降至17.2%、由70.4%降至16.7%。`anchor700`也从两轨100%降至约65.8%，所以局部失效并非重组专有。所有这些区间半宽均未改变；年度均值和Winkler改善不能掩盖这种月度风险。

## 判断与下一步

1. **强月报重组对统计年龄只有有限的年度点误差稳定性。** 旧一个月时MAE近乎不变；旧两个月时MAE恶化。不同月份不是单调变化，不能声称“输入越旧越差”的统一规律。
2. **区间门槛仍未通过。** 重组总体覆盖约69–71%，明显低于90%；年龄增加后覆盖更低且固定宽度没有收窄。`anchor700`总体更稳，但其9月仍出现大幅覆盖落差。
3. **两轨必须分开解释。** 消费侧有自身交换分摊与官方强度定义；和生成侧数值接近，只反映本次共同输入扰动，不能替代来源信息或消费侧性能验证。
4. **不形成新算法增量。** 本结果为2024单一区域上的滞后信息压力测试；改变输入月份同时改变观察到的季节与燃料结构，无法把差异完全归因于“陈旧度”本身，也不能外推到中国或跨区分布。
5. 2026年11、12月已经封存的`t−3/t−4`两轨预测仍需等待响应成熟再盲评分。它们处于此历史实验覆盖的最新输入年龄范围内，但本实验不证明其未来覆盖。年度煤/气装机预算保持独立`M+C`对照。
