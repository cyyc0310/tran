# V293 冻结协议：月度燃料边际对小时超阈值计数的锐界

日期：2026-10-30。先冻结解析界和阈值，再执行已打开队列上的数值复核。

## 问题与固定信息合同

只有一个目标 BA-month 的逐燃料月电量 `M_k` 和固定燃料EF `e_k`，没有小时燃料量或小时总发电量。目标小时数 `T` 与时间索引已知，但每小时总量只要求为正。目标是超阈值小时数 `Kτ=#{t:C_t>τ}`，其中 `C_t=Σ_k e_k g_{tk}/Σ_k g_{tk}`，`g_{tk}≥0` 且 `Σ_t g_{tk}=M_k`。

对给定 EF，先定义月度发电加权锚 `μ=Σ_k M_k e_k / Σ_k M_k`、活跃燃料集 `A={k:M_k>0}`、`H={k∈A:e_k>τ}`。当 `H` 为空时 `Kτ=0`；当 `A⊆H` 时 `Kτ=T`。否则（有高阈值和非高阈值活跃燃料）：若 `μ>τ`，锐计数范围为 `[1,T]`；若 `μ≤τ`，锐计数范围为 `[0,T−1]`。严格大于阈值；`μ=τ` 归入后者。解析证明应说明可行性端点由将全部月燃料按比例放入每小时、或向少数小时分配任意小的正高EF电量并将其余燃料集中到其他小时构造。区间表示可行计数的最小/最大包络，不预设每个整数都可达。

## 数值复核

复用 V231 已打开 EIA 2026年7–9月非开发 BA 队列，阈值冻结为 `400, 500, 600, 800, 900 g/kWh`，使用 V231同一固定八燃料 EF。记录锐界宽度、月锚相对阈值的一侧、活跃EF支持是否跨阈值、代理小时计数是否落在锐界内。每个BA-month逐阈值形成一行。

## 解释限制

- 这是固定EF、小时总量未知的结构性识别结果，不是预测区间或概率覆盖率。
- EIA生成侧标签是固定因子代理，目标队列已打开，不是盲测或中国实测。
- 不给EF加任意误差盒；EF不确定性已在 V269/V271 支持端点研究中单独处理。
- 如样本端点核验失败或队列不一致，停止并报告失败；不得调阈值或改公式以追代理值。
