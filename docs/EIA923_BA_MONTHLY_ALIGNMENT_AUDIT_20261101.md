# EIA-923 月度燃料量与 EIA-930 平衡区小时数据对齐审计

日期：2026-11-01。此审计承接[真实月报 vintage 审计](ACTUAL_MONTHLY_VINTAGE_AUDIT_20261101.md)，检验 EIA-923 是否提供与现有小时样本相同地理单元的月度燃料特征。它是接入/定义审计，不是预测效果实验。

## 数据和处理

EIA说明，Form EIA-923 在电厂与prime mover层级收集月度发电与燃料数据；月度发电表直接含 `Balancing Authority Code`、MER fuel type code 及 1—12 月 `Netgen`。因此本轮按官方BA字段聚合，无需先把州级统计强行拆分到BA。[EIA-923数据说明和文件目录](https://www.eia.gov/electricity/data/eia923/index.php)

使用 2024 Final EIA-923 档案，将煤、天然气、油类、核、水（含抽蓄）、风、太阳及其他类别映射并聚合；与 EIA-930 2024小时燃料文件按 BA×月比较。小时 MW 对完整自然月求和作为 MWh。只对 8种小时燃料全部不缺失且覆盖完整自然月的 BA×月计算误差；没有填补缺失小时或燃料。范围是已存在共同小时评测中的 7个 BA，故此为已查看地区的开发审计。

## 结果

EIA-923给出 7个BA×12月共84个BA月值；EIA-930小时文件中有61个BA月同时达到完整月小时和燃料字段条件。共同样本中：

- EIA-923 月发电量除以 EIA-930 小时发电量之比的中位数为 **1.044**。
- 八类燃料份额向量的逐项绝对差之和（L1）中位数为 **0.082**，均值0.100，90分位数0.190，最大0.462。
- BA之间异质性明显：L1中位数从 FPL 的0.021到 BPAT 的0.181；完整配对月分别为7和8。

这证明**BA级月度燃料预算可以与已有小时BA键直接连接**，同时表明 EIA-923 与 EIA-930 在统计总量、覆盖和燃料分类上存在可测差异。对迁移模型而言，EIA-923可作为真实公开粗月输入候选；它不能被当成小时特征的精确月度守恒边际。基准应同时保留官方月度特征方法和从小时聚合构造的 oracle/诊断参考，分别标注数据来源。

该口径差异符合EIA公开的测量边界：EIA-930记录BA可见/管理机组的小时净发电；EIA-923覆盖更广的电厂统计，并经过审核；EIA说明BA小时总量与其他月/年出版物可能显著不同，少量燃料类别也可能出于保密被并入 `Other`。[EIA-930方法与差异说明](https://www.eia.gov/electricity/930-content/about.html)。本轮不把这些通用口径解释当成每个具体偏差的因果归属，尤其是FPL 2024-01的大偏差还需逐类别调查。

## 发布版本限制与研究含义

本轮用于BA映射的2024 EIA-923文件是**2024 Final**，ZIP内工作簿时间为2026-01-12。EIA官方页面另列当前年份月度文件及历年年度文件，并声明2025年前数据为final；修订页面记载历史年度文件会重新发布。[EIA-923发行与修订说明](https://www.eia.gov/electricity/data/eia923/index.php)、[修订记录](https://www.eia.gov/electricity/data/eia923/correction.php)。因此，它适合证明统计字段、地区映射和现行最终值的接口可行性；不能伪称为2024年每个 `t−2` 时点当时取得的月度BA值。

与之相比，EIA Electric Power Monthly历史ZIP留有当时州级月表快照，但州与BA边界不同；EIA-923最终文件有BA尺度，却没有本轮找到的完整历史月度发行快照链。当前可确认的结果是“发布快照”和“小时地理对齐”分别可行，二者尚不能在2024历史评测中同时满足。跨国小时算法排名仍应以既有同口径实验为主，直到解决这一历史源特征版本链或开始前瞻归档。

对目标研究的具体推进：

1. 将EIA-923聚合器作为BA级公开月报基线接入源域伪目标训练，先比较其与小时回算混合的差异；实验结果必须标记为**最终值/滞后模拟**，不能标成as-issued。
2. 按同一燃料映射做US→GB、GB→US两向冷启动；目标月统计仍严格限制在所声明的滞后窗，小时标签只在预测封存后评分。
3. 对可信度分别报告测量口径导致的粗组成偏差和模型区间覆盖，不把两者合并为一个校准残差。
4. 并行归档当前及未来EIA/NBS每次月度原始响应和发布时间；旧年份不反向伪造vintage。

这项证据改善了第1、2优先级中的数据接口与输入真实性审计；它没有建立新算法收益。当前主要创新机会仍在：利用源端丰富小时监督，在目标只见延迟粗月报时学习可迁移的小时形状/燃料运行关系，并在目标国完全留出条件下相对强重组和概率基线给出稳定增量。
