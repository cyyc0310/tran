# 同源标签预算的直接CIF与条件区间强参考

2026-10-31，Sol。查看R4后补足比较的开发实验，不是未知国家确认或原创方法。参数、源切分和评分方式在本轮预测/评分前固定。

## 标签和信息预算

沿用源观察天气35448小时、1477地区日，9配置，两目标预算（原月报／月报＋静态装机代理），源校准576小时，目标624个唯一小时。训练是ERA5源历史，校准和目标都是起点前GFS；原始公众发布认证仍False。目标不提供小时CIF/发电/负荷历史。

原R4完整源年银行还使用了更多未配对的源小时标签，不能当成严格同35448标签预算的主比较。本轮从每个proper source tuple的35448候选子集重建paired银行，复用同一批数据训练的R4日幅度参数；配对银行、日幅度、直接CIF/火电占比主比较使用相同源细标签。过去公开粗月报对全部方法可用，聚合源历史不计为偷偷提供当前小时标签。旧R4全年银行只作为额外标签参考单列，不冒充标签匹配。

## 直接预测和条件区间

直接CIF响应为固定因子发电侧代理g/kWh；直接火电占比响应为1000×火电／总发电，转CIF时乘共同的EF/1000。装机预算使用同一公开代理因子；月报预算使用paired银行源宏因子。前者不依赖火电内部细分预测，后者隔离“直接预测火电比例”与燃料重组的区别。

两响应各有无/有天气HGB。共享小时HISTORY（此处小时谐波有意义，不能按日模型零化）、合法月报年龄、五年气候和季节资源派生；天气版本增加小时及日预报资源、温度/度日和公开风光比例乘资源的派生量。装机预算再加入该代理因子。无国家ID或当前发电/标签输入。源国家、地区、小时的损失权重均衡；HGB的离散分箱和最少叶样本数按库原实现执行，并不声称每个内部步骤国家等权。

固定HGB：200轮、15叶、叶最少64小时、学习率0.05、L2=10、关闭早停、种子416。不做目标调参。全源拟合均值与0.05/0.5/0.95三个分位数，源预测在原响应物理范围0–1000截断，三个分位数排序修复交叉。

异方差尺度用三段源日历块整体留出的绝对误差训练：3–4月、5–6月、7–9月；同块全部国家/区域一起留出，不能随机留单小时。OOF训练可以使用其他2022月份，属于最终2023模型训练中的交叉拟合，不称作2022历史起点前真实预测。尺度头采用绝对损失，最终均值头再用完整源训练；尺度转换成CIF单位后最小为1g/kWh。

源2023H1只计算权重90%经验分位数，比较全局、异方差、signed-CQR和非负CQR四种规则。signed-CQR允许负扩张来收窄过宽源区间；若其集合为空或越过预测中位数，扩大到包含中位数并限制0–1000。它是带修复的源加权参考，不宣称严格等同论文原始CQR或在跨国/时间相关样本下有分布无关保证。[Romano等，NeurIPS 2019](https://proceedings.neurips.cc/paper/2019/file/5103c3584b063c431bd1268e9b5e76fb-Paper.pdf)

原银行和有/无天气日幅度HGB在paired银行上使用同一source-CQR规则，提供raw、非负校准和signed校准。源单国模型在两个目标间重用参数，必须检查源tuple和输入相同；所有模型和OOF预测可保存审计。

## 公平评分与封存

三个分位数不能假冒完整CDF，本轮公共概率指标用90% WIS：`(0.5*|y−q50|+0.05*IS90)/1.5`，等于三个分位数平均pinball的两倍。原成员参考用其真正分布中位数计算WIS，另保留成员均值的点MAE；直接global/hetero以均值预测作对称区间中心，并在WIS中将这个对称中心声明为中位数，不用单独拟合的quantile-HGB q50替代。CQR以该拟合q50作点预测。不能把不同点定义悄悄混合。报告point MAE、median MAE、形状、覆盖、宽度、IS90和WIS90。

所有配置、预算、方法的预测、源半径、模型、OOF及成员都在目标评分前封存。按地区→配置宏平均，并展示国家/地区失败。9配置不等于9独立国家，624小时仍来自3个开发起点。只检验结构模型在同标签/信息预算下是否超出强直接参考；即使区间有效，也不宣布原创性或打开未知国家。
