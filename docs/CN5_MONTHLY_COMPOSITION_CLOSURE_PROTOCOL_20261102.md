# CN5月均燃料组成约束的小时响应迁移协议

冻结日期：2026-11-02，运行前。问题：严格CN5预测时信息下，源国小时燃料响应模型能否先迁移目标月的平均火电内部组成，再约束小时组成曲线，使其月度热电量加权边际与预测组成一致？本轮只检验这一个结构性候选，不扫描模型或阈值。

## 任务和数据边界

- 复用Energy-Charts严格CN5九国开发队列。外层整国留出；2022源小时监督训练、2023H1来源伪目标校准、2024目标评分。九国和2024此前均已打开，结果仅为开发回放，不能作为未见域确认。
- 目标输入仍仅有当地日历与`t−2…t−7`火、水、核、风、光滞后月度份额及其既有低维统计。小时燃料标签只用于源训练和封存后评分。
- 响应标签是Energy-Charts细燃料小时序列按固定因子构造的发电侧代理；不是中国实测/官方CIF，不外推到消费侧。

## 单一候选：月均组成预测＋小时组成闭合

1. 沿用源小时四头HGB燃料份额模型，得到目标小时初始煤、气、油、其他火电份额；输入、参数和训练源小时均与`fuelshare_history`相同。
2. 另将源2022小时燃料量先按国家—月份聚合，得到热电量加权的四燃料月均份额。只用无小时的目标月日历、CN5滞后份额及既有热电/总量摘要，拟合一次预设`StandardScaler + multi-output Ridge(alpha=10)`。每折训练样本按国家等权、国家内月份等权；输出截为非负后归一至单纯形。
3. 每个查询目标月内，对小时HGB份额做加权迭代比例拟合（IPF）：逐小时份额和为1；按同一源小时形状模型估计的目标热电出力量加权后，月均四燃料份额等于第2步预测值。预测月标签、目标小时燃料量和目标CIF均不可用于约束。
4. 使用所得小时组成与现有固定燃料EF计算小时热电有效因子，再乘与原`fuelshare_history`完全一致的CN5重组热电小时份额。唯一结构变化是月均组成约束。

## 对照、校准与评分

- 同一外层折比较：比例重组、标量`factor_history`、原四头`fuelshare_history`、候选`monthly_composition_closure`。不增加其他调参候选。
- 所有方法用同一来源2023H1、国家等权90%绝对误差半径；先封存2024全部预测及半径，再读取标签评分。
- 报告国家—月份等权宏/逐国小时MAE、去日均形状MAE、90%经验覆盖、区间宽度、Winkler，以及四燃料月均组成误差。按国家和月份配对，不将小时视为独立样本。
- 同时核对IPF月边际误差、预测非负性、每小时份额和、所有基线共同行数与封存哈希。
- 预测文件另存生成地时区对应的目标月份字段；夏令时和UTC换日不得改变月内IPF审计或评分分组。

## 继续门槛与停止规则

只有候选相对原燃料份额头和比例重组都至少降低5%宏MAE，形状不恶化，90%宏覆盖不低于原燃料份额头且不低于88%，最差国覆盖不下降超过5个百分点，并改善Winkler，才值得冻结一次真正未查看域确认。否则停止“月均闭合”路线，不再换Ridge alpha、IPF目标/权重或约束强度；收益仅作为信息可识别性诊断。该门槛是筛选规则，不是覆盖保证。

## 可复现性

新结果必须包含协议与代码/输入SHA-256、逐国预测、校准半径、封存清单、原始机器评分和结果说明。任何输出未满足月边际约束或哈希变化均令本轮无效；不以人工修补目标输出替代完整重跑。
