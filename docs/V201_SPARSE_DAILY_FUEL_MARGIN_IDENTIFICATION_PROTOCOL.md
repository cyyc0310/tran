# V201：月度燃料边际之外，少量逐日燃料统计能否约束小时尾风险？

状态：新的信息预算开发实验，沿用已打开的 EIA 代理区和 V86 同一时窗；不属于未看地区确认，也不代表中国实测。它不再训练或搜索小时预测算法。

## 研究问题

V86测了完整逐日报告下的H/G/Q信息前沿。本轮固定一个更贴近“月报已经有、还能少补一点本地统计”的预算：完整月度八燃料总量已知，再额外观察k个日历日的逐燃料发电量（八类日量）。对其余小时只知道月总量扣除已报日量后的剩余燃料边际。量化这些稀疏日报能否缩小时阈值计数K的兼容集合，及需要多少日报才认证指定风险频率。

八燃料报告为 `[coal, gas, oil, other, nuclear, hydro, wind, solar]`（列次从冻结数据映射中读取）；固定演示EF为 `[1000,400,800,400,0,0,0,0]` g/kWh。每个已报日及所有未报小时残余池，只由燃料边际推导H/G和活跃支持M，使用粗 H/G/M 计数锐集。所有块的集合作Minkowski和，保留孔洞。无容量、爬坡、跨区流或逐小时总发电信息。

## 输入预算与采样计划

沿用V86的25区和2024-07至2025-12时窗，仅使用完整UTC日；月度边际从同一批完整日小时聚合，代表同期oracle粗月报，不是官方发布版本。目标阈值 `tau ∈ {100,300}` g/kWh；月尾频率风险为 `K/n ≥ {1%,5%,10%}`。

日报数量固定 `k ∈ {1,3,7,14}`，采样策略为：

- `evenly_spaced`：按月内日期均匀分散的确定性日程；
- `first_days`：连续抽取月初k日，作为聚集采样控制；
- `random`：每个地区月、k固定50个可复现无放回随机日程，汇报随机日程分布；
- `monthly_only`：k=0基线；
- `all_daily`：所有完整日均报告的上界对照。

采样日不按隐藏小时K、标签、逐日EF或后验结果选择；不做oracle主动选日。

## 指标、核验及解释

报告识别集跨度/n、指定频率的正证书/负证书/弃权率、实际K包含率、日报字段数（每日报告八燃料发电量）以及逐省分层。随机策略先在地区月内对50个日程汇总，再按月/省等权，不把种子或小时当独立系统。`all_daily`与V86每日燃料边际信息前沿对照；不同于V86的每日H/G/Q，V201的附加预算是k日八类逐燃料总量，不含日内Q。

要求所有真实代理K均落在每个报告预算的兼容集合内；稀疏集合必须包含all-daily集合，all-daily集合包含monthly-only集合。违反任一处则停，不修边界后继续计分。该实验是同期逻辑识别，不是预测误差、概率coverage或新地区保证。即使集合明显变窄，仍需另行证明日报能合法获得、统计边界匹配，并在中国源数据/独立小时标签确认。
