# TransCIF 研究定位：有限信息下可信、可迁移的 CIF 基准框架

日期：2026-10-23。

## 用户明确的目标

在有限已知信息条件下，特别是中国等缺少现成 CIF 产品/历史的场景，使此前未开展 CIF 预测的地区获得可信预测；建设统一、可迁移的 CIF 预测基准框架。

此前关于月度统计、机制歧义和风险决策的讨论是这个框架内的候选方法与分析，不替代这一总目标。当前已有代码与实验只构成参考原型，不能因框架定位确定便将计划写成已实现。

## 建议的论文定位

**TransCIF: A Unified Benchmark and Transfer Framework for Carbon Intensity Forecasting under Limited Local Information**

核心问题：给定一个新地区在预测起点实际可获得的信息，能在多大程度上预测其未来电力碳强度，误差和不确定性怎样随信息条件及跨域差异改变？

统一指统一数据契约、核算边界、输入可见性、迁移/时间划分和评估接口；基准可容纳多个模型。主迁移轨道使用源域学习的共享参数，目标输入采用合法公开信息。若使用目标数据校准或更新参数，另行声明适配轨道。

“此前没有做过 CIF”需进一步分解为没有产品、没有历史 CIF 标签、没有逐时电力遥测，不能混用。

## 建议的信息轨道（尚待实施）

| 轨道 | 允许的目标输入 | 研究意义 |
| --- | --- | --- |
| S0 结构信息 | 已发布年度装机/能源统计、外部 EF、位置和日历 | 最低信息条件下的水平与季节性先验 |
| S1 公开预报 | S0 + 起点已签发、可获得的天气预报 | 无目标电力逐时遥测的条件预测 |
| S2 粗统计增强 | S1 + 起点已发布的历史月/季发电、能源占比等 | 中国等低频统计场景；检验低频信息能帮助什么 |
| S3 电力遥测可用 | S2 + 目标历史逐时发电/负荷等，但不提供历史 CIF | 无 CIF 标签但有运行信息；与严格无遥测分开 |
| S4 CIF 历史可用 | 明确的目标 CIF 上下文或少量标签 | 历史输入、few-shot、校准或本地监督参照 |

地区缺少某一项统计时记录实际字段，不强行假设全部信息齐全。负荷预报、天气集合、进出口信息是额外显式开关，不能默认每个地区可获得。仅有天气、缺少负荷预报的路径应有独立合法方法和误差报告；当前实现尚不支持这一降级路径。

粗统计用于特征、推理条件化还是目标参数更新必须记录。公开 EF 或配置若由目标隐藏 CIF 标签拟合，不能进入主轨。已经拥有逐时分燃料发电、再按 EF 重建历史 CIF 的情况属于电力信息更充分的轨道。

## “可信”应对应的证据

1. 信息可信：来源、发布时间、统计区间、修订和假设明确；配置、天气、负荷、EF 均可追溯。
2. 核算可信：发电侧/用电侧、直接 CO₂/生命周期 CO₂e 和时空单位明确；不混合成一个排行榜。
3. 迁移可信：目标小时标签不进入源训练、选模与校准；留区域、留整国、跨年检验；覆盖重叠区域成组排除。
4. 统计可信：逐区域误差、相对合法基线表现、区间宽度/覆盖、分组失效情况；不将所有小时或训练种子视为独立电网。
5. 使用可信：信息不足或域外风险高时，可输出更宽不确定性、降低推荐率或回退，并报告代价。

不合并成未经验证的单一“可信分数”，也不把可追溯文件等同于准确预测。仅源域校准不能自动保证任何新地区的覆盖。

建议首版延续发电侧直接 CO₂ 主轨，以减少核算混杂；面向实际充电核算的用电侧另设轨道，显式处理交换与储能。这个选择是实施建议，不是用户已经确认的边界。

## 核心基准怎样建立

第一层是在有可核对小时参考的数据丰富地区，执行受控目标信息屏蔽；按 S0–S4 比较相同源数据、监督信息和搜索预算下的方法。把某地区视为此前未做 CIF 的新地区，其隐藏小时标签只用于最终评分。

若月统计从隐藏小时标签人工聚合、发布时间由实验假设生成，应称为受控信息预算实验，不能冒充真实统计发布档案。真正部署回放另要求原始发布证据。

第二层是中国等实际数据稀缺地区的部署研究。若只有日/月参考，检验对应尺度的一致性、统计来源、物理约束、源支持及假设敏感性；独立小时验证仅在得到相应参考时开展。日/月聚合吻合不验证小时形状或小时概率覆盖。

对于由发电与 EF 重建的参考，分别报告“统一边界重建标签预测”和“独立机构参考核验”，避免相同公式造成的循环验证。

基线至少包括同轨合法常数/季节先验、同信息树模型、公开协变量神经网络、确定性物理方法与当前概率调度参考。TimeXer 等作明确的同信息适配。需要目标历史 CIF 的 persistence、CarbonX 原版及本地监督结果进入 S4 参照，不能参与 S0–S2 同信息排名。

统一接口不要求全部方法都有所有输出。点预测方法比较点误差，概率方法另比较 proper score 和覆盖/宽度；所有方法均报告适用输入、失败和预算。

## 应形成的三类论文贡献

- 任务与基准：面向有限目标信息的明确 CIF 冷启动定义、按发布时间约束的信息轨道、核算一致的跨域数据与评测。
- 参考方法：用公开配置、可用预报及允许的粗统计连接源域知识与目标地区；验证信息缺失、结构差异和运行机制差异下的行为。
- 实证认识：哪些信息最有价值，何种地区可迁移，何种情况下失效，哪些结论只能在日/月尺度成立。

仅整理数据和统一 API 不足以承担强基准贡献；需要真实有代表性的任务、强且公平的基线、可复现工具和能够改变既有认识的分析。也不必先证明每个模型组件都首次出现，才允许推进框架论文。

## 当前实现与目标的差距

已有：公共输入/标签分离、as-of 选择、源域训练与选模、原型跨域协议、物理调度、点/概率评分及审计产物。

待建：完整真实合规数据、统一信息轨道与可变输入、缺负荷预报的合法预测路径、多方法基线适配、独立核算参考、系统性跨国/跨年基准、中国案例的分尺度证据。

当前四人工配置是工程测试和方法开发，不是上述框架的已完成真实基准。现有 FuelDecomp 历史成绩与 v0.2 原型也不能跨协议直接合并。

## 原始文献定位

- [DGCFM，WWW 2026](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf)：已有跨域/zero-data 研究，需逐字段比较推理输入。
- [CarbonX](https://arxiv.org/html/2510.01521v2)：使用目标历史 CIF 的统一模型，不能把 zero-shot 微调设置等同于无目标遥测。
- [GIFT-Eval](https://arxiv.org/abs/2410.10393)：说明统一评测基础设施、多任务和泄漏控制本身可以是研究载体；不能直接替代 CIF 专门的信息/核算协议。
- [fev-bench](https://arxiv.org/abs/2509.26468)：强调协变量任务、可复现接口和有统计依据的聚合。TransCIF 须在此基础上贡献 CIF 冷启动与核算可比性的专门设计。
