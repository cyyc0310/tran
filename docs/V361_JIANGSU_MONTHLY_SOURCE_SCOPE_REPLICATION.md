# V361：江苏全年监管办与NBS月发电统计范围复核

日期：2026-10-30。此项是V360的来源差异复核，不是CIF预测实验。目标是检查河南单省发现能否在另一省的多月官方监管通报中复现。

## 配对规则与数据来源

国家能源局江苏监管办公布了2024年12份“江苏电力运行情况通报”，列全省月发电量。NBS省级月数据由公开转录其统计表的中商产业研究院数据库读取，并保留了每月页面URL。由于国家统计局官方JavaScript入口在当前环境连接关闭，NBS数字尚待从该入口原始导出复验，所以这次结果是来源审计线索，不作为正式CIF实验输入。

按NBS发布窗口匹配：2024年2月的“当月产量”为空、累计产量为1000.30亿kWh，视为1—2月累计；与江苏监管办1月589.61＋2月450.04=1039.65亿kWh相比较。2024年3—12月逐月配对。所有逐期原值和来源URL见[CSV](../data/china/jiangsu_nea_nbs_monthly_scope_check_2024.csv)。

## 结果

- 11个匹配报告期中，NEA全省月值都高于NBS规上工业值。
- NBS报表值与NEA值的等期平均差为6.25%（按NEA值为分母）；按逐期差额简单求和为408.76亿kWh，对比NEA月值总和6703.76亿kWh为6.10%。
- NBS的2024年累计值为6330.7亿kWh，较NEA年累计6703.75亿kWh少373.05亿kWh（5.56%）。NBS当期/累计字段不能混成同一个加总恒等式：11期当期值之和为6295.0亿kWh，比年累计值少35.7亿kWh。

逐期差在方向上稳定，扩大了V360“两个省同月来源差同号”的证据。但这并不能将差额认定为规下发电：两来源可能在企业覆盖、纳入电源、统计时点、修订和累计核实方面均不同。NBS官方答复明确说明，企业名录范围会变化，月度当期值相加可能不等于累计值，累计值还会随复核更新。

## 解释与路线

V361增强了一个数据合同结论：NBS规上月量与监管办全省月量不能未经校准就联合视为同一物理供给边界。多源加宽的锐界可能是在反映统计总体差异；V359没有观察到区间效率提升，不能通过把这个差额重新命名为未知燃料组来制造预测收益。

下一步继续将NBS五类月量用作主预算，并让NEA月报作为单独来源敏感性臂。只有在目标标签的统计边界明确匹配后，才比较覆盖与宽度。若只能保留NBS规上数据，则小时尾风险的验证应以同范围可得小时排放/发电标签为准；否则需把来源与范围不确定性纳入预测区间，并接受区间可能很宽。

## 复核边界

- NBS数值是第三方对国家统计局地区月报表的转录，尚未对官方portal直接导出逐项复验。
- 仅江苏2024年，且监管办通报仅给总量，不含与NBS逐技术类别可完全匹配的明细；未做多省统计推断。
- 逐期差额简单相加受到NBS当期数据与累计数据不严格可加影响，不能解释为年度缺失发电真值。
- 没有读取小时CIF目标，没有计算预测覆盖、区间效率或新算法收益。
