## 哪类信息可能真正约束剩余风险

1. **只有日/月总量。**可更新过去聚合碳水平、组成及总量动态，仍缺燃料如何在小时之间分配。V16已表明更频繁反馈没有自动形成区间效率优势。
2. **合法日前的发电与非排放电源计划/预测。**若同一统计边界、覆盖全部需要扣除的电源，差值可帮助约束未来排放活跃份额；它比独立历史netG更接近需要的对象。仍须保留预报误差及内部煤/气/油差异，不能把差值直接当准确煤电量或碳强度。
3. **机组支持、必开必停、限制和可用能力。**可能排除先验允许、当地却不可能的燃料替代或大幅出力；这是V15中未观测油/other歧义的候选约束。仅有装机、过去没发电或一次申报不等于未来可靠硬上限；区域归属、多燃料、存量变化、修正和设备可用性都要有截至时点依据。
4. **固定时段的排放等效能量与G汇总。**可识别过去块加权CIF并携带日内时间定位，适合先在现有源数据模拟价值实验；本次官方字段核查尚未发现已经可匿名下载的T8历史包。它属于明确新增的粗CIF信息预算。

这些是研究推断，不能从规则条目直接推出它们已足够实现可信小时预测。尤其“火电”与本代理正EF组不是同一认证字段，核电、水电、储能、生物质、进口及自备电不能凭名称粗略相减。系统负荷也不等于区域正部发电G；净流入、损耗和储能口径改变比值。

## 后续数据合同需要落到什么程度

对每个实际候选字段，至少保存原始发布/修订时刻、预测对应时段与区域边界、物理单位及毛/净/上网口径、缺失规则、原始文件哈希和访问/可共享条件。若只有最新修订版，不把它回填到过去当时可得的数据。数据提供方约定的发布权限与论文复现方式分别写明；本记录没有联系任何机构或发送数据请求。

实验应让所有同预算参考获得字段的信息闭包：若给t/c且有可靠零油与固定EF，就等价包含小时CIF；若给T8，就包含过去块加权CIF。前者必须标为本地小时响应预算，后者标为粗响应预算，而不是利用字段名继续宣称完全无CIF信息。

在取得真实档案前，V17只能回答“某种模拟发布包在已查看源区是否有预测价值”。若出现增量，再核实该包能否由真实发布渠道提供；若现实不可得，就须保留为信息价值/制度设计结果，不能把模拟可得性写成中国落地验证。
