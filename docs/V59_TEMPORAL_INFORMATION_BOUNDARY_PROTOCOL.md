# V59 小时 CIF 的时间粒度信息价值边界

日期：2026-10-27。对已打开六个 EIA 区域2026H1代理标签做事后部分识别，不用于模型训练、选择或预测。所有 fuel margins、hourly totals 与代表小时thermal share均取自当月真实标签，属于 oracle sensitivity；公开月度输入不包含未来当月真值。

## 固定场景

以等小时 CIF 月均值为 estimand，比较：

1. 月度燃料边际、没有小时总量约束的解析边界；
2. 每日燃料边际、没有小时总量约束的逐日解析边界；
3. 月度燃料边际 + 每小时总发电量的 LP sharp bounds；
4. 每日燃料边际 + 每小时总发电量的 LP sharp bounds；
5. 月度燃料边际 + 每小时总发电量 + 每日一个/两个/四个固定UTC小时的已知thermal总量的 LP sharp bounds。

固定代表时点为每日12 UTC；06/18 UTC；00/06/12/18 UTC。不根据CIF误差选时点。逐小时thermal约束是一个热电组总量而非燃料细分，所有场景始终保持月度八燃料总边际。LP目标为月内等小时CIF平均，变量是每小时八类非负发电量，所有边界需包含真实标签平均并检查 HiGHS 状态。

## 解释

这些输入全来自目标月事后标签，回答的是信息上限：若未来能合法取得哪类局部时序摘要，怎样收窄月度CIF兼容集合。它不证明该字段在中国可获得，也不把oracle边界宽度当作概率预测区间或有限样本覆盖保证。标签是EIA固定EF正部报告发电proxy。
