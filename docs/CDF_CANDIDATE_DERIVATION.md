# 观测几何与预测CDF风险联合分配：候选的推导和边界

本文件描述实际实现的研究候选，不是首次提出最优重要性采样或新定理的声明。代码为 `inference_v2.py` 中的 `goal_cdf_*`，实验约定见 `GATE2_V2_PROTOCOL.md`。

## 从分布估计目标到提议分配

给定公开观测后的目标后验为π(z)，最终预测为Y=f(z)。对坐标j及阈值t，CDF是后验期望

\[
F_j(t)=E_\pi[\mathbb1\{f_j(z)\le t\}].
\]

自归一化重要性估计的渐近方差包含

\[
\int \frac{\pi(z)^2}{q(z)}
 [\mathbb1\{f_j(z)\le t\}-F_j(t)]^2\,dz.
\]

这是标准SNIS理论的应用，并不赋予有限预算的精确保证。若发现的近似模式为k、质量m_k、模式内提议已经理想化匹配，那么各模式风险r_k下，方差目标可近似为Σm_k²r_k/α_k。对Σα_k=1，标准拉格朗日推导给出α_k∝m_k√r_k。这与已有Neyman分配/目标导向重要性采样属于同一原理，不能把这一公式当作独立创新。

需严格区分随机混合和固定分层。这里的指标风险包含 `P_k(1-P_k)+(P_k-F)^2`，即模式内与模式间两项；不能直接等同于只有模式内方差的固定分层Neyman分配。本实现使用随机化Sobol选择混合标签，计数近似平衡，且各Gaussian分量重叠并包含固定防御先验，因此独立随机、分离分量的近似目标仅提供启发式动机，不是实际QMC估计器的最优解。[He与Owen的混合重要性权重优化](https://arxiv.org/abs/1411.3954)是必须对照的直接近邻。

## 本实现如何形成可计算近似

1. 从标准正态源先验抽取低差异pilot，仅用likelihood挑选分离中心。
2. 对中心做收费的有限差分，估计负log后验的对角曲率，得到局部协方差C_k和一次截断Newton修正。Laplace质量为中心后验密度乘局部体积近似。
3. 用同一差分得到未来轨迹导数J_k。局部预测通过delta方法近似为Gaussian；在时间、DCT或Haar坐标下计算各坐标均值及方差。
4. 各坐标的阈值是pilot模型预测的0.1/0.3/0.5/0.7/0.9分位点，不使用真值。局部概率P_kjt为Gaussian CDF，零方差时使用确定性指标。
5. 混合CDF近似为F_jt=Σm_k P_kjt。局部指标风险为

\[
r_k=\operatorname{average}_{j,t}\lambda_j
 \{P_{kjt}(1-F_{jt})^2+(1-P_{kjt})F_{jt}^2\}.
\]

6. 依据m_k√(r_k+floor)分配质量，并保留10%的原始近似模式质量；完整提议再混入25%标准先验以保留全局支持。最终样本使用整个冻结混合密度q，而不是被抽中分量的密度，按p(z)L(o|z)/q(z)加权。

上述做法将观测后验几何、预测边际分布目标和有限预算联系起来，是本轮自己设计并实现的候选。其科学价值需要相对于共享几何的强基线证明，不能由组合本身保证。

## 能检验和不能声称的内容

- `local_mixture_qmc` 与CDF候选共享pilot、中心、局部几何、差分次数和最终样本数。它是检验风险分配增量的直接消融；Sobol先验和SMC用于检验整个局部提议是否必要。
- 与 `goal_*` 均值风险分配比较，才能判断“面向分布”是否优于“面向曲线均值”。
- r_k只是有限阈值的边际CDF误差近似，不是全实数范围的积分误差，也不是完整24维联合分布的误差界。DCT/Haar坐标的边际CDF目标与时间坐标的边际CDF目标不同。
- 对角曲率、单步中心更新、有限pilot模式发现及Laplace质量都可能错误。防御先验保留支持，不保证有限预算已经找到遗漏模式。
- 低预算高维场景可能只容许一个收费中心，此时质量分配没有可操作空间。应如实报告，不把与基线相同的结果写成改进。
- 固定尺度权重表达开发效用假设，不能当作粗观测提供了新的高频证据；完整正交变换本身不能增加信息。
- 本轮没有证明新的收敛率、跨域覆盖率或对真实中国CIF的准确性。若候选仅在自己设计的简单反例上有效，或不能超过标准低差异采样，当前算法论文主张仍不成立。

真正可能构成后续方法贡献的内容，是经过验证的误差诊断或更可靠的预算分配机制，在不同观测算子、模式几何与观测年龄下产生可重复增量；这仍需要进一步证据。
