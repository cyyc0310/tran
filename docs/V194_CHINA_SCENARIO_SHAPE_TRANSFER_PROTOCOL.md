# V194 冻结协议：中国模型投影中的月均锚定小时形状迁移

状态：**预注册后可运行；目标小时情景文件目前尚未下载或打开。** 本轮是针对2026新公开中国逐小时CIF投影的模拟世界压力测试，不是中国真实运行数据验证，也不是原创算法声明。

## 问题与严格适用范围

问题：在**已知目标月等小时均值CIF**的oracle上限条件下，其他省份的中心化小时形状能否迁移到完全未用作供体的目标省？同情景和留一情景供体之间是否稳定？若形状仍无法迁移，则仅有月度燃料发电量（通常比目标月均消费侧CIF信息更弱）不会自动识别小时形状。

目标月均值由目标月所有小时CIF计算，是事后粗锚，不是月初可用输入。任何结果只称**oracle月均CIF条件下的小时形状重建/风险压力测试**，不能写成月报燃料统计的月前预测、真实省份小时准确率或校准保证。情景小时标签由同一GTSL/PSOS/CEF投影模型生成，不当作独立实测真值。

## 数据范围与冻结前资料

数据源为Li et al. 2026 *Scientific Data*配套Figshare v3（CC BY 4.0；数据DOI `10.6084/m9.figshare.28953545.v3`）。五个情景S1–S5、八个年份2025/2030/…/2060、31个省级列；小时CIF单位tCO₂/MWh，输出报告四位小数。

协议冻结前只检查了原始数据注释PDF和输入参数工作簿。没有下载、查看、哈希或汇总任何五个CEF小时情景文件。原始说明称行按一年小时顺序，常年8760行、闰年8784行；具体`Time`列、月份边界、缺失值和省份列将在输入预检确认。若不能确认从年初起连续排序或不能建立公历月份索引，停止月级评分，不猜测修补。

## 外层分割与信息预算

1. 主轨道：对每个情景×年份×目标省`q`做**省身份留一**。目标省在该query的全部源供体中禁止出现；目标小时序列只可通过预先定义的目标月份均值锚进入预测，不允许目标小时形状、其它月份小时或目标省其它情景小时进入供体池。
2. 同情景供体轨：固定每个目标月30个供体档案，即该情景/年份/月份下其余30省各一条小时形状。
3. 留一情景供体轨：目标省`q`在S1–S5的全部小时记录均排除；供体来自其余四情景的其余30省。每query固定抽30条形状档案，按情景分配8/8/7/7条、无放回、确定性seed，四情景均有代表。该轨道与同情景轨的源数量相同，因情景覆盖不同而另表报告。
4. 同一省在另一个情景的数据不得被用作目标小时或供体，防止模型的省级结构信息泄漏。供体省份、情景及profile ID完整封存。
5. 小时CIF与目标月均值处于同一个公开工作簿，故文件级“没有读取目标小时标签”无法成立，也不作此声明。实现须将预测函数签名限制为`target_month_means`与供体profile；目标全小时数组走独立评分容器，所有预测 artifact 完成并封存后才进入评分函数。另以保持目标月均值不变的目标小时置换证明预测值只依赖被允许的粗锚，不依赖目标月内排序/形状。此干预是功能隔离检查，不是数据发布vintage或标签访问的密码学证明。

## 固定方法（无结果后选择）

每个目标月均值`μ_qm`及每条供体月均值`μ_pm`均由相应完整小时月序列计算；供体形状`r_ph = C_ph − μ_pm`。

1. `constant_anchor`：所有小时预测`μ_qm`，零形状基线。
2. `all30_mean_shape`：`μ_qm + mean_p(r_ph)`，同情景30源或跨情景固定30档案。
3. `all30_shape_law`：等权粒子`μ_qm + r_ph`，报告点wise经验分布、CRPS和central90区间。
4. `nearest5_mean_shape`与`nearest5_shape_law`：按`|μ_pm − μ_qm|`选最近5条供体形状，分别计算均值预测及等权经验分布。最近数固定为5，不搜索k。
5. `permuted30_shape_law`：把all30每条供体月内中心化小时形状分别按冻结seed随机置换小时顺序，再按方法3输出；保留供体月内边际值、打破供体小时与目标小时的时间对齐，是预设负控制。

不按目标细小时标签选择供体、方法、阈值或情景。若数据实际有负值，不裁到0；单位换算后保存无裁剪预测，物理界限只作输入审计，不用于优化。

## 评分、分析单位与屏蔽检查

- 每月对全部小时报告 level MAE（应由精确oracle均值约束至数值误差附近）、中心化 shape MAE/RMSE、原始小时MAE/RMSE；对`*_shape_law`另报小时CRPS、nominal central90经验覆盖、宽度及Winkler。名义90只是经验区间定义，不是有限样本或目标省覆盖保证。
- 先每目标省等权，再分别按scenario/year显示结果；scenario/year与月块用于配对描述，不把小时或省年情景组合伪作独立系统。给出逐省、逐情景表及所有缺失分母。
- 月内目标标签置换负检查：在保持每个目标月`μ_qm`不变时，对目标月小时标签做置换，所有预测必须逐值不变；变动则说明意外读取了目标形状并使run作废。
- 输入检查：五文件版本/哈希、8 sheet年份、31省列、8760/8784长度、时间顺序、finite值、单位和月份小时数。CIF输出四位舍入会限定可复算精度。
- 预测seal包含协议/代码/数据hash、角色、粗锚来源、供体及method。seal完成后才加载目标小时评分矩阵。完整审计独立复算数据分割、所有月份锚、各方法首尾查询与全量核心分数、coverage/Winkler及跨scenario 30源抽样。

## 解释和停止规则

- 只有shape-transfer在不同省、情景、年份上相对`constant_anchor`稳定改善，并且经验区间表现比打乱负控制有信息，才保留“小时形状可由异地供体迁移”的假设；这不是算法新颖性门槛通过。
- 如果同情景有效、留一情景失效，只能说明对投影情景偏移脆弱；不得汇总成普遍中国迁移。
- 如果同情景都无效，停止追加普通donor/最近邻/树模型搜索；优先回到月度信息未识别形状的边界。
- 如果预测在目标月内置换检查失败、时间索引无公历边界、同一省跨情景泄漏或标签预先打开，保留失败归档，不能降级声明后继续评分。
- 即使结果很强，剩余必要验证仍是：用户真实月表的列名/发布版本合同、至少一个真实或经授权的中国小时计量标签、以及真正前向的月报可用时点。此投影数据库只能作单独模拟挑战集。
