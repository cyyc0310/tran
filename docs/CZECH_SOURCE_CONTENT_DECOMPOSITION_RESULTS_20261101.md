# 捷克来源增量拆分：直接头受益于捷克特征，强重组未受益

日期：2026-11-01。按[拆分协议](CZECH_SOURCE_CONTENT_DECOMPOSITION_PROTOCOL_20261101.md)完成r4。该轮在原五国开发目标上，分别改变小时训练来源和风险校准来源；PX是从其他四个源国按捷克对应时段等量抽样的伪来源，作为源小时数量/同权来源槽位控制。目标标签在15个训练臂预测文件全部封存后才评分。

## 控制审计

- CZ映射后的2022小时训练行7,344、2023H1校准行4,344；每个PX样本按对应时期严格同样本数、无放回抽取，固定种子和行身份保存在证据包。
- 三个训练池（old4、old4+CZ、old4+PX）与三个校准池交叉组成九格，每个原五国目标各自训练和预测；模型、参数、目标特征、分区和概率规则不变。
- r1曾在超出项目声明的环境（NumPy 2.4.5、pandas 3.0.3）运行；BE `direct_history`与旧预测不匹配。r4改用项目范围内的NumPy 1.26.4、pandas 2.2.3及scikit-learn 1.8.0后，40/40共同目标/方法点预测均在`1e−8`内复现，包括BE `direct_history`。正式结果采用r4；旧运行没有记录完整包版本，无法把该差异唯一归因于某一个包。
- 输入、代码、基线、输出文件哈希全部核对一致；15份预测封存后才读取目标小时标签。未运行代码测试。
- 后续为多PX种子增加了运行器参数并更新了协议；r4实际使用的旧版运行器和协议已按原记录哈希精确复原，保存在[r4源码快照](evidence/czech-source-content-decomposition-r4/source_snapshot/manifest.json)，避免后续文档更新覆盖历史运行代码。

## 训练来源内容对照

校准池固定为old4，保证点预测差异来自训练池。国家等权、国内月份等权，单位为gCO₂/kWh代理尺度。

| 方法 | old4训练 | 增加CZ训练 | 增加等量PX训练 |
|---|---:|---:|---:|
| 比例重组 MAE / 覆盖 / 宽度 / 区间分数 | 38.48 / 88.67% / 192.10 / 292.42 | 43.33 / 92.16% / 232.30 / 296.28 | 38.50 / 88.67% / 192.10 / 292.83 |
| 直接最新头 MAE / 覆盖 / 宽度 / 区间分数 | 91.00 / 69.01% / 185.95 / 941.83 | 54.29 / 80.31% / 182.10 / 335.34 | 90.85 / 69.30% / 185.50 / 955.57 |
| 火电因子历史头 MAE / 覆盖 / 宽度 / 区间分数 | 39.37 / 86.02% / 174.69 / 315.80 | 96.45 / 62.22% / 174.65 / 1175.85 | 39.53 / 85.99% / 174.73 / 316.06 |

捷克的源小时内容对直接头有比等量PX控制更大的帮助，主要体现在水平预测；但它仍明显输给强比例重组（MAE和区间分数均更差）。该结果说明新源可能提供直接模型可利用的域信息，却不能说明整个CIF迁移流程改善。相反，捷克来源令重组与火电因子头恶化，存在清楚的模型依赖负迁移。

## 校准来源对照

固定old4训练模型后，只改变源残差池：

| 方法 | old4校准 | 增加CZ校准 | 增加等量PX校准 |
|---|---:|---:|---:|
| 比例重组覆盖 / 宽度 / 区间分数 | 88.67% / 192.10 / 292.42 | 99.13% / 343.04 / 346.63 | 88.73% / 192.51 / 292.48 |
| 直接最新头覆盖 / 宽度 / 区间分数 | 69.01% / 185.95 / 941.83 | 94.72% / 610.67 / 665.54 | 69.04% / 186.21 / 941.89 |

加入CZ校准标签能覆盖更多跨域尾部误差，但区间大幅变宽；强重组区间分数变差。等量PX残差池与old4几乎一致，说明变化来自CZ的残差分布，而不是单纯多了校准小时数。源校准只是一种经验迁移，不提供跨域覆盖保证。

## 研究判断

最有价值的可继续问题不是“多加一个源国是否平均变好”，而是**如何在目标无小时标签时识别哪些源国对哪一类预测器提供有效信号、哪些源国只会改变风险尾部**。不过，简单粗组成距离门控等旧方法未成功稳定解决该问题；本轮也只有5个开发国家，PX仅用一个预先固定抽样。故不冻结新算法，下一步应先对多个PX随机种子做稳健性检验，再将结果作为伪目标源筛选机制的开发证据。方法即使稳健，也须超过同预算强重组并在最差国家保持覆盖。
