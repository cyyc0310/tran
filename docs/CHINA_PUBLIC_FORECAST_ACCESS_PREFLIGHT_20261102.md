# 中国小时预测扩展预算：公开访问预检

日期：2026-11-02。该预检为双轨跨域迁移基准确认扩展输入能否作为一般研究者可取得的信息；只依据官方规则、政府披露和可公开网页，不登录交易平台、不使用市场成员数据，也不训练模型。

## 核心判定

现有已核验的省级滞后月发电量`M`仍是发电侧主预算，年度装机仍单列`M+C`。制度中写有预测/交易信息、保存期限，**不等于公众可免登录下载的历史预测曲线**。本轮没有找到可用于上海省级小时回测的开放、机器可读、带预测签发时间和历史版本的出力或联络线预测文件。因此暂不把`M+F`或`C1+Fflow`加入中国主预算，也不生成基于规则假设的模型结果。

用户进一步确认目前没有上海/浙江电力交易平台市场成员账号，研究仅使用公众数据。因此市场成员披露层的曲线不进入本研究预算；除非未来出现无需成员身份即可公开下载、且保留签发时间与历史版本的档案，否则不再把申请市场账号作为当前方法路线的前置条件。

## 两条轨道受影响的方式

**发电侧。** 上海月度火、水、核、风、光统计继续作为`M`，年度煤/气装机为独立`M+C`。交易文件提到的可用发电能力、交易限额或发电量合同曲线，分别是交易约束/合约信息，不能未经字段验证就当成物理分燃料预测。只有拿到逐技术预测、签发时间、目标交付时间、MW/MWh口径、历史修改版本及省级边界后，才可评估加入`M+F`的增量。

**消费侧。** 上海是受端城市，政府公布的2025跨省市场交易总量只能证明来源流量的重要性，不等于逐时毛受电、送端份额或碳强度。用户授权可查的历史分时用电数据、平台负荷曲线和省际交易曲线是不同字段；即使取得流量，也仍需每个送端小时强度、损耗和一致的消费分母。缺这些字段时只做流量约束/部分识别，不报告小时消费CIF的已验证预测精度。

## 采集准入合同

对于每条候选曲线，进入研究前需留存：公开URL或合规访问依据、权限层级（公众/已注册市场成员/特定主体）、原始下载时间、预测签发时间、适用时段和预测时距、历史归档规则、原始文件哈希、分类与区域映射、单位及时区、完整小时覆盖及缺失/修订状态。无法确认权限、发布时点或历史版本的文件，只能用作不可回测的当前样本，不进入 as-issued 前瞻准确度主表。

## 证据与限制

- 国家规则区分面向社会公众、有关市场成员、特定市场成员的三类信息；官方答记者问还说明信息披露平台管理市场成员登录账号，并在查阅前要求信息披露承诺书。[国家能源局规则](https://zfxxgk.nea.gov.cn/2024-01/31/c_1310763726.htm)、[官方答记者问](https://www.nea.gov.cn/2024-02/07/c_1310763802.htm)
- 上海正式细则载明平台预测曲线范围、信息留存期限及平台访问安排。[上海电力中长期市场实施细则，华东监能市场〔2026〕24号](https://hdj.nea.gov.cn/dtyw/tzgg/202603/P020260331593974942947.pdf)
- 上海监管局的公开报道仅确认2026年上半年市场发布会介绍电网运行和三季度电能平衡预测，没有附逐小时预测档案。[发布会报道](https://hdj.nea.gov.cn/dtyw/jgdt/202607/t20260727_305426.html)
- 上海政府答复披露2025年长三角市场购电量76.3亿千瓦时，但未给出来源逐时结构。[上海市发改委答复](https://fgw.sh.gov.cn/fgw_zxwyta/20260603/a916ea02b80d41949fc8f480795437f3.html)
- 浙江官方披露附表列有预测条目，但“公开”在国家规则术语中指向有关市场成员。[浙江披露附表](https://zjb.nea.gov.cn/dtyw/tzgg/202512/P020251220333999314238.pdf)

结论仅限于本次官方公开网页检查：没有找到可直接纳入普通公众回测的省级小时预测vintage。这不证明市场成员账户或经正式授权的数据渠道不存在；如用户或合作方可合规取得对应曲线，可按上面的采集合同做字段级预检，再分别推进发电与消费轨道。
