# V60：中国省级月度电力数据审计与可验证性边界

日期：2026-10-27。对 Ember 当前公开的省级月度 CSV 做结构与算术审计，并把其2022年省级发电侧因子与生态环境部/国家统计局2022省级消费侧因子作描述性比较。脚本为 `scripts/audit_ember_china_monthly.py` 和 `scripts/compare_ember_mee_annual_coarse_factor.py`；原始下载、SHA-256、覆盖和表结构结果在 `results/china-monthly-ember-audit-r1/` 与 `results/china-monthly-ember-audit-r2/`。

## 数据实况

本次实际下载的月度 CSV 最后修改时间为 2026-10-22，覆盖 2016-01 至 2026-09，含 31 个省级地区加一个全国汇总。数据每个省月有8类非聚合电源（煤、气、其他化石、生物质、风、光、水、核），同时有14种源分类，其中聚合行包括“风光”“可再生”“化石”“总发电”。总计 57,792 行；4,128 个地区月（32×129）均有完整8类电源和总发电行。

对总量行按 `Emissions (MtCO2e) / Generation (TWh) × 1000` 重算碳强度，和CSV给出的 `Emissions intensity (gCO2e/kWh)` 最大绝对差仅 **0.00050 g/kWh**，与字段显示精度一致。八类源的月发电量之和与总发电量最大差 **0.003 TWh**。这些检查证明文件内部字段算术吻合，**不证明排放数据独立、估计准确、口径完整或可重建小时结构**。

Ember的[数据方法说明](https://storage.googleapis.com/emb-prod-bkt-publicdata/public-downloads/ember_china_generation_methodology.pdf)直接揭示了重要出处：国家统计局月报只覆盖规上企业，火电按一个总类发布，分布式太阳能有漏报；Ember组合NBS、CEC、NEA、Energy Institute、Carbon Monitor、装机数据库与ERA5，做月度校正/分解。其省级煤、气等月发电拆分使用装机结构、全国燃料边际和迭代比例拟合；光伏分配使用天气/容量模型。CSV不是“所有省每月都直接观测到每种燃料”的等价物。

当前下载的数据文件没有历史发布版本链。文件记下 `Last-Modified` 与哈希后，可以冻结本次快照做回溯描述，但不能据此重建某个过去预测起点当时可见的版本。当前版本修订值若回填到旧月份，会造成时点穿越。用户提供的月表来源、原始表头、单位、发布日和修订方式仍需单独做数据合同；不能从字段看起来细，就推断发布时点合法。

## 与官方省级年因子的同年比较

把Ember各月燃料排放与发电量在2022年内求和，计算 `ΣEmber排放 / ΣEmber发电量`；再与V52记录的MEE/NBS2022省级电力因子对齐，30个省份的相关系数为 **0.930**，但Ember发电侧强度平均高 **98.9 g/kWh**，平均绝对差 **110.7 g/kWh**，单省差值范围约 **−117.9 至 +229.8 g/kWh**。两者相关说明省际空间排序可能共享强信号；偏差也说明不能直接混作一个响应变量。

这是**不同估计对象的描述性对比**，不是Ember或MEE谁更准确的检验：MEE因子按其官方方法涵盖消费/净调入等边界，Ember此处是生成侧月度数据汇总；燃料排放因子、来源融合和边界均不相同。未经边界协调的线性“校准”不能作为发布中国小时CIF的科学依据。

## 小时级中国标签能否公开用于验证

本轮文献检索没有找到可直接下载、覆盖多省多年、具一致口径的中国实测小时CIF公共标签。近期一篇中国电网小时动态因子研究使用华南某市2024-08至2025-02超过5,000条小时记录，但作者说明数据由南方电网在保密协议下提供，具有商业敏感性，不能复用为公开 benchmark 标签。[研究与数据声明](https://www.mdpi.com/2227-9717/13/11/3393)。中国工程院期刊的江苏案例展示了2023年四个典型日、13个地级市的逐小时计算，但这属于稀疏典型日示例，不能充当连续跨年小时留出集。[论文](https://www.engineering.org.cn/sscae/CN/1177188236516242258)。CISPO-China 2025–2060则是模型情景投影，已用于V52模拟器压力测试，不能当实测真值。[Scientific Data论文](https://www.nature.com/articles/s41597-026-07272-6)。

另找到Carbon Monitor-China省级日度电力排放估算。2019–2020的31省日度CO₂工作簿可在Zenodo获取；逐省逐月归一化后，日曲线与全国日曲线完全相同，说明这个版本的本地日曲线是全国模板按月权重缩放，并未提供独立省内日变化；相关ESSD讨论稿也明确承认该局限，且页面标记修改稿未接受。更新页面称中国省级日排放数据已更新至2023年底，但下载需登录。2026年另有近实时日度排放框架覆盖2019至今，但数据按请求提供，也不是小时CIF。细节见[V61审计](CHINA_DAILY_POWER_EMISSIONS_AUDIT_V61.md)。

## 对 TransCIF 创新路线的影响

目前更可信的突破候选不是“从月报恢复唯一小时CIF”——V58/V59已证明信息不足——而是一个**信息预算明确、估计对象分开、能报告可识别边界的跨区冷启动基准**：

1. 公开月/年数据作为低频本地水平锚，但为用户原始表和二次估算分别建schema、记录发布版本与时间合法性。
2. 将生成侧CIF、消费侧CIF、碳足迹因子分开作为不同 estimand；不把Ember月值、MEE年值、CISPO小时情景拼成“同一真值”。
3. 小时预测的点与分布明确标为“源区小时形状先验补充”。月度信息自身只负责约束其可识别的部分，并输出其兼容集合宽度；不把跨区校准后变窄的区间说成月表识别出的确定性。
4. 用V58/V59在 EIA 有真实小时发电组成的区域做高频真值下采样实验；分层比较输入信息预算（年、月、日、小时总量、稀疏热电观测），并纳入可解释的调度/容量约束，评估均值、小时尾部和连续超阈风险。
5. 中国测试分为“公开月度数据的时点合法预测”和“仿真压力测试”两条证据，不把后一条包装成真实省份小时验证。若要检验小时预测有效性，需取得可复现的本地小时标签或数据合作授权；当前公开数据缺口是评估数据缺口，不是一个可以由算法绕过的缺陷。

当前的真实新增证据是：**中国省级月度多燃料数据可从公开二次数据集中取得，且其字段内部算术一致；但数据含估算/修订，跨估计对象与官方因子有实质水平差异，公开连续小时真值仍缺失。**它能支撑低频锚与信息预算研究，不能单独支撑可信小时尾部预测的实证结论。
