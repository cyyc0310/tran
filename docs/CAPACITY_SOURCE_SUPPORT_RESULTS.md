# 高煤支持未带来学习增量，剩余误差集中在月内组成变化

2026-10-31，Sol。按[协议](CAPACITY_SOURCE_SUPPORT_PROTOCOL.md)追加两组同数量供体，复用已批准的公开装机预算，固定原小时profile以免模板改变混淆因子学习。此轮全部是已查看国家和供体上的开发实验。

## 两组同预算供体的结果

2020年登记BA库存中，PACE煤/(煤+气)0.663847、LGEE0.592523，SRP0.091521、DUK0.428939；原7美国区最高0.431662。增加前一组确实扩展美国源支持，但不是显著扩大全球边界，德国自身已约0.661646。库存是软特征，不认证运营范围或物理缺席。

两组每个追加区都匹配训练3162小时、校准2951小时；原基底不抽样。三国9配置×14方法全部执行，目标预算不增加。下表为US→DE；宽度未做支持投影，与原装机点实验口径一致。

| 方法 | 原池MAE | 高煤追加MAE | 控制追加MAE |
|---|---:|---:|---:|
| 装机形状锚 | 125.78 | 125.78 | 125.78 |
| 装机HGB火电因子 | 122.44 | 126.43 | **121.90** |
| 源利用率＋装机 | 122.36 | 124.93 | 123.44 |
| 装机HGB直接CIF | 177.16 | 219.03 | **158.81** |

GB+US→DE，装机因子也从121.94变为高煤126.88、控制121.56。增加高煤支持并未带来学习增量，不能再把失败只归因于煤装机比例超出训练范围；供体还伴随其他结构、地域和时期差异，不能反过来宣称高煤支持具有负因果效应。

高煤池的US→DE简单macro覆盖92.64%、宽628.92；相应原池53.84%、宽268.97。装机形状锚的点完全不变，覆盖43.03%→59.86%、宽198.98→281.42。这些主要是校准误差分布改变后的加宽，仍非维持覆盖下缩宽。

所有9配置宏平均，高煤装机形状锚覆盖85.48%、宽362.33；原池80.81%、宽337.18。学习装机因子MAE原118.70、高煤119.66、控制118.24，全部仍差于简单锚85.12。原池监督更少，主要公平对照为两个同标签数量追加池，不能将原池差异全归于方法。

两策略各27个预测封存通过；每个目标的容量平锚/形状锚点值与原池精确相同；源不含US的5配置全部14方法精确相同。启动/结束输入与代码SHA、源匹配数量全部核验。[高煤证据](evidence/three-country-capacity-support-free-r1/manifest.json)、[控制证据](evidence/three-country-capacity-support-control-r1/manifest.json)保留完整负结果和不变性receipt。

## 事后oracle：误差不只在煤气水平

为选择下一步，另作明确使用未来信息的诊断，**不把oracle当可部署预测或可达到增益**。在每个地区内部，各模式共用当前月有效覆盖≥99%的行；并非所有地区取共同月份交集。原150组地区月份中135组通过，共99378小时，故US总体队列与主实验不同。德国US→DE使用相同完整6个月队列。

固定装机因子和源profile，分别替换真实当前月粗组成、月有效因子或逐小时对应量。有效因子按排放代理总量/火电量计算，未用CIF小时算术均值。US→DE诊断如下：

| 仅用于诊断的条件 | MAE |
|---|---:|
| 原装机形状锚 | 125.78 |
| 给真实当前月粗组成 | 120.43 |
| 给真实当前月火电有效因子 | 121.27 |
| 上述两者同时给出 | 116.07 |
| 给真实逐小时粗组成，因子仍为装机锚 | 48.62 |
| 给真实逐小时因子，组成仍为原预测 | 108.12 |

完整逐小时组成和因子同时给出可代数重构标签，误差约0，只作为恒等检查。各oracle收益有交互、不可相加，也不是因果分解或改进上限认证。

即便提前知道当前月平均组成和有效因子，德国误差仍有116.07；固定因子下知道逐小时粗组成则降至48.62。这提示当前均值小时模板遗漏的**月内逐小时组成变化（含日际变化）**比继续微调月平均煤气因子更值得优先检验。它不证明这部分变化能从月报或外国数据精确预测，也不证明天气一定有效。

诊断不训练新模型、不修改封存预测、不接触新确认国家。[诊断证据](evidence/capacity-error-oracle-diagnostic-r2/manifest.json)包含全部9配置、共同队列及来源；r2补齐metadata首尾hash、时间逐元素对齐和父seal核验，三个诊断CSV与r1字节相同，公式和数值未改。

## 下一轮重点

现在的三国重组参考主要使用平均24小时profile，尚未覆盖V7的完整联合轨迹机制。下一步先将既有源轨迹银行接入同一中国预算：源端学习热、水、核、风、光等联合小时变化，目标只给合法滞后月量和独立装机预算；未来当月真值仍禁用。

固定比较联合轨迹、打散各类相关性的独立轨迹、平均profile以及同预算直接analog/条件分位数，分清收益来自联合组成、非线性比值还是额外源标签。统一源标签队列、国家/地区先验、季节和发布时滞；源内留域定规则后再评开发国家。V7及普通analog本身是已有参考，接通它们不能直接叫原创。只有新的跨域学习或风险机制稳定超过这些参考，才考虑冻结和未知国家确认。

年度元数据质量仍是平行任务，见[年度版本审计](PUBLIC_CAPACITY_ANNUAL_AUDIT.md)。当前证据支持调整研究优先级，不支持已找到足以投稿的算法创新。302项相关测试通过，3个常量列StandardScaler数值警告保留披露。
