# V51：已发布燃料结构回看窗与小时风险的整源诊断

2026-10-27，预注册后计算。问题：现有三月全燃料EF proxy对源区小时p90/p99风险有正向整源留出信号；它主要代表近期状态，还是跨季节/年份更稳定的组成水平？本实验仅做特征时间尺度诊断，不训练生产模型、不选择预测方法、不声称覆盖增益或原创算法。

## 固定对象与输入边界

- 固定10个已反复开发的V50外部校准地区，以及同一源级风险响应：七outer标准化小时风险分数的地区中位数p90为主、p99为次。
- 仅使用V50 freeze中hash绑定的两张月表；只纳入同一source、完整公历月、月末及available_at均不晚于查询日的行。保留原注册查询日（2024年7–12月日历），每个source/query按period_start排序取最新合法1、3、6或12个月。
- 每月特征是八燃料份额乘既有项目EF `[1000,400,800,0,0,0,0,400]` 的和。对每个source，先在每个查询日对窗口内月特征等权平均，再对查询日等权平均。不得用未发布月份、目标/2025响应、PACE/LGEE或未查看地区。
- 每个窗口分别做固定截距＋单一标准化特征线性回归，10折leave-one-source-out；与每折相同训练源均值作基准。不得调参、筛选或移除地区，也不将小时、月、日期当作独立地区单位。
- 主要指标为p90的LOO MAE/RMSE；次要p99 MAE/RMSE、方向正确率及每个留出源误差。与已完成的3月结果并列，但由于看过该结果，整个序列均属探索性，不能把最佳窗口称为确认结果。

## 事前解释规则

- 若6或12月稳定优于3月，解释为粗组成风险信号可能更多表征慢变区域结构；不能据此推断小时尾风险可被局部校准。
- 若1月明显最好，解释为短期状态信号值得后续验证，但仍受小样本支持与发布延迟限制。
- 若各窗接近、不同目标分化或优势只由少数地区贡献，则不增加窗口选择器；风险信号不能晋级为条件区间。
- 不因该特征诊断对目标开封，也不调整V50任何预测/区间结果。

输入边界、响应来源和完整局限在运行后绑定具体冻结哈希；源区全是重复开发地区，统计显著性不作主张。
