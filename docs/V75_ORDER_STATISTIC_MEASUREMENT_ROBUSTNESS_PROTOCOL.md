# V75：风险定向G摘要在相对测量误差下的稳健认证

冻结日期：2026-10-28。V74发现低维次序统计摘要在部分历史风险决策下接近完整小时G，但使用精确输入。V75对相同V20七源1000日做有界相对测量误差压力测试，回答认证率是否依赖无限精度。误差水平是敏感性网格，不代表任何已测设备精度。

## 冻结队列与误差盒

沿用V20固定来源、日期、小时mask、EF支持、阈值和区块。每个输入标量的真值允许在观测值`xhat`的`[xhat(1−ε),xhat(1+ε)]`内，ε=0、0.1%、1%、5%、10%；各坐标独立取最不利端点，不利用协方差抵消。压力测试输入包括块碳能量H、块G总量、minG、S₂、L₁。S₂/L₁和块G总量共享小时G来源，但独立盒是保守鲁棒性假设。

对严格阈值τ，保守认证条件：

- K=0：`Hhat(1+ε) ≤ τ minGhat(1−ε)`。
- 整日K≤4：每个块都满足`Hhat(1+ε) ≤ τ S₂hat(1−ε)`。
- 整日K≥8：每个块都满足`Hhat(1−ε) > τ Ghat(1+ε)+(1000−τ)L₁hat(1+ε)`。

主要目标为V74最有希望的τ=900、K≤4/S₂；其他风险目标和阈值只作预先列出的敏感性。按源宏平均报告认证率，同时报1000日合并比例。误差增大时认证集合必须单调不增。

## 边界

这是输入误差盒下的逻辑压力测试，不是测量误差估计、统计置信区间、预测coverage或硬件成本研究。若EF、标签、分母口径或月/块发布时间不一致，误差盒不能修复estimand错误。当前中国公开月/年数据不含小时G与块H，因此通过也不代表月度-only可部署。
