# 严格五类伪目标条件门控：九国整国留出结果

按[冻结协议](PSEUDOTARGET_COARSE_CONDITIONAL_STACK_CN5_PROTOCOL_20261101.md)完成九国开发回测。目标信息严格限定为中国可用的火、水、核、风、光滞后月统计；小时代理标签中的其他可再生类别仍进入排放分母，但不输入模型。九个目标2024预测均写盘并校验SHA后才读取目标标签评分。

单位gCO₂/kWh；先在目标国内按月份等权，再对九国等权。区间半径使用源国伪目标2023H2交叉拟合绝对残差的90%分位数。数字只适用于固定EF发电侧代理和滞后统计模拟。

条件门控区间比比例重组窄约14%，但MAE高12.6%、覆盖低3.3个百分点、形状误差也略高；其区间分数好于比例重组，却未超过macro重组或等权集成。与等权集成相比，条件门控MAE高5.84 gCO₂/kWh（9.1%）、覆盖低4.0个百分点、区间分数高17.24 gCO₂/kWh。窄区间带来的分数改善不足以补偿点误差及覆盖损失。

## 失效集中在哪些目标

条件门控相对比例重组的逐国MAE（括号为相对变化）：AT 46.64（+0.4%）、BE 51.91（+12.9%）、CZ 163.21（−0.1%）、ES 31.71（−15.3%）、HU 88.63（+147.6%）、NL 77.25（−6.2%）、SE 13.53（+58.1%）、SI 114.43（−4.1%）、SK 42.59（+109.9%）。只在ES、NL、SI有明显点误差改善，且都不是稳定的全域收益。

CZ覆盖36.6%、HU覆盖79.2%、SI覆盖74.5%，门控没有修复三个主要欠覆盖域；HU、SK的点误差出现大幅退化。条件门控比比例重组窄，但其最差域风险没有消失，且与macro重组/等权平均相比总体并无优势。

## 研究决策

1. **伪目标粗组成门控不晋级。** 严格中国五类预算下，九国结果仍不支持将一般softmax stacking视为迁移创新；不得再围绕相同模型换惩罚、堆叠头或网格搜索。
2. **年度装机继续单列为信息预算，不当作方法贡献。** 中国相容的宽口径M+C已在同九国测试，因子头相对M改善仅0.35 MAE且覆盖下降；煤/气拆分在海外部分代理上有水平信息，但当前中国省级预算无该字段，官方消费标签结果也未显示稳定迁移增量。
3. **两种CIF目标分轨报告。** 本结果属于本地发电侧代理。消费侧CIF仍使用官方消费强度标签和单独评估；需要把跨区流量及流入电量来源碳强度纳入目标信息合同，不能由发电侧指标代替。
4. **论文现阶段贡献应是可复现基准与边界，而非新预测算法。** 可支持的结论是：有限五类月报、即使加入伪目标门控，也不能稳定识别CZ/HU等域的小时尾部风险。中国小时真值缺失，海外代理结果不能宣称中国省级预测已验证。
