# 月度组成适配的发电/消费双轨配对协议

冻结：2026-11-01，运行和目标评分前。本轮专门补足第四优先级中尚未配对的部分：已发布滞后粗月量驱动的月度适配，能否同时改善发电侧与消费侧小时强度预测，并改善覆盖—宽度权衡。

## 双轨估计对象与队列

- 方向：US→GB、GB→US；源2022小时标签拟合，源2023H1/H2用于误差校准，目标为2024。美国目标为七个BA，英国为NESO GB。目标和年份均已在此前研究中查看，本轮是嵌套开发回放而非盲测。
- **发电轨：**EIA-930/NESO小时燃料按固定EF计算的本地发电侧代理。
- **消费轨：**EIA/NESO发布的小时消费强度估计。该估计含跨区排放分摊，和发电轨独立拟合、评分，不能互换解释。
- 月度组成数据：美国目标/源使用EIA-923 BA月度净发电最终档案（2020–2024），GB使用NESO历史发电月量。仅按`t−2`的火、水、核、风、光统计可用；预测当前月组成的适配器只读取当前预测月`t−2`及以前观测。美国EIA-923为年度最终档案按滞后索引模拟，不是历史as-issued月报。

## 方法和防泄漏合同

比较不做目标小时监督适配：

1. **Observed M：**常规强基线，响应模型按源端`t−2`实际可见粗月量训练，目标使用相同滞后粗月量。
2. **Persistence / seasonal / local Ridge / source Ridge：**先以合法历史月量预测该小时所在月的粗组成；源端响应模型也只用各历史月份在预测起点可算出的组成预测训练。每个国家/BA的本地Ridge仅使用该区域截至`t−2`的粗月历史。source Ridge仅用源区截至2022年的粗月变化训练。
3. 各预测特征只包含粗组成、日历及粗组成×小时日历。固定EF重组、粗组成HGB与粗组成Ridge作为点基线；同一方法/标签轨由源2023残差估计位置偏差及全局90%对称经验半径。该经验区间不承诺跨国覆盖保证。

所有目标标签预测先写盘并封存，随后才加载/评分2024目标标签。逐月报告MAE、日内形状MAE、覆盖、宽度、区间分数；宏结果按国家等权并分别给出BA最差值。月度表不以随机小时作为独立样本计算显著性。

## 晋级门槛

适配候选只有在两种标签轨和两个迁移方向上均比Observed M及强重组至少一个主要点指标有可重复实质改善、形状不恶化，且90%覆盖不下降超过2个百分点、区间宽度/分数显示有效效率改善时，才考虑冻结。总体覆盖改善若依赖大幅扩宽，或任一主要BA仍发生严重欠覆盖，候选不晋级。该门槛不因结果修改。

## 边界

月量代表发电组合，不含消费者跨区电量来源和来源碳强度；消费轨实验只能检验“这些公开粗月量对消费标签是否有预测信息”，不能视作消费端可识别性解决。现有小时标签、EIA最终月量和GB→US/US→GB目标都是开发数据；不做未知国家确认。真实月度发行版时序和统计地理对齐仍由实际发布版审计单独判断。
