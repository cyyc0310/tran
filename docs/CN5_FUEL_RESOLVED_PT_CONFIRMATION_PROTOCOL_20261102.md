# CN5燃料组成响应头：葡萄牙盲小时响应确认协议

冻结日期：2026-11-02，任何目标强度分数计算前。法国和波兰小时确认已完成；意大利候选在目标标签分数计算前因`other_renewables`全时段为空而拒收。葡萄牙按**字段存在性、预测历史完整性和非标签误差覆盖**选定，不查看目标强度或模型误差。意大利原始字段完整性审计和停止原因保留在实验日志中。葡萄牙小时目标响应在本项目的跨国CIF研究中此前未评分。

## 固定任务

- 目标：Energy-Charts Portugal 2024当地小时的固定EF发电侧代理；时区`Europe/Lisbon`、小时分辨率。仅使用`t−2…t−7`火、水、核、风、光五类滞后月统计和日历。
- 训练：严格CN5九国2022小时燃料标签。源校准：九国交叉留国2023H2伪目标绝对残差等权90分位。
- 方法、模型参数和源校准沿用已冻结的`fuelshare_history`确认实现，不因法国、波兰或其他目标结果调整。本轮比较`anchor700`、比例重组、宏重组、火电因子历史头、直接历史头和燃料组成响应头。
- 先写盘封存全部目标预测、源半径、输入及代码SHA-256；校验后才计算2024逐小时目标固定因子标签。

## 固定分类与标签

- `coal`：结构性零。葡萄牙ERSE年度市场报告指出其燃煤电厂已于2021年关闭，故2022–2024目标窗不含燃煤发电。[ERSE 2022年度市场报告](https://www.erse.pt/media/hcpj5cur/report-ce-2022_pt_en.pdf)
- `gas`：`fossil_gas`
- `oil`：API没有独立油电类别；不单独推断，`others`按项目其他燃烧组代理并入`other`
- `other`：`biomass`、`others`
- `hydro`：`hydro_run_of_river`、`hydro_water_reservoir`；排除抽蓄
- `wind`：`wind_onshore`、`wind_offshore`
- `solar`：`solar`
- `nuclear`：结构性零；葡萄牙监管机构确认当地无核电站。[ERSE生产类型说明](https://www.erse.pt/en/electricity/functioning/production/)
- `other_renewable`：Energy-Charts响应未列独立此类生产类型，按接口结构零处理；未分类的`others`仍按上述固定规则进入`other`。

固定因子为煤1000、气400、油800、其他燃烧组400、水/核/风/光/其他可再生0 g/kWh。`others`并入EF=400的`other`是简化代理映射；无独立`other_renewable`生产字段按结构零处理也是接口假设。将代理标签与官方发电CIF或直接排放测量混同无效。跨境交换、负荷、残余负荷及抽蓄不进入发电分母。所有被映射的存在字段要求逐小时非空、非负；2024每月标签及`t−2…t−7`输入源月覆盖至少99%，否则在评分前停止。

## 评分与预先判断规则

报告十二个月逐月、冬/春/夏/秋分层、月等权宏平均和小时池化结果：MAE、日内形状MAE、残差偏差、90%经验覆盖、区间宽度及Winkler分数。候选只有相对比例重组和anchor呈现明确点误差或proper-score收益、宏覆盖下降不超过2个百分点且不在单季严重失效时，才作为后续多国可迁移候选；结果无论正负均不据此调参。

这是一个新的小时响应域，但只有单一国家与固定因子代理标签；不是中国小时精度验证，也不证明消费侧CIF迁移。低频日/年分析中葡萄牙如有出现，不改变本协议对“此前未评分的小时响应”的定义；论文将按完整项目历史披露这种域级边界。
