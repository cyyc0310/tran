# 滞后月度组成适配的发电/消费双轨结果

协议：[双轨适配冻结协议](DUAL_TRACK_MONTHLY_ADAPTATION_PROTOCOL_20261101.md)。复现脚本：[run_dual_track_monthly_adaptation.py](../scripts/run_dual_track_monthly_adaptation.py)。完整封存预测、逐BA结果与核验记录：[证据包](../results/dual-track-monthly-adaptation-r1/README.md)。

## 实验范围

在US→GB及GB→US两个方向，对本地发电代理与官方消费侧小时标签分别评分。美国BA月量来自2020–2024 EIA-923年度最终档案，GB用NESO历史表；模型按源2022训练，源2023H1估位置偏差、H2估加权绝对残差q90，评分目标为2024。输入严格按`t−2`月份统计索引；月度适配模型在每个预测月只用当时可见的历史月量。对`source_ridge`训练源响应头时按月份滚动拟合月度预测头，排除了预测月统计量进入其自身预测特征的泄漏。

共有80个目标预测文件、513,140个封存预测行；响应标签完整后共评分512,800小时。所有预测和区间先封存后评分；代码、输入及预测封存哈希均无差异，数值预测无缺失。目标年份与国家/BA均曾用于开发，不是盲测；EIA-923为当前最终档案的`t−2`模拟，不是as-issued实时回放。

发电侧GB→US是最明确的局部增量：MAE降低9.0%，覆盖提高1.1个百分点，区间只缩窄0.6%；59个有效BA-month中39个MAE改善，七个目标BA的等月MAE都下降。但宏覆盖仍只有89.8%，MISO发电覆盖从34%到35%，基本未修复。发电侧US→GB的MAE增益仅0.3%，而宽度上升约1.9%。消费侧方向不一致：GB→US MAE改善约3.2%，59个有效BA-month中34个改善，但BPAT平均MAE变差，覆盖只有73.8%，严重低于名义值；US→GB MAE恶化约10.0%，覆盖也下降。消费侧MISO覆盖仍仅约13%。

季节适配和源Ridge没有形成更稳的双轨结果。季节法在GB→US发电侧重组MAE也有改善，但加宽约13%，不满足有效缩窄；source Ridge在多项强基线上负迁移。直接粗组成HGB适配版本更不稳定。逐方法、逐BA与月份分数见机器结果表。

## 判定

本轮没有达到双轨晋级门槛，**不能宣称月报适配在保持覆盖的同时缩窄区间**。本地Ridge的有利结果集中于GB→US发电侧，消费标签方向发生反转；剩余的MISO尾部风险既没有消失，也未被粗月适配识别。较低区间分数的少数切片不足以抵消消费覆盖失效及跨方向不稳定。

这项结果收紧了第四优先级的结论：公开历史粗月量能够驱动一个可部署的本地组成适配步骤，但适配收益取决于标签轨道、迁移方向和目标区域。继续扫同类月度预测器或风险半径意义不大。下一步应把**真实发行版时间、同统计地理支持、发电/消费标签轨道**作为独立评测轴；当前NY州EPM到NYIS结果有明显边界错配，EIA-923也只是年终最终档案。若没有预测时可核验的BA/省级as-issued月报及同域小时参考，就无法证明真实在线适配增量或中国小时覆盖。
