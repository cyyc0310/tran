# V240 结果：EF阈值侧不确定性会消除小时总量的信息价值

协议：[`V240_EF_UNCERTAINTY_TEMPORAL_RISK_PROTOCOL.md`](V240_EF_UNCERTAINTY_TEMPORAL_RISK_PROTOCOL.md)。MILP：`scripts/v240_ef_uncertainty_temporal_risk.py`。解析证书：`scripts/v240_threshold_side_certificate.py`。结果：`results/v240-ef-uncertainty-temporal-risk-r1/`。

## 压力测试

沿用V239的16个2025完整BA-month和500 gCO₂/kWh阈值。三个正EF组独立取名义值±10%，零EF组固定为零；为了保守包络，因子还允许在每个小时改变。该集合宽于全月固定EF不确定性。64/64端点最优，16/16固定名义EF尾数见证包含在外包络，所有日/小时界嵌套成立。

在EF外包络下，日总量界平均宽728.4小时，小时总量界平均宽601.6小时；小时总量平均再缩窄126.8小时（加权相对日界减少17.4%，案例百分比均值17.6%）。相较V239名义固定EF的165.6小时，增量平均减少38.8小时，但大部分仍保留。12/16案例严格缩窄，范围63–354小时（另四例为零增量）。按月份平均额外收窄：4月162.0小时、7月94.4小时、10月117.0小时。

失效案例精准集中在PACE 4/7/10月及AZPS 10月。它们EF箱下的月均CIF区间跨过阈值500.0001；四例的外包络界都变成全月`[0, 720/744]`。剩余12个未跨阈值案例均仍有小时层收窄，63–354小时。这比只报告总体平均更重要：在阈值两侧本身不确定时，小时总量无法辨别整月尾数。

## 阈值侧不识别命题

正式陈述和完整证明见[`THRESHOLD_SIDE_NONIDENTIFICATION_THEOREM.md`](THRESHOLD_SIDE_NONIDENTIFICATION_THEOREM.md)。

令每小时总量为已知正数`G_h`，月燃料边际为`M_f`，且`Σ_h G_h = Σ_f M_f = M`。考虑可行分配

`x_{h,f} = G_h M_f / M`。

它非负、逐小时恰好满足总量`G_h`，逐燃料月和也恰好等于`M_f`。因此每小时燃料份额都与月份相同，小时CIF恒等于月均`μ(e)=Σ_f e_f M_f/M`。

若一个EF不确定集合中存在`e⁻`使`μ(e⁻) < τ*`，也存在`e⁺`使`μ(e⁺) ≥ τ*`，则同一条比例分配在`e⁻`下有`K=0`，在`e⁺`下有`K=H`。因此无论EF被视作全月共享未知参数，还是小时变化的区间参数，其对K的可行**最小—最大界**都是完整`[0,H]`；若允许每小时独立选EF，区间内每个整数计数也都可由逐小时选高/低EF构造。**任何小时总量曲线都无法缩窄K的区间。**这是充分的全区间不可识别条件；未跨阈值只消除这个特定障碍，并不保证一定收窄。

在正EF统一相对误差盒`[ (1-r)e_f, (1+r)e_f ]`、零EF保持零的情况下，月均盒为`[(1-r)μ₀,(1+r)μ₀]`，可直接计算阈值侧翻转所需的最小相对因子误差。本样本上述四个失效BA-month的临界相对误差分别为：PACE Apr 8.76%、Jul 7.44%、Oct 3.63%，AZPS Oct 6.62%；均小于压力测试的10%。解析构造证书的月边际守恒最大误差`2.61e-8 MWh`，小时总量误差`1.46e-11 MWh`；详见`threshold_side_certificate.csv/json`。

## 研究含义

这里出现了可形成论文贡献的核心判据：是否存在可信的小时风险预测，先取决于排放因子/源别有效EF不确定区间是否跨过目标阈值；若跨过，单加小时总量无法解决。要获得有意义的尾风险界，最低本地信息可能不是更多时间点，而是足以把月均CIF锚定在阈值一侧的EF/排放校准信息；只有越过该关口，小时总量的时间分布才有机会继续收窄风险集。

但当前证据是固定EF代理上的识别几何和人为±10%压力盒，不是中国EF不确定度的经验估计，更非概率覆盖/预测准确率。`[0,H]`结论只针对允许hour-varying EF外包络；若真实EF是全月共享参数，外包络会保守地放宽集合。下一步需对比燃料/类别EF不确定范围的实际来源，测试全月共享EF或多个文献因子场景，并在中国公开月度字段下做可复现的信息预算分析。
