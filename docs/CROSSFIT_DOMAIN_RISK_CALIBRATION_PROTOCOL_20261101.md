# 源端留区伪目标校准：US→GB区间风险复核协议

冻结日期：2026-11-01，运行前。问题：现有US→GB校准用同一批美国BA训练小时模型、再用这些BA的下一年误差确定区间尺度。若这些误差低估新地区风险，可否用留一BA伪目标的真正外样本误差校准，并在GB保持覆盖的同时减少宽度？本轮也检验上一轮指出的点中心与区间半径分离。

## 固定样本与方法

- 同一EIA-923美国BA月量＋NESO英国月量，同`t−2`月份额、2022源小时训练、2023校准、2024目标。
- US→GB为主方向；只评GB 2024小时标签。目标在此前研究已查看，故本轮是机制开发，不是盲测或新国家确认。
- 源响应为EIA官方消费侧强度。该任务跨机构标签定义不同，独立于Energy-Charts固定EF发电侧代理轨道。
- 三个中心：粗月特征HGB（M）、粗月＋年度化石热耗HGB（M+H）、固定EF强重组。源标签、模型结构和目标时间完全相同。
- `time_only`校准：每个模型用全部US BA 2022拟合，在相同BA 2023时段算误差。
- `LOBA_OOF`校准：对每个BA，训练仅用其他六个BA的2022标签，用被留BA的2023标签算外样本误差；共七个轮换伪目标。跨模型风险半径替换另作M中心/M半径与M+H中心/M半径配对。
- 对源BA误差先作国家等权平均偏差修正，按源小时绝对误差的90分位或各BA q90最大值构造对称区间。LOBA OOF来源的BA数只有7，不宣称精确条件覆盖；q90采用描述性留区风险校准，不称有限样本conformal保证。
- 所有GB预测写盘和哈希封存后才读取2024标签。

## 报告与判断

逐方法报告MAE、日内形状MAE、90%覆盖、平均宽度、90%区间分数；比较同中心的time-only与LOBA OOF半径，以及M+H中心配M半径。主要门槛是相对强重组与当前M基线改善区间分数、且覆盖不因缩宽显著恶化。宏结果不能掩盖已知目标失败。即使达到，也只支持进入未见时间窗开发，不构成国家级交换性或中国覆盖保证。

## 数据边界

EIA-923历史数据为当前Final档案并按`t−2`年份模拟，非全历史as-issued；英国DUKES热耗取当前修订值。EIA与NESO官方消费侧估算并非共同核算真值。2024目标此前已查看。中国部署仍应以本地发电侧估计对象与公开月表为主，消费侧跨区排放单列。
