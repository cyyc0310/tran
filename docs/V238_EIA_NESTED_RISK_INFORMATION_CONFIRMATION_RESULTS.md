# V238 结果：真实逐小时发电总量对联合尾数识别的复制

日期：2026-10-30。协议：[`V238_EIA_NESTED_RISK_INFORMATION_CONFIRMATION_PROTOCOL.md`](V238_EIA_NESTED_RISK_INFORMATION_CONFIRMATION_PROTOCOL.md)。运行器：`scripts/v238_eia_nested_risk_information.py`。机器结果：`results/v238-eia-nested-risk-r1/`。

## 结果

覆盖核验发现EIA本地2026快照从7月2日开始，所以原拟7月不完整；在查看任何CIF端点前，协议改为完整8月，并依据完整小时覆盖和地区覆盖将样本扩为AVRN、AZPS、CPLE、ERCO、PACE、SOCO、PGE、PSCO，共8个完整BA-month。目标结果没有用于样本筛选。

固定EF派生标签与EIA燃料分解的最大重构误差为`1.14e-13 g/kWh`。64个MILP端点中56个证明最优（87.5%，达到预设80%门槛）；所有实际固定EF派生的尾数都落在对应可行集端点之间。对已证明的端点另做三层集合独立核验：10/10个日界完整案例均被月界包含，10/10个日/小时配对均满足小时界被日界包含，无失败。[嵌套审计](../results/v238-eia-nested-risk-r1/nested_enclosure_audit.json)。SciPy 1.17.1，输入、协议和脚本哈希保存在机器结果`metadata.json`。

在500 g/kWh阈值下，8个区域的日/小时两套端点均证明最优。两个区域（AVRN、PGE）的月边际活跃EF支持不允许任何超阈小时，风险界恒为0；其余六个有非平凡风险支持的区域如下：

| BA | 日总量条件下 K 界 | 小时总量条件下 K 界 | 观测固定EF尾数 | 界宽减少 |
|---|---:|---:|---:|---:|
| AZPS | 0–737 | 0–625 | 196 | 112小时 |
| CPLE | 0–733 | 0–536 | 0 | 197小时 |
| ERCO | 0–732 | 0–490 | 0 | 242小时 |
| PACE | 3–744 | 60–744 | 470 | 57小时 |
| PSCO | 0–738 | 0–621 | 101 | 117小时 |
| SOCO | 0–738 | 0–621 | 0 | 117小时 |

六个非平凡案例中，给定日总量后再给小时总量，K界平均缩窄140.3小时（这些日界的平均宽度为736.5小时，平均再缩窄19.1%）。相较之下，仅月度边际到日总量通常只缩窄2–11小时。这复制了V237的关键方向：对整月超阈小时数，日内小时总量的时间分布比仅知道每日总量更有识别价值。

在900 g/kWh阈值下，只有2/8个BA的“日+小时”配对两端都证明最优，且两者都是零风险支持的平凡集合；其余数据不能支持强结论。虽小时条件端点14/16最优，但日条件仅10/16最优，所以不汇报未配对界宽增益。

## 含义与论文边界

这次不是对“负荷曲线等于发电曲线”的假设做验证：小时总量来自EIA实际逐小时燃料发电记录并求和。它比V236–V237的中国重建负荷代理更接近目标信息合同。不过这里的CIF仍是EIA燃料发电乘固定EF构造的代理，没有独立直接CO₂小时标签；可行集包含已观察燃料调度仅说明模型约束没有排除该轨迹，不是统计覆盖率、预测准确率或因果结论。样本是已打开的V226地区，只有2026年8月一个月。

**当前判断：V238是值得继续验证的结构复制，不构成已完成的算法突破。** 尾数锐界的优化形式使用标准MILP，不能把“用了MILP”单独当创新。可发展贡献更可能是一个以目标量和可用字段为中心的CIF信息基准：给定月度源边际与总发电时间剖面，对全月超阈小时数计算尖锐识别集，并测量从月→日→小时信息的增量，同时区分“部分识别”与概率预测/覆盖。需要更广跨月样本和中国本地生成侧数据才能评估普适性。

相关工作界线：EDGAR已长期使用源/地区特定时间曲线把低频排放拆到小时，因此时间分解本身不是新方向（[EDGAR高时空分辨率排放剖面](https://doi.org/10.1038/s41597-020-0462-2)）。IEA实时电力排放文档从逐小时燃料生成变化估计边际燃料，也不是本研究的识别问题（[IEA方法文档](https://iea.blob.core.windows.net/assets/e604f400-037e-43c3-88de-6bcb7af3e064/Real-timeCO2emissionsfromelectricity-documentation.pdf)）。分布鲁棒优化中尖锐尾概率界已有一般理论（[Tight tail probability bounds](https://doi.org/10.1016/j.ejor.2021.12.010)）。因此候选新意应限定为：在月度燃料边际约束下，针对小时CIF经验尾数这一领域量，构造并验证多尺度生成总量信息的锐界/价值曲线，而不是泛称“首次做尾风险界”。

## 决策

继续扩大到多个季节和年份，优先解决三个问题：

1. 用跨月、跨燃料结构的EIA数据检验小时总量的界收窄是否稳定，预先限定样本后报告所有区域与阈值。
2. 把固定EF升级为EF区间/燃料类别不确定性，并检查结论对EF近似和EIA类别映射是否稳健。
3. 在中国月度源别发电边际可得但小时源别分配不可得的情形，寻找可公开获得的**本地生成侧小时总量或最小调度字段**；负荷代理结果不能替代该验证。

若这些复制失败，应将贡献收敛为识别边界/数据基准论文；目前不冻结预测算法，也不声称中国小时CIF预测已被验证。
