# 真实发布月报跨域滚动试验协议

2026-11-01。此轮为时间可见性与跨域效用诊断，不是冻结新算法或未查看地区确认。目的是把EIA官方月报的真实发布时间接入GB→美国小时发电强度代理迁移，并检查月度信息是否改善预测。

## 任务边界

- 源：GB/NESO小时发电燃料结构。按既有跨国基线，在2022年源样本训练、2023年源样本校准。
- 目标：NYIS平衡区，2025-01至2026-09小时；目标标签为EIA-930八燃料固定EF发电侧代理，不是官方消费侧CIF，也不是独立观测排放。
- 目标输入：EIA《Electric Power Monthly》按纽约州发布的最近一份月报，取预测目标月开始前已发布的归档。用HTTP `Last-Modified`核验发布时间，按归档中的最近完整观测月份生成五类份额。目标月份t通常用t−3月量；若当月报告延迟，则如实使用更早数据。2026-06使用2026-04期归档（报告2026-02数据，t−4），因为2026-05期归档的HTTP修改时间为2026-06-03，晚于预测起点。
- 预测点比较沿用现有基线：700锚、源火电有效EF锚、日历Ridge、五类Ridge、五类HGB、五类小时轮廓重组。风险统一使用GB源2023残差均值和标准差；该风险带不保证目标覆盖。
- 所有目标小时点预测先写入`predictions_sealed.csv`并计算哈希，随后才加载EIA-930目标燃料列、过滤完整日并评分。小时CIF代理仅由燃料加权固定EF构造。
- EPM状态统计和EIA-930 BA目标存在地理统计边界差异，因此即使数值运行完整，也必须通过同月状态—BA组成对齐审计后才能解释预测能力。

## 输出与复现

- 运行：`python scripts/run_actual_issue_cross_country.py --output results/actual-issue-gb-to-nyis-rN`（N须是新的目录名）
- 完整输出：`results/actual-issue-gb-to-nyis-r5/`
- 输入发布时间、报告观测月份和归档哈希：`as_issued_inputs.csv`；原始归档及HTTP头记录在`data/eia-epm-vintages-r1/manifest.csv`。
- `r1`、`r2`是修正过程产生的未完成诊断运行；`r3`、`r4`是完整评分但未包含全部审计哈希的运行。使用包含空间审计与源输入哈希的`r5`作为可复现结果。

本协议在开发性诊断过程中形成，不能描述为结果揭盲前的预注册。不得把NY州→NYIS当作精确同地域输入，也不得把本试验写成真正新地区确认。
