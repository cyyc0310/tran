# TransCIF跨国基准任务目录

更新：2026-11-02。本目录统一登记现有主要跨国小时预测任务，但**不是跨轨总排行榜**。机器可读任务表见[CSV](CROSS_COUNTRY_BENCHMARK_CATALOG_20261102.csv)；每一行都指向完整协议、结果和封存证据。指标摘要用于定位证据，正式引用应回到对应结果报告及机器产物。

上述划分刻意防止把不同标签、代理、时间版本和目标域拼成一个宏观分数。CSV中的`headline_metrics_by_method`保存对应任务最关键的模型对照；每个数值仍需回到结果文档核对定义、目标支持、区间算法和地区分层。

## CSV字段约定

- `priority`对应四项研究任务：跨国小时预测、源内中国信息预算伪目标、可迁移燃料响应、月报适配与区间可靠性。
- `target_response_definition`标记标签/代理对象；`track`将发电侧、消费侧和代理分开。
- `target_input_budget`描述预测时目标特征；`target_vintage_status`描述滞后模拟是否使用原始as-issued版本。
- `scored_support`给目标时间点或地区数。遇到多BA时，BA内小时不可视作独立地域样本。
- `headline_metrics_by_method`只摘要主要对照，不替代每模型逐月/逐域结果。不同任务的区间分数可能使用Winkler、CRPS或实现特有区间分数，不可互相排序。
- `evaluation_status`、`target_response_previously_viewed`及`blind_geographic_confirmation`显式区分开发回测、前瞻封存、无标签推理与独立确认。`target_response_previously_viewed`取`yes`、`no`或`not_available`；它只针对目标响应标签，不代表目标输入或国家在项目中从未出现。
- `source_response_definition`和`source_training_and_calibration`记录迁移源监督与时间切分，避免只看目标指标而遗漏源/目标测量制度及校准窗。
- `machine_evidence`为仓库根目录相对路径；结果文件中的哈希、预测支持和标签打开顺序具有最终优先级。

## 当前四项任务的证据状态

1. **跨国小时预测已接通，并新增一个冻结方法日本外部系统复核。** US↔GB两方向各自有代理/官方标签实验；US/GB→AEMO与→日本也有跨域测试。日本九区中强重组只在3区胜过700锚，宏点误差和区间分数均较差、覆盖37.3%；这仍是固定因子代理与回算月量，不是盲标签、官方CIF或as-issued确认。冻结的两月总量趋势也未改善US→GB官方标签结果。整体暂未形成可可信迁移算法。
2. **伪目标模拟已证明可作筛选工具，尚未产生跨国增量算法。** 多个因子头、组成门控和专家回退在源内有时改善，但GB负结果显示选型收益未迁移。最新乘法式月均锚定形状在九国LOCO中接近700锚，却明显落后于燃料份额强学习头，未通过晋级门槛。
3. **燃料运行关系没有跨域独立胜出。** 固定因子小时重组继续作为强参照；它在特定方向/年份有收益，在其他官方标签方向失效。
4. **区间可靠性未达成。** 2025官方跨域结果多处欠覆盖；来源经验覆盖不能当成整国保证。两月趋势虽令US→GB直接HGB区间缩窄0.64%，覆盖也下降0.68个百分点、Winkler恶化2.32%。12月t−2预测仍未评分；不能用扩大区间来补写成功。

**新增源子集风险尺度检验仍未改变第4项结论。**严格CN5九国外层LOCO用六源子模型标准差调整90%区间，覆盖由固定源池化的89.63%升至94.76%，最差国覆盖由58.80%升至77.69%；但宽度增加70.5%、Winkler恶化33.2%，只在4/9国改善Winkler。按事前门槛停止，不把模型分歧当成可信域风险估计。[协议](CN5_SOURCE_SUBSET_DISPERSION_PROTOCOL_20261102.md)、[结果](CN5_SOURCE_SUBSET_DISPERSION_RESULTS_20261102.md)。

**AEMO燃料组成响应头顺序复核显示点误差有条件改善、区间失败。**US+GB训练的fuelshare头宏MAE为202.42，比重组低19.6%、比coarse Ridge低5.5%；但US-only及GB-only均未优于重组，最佳基线区间分数仍好17.9%，宏覆盖36.2%，NSW/QLD严重欠覆盖。该目标已看过，不能视为盲确认；保留为燃料组成跨域关系的正向点估计、负向风险校准证据。[结果与边界](AEMO_FUELSHARE_RESPONSE_TRANSFER_RESULTS_20261102.md)、[协议](AEMO_FUELSHARE_RESPONSE_TRANSFER_PROTOCOL_20261102.md)、[运行与封存](../results/aemo-fuelshare-response-transfer-r1/README.md)。

**意大利新小时代理复核限制了燃料份额头的增量主张。**意大利2023年冻结回放中，fuelshare MAE62.22、形状MAE21.21、覆盖86.44%、Winkler320.90；比重组/历史因子头好，但`direct_latest`的MAE56.75、覆盖92.88%、Winkler301.60更优。燃料份额头未过88%覆盖和最强基线区间分数门槛，停止对意大利调参；这是新小时代理方法复核而非盲地理确认。[结果与判断](ITALY_FUELSHARE_RESPONSE_TRANSFER_RESULTS_20261102.md)、[冻结协议](ITALY_FUELSHARE_RESPONSE_TRANSFER_PROTOCOL_20261102.md)、[封存证据](../results/italy-fuelshare-response-transfer-r1/README.md)。

## 研究用途和下一步

该目录可以支撑论文的**任务定义、输入预算、标签口径和负迁移证据**，但尚不足以支撑“外国小时模型已可信地预测中国省级小时CIF”或一个已胜出的原创算法。接下来有新算法时，先在源内按整国/整区嵌套伪目标验证，保持同标签、同输入预算和同区间方法；只有结果通过预设的最差域覆盖与点误差/区间效率门槛，才冻结并在未查看目标上确认。独立确认必须有完整目标小时标签，目标标签定义与所主张轨道匹配。

中国输入侧已可复现t−2月度五类预算，但目前只有规上统计的修订快照，且多省对外国源特征外推。消费侧还缺来源流量与送端强度的公众、可追溯输入。若这些任务条件没有补齐，论文应报告预测可识别边界和数据缺口，不把无标签中国推理包装为精度验证。
