# V382：省级年度煤气油结构来源与NBS月度火电口径闭合审计（2026-10-31）

## 问题与来源

用户当前实际可用的本地预算是公开月度发电类别量；需要判断公开年度统计能否提供可信的火电内部燃料年度锚。检索发现一份2023年2月公开的中国电力数据库技术报告，表3列有2020年31省煤、气、油火电“供电量”，上海数值分别为611.33、149.91、1.52亿kWh，总供电量821.62亿kWh。[报告PDF](https://study.1mi1.org/articleAttachments/upload_9e0a7bd8b24583aa4daa4eefd5defe11.pdf)

该表不是逐类电厂的直接公开计量序列。报告称其依据《中国能源统计年鉴2021》省级能源平衡表的火电量与燃料消耗量，并结合《2020年电力工业统计资料汇编》的火电厂用电率推导。关键分配假设是：燃煤、燃油、燃气厂用电率相同；按标准煤折热后的燃料热量占比等于相应类型火电的发电量占比。报告也明确写明省级电网供电结构通过六大电网混合与净交换进行统计简化。[方法段](https://study.1mi1.org/articleAttachments/upload_9e0a7bd8b24583aa4daa4eefd5defe11.pdf)

国家能源局答复确认，分省、分能源类别发电量可从国家统计局网站查，中电联年鉴提供省级用电量；这并没有确认省级煤/气/油发电量属于官方公开直接字段。[国家能源局答复](https://www.nea.gov.cn/2021-05/11/c_139938862.htm)

## 上海口径闭合计算

将表3的单位从亿kWh乘以100换为GWh，并与V320 OREO转录的上海2020年NBS月面板对齐。NBS源有11个报告桶：1–2月累计只占一个桶，3–12月各一个；按原始月报语义各计一次，火电全年桶和为80,350 GWh。

| 项目 | GWh | 解释 |
|---|---:|---|
| NBS转录月桶火电和 | 80,350 | 规上口径火电毛发电量；不是全口径电网供电量 |
| 1mi1表3总供电量 | 82,162 | 年鉴/电力统计资料推导值 |
| 1mi1煤+气+油供电量之和 | 76,276 | 表内列出的化石三类 |
| 1mi1总量减煤/气/油和 | 5,886 | 表中未按煤/气/油分配的差额 |
| 1mi1总量减NBS火电毛发电量 | +1,812 | +2.26%相对NBS火电毛发电量 |
| 1mi1煤/气/油和减NBS火电毛发电量 | −4,074 | −5.07%相对NBS火电毛发电量 |

煤/气/油三项内部归一后的份额为80.15%/19.65%/0.20%。这组比例可作为一个**2020年来源依赖的先验/敏感性情景**；不能当作将80,350 GWh完整分解的统计恒等式。既有表内总供电量高于NBS火电毛发电量，而煤/气/油小计又低于NBS毛发电量；计量边界与残余类别均未被原表充分解释，不能通过静默归一化或把5,886 GWh差额强行归入低/零排放类来“闭合”。

## 对创新路线的影响

这条证据把“年度细燃料锚”从纯假设推进为**有公开来源、但需边界误差建模的可用性候选**。有价值的原创机制不应将年度三类比例平均分到每个月，而可以将年度燃料总量视作带不确定性的约束、月度火电量作为逐月边际，并对未解释残差单列，求解月度各燃料可行分配及由此诱导的CIF/尾风险集合。随后可比较：年度结构点固定、年度份额区间、无年度细分的粗火电基线、简单锚定及标准动态模型。此机制需要证明集合边界有效、确实变窄、并在真实小时标签覆盖约束下提高预测区间效率；目前只完成字段与口径审计，不能宣称预测算法增益或论文突破。

关键下一步是找到另一份可复算的原始燃料/能源平衡表，交叉核对该推导表，以及同一上海年份的全部报告语义。若只能拿到经二次计算的2020结果，研究设计应把其作为额外高信息预算的敏感性层，不应写成“只凭公开NBS月表”。
