# V372：省级月报相对全国汇总的信息增量稳健性协议

登记日期：2026-10-30。V366只比较`[400,1000] g/kWh`、`τ=300`单一情景。本轮在查看结果前扩展EF支持和阈值网格，判断省级占比优势是否依赖该单点设定。

## 问题与信息预算

同一2022–2024 NBS来源转录面板、同一省期、同一火电占比、同一阈值与EF支持下，比较：

1. **全国臂**：用每个年度与报告期bin内31省聚合的火电占比，赋给所有省份；
2. **本地臂**：使用对应省份自己的火电占比。

两臂唯一差别为空间分辨率。对`K=#{h:C_h>τ}`的充分全宽非识别证书沿用V364：`L*s ≤ τ < U*s`。该证书在固定小时总出力曲线下也可构造`K=0`与`K=H`两个相容世界。

## 冻结网格

- 火电有效因子支持情景：`[400,1000]`、`[350,1100]`、`[700,900]`、`[0,1100] g/kWh`。
- 严格超阈值：`τ∈{100,300,500} g/kWh`。
- 主比较量：全国臂全宽证书数、本地臂全宽证书数、本地臂退出的全国全宽证书数及占全国证书比例。
- 次比较量：每年与本地臂至少出现一次证书的省数。

不调EF来拟合标签，不训练模型，不打开小时标签。省期不是独立抽样单位；本轮只给有限总体的精确计数，不做显著性检验或总体外推。

## 数据和限制

输入为V364保存的NBS来源OREO转录表生成的逐省期证书表，不是从用户所给NBS页面实时抓取的官方原始响应。月度边际是规上工业口径；火电类别内部燃料与有效EF未知，因子区间是情景。跨省聚合也沿用同一转录面板，不代表更大的全口径电网供给。

即便本地占比退出充分全宽证书，也只说明V364这条`比例混合见证`不再适用；不保证真实小时K界变窄，不代表预测精度或覆盖改善。

## 运行与停止标准

脚本只计算已冻结网格，不按结果增加支持端点。若省级占比在大多数支持—阈值组合下都使本地臂全宽证书下降，保留它为基准的地域分层输入；若结果只在个别情景成立，则不把“省级数据消除全国信息缺口”作为稳健结论。算法路线仍需真实标签上的同预算基线验证。
