# V257 目标区滚动小时风险校准

## 问题

V256发现同月随机校准覆盖接近名义水平，但月初连续日校准后续日期明显欠覆盖。V257检验已观察到的近期日风险是否足以追踪这种变化：在同一组月内后续预测日上，对比固定月初校准分位数与每次使用最近n个已完成日重新校准。

## 冻结设计

- 延用V256的10个已打开目标BA、120 BA-month、V253完整24小时日、V252年度热耗率中心，不增删目标或标签筛选。
- 风险分数仍为一天24小时中相对固定中心的最大绝对误差。
- 比较滚动窗口`n={9,12,18,24}`，有限样本排名为`ceil(0.9(n+1))`，按1-based计数。
- 每个BA-month按日期排序。预测第`i`个测试日时，只取其之前最近n个完整日风险分数，计算q并形成中心±q区间。配对固定方案则只用该月最早n日计算一次q，并对滚动方案同一组日期评分。
- 测试集为日期序列中第n日之后的全部完整日；因此n不同的预测期不同。主要滚动—固定比较在每个相同n内配对，不跨n直接作单纯因果解释。
- 指标：整日覆盖、小时覆盖、平均全宽、Winkler90；先BA-month内平均测试日，再BA内平均，最后BA等权。报告BA簇bootstrap区间。

## 可用信息与限制

每次更新要求上一日的CEMS小时结果已经可得；这是逐日在线风险更新，不是无高频数据冷启动。中心继续使用目标整月2025毛发电量与2024目标年度热耗率，包含目标整月信息，故这里只检验风险校准更新机制，不能称完整的实时日 ahead CIF预测。目标标签已打开，结论不是独立地区验证。

滚动次序统计量在小n下会离散跳跃；n=18取最大值，n=24取第23顺位。未来日与最近n日也可能不满足交换性。结果是经验覆盖诊断，不构成分布无关在线覆盖保证；不把标准滚动窗口或自适应校准宣称为算法创新。
