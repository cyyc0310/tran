# 研究问题与证据门槛

拟题：**Probabilistic Dispatch Transfer for Carbon Intensity Forecasting in Grids without Local Telemetry**。

研究问题是：在没有目标逐时 CIF、发电和实测负荷历史时，能否用源域学到的调度状态分布，结合目标已公开配置及预报，产生物理可行、对负荷时段选择有用的 CIF 联合情景？公开装机和能源占比无法唯一确定调度，跨域潜在状态也可能不可识别。论文需要正面处理这种不确定性。

当前性能优先级为跨域 MAE/RMSE，概率预测与调度作为辅助任务。SOTA 结论需要真实、同信息集的强方法对照；四个固定人工电网上的改进仅属于方法开发。

## 近期工作的边界

| 工作 | 已有贡献及本项目应如何比较 |
| --- | --- |

以上为定位所需的近期原始论文，不是穷尽性综述。发表年份与 DOI 年份可能不同；核验日期为 2026-10-19。当前仓库没有复现这些论文，不能把本地岭回归对照称为 SOTA 比较。

## 当前实现与待验证贡献

已实现 `pθ(z₁:H | public configuration, issued forecasts, calendar)`：小型 TCN 产生可用率、成本、负荷状态的均值和尺度；日级随机项与 AR(1) 创新保持时间相关。每条情景先得到核、风、光可用出力，再按比例弃电，剩余负荷经可微凸调度分配到煤、气、水。调度解满足容量边界与已服务负荷平衡，缺电单列。

调度目标为 `Σf [c_f g_f + τ g_f²/(2 a_f)]`，约束 `0≤g_f≤a_f`、`Σg_f=min(residual_load, Σa_f)`。零容量燃料输出零；固定外部 EF 将发电情景转换为 `CIF=Σg_f EF_f/Σg_f`。源训练目标为 fair MC CRPS + 0.25 路径 energy score + 50 平均燃料占比 MAE + 1000 缺电比例。权重目前固定，尚未经过独立源域嵌套调参验证。

MAE 模式增加共享参数的确定性物理点输出，目标为 `点 MAE + 0.1 CRPS + 0.025 energy + 500 归一化源发电 MAE + 1000 缺电比例`。发电误差按公开总容量归一化，补上占比监督不能识别的绝对出力约束。可选条件编码器提供全时域上下文、可低于 50% 的确定性可用率及可学习正调度平滑度；其收益需要与只改训练目标的消融区分。

这一步提供可审计的归纳偏置，尚不构成充分的方法创新。面向论文的下一步应集中于：

- **调度歧义与迁移风险**：已实现独立源组交叉拟合、仅源留域选择潜在尺度，以及全源/留组模型构成的有限机制集合。元数据外推时可弃权；该集合尚不是可识别的物理歧义集合，不保证包含真实目标调度。需要检验是否改善最差域表现。
- **联合情景的决策价值**：已加入确定性解、仅源尺度修正、混合路径和逐小时打散路径对照，以及均值/CVaR 的有限机制最坏情形时段选择。最坏机制 CVaR 指 `max_k CVaR(P_k)`，不等同于对机制分布任意混合的最坏 CVaR；当前没有端到端决策训练。
- **可证伪的适用边界**：区分配置滞后、预报误差、装机外推、缺电和进出口占比的影响；预先定义何时模型应拒绝自动推荐时段。不能把源域校准解释为任意目标域的覆盖保证。

## 发表前必须补齐

先建立可追溯的真实预报发布时间档案；没有目标公开负荷预报的地区，需要另建仅使用源数据及公开目标统计的需求预测器，当前代码会直接拒绝缺失输入。旧 `data_2023/` 没有通过新协议认证，不参与这里的真实实验。

再做跨年、留电网及留整国的外层测试，源域内部完成全部调参。对照需包含同信息的强树集成/概率模型、确定性物理调度、无物理概率模型以及可复现的近期方法。报告逐电网 CRPS、MAE、energy score、区间宽度和覆盖、缺电率、均值/CVaR 代理成本与 oracle regret；用电网/时间块配对重采样表达不确定性，不能按小时独立检验。

优先消融物理层、联合相关性、公开占比先验、源发电监督及预报集合。EF 与 CIF 标签若来自同一重建公式，需单列该耦合并尽量加入独立核算验证。平均 CIF 负荷转移结果不等于边际排放或真实因果减排。

模拟实验只验证工程流程和约束。真实数据上未通过上述检验前，不声称优于现有方法、达到目标覆盖率或具备顶刊发表结果。

当前模拟已出现源留域 CRPS 最优尺度仍明显欠覆盖、集合增益依赖目标能源结构的情况。因此尺度选择与概率校准必须分开报告；有限机制集合和支持诊断继续作为可选实验，尚不替换原基线。

## MAE/RMSE 优化优先级

| 优先级 | 瓶颈与处理 |
| --- | --- |
| P0 | 只有四个固定人工配置，真实签发预报和独立核算仍缺。先建立真实跨年、留整国基准，再讨论 SOTA；新天气随机种子不等于新配置分布。 |
| P0 | CRPS 训练/选模与 MAE 目标不一致。已加入物理点输出、MAE 主导监督、源域 MAE/RMSE 选模及点估计定义审计。 |
| P0 | 原模型的情景中位数可能优于新增点头。已将 mean/median/physical 写入模型配置并提供按源 MAE 选分布模型的路径；所有新方法必须与正确的点估计基线比较。 |
| P1 | 原 TCN 局部场仅 5h，且确定性可用率下限 50%。已提供全时域条件编码器与更灵活的物理参数化，须通过同预算消融判断收益。 |
| P1 | 原训练只约束平均燃料占比，不能充分确定绝对出力。点模式加入按容量归一化的源发电监督；学习率、日程、采样和训练预算均可配置。 |
| P1 | 已加入可审计的源验证学习率搜索，但 checkpoint/学习率仍主要检验已见源配置的时间泛化。架构和超参数应通过内层留域任务选择；多机制或更大调参预算不自动改善跨域 MAE。 |
| P1 | 对照曾只有岭回归和常数。已补同输入 MAE 提升树；仍需复现或公平适配近期碳强度方法、外生变量模型和预训练方法。 |
| P2 | 已按天气成员复用编码，并核验情景、输入梯度及参数梯度等价；成员数较多时自动保留逐情景编码。实际加速应报告完整模型测时，不能用编码器调用数代替。 |

新增 `shared` 对照仅学习 22 个全局调度分布参数，不通过神经网络拟合配置特征。它用于区分物理映射的迁移收益与少数源配置的记忆；模拟器本身共享潜在调度规律，若该对照占优也不能推断真实电网共享同一规律。
