# 研究问题与证据门槛

> 2026-10-31路线更新：按用户要求，主任务恢复为国外有标签数据训练、中国无小时CIF标签迁移。后续具体优先级见[跨域迁移研究计划](CROSS_DOMAIN_TRANSFER_RESEARCH_PLAN_20261031.md)。本文中的历史结果继续有效；建议将部分识别升级为主线的旧路线判断由新计划覆盖。

拟题：**Probabilistic Dispatch Transfer for Carbon Intensity Forecasting in Grids without Local Telemetry**。

研究问题是：在没有目标逐时 CIF、发电和实测负荷历史时，能否用源域监督学到的调度状态分布，结合目标已公开配置及预报，产生约束一致且对时段选择有用的 CIF 联合情景？“公开预报可获得”是输入前提；缺失时当前实现报错。

该问题值得研究，但“物理层 + 条件网络 + 概率预测 + 时段选择”的组合尚不足以证明方法新颖性。现有结果仅支持方法开发，数据与数值依据统一见 [RESULTS](RESULTS.md)。

## 实现究竟提供了什么

`models/dispatch.py` 建模 `pθ(z₁:H | configuration, issued forecasts, calendar)`，输出可用率、成本、负荷状态；可选资源校准增加风速及光照状态。日级随机项和 AR(1) 创新提供时间相关性。每条路径先分配核/风/光并按比例弃电，余下负荷经可微凸调度分配至煤/气/水：

`min Σf [c_f g_f + τ g_f²/(2 a_f)]`，约束 `0≤g_f≤a_f`、`Σg_f=min(residual_load, Σa_f)`。

发电情景通过固定外部 EF 得到 `CIF=Σg_f EF_f/Σg_f`，缺电单列。约束一致指这一单节点模型内部，不等于真实网络调度可行。模型不拟合目标 EF，也不添加目标 CIF 残差修正。

三种训练目标由 `training/losses.py` 定义：

| 目标 | 训练监督与选模默认值 |
| --- | --- |
| `crps` | CIF fair MC CRPS + 0.25 路径 energy score + 50 平均燃料占比 MAE + 1000 缺电比例；按源验证 CRPS 选模 |
| `point` | 点 MAE + 0.1 CRPS + 0.025 路径评分 + 500 容量归一化发电 MAE + 1000 缺电比例；按源电网宏平均 MAE 选模 |
| `joint` | CIF CRPS + 0.25 路径评分 + 500 联合归一化发电 energy score + 1000 缺电比例；按源电网宏平均 MAE 选模 |

缺电惩罚不是 proper score；权重为开发设定。资源误差、可用率与成本状态仅凭源发电标签不可分别识别，不能把潜变量解释为已观测物理参数。训练期 fair MC score 与评估期经验分布 score 使用不同有限样本归一化。

可选有限机制集合由全源和留源组模型组成，尺度只按源留域 CRPS 选择。配置距离和缺电阈值是诊断/弃权启发式；集合不保证包含真实目标机制，方差分解也不是已经识别的偶然/认知不确定性分解。`max_k CVaR(P_k)` 仅在这些有限机制间取最坏值，不能称为任意混合分布的最坏 CVaR。

`physics/envelope.py` 的极值计算是指定总发电量、容量、最小出力及独立 EF 区间下的基础线性规划。只有该信息类允许全部这些调度时，中点/半宽才分别给出最坏绝对误差最优点/风险下界；它不是完整公开信息下的新定理或不可突破预测下界。

## 可证伪的论文主线

优先检验**公开结构变化与不可识别调度状态应如何分开迁移**，而不是继续增加编码器：

1. **结构约束是否改善域外预测？** 与同信息、同源监督预算的无物理概率模型、确定性物理模型、强树模型及近期方法比较。若简单共享调度在不同源支持下同样有效，就不能把收益归因于配置条件网络。
2. **联合路径是否改善风险决策？** 在匹配逐小时边际分布下打散时序相关性，均值时段目标理论上保持不变，应作为不变性对照。路径增益须通过 CVaR/尾部风险或多时段约束验证，同时比较边际 CRPS、路径评分、代理成本和 oracle regret。若风险决策无收益，联合情景的应用主张须收缩。
3. **迁移歧义能否被诊断？** 预先固定配置外推、资源误差和缺电压力测试，报告拒绝率与接受/全样本风险。有限集合的宽度或源域校准不能代替目标覆盖验证。

## 投稿前的必要证据

- 真实美/英/澳基准必须先统一燃料、储能、净交换和直接 CO₂ 边界，并补齐配置及预报的发布时间档案；当前原生 staging 尚不满足六燃料模型契约。重建 CIF 与独立机构标签分别评价，防止同一 EF 公式带来的循环验证。
- 冻结实验协议与预算，全部调参在源域内部完成；提供跨年、留网及留整国外层测试。四个人工配置的新天气种子不是新配置分布，也不是新的独立盲测。
- 报告逐电网 MAE/RMSE、CRPS、energy score、区间宽度/覆盖、缺电率与决策成本，按电网/国家和时间块配对表达不确定性，训练种子不当作独立电网。
- 分别消融物理约束、联合相关性、占比先验、源发电监督、集合预报和资源校准。结论同时报告负结果及搜索预算；公开数据、模型和评分入口。

在这些证据到位之前，可写清晰的方法与协议稿，不能写成已验证的真实跨域 SOTA、概率覆盖保证或因果减排论文。

## V59–V60 中国低频信息与验证数据更新（2026-10-27）

V59 的 EIA oracle 部分识别结果表明，日燃料边际单独将等小时月均 CIF 的平均可行界从632.2降到482.5 g/kWh；真实逐小时总发电量 oracle 将边界降到76.6，日边际与小时总量联合为58.6。固定每日热电样点的边际收益较小。这是信息价值/识别结果，非预测覆盖率。协议和分析见[V59结果](V59_TEMPORAL_INFORMATION_BOUNDARY_RESULTS.md)。

V60 已实际下载并哈希冻结 Ember 当前中国省级月度数据快照（2016-01至2026-09，31省加全国总量，8个燃料/电源类别）。逐字段内部算术一致，但方法说明确认部分省级燃料与光伏月数据经估算校正；当前文件不保留历史发布vintage。其2022年生成侧省级强度与MEE消费侧年度因子在30省相关0.93，但平均绝对差110.7 g/kWh，不能混为相同标签。V60还确认一些中国小时CIF标签属保密数据，另有可用的省级日度电力排放估算但不是小时CIF。详情及来源见[V60审计](CHINA_MONTHLY_EMBER_AUDIT_V60.md)。

V61对公开 Zenodo 2019–2020 省级日度电力CO₂工作簿做了行级审计：所有31省日曲线在同一个月内都与全国日曲线完全同形（归一化相关约1、比例CV < 5e−15），说明其发布的地区日频形状只是全国估算按月省份权重缩放，并不增加本地日变化观测；相关ESSD讨论稿也承认这一限制且修订未被接受。2026年另一近实时日度框架延伸到2019–present，但数据按请求提供，预测对象是日度排放，仍不是小时CIF标签。其补充材料显示日度动力煤活动是候选本地形状代理：25省有CCTD逐日数据，6省用前25省平均形状填补；多数省的电力日度排放不确定度约±23.8%，5个缺口省约±73.3%。因此它提示了“月度本地水平 + 日度本地活动”可能比全国模板更有信息，但既不满足用户确认的公开月/年数据预算，也不能识别小时燃料归属；不应将其列作可复现冷启动基准输入。[V61审计](CHINA_DAILY_POWER_EMISSIONS_AUDIT_V61.md)。

V61还核对了统计的as-of语义：国家统计局能源月报以规模以上工业企业为口径并注明统计范围逐年变化；当月报告通常在次月发布（2026年9月报告于10月20日发布），国家能源局列示全国月度电力统计约每月20日发布。这意味着目标月最终实际发电量若作为条件输入，任务是“已知月边际下的事后小时分解”，不能称该月月初/日内前瞻预测。需要前瞻结论时，输入必须是预测时点已发布的历史月或真实归档预测vintage，并检查是否覆盖自备电、规模以下和分布式电源。用户确认其月表含全电源类别，但具体来源、统计范围与发布vintage仍待锁定；对应边界见[V61审计](CHINA_DAILY_POWER_EMISSIONS_AUDIT_V61.md)。

这些证据把创新机会进一步收敛到“透明信息预算下的跨区CIF冷启动基准与部分识别/稳健风险报告”，而不是宣称月报恢复唯一小时序列；真实中国小时概率预测结论仍需独立小时标签或可复现合作数据支撑。

## V64：中国逐小时负荷公开数据是模型代理，不是CIF分母真值（2026-10-27）

审计了2026年31省2015–2024天气驱动小时负荷曲线和2018年Zenodo曲线。前者所有310省份-年份时标完整，日形状相关中位数0.957，但论文方法依赖NDRC 2018典型日/每日高低值、年度总量和气象变量重建；后者随附说明明确逐日将典型工作日/节假日模板缩放到NDRC每日高低值。两者都不是省级小时发电/CIF实测。前者与Ember 2016–2024省级月发电对齐的3240省月中，负荷/发电比中位数1.025、P10/P90为0.662/1.457，每省月比值CV中位数9.95%，不支持将负荷无误差地当作发电分母。它仍可作为单独标记的辅助情景信息，后续需用软约束/代理误差评估，不得做硬物理约束或hourly覆盖验证。[V64审计](CHINA_HOURLY_LOAD_PROXY_AUDIT_V64.md)。

## V65：负荷代理的约束增量很大，但不是可验证的形状收益（2026-10-27）

针对月燃料边际给等槽均值CIF的锐界，V65以30省3240省月比较仅月边际、平坦24槽总量、按模型化负荷形状分配的24槽总量。负荷形状条件下平均界宽54.0 g/kWh，相对月边际only的918.8收窄94.1%；但平坦24槽条件下界宽数值为零，因为等小时平均此时恰等于已知月能量加权CIF。换言之，负荷代理并未优于平坦时段约束；非平坦形状反而留下约54 g/kWh的兼容宽度。2018年360个共同省月里，天气重建曲线比Zenodo典型日模板平均窄4.6 g/kWh，61.4%省月更窄，增量弱且仍无发电真值验证。严格结论仅是：代理小时总量假设会改变部分识别集合；不能称为小时预测精度或覆盖收益。V65不构成算法创新。[协议](V65_LOAD_SHAPE_INFORMATION_VALUE_PROTOCOL.md)、[结果](V65_LOAD_SHAPE_INFORMATION_VALUE_RESULTS.md)。

## V66：只有月边际时，小时超阈计数基本不可识别（2026-10-27）
