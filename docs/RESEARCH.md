# 研究问题与证据门槛

拟题：**Probabilistic Dispatch Transfer for Carbon Intensity Forecasting in Grids without Local Telemetry**。

研究问题是：在没有目标逐时 CIF、发电和实测负荷历史时，能否用源域学到的调度状态分布，结合目标已公开配置及预报，产生物理可行、对负荷时段选择有用的 CIF 联合情景？公开装机和能源占比无法唯一确定调度，跨域潜在状态也可能不可识别。论文需要正面处理这种不确定性。

当前性能优先级为跨域 MAE/RMSE，概率预测与调度作为辅助任务。SOTA 结论需要真实、同信息集的强方法对照；四个固定人工电网上的改进仅属于方法开发。

## 近期工作的边界

| 工作 | 已有贡献及本项目应如何比较 |
| --- | --- |
| [DGCFM, WWW 2026，作者全文](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf) | 已研究跨区域及 zero-data 设置；问题定义还使用历史 CIF 和电力流时间序列。必须核实其推理时信息集、原始实现与本任务的差别，不能声称首次跨域或首次零样本。 |
| [EnsembleCI, e-Energy 2025](https://arxiv.org/html/2505.01959v2)，[代码](https://github.com/emmayly/EnsembleCI) | 自适应集成与区域差异分析；其评估特征含历史 24 小时 CIF 和发电量。同信息输入的公开协变量版本应作为强对照，原始历史输入版本单列信息更充分的参照。 |
| [Kohút et al., Applied Energy 377, 124527, 2025](https://doi.org/10.1016/j.apenergy.2024.124527) | 已将物理行为、能源结构估计、优化修正与用电安排结合。单独增加物理层或调度应用不足以构成新颖性。 |
| [TimeXer, NeurIPS 2024](https://proceedings.neurips.cc/paper_files/paper/2024/hash/0113ef4642264adc2e6924a3cbbdf532-Abstract-Conference.html) | 用自注意力和交叉注意力建模内生/外生变量。其原任务并非无目标历史，需要适配同一信息集后作为强参照，当前条件 TCN 不称为 TimeXer 复现。 |
| [Chronos-2, 2025](https://arxiv.org/abs/2510.15821) | 支持多变量与协变量预测及组注意力。是否适合本任务取决于目标历史要求、预训练数据和输入适配，尚未在本仓库比较。 |
| [CarbonX, 2025](https://arxiv.org/html/2510.01521v2) | 统一时间序列基础模型及预测区间，但 zero-shot 推理仍使用目标 CIF 历史，区间校准也使用历史残差。应列为信息更充分的参照，不能直接作为无目标遥测的同信息基线。 |
| [Zhang et al., 2026 预印本](https://arxiv.org/html/2601.06530v1) | 用多小波局部卷积及动态跨变量相关建模，在四个澳洲市场评估；原任务使用历史多变量序列。可参考其多尺度设计，但公开未来协变量版本需要重新适配，尚未复现。 |

以上为定位所需的近期原始论文，不是穷尽性综述。发表年份与 DOI 年份可能不同；新增核验日期为 2026-10-20。当前仓库没有复现这些论文，不能把本地树或岭回归对照称为 SOTA 比较。

## 当前实现与待验证贡献

已实现 `pθ(z₁:H | public configuration, issued forecasts, calendar)`：小型 TCN 产生可用率、成本、负荷状态的均值和尺度；日级随机项与 AR(1) 创新保持时间相关。每条情景先得到核、风、光可用出力，再按比例弃电，剩余负荷经可微凸调度分配到煤、气、水。调度解满足容量边界与已服务负荷平衡，缺电单列。

调度目标为 `Σf [c_f g_f + τ g_f²/(2 a_f)]`，约束 `0≤g_f≤a_f`、`Σg_f=min(residual_load, Σa_f)`。零容量燃料输出零；固定外部 EF 将发电情景转换为 `CIF=Σg_f EF_f/Σg_f`。源训练目标为 fair MC CRPS + 0.25 路径 energy score + 50 平均燃料占比 MAE + 1000 缺电比例。权重目前固定，尚未经过独立源域嵌套调参验证。

MAE 模式增加共享参数的确定性物理点输出，目标为 `点 MAE + 0.1 CRPS + 0.025 energy + 500 归一化源发电 MAE + 1000 缺电比例`。发电误差按公开总容量归一化，补上占比监督不能识别的绝对出力约束。可选条件编码器提供全时域上下文、可低于 50% 的确定性可用率及可学习正调度平滑度；其收益需要与只改训练目标的消融区分。

显式中位数/均值模式现在监督对应的 CIF/发电摘要。`joint` 模式另用 `CRPS(CIF) + 0.25 ES(CIF路径) + 500 ES(vec(g/总容量)) + 1000 缺电比例`，默认按源 MAE 选模型并报告 CIF 中位数。联合发电评分可区分 CIF 相同而发电分布不同的机制；缺电惩罚本身不属于 proper score。

`weather_calibration` 在功率曲线前增加源学习的风速修正、在光伏资源上增加 logit 修正，不再把单个预报成员的风电潜力当成真实出力上限。光伏仍保留预报非零时段支持，无法恢复所有预报都漏报的光照。资源误差与设备可用率仅凭源发电标签不能分别识别；参数不能解释为已观测到的真实气象偏差。

这一步提供可审计的归纳偏置，尚不构成充分的方法创新。面向论文的下一步应集中于：

- **调度歧义与迁移风险**：已实现独立源组交叉拟合、仅源留域选择潜在尺度，以及全源/留组模型构成的有限机制集合。元数据外推时可弃权；该集合尚不是可识别的物理歧义集合，不保证包含真实目标调度。需要检验是否改善最差域表现。
- **联合情景的决策价值**：已加入确定性解、仅源尺度修正、混合路径和逐小时打散路径对照，以及均值/CVaR 的有限机制最坏情形时段选择。最坏机制 CVaR 指 `max_k CVaR(P_k)`，不等同于对机制分布任意混合的最坏 CVaR；当前没有端到端决策训练。
- **可证伪的适用边界**：区分配置滞后、预报误差、装机外推、缺电和进出口占比的影响；预先定义何时模型应拒绝自动推荐时段。不能把源域校准解释为任意目标域的覆盖保证。

## 发表前必须补齐

先建立可追溯的真实预报发布时间档案；没有目标公开负荷预报的地区，需要另建仅使用源数据及公开目标统计的需求预测器，当前代码会直接拒绝缺失输入。旧 `data_2023/` 没有通过新协议认证，不参与这里的真实实验。

再做跨年、留电网及留整国的外层测试，源域内部完成全部调参。对照需包含同信息的强树集成/概率模型、确定性物理调度、无物理概率模型以及可复现的近期方法。报告逐电网 CRPS、MAE、energy score、区间宽度和覆盖、缺电率、均值/CVaR 代理成本与 oracle regret；用电网/时间块配对重采样表达不确定性，不能按小时独立检验。

优先消融物理层、联合相关性、公开占比先验、源发电监督及预报集合。EF 与 CIF 标签若来自同一重建公式，需单列该耦合并尽量加入独立核算验证。平均 CIF 负荷转移结果不等于边际排放或真实因果减排。

模拟实验只验证工程流程和约束。真实数据上未通过上述检验前，不声称优于现有方法、达到目标覆盖率或具备顶刊发表结果。

当前模拟已出现源留域 CRPS 最优尺度仍明显欠覆盖、集合增益依赖目标能源结构的情况。因此尺度选择与概率校准必须分开报告；有限机制集合和支持诊断继续作为可选实验，尚不替换原基线。

## MAE/RMSE 优化优先级

| 优先级 | 瓶颈与处理 |
| --- | --- |
| P0 | 只有四个固定人工配置，真实签发预报和独立核算仍缺。先建立真实跨年、留整国基准，再讨论 SOTA；新天气随机种子不等于新配置分布。 |
| P0 | CRPS 训练/选模与 MAE 目标不一致。已加入物理点输出、MAE 主导监督、源域 MAE/RMSE 选模及点估计定义审计。 |
| P0 | 原模型的情景中位数可能优于新增点头。已将 mean/median/physical 写入模型配置并提供按源 MAE 选分布模型的路径；所有新方法必须与正确的点估计基线比较。 |
| P1 | 原 TCN 局部场仅 5h，且确定性可用率下限 50%。已提供全时域条件编码器与更灵活的物理参数化，须通过同预算消融判断收益。 |
| P1 | 原训练只约束平均燃料占比，不能充分确定绝对出力。点模式加入按容量归一化的源发电监督；学习率、日程、采样和训练预算均可配置。 |
| P1 | 已实现内层留独立源组/国家的架构和学习率选择。四配置开发消融未显示稳定收益；增加调参预算不能代替足够源域覆盖和真实盲测。 |
| P1 | 已补 CIF 提升树及容量归一化逐燃料提升树，后者匹配主模型的源发电监督，并使用同类公开功率特征；仍需公平适配近期方法。 |
| P2 | 已按天气成员复用编码，并核验情景、输入梯度及参数梯度等价；成员数较多时自动保留逐情景编码。实际加速应报告完整模型测时，不能用编码器调用数代替。 |

## 后续开发结果与论文主张

2026-10-20 的消融仍使用上述四个固定配置。源留组联合选模在两个天气种子上 MAE 为 47.44/56.11，时间选模为 45.64/56.09（单训练种子）。中位数主损失在原开发集改善、另一天气集退化；`covariate` 也未稳定优于原 TCN，均保持可选。容量归一化发电树的 MAE 为 68.45/118.29，较直接 CIF 树的 127.89/138.35 更强，但不能据此声称已比较文献 SOTA。

联合发电评分下，同架构、同预算的资源校准消融如下（各四目标、三训练种子、250 步、64 路径；数值为 MAE / RMSE）：

| 编码器 / 天气种子 | 无资源校准 | 有资源校准 |
| --- | --- | --- |
| TCN / 19 | 44.53 / 60.89 | 43.49 / 58.55 |
| covariate / 19 | 45.05 / 61.40 | 44.22 / 59.48 |
| TCN / 31 | 58.12 / 79.04 | 56.43 / 77.51 |
| covariate / 31 | 55.71 / 75.60 | 54.51 / 74.37 |

四组匹配比较均改善点误差及 CRPS，但不稳定超过此前最佳点模型；四个 MAE 配对区间仍跨零。只有少数固定人工电网、短测试期、连续开发和未校正的多重比较，不能作为确认性显著性或新配置泛化证据。完整记录在 `results/joint-resource-development/`；全部原始输入与对应 Git 源码哈希须匹配。标签解析/修订视图另经缓存加速：72 窗口本机中位耗时约 0.279→0.025 秒，标签值哈希一致，不能解释成端到端训练加速 11 倍。

值得继续检验的论文主线是**区分公开结构变化与不可识别调度状态的无遥测迁移**：先纠正燃料、储能、净交换与发布版本的语义，再学习源支持的联合资源/调度分布，通过物理层迁移到目标。理论部分应刻画哪些机制从现有信息无法区分，以及这种歧义如何影响 CIF 和时段选择；不能把当前有限模型集合称为已覆盖真实机制的识别集合。资源校准和联合评分本身也不足以保证新颖性。

投稿门槛是美国/英国/澳洲真实签发预报、核算一致且独立的标签、源内固定调参后的跨年/留网/留国盲测、近期同信息强基线，以及逐域配对不确定性。现有美国原生燃料/储能和英国消费侧产品已超出六燃料单节点模型的适用范围；目前仍未达到该门槛。
