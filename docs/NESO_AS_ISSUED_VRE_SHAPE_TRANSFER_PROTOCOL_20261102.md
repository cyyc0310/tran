# NESO as-issued风光形状迁移消融协议

冻结日期：2026-11-02；评分前冻结。该实验使用已在先前研究中打开过的GB 2024小时标签，定位为**回顾性开发诊断**，不是盲确认、预注册新域验证或中国预测效果证据。

## 问题与信息合同

问题：相对于中国式滞后五类月发电量`M`，预测起点已签发的目标地嵌入式风光预报`F`，能否改善跨国源小时经验迁移到GB小时发电CIF代理的中心/形状预测？

- 源：美国7个EIA BA；2022训练，2023源校准；目标GB 2024。
- 目标主预算M：项目原冻结器构造的精确`t−2`火、水、核、风、光月份额。其来自小时代理回算，模拟月报滞后，非历史as-issued NBS/ET月值。
- M+F：仅再加NESO逐日09:12 UTC（交付日前一日）发布的嵌入式风/光两类预报。每个UTC交付日内分别按该日预报均值归一成形状；不跨日汇总，不使用当月未来日期的预报来标准化当前日。
- Oracle上限M+F*：评分封存后，以目标小时实际风/光曲线替代F，采用相同的逐日归一。这只诊断“理想小时形状信息”的上限，绝不作为可部署预测。
- 预测共同支持：M、M+F、锚点与Oracle全部限制在有完整日提前F且M合法的相同目标小时。预计缺4个UTC日。目标小时标签仅在所有模型预测与哈希落盘之后用于评分。

## 固定方法和比较

1. `anchor700`：700×滞后月热电份额。
2. `source_thermal_ef`：源2022等区域加权火电有效因子×滞后月热电份额。
3. `coarse_boosting`：原始中国式五类M输入下的源HGB直接CIF强基线。
4. `coarse_recomposition`：原始五类M的源小时粗技术轮廓强重组基线。
5. `forecast_shape_recomposition`：保持完全相同的源训练、源有效火电因子、源热电/水/核小时轮廓与目标五类M；仅将目标风/光归一日形状换为as-issued F。
6. `oracle_shape_recomposition`：与第5项相同，但将F替换成目标小时标签中的实况风/光形状。

方法5、6的目标因子计算仍只用固定EF发电侧代理，非官方碳强度。模型参数不搜索，不按GB目标结果再调节风光权重或月份选择。主要指标：同小时MAE、逐日去均值形状MAE、月MAE、目标日配对bootstrap MAE差。区间只作次级诊断：M+F沿用原强重组的源校准偏差和半径，固定相同宽度，报告经验覆盖/Winkler；这不是M+F自身校准，也不构成90%覆盖保证。若中心增量未达到至少5%宏MAE且多数月份方向一致，则不继续为此分支训练专门风险头。

## 解释边界

- F只覆盖嵌入式风电/太阳能估计，不能假设代表全部风、光发电。日内归一仅迁移形状，不把部分容量尺度冒充全体发电量。
- GB 2024及其小时标签此前已多轮用于方法开发；本轮只能提供同目标信息价值诊断，不能升级盲测证据等级。
- GB单一聚合目标不能支持跨国普遍性；消费侧官方CIF不进入本协议。
- M+F优于M只能说明在该目标和代理标签上的可迁移预测时信息价值；不能把增量归功于新算法，也不能直接外推中国各省的 forecast 产品。
