# V217 EIA本地小时锚总预算前沿协议

V217沿用[V216数据和模型协议](V216_EIA_SPLIT_CONFORMAL_ANCHOR_PROTOCOL.md)，固定中心/校准点等分，仅改变每个目标地区月的目标侧随机小时锚总数`B∈{18,24,30,36,48}`，每个预算重复200次。各自使用`B/2`个锚拟合本地平均残差偏差、`B/2`个独立锚校准绝对残差；90% split-conformal半径取`ceil((n_cal+1)×0.90)`阶次统计量。目标区与源区排除、小时代理标签、2025源期、2026H1评估期、缺失门槛及地区bootstrap均不变。

非随机化有限半径在90%水平要求`n_cal≥9`：`n_cal=8`时所需秩为9，区间需无穷宽；9个校准点时取样本最大校准分数。故18为本轮等分网格里第一个具有有限半径的预算，不代表总目标观测最小值，因为可以用既有源区中心、把全部本地锚留给校准。本协议只评估随机目标小时索引下的点wise边际覆盖，不作固定地区条件或整月同时保证。

执行脚本：[v217_eia_anchor_budget_frontier.py](../scripts/v217_eia_anchor_budget_frontier.py)。
