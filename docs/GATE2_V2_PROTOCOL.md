# 第二关 V2：实现前实验约定

2026-10-23。用户授权尝试采样优化、自己的方法候选、小波尺度对照及动态预测原型。旧三关结果和冻结代码保持独立。本次为方法探索，不宣称任何原理首次提出，也不重用2024真实目标标签选择模型。

## 目标与判据

判断观测后验几何与预测分布目标联合驱动的预算分配，是否比最强标准同预算方法更准确。标准Sobol、多峰局部提议和SMC是比较对象；原多样性方法和预测均值风险分配是消融。只有针对分布目标的收益在不同观测几何下持续成立，才值得继续主张方法增量。

主诊断为39参考分位处、24小时平均CDF差；同时报告CRPS、90%覆盖与宽度、去日均形状误差、energy与variogram评分。CDF差是数值逼近诊断，不是实际电网概率评分。energy的分布内二阶项使用独立配对Monte Carlo；其随机误差不作为主方法选择依据。

第二关V2不会以“胜过旧候选”作为通过条件。每种方法与全部强基线比较；配对种子bootstrap仅描述这些案例，不作为多方法/多场景选择之后的确认性显著性。未设置事后挑选的提升阈值；结果足够好后须另冻结算法，在新的机制/算子族确认。

## 数据、拆分和成本

- `stress_cases.py` 定义5个开发场景、8个预先固定压力场景：不等质量、窄似然、四模式、旋转12维曲线后验、旧观测到未来演化、局部瞬态、无害与增加信息。
- 各场景的先验为标准正态；仅2个有效坐标，其他坐标为可解析积分的nuisance。旋转后采样器不知道有效坐标。它们是数值反问题，不是经过核验的电网模拟器。
- 开发：预算128、512，种子2000–2009；压力：相同预算，种子4000–4019。所有方法全部运行，不根据开发结果删方法或改超参数。压力集为预先固定补充评价，不冒充大规模真实地区外部验证。
- samplers只获得evaluate、维度、预算、种子；不提供模式数、有效坐标、参考网格或测试真值。pilot、局部差分、中心更新和MH移动每个forward行均计费；报告实际调用及时间。SMC可少用至多4行，所有方法均不能超过声明预算。
- 独立参考在(v,w)坐标做梯形积分；粗1201×161、细2401×321，固定v∈[-8,8]、w∈[-6,6]。报告网格加密的CDF及90%端点差；细网格作为评分参考。可剔除单点权重<1e-15但记录剔除总质量。参考计算独立记账，不计入方法预算。
- 测试真值16条由细参考独立种子96311抽取，仅供评分。原有pilot不读取真值。固定box仍有尾部截断假设，不称数学精确参考。

## 候选与消融

第一组：先验随机/Sobol、原高斯/多样性、共享局部几何的随机/QMC多峰提议、固定温度SMC。

第二组：按局部预测均值风险分配质量（goal_time/dct/haar）。第三组为自己的研究候选：按局部近似后验的CDF估计误差分配质量（goal_cdf_time/dct/haar）。共享pilot、中心、协方差和计算量，只改变提议质量。

CDF候选依据Bernoulli指标的局部二阶误差，近似各模式对预测CDF数值积分方差的贡献；阈值从pilot预测选取，局部概率用差分导数传播到Gaussian近似，再用posterior_mass×sqrt(risk)分配提议。最终样本始终按完整pL/q校正。最优重要性分配和delta/Laplace近似均已有先例，新的组合是否有贡献由证据决定。

小波采用完整正交Haar，DCT为正交DCT；等权变换保持距离，作为不变性对照。固定非等权尺度效用可精确改写为时间域二次核，不能将其收益自动解释为小波独有优势。细节权重为明确的开发假设，不能按测试表现调节。

动态预测采用独立协议、代码和输出，见DYNAMIC_V2_PROTOCOL.md。只用2022拟合及构造时间外残差，2023逐区作为本轮源域探索验证；不触及已看过的2024评测。

## 复现与回退

运行脚本在首次执行前保存本协议、依赖版本、代码hash和参数；输出目录非空则拒绝覆盖。运行完成核对代码hash，失败或修改后的实验保留原记录。候选不成立时保留为负基线，不替换原方法或修改旧第二关通过状态。
