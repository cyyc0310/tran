# US→GB 2026年12月前瞻输入时效对照：较新月量移动预测中心，尚无准确度结论

完成日期：2026-11-02。冻结输入协议：[t−2对照协议](PROSPECTIVE_GENERATION_US_GB_DEC2026_TMINUS2_PROTOCOL.md)。正式预测目录：[r2封存结果](../results/prospective-generation-us-gb-dec2026-tminus2-r2/)。运行器：[封存脚本](../scripts/seal_prospective_generation_us_gb_dec2026_tminus2.py)。

## 实验与预测时点

在此前已封存的12月双向US↔GB预测上，只改变US→GB目标端可见月份：原预测使用NESO 2026年9月（t−3）；本轮改用公开Datastore截至2026-11-02 03:23:29 UTC前已可查询的2026年10月（t−2）燃料结构。源训练、校准、算法、目标窗口和预测队列不变。GB→US的ERCO/FPL两项保留为反向对照，预测数值逐行完全相同。

NESO输入来自公开历史燃料结构当前快照，按London当地月界提取10月完整月份；夏令时回拨后该月为745个本地小时、1,490条半小时记录。将煤、气、生物质与Other按既有预算映射到热电，风加嵌入式风电，水、核、太阳能单列后做五类归一。该月量从公开半小时历史出力聚合而来，不是历史首发月报值；源端明确指出历史记录可能因清洗改变。标签是固定因子发电侧代理，不是官方或实测CIF。

预测目标仍是2026年12月744小时。点预测、区间和输入已先封存；`prediction_seal.json`逐文件写明未在预测前读取目标响应，`status.json`记录尚未评分。全部预测文件及19项来源/代码哈希复核通过。

| 水电 | 1.45% | 2.02% | +0.57 |

| 风电 | 40.90% | 40.51% | −0.39 |
| 太阳能 | 9.22% | 6.04% | −3.18 |

换入10月数据后，US→GB来源热电锚点整体上移：`anchor700` 744小时平均增加9.14 gCO₂/kWh，源火电有效EF头增加7.35，比例重组增加6.94；粗Ridge平均增加12.27，粗Boosting平均仅变化−0.52（小时平均绝对变化2.79）。日历Ridge不依赖这些月量，预测完全不变。

**六种方法的来源90%区间平均宽度均没有改变。**输入月份额只移动或改变预测中心；来源校准半径冻结，因此没有利用10月信息估计目标域风险或实现区间缩窄。这轮只能证明一个月的新信息会改变预测值，不能证明变化方向更准、覆盖得更好或具有跨域适应收益。

## 对四项研究重点的影响

- 对优先级1，补上同一GB目标窗口上真实公开月量时效（t−2/t−3）的配对前瞻预测输入；GB历史数据仍是当前修订状态，尚非完整as-issued链。
- 对优先级4，直接看到“中心变化与风险半径不变”可以被区分。当前数据时效增量本身不提供可信区间缩窄；需等标签成熟判断中心误差是否改善，不能按封存结果选择方法。
- 对消费侧，NESO五类本地发电月量没有给出跨省输入来源和来源碳强度，本轮不用于消费CIF，GB→US消费轨也不在此结果中。
- 对优先级2/3，没有新训练方法或燃料响应证据，本轮不晋级算法。

12月目标响应按前瞻评分合同至少等到2027-02-03 UTC后再读。届时同队列、同标签下比较原t−3与新t−2，并报告MAE、覆盖、宽度和区间分数；不以预测本身移动多少作为收益。
