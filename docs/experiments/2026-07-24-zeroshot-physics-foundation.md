# 零样本 config-only 基础验证（真实 SA1 样本）

**日期：** 2026-07-24
**脚本：** `scripts/zeroshot_physics_validation.py`
**性质：** 在重构 TransCIF 为"纯零样本 / config-only"之前，对该设计的**根本假设**做机制级验证。**不训练完整模型**。

> **数据披露（如实）：** 本机 `/tmp/nemed_output` 全量 NEMED 多区域数据**已不存在**，且无逐电源出力明细。当前唯一真实数据是 `tests/fixtures/real_aemo_sample_sa1.csv`（SA1 单区、300 条逐小时、二元 renew/non-renew 聚合，时间 2023-01-01 00:00 .. 2023-01-13 11:00）。因此**真实的多 ISO / LORO 零样本验证被数据获取阻塞**，本实验仅验证机制基础。所有数字均来自上述真实样本，未使用任何合成或虚构数据。

## 被验证的根本假设

零样本 config-only 设计成立的前提是：
> CIF(t) 可由（跨域不变的）发电**结构** + 域相关**配置**（排放系数 ef_g）合成：`CIF = f(structure ; config)`。

## 实验与结果

样本统计：CIF 范围 28.6–504.6、均值 121.1 gCO₂/kWh；renew_share 均值 0.787（SA1 高可再生特性）。

| 编号 | 实验 | 结果 |
|---|---|---|
| **E1** | 物理合成天花板：用**真实 renew_share** + SA1 config(0 / 490.43) 合成 CIF | **MAE = 16.91 gCO₂/kWh** |
| **E3** | 日前持久性基线（lag-24h） | **MAE = 72.13 gCO₂/kWh**（须超越的门槛） |
| **E2** | config-swap 敏感性：对 SA1 真实结构套用**其它区域**的 ef | 见下 |

**E1 附注：** 数据反推的等效非可再生因子均值 610.4（std 84.2），高于 config 常数 490.43——说明二元常数因子只是近似，这 ~120 的偏差是 E1 残差（16.9）的主要来源。

**E2 config-swap（仅换 config、结构固定 → config 控制 CIF 量级）：**

| config | ef (renew, nonrenew) | 合成 CIF 均值 |
|---|---|---|
| AU_SA | (0.00, 490.43) | 104.5 |
| AU_NSW | (0.09, 875.23) | 186.6 |
| AU_QLD | (0.00, 841.59) | 179.3 |
| AU_VIC | (0.00, 1160.12) | 247.2 |

> E2 是**机制演示**：把别区 ef 套在 SA1 真实结构上，说明"改 config 即改 CIF 量级"；并非预测这些区域的真实 CIF（它们的结构不同）。

## 结论（对重定位的直接影响）

1. **零样本基础成立**：给定正确结构，config-only 合成极准（E1=16.9），比持久性（72.1）好约 **4 倍**；且 config 可干净地控制 CIF 量级（E2）。这为"纯零样本 config-only"提供了正面证据。
2. **真正瓶颈是"跨域结构预测"，不是物理层。** 此前 SA1 零样本失败（physics_only≈84）根因是共享模型把 SA1 的结构（高可再生）预测错了——它在低可再生的 QLD/NSW/VIC 上训练。→ 重构的**首要投入应放在"让共享结构预测器在目标域也准"**（config 条件化 FiLM + 多样化源域池），而非首先纠结二元→多电源。
3. **二元→全电源 ŝ_g 降为二阶精修**：E1 已证明二元在"结构已知"时足以远超基线；全电源 ŝ_g 主要收益是消除 490→610 的因子偏差（把 16.9 再压小），属于精度打磨而非成败关键。
4. **数据获取是当前头号阻塞项**：多 ISO + 逐电源数据缺失，无法做真实 LORO 零样本。需优先接入 Electricity Maps / ENTSO-E / CAISO。
