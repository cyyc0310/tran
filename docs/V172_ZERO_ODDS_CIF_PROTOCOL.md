`log q_i = log p_i + α Σ_f [z_if log(τ0'_f/π0_f)+(1−z_if)log(τ+'_f/π+_f)] + normalization`。

用稳定log-sum-exp，指数相差低于−700的项按−700截断，与此前权重控制一致。原子始终有正权，物理样本和CIF取值不变，G>0。某燃料源支持只有一类时不更新该坐标，记录不可实现的目标零质量差；不能添加未观测小时或伪造支持。

这是普通乘积赔率/温度化权重控制，不是精确多边际raking，也不保证目标零概率被精确满足。关联零事件可能重复计权，正是必须与强基线比较的原因。α=0直接返回原law，不用重新数值构造。权重可以改变燃料期望及粗锚；不宣称本轮固定月度均值，须报告前后燃料均值，避免误把水平修正全部归因于尾部。
