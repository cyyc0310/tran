# V386：上海年度电力平衡对 CIF 目标边界的约束

登记日期：2026-10-31。问题：用户提供的上海月度火、水、核、风、光发电统计，足以支撑哪类 CIF estimand；若目标是消费侧因子，还缺什么信息？

## 冻结分析

从上海市经信委《上海电力供应环境可持续性关键绩效指标报告（2024年度）》转录五个年度锚：全社会用电1984亿kWh、本市发电1085亿kWh、市外来电899亿kWh、本地新能源发电103.5亿kWh、可再生能源消纳量622亿kWh。输入逐字段存于`data/china/shanghai_2024_power_balance_anchors.csv`并附官方来源。脚本验证`本市发电 + 市外来电 = 全社会用电`，计算本地/市外电量份额及新能源供给与消纳之间的描述性差额。

另做一个纯敏感性算术：固定上海本地年平均强度，仅令进口电平均直接EF在`[0,1000] g/kWh`内变化，则进口项单独给消费侧年平均因子带来的区间宽度为`进口占比×1000`。该区间不是估计得到的EF支持，不用于预测表现；只用于量化进口因子缺失在一个宽但明确的假设下可有多大影响。

## 结果解释边界

用户NBS表是本地发电侧的类别电量。上海年度供需平衡显示约45%的用电由市外输入；年度本地发电构成不能决定消费侧CIF，除非同时取得发送地区/电源、输电流量、逐时进口及其对应排放因子。年度可再生能源消纳口径高于本地新能源发电量，提示绿色属性与电力来源也需分开处理；两者之差只作量级提示，不宣称来源归因恒等式。

本分析不检验预测精度或小时风险覆盖，也不改变V108的generation-based estimand。2025年官方报道只说市外来电“接近五成”，不把模糊措辞转成精确比例。完整结果见`V386_SHANGHAI_CONSUMPTION_BOUNDARY_RESULTS.md`。
