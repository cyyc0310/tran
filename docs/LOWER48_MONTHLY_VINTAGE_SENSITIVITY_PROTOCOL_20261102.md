# EPM月报修订对Lower 48跨国预测的影响：冻结协议

冻结日期：2026-11-02。此项是优先级4（真实月报适配/可靠性）的数据版本敏感性审计，不是新算法试验。

## 目的与边界

检验：在相同目标2024小时、同一GB源模型和校准、同一EIA-930 Lower 48最终目标标签下，若输入粗月量由预测起点前可见的EIA Electric Power Monthly（EPM）首发版换成一年后同月EPM发行中的修订版，预测和评分改变多少。

目标发行月报先前使用美国全国总计行代理Lower 48，故本试验只比较**相同统计边界的两种版本**，不把结果写成Lower 48精确边界或中国输入的精度验证。尝试从州行汇总时，火、水、核、风、光多个州级单元被抑制；不置零、不用来构造“完整同域”特征。

## 设计

- 主预测：复用`lower48-actual-issue-dual-track-r4`中2024每月预测起点前最近的EPM首发版本及其`t−2`月量。
- 修订预测：对每个目标月，改用**同一观察月在2025年同月EPM发行包中的数值**，其余粗组成映射、日历、GB 2022训练、GB 2023校准和全部预测器完全相同。只替换目标五类月量；不训练、不校准、不调参。
- 两个版本全部预测先写盘并SHA封存，再读取同一Lower 48 EIA-930目标小时结果评分。发电/消费强度分别保留，不合并。主输出报告逐月粗输入改变量、预测逐小时差值、MAE/CRPS/区间分数/覆盖差。
- 2025年同月修订值是事后版本，只用于敏感性计算，绝不作为2024预测时可用输入。目标标签是当前归档快照，统计范围仍与US全国EPM输入不完全一致；区间为单一GB源校准经验区间，不是跨国保证。

## 判读

若首发与修订输入的预测/排名变化可见，说明回测必须锁定发行版本，当前历史下载值不能替代当时已知值；无论误差变好或变差，都不得把修订值的成绩归因于一个部署算法。若修订敏感性很小，也只说明该样本与模型下影响有限，不证明其他国家/指标不存在版本问题。

## 复现

先获取EIA官方2025年1–12月EPM ZIP发行档案并记录HTTP元数据/原文件SHA。复现入口：`PYTHONPATH=src python scripts/run_lower48_monthly_vintage_sensitivity.py --output results/lower48-monthly-vintage-sensitivity-r1`。报告目标地理错配与单源区间限制。
