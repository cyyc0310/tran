# 年度煤／气装机叠加官方月报的同任务结果

日期：2026-11-01。实验检验用户新批准的信息预算：在官方EIA-923 BA级粗月量之外，额外增加预测时可公开的年度煤／气装机结构。使用[冻结协议](EIA923_CAPACITY_INCREMENT_PROTOCOL_20261101.md)，保留US↔GB双向、2022源小时监督、2023风险拟合/校准、2024目标评测、t−2月量、七种预测器和三类90%区间。

## 对照结构

- **M**：EIA-923美国BA月组成＋GB原NESO小时回算组成。
- **M+C**：同一个月统计模型上，将热电因子换成`400 + 600 × 年度煤装机/(煤装机+气装机)`；该比值逐地区设置，对点预测重新拟合源端区间。

目标标签只在112份预测文件写出并封存后读取。M臂的112份预测与上一轮EIA-923官方月量实验逐文件字节一致，确认了本轮比较只增加装机处理。年度结构为2020统计年，US按登记BA聚合，GB采用UK（含北爱尔兰）统计代理；数据不是逐小时运行结构，也不是历史as-issued版本。来源和范围见[容量预算审计](PUBLIC_CAPACITY_ANNUAL_AUDIT.md)及[原三国装机实验](OFFICIAL_ANNUAL_COAL_GAS_CAPACITY_RESULTS_20261101.md)。

## 逐区失效与判断

GB→US本地Ridge中，MISO的90%覆盖从44.4%降到7.9%，MAE从131.0升到205.4；BPAT从MAE13.2、覆盖100%变成MAE152.8、覆盖1.4%。CISO、ISNE和NYIS仍覆盖较高，但严重失效地区抵消了这些结果。US→GB唯一目标GB的本地Ridge MAE从63.0升至129.2，覆盖从89.8%降至73.8%。

在当前实现中，这个失效模式符合“nameplate容量结构不能直接代表小时发电量结构”的解释：容量因子锚逐地区直接改变火电有效因子，却没有观测或推断煤/气机组的利用率、燃料调度和跨燃料结构。逐区结果支持这是合理解释，但单轮实验不能证明每个地区误差由该机制单独造成。

因此，本轮结论应写为：

1. 公开装机有研究价值，且用户允许将其作为独立信息预算；但**在官方月量之上直接把装机份额硬转换成火电因子无效**，当前不得进入主模型。
2. 如果继续探索，应把装机作为弱先验/支持特征，并让源端数据学习容量到实际发电结构的偏差；关键对照是地区留出和国家留出下相同月报预算。当前七个BA加一个GB单元不足以学出可迁移的容量利用率映射，暂不在本回测上继续调比例以追求收益。
3. 研究主线仍应是跨国小时CIF迁移：装机是一项附加预算，不替代月度发电信息，也不是算法创新本身。中国的装机信息可作为可选输入层，不能因本轮负结果就删去基准中的独立预算档。
