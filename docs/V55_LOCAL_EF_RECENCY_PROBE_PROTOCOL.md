# V55 本地热电 EF 时效窗口开发探针

日期：2026-10-27。目标是假设：V54中PSEI/LDWP后段偏差可能来自完整年度thermal EF对燃料结构变化响应过慢。只做已打开数据集上的方法开发，不称为独立确认。

## 数据划分与信息时点

用2025 H1在此前11个来源区做来源留一校准/方法比较；2026 H1作为时间前推评分期，包含11个来源区和此前已打开的六区。小时形状只来自11个旧来源区上一年同月；目标粗量继续使用预测起点可得的上一年同月五类月报；目标本地燃料月统计只用于EF估计。每条月报均要求 period_end 和 available_at 不晚于预测起点。2026 H1标签不用于方法选择以外的独立论文确认，因此此轮只报告开发证据。

## 预先固定EF候选

`donor_same_month`、`local_latest_complete_year`、`local_latest_asof_month`、本地最近连续3/6/12个可得月的燃料量加权EF。窗口必须是连续已发布自然月；不足窗口则该预测不可用，不向未来借数据、不补零。每个EF方案各自用2025 H1来源区残差校准pooled q90和source-max q90。全部方案都评分，禁止看完结果再删失败方案。

## 输出和解释

按区域等权报告2026 H1 point MAE、bias、pooled覆盖、最差区覆盖、区间宽及Winkler；同时列每区和缺测月份。若短窗口胜过年度锚，只视为“信息时效值得继续研究”，仍需至少一个未参与本探针的新年份/来源池独立复现。标签仍为EIA固定因子正部已报告发电代理，并非实际全网排放。
