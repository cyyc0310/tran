# 捷克源域增量拆分：国家内容、源样本量和区间校准

冻结日期：2026-11-01，r2运行前。该实验跟进六国LOCO中“直接头随捷克源域改善、强重组没有改善”的现象，拆开训练源域组成与校准样本组成的作用。标签仍为Energy-Charts固定因子发电代理；所有地区已进入开发，不是最终确认。

## 目标、可见输入与切分

- 外层目标固定为原五国NL、ES、BE、AT、SE，逐国留出。每折使用其余四国；2022训练小时、2023H1校准、2024目标评估。目标输入仅为日历和当前修订小时数据回算的`t−2`及更早粗月统计，目标标签在预测文件封存后才评分。
- 目标端原五国、每种方法、共同小时支持、字段、模型超参数与五国LOCO相同。只评估同一八种既有预测器，不添加新的学习方法。
- 比较训练来源：`old4`（其余四个原源国）、`old4+CZ`（完整捷克源）、`old4+PX`（等量伪来源）。PX为从old4的同一训练小时池中无放回抽取、行数与CZ 2022可用训练行完全相同的一批记录，随机种子按外层目标固定。PX行的country/region键统一为PX，源权重与CZ单一地区相同。
- 比较校准来源：`old4`、`old4+CZ`、`old4+PX`。PX从old4的2023H1可用校准行池无放回抽样，行数与CZ同期可用行数相同。样本身份及种子写入审计文件。
- 对三种训练池各自拟合源模型，并对三种校准池各自重估绝对误差90%经验半径，共得到3×3的训练/校准组合。PX复制的观测只作来源量/域槽位控制，不作为独立国家或新标签证据。

## 主要归因对照

1. **训练内容增量：** 固定`old4`校准，比较`old4+CZ`与`old4+PX`点预测和区间结果。两者训练新增小时数和源域权重相同，变化主要对应捷克来源内容与既有源重复抽样的差别。
2. **纯校准增量：** 固定`old4`训练，比较`old4+CZ`和`old4+PX`校准半径；点预测须逐元素不变。
3. **训练×校准联合：** 比较对应的同源池`old4+CZ / old4+CZ`和`old4+PX / old4+PX`，检查训练内容与风险支持的交互。
4. `old4/old4`作为本轮同进程重建基线。旧版探索运行曾出现`BE/direct_history`差异；正式r4在项目支持环境中重新核对，40/40共同目标/方法点预测均在绝对误差`1e−8`内复现。旧运行没有完整记录包版本，因此不把差异归因于单个依赖。正式结果采用r4；旧运行只保留为迭代记录。

主要指标按目标国、再按月份等权：MAE、日内去均值形状MAE、90%经验覆盖、区间宽度、区间分数。五国为外层统计单元，小时不是独立重复。不得根据外层目标分数挑选模型、随机种子或区间规则。

## 解释边界

PX是对额外同权来源槽位和等量行数的控制，不是自然国家；样本从旧源抽取且与原训练池部分重复，因此回答“新增CZ是否超出增加同权旧源质量”，不代表所有国家的域多样性效应。若CZ只帮助直接头但不胜强重组，或覆盖增益依赖加宽，不能称为可部署算法增量。结果不能证明中国小时准确度、as-issued发布可见性或跨域覆盖保证。

## 运行版本记录

r1的历史复现差异已由正式r4复核解决：隔离环境使用项目支持范围内的NumPy 1.26.4与pandas 2.2.3、scikit-learn 1.8.0，40/40共同预测在`1e−8`内复现。由于旧封存未记录完整依赖版本，不能据此断言是哪一个包导致了旧差异。正式指标、输入和代码封存均以r4为准；r1至r3仅作开发过程记录。

## PX抽样敏感性复核（r5）

为判断r4中单个PX随机抽样是否驱动结论，固定所有原始输入、目标国、模型、训练/校准时段、指标及预测规则，仅改变匹配样本的抽样身份。保留r4根种子`20261101`为锚，另预先固定五个根种子：`20261102`、`20261103`、`20261104`、`20261105`、`20261106`。每个根种子分别生成五个目标折的2022训练PX抽样和2023H1校准PX抽样；不按目标结果筛选种子。每个种子独立运行并封存所有预测后才评分。

报告五个新种子的PX臂逐种子指标、目标国指标及其均值/范围，并与每折不变的old4和CZ臂对照。主要判断是CZ相对PX的训练内容优势、PX自身相对old4的抽样波动，以及校准尾部差异是否持续。该敏感性分析仍只有五个开发目标、固定因子发电代理和同一旧源池；它只能判定抽样稳健性，不能证明独立国家多样性效应、真实中国CIF精度或可迁移区间覆盖。
