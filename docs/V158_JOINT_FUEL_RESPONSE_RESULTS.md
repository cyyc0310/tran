# V158：联合燃料残差与响应字典没有形成稳定增量

Sol。12/12组合已完成，主实验与比较审计均exit0。完整1440条评分，36个已查看目标区月、两源划分、两预算、五模型、两校准；重复方法和校准不增加独立目标数。288条标量臂记录的CRPS、MAE、覆盖、宽度、Winkler复现V156。源抽样360条、归档哈希、12组proper源原型及144条asof重复控制核验通过。未打开新地区。

结论：普通联合监督有局部价值；截负归一普遍损害概率评分；响应字典没有稳定胜过普通联合模型，四个组合都输给小时重组。本轮不晋级，不以更窄但失覆盖的区间宣称效率改善。

## 收益归因

- **普通联合监督。**joint_linear相对标量锚定的CRPS在同月仅改善0.66%/0.20%，滞后改善3.07%/6.71%。后者第二划分最差覆盖82.26%，第一划分宽度略增0.24%，均未联合达标。
- **截负再归一。**joint_nonnegative相对joint_linear的CRPS四组恶化4.55%/4.59%/10.51%/7.78%。物理可行并不保证概率正确。
- **合法零支持。**只在同月提供额外作用；相对非负修复CRPS改善3.85%/5.21%，仍输小时重组，覆盖也不足。不能把当月零燃料硬约束用于未来月。
- **响应字典。**相对joint_budget仅在滞后第一划分改善1.21%，另外三组恶化0.64%/1.08%/5.97%。四组按共同日历月份配对的描述区间均跨0；不是稳定新增信号。相对小时重组，CRPS差距为+6.96%至+23.04%，四组描述区间都在较差一侧。
- **强条件模型。**响应版本在滞后第一划分胜异方差模型5.44%，覆盖达标且宽度下降3.71%；但该组仍比小时重组CRPS差18.10%、区间评分差4.58%。单独选择这一个较弱参考会造成错误创新归因。

max-region校准可使响应版本覆盖达到95.51%–100.00%，宽度却为286.23–672.37；CRPS没有变化。不能用这种覆盖修复宣布成功。[消融](../results/v158-joint-response-audit-r1/ablation_comparisons.csv)、[配对描述](../results/v158-joint-response-audit-r1/paired_month_crps.csv)。

## PACE和LGEE的失效位置

PACE同月响应版本覆盖75.64%/68.86%，小时重组为87.40%/87.17%；区间缩窄伴随严重漏盖。滞后第二划分PACE覆盖75.13%，低于小时重组87.82%，这不是尾部支持问题已解决。

LGEE同月响应CRPS19.39/20.71，与小时重组20.05/20.40没有跨划分稳定优势。滞后响应CRPS49.18/56.82，小时重组28.50/28.27；第二划分LGEE覆盖87.29%，亦低于普通联合线性臂98.56%。本轮响应嵌入没有解决组成时效下的负迁移。

## 更具体的失效解释：加性份额坐标并不随月度组成保持不变

proper源诊断共12上下文、60原型，不使用校准或目标标签。把d=s−S平移到另一个月度组成，平均约77%的源小时出现负燃料分量；修复改变CIF的比例，同月平均81.15%、滞后76.67%。因此，修复不是罕见边缘处理。字典有4–5个活跃维度，标准化方差中相对标量残差**线性**回归仍有26.68%–70.11%未解释；这不证明它含有非线性标量变换无法取得的信息。修复回退次数全部为0，失效不是除零回退导致。

一个无目标数据的两小时构造说明坐标问题：源月煤/零碳能源占比20%/80%，目标80%/20%；两地共享相同燃料发电形状Q=[[1.8,0.2],[0.2,1.8]]，每燃料两小时平均均为1，源与目标月能源边际均精确满足。目标真实CIF为972.97/307.69；直接迁移源份额差并截负归一得到1000.00/627.03；乘性发电形状重组精确恢复目标。

这个反例不证明真实误差全部来自该原因，也不证明乘性模型总是正确。它说明：即使两地的潜在燃料发电形状完全共享，份额差仍会因为总发电分母随组成改变而变化。继续强化这种差分标签的森林分裂，不能修复这个基本不变性问题。[构造记录](../results/v158-coordinate-counterexample-r1/summary.json)、[带完整前后哈希的源诊断](../results/v158-response-dictionary-diagnostics-r2/summary.json)。r1诊断遗漏部分数据依赖的哈希，r2补齐并完全复现60条几何结果；这不是额外准确率试验。

## 下一步与论文判断

停止沿V158的加性份额残差＋事后修复路线调分裂规则。下一轮应先做**乘性燃料发电形状坐标下的同监督强基线**，再检验物理响应学习是否仍有增量。普通比率重组本身就是现有强基线；换坐标、换森林都不能单独算创新。方法应先在proper源内部做地区留出选择，校准源与当前目标只承担冻结后的评价，不重新扫描目标超参。

本轮未满足原小时预测门槛，不能冻结方法或打开新地区。响应嵌入森林属于有限特征核的现有方法族，且没有稳定性能收益，目前不足以支撑方法论文。[相关原论文与代数边界](V158_METHOD_NOVELTY_BOUNDARY.md)。发布时点、零本地小时输入、粗统计可识别边界和可复现迁移基准仍有研究价值，但还缺有效的新机制及独立确认。

模型使用固定EF的非负生产CIF代理、回溯质量筛选及模拟发布时点；不是中国实际小时排放验证。中国原始表头、修订版本和标签仍待接入。用户确认各发电类别可得支持继续研究细燃料月度预算，不能替代这些核验。
