# V30 独立设计预审：条件粗尺度信息价值

2026-10-26，Sol；只读设计与 V29 结果，未读取新的实际月度数组、小时响应或未知地区值。本文件只评估研究原则；实现、正式协议与最终 producer 绑定须另审。

依据：`docs/COARSE_CONTEXT_V30_DESIGN.md`、`docs/CONDITIONAL_LAW_V29_RESULTS.md`，以及拟锁定的七地区留一区、五特征族、Ridge／ET 点估计合同。

**原则结论：允许推进源开发的粗尺度条件信息价值实验；尚不构成正式执行批准。** V29 普通 Scale-anchor 只有一个配置临界过门槛，且存在 MISO／ERCO 交换，因此先检验合法月度上下文能否改善跨区燃料水平，问题合理。这条路线本身不实现原创方法突破，也不授权未知地区实验。

## 可接受的实验含义

当前实现的五组组成 `g` 是条件逆问题的输入。即使所有滞后上下文按月初合法，当前月实现 `g` 仍是 oracle 诊断信息：本轮估计“给定实现粗组成时，公开历史能否帮助推断隐藏燃料比例”。它不能证明月初未来预测能力。未来接回小时阶段时，必须沿原 MG 预测分布积分，并另行锁定合同；不能将当前实现 `g` 替换进去。

普通 Ridge／ET 若已解释收益，应归为信息利用与强参考改进。粗比例或 EF 点误差改善不推出概率校准、小时覆盖、形状恢复或调度识别改善。本轮只有点模型，不需要为不存在的方差模型增加 inner LOSO。

## 正式协议与实现必须满足的合同

1. **五族同队列。** G5、Season、History、Trend、Size 全部使用相同完整三条合法历史和相同正 POS 当前标签队列。G5 也必须在这个新队列重训；不得把原 V29 不同队列结果作为历史特征增益的配对基准。应固定零值／非有限值／缺失月份的处理及正值阈值。
2. **特征维度与归因固定。** 拟议的累积维度是 5、7、28、30、31；Season 是月份正弦／余弦，History 增加三条各五组组成、三条月龄与三条发布年龄，Trend 增加两条历史月均功率的对数比，Size 再增加最近历史月均功率的对数。月均功率按所选过去期间的日历小时计算。Trend 与 Size 只能使用合法所选过去总量，不能读取当前总量。需要同时报告相对 G5 与相邻族的配对差，避免将季节、历史、趋势和规模的累计效果混称为单一机制。
3. **逐样本 as-of。** 每个当前标签月的 origin 都是该月月初；候选历史须 `period_start < origin`、`period_end <= origin`、`available_at <= origin`，并固定排序与三条选择方式。历史不是截至 2025 年统一截断后再回填。发布代理只能支持“按该代理可得”的结论；不能因此声称真实发布日期或中国数据 vintage 已认证。源监督的当前 `g` 与隐藏 `r` 可以在部署截止前已发布，不能据此放松上下文在各自 origin 的可得性。
4. **公开组与隐藏标签隔离。** 可见 POS 从四个公开零碳组的补集构成。当地 coal／gas／oil／other 不进入上下文计算、有效性筛选、排序或元数据。改变当地隐藏分项为非数值毒值、保持合法可见组与 total 不变，全部上下文特征应不变。监督隐藏标签仅能在排除 outer 后进入训练；outer 隐藏标签的正值／有限性条件只能属于预先固定的评分标签队列，不能影响任何拟合或预测特征。
5. **拟合只看六源。** 七个 outer 各自拟合五族 × 两模型，共 70 fits；过滤后重新按训练地区均衡，不能沿用旧队列权重。Ridge alpha=1，其加权均值／标准差只由训练源计算，并固定常量列处理；ET128leaf2 使用原始特征，采用相同训练权重。区域身份、outer 隐藏统计及目标标准化不得间接进入输入。
6. **预测先完整封存。** 全部七地区、五族、两学习器的预测与必要的 cohort/support 元数据须在读取 outer 隐藏评分值前完整封存。各 fit 排 outer 全历史；当前 outer 的公开 `g`、合法公开历史和过去总量属于已声明输入。不能先看某区误差再改变族、窗口、模型或筛选。
7. **组成与 EF 定义。** 预测 r4 一次投影到 simplex 后用于比例和 EF 点评分；固定零 POS 处理，不能反复投影或按真值调中心。EF 使用固定的燃料系数与已声明单位；若评的是隐藏正排放混合的条件 EF，它不是完整电网 EF，须区别于乘当前 POS 后的量。
8. **地区均衡与交换可见。** 先算每区合格月误差，再等权宏平均，明确 r4 MAE 的分量聚合与 EF 误差定义，并报告每区 signed bias、MAE 与合格月数。需同时给出 MISO／ERCO 和最差区表现；大量相关月份不能当独立地区重复。此处训练权重与评分地区均衡分别说明，避免把加权残差汇总冒充宏地区指标。

## 结果解释边界

正式协议应在评分前固定“何种跨地区信号值得继续”的判定，至少同时检查宏误差、地区集中与 MISO／ERCO 交换；如没有单一成功门槛，应明确本轮为描述性信息价值筛查，并预先固定完整报告全部十臂。七区均已查看，本轮任何胜出仍是源开发结果。

月龄与发布年龄可能编码季节、地区发布习惯或数据生产流程。即使严格合法，它们的收益也只能归于该代理信息预算下的条件预测，不能单独解释为燃料机制或可迁移的物理规律。需要报告这些特征的支持范围以及 outer 是否超出训练范围，但诊断不得用于评分后的重选模型。

未发现需要否决上述研究原则的确定性问题。最终实现批准仍需核对正式协议、producer 和合成隔离测试；本文件不预判实际增益，也不打开新的实际数据读取权限。
