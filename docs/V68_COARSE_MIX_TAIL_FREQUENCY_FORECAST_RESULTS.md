# V68：月度燃料构成的下一月小时尾频率跨区预测（2026-10-27）

V68将目标从事后小时界限改为预测：用目标月起点前可合法看到的最近月度燃料构成，预测下一完整月份小时固定EF代理强度超过阈值的比例。17个EIA平衡区都已在先前开发中查看，因此这是留区开发而非盲测。2026H1每阈值有100个区域月，输入月特征按月末+30天释放规则筛选；小时标签也按月末+30天作回顾性可用假设，但原生首次发布时间未归档。标签是固定EF正发电加权代理，不是完整电网消费CIF。

## 解读与下一步

这是一个可追踪的非线性开发信号，尤其τ=300/600；它尚不能证明收益来自“完整燃料构成”，因为ExtraTrees与Ridge的函数族不同，亦未做同一树模型下的特征预算消融。必须先以相同留区、逐月切分和树超参数比较：只含最新热组EF/日历、最新全构成、再加三月组成；并报告相对最新EF基线的地区聚类差值。若全构成树仍有明确增量，再进行预先冻结的真正未查看地区确认；若增量消失，关闭“构成交互”创新，只保留非线性基线表现。

因此V68**还不是突破**，但给出了一个可证伪且具体的下一步：判明非线性收益是否由低频全燃料组成信息带来。不得将这轮结果写成小时概率覆盖、区间保证、中国验证或独立新域确认。协议、实现与原始指标见[V68协议](V68_COARSE_MIX_TAIL_FREQUENCY_FORECAST_PROTOCOL.md)、[脚本](../scripts/v68_coarse_mix_tail_frequency_forecast.py)及[`results/v68-coarse-mix-tail-frequency-forecast-r2`](../results/v68-coarse-mix-tail-frequency-forecast-r2/)。
