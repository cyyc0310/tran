# 总发电与火电日幅度：先训练普通源端参考

2026-11-01，Sol。R6a/R6c之后的开发准备，不是未知国家确认或原创方法协议。完整天气R6b的代码、参数和原结果不变。

目的：为后续比较独立风光修正与总量/火电协调，先建立普通预测头。未来总发电不是已知输入，也不是负荷；本阶段不产生2023目标预测，不读取2023小时标签评分，不增加训练标签。

沿用R5严格配对35448个2022源小时，6组单国/双国供体；源端可见输入仍为t−2粗月报、日历、2016–20气候参考，可独立加ERA5训练天气。ERA5是观测训练预算，不能称历史签发预报。年度装机不进入这两个头；同一源模型可在后续两个信息预算中复用。

标签分别为源实际日平均总发电/合法过去月平均总功率，以及源实际日平均火电/过去月平均火电功率。分母按本地月实际小时数计算。零火电分母行只从火电头训练中排除，不用目标信息补齐。总量指6粗技术求和。单位为MW等效功率，幅度无量纲。

固定普通Ridge(alpha=10)与HGB(200轮、7叶、叶最少5日、学习率.05、L2=1、seed416)，使用清理过日谐波的原资源特征和国家→地区→日等权。以log1p幅度平方损失拟合，逆变换是位置参数，不宣称物理条件均值；输出截断至非负和该次proper source训练幅度最大值，后者不是目标物理上界。

不选模型，完整保存总量/火电×有无天气×两学习器。源2022分≤4月、5–6月、7–9月三块，每次留一整块，拟合上界、标准化和权重仅用其余块。此OOF检验时间外推/插值，训练可含被留块之后的其他源日期，不能称滚动预测或整国外测。输出与幅度1的持久性比较，先宏地区再宏国家汇总；不使用源OOF成绩自动选赢家。

模型与OOF输出封存，继承并核对R5完整输入和模型SHA；所有训练标签行、火电比例须逐值等于原R5响应行。若后续使用这些头，另行冻结2023推理、随机总量传播、非负协调、源校准与强基线对照；本阶段不从源OOF推断跨国CIF收益、覆盖或创新成立。
