# V239 冻结协议：跨季节复制小时总量风险信息增益

日期：2026-10-30。覆盖清单仅按完整月小时数确定；风险端点与尾数响应在协议冻结前不读取。

## 目标与假设

V238在2026年8月的六个非平凡BA上发现：给日总量后再给小时总量，使500 gCO₂/kWh超阈小时数可行界平均再缩窄140.3小时。V239检验这一方向能否在不同年份和季节复现。

## 冻结样本

- 年份：2025。
- 月份：4月、7月、10月。1月因快照覆盖不完整而排除；这是覆盖选择，不读取CIF结果。
- BA-month：AZPS、CPLE、ERCO、PACE、SOCO均纳入4、7、10月；PSCO仅纳入4月。总计16个完整BA-month。各自完整小时数由月历天数×24确定。
- 阈值：仅500 gCO₂/kWh；正事件边界为500.0001 gCO₂/kWh，与V237/V238相同。
- 燃料源：沿用EIA八源月边际和V225固定EF，将相同EF合并为四组。标签仍只是固定EF代理。

## 信息条件、端点和汇总

逐BA-month固定月燃料组边际和每日总量；比较日内自由与EIA小时总量固定两种可行集。按V237 MILP最小化/最大化全月超阈小时数K。报告端点状态、gap、固定EF实际尾数见证、嵌套检查和每地区/月份界宽。

主要增量是每个完整配对中 `width(daily-only) - width(hourly-total)`。纳入汇总须两种信息条件的两个端点都证明最优。若至少80%端点最优、至少12个完整BA-month和4个BA，则描述跨季节平均；不把优化可行界解释为预测区间覆盖或准确率。

## 限制

样本来自V226已打开的EIA来源，不是盲测；固定EF不是实测CIF，协议只测试信息集合几何。2025年1月和部分BA的缺失月份不得通过插值补齐。无论结果正负都保留所有冻结BA-month。
