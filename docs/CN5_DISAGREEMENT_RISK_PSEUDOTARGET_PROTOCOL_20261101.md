# CN5模型分歧风险映射：源端整国伪目标协议

冻结日期：2026-11-01，运行伪目标评分前。依据[已查看2024诊断](CN5_PREDICTION_DISAGREEMENT_RISK_DIAGNOSTIC_20261101.md)，仅测试预测器分歧能否在未见源国伪目标中提供区间风险排序；不再基于2024目标分歧挑选规则。

## 数据与预测

- 九国严格中国五类预算：目标特征仅含火、水、核、风、光`t−2…t−7`月份额与日历；2022源小时标签用于训练，2023H2伪目标小时标签仅用于源风险半径估计/伪目标留国验证。
- 对每个国家`c`，以其余八国2022小时数据拟合基准；仅向`c`输入2023H2可用CN5信息，生成比例重组、火电因子头和燃料组成响应头预测。`c`的2023H2预测不使用该国训练标签。
- 风险目标固定为比例重组逐小时绝对残差。两个预测时可计算的信号为`|factor_history − ratio_recomposition|`与三模型逐小时预测范围。
- 外层验证按整国留出：留出伪目标`c`的半径映射只由其余伪目标国家2023H2残差训练。比较同一交叉拟合预测队列上的全局国家等权90%半径与3档分歧条件90%半径。分歧档边界由训练伪目标样本的合并三分位数确定；每档至少需4个不同校准国家，否则回退全局半径。
- 每个校准国总权重相同，每国每档内小时等权。区间为比例重组点预测上下对称半径；不在本轮学习点预测中心。

## 主要指标及停止门槛

报告逐伪目标国和国等权宏平均的90%经验覆盖、平均宽度、Winkler区间分数，并报告按国家分组的分歧—绝对误差Spearman。通过标准：任一分歧映射相对全局半径降低宏区间分数至少5%，宏覆盖不低于88%，且无伪目标国家覆盖下降超过10个百分点。未通过则关闭基于预测分歧的区间校准分支；不在该队列继续扫描箱数、特征或分位点。

## 边界

这是固定EF发电代理的源内伪目标实验；五类月量是现行修订小时回算并严格滞后模拟，不是as-issued历史版本。国家数为9，池化小时覆盖不是新国家90%保证。该实验既不验证中国标签，也不验证消费侧CIF。任何后续目标应用必须在源端门槛通过后另行冻结目标协议，不能回看外层目标标签调区间映射。
