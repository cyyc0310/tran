# 细分燃料增益归因：月度因子水平与源小时曲线

状态：2026-11-01事后开发诊断。前一轮M、M+F实际月报结果已查看，因此本实验不能作为独立确认或无偏显著性检验。

## 问题

前一轮中，EIA-923细分燃料M+F相对五类强重组略降MAE，但形状误差更高。此诊断区分两种解释：细分燃料份额本身给出的月度固定有效因子，和从GB训练迁移的燃料特异小时轮廓。该诊断估计二者的相对作用，不增加任何目标侧信息预算。

## 冻结计算合同

- 固定原实验的20个BA月、14,592小时、EIA-923 2026-08原始月报和EIA-930固定EF代理标签。
- **M5强重组：**直接从原实验机器输出取用，保持完全相同的小时预测。
- **M+F源小时轮廓：**直接从原实验机器输出取用，保持完全相同的小时预测。
- **M+F静态EF：**以每个BA月的EIA-923细分份额对燃料EF加权，月内小时预测保持常数；偏差和尺度用GB 2023小时响应及合法`t−2`细分月份额校准。
- 按原实验相同的BA月宏平均、去日均形状MAE、CRPS、覆盖、宽度和区间分数比较。所有结果只作同批样本事后诊断。

## 解释边界

静态EF是简单信息锚点，不是新的模型候选。若M+F源轮廓胜过静态EF，说明小时结构可能有帮助；若M5仍更好，则说明现有源燃料小时关系没有稳定替代粗五类重组。该诊断不能支持新地区泛化、前瞻性能或论文显著性结论。
