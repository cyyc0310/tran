# V199：中国八类月度发电结构能否选到更好的小时 CIF 供体？

状态：本协议针对已查看的2025中国模型投影小时数据做回顾性机制探针，不是盲测或实测验证。该实验不改变 V194–V198结果，不调参，也不声称提出新算法。

## 研究问题

用户确认其可取得按月逐类发电量。本地公开近似数据 Ember 也提供煤、气、其他化石、生物质、风、光、水、核八类月电量，但属于融合估算和可修订快照。检验这类低频组成能否帮助目标省挑选小时形状供体；不假设组成能决定小时调度，也不从月度排放强度字段构造输入。

## 数据与明确限制

- 结果标签：Li et al. 2026 Figshare v3 的五情景、2025小时省级CIF。目标标签曾在 V194 中评分，故本轮所有结果均为已查看数据上的回顾性开发探针。
- 目标/供体输入特征：Ember 2025每省每月八个非聚合电源的发电量，归一化为8类份额；仅用于供体排序，不使用Ember排放、排放强度或目标CIF小时值。
- Ember为当前修订快照，没有2025月报首次发布时间/历史vintage链；该特征不能冒称当时可得的部署输入。它也不保证与投影情景的地区统计边界或生成模型完全匹配。
- 目标小时月均值仍作为所有臂共有的事后oracle锚，仅用于隔离形状迁移；这强于真实预测预算。因此实验只回答形状排序，不回答月报预测或真实小时CIF准确率。
- 仅主用同情景省留一，另报跨情景固定供体档案。全国汇总不进入供体或目标。

## 固定比较

每个 query 为情景×省×月份。固定 k=15，不按目标小时误差选择 k、距离或方法。目标均值对所有方法相同。

1. `constant_shape`：目标小时均值常数，零形状基线。
2. `all30_mean`：V194固定30条供体形状等权均值。
3. `mix_bc_k15`：V194同一候选档案中，按八类份额 Bray–Curtis 距离选15条形状并等权平均。
4. `level_oracle_k15`：按供体月均 CIF 与目标 oracle 月均的距离选15条，仅作不可部署的形状近邻上界参考。
5. `random_k15`：按query固定seed从同一候选档案抽15条并平均，作档案抽样基线。

跨情景候选档案继续使用V194固定8/8/7/7情景抽样；`mix_bc_k15`在这30条中排序，结果附报其情景组成，避免隐藏供体集变化。

## 评分与解释

主要指标为中心化小时形状 MAE/RMSE；同时报逐省、逐情景和两条供体轨道。按省聚类 bootstrap 给`mix_bc_k15`相对`all30_mean`和`random_k15`的配对差异描述区间。查询/小时不当作独立省份样本。另计算Ember月度发电侧强度与CIF投影月均的描述性对应，仅作为口径/模拟差异检查，不称预测准确率。

即使燃料组成近邻在此处胜出，也仅说明当前代理快照可提供形状排序信号；Bray–Curtis近邻本身是已有普通迁移基线，不能作为算法创新。若不胜，则不继续扫距离/核带宽；此前V63结果仍是跨域负证据。若有稳定增量，下一步应先用用户实际表头和as-of版本确认数据合同，再设计独立时间/地区实验；没有匹配小时真值时不得宣称中国运行有效性。

## V199-r2 单位明确补充

Ember公布的强度单位为 gCO₂e/kWh；Figshare投影 CIF 单位为 tCO₂/MWh。两者比较前将投影值乘以1000换算成 gCO₂/kWh：1 tCO₂/MWh = 1000 gCO₂/kWh。该比较仍只是生成侧 Ember 估算与投影模型月均的描述性差异，不是方法评分。八类发电量份额形状臂不使用该强度字段。
