# CN5燃料组成响应头：法国未评分国家确认协议

冻结时间：2026-11-01，运行前。目的：在一个此前只做过字段可用性审计、没有计算或查看CIF误差的国家上，对已开发的燃料组成响应头进行一次外部确认。候选算法、输入合同、源集、校准和评价口径均在预测前固定；法国标签不得用于修改结果或选择超参数。

## 确认对象和盲测状态

- 外部目标：法国（FR），Energy-Charts公开发电响应，2024年。
- 该法国文件此前只用于API类别/小时缺失审计；此前协议把FR列为暂缓国家，未对其CIF标签进行模型评分。此前已查看的候选国为严格CN5九国NL/ES/BE/AT/SE/CZ/SK/HU/SI。法国不是这些外层开发目标之一。
- 在运行时，所有法国2024逐小时预测及校准半径先写盘哈希封存。评分代码在预测及输入哈希核验后才读取法国小时标签；不得中途查看标签、挑月份或调参。
- 这是单一外部国家、单一发布数据源上的确认，不能提供多国覆盖保证，也不是中国实测验证。

## 预测任务与数据映射

只评2024年3–12月。使用法国本地时间的完整小时；不对缺失标签插补。目标特征仅来自日历及截至`t−2`的过去六个月（`t−2…t−7`）火、水、核、风、光发电份额。所有统计由Energy-Charts当前修订小时序列回算，属于滞后月报模拟，不称历史as-issued发布回放。2024年1–2月因2023年早期风电字段缺失而没有完整六个月特征历史，按预测前字段合同剔除；该选择只依据输入可用性，不看目标误差。

FR生产类型映射冻结为：煤=`fossil_hard_coal`；气=`fossil_gas`；油=`fossil_oil`；其他燃烧=`biomass+waste`；核=`nuclear`；水=`hydro_run_of_river+hydro_water_reservoir`；风=`wind_onshore+wind_offshore`；光=`solar`。抽水蓄能、储能、跨境交换、负荷及派生比例均排除。接口不存在的生产类按既有Energy-Charts协议记零；存在序列的空值不填零。法国原始数据没有单列`others`/`other_renewables`，该分类边界须作为固定因子代理局限披露。France点预测与标签不是机构CIF或实测排放。

只使用10个目标月中的有效小时；每月要求输入聚合用小时达到该月本地实际小时的99%，小时响应所有映射燃料类别完整且非负。若3–12月任一目标月不能达到合同，该月依据输入/标签完整性合同整体剔除并逐月报告；不得以结果误差为由删除。

## 固定训练、校准与基线

### 源集及训练

外部目标法国从未作为源训练域。源训练集固定为其余九个严格CN5已查看国家：NL/ES/BE/AT/SE/CZ/SK/HU/SI。每次训练仅用源国2022小时标签，并等权国家；目标输入均为严格CN5，排除`other_renewable`。目标小时标签、目标燃料份额和目标同期小时值不得进入训练或校准。

### 冻结候选

`fuelshare_history`使用四个源训练HistGradientBoosting份额头，分别预测煤/气/油/其他热电份额；负份额截零后归一到单纯形，全头为零时回退到源训练等权平均份额。固定燃料EF计算热电有效因子，再乘同一源训练热电小时轮廓。完全复用已审查实现和参数；不重训挑参数，不用法国标签拟合本地头。

### 校准

使用源国2023年7–12月交叉拟合校准：对每个伪目标源国p，仅用其他八国2022训练，预测p的2023H2小时；为每个已登记方法收集绝对残差。将九个源伪目标的残差按国家等权聚合，取加权90%分位数作固定对称区间半径。法国预测区间使用该半径；不读法国标签估偏差、缩放或校准。

### 同队列强基线

固定比较`anchor700`、`direct_history`、`factor_history`、`macro_recomposition`、`ratio_recomposition`与`fuelshare_history`，使用同一九国训练集、预测时特征、校准伪目标与法国小时队列。模型定义、树参数、种子、EF和组映射均不得按法国结果改动。不得把静态固定因子当作唯一基线，也不得仅报告有利方向/月份。

## 评分和解释门槛

报告3–12月整体（先月等权再汇总）及逐月、小时池化指标：MAE、去日均形状MAE、经验90%覆盖、平均区间宽度、90%区间分数；同时报告有效小时数和未覆盖月份。法国仅一个国家，不对小时做独立样本显著性推断，不声称有限样本90%整国覆盖保证。

外部确认只有在燃料组成头同时满足以下条件时才算支持：

1. 相对比例重组MAE改善至少5%，且日内形状MAE不恶化超过2%；
2. 90%经验覆盖不低于90%，且相对比例重组覆盖下降不超过3个百分点；
3. 区间分数优于比例重组，且区间宽度没有通过单纯加宽获得改善。

未达条件则按失败报告，不再用法国重调模型。通过也只能称单国家外部复制信号；另需新增国家或更长时间前向外部验证。

## 预测前字段可用性审计

冻结前不看CIF标签。依据原始序列元数据，FR八个用于映射的类别字段均存在；按不填空值的完整行，2024年目标标签各月份均可满足99%小时合同，2023年6–7月风电缺失使2024年1–2月不满足六个月滞后特征合同；2024年3–12月均满足。审计只决定固定评分窗，不使用强度、标签均值、模型误差或区间结果。
