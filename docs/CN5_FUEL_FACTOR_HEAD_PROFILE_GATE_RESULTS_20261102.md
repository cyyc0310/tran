# 按目标粗组成选择燃料头没有通过源内双重留出

日期：2026-11-02。本探索按[冻结协议](CN5_FUEL_FACTOR_HEAD_PROFILE_GATE_PROTOCOL_20261102.md)运行；先做2023H1双重源伪目标门控验证，再在此前已打开的2024九国开发目标上作次级评分。机器输出位于[`cn5-fuel-factor-head-profile-gate-r2`](../results/cn5-fuel-factor-head-profile-gate-r2/)，主预测来自[上一轮已封存结果](../results/cn5-fuel-factor-head-blend-r1/)。这不是未查看地区确认。

## 方法回顾

根据CN5五类滞后月量形成目标六个月平均结构，用Hellinger距离找最近的源伪目标；选择器只读该源伪目标在2023H1选出的alpha。每个伪目标的两头预测模型排除了外层源域和该伪目标。H2只为按同一路由得到的来源残差校准90%半径；2024标签不参与特征、路由、选择或半径。

## 结果

双重源伪目标H1验证中，最近组成原型门控MAE为69.81 g/kWh；逐折全局alpha为68.66，燃料组成头为67.06，因子头为73.70。最近邻路由比全局alpha差1.7%，比最佳单头差4.1%，未达到预设的至少5%源内增益门槛。

在已看过的2024九国开发回放中，路由宏MAE 59.46、形状MAE 17.76、90%覆盖92.37%、平均宽度368.57、Winkler 443.88，最差国MAE 113.61、最低国覆盖68.06%。相对上一轮全局alpha混合，MAE改善1.8%、Winkler改善0.2%，但区间宽7.3%；相对燃料组成单头，MAE恶化8.4%、Winkler恶化6.4%。路由源原型为`ES→NL`、`BE→ES`、`ES→BE`、`SE→AT`、`SI→SE`、`HU→CZ`、`SI→SK`、`BE→HU`、`SK→SI`；按伪目标风险选择源头未能稳定对齐目标误差。

## 结论

停止“按五类粗组成相似度给火电因子头/燃料组成头路由”的路线。它没有超过源内全局选择和单头强基线，也未能在保持区间效率的同时缩窄预测区间。此机制及上一轮全局凸混合均不能作为TransCIF论文的创新算法主张；燃料组成头继续作为比较基线，先前葡萄牙正向结果不能抹去波兰负迁移和本轮选头不稳定。

本轮仍属已查看九国和修订小时月量模拟。它收紧的是当前实验决策：不继续调alpha、距离度量或邻居数，不用该路线测试未查看国家。下一项方法工作必须提出不同的、源伪目标能支持的误差识别路径；若找不到，论文主贡献应聚焦统一双轨迁移基准、真实信息合同和可识别性/失效边界。
