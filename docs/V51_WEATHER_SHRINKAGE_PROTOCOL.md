# V51 本地天气太阳能形状跨源收缩实验协议

## 问题

此前把目标地区归档太阳辐照度归一化为月内太阳能小时形状，在 oracle 月总量条件下曾显示有限的可再生组合形状收益。本实验检验一个更谨慎的问题：如果天气形状增量的可靠程度可以从其他源区学到，跨源校准是否能改善合法 as-of 小时 CIF 预测？

## 预测信息与模型

- 目标月份类别/燃料月总量仅采用目标月开始前已发布的上一年同月统计；目标月当月统计只用于事后评分，不进入预测。
- 非太阳能燃料小时形状及太阳能基准形状来自其他六个已查看开发源的 2024 同月小时曲线。按源先归一化，再等权聚合。
- 太阳能候选形状是来源地归档 GFS 辐照度按小时归一化的月内轮廓；缺失小时按跨源气候形状补足。
- 混合预测为基准太阳能形状与天气形状按 `alpha ∈ {0, .25, .5, .75, 1}` 的凸组合；每种方法使用相同的 as-of 月总量。
- 外层留一源区。目标源的 `alpha` 由其余六源 2025H1 CIF MAE 选择，源区等权；随后仅在外层留出源评分。
- 固定项目 EF 代理 `[1000, 400, 800, 0, 0, 0, 0, 400] g/kWh`；不解释为中国官方排放因子。

## 预先规定的判据

天气机制只有在外层留出源区的宏观 CIF 误差优于 `alpha=0`，且不是由单一来源或个别月份驱动时，才保留为候选。全部选择 `alpha=0`、未优于基线或来源间方向不稳定，都视为否证，不再把天气收缩描述为创新机制。

## 数据边界

七个来源和 2025H1 标签均已用于此前开发；这是外层源区交叉验证式诊断，不是新地区确认。档案天气数据的完整预报发行版本/发布时间尚未完全核实。部分地区月度标签缺失，区域宏指标需说明来源权重与有效月份。实验只覆盖当前数据资产中的天气代理，不代表中国公开数据合同。
