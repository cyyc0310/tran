# EIA–NESO 官方消费侧小时强度跨国迁移协议

2026-11-01，运行前冻结。目标是验证跨国粗月报模型在各机构官方小时**消费侧**CO₂强度标签上的表现，作为固定EF发电侧代理的独立外部轨道。US→GB和GB→US均按同一消费侧对象评价；不把EIA发电侧与NESO消费侧强度混用。

## 数据与时间

- 美国：EIA按BA历史工作簿的`CO2 Emissions Intensity for Consumed Electricity`，原单位lb CO₂/kWh，乘`453.59237`转为g CO₂/kWh。EIA估算排放并用MRIO分配跨区排放，不称实测真值。
- GB：NESO`df_fuel_ckan.csv`的`CARBON_INTENSITY`，单位g CO₂/kWh，30分钟历史值先转UTC，再对一小时内两点等权平均。NESO值为修订后的官方估算，不称实测真值。
- 共同源训练2022，源校准2023，目标测试2024；M预算目标输入只用中国可获得的火、水、核、风、光粗月发电份额和日历。统计月份为精确t−2及更早。输入月量从源小时发电结构重建，模拟发布滞后，尚非历史as-issued。
- 另设M+C嵌套预算：给M增加公开的2020煤／气年度装机份额及容量总量特征，使用相同训练、校准与评分小时。美国取EIA-860 2020 OP按BA汇总；DE和GB容量地理口径及版本限制见[年度预算协议](OFFICIAL_ANNUAL_COAL_GAS_CAPACITY_PROTOCOL_20261101.md)。此项是信息价值消融，不把装机当小时调度上限。
- EIA强度和NESO `CARBON_INTENSITY`只用作响应与源风险校准，不进入公开特征。源标签按2022/23独立提取；运行开始要求2024目标标签目录为空。所有目标预测写盘并哈希后，才执行独立的2024标签提取和评分。封存前哈希清单不含目标响应文件或字段。
- GB官方时间戳是UTC。小时局部日历特征转换到Europe/London；US局部日历和BA时区沿用EIA表中的本地时间定义。预测与标签通过UTC小时戳一对一连接。

## 比较模型

1. 源官方消费强度常数（源区均衡均值）。
2. 日历Ridge。
3. 中国粗月报特征Ridge（粗类型份额、日历交互）。
4. 中国粗月报特征HistGradientBoosting。
5. 固定EF强重组参考：其点预测由源小时燃料和统一EF得到，再用相同官方源2023误差校准；同时保留为不同标签轨道之间的基线。

所有方法以2023源残差均值和标准差形成相同定义的Gaussian风险参考；按源区等权计算，报告未经校准点误差及校准后MAE、去日均形状MAE、Gaussian CRPS、90%覆盖、宽度和区间分数。预测点不因2024目标标签而改选或调参。若官方目标强度缺失，该小时不评分，但预测仍保存并记录；覆盖度按应有小时数和可评分小时数分别披露。

## 预先限定的解释

官方消费侧轨道含跨区排放分配，NBS目标输入不包含小时交换流。因此模型成绩评估的是“仅粗发电月统计预测机构消费侧强度”的完整迁移任务，跨区流是未观察的域差异，不解释为可由发电份额逻辑识别。美国与GB的估算机构方法不同，固定EF轨道仍是控制比较，不能将两轨道数字拼成一个指标。

进入运行前需核对：EIA各BA工作簿列名按名读取（列位置在各BA文件间不同）、UTC唯一性、消费强度缺测、EIA单位换算和NESO半小时到整点聚合。美国所有BA预测文件共用同一可用粗特征样本；标签缺失仅影响响应评分及校准有效样本。
