# 年度火电装机预算的同五国增量实验

2026-11-01，运行前冻结。该分支在五国Energy-Charts留一国实验中增加一项年度宽口径装机信息，比较同一目标小时上M（月报）与M+C（月报＋年度热电容量占比）。

## 年度字段和可见性

来源为Eurostat `nrg_inf_epc` 年度净最大电力容量表，筛选`CAP_NET_ELC`、总运营方、MW。按SIEC `CF`（combustible fuels）除以`TOTAL`计算热电装机占比，作为中国省级公开火电装机的宽口径近似。原始API响应、响应更新时间、请求过滤器、统计年份及SHA由采集文件和解析清单保留。数据接口最后更新时间为2026-10-22，提供的是当前修订值，不是2022/2023历史as-issued版本；所以只做“统计年滞后两年”的信息预算模拟，不声称逐日历史可见性回放。

对2022训练样本接入2020统计年装机；2023源校准使用2021统计年；2024整年目标使用2022统计年。全部五国保持同一滞后。年度容量仅作软预测特征，不作为小时可用容量上限。目标国任何小时标签、2024小时发电值均不进入容量查询或建模。

## 比较合同

沿用`ENERGY_CHARTS_LOCO_PROTOCOL_20261101.md`中的五国、时段、月报模拟、九类固定因子代理、权重、源校准、封存和评分规则。M分支为原八个方法。M+C增加三种HISTORY+`capacity_thermal_share`参考：`capacity_direct`直接HGB拟合小时代理标签；`capacity_factor`用相同HGB拟合有效热电因子并乘原强重组小时热电形状；`capacity_ridge`使用标准化Ridge直接拟合小时标签。HGB沿用原参数，Ridge沿用原alpha=10。容量分支与M获得完全相同的目标小时、源训练标签、源校准样本及区间规则。

该设计只检验年度宽口径热电容量是否为现有强重组和火电因子学习提供可迁移信息；并不单独证明专门新算法成立。逐国报告与宏观平均并列，重点观察荷兰失败能否改善，以及区间覆盖是否提高而不靠增加源校准残差半径。统计地区仍只有五个，且均为已查看开发域，不是最终确认国家。
