# 严格中国五类预算下的年度装机增量协议

冻结日期：2026-11-01。该协议使用[严格五类九国LOCO](ENERGY_CHARTS_NINE_COUNTRY_CN5_PROTOCOL_20261101.md)的同一输入、标签、目标小时和评估流程，只额外加入一列年度热电装机占比，重新检验M+C增量。

装机字段为Eurostat `nrg_inf_epc` 年度净最大电力容量的`CF/TOTAL`。2020统计年对应2022训练，2021对应2023源校准，2022对应2024目标。当前修订数据不等于历史as-issued发布版，所以只作滞后信息预算模拟。装机不作小时物理上限。

M为严格五类预算下的八个固定基线。M+C只给HISTORY五类月报特征追加`capacity_thermal_share`，比较direct HGB、Ridge与火电因子HGB；HGB参数80轮、15叶、最小叶100、L2=10、seed416、无早停，Ridge alpha=10。模型训练、源校准和外层目标小时与M完全一致。所有M与M+C逐点预测、校准半径在评分前分别哈希封存。

以目标国、月份等权报告MAE、形状误差、小时覆盖、宽度、区间分数；特别比较容量因子头与无容量因子历史头、容量直接头与直接历史头、以及两者相对严格五类比例重组强基线的变化。九国均为开发域，间隔为小时池化经验覆盖，不是新国家保证。
