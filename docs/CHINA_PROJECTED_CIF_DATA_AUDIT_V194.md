# V194：中国逐小时 CIF 情景投影数据源审计

日期：2026-10-29。目的：核实一个新发布的中国小时 CIF 数据源能否补足本项目的中国小时目标验证。只下载并检查 Figshare 的数据说明 PDF、输入参数工作簿和公开 API 元数据；**没有下载或读取五个目标小时 CIF 情景工作簿，也没有据其调参/评分**。

## 数据源及可复核文件

- 论文：[High temporal and spatial resolution projected electricity carbon emission factors of China from 2025–2060](https://doi.org/10.1038/s41597-026-07272-6)，*Scientific Data*，2026-04-21。
- 数据集：[Figshare v3，DOI 10.6084/m9.figshare.28953545.v3](https://doi.org/10.6084/m9.figshare.28953545.v3)，API 元数据标注 **CC BY 4.0**。
- 本地只读资料：[数据注释PDF](../results/china-projected-cif-v194-inventory-r1/dataset_annotation.pdf)、[输入参数表](../results/china-projected-cif-v194-inventory-r1/input_parameters.xlsx)、[下载与MD5/SHA256收据](../results/china-projected-cif-v194-inventory-r1/receipt.json)。两个文件均与 Figshare 提供的 MD5 一致。

论文/数据说明称，数据覆盖中国大陆31省及全国，五个发展情景，2025–2060每五年一个年份；每个省年有8760或8784个小时，消费侧间接电力碳排放因子单位为tCO₂/MWh、小时值四位小数。小时结果由GTSL规划、PSOS小时运行和碳流CEF模型生成，属于**模型投影/模拟标签**。论文用2021–2023年官方省级年度因子作历史对比，报告年度聚合MAPE最高2.525%；这验证的是年均量级，不是小时误差或真实小时覆盖。

输入参数工作簿含17张表，描述总线/省份、机组及其碳因子、2020装机、储能、交流/直流线路、可装机约束、机组成本/运行参数等。它不是目标未来月份的逐类已实现发电量或逐小时实测记录。小时CIF输出情景文件在本次审计中仍封存。

## 对当前研究目标的价值

这是一个**中国系统模型世界**的外部压力测试机会：可检查来源省小时形状能否迁移到未用于拟合的省份，并可在情景留出下检查源形状对负荷/碳预算路径变化的敏感性。它比EIA固定EF非负发电代理更接近中国消费侧碳流对象，且显式包含电网运行与跨区碳流。

但它不能作为“中国真实小时 CIF 预测准确性”确认：小时结果是同一个规划/调度/碳流模型生成的仿真输出，GTSL/PSOS核心代码未公开，且输入工作簿不含目标省未来月份逐类实际发电量。用同一投影的目标小时标签回算目标月均CIF，只能作为明确标注的**oracle月均锚**；它给预测器的目标侧信息强于用户目前描述的月度燃料发电统计，不能冒称实际可部署信息或中国月报预测成绩。

## 后续冻结实验的候选合同

若继续使用该资源，单独建立“oracle月均CIF条件下的小时形状迁移”轨道：

1. 先冻结五情景×八年份×31省的省级外层留一协议；同一目标省的全部情景小时记录不得进入供体拟合。另一条情景外推轨道还要同时留出目标省身份与目标情景。
2. 输入仅为目标省该月完整小时序列计算出的月均CIF，并明确记为事后oracle上限；评分目标是该月中心化小时形状/尾部，不能把它描述为月前预测。
3. 对比常数月均锚、同情景其他省中心化小时形状均值、供体形状经验分布、固定最近层级供体，以及打乱供体小时顺序负控制。所有方法使用同一目标月均锚及标签口径。
4. 按目标省宏平均报告形状MAE/RMSE、小时CRPS、区间覆盖/宽度/Winkler；省份、情景、年份分别报告，不能把1240个省年情景单元当作1240个独立电网。
5. 在协议/代码冻结前不打开情景小时CIF文件。任何结果只可称同模型情景内/跨情景迁移压力测试；不能用于真实中国已发小时CIF准确率或真实发布vintage声明。

该轨道可证伪“已知聚合水平后，小时形状还能可靠地从其他地区迁移”的假设；它不能替代在真实月报、真实发布时间和独立小时测量上的关键验证。是否值得实施，仍取决于冻结协议是否能形成与已有V193/V68/V69/V71/V142方法可区分的实验，而不是仅换一个数据源。
