# V23 R2 amendment: quantized response bins are half-open

Registered after the completed V23 R1 output, before R2 computation. R1's 10 g/kWh observed intervals correctly enclosed the true CIF but its prospective-bin enumerator treated every bin as closed on both ends. Under the frozen floor quantizer, a value exactly on a 10 g/kWh boundary belongs only to the bin that starts there; the adjacent lower bin is not a possible answer. R1 therefore slightly overstates worst-case branches for the `one_step_minimax_Kspan` policy in quantized mode. This is conservative for identification, but it means its query-selection comparison was not exact at those boundary points.

R2 defines observable bins as `[10k,10(k+1))`, with the final bin ending at 1000 inclusive. It changes only the set of possible answers considered when choosing a quantized minimax query; the actual reported CIF interval remains the registered closed enclosure, so any feasible set still contains the true label. All days, regions, thresholds, query budgets, policies, exact-mode calculations, support assumptions and metrics remain fixed. R2 writes to a new output directory and binds R1's completed freeze and outputs as its audit parent. R1 files are preserved unchanged.
