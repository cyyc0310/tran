# V4：统计支持、时效性与水平—形状迁移

2026-10-23，最终新区小时评分前制定。本轮全部执行与独立审查使用Sol。

## 研究假设与信息约束

研究是否能通过按历史统计支持窗口条件化长期地区结构、周期项和短期漂移，改善无目标小时遥测的跨区预测；并用独立源地区残差校准减少覆盖不足。积分核、状态空间、专家组合和分组保形本身均有先例，本候选尚无首创或任意未见域覆盖主张。

每次预测仅读取日历与 `available_at + extra_delay <= origin` 且 `period_end <= origin` 的月度燃料份额；基础available_at为月末+30日，extra_delay=0/30/90。统计转换为固定EF发电侧代理，属于能量加权比率，不等于日均小时CIF；将两者差异作为观测噪声而非硬约束。观测窗口用多个积分节点或解析周期均值表示，不将月总量强制套在未来日。

候选分开处理地区长期偏置、季节周期和短期漂移；长期部分不随着最近统计年龄整体消失。小时形状保持去日均，来自源小时参考与合法目标粗统计的相容源形状；不读取目标小时历史。预测方差与历史支持、外推距离及源形状不确定性相关。无月度信息时明确回退源先验并报告。

## 数据拆分

- 预测模型训练：BPAT、ERCO、MISO、NYIS，2022小时参考。其粗历史可在预测当时按发布时间更新。
- 独立源校准：CISO、FPL、ISNE，2023小时参考；不在上述小时训练域内。
- 源开发选择：CISO、FPL、ISNE，2024。可进行多轮候选改动，明确为开发；每轮不可覆盖。
- 既有2023/2025/2026结果均已查看，不能重新称未见确认。需要时作为明确标注的诊断。
- **最终外部地区：SWPP、AVA、BANC、JEA、SC、NWMT，2025全年**，只根据原始记录与既定质量mask选定，未根据CIF或预测误差挑选。其2022–2025粗月历史可用于as-of输入，小时数据不用于模型、参数、校准或方法选择。NWMT历史2024-07粗月缺失，保留作自然缺失情景。

新区原始数据准备可读取native发电进行schema、净发电平衡和完整日质量检查，不计算CIF分布或预测成绩。与V3相同，输入来自下载时修订文件，假定发布延迟，非真实历史发布版本。

## 强对照、迭代与选择

至少包括近期水平、季节水平、固定水平形状组合、历史粗统计harmonic ridge、local-level/OU状态模型、源监督岭回归、源训练softmax专家组合；候选包括不同漂移持续性、积分支持/点支持消融以及仅水平和形状的独立消融。相同信息和校准条件比较，不能以给候选更多数据替代方法贡献。

第一轮比较固定广谱结构；第二轮依据源2024错误诊断修改长期/季节/漂移比例、源形状或不确定性；必要第三轮只针对明确失败机制，保留所有结果。模型变更后在新的不可变目录重跑，不能将开发集改善称确认。

主选择在全部延迟上选统一方法和校准模式，保留分延迟结果：优先要求每个源验证地区的90%覆盖至少85%，且宏平均覆盖距90%不超过5个百分点，再在合格组合中取等地区/等延迟宏CRPS最小。没有组合通过则明确写失败，保留最接近者作诊断。区间宽度、90%interval score与CRPS共同评价，不能以无限扩宽宣布成功。所有强基线可使用相同校准工具。

## 校准与评价

比较原始源残差、标准pooled standardized split quantile、地区等权quantile、源地区保护分位（max与domain80）及年龄分层。标准化保留有符号日内残差路径；分析区间与经验样本区间分别报告，不混同边际对称区间与严格路径覆盖。源选模与校准数据分离，但源地区有限、时间依赖、未见域偏移仍使一般覆盖保证不成立。

报告逐地区/延迟：CRPS、点MAE、raw水平和去日均形状MAE、90%边际覆盖/宽度/interval score、低高尾失覆盖、整日路径覆盖、原始负值比例。宏平均地区等权；同步月份配对重采样为描述性区间，不把天或方法日当独立电网。

## 完整性与停止规则

拟合前冻结源码闭包、协议、数据hash和环境；最终外部所有方法、地区和延迟预测先整体封存，再读取任何外部小时参考评分。最终方法由源开发结果固定，不允许看新区分数后调整再自称确认。若修改后需另留新数据。

成功只表述为固定EF代理和这一信息预算下的实证改进。若只提高覆盖且宽度/CRPS显著恶化，或不能胜过状态/专家/简单统计强基线，则方法优势未成立。新增算法名称不能替代与先例的区分、消融或理论。无月度历史/只有年度统计和真实中国小时可信性不由本轮自动获得。

## 第二轮补充：源开发反馈后的固定新增候选

第一轮源2024开发已完成；最终六新区尚未评分。第一轮GP中等持续性+原始残差有较低CRPS，但最弱源覆盖84.3%未达85%门槛；长持续性版本通过。最坏源月保护约98%覆盖且显著扩宽，不能视为成功的校准。第一轮用明确的pandas2.3.3/ns环境，后置环境观察不冒称拟合前快照；后续统一显式ns并在拟合前记录环境。

第二轮保留原12个点预测对照，另加入两个“同支持年度创新桥”（90/365日持续性）和中/长GP等权混合。创新桥先以已发布历史同月为锚，再用**相同历史月支持之间的年度差**消去固定地区和周期水平，对差值的带噪窗口观测做OU条件化并向未来传播。锚本身保留误差地板；不存在可靠年度配对时回退季节锚及基础不确定性。这是本项目设计的候选构造，年度差分和GP条件化均有先例，未宣称新理论。

新增组件校准将源残差精确分为日均误差和零均值形状误差，分别按源预测level_sd与shape_sd的日内RMS标准化，联合抽同源同日路径，在目标按各自scale恢复。这样level不确定性增大不会机械扩张shape。预先固定factor=1与1.10两版本，另五种标准/保护校准均保留，所有点方法可使用全部校准，不能只给候选改善区间。年龄分组固定≤60、61–120、121–240、>240日，不把每个整数年龄作稀疏分组。解析加权全源路径区间与有限样本经验区间分别报告。

第二轮形状尺度还使用合法粗特征对应的32个源邻居形状加权离散度，并与全源形状方差各取一半；固定全源方差地板避免稀疏近邻导致虚假确定。该尺度用于所有点方法的标准化/组件校准，点预测不受影响，不只给候选额外信息。

最终仅使用第二轮统一候选表做源选择，第一轮作为已完成开发证据，不拼接不同快照的最佳数字。外部模型直接复用最终源开发封存的fit/calibrator字节，并验证模型闭包与环境一致。纯runner编排差异另列，不允许模型同名参数变化。此补充在外部标签评分之前固定；新区数据准备时留存的早期协议hash不覆盖，最终协议独立进入拟合前冻结。
