# V51 合法月度类别预测基线与天气失败拆分

## 月度统计 as-of 预测

在七个已查看源区，对能在目标月开始前发布的月度八燃料分项，比较上一年同月季节朴素、最新可得月日均出力外推、最近三个可得月日均值外推。目标月的实际月报只用于事后评分，且 2025H1 有标签的37个源区月都能用上一年同月记录作为合法输入。

| 方法 | 总量绝对误差/实际总量 | 燃料向量 L1/实际总量 | 固定 EF 月度能量加权 CIF MAE |
|---|---:|---:|---:|
| 上一年同月 | 5.80% | 15.69% | 15.29 g/kWh |
| 最新月日均率外推 | 10.81% | 20.96% | 27.48 g/kWh |
| 最近三月日均率均值 | 11.25% | 21.71% | 27.20 g/kWh |

该结果说明季节性明显，简单追随最近公布月份会恶化预测。分项月报和固定项目 EF 下的月度能量加权 proxy 可以评价月总量/组成预测，但它不是小时普通均值，也不是中国官方排放核算结果。

## 太阳能天气形状失败的 oracle 拆分

为判断 as-of 天气分支变差是否只由目标月太阳能总量估计错误造成，把太阳能月总量替换成目标月真实月报值，仅用于诊断；其他燃料总量仍取上一年同月合法 as-of 预测。两方法总燃料误差均为13.55%，因为太阳能总量 oracle 对两者相同；跨源气候形状 CIF MAE/RMSE 为39.03/48.00，天气太阳能形状为46.90/57.68 g/kWh。天气形状仍然明显恶化，尤其 CISO、ERCO、FPL。可见月总量季节朴素误差并非天气分支退化的充分解释；在该固定 EF 代理和当前归档天气设定下，小时轮廓本身或其与剩余燃料预测的组合仍不匹配。

oracle 结果不得称为可部署预测，不用于调方法或新地区确认。天气档案的发布时间/预报版本仍不完整核验，小时标签覆盖也有地区差异。

## 研究含义

两项诊断都没有发现新算法增量。当前应把“月度类别总量预测”作为明确的输入层，与“月内燃料小时形状”分层评估，并把月度能量加权 proxy 和小时均值/CIF尾部作为不同 estimand。可迁移的贡献机会仍在可信基准与风险分解：在明示发布日期、统计边界、类别合并的约束下，逐层报告月统计可识别量、迁移形状假设、小时校准覆盖/宽度和失败地区。仅凭目前七源结果，尚未达到冻结方法的标准。
