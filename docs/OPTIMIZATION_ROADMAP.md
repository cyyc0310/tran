# TransCIF-FD 优化路线图:按电网特征分档的专属方案

日期:2026-08-15 · 依据:FD-0→FD-10 全部实验证据(本文每个方案都标注了支撑 verdict)

**实现更新(2026-08-19)**:FD-17 之后的可复现实验表明，含燃料遥测的区域应默认走
fuel-first 路径(`wind_route_tau=1.1`)，无燃料区域仍由 `has_fuel` 强制走 aggregate
路径；旧的 `0.25/0.45` 仅保留作消融。评估脚本已将 1.1 设为默认，并新增可选的
`--physics-target`(源域用燃料份额×有效 EF 训练)与 `--domain-penalty`(跨源域风险离散
正则)。这两项默认关闭，避免改变历史基线。

## 0. 总原则(三条历史教训的约束)

1. **难度是波动性,不是结构类型**(FD-10:r=0.85 vs r=−0.04)——分档优化目标是"给每档正确的特征与损失",不是"给难区更大模型"
2. **学习型条件化会失败**(FD-2 hypernet、BasisMix、FiLM 三次验证)——档位路由必须**确定性规则**(config 份额阈值),这是仓库历史上唯一 work 的条件化(RegimeMoE −4.2 的机制)
3. **I_+ 以上层级被 equalizer 封顶**(FD-4/FD-9)——所有方案的作用点在 **I_cfg / I_0 / 数据与标签**

## 2. 逐档方案

### A 基荷平滑档(目标:逼近 persistence 地板,MAE≤10-15)
- **失败机制**:无——已接近地板(效率比 0.96);剩余误差是水平微偏
- **方案**:①**更长上下文**(336h→720h,MAE-floor lever #3,平滑序列无代价);②水电**季节入流**特征(月度径流气候态,公开);③逐网格 ZS+ 菜单固化
- 预期:BPAT 6.2 已达标;UK_03 41→~30
- 实现:`SEQ_LEN` 档位化(结构档 A 用 720);入流特征进 fut_exog

### B 风电波动档(目标:吸收 NWP 剩余技能 + 诚实的区间)
- **失败机制**:24h 风不确定性 = NWP 误差本身(FD-8 已证模型吸收了再分析能给的)
- **方案**:①**多层/集合 NWP**(100m 风 + 950hPa 风 + ensemble spread)替换单点风——直接攻瓶颈;②**分位数输出**(p10/p50/p90,CRPS 评估)——波动区产品形态;③AU 四区(SA1/VIC1 属本档)接 **NEMED DUID 燃料遥测**(IMPROVEMENT_PLAN TODO),从聚合路径升级到分解路径;④**风电 ramp 事件特征**(过去 6h 风爬坡率)
- 预期:点值 MAE 受 NWP 技能约束(效率比 0.93 已健康);区间覆盖 90% 是可达 KPI;AU 四区 I_cfg 89.6→60-70(DUID 后)
- 实现:`data/fuel.py` 加多通道天气加载;`calibration/conformal.py`(已有)出区间;NEMED 独立 venv 生成

### C 光伏鸭子曲线档(目标:晚高峰爬坡形态)
- **失败机制**:光伏天文部分已精确;误差在**晚高峰热电爬坡响应**(温度→负荷→dispatch)
- **方案**:①solar 调制界放宽(0.4·tanh→0.6)+ **逐时容量因子气候态**(再分析,含电站分布效应);②**温度-负荷耦合特征**(度时数 × config 热电份额 → 爬坡先验);③晚高峰损失加权(17-21 时 ×2)
- 预期:CISO 89→~70(鸭子曲线黄昏段的形态误差是主项)
- 实现:`fuel_decomp.py` solar_mod 界 + 度时数进 fut_exog;损失加权按日历小时

### D 进口重组档(目标:消标签噪声 + 引入邻居信息)
- **失败机制**:本地结构不决定本地 CIF(伦敦 25% 进口来自多国电网);**标签噪声 10-37%**(FD-10 实测 UK_14:70.3→44.0)
- **方案**:①**双轨标签**:评估对物理重建 CIF 并行报告(零模型改动,UK_14 立降 37%);②**联络线通道**:imports EF = f(邻居电网月度结构, 日历)——可学习头(进口结构比本地简单);③训练时进口窗降权
- **对中国**:省间输送月度公开、来源单一(不像 London)——此档在中国≈可解,本档方案直接迁移
- 预期:UK_14 70→44(标签)+ 邻居通道再 −5~10;UK_13 70→59+
- 实现:eval 加 `--physics-target`;imports-ef 头(config 邻居份额 + 日历)

### E 火电调度档(目标:煤/气切换的可观测代理)
- **失败机制**:机组启停由燃料价格/检修决定(config 与天气之外);US 组已 easy(31.2),AU 组难在无遥测 + 价格调度(ramp 22-25)
- **方案**:①**燃料价格通道**(公开:Newcastle 煤/API2、Henry Hub/TTF 气,日度)→ 煤/气边际切换的确定性代理;②**检修日历**(公开季度计划);③AU 由 NEMED DUID 覆盖(同 B 档方案 ③)
- 预期:AU QLD/NSW I_cfg 62-85→50-65(价格通道解释启停节奏)
- 实现:新 exog 加载器(日度价格广播到小时);therm_dyn 消费价格特征

## 3. 统一框架:确定性结构路由(共享骨干)

```
config 份额 → 确定性规则 → 结构档 → {特征集, 损失权重, 序列长度, 输出形态} 档位专属配置
                ↓
        共享 FuelDecompNet 骨干(不分裂模型,保跨档迁移)
```

- 路由零参数(规则阈值上表),完全避开 hypernet 教训
- 档位只切换**输入特征与损失权重**,权重仍跨档共享(小样本下必须)
- 这正是 RegimeMoE(−4.2,仓库唯一成功条件化)的 FD 版:专家=特征方案而非模型副本

## 4. 评估配套(把分档变公平)

1. **分档排行榜**(BENCHMARK.md):每档独立 median/效率比
2. **效率比(MAE/persistence)升为主指标**(0.93-0.96 跨档均匀是强 claim)
3. **双轨标签**(D 类):报告 CIF 轨 + 物理真值轨
4. 波动区 **CRPS/覆盖率** 轨道(conformal 模块已有)
