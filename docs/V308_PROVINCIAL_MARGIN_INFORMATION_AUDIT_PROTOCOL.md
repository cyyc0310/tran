# V308：省级送受总量能否约束区域OD可行集？

**探索性审计；2023年区域/省级流量表均已查看，不是盲测。**

## 问题

Quan et al. (2025) 的区域表1/2给各区域跨区流量边际，表3给各省跨省送出/受入总量。表3没有省对省来源—目的矩阵。本轮检验：仅把省级总量聚合到七区域，作为区域跨区送受量的容量上界，是否能够比表1/2本身进一步约束区域运输多面体？

## 冻结计算

1. 按七区域划分把表3省级送出/受入总量求和。
2. 与表1/2区域跨区送出/受入边际逐区比较。
3. 如果对每区，区域跨区边际均低于省级跨省流量总量，那么“仅有省级总量上界、没有省际目的地/来源关系”的约束在区域LP中冗余；不据此构建省级OD分配或猜测来源。
4. 由于源表可能存在小额闭合差、不同维度含义不同，记录总量差异，不强制平差。

## 解释边界

若省级送受量总量比区域跨区边际大，说明总量字段同时包含区域内省间交换或统计范围更广；它本身不代表所有省级量均为跨区域电量。聚合容量上界冗余不代表详细省级发送/接收总量无信息，更不证明OD关系没有信息；它只说明缺少成对来源—目的关系时，本轮这种粗化无法收紧区域边际。
