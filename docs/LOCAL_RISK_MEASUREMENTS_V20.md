## 1. 先固定要识别的对象

当前是固定EF的**发电侧代理**：正八燃料发电P_fh、G_h=sum_f P_fh>0，`C_h=sum_f EF_f P_fh/G_h`，C∈[0,B]、B=1000。它不是消费侧、边际排放或生命周期碳强度。本文Tail的`H_b=sum_h G_h C_h`；别与V17按EF/1000计算的等效能量H混淆。

| 风险函数 | 同期粗观测已经约束什么 | 仍留下什么 |
| --- | --- | --- |
| 月/日/块发电加权均值µ_E | 全燃料总量或同口径H/G直接确定µ_E | 不等于等小时均值m_U；无小时排列信息 |

| 峰值、哪几个小时高、爬坡 | 认证支持可以排除某些极端值；定位观测可约束相应小时 | 无时间顺序的边际分布/矩不能恢复排列与爬坡 |
| 未来P(K_tau>=k)、小时90%区间 | 需要合法过去信息形成的粗预报law与未识别细风险迁移模型 | 同期物理包含不等于未来概率校准或跨地区覆盖 |

[V19](RISK_INFORMATION_V19_RESULTS.md)给出的经典关系为`µ_E−m_U=Cov_uniform(G,C)/mean(G)`。增加c=CV_G后，`(µ_E−m_U)^2<=c² m_U(B−m_U)`；这约束**水平**而非唯一识别尾部。V19源历史T8均值范围宽从833.333收紧至CV必要外界50.489、全G简化集合sharp界35.261 g/kWh，不是预测区间同幅缩窄。

反例应按准确口径使用：在G均匀的coal/hydro可行子类，四块均值500仍允许flat500与集中1000/0，尾部不同；块内重排还可保持边际分布与K而改变高值时刻、爬坡。不均匀G时不能任意重排C并声称H不变，而应检查加权约束下的可行替代。这里用的是经典部分识别，不是新理论。

## 3. 更直接的风险摘要：不必总是发布全部G24

对一个n小时块、固定正G、总量G、碳能量H和共同阈值tau，记S_k为**最小k个G之和**、L_k为**最大k个G之和**，L_0=0。指定非空超越集合的能量条件为`tau*G_S < H <= tau*G+(B−tau)*G_S`。由此独立核准：

- H<=tau*G时，下端重量限制自动成立；exact k可行当且仅当`tau*S_k<H`（1<=k<=n），K=0也可行，故整个K集合为[0,Kmax]内全部整数。
- H>tau*G时，strict重量上界自动成立；exact k可行当且仅当`H<=tau*G+(B−tau)*L_k`，故整个K集合为[Kmin,n]内全部整数。
- 因此这个**共同阈值、单块H/G/support**类的fullG计数集合事实上必连续；四块和也连续。旧V20保留holes是通用组合守护，本轮不应宣称发现了实际孔洞。不推广到异质阈值、额外耦合约束等更复杂集合。

这给出风险定向的充分摘要：要**排除K>=k**，只需S_k且判据为`H<=tau*S_k`（1<=k<=n）；要**强制K>k**，只需L_k且判据为`H>tau*G+(B−tau)*L_k`（0<=k<=n）。特别地，认证K=0恰需`H<=tau*min_h G_h`。于是四个块Gmin足以复现全部G24的全日K=0证书；这不是说四个Gmin能复现全日任意K的sharp范围，后者还涉及块内多项累积排序和块间数量分配。

端点核对：H=0仅K0；H=tau*G允许0..n−1但不允许n；H=B*G仅Kn。例G=(1,2)、tau600、B1000：H600时K={0}，H601时{0,1}；H2600仍允许{1,2}，H2700才仅{2}。本稿以560组纯合成Fraction比较独立排序式与原枚举并通过，未重跑源生产文件。

这是经典排序/knapsack推论，不是新定理。所谓“一个标量充分”是对**给定H/G、支持、阈值和指定块事件**的充分性，不是所有测量类中的全局最小成本。供应方仍需小时G计算Gmin/S_k/L_k，可能比直接发送G24省通信而完全不省采集；未来真实排序和也仍未知。

**信息闭包不可省略。** 按当前EF，令t_h为正EF组总发电，c_h为coal，o_h为oil，则`C_h=(400t_h+600c_h+400o_h)/G_h`。若本地小时t、c、G已知且o=0得到可靠认证，就已可反算小时CIF；不能因字段名没有CIF而称零本地小时碳信息。油或EF未知时保留相应范围。同预算直接CIF/粗CIF/状态空间参考应获得所有可推导值；T8本来就含历史6h加权CIF，不能仅因某论文原版用hour context而永久排除其明确的coarse适配。

## 5. “最小”只在声明的测量类内成立

- 若任务只问一个已完成日的E=1{K>=k}，允许提供方直接发布准确E，那么一bit标签就足够；可行集合本来包含E真/假时，零新增信息不足。这个平凡结论不代表取得该bit便宜，更不是未来预测输入。
- 若只允许无噪小时CIF点查询，V19的**20次最坏情况**仅针对G全1、coal/hydro、四块均值500、strict600、从仅这些粗观测开始、对所有可行路径零误差精确求K。5次/块推第6；沿flat500应答，少于20会有一块两未知点可改成750/250。不能推广为任意电网、任意噪声、平均情形或概率预测都需要20标签。
- 若允许认证C<=600，strict600的K立即为0；若只给尾计数，没有高值时刻或爬坡；若只给无序边际分布，也不能恢复时间排列。测量类改变，最小数就改变。
- 有噪/量化观测应扩为包含真实路径的可行集合。只有对所有可行路径结论一致才出硬认证，其余明确未决；不能靠更窄但失真的假支持提高“认证率”。

## 6. 下一步：优先检验具体风险测量，不继续盲加矩

**先做风险定向的G-only摘要压力实验。** 如果独立同口径小时G通道可取得，Gmin是比继续泛加矩更直接的零新增碳响应选项；当前只有oracle模拟，真实渠道仍须取证。认证机组支持也接近原无本地小时CIF合同，但缺真实就绪/修订档案及分母边界，不能在真实预测中硬用。明确少标签的风险观测是下一类预算，而不是与G-only摘要混算的免费信息。

建议先冻结一个小的source-only测量压力实验，不增加预测模型：

1. 七源按已封日期mask取每源首末有效日共14日，不按效果选日；主tau300，压力100，600/900只评估零事件范围。已看全源汇总后的方案属于适应性开发，不声称独立预注册发现。
2. 对共同T8，比较每块Gmin、每块sum(G²)、全部G；前两者各4新增标量。先核exact Gmin的K0证书与G24一致——这是上节已证明的恒等关系，**重跑一致不能算新经验增量**。再固定有限载荷/区间量化压力：例如Gmin/G_block在[0,1/6]、CV²在[0,5)分别量化为同样8/12/16bit区间，共享H/G精度规则。Gmin用区间下端、H用上端才能安全认证无超越；所有方法保留相同测量不确定性，而非四舍五入后当真值。
3. 比较正确零事件认证率、未决率、消息bit数与供应方小时G需求。G2当前算法是必要outer而非其精确识别集，故Gmin优于它不能全归为信息优越：还须保留G2更紧的普通矩可行性参考或明确这个算法松弛。另可预定单一块k=3，以四个S_3对照四个二阶矩回答相应块事件；不要把Gmin和S_3一起发送却仍计4标量。
4. 失败标准：任何错误认证/真路径被排除即停止查错；exact恒等不成立即实现失败。若有限精度下Gmin相对最强普通同载荷参考未减少未决，或独立G的口径/发布vintage无法认证，就不推进实际预测通道。相同bit数也不等于相同Shannon信息、采集成本或误差，报告不作更强预算公平声明。

如果G-only通道仍不足，而允许新标签预算，再做少量CIF查询的后续合同：

1. 合成6h小类同时保留flat/尖峰/重排/严格等阈值及不均G，验证每个certificate确实包含所有可行路径。有限离散小类可用精确动态规划给查询策略最优参照；其最优性不能推广到连续24h集合。故意错设的支持另列为假设失效，不作为真实认证数据。
2. 七源按已封V20日期mask取每源首末有效日共14日，不按结果挑日。主tau300，压力100；这是已看全源汇总后的**适应性开发选择**，不是新的独立预注册发现。600/900仅保留合成/零事件范围检验，不用来评价正尾检出。
3. 基础T8+G24为同期oracle已知。新增测量仅允许b={0,1,2,4}个小时CIF查询；先exact模型，再预定10g/kWh量化区间（真实值必须留在区间中），不把量化值当精确真值。成本先按相同单次查询数比较，并另列传输精度与供应方细数据需求。直接K/事件发布只作**不同测量类**的上限参照，不与一个点查询等价计费。
4. 同一真路径、同一基础集合，比较固定时钟均匀布局、固定种子随机、最大当前CIF可行区间宽度，以及普通决策分歧/最坏剩余K跨度的贪心查询。自适应方法只能见已回答的查询及原粗包，未回答CIF由隔离oracle保管；所有方法同样得到已查询标签的信息闭包。若加入源prior/GP/原native粒子作查询排序，应给全部相关强参考同一prior，且**prior只排查询，不删除硬约束允许的世界**。
5. 主报告E=1{K>=1}、E=1{K>=6}的正确认证/未决率、K跨度、查询成本曲线及逐区结果，正负事件分开。硬认证只在可行集合对E全一致时输出。任何错误硬认证或真路径被排除都是失败；不靠删日/改阈值挽救。新增决策策略若在b=4相对最强普通策略的地区等权未决率没有至少10个百分点下降，或只在exact下有收益、量化后消失，则不推进“选择策略增量”主张。14日只是原型门槛，达到也需新冻结全源/噪声/实际成本检查，不算独立确认。

这个实验检验**对过去风险的测量/认证效率**，不计算未来CRPS改善。若后来要用合法滞后事件记录适应未来风险，需要另轮prequential合同、普通Bernoulli/计数状态空间与同预算概率校准参考；未来当前日的真K不能作为输入。原预测路线仍应先修复并完成native数据阶段、再补native-feature强控制，不以本测量实验替代它。

因此可以研究**带成本、延迟、量化和模型失配的具体碳风险测量选择**，但“决策导向query + LP认证”这几个词本身不构成贡献。需要展示：选定真实可用测量类后，新增约束实际排除了哪类反例；在同预算强选择策略下仍降低正确认证所需成本；若用了概率prior，失配只影响效率还是也破坏保证；与原预测任务的收益是否另经合法时间验证。当前仅有信息价值与可行集合证据，尚没有这些新机制结果或未知区测试授权。
