# V51 小时燃料组信息价值阶梯

## 目标

比较月度燃料总量相同、每小时总发电量相同的条件下，增加不同的一条小时燃料组总量序列，分别能把发电侧小时 CIF 的 sharp 物理可行区间收窄多少。该实验测的是字段的信息价值上界，不训练预测器、不声称中国公开字段可得。

## 固定信息层级

在每个完整源区月中，固定月度八燃料总量 `M_f`、各小时总发电 `G_h` 和项目因子 `[1000,400,800,0,0,0,0,400]`。对以下每个候选字段逐一增加其小时组总量 `A_h = Σ_{f∈S} g_fh`：

- `wind_solar`：风能+太阳能；
- `hydro_wind_solar`：水能+风能+太阳能；
- `coal_gas_oil`：煤+气+油；
- `positive_EF_group`：项目 EF 大于零的煤+气+油+other；
- `coal_only`：煤。

对候选组 `S` 与其补集分别执行连续背包分配：最小化或最大化当前小时排放分子，同时受月总量库存 `M_f` 和该小时组量/总量约束。每个小时的边界在这些约束和非负生成假设下是 sharp；不限制燃料每小时容量、爬坡、启停或跨小时耦合。各小时端点不主张可同时达到。

## 数据合同

使用已经查看的7个旧源区2022–2024原始小时燃料数据。只纳入完整日历月和有效、有限、非负、总发电量为正的小时；每个地区月的月总量由该同口径小时数据聚合。共203个完整月、148,104小时。所有新增小时组量都取真实小时数据，是 oracle；天气或其它模型产生的组量不能替代。所有组只在 V50 固定项目 EF 代理下定义。

每组报告平均小时边界宽、月内宽度p90的地区月小时数加权均值、区间包含观测代理 CIF 的比例，以及宽度≤100 g/kWh 的小时占比。地区月是描述单位，地区是宏观迁移独立单位；这里没有预测误差或未来覆盖指标。

## 边界

这是已看过的美国源区信息价值审计，不是中国可用性审计。中国“火电”“不可再生”“可再生”可能与项目组别不一致，且项目 `other` 因子是代理。禁止把实测小时组总量写成仅靠月数据/天气恢复的变量。逐源表及输入哈希见`results/v51-partial-identification-tiers/`。
