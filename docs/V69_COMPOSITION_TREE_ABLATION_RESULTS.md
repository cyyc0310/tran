# V69：同容量树模型下全构成没有稳定尾频率增量（2026-10-27）

固定V68的17个已开发EIA代理区、2026H1整区留出、月度发布/标签滞后规则和ExtraTrees容量（100棵、叶节点12、max_features=.8），只改变输入字段。V68质量过滤后为100个地区月、τ=300/600各有79/31个正尾地区月。

## 区域月误差

| 阈值 τ | 最近月热组EF+日历 | 最近月全燃料构成+日历 | 最近月+前三月全构成 |
| ---: | ---: | ---: | ---: |
| 300 | **0.1535** | 0.1454 | 0.1487 |
| 600 | **0.0919** | 0.1052 | 0.0993 |

数值为等权MAE，粗体为三臂最小者。τ=300加入最新全构成带来5.3% MAE下降，但地区聚类配对差95%区间为[−0.0386, 0.0287]，跨零，且改善不足协议要求的10%。τ=600最新全构成反而使MAE增加14.5%；追加三月构成仍比EF臂差8.1%。三月动态相对最新构成臂在两个阈值的变化都不显著。按冻结规则关闭这条候选，不开启封存区。

因此V68树模型相对季节均值的大幅提升不能归因于低频全燃料比例或三月变化带来的稳定增量；现有证据更支持简单热组EF水平加非线性/时序项已经捕捉主要可迁移信号。它也未证明特征本身完全无价值：置信区间仍宽，地区数只有17，但不足以作为论文方法创新。

下一步转向合法月统计中未归因的信息：检验总发电规模（全燃料月发电量之和，用户公开表可得）是否提供地区类型代理，并与热组EF做同容量ExtraTrees消融。如果总规模也无增益，停止继续堆叠月度特征，论文主线应明确为部分识别/拒答基准及其信息边界。仍需注意小时标签无真实首次发布档案、固定EF是生成侧代理、无中国小时实测验证。协议与原始配对结果见[V69协议](V69_COMPOSITION_TREE_ABLATION_PROTOCOL.md)、[脚本](../scripts/v69_composition_tree_ablation.py)和[`results/v69-composition-tree-ablation-r2`](../results/v69-composition-tree-ablation-r2/)。
