# V161：合法月报历史的粗层价值实验

在V160负结果后、V161评分前冻结。本轮不增加数据预算，只检查最近一期月报以外的已发布轨迹是否值得进入后续小时模型。它只预测月度能源加权EF锚A=ΣM_f EF_f/ΣM_f，不预测小时CIF，不评价区间覆盖，更不能替代原小时gate。

源池、六折proper/test身份和asof查询严格复用V159；29源、2024、模拟month_end+30日发布，不读新目标2025标签。校准源（每折4或5个）在本次点预测筛查中不使用。每折proper源全部2024可评价粗月样本作监督，不增加小时标签；测试区每月与V159 asof测试分母相同。

基础13特征：最近月8份额、log1p总量、统计年龄/365、目标月sin/cos、EF锚/1000。历史特征再加23维：最近两报告的8份额斜率/月、log总量斜率/月、两报告间隔/12、全可用前缀能源加权8组成、历史月锚标准差/1000、log1p报告数、最近至多6个合法持平回测误差RMS/偏差（各/1000）及log1p误差数。少于两报告时斜率和间隔置0；其他摘要使用实际可用前缀。

回测误差对某个已发布月m，严格在m月初以当时已经发布的最后一个月锚作持平预测；等m的报告已经在当前查询前发布后才可使用误差。不能用m最终值反过来决定当时预测，也不能把全部当前历史当成每个过去月当时可得历史。

九个固定方法：持平；最近两报告的线性趋势外推（按实际月份间隔）；local harmonic ridge（≥4历史报告时，时间/12与月sin/cos，ridge1；否则持平）；proper源Ridge1基础/历史/等维噪声特征；proper源ExtraTrees32、leaf4、max_features1、seed20261028基础/历史/等维噪声特征。噪声臂在基础13维上增加23维标准正态，以SHA256(v161/noise/region/month)固定、与标签无关，控制新增维数和搜索空间。proper模型拟合锚残差A_query−A_input，源等权；Ridge特征标准化只用proper加权均值/标准差；ExtraTrees不额外缩放。所有最终锚裁[0,1000]。

每个源区每月等权计算MAE/RMSE/偏差，再在29源之间等权。全部方法和源折完整报告。只有历史模型相对同容量基础模型及最强普通基线有跨折一致改善，才值得进入小时风险模型。该价值本身不算新算法；即便粗层MAE大幅下降，也不能宣称小时区间已经改善。

保存逐查询历史来源、发布时点、回测来源/预测/实际、维数、拟合角色、预测与哈希。原缓存仅覆盖2024–2025，不能把缺少2023报告误写成实际只存在短历史；本轮只能评估此缓存支持的短前缀。源训练和源测试共享2024时间范围，仍为跨区开发筛查。
