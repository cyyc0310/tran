# V278：冻结燃料构成风险门控的2026时间外验证

冻结日期：2026-10-30。V277开发数据提示，月燃料构成风险模型可通过简单规则选择性发布：只有校准风险半径严格小于跨BA pooled-source q90半径时才发布，否则该BA-month弃答。V277结果用于选定唯一分支；V278只用`fuel_mix`（八类月发电占比及月总发电量），不使用V277表现较差的净进口/因子扩展。

## 冻结设定

- 目标：EIA-930消费侧估算CIF，七个BA（BANC、BPAT、CISO、ERCO、FPL、MISO、NYIS）。
- 训练：2019–2023跨BA Ridge（alpha=10），以月燃料构成及月正发电量预测月内日最大绝对偏差的q90。
- 校准：2024跨BA留一校准；每个目标BA的校准乘子和pooled-source q90均排除该BA的所有校准标签。
- 时间外评分：2026年1月至可获得的最后一个至少含20个完整日的月份。2025标签不进入拟合、校准或门控阈值。
- 门控：仅当条件半径`<`pooled-source半径时发布；不按2026结果重调阈值、特征或模型。
- 中心：月度消费侧CIF加权均值是同月oracle中心，所以实验只验证给定月中心后的小时/日风险半径，不是完整的月前预测。
- 目标估算标签仍是EIA模型结果，不是独立CEMS覆盖；地区集合不是未见BA确认。

## 报告指标

报告全部七BA的有效日/BA-month接受率（零接受BA保留在分母）、接受日集的加权日同时覆盖、区间宽度、Winkler分数和逐BA接受覆盖，并列出全量发布强基线。选择性覆盖必须与接受率一起解读；拒答日不能计为覆盖。即使2026时间外结果良好，也只能支持时间外可重复性，不能声称未见地区泛化或中国验证。
