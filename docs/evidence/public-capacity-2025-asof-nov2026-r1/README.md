# 2025 public annual capacity available by November 2026

This evidence package archives official EIA-860 final 2025 data and DUKES 2026 Table 5.7, both published before the November 1, 2026 forecast origin. The extracted CSV aggregates EIA operable generator nameplate capacity by registered balancing authority and coal/natural-gas primary energy source. DUKES supplies a UK aggregate capacity context for GB; its boundary and de-rated capacity definition differ from EIA.

`audit_summary.json` stores source and output SHA-256 values, release dates, and limitations. The original EIA-860 workbook member names and DUKES sheet/row definitions are described in the parent audit. These are predictor inputs only; they do not bound dispatch or give target-hour CIF labels.

This audit does not contain forecast metrics. The currently sealed November prediction used the earlier 2020 M+C reference. A 2025 M+C forecast must be generated as a separate arm and later scored on the same target labels.
