# V401 machine evidence

This evidence package contains the r6 summary and all 231 region-month-threshold bounds from the 2024 EIA seven-BA information-identification experiment. The runner SHA-256 and source CSV hashes are recorded in `summary.json`; the detailed CSV SHA-256 is recorded there as well.

- Protocol and definitions: [V401 protocol](../../V401_MONTHLY_MARGIN_TAIL_IDENTIFICATION_PROTOCOL.md)
- Interpretation and limits: [V401 results](../../V401_MONTHLY_MARGIN_TAIL_IDENTIFICATION_RESULTS.md)
- Runner: [v401_monthly_margin_tail_identification.py](../../../scripts/v401_monthly_margin_tail_identification.py)

M+T and M+T+D use oracle information and do not estimate deployable prediction coverage. All target labels and regions were previously opened.
