# 日模型零均值特征清理证据

对应[R4结果](../../DAILY_RESOURCE_NUMERICAL_RESULTS.md)及[预测前协议](../../DAILY_RESOURCE_NUMERICAL_PROTOCOL.md)。与源扩展C同数据、模型参数和624唯一目标小时，零化14个数学上恒零的日均谐波输入；原小时调用数据不改。仍为已见国家上的开发检查。

`manifest.json`绑定本包SHA。预测CSV的gzip可无损还原原164736行；标签队列可按region、valid_at、label_row绑定，原始成员row沿用该2400行队列位置。`hgb_members.tar.gz`包含72个有/无天气HGB成员文件，可在两银行、两预算与9配置上独立复算原始CRPS；全部方法的点/区间评分均可由包内预测与标签复算。

其他模型的396个全成员、9个完整参数仍在本地结果路径，均已由独立Sol完整核验；本包不重复收入全部成员或大型RF模型，不是全原始重训发布包。源天气队列、派生气候和此前共享实现见[继承证据](../resource-response-development-r2-r3/README.md)；原生能源/GFS数据仍需按原始清单取得。源观察天气与目标签发预报的区别、原始发布认证False均保持。

`training_audits.tar.gz`保存9份源训练凭证；`results/independent_review.json`记载全指标、身份与14列scaler零均值/零方差检查。源功率及上界未更换，警告44→0，不能据此改说“Ridge旧收益稳健”。

HGB主要数值收益保留，但最差CISO56.94%、GB66.67%，原月报预算覆盖61.90%。清理是实现稳健性改正，不是原创方法、可靠覆盖保证或未知国家确认。旧C结果不删除，后续以清理实现作学习参考。
