# 伪目标组成条件样本重加权证据包

`results/` 保存五个外层目标的预测、封存记录、逐月/逐国指标、内层带宽选择及启动哈希。`code/` 保存运行脚本、导入的研究模块和冻结协议。`input/` 保存采集清单、质量审计，以及上一轮冻结粗组成专家门控的预测和校准配置，供同预算比较复核。

原始Energy-Charts国家响应约181 MB，保存在本地忽略目录`data/energy-charts-v2-panel-r1/`，没有复制进证据包；原始五国JSON及启动文件的SHA-256在`results/startup_hashes.json`。证据包内文件SHA-256见`evidence_sha256.json`。目标2024预测文件在任何目标标签评分前写入并记录SHA-256；标签指标随后生成。实验使用当前修订小时序列模拟延迟月量，不是历史as-issued中国月报，也不是实测CIF。
