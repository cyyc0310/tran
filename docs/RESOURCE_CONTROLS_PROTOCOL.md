# 日幅度第二轮：先补齐普通强参考

2026-10-31，Sol。查看[第一轮结果](RESOURCE_AMPLITUDE_RESULTS.md)后形成的自适应开发方案；下述方法与参数在第二轮预测/评分前固定。不打开未知国家，不以本轮选择宣称确认或创新。

## 问题和预算

第一轮裸立方风资源比例有日变化信息，但幅度失真，Ridge还出现约9755的风乘子外推。先判断这些失败是否能被普通饱和曲线、受约束回归及树模型解释，避免把弱基线的失败误认为专门机制的机会。

继续同一12个GFS窗口、1200个源训练小时、576个源校准小时、624个唯一目标小时、9个国家配置。匹配标签银行和完整源年银行分别比较，两者共用源幅度模型；原月报与静态装机代理继续单列。新增特征完全从现有天气、五年历史气候和公开月报导出，没有增加本地小时观测或新的地理点。

## 固定方法

共11个方法：原银行、第一轮天气太阳能、第一轮立方风光、固定饱和风光，以及Ridge/RF/HGB各自的无天气与有天气版本，另加受源最大幅度约束的有天气Ridge。

100m风曲线固定切入3m/s、额定12m/s、切出25m/s；切入到额定间立方增长，额定到切出间为1，其他为0。它是假设的通用参考，不是当地风机清单或机组功率曲线真值。历史五年逐小时计算该资源再按原本地年月与等年方式汇总，严禁把均值风速送入功率曲线替代逐小时积分。

所有学习器共享原日历、粗月报历史、原立方/太阳能资源比例，以及新增饱和曲线的季节比例/支持标记；有天气版再读取两种风资源预报比例与温度/度日。不在学习器之间更换特征。目标均为源实际日功率／源合法滞后月均功率的log1p，源国家、地区、日依次等权；无效燃料子样本重新计权。

- Ridge：强度10，标准化后拟合。
- 受约束Ridge：同一拟合，expm1后截为非负并限制在正确源训练样本的最大幅度；此上界不是目标物理上界。
- RF：256树、叶最少3样本、全部特征、随机种子416、单线程。预测在源叶响应范围内。
- HGB：200轮、最多7叶、叶最少5样本、学习率0.05、L2为1、关闭早停、种子416。输出限制为非负且不超过该源训练最大幅度。

每国只有6个或更少的单区源日时，树可能不能细分，必须披露，不能说这些模型已充分利用完整源年的天气—发电配对。完整源年银行虽有更多发电标签，本轮幅度学习仍只有匹配的稀疏GFS配对。

## 约束与判定

同一天、同银行的所有方法保持原kernel和随机供体索引，只改风光幅度，其余燃料不变。源未支持燃料q=1；气候参照不支持时对应燃料回到原路径。原银行、太阳能比例、立方风光三个分支的原预测和源CQR半径须与第一轮逐值核对。保存模型重载后预测须完全相同。

只允许源2022拟合，源2023H1作区间校准。全部配置的模型、预测、粒子和半径在目标评分前封存；所有方法使用同一源CQR规则，没有目标校准、目标挑上界/强度或事后删极端值。报告点/形状误差、原始CRPS、原始及校准覆盖、宽度和区间分数，展示逐国家负例。普通参考若已解释收益，不重新命名为创新。

未来扩大源观察天气配对时须作为新的源信息轨道：源历史ERA5可以参与国外训练，目标仍只读起点前GFS。源天气的观察/预报分布差异和修订档案假设须单列，不能把扩展源数据的差值归给本轮算法，也不能让被留出的目标国家混入源拟合。该扩展尚未在本轮启用。
