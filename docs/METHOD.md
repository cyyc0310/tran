# TransCIF-FD 实现思路(完整方法学,v1.0 最终态)

> 日期:2026-08-16 · 状态:FD-0→FD-17 全部落地 · 145 对正式数字:I_cfg **50.15** / I_0 **45.66**(首次大幅胜 legacy ZS)/ I_+ 47.07

## 0. 问题形式化

**任务**:在一组源电网上训练,预测从未见过的目标电网的逐小时碳强度(CIF, gCO₂/kWh)。**信息层级**(目标侧合法输入,严格嵌套):

```
I_cfg ⊂ I_0 ⊂ I_+ ⊂ I_J ⊂ I_S
 零遥测   +份额流  +CIF历史 +288h标签 +全年标签
```

I_cfg 是中国场景的产品形态(仅月度电源结构 + 公开气象 + 日历),也是本项目的方法学主贡献。

## 1. 核心思想(三句话)

1. **物理分解**:CIF = Σ_f share_f(t)·EF_f——预测**逐燃料份额轨迹**而非聚合量;每类燃料施加自己的归纳偏置(光伏=天文、风=功率曲线、火电=残差、基荷=水平)
2. **形态与水平分离**:水平来自 config/观测锚定(确定性),形态来自模型+确定性外生通道——两者的梯度通路刻意解耦(ZS+ branch-0 机制的模型内化)
3. **数据先于模型**:15 个 phase 中最大的三个增益全部来自数据工程(AU 时区 bug 修复、AU 燃料遥测、路由),模型侧增益集中在锚定与形态损失

## 2. 数据层(五条轨道,全部无密钥)

| 轨道 | 源 | 处理 |
|---|---|---|
| 逐燃料遥测 | US EIA-930 / UK Carbon Intensity API / **AU NEMED DUID 自分类提取** | 10 燃料规范轴;AU 用名字连接+强度带+夜间测试(注册表被 Cloudflare 拦) |
| 天气 | Open-Meteo ERA5(表面)+ weather2(阵风、海平面气压) | 时间戳连接;950hPa 归档不可用(探测全 null) |
| 燃料价格 | 世界银行粉红表(月)+ FRED(日) | 辖区映射(AU→日LNG/UK→欧TTF/US→HH)、z-score、**1 月发布滞后** |
| 日前负荷 | EIA-930 Demand Forecast 列 | z-score + **逐窗去均值**(年 z 会泄漏季节水平) |
| 天文/日历 | 纯计算 | **时间线规范化后**计算:AU 数据为 NEM 本地时→UTC(含 DST 修正),US/UK 本就 UTC |

**关键教训**:AU 本地时 vs UTC 假设的 bug 让 solar↔clearsky 相关 **−0.697**(天文通道错了 10 小时)——修复后 **+0.976**,并连带修复了 ZS+ 校准输入(这是打破 equalizer 的真正原因)。**任何多源数据管道的第一件事:统一时间基准到 UTC。**

## 3. 特征栈(逐窗口)

```
输入侧:
  x_rs       (L,)      可再生份额历史(I_0;I_cfg 时置零)
  x_fuel     (L,10)    逐燃料份额历史
  x_weather  (L,10)    温度/短波/风100/wcf/晴空指数/阵风/气压异常/负荷实际z/
                        风regime 24h均值/ regime 6h倾向(FD-16,因果天气派生)
未来侧(日前合法:天文/日历确定性,天气为 NWP 代理,负荷为官方预报):
  fut_weather(H,10)    同上(未来 24h)
  fut_exog   (H,17)    太阳高度角/晴空包络/wcf/csi/日历sin-cos×6/

                        年均晴空指数, has_fuel, |lat|/60]  ← 全部公开可得
  ef_vec     (10)      区域 EF 向量(热力组重标定至 ef_nr)
```

## 4. 模型(FuelDecompNet,~21k 参数)

```
config → cfg_mlp ─────────────────────────────────┐
                                                   ├→ 各头 FiLM/先验
solar:  cfg份额 × [astro(h)/日均astro] × (1+0.4·tanh(MLP(fut_weather)))   ← 天文主导
wind:   水平 × [wcf(h)/参考wcf] × 调制, wcf_norm ∈ [0.2,3]               ← 防爆炸
        参考 = 0.7·过去一周 + 0.3·年均,且干旱锚定(regime24/年均≪1 时向年均回归) ← FD-16
baseload(5): 水平(历史168h 或 config) + 支撑掩码×先验 + 掩码×日历修正     ← 零份额燃料不幻觉
thermal(3):  T = 1−Σ非可调度;  split = softmax(log(cfg+0.02) + 掩码×修正) ← 零初始化=配置先验
物理层:  CIF_fuel = Σ ŝ_f · ef_f · (1±0.35·tanh(EF校正))
聚合头:  DLinear(rs) + logit(mean_rs)锚定 + 持久门(仅历史模式)             ← AU/风主区路径
结构路由: wind_cfg ≥ 0.25 → 聚合路径,否则燃料路径(零参数,config 判定)    ← 风场代表性问题的解
水平锚定: CIF += gate·((1−rs̄48h)·ef_nr − CIF均值)  (仅 I_0;ZS+ branch-0 内化)
```

**容量纪律**:全模型 <25k 参数——三次证明深条件化零样本有害(FiLM/hypernet/融合元学习器)。

## 5. 训练

```
损失 = CIF MAE
     + 1.0 · EF加权份额误差(份额误差换算 gCO2 单位,避免被 CIF 梯度淹没)
     + 0.3 · 聚合 rs MAE(辅助/兼容信号)
     + 0.5 · 形态损失(逐窗去均值 CIF MAE)                    ← 直接优化日内形态
采样: config 距离加权 1/(|Δmean_rs|+0.05)(+18.5% 消融的最强杠杆)
冷模式 dropout: p=0.3 每窗独立丢历史 → 一套权重同时服务 I_cfg 与 I_0
可选: p_mix 物理引导网格重组(凸组合伪网格,物理精确标签;MAE 中性但冷偏差减半)
600 epochs · Adam 1e-3 · cosine warmup · 全部动态修正零初始化(从物理先验热启动)
```

## 6. 评估协议

- **LORO**:28 源→1 目标,29 区×5 seeds=145 对;测试=最后 20%,L=336,H=24,stride=24
- **配对统计**:Wilcoxon/paired-t/bootstrap + Holm;**效率比**(MAE/persistence)跨档均匀 0.93-0.96 是强 claim
- **双轨标签**:对燃料区域并行记 `vs 报告 CIF` / `vs 物理真值(份额×EF)`——UK South-East 标签噪声 10-37% 被隔离
- **日前双轨道**:Track A 再分析(主榜)/ Track B NWP 技能退化(`--weather-noise`,温度+2K/风+20%/短波+25%)——实测中位不变
- **形态指标**:diurnal MAE(逐窗去均值)、monthly-shape、Spearman(碳感知调度消费的排序量)

## 7. 校准(I_+ 层)

`zs_plus_predict`(既有主力)+ `make_zs_plus_share_fn` 钩子:6 分支(锚定模型/日滞后/周滞后/7日均值/周均值/原始)逐 lead 回测逆幂加权 + 56 天菜单重选。燃料骨干经修复的数据喂入后**首次全尺度胜过 legacy**(46.47 vs 46.80,win 82%)。

## 8. 部署路径(中国省份)

```

  → monthly_config_at(滞后1月) → FuelDecompNet(I_cfg)
  → 逐小时 CIF 曲线 + 逐燃料分解 + 排序信号
演示: scripts/experiments/demo_cn_province.py(虚拟华北煤主省:
  7月周 mean 497.6,光伏峰→CIF谷,煤电日内 0.68→0.54 让路)
预期分档:煤主省 easy(25-45)/水电省 A(15-35)/风光省 B-C(45-70,区间为主)
```

## 9. 设计原则(15 个 phase 的正负结果提炼)

| ✅ 有效 | ❌ 无效(勿重复) |
|---|---|
| 物理分解 + 确定性外生(天文/日历) | 深容量条件化(FiLM 30×/超网络/融合元学习) |
| 水平锚定(形态/水平分离) | RevIN(破坏物理水平) |
| config 距离加权采样 | donor 燃料距离加权(p=0.025 反向) |
| 冷模式 dropout(双层级一套权重) | I_J 单骨干联合微调(equalizer 之下无增益) |
| 确定性结构路由(零参数规则) | 晚峰损失加权(扭曲水平) |
| EF 加权份额损失(gCO2 单位统一) | 年 z 负荷通道(季节水平泄漏;去均值后中性) |
| 双轨标签/日前双轨道(把数据问题显式化) | 追求"系统中位 MAE≤10"(地板 50-53,天花板 30-35) |
| **数据工程优先**(时区/遥测/标签) | 950hPa 归档变量(不存在;先探测再集成) |

## 10. 最终数字与边界(FD-17 官方,`fuel_decomp_eval_full_fd17.json`)

| 层级 | median | 相对位置 |
|---|---:|---|
| I_cfg | **50.15** | FD-16 前 62.75 → 单位修复+场加权天气+τ=0.45 路由(win 83%,p=3.9e-20) |
| I_0 | **45.66** | **首次大幅胜 legacy ZS(50.72,−5.1)**;win 81%,p=6.8e-16 |
| I_+ | 47.07 | legacy ZS+ 46.80:−0.27(FD-16 前 +0.33)——遥测轨道少吃天气,诚实代价 |

**FD-17 三件事**:① 风速单位 bug(Open-Meteo km/h 被当 m/s:39-42% 小时误读为切出);② VIC1/SA1/NSW1 风电场容量加权天气(41 场 7 GW,wind_share 解释力 R² 0.08-0.15→0.33-0.48);③ 结构路由 τ 0.25→0.45(燃料路径扩至风电中区)。区级:UK_10 I_cfg 72→34、UK_17 105→70、VIC1 137→100。

**边界**:NSW1 残留 −8(DUID 标签噪声+近似坐标);UK_05 种子不稳;BPAT I_0 噪声放大;I_+ 微退。**天花板路径**:更多数据年、NWP 集合预报、真实省份试点。
