# 跨国迁移主线：年度装机增量与火电因子失效综合判断

更新：2026-11-01。本文将年度装机信息预算和五国火电因子误差分解放回用户确定的主任务：用其他国家小时数据训练可迁移模型，在目标区仅有有限、滞后公开信息时预测小时 CIF，并为中国部署建立可复现基准。

## 当前可支持的研究问题

中国式目标端可取得滞后的月度分类发电量；年度装机可作为独立可选预算。当前月表包含火电、水电、核电、风电、太阳能等技术类别，但火电未拆煤、气、油。于是月报能约束若干技术类别的月度总量，却不能直接辨认火电内部燃料份额、月内调度和小时形状。国外小时标签可训练这些关系，但跨国燃料结构和运行制度差异会造成迁移风险。

因此主任务应明确写成**跨国家冷启动小时强度预测**：源国提供小时监督；伪目标训练阶段只暴露目标可见的月报、滞后、年度信息预算和合法预报；整国外层留出只评分，不参与训练、调参或校准。年度装机是信息预算轴，不等同于算法贡献。

## 火电因子头为何没有胜过强重组

五国外层重建检查覆盖43,918小时；比例重组、因子历史头、macro重组和直接历史头逐行复现既有封存预测。宏观等月等国结果中，比例重组MAE为38.48，因子历史头39.37；90%覆盖分别为88.55%和85.64%。因子头并未解决区间覆盖，且点误差略差。

荷兰是清楚的失败例：外部源因子为437.1，而目标2024热电量加权因子为478.4；火电因子头在活跃小时上的误差为74.1，平均偏差−73.1。比例重组MAE为75.67，因子历史头为85.12，覆盖分别56.1%和50.7%。将预测换成真实小时热电份额、但保留源因子时，诊断MAE降至43.29；将预测份额与目标真实火电因子组合时为59.39。这两个oracle都看到了目标标签，只用于分路诊断，收益不可相加。

这表明剩余误差至少涉及两件不同的事：粗热电份额的月龄/小时变化，以及火电内部有效因子对季节和地区的变化。既有份额模板只比滞后月份额略好；简单因子头和伪目标收缩没有形成跨国稳定增量。下一步若研究火电因子，需用源国家间可验证的条件关系，并清楚限定目标端可以观察到什么，不能只再加一个地区特征后按已看国家挑结果。

机器证据与哈希校验见[因子分解证据包](evidence/factor-head-transfer-decomposition-r1/README.md)，冻结的诊断合同见[协议](FACTOR_HEAD_TRANSFER_DECOMPOSITION_PROTOCOL_20261101.md)。

## 论文创新和价值判断

现有结果**足以支持一个有价值的跨域基准/评测框架问题，但不足以宣称已有新预测算法**。目前可 defend 的工作量应落在：

1. 为目标地区定义可执行的信息预算（滞后月统计、年度公开装机、合法预报），并严格模拟发布时间和地理/技术口径。
2. 建立跨国家、整国留出的零目标小时标签评测，报告强重组、普通统计模型和概率基线，避免从小时伪重复推断泛化。
3. 把误差拆到可观察粗组成、不可见火电内部燃料结构和小时变化三层；用封存目标后的oracle只说明哪类信息仍缺失。
4. 若提出算法创新，应把新机制限定为**源端伪目标训练怎样适配跨国信息预算，并怎样估计迁移失败的风险**。已有门控、样本重加权、残差迁移和因子收缩都未稳定超过强重组，因此不能把这些现成尝试重新命名为贡献。

中国官方小时CIF真值目前缺失，故不能从海外代理结果声称中国预测准确或区间可信。中国数据可用于端到端部署输入/可见性演示和点预测发布；精度结论必须明确限定在海外整国留出代理任务，或等待独立中国小时标签验证。

## 接下来一轮的决策

- 固定M（月报）为主预算，M+C（统计年滞后容量）为单独嵌套消融；中国相容的宽技术类别容量是主M+C。煤/气细分只列为有额外字段时的上限/敏感性结果。
- 不继续单独搜索容量乘数、HGB容量头或静态锚。已见结果显示宽容量增量近零，煤/气形状锚虽改善点误差但覆盖不足，官方月量方向还出现明显反例。
- 下一方法实验必须针对“跨国伪目标训练的迁移收益是否随目标信息预算而变”这个交互问题；固定外层国家、按国家/月份配对，对比强重组、标准直接模型及伪目标方法；容量预算保持可开关并报告相对M的配对差。
- 开发域的改善达到预先设定的点误差、区间覆盖和区间效率门槛后，冻结所有选择，再对此前未读取的国家做一次确认。若没有算法增量，则论文主张收敛为统一基准、信息预算和可迁移性失败诊断，不声称新模型突破。
