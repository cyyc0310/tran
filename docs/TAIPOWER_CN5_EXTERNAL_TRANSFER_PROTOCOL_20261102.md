# 美英到台电系统：公开CN5月报外部迁移协议

冻结日期：2026-11-02。此协议在目标误差和目标区间评分前冻结。它评估严格滞后五类月度信息下的跨系统发电侧固定因子代理，不定义为台湾官方CIF，也不替代US↔GB双向主任务。

## 目标与证据边界

- 目标窗口固定为台湾2026年4–6月；目标小时标签来自台电公开机组10分钟净出力档案，统一聚合至当地整点小时。
- 预测目标是与源端相同固定EF构造的发电侧强度代理：煤1000、气400、油800、其他燃烧400、核/水/风/光及其他可再生0 gCO₂/kWh。该代理不等同真实电厂排放核算或消费侧CIF。
- 目标数据结构已在预检中打开少量记录，且台湾过往日尺度标签是否在全项目历史中出现仍未完全审计。因此本轮只称“预检后冻结方法外部压力测试”，不称严格盲测或盲地理确认。
- 当前台电高频文件是2026-11-01修订快照，覆盖2026Q2；目标月统计使用能源统计专区公开JSON API当前快照。没有可追溯的逐月首发输入快照，故该实验不是严格as-issued回测。

## 预测时输入合同

- 使用能源统计专区“3-02发电量（全国）”月表；从月报拆分煤、油、气、核、常规水力、太阳能、风力、生质能、废弃物、地热。燃料内部份额只用于形成五类中的火电总量，不作为目标特征。
- 按源端严格CN5定义构造五组：`thermal = coal + oil + gas + biomass + waste + other combustible`；`hydro = conventional hydro`；`nuclear`、`wind`、`solar`各自保留。抽蓄发电不计入主五组；地热作为0-EF `other_renewable`，不进入五组分母。五组份额除以这五类之和。
- 对目标月`t`，只使用精确`t−2`至`t−7`六个月份额和台湾当地日历。不得使用目标月或`t−1`月统计、机组级数据、小时标签、负荷、天气、年度装机或月度煤/气/油细分特征。若任一必需历史月缺失则拒绝该目标月，不替换为较新月份。
- 月份额取官方当前修订快照回算的历史月值；结果仅能说明严格月滞后输入合同下的回顾性测试，不能推断这些修订值在原预测起点已可见。

## 源训练、比较和区间

- 源端限定美国EIA七个平衡区与英国NESO全国区；2022年训练，2023年1–6月校准。目标台湾不参与训练、模型选择或区间校准。
- 冻结方法使用现有`multicountry_cn5`实现：`anchor700`、`macro_recomposition`、`ratio_recomposition`、`ridge_history`、`direct_latest`、`direct_history`、`factor_latest`、`factor_history`；增加既有`fuelshare_history`作为候选，不新增或调参模型。所有方法接收相同目标月表与当地日历；基线未使用的历史滞后视图不额外提供。
- 所有区间只由来源2023H1残差校准，沿用US/GB→AEMO交叉域实现：先等权汇总来源区域平均偏差，再用区域等权残差均方根估计正态尺度，形成90%区间并报告CRPS/Winkler。所有方法共用同一规则；它不代表目标90%覆盖保证。
- 预测点值和区间参数先写出并SHA-256封存；验证哈希后才下载/解析目标小时响应数值并评分。目标映射仅允许基于协议白名单，遇到任何未映射类别不临时改归类。

## 标签映射、数据质量与统计范围门槛

- 机组燃料枚举的固定白名单：燃煤→coal，燃气/LNG→gas，燃油→oil，生质能/废弃物/明确标记的其他燃烧→other，核能→nuclear，常规水力→hydro，风力→wind，太阳光电→solar，明确的地热/零直接燃烧可再生→other_renewable（EF=0）。明确抽蓄机组排除。购买电力、汽电共生但燃料不明、混合燃料无拆分、或其他未列类型均标为未映射，不根据结果选择EF。
- 台电10分钟采样每个整点小时必须有完整6个时间槽；聚合后小时标签映射出力支持须≥99%，所有映射燃料值非负且总分母为正，否则该小时不计分；若任一目标月有效小时不足预期小时99%，整月拒绝评分。
- 在目标标签解封后做统计范围核对：将小时聚合的五类月发电量与同月全国月报相应五类比较。任一目标月总生成量差异超过10%，或主要燃料类别差异超过10%，则标记月报/小时目标空间口径不匹配，主精度表不作迁移结论；不改用台电或IPP月表来追逐较好指标。
- 由于目标季度只有三个月，任何宏观指标都只视作该窗口的描述性结果，不做跨季度/全年泛化或显著性结论。

## 指标与停止规则

报告逐月和季度汇总的MAE、去日均形状MAE、CRPS、90%覆盖、区间宽度和Winkler区间分数，并与相同来源校准下的所有强基线对照。候选只在统计口径、标签支持均通过后评分。若fuelshare不能至少胜过`ratio_recomposition`和`factor_history`的MAE，或覆盖低于88%，或Winkler差于最强同预算方法，则不晋级并停止在该台湾季度调参。无论结果如何，不据此宣称中国省级小时预测准确。

## 复现和归档要求

保存月报API响应与请求时间/哈希、目标原始档响应头/哈希、列映射、源输入文件哈希、代码及协议哈希、预测封存、逐月评分和统计范围审计。数据按来源要求署名：Energy Statistics Information Service与Taiwan Power Company；遵守政府资料开放授权第1版。
