# V48：重组形状有预测价值，水平漂移需要单独控制

2026-10-27，Sol。本轮发现了更具体的优化入口：直接改用重组底座，会同时改变日均水平与日内形状，部分地区覆盖反而下降。将原锚定路径的逐粒子日均保留、只换入重组路径的居中形状后，15个水平的宏CRPS和形状误差均改善，覆盖均提高，但宽度也全部增加。这个匹配控制说明形状有独立预测价值，也说明不能把底座差异都归因于形状。它仍是普通仿射控制，没有证明新的风险学习机制。

原Scale-anchor记为A、Scale-recompose记为R，F为二者逐值相同的fine draws。U=F·EF8，P=MG_POS*(query_mean4·EF_POS)，S为已封月度水平。四模式沿用R−U+S、R−P+S、R+mean_particle(S−P)和Keep每粒子的日均重复。额外AlignedKeep为R−mean_hour(R)+mean_hour(A)−P+S：它在raw、clip前与旧Keep-A具有相同逐粒子日均，并保留R的居中形状及粒子配对。正式预测另与父V47实际Keep数组直接核日均一致，不只做自身公式互核。

这些加常数的控制不识别完整燃料比例，也不继承R原燃料重组的物理一致性或新中心的校准保证。clip会改变日均和形状，跨粒子分位数也没有形状保持保证。CIF与EF均为固定燃料排放因子的发电侧代理，单位gCO₂/kWh，不是实测排放或消费侧碳强度。PACE、LGEE、真正未知地区和新增供体2025细标签均未打开。

## 创新判断与下一步

本轮的推进是把“较好的形状”与“日均水平的非预期变化”分开检验，并找到普通架构下更有效率的区间参照。AlignedKeep属于普通仿射重排；形状保持与预测协调已有先例，新增文献核查见另存记录。不能将均值对齐、基线组合或更换小时底座包装成原创理论。

下一步应建立严格排除评估地区的源小时风险数据集，分别估计新中心的日均误差与居中形状误差，并比较普通全局校准、分量校准、异方差与条件分位数方法。先检验这些标准方法能否消化本轮的效率空间，再决定需要何种专门机制。候选创新需要利用合法粗历史能够识别的风险，同时保留不可识别的内部燃料与调度风险；仅给两种误差各乘一个尺度还不构成创新。

源风险预测必须排除相应地区的细标签、小时bank与条件比例训练，不能通过其他teacher回流；重建模型的规模变化和回溯快照条件也应保留。当前新中心风险未独立校准，开发地区仍被反复查看，方法不冻结，未知地区继续保留，长期目标未完成。
