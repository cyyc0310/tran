# V153：日历条件分布与月度边际一致性

冻结于V152后、V153评分前。继续V151的2024 proper源/独立校准、2025三个开发目标、两源划分和同月/asof30天预算，不打开新地区。恢复V144每个原始小时的UTC时间，必须逐月逐行复现全部677,928行发电数组后才能使用。UTC日历是合法输入；本轮不引入天气或当地时区。

六法：V151整月条件池；UTC小时条件池；UTC小时+周末条件池；上述两种池各自增加逐燃料期望边际重组；小时边际重组的供体小时统一偏移+7小时负对照。组成核固定.3，与V151相同、每源区两个2024近月、源区与查询身份排除不变。单元缺源小时则用该源整月回退并记录。

逐燃料一致性控制：原源形状q=g/(M_source/T_source)，源中不存在燃料则q=1。对查询完整计划UTC月的单元占比p(s)，计算每个供体/燃料的A=sum_s p(s) E(q|s)，条件化前使用q/A。它使计划日历上的期望燃料量等于提供的查询M；不改变缺失燃料假设、不识别真实小时调度。p(s)必须来自完整计划日历，禁止使用目标有效小时比例。缓存M来自回顾性有效小时总量，仍不是真实已发布完整月表，因此一致性只针对给定统计合同。

预测所有计划单元，按恢复的有效时间评分。相同V151 pooled与max-region源误差半径、完整经验CRPS、小时覆盖/宽度/Winkler。比较日历收益、边际调整收益及相位负对照；不能把条件分层或标准raking称原创。整月臂须复现V151全部对应原均值/CRPS/端点，日历一致性需数值核验。

保存月份/地区指标、源校准半径、源身份及输入统计合同、缺单元回退、边际归一误差、完整分母和哈希。目标统计质量筛选及模拟发布限制沿用V151；此轮只是下一机制必须战胜的小时条件强基线，未达到真实部署或独立确认。
