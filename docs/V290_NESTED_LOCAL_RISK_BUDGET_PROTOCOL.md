# V290：滞后EF支持下的嵌套本地风险标签预算

## 目的与证据等级

本轮是PACE/LGEE既有目标上的**探索性重复时间诊断**，不属于地理盲测、未查看标签验证、中国验证或真实as-of回测。它只回答：在V289滞后本年EF支持规则下，将月内本地完整小时风险校准预算从9天提高到12/15/18天，是否能减少此前3个欠覆盖月，以及区间效率付出多少。

V289规则在目标年份标签打开后提出；EIA工作簿没有历史发布vintage。校准日是本地小时标签，超出用户确认的中国月度/年度信息预算。因此无论结果如何，都不得宣称可在当前中国公开统计条件下部署。

## 冻结数据、划分与方法

- 目标仍为PACE、LGEE，2020–2023共96 BA-month；供体、因子支持、目标月oracle中心及小时评分沿用V286–V289。
- 方法为`lagged_current_year_ef`、`prior_year_local_ef`、`cems_support`、`source_loo`。前三者共享同一小时可行范围与样本；source_loo使用同一供体分数，作为已知失效的简单跨区参考。
- 比较校准预算9、12、15、18个完整本地日。对每个BA-month/repeat，9日抽样须逐字复现V289既有划分；额外3/6/9日从剩余日期按固定独立seed取样，形成嵌套预算。测试日是当月未抽入校准集的全部剩余日。
- 100次重复，基种子286；预算扩展seed290。各支持方法在同一抽样内配对；不调任何因子区间或风险规则。
- 主要指标：同时日覆盖、平均区间宽度、Winkler-90；同时报告BA-year及BA-month覆盖、低于90%的月份计数。按剩余测试日计算指标，不把校准日计入测试。

## 解释规则

- 若18日仍有任一BA-year均值低于90%，候选更新规则不通过既定年度覆盖门槛；不再增加预算或调同一目标。
- 月份均值跨过90%仅作为覆盖稳定性描述，不宣称每月具有有限样本90%保证；每月重复均值并非独立月外样本。
- 若覆盖增加但宽度/Winkler上升，结论是信息预算的覆盖—效率代价，不称算法创新。
- 无论如何保留V289的post-hoc/as-of限制。对中国结论只能说现有实验需要额外本地小时标签，月度逐类发电量无法提供该校准输入。

## 复现约束

运行前协议哈希写入metadata；不覆盖已有结果目录。脚本须验证V290的9日校准日和V289每个BA-month/repeat完全一致，且前三个支持分支的V286历史基线不被修改。运行后记录输入、脚本、协议和输出哈希。不得根据目标结果改规则后复用同一标签作为确认集。
