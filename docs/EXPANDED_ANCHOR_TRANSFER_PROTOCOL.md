# 扩展日期、同预算锚定与重组评价

2026-11-01，Sol。接续[源端锚定模型协议](HOURLY_ANCHOR_BASELINES_PROTOCOL.md)和[24窗采集协议](WEATHER_TRANSFER_EXPANSION_PROTOCOL.md)。本文件在扩展目标评分前固定；仍属已见US/GB/DE的开发，既有15日起点已查看，新增25日也不算未知国家确认。

在尚未消费新增目标成绩时，另固定一个不使用当期签发天气的独立阶段：共享历史气候参照保留，目标队列与源标签相同，装机预算仍分开。这一阶段仅读取已封存的公共cohort及其纳入审计，不读取GFS数值，因而不要求尚在采集的24窗完成。完整当期天气阶段继续执行，不以该阶段代替。所有源模型参数此前已经冻结训练完毕，两个阶段都不再调参。

源监督维持35448小时、6种proper source tuple。重用R5的48套绝对CIF/火电占比模型、6配对银行、R4同源标签的有/无天气HGB；增加48套源端加法/logit变化量模型。天气和气候信息合同一致。原月报与加静态装机代理预算分别计分，不把现有静态代理叫作认证年度发布版本。

原生日历为2023每月15/25日共24窗；当前队列由预先规则选出201地区日、4824小时（源校准2424、目标开发2400）。全体方法共用同一队列和缺测策略。按目标国留出：仅其他源国的2023H1校准标签计算风险参数，目标国上半年标签不可用于该国迁移模型的校准。

每预算固定45种方法/风险组合：4重组（原银行、无天气HGB、天气HGB、同标签简单cube风光）各raw/非负/signed校准，共12；4绝对响应与4锚定变化量模型各global/hetero/signed/nonnegative-CQR，共32；固定可见火电比例乘共同EF的简单锚仅源global校准，共1。没有额外全年标签轨道，不根据目标成绩选择每个地区的模型或区间规则。

不使用当期天气的阶段固定每预算23组合：原银行/无天气HGB各3风险，2绝对响应及2锚定变化量模型各4风险，加固定月报锚1风险。预期331200预测行、36成员、126校准、1242区域/414配置/46宏行。无天气重组在副本填中性占位值，仅使用B头；占位天气不进入模型设计。缺失全部天气列或任意更换天气值时，这两条轨迹必须与原R5无天气路径逐值相同。这里不是“只有月报、无任何气候先验”的预算。

另保存各直接/锚定模型的未校准目标位置、尺度和分位数，以及proper源校准的相同量，并与预测一起封存；用于独立复算校准和后续相同目标队列的风险消融，不由截断后的区间反推原尺度。源校准从原3日期扩为12日期，是新增源校准标签预算，不能把与R5的差值全归因于算法；日期扩展与校准扩展的效应需要在相同目标队列另作对照，届时源半径也须在目标评分前固定。

同标签cube比例沿用既有物理资源公式，仅更换为R5配对银行；不重新拟合幅度模型。全局和异方差区间以各模型声明的位置作对称中位数，CQR以拟合q50；logit位置不是物理条件均值。分位数交叉排序、signed中位数包络和0–1000物理修复保持R5规则，没有倍率搜索，也没有跨国覆盖保证。

所有已冻结源模型/输入/代码/元数据通过SHA后才评价；使用当期天气的完整阶段还须24窗齐全核验。完整阶段先计算全部配置预测与源校准并保存72个配对成员文件；对旧R5共有小时，3重组和4绝对模型的point/median必须保持一致。不使用当期天气阶段只核对其对应的2重组及2绝对模型。新区间可因源校准样本扩展而变化，不能强行要求半径不变。然后封存全部预测、校准、运行版本、计划和重叠核对；最后才消费目标小时标签作评分。

预期输出为648000预测行、234条源校准记录、2430区域行、810配置行、90宏行；实际小时和纳入状态仍以冻结队列为准。报告逐地区、配置及地区日起点的MAE、形状MAE、中位数MAE、WIS90、覆盖、宽度和区间分数，宏分数按地区→配置等权。所有方法共同用WIS，不从三个分位数伪造完整CRPS。小时不能当作独立国家重复，点差不能自动叫统计显著。

本轮目的首先是检验普通锚定变化量能否解释重组优势，并检验扩大源校准能否改善风险。若只是加宽、变换参数化或简单锚即可解释，不宣称专门创新机制。若在更多日期仍存在跨方法互补，下一步再做总发电先验—风光—火电补偿的同预算消融；真实未来总量、实际天气和当月细组成均不可成为预测输入。
