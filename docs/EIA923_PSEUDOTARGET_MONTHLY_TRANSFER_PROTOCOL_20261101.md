# EIA-923月统计驱动的伪目标训练：US→GB协议

冻结日期：2026-11-01。问题：将美国源BA的粗组成输入从小时回算替换为EIA-923报告月量后，源端留BA伪目标训练是否更接近目标月报冷启动，并能否改善GB跨国小时消费强度预测。GB 2024此前已用于开发，不属于盲测。

## 预算与输入

- 主输入预算M：当地日历与五类（火、水、核、风、光）月发电份额，严格使用精确t−2月及更旧月份。GB特征仍由NESO公开历史燃料月统计构造；美国来源BA在伪目标/训练特征有两臂：小时EIA-930汇总；EIA-923各BA官方月净发电量。
- EIA-923采用当前官方年度最终档案2020–2024。统计范围、BA代码、燃料映射和缺失月审计另行保存。2020/2021旧表用`Reported Fuel Type Code`，2022–2024新表用`MER Fuel Type Code`；旧表`WAT`常规水电映射到水电，`WAT`且`Reported Prime Mover=PS`的抽蓄净发电负值视为抽水耗电并截为0、正值保留；新版`HYC/HPS`映射到水电。其他代码按映射表归并后再按BA和燃料分项月净发电量映射至五类。
- 为每个预测/训练小时p，从BA月表取p−2；不以小时回算值补缺，不以更新月份替换；若输入缺失，该BA×小时从两臂共同样本排除。
- 两臂使用同一2022源小时官方消费侧标签训练、2023H1伪目标折选择、2023H2风险校准、GB 2024目标小时；不输入目标小时负荷、交换、小时燃料或目标CIF。目标GB 2024响应只在两臂预测全部封存后评分。
- EIA-923提供最终值，非历史as-issued快照。实验解释为“官方最终月报值按t−2滞后模拟”，不称严格发布时点回测。

## 伪目标模型与比较

采用已冻结的US BA留一伪目标专家回退流程，不另改算法或超参数。七个BA轮流作为伪目标r；内层专家排除r及被排除BAj，训练仅用其余五BA的2022小时标签。伪目标r的2023H1月报输入从对应预算臂读取。固定候选为`alpha∈{0,.25,.5,.75,1}`和`tau∈{.1,.25,.5,1,2,5,+∞}`，比较粗月pooled HGB与源专家的凸回退；温度以七BA等权伪目标MAE选择，alpha按相同伪目标集合选择。2023H2仅作来源区间校准。目标标签不参与模型、预算、alpha/tau或区间选择。

主结果比较M臂粗月HGB、伪目标回退、简单固定EF强重组、source mean、calendar/coarse Ridge；已批准的年度容量HGB另列M+C，不与月报M增量混写。指标包括等BA宏MAE、日内形状MAE、Gaussian CRPS、90%覆盖、宽度和区间分数；逐月、逐BA列出最差切片。若增量依赖加宽或点误差不能超过强重组，不称可信算法增益。

## 范围边界

只有US→GB可直接构造多源BA伪目标任务；GB→US仍作为既有单源方向，不能通过复制GB全国月表制造伪地区独立性。两个国家的官方消费强度估算口径不同，EIA-923与NESO源月量均非目标强度标签。结果是已查看开发目标上的信息预算/任务训练实验，不是未见国家确认或中国预测准确度证明。
