# V261 来源域嵌套选择风险残差校准幅度

## 研究问题

V260-r2的容量利用率特征显著改善来源BA的`log(q90)`留区预测，但原始目标区间欠覆盖，简单来源残差q90修正又过宽。V261只用2024来源BA嵌套留区CV选残差修正分位数，再将固定规则用于2025已打开目标；目标标签不得影响分位数选择。

## 嵌套来源验证

- 来源样本仍为V260-r2的2024年50 BA、596 BA-month；响应为各BA-month日max绝对残差经验q90。
- 外层GroupKFold按BA分5折。每折留出约10个完整BA用于评分；训练BA内再做5折GroupKFold生成OOF log-risk残差，残差校准分位数因此不使用外层验证BA。
- 模型为V260-r2的岭回归容量利用率增强模型；惩罚参数只在外层训练BA内用5折GroupKFold、log(q90) MAE选择。
- 残差修正分位数预定为`p∈{0.50,0.60,0.70,0.80,0.90,0.95}`。每个外层折用内层训练BA OOF残差的higher分位数delta校准q预测：`qhat=exp(predicted_log_q90 + delta_p)`。
- 外层评分使用留出BA实际完整日风险分数，先在BA-month内计算`score≤qhat`的日覆盖，再按BA等权汇总。覆盖目标≥90%，至少80%的BA-month覆盖≥85%；通过的p选平均区间全宽最小者；如无候选通过，选择平均日覆盖最高的p并停止目标应用。
- 该嵌套外层验证会同时报告每个p的覆盖、BA-month门槛比例、平均半宽、BA成簇bootstrap区间和选定p。门槛与选p只使用2024来源CV。

## 目标应用

只有来源CV存在通过覆盖门槛的p，才应用到2025目标BA。最终模型在全部2024来源BA上拟合；残差delta由全来源严格LOBA OOF残差按已选p计算。目标特征只用2025逐类月发电量、2024目标BA年度热耗率和2025 EIA-860容量库存。比较原始容量q预测、嵌套选择的来源残差校准区间及V254全源q90，目标CEMS小时标签只用于最后评分。

## 解释边界

虽然校准分位数只由来源CV选择，2025目标标签此前已打开，故目标评分是方法特定重分析，不是盲测。跨年漂移和BA内月份依赖未消除；来源区经验CV不提供无条件覆盖保证。任何标准岭回归/残差或conformal校准均不作为原创方法主张。全套目标中心仍是月后信息条件，标签仍是化石机组毛负荷强度。
