# EIA-923实时月度发行版与BA小时数据对齐审计协议

冻结日期：2026-11-01，评分前。目标是确认官方当前月度EIA-923发行版能否形成与已有EIA-930 BA小时面板可连接的真实公开粗月预算；本审计不训练模型、不评分CIF。

## 固定输入与范围

- 官方EIA页面在2026-10-23发布2026年8月月报；保存该页面提供的月度ZIP原始字节及HTTP响应头。发行页面同时列出下一次更新为2026年9月数据，预计2026年11月底。
- 小时对照使用仓库中2026 EIA-930 Jan–Jun、Jul–Dec两份原始文件，只评估七个既有BA：BPAT、CISO、ERCO、FPL、ISNE、MISO、NYIS。EIA-930文件是当前下载版本，不宣称其历史修订版本与EIA-923发行日完全同步。
- EIA-923 Page 1按`Plant Id × MER Fuel Type Code`列月发电量；Page 6 Plant Frame按`Plant Id × Year × Month`提供BA码。只使用2026年`Reporting Frequency=M`行，按plant-month连接；不使用年度调查记录。
- 燃料统一为煤、气、油、核、水、风、光、其他；映射固定为EIA-923 MER代码`COL/NG/DFO-RFO-PC/NUC/WAT-HYC-HPS/WND/SUN/其余`。EIA-930使用项目现有规范化和代理有效小时规则；符号净发电先按既有生成侧代理函数处理。

## 完整性与评分规则

- 硬检查月报标头的观察年/月、BA映射唯一性、Page 1目标BA电厂行连接、原生小时唯一性及月小时数。
- 计算EIA-923每个BA×月的数值行比例。若任一已映射Page 1电厂/燃料行的Netgen不是有限数，该BA×月标记为不完整；不把缺失补成零。
- EIA-930只在代理有效小时数等于该自然月的预期小时数时提供比较值；未达到的BA×月保留行并标记不完整，不插值、不外推。
- 仅在EIA-923和EIA-930均完整的BA×月上计算总量比及八类结构份额L1差。分别报告全部56个候选BA×月的连接、记录覆盖和有效小时覆盖，防止完整样本选择被隐藏。
- 目标估量是发布输入与现行小时代理聚合的一致性，不是模型误差、真实排放CIF或发行时点标签配对。所有目标BA均为已查看开发域。

## 可解释边界

如果Page 6月度Plant Frame能够提供唯一plant-month BA映射且足够BA×月记录完整，说明真实发布月报可接入现有BA模型的数据管道；这不等于完成US↔GB预测回测，也不能消除消费侧跨BA电力流、净发电统计口径和小时缺报造成的误差。后续模型实验仍需把该真实发行输入与修订小时回算的`t−2`输入配对，固定训练集、预测器和测试小时后比较。

原始发布来源：[EIA-923官方发行页](https://www.eia.gov/electricity/data/eia923/)。
