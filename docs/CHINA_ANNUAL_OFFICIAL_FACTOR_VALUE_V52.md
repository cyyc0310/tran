# V52：中国官方年度因子锚定与小时形状迁移压力测试

2026-10-27，Sol。问题是公开的本地年度电力因子能否为目标地区提供有效水平锚，以及能否据此迁移小时形状。结果用于确定信息价值与失效边界；它不是中国小时实测验证，也不是突破确认。

## 数据与可得性口径

生态环境部/国家统计局公布的2022省级电力二氧化碳排放因子在2024-12-26发布；2021版在2024-04-12发布，均早于2025年预测起点，因而可作为2025预测的滞后本地低频输入。[2022年公告及表格](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202412/t20241226_1099413.html)、[2021年公告及计算说明](https://www.mee.gov.cn/xxgk2018/xxgk/xxgk01/202404/W020240412827267102800.pdf)。不过，MEE因子是纳入电力净调入等因素的**消费侧**年度因子，不等于TransCIF当前代理定义的本地燃料发电侧小时强度；若进入中国论文，应单列 estimand 和信息预算，不得把年度因子当小时真值或硬守恒条件。

独立小时序列来自2026年Scientific Data论文随附的CISPO-China省级情景数据，覆盖31省及2025年等年份/情景。它是规划模型生成的消费侧小时排放因子，不是省级小时实测标签；本文只取30个同时有MEE 2022省值的省份、5个2025情景，每省8760小时，作为同一模型家族上的模拟器压力测试。[论文](https://doi.org/10.1038/s41597-026-07272-6)、[数据集](https://figshare.com/articles/dataset/Hourly_carbon_emission_factors_of_31_provinces_and_cities_in_China_from_2025_to_2060/28953545)。所以该评估不能证明对真实中国系统、其他国家或真实未见区的外推能力。

## 设计

逐个留出省份，只以该省在目标起点前发布的2021/2022 MEE年因子构造本地预测，比较：

1. 本地2022因子平铺为小时预测；
2. 全国2022因子平铺；
3. 本地2021至2022变化线性外推三年；
4. 其他省份2025模拟年均值对MEE两年因子的留一省线性映射；
5. 第4项加其他省份同一2025情景的平均小时异常；
6. 第4项加以目标省MEE因子条件化的其他省份同年小时异常回归。

指标按省等权宏平均，单位gCO₂/kWh。第4项用其他省目标情景均值作训练标签，因此是模拟器内的转移诊断。第5、6项更使用了其他省份的同年小时结果，属于**目标年形状 oracle**，并非部署时可得方法。五个情景虽然不同，但共享相同模型家族，不能当作五次独立现实世界重复。

## 结果

| 方法 | S1 MAE | S1 RMSE | 五情景 MAE范围 | 五情景RMSE范围 |
|---|---:|---:|---:|---:|
| 全国2022因子常数 | 225.05 | 245.53 | 224.40–225.11 | 244.89–245.59 |
| 本地2022因子常数 | 157.81 | 183.90 | 157.43–157.81 | 183.55–183.91 |
| 本地2021→2022趋势外推 | 151.36 | 172.80 | 150.68–151.56 | 172.22–172.95 |
| LOO省级水平映射 | 132.72 | 154.07 | 132.22–133.28 | 153.70–154.68 |
| LOO水平＋其他省同年平均小时形状（oracle） | 120.66 | 138.45 | 120.08–121.30 | 137.96–139.16 |
| LOO水平＋本地年因子条件化小时形状（oracle） | 121.03 | 137.89 | 120.53–121.49 | 137.44–138.41 |

本地年度因子相较全国常数明显改善省际水平排序，但仍没有给出可信的小时预测：本地平铺MAE约158，而目标小时标准差约102。对形状oracle作配对比较，因子条件化分支的平均MAE反而增加0.36，150个省×情景配对中73个MAE较低；平均RMSE只降低0.58，75/150个配对较低。五个情景的MAE差均为正（+0.18至+0.48），所以没有稳定增量。极少RMSE变化且以同年他省信息为条件，不足以支持新的形状迁移机制。

上述因子条件化形状不是更好的方法，最多是一个有用的反证：已知目标本地滞后水平，并不能让模拟器内学到的省际形状关系稳定转移到目标省。更强的同年形状oracle本身也只把MAE降至约120，仍留下大的水平/小时残差。

## 对研究路线的判断

- **可用信息结论：** 若用户可获得同口径、按省发布且预测时点前已公开的年度MEE因子，它值得作为单独的信息预算臂；在本模拟器中，本地年因子比全国常数更能提供空间水平信息。
- **不可支持的主张：** 年度因子不识别小时形状、调度尾部或区间覆盖，也不等价于火电/燃料发电侧小时CIF。不能据此宣称可信窄区间、真实跨地区预测突破或算法创新。
- **方法结论：** 不保留“本地年度因子条件化形状”作为创新候选。跨区同年oracle只作机制上限，不进入可部署基线排名。
- **下一步：** 真实中国方向应先把公开月报字段、边界、发布时间和修订版本做成逐列数据合同；在项目当前更贴近的月度可得条件下，按可识别量报告月度发电加权强度/范围，并单独评估小时风险。年度MEE因子可以作为额外低频预算与朴素滞后锚、趋势锚及标准动态迁移基线比较。只有在实测小时标签或可审计外部验证上出现同预算、源外稳定增量后，才谈冻结与新地区确认。
