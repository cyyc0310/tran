# V264 冻结协议：完整V239样本的一小时相位包络复制

日期：2026-10-30。V239已打开的16个EIA BA-month；这是一轮规则复制，不是新地区盲测。

## 问题与固定设计

V263在5个可解BA-month上发现，一小时局部相位包络几乎保留精确小时总量对尾数锐界的收窄效果。V264沿用同一代码规则扩展到V239全部16个2025 BA-month：AZPS、CPLE、ERCO、PACE、SOCO的4/7/10月以及PSCO 4月。

固定月燃料边际、每日总量、EF `[1000,800,400,0]` 和500 gCO₂/kWh阈值。每日真实小时总量曲线循环右移1小时形成观测；每小时允许真实值在观测当日相邻三点最小/最大值之间变化。与V263相同，按构造原曲线属于误差包络且日总量精确守恒。用MILP计算实际小时、精确小时总量和相位包络三种条件下全月超阈小时数K的锐界。

## 主要判定

报告完整16例及所有端点求解状态；主汇总仅纳入三种条件都已证明最优的完整配对。检验：(1)真实固定EF尾数是否包含；(2)相位包络界是否嵌套于每日-only界；(3)相位包络相对精确小时界增加多少宽度；(4)BA与月份异质性。集合见证包含不是统计预测覆盖率。

## 限制

目标来自已打开EIA活动量与固定EF代理，不是CIF独立测量。结论只回答固定可行集上的信息几何，不表示中国重建负荷等于发电量，不证明小时预测精度。求解未证明案例必须单列，不用incumbent充当锐界结果。
