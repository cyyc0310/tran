# CN5跨国迁移中的目标小时负荷Oracle信息价值协议

冻结日期：2026-11-02，运行前。该实验服务于优先级2/4：先确定小时负荷是否含有足够信息改善迁移，之后才决定是否花力气获取预测时合法可见的负荷预测。目标时点实际负荷不可部署，只作为信息上限，不能替代M主预算成绩。

## 数据与切分

- 数据：严格CN5九国Energy-Charts小时序列，2022源训练、2023H2源伪目标交叉留国校准、2024外层目标评分。国家为NL、ES、BE、AT、SE、CZ、SK、HU、SI；九国和2024已在项目开发中查看，因此本实验为已查看数据上的嵌套LOCO诊断，不是盲区确认。
- 主输入M：滞后五类月发电份额`t−2…t−7`、既有历史粗统计摘要和日历；与[燃料响应头协议](CN5_FUEL_RESOLVED_RESPONSE_PROTOCOL_20261101.md)保持一致。
- Oracle扩展M+L*：只增加目标小时实际`load`，并除以该地区2022年平均负荷，以去除不同国家规模单位。该2024同小时负荷在真实月初预测时不可得，因此所有M+L*指标须明确标成Oracle上限，不能当作真实部署输入或中国可得预算。
- `load`从Energy-Charts当前小时响应读取，按地区本地时钟与标签逐行对齐。缺测行按共同支持集剔除；不得用目标小时发电、燃料、CIF代理、`residual_load`或跨区流量生成Oracle特征。

## 第一阶段模型筛查

- 在同样训练行、同一源国家权重及同一HistGradientBoosting参数下，训练严格CN5 `factor_history`：预测热电活跃小时的有效因子；与原强重组使用相同、仅由源训练国家估出的热电小时形状合成CIF。
- M模型用`HISTORY`特征；M+L*只加`load_norm`. 不在外层目标调参或选模型。
- 第一阶段只筛查点预测和形状：源模型用2022训练，目标用2024；每个目标国家都完整排除在监督训练外。暂不构造预测区间，避免Oracle输入价值筛查与风险校准混在一项里。
- 2024外层目标预测在读取目标燃料标签前生成并封存。评分按国家内月份等权、目标国家等权；报告MAE、日内形状MAE和逐国分布。另报告严格比例重组，不以它替代同头M对照。
- 只有Oracle在多国显示清楚的中心/形状增量，才追加第二阶段：复用严格源伪目标交叉留国校准，评估覆盖、宽度和Winkler；第一阶段不允许据点误差改善宣称可信概率预测。

## 预先规定的解释门槛

- 若M+L*相对M在至少6/9国家降低MAE且国家等权MAE至少降低5%，则说明目标小时负荷可能含有值得追踪的增量信息；下一项才去寻找具有as-issued发布时间的合法负荷预测，并以同样分区做真实M+L回测。
- 若Oracle本身没有稳定增益，停止该负荷特征路线，回到滞后粗组成的可识别性/回退机制。
- 若点指标提高但覆盖或Winkler变差，记录为中心信息增量，不晋级为可信概率方法。

无论结果如何，M+L*只作“信息存在性上限”。中国用户确认的主预算仍是省级月发电类别统计；该实验不能被表述为中国负荷数据可得、可部署或消费侧流量充分。
