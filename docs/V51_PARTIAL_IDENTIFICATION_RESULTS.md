# V51 月度信息与小时 CIF sharp bounds 结果

## 物理边界宽度

203 个完整源区月、148,104 小时的结果如下。区间两端是给定信息集和固定 EF 下的逐小时 sharp 边界，小时覆盖均为 100%，这是构造保证，不是模型预测能力。

| 可用信息 | 平均小时边界宽度 (g/kWh) | 月内小时宽度p90的加权均值 | 窄区间小时占比 |
|---|---:|---:|---:|
| 仅月燃料总量 | 838.42 | — | 依源而异 |
| 月总量 + 小时总发电量 `G_h` | 764.68 | 770.21 | 25.58%（宽度≤500） |
| 月总量 + `G_h` + 小时正 EF 组总发电量 `P_h` | 220.11 | 265.13 | 26.36%（宽度≤100） |

实际小时 CIF 的月内标准差按小时数加权平均约37.28 g/kWh。表中p90列是203个源区月各自的小时宽度p90，再按月小时数加权的均值，不是把所有148,104个小时合并后的全局p90。小时总发电量单独只把平均物理区间缩窄约8.8%，仍远宽于观测月内波动。增加每小时正 EF 组发电量后，平均区间宽度比仅 `G_h` 情况下降约71.2%，这是这轮最明确的信息增量；它仍是均值220、月内p90加权均值265的宽边界，地区差异很大。

地区月均宽度（仅月度 / 加小时总量 / 再加小时正 EF 组量）：BPAT 400/400/0；CISO 920/823/217；ERCO 1000/1000/341；FPL 610/401/0.5；ISNE 1000/783/266；MISO 1000/1000/398；NYIS 800/757/203。固定因子和现有源区燃料库存使不同区域的潜在收益差异显著；不能用宏平均遮盖 ERCO/MISO 的宽边界。

## 研究结论

用户当前确认可取得的是月度各类发电量。该预算能形成月度能源加权 CIF proxy 或类别 EF 不确定时的月度识别集合，但无法由数据本身识别小时风险。已有脚本证明，甚至额外知道小时总发电量也不足以点识别时间平均 CIF；本轮边界显示，小时总量对逐小时 sharp 区间的收紧通常很有限。

最值得优先考察的最小本地小时信息，不是“再给一条小时总量”，而是**小时正 EF 组的发电量或其占比**（与小时总量配对）。它直接约束排放分子的供给侧来源。在本项目固定 EF 代理中，这个 oracle 分量显著收紧区间。对中国，需先查清月表是否含煤、油、气、生物质分项，以及有没有公开的小时火电/燃料组时序；官方火电分类并不等于项目正 EF 组。若只有天气数据，天气预测的可再生形状只是模型假设，不能冒充观察到的 `P_h`。

这一结果支持一个更有价值的论文主线候选：**低频统计下的可识别集合与小时风险的信息价值基准**。统一框架应分开报告：月度统计严格识别的部分、在给定本地信息预算下的 sharp 小时边界、模型给出的边界内概率分布，以及跨地区覆盖—效率。把月度平均 proxy 直接称作小时 CIF 预测会越过识别边界。

尚未达到算法突破或新颖性确认：transportation / continuous-knapsack sharp bounds 是自然的已知优化构造；本轮只展示项目情境中的可识别边界和一项信息预算的经验价值。新颖贡献需要通过真实中国 schema 与可取得发布序列、强预测基线和真正未看地区回测，证明 benchmark/协议可迁移且信息增量稳定。`P_h` 在中国可用性未确认，故本轮不据此冻结方法或开启目标地区。

输入/输出和逐小时区间在`results/v51-partial-identification/`及`results/v51-partial-identification-grouped/`。输入均是已经查看的七个旧源；没有 target 或新地区数据进入。
