# 官方消费强度上的伪目标重组残差学习协议

冻结日期：2026-11-01，运行前。研究优先级2/3：源域拥有小时响应和燃料标签时，用跨BA伪目标训练一个对强重组的受限误差修正器；检验它能否迁移到GB官方消费侧小时强度。

## 任务和预算

- 仅US→GB。美国七个BA构成源域，可提供诚实的留BA伪目标折；GB只有一个全国源/目标，不能在GB内部构造伪目标训练任务。
- 两个输入臂：`hourly_reconstruction`用EIA-930/NESO小时序列回算的t−2月度粗组成；`eia923_monthly`将美国BA输入替换为EIA-923官方月度粗组成。GB输入两臂相同。
- 响应是EIA官方消费强度，GB目标是NESO `CARBON_INTENSITY`消费强度，两者均为机构估算。目标2024在本轮前已被打开，实验是开发回测。
- 强基点是源小时燃料校准的固定EF重组。候选修正模型只学习观测官方消费标签与强重组之间的残差；目标推理仍使用目标t−2粗组成、日历和源拟合修正器，不用目标小时标签。

## 伪目标训练和选择

1. 源训练年为2022。每个US BA各作为伪目标一次；对伪目标的强重组基模型只使用其他BA拟合，然后在该BA得到逐小时强重组残差。伪目标行拼接训练残差Ridge与HGB修正器，区域等权。
2. 选型严格留BA：每个2023H1验证BA既不参与该折的基模型拟合，也不参与残差修正器训练任务；候选仅为残差Ridge/HGB和收缩系数`{0,.1,.25,.5,.75,1}`。按BA等权MAE选择，平分时取更小修正系数。所有选择只看源BA，不看GB 2024。
3. 2023H2独立执行留BA源校准：每个留出BA的基点和残差修正器都只用其他BA；校准预测误差按源BA等权，估计方法专属bias与Gaussian sigma。
4. 最终重组基点用全部US BA的2022标签拟合；残差修正器由2022年各BA交叉拟合的伪目标残差训练。GB 2024所有预测先写盘并封存，再读取目标标签评分。

## 基线和判读

比较源均值、日历Ridge、粗组成Ridge/HGB、容量条件Ridge/HGB、固定EF重组及所选伪目标残差回退。主要看MAE、日内形状MAE、CRPS、90%覆盖、宽度和区间分数。需要同时优于强重组，且不得靠降覆盖换窄区间；若被选收缩为0，或跨国增益很小/覆盖下降，则结论为源内伪目标不足以识别可迁移修正。

EIA-923用2020–2024现行最终档案并按t−2模拟，非历史as-issued。源监督/校准来自2022/2023，官方目标标签已在早期开发中查看，故不能称为盲测确认。整个比较专注源端训练和跨国推理，不据此声称中国精度；中国省级真实小时CIF尚无验证标签。
