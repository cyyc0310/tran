# V167：未观测燃料增长与观测到的正转零输出分开处理

新评分前冻结。V166的载体敏感性未改善整体，观测过去0→当前正的放大代理也很小；但过去和当前均为0的源燃料，在目标过去为正时，原动态重组仍将其未来量置0。改变正载体强度不能改变分子0。本轮仅检验这项建模约定，不能预认定它是失效主因或原创机制。

沿用V159的29源六折、2024、asof_30d、proper源相同≤4096小时、相同供体和校准地区，不打开2025目标或未查看地区。所有预测仅使用目标已发布月报；源proper当前月量作为源训练结果可用。源某月0不是结构性装机0。

定义目标过去S、载体B=.99S+.01π，源过去D、当前F，原世界a=B*F/(.99D+.01π)。原source shape的q在源当前正燃料有观测，为0时仍沿用q=1占位。本轮不引入缺失形状新学习器，保持此假设并记录局限。

仅当D_j=F_j=0且S_j>0时，将燃料j视为源增长响应未观测。源D_j>0、F_j=0是观测到的正转零输出变化，不能据此断定停机原因，本轮不覆盖其0；源D_j=0、F_j>0的出现仍保留原载体映射。

八臂，前三个为原positive、原conditional、V164 world_gaussian参考；新增五臂：

1. mask_reweighted：原动态原子不变，原条件概率p乘exp(−m/.1)，m为上述未观测燃料的目标过去能源份额之和。仅普通供体支持惩罚控制，.1预先固定。
2. neutral_share：未观测分量a_j替换成B_j，再与原q shape重组，其他分量不变。表示中性份额增长假设。
3. neutral_energy：未观测分量替换成B_j/t，t=源当前总月量/源过去总月量，其他不变。表示中性月能源增长假设。两个中性假设分别保留，不按测试分数挑选。
4. neutral_share_gaussian：share世界构造后，用其世界能源锚与相同合法Ahat/σ进行V164 Gaussian更新。
5. neutral_energy_gaussian：同上但用energy世界。

Ahat和σ完全沿用V165确定求和顺序的proper-only月度点模型/五折OOF RMS，未使用目标当前粗量、小时标签。所有候选使用相同月报类别/源小时预算；Gaussian对照用于区分普通月度锚预测更新与缺失增长处理。原世界乘其共同源总量增长因子不改变CIF；energy填补中的t不能省略。

每臂按相同calibration地区重新求pooled/max_region半径；新五臂还使用原conditional固定半径。三个参考只报recalibrated，因此每test月26评分，241月共6266行。原两参考964条、Gaussian482条须复现旧归档≤1e−7；每折两查询同时扰动小时数据容器与月度容器中未发布目标月统计，完整预测CDF必须保持不变。保存每世界mask、权重、月度a/锚以及粗层预测；这些是可审核模型输出。

报告CRPS、严格/ULP64覆盖、最差地区、宽度、Winkler及非固定EF24源。与V164组成预测、普通熵更新、V165异方差及V159标量/V160MMD比较；相对于弱原重组有收益不代表原创增量。通过原gate才可讨论冻结新地区。若中性填补只改变均值或加宽区间，不推进为论文机制；若缺失增长有价值，下一阶段才比较q=1与同预算独立/条件形状补全，不提前声称成功。

本轮只是支持掩码与中性增长的普通控制，未证明存在可识别的目标反事实；共享2024时间、合成发布日、固定EF代理等限制不变。
