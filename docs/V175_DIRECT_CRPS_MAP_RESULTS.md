# V175：直接CRPS与地区minimax未过门槛，停止当前再校准支线

2026-10-29，Sol。18方法、16,388条CIF评分及全量审计完成，1,504项描述性数值比较全部false。所有新候选连宏覆盖90%/最差85%的双条件也未通过。没有新地区或2025确认。本轮没有足够的论文原创增量，按预定规则停止扫描再校准网格、α或地区例外。

## 困难地区与负迁移

同一pooled、自身校准下，CPLE原Gaussian覆盖63.64%/宽174.65；全局half67.83%/182.93，地区max half84.77%/261.49。AVRN则从68.93%/282.71到全局74.63%/317.28、地区max75.05%/326.74。局部覆盖提高仍伴随明显变宽，且最差地区仍不足。

EPE全局half覆盖91.76%/宽83.90，优于原89.70%/93.87；但43维half反而70.68%/54.77、CRPS18.432对原16.946。PNM的地区max half宽425.99对原270.06，CRPS68.087对61.353。不能只用EPE全局的正例代表统一迁移，也不能将更宽区间解释成有效创新。PACE/LGEE/SC未在本轮重新评价。

事后优化诊断还显示：Gaussian/43维half在proper源核混合上的目标平均下降3.169，而真实held源CRPS恶化0.110。这个源量是拟合混合上的优化下降，不是可识别的目标风险改善；不能唯一归因于过拟合、地区偏移或内外训练池差异。它说明“目标确实优化成功”与“风险可迁移”是两件需要分别验证的事。group_max的源最坏风险与held宏平均本来也是不同目标，不直接互作校准量。见[优化诊断](../results/v175-source-objective-diagnostic-r1/macro_gains.csv)。

## 实现和审计

保持V174样本、19点单调映射、20/43输入与PIT森林树/叶权重不变；只改变叶内平均的统计与后续凸优化目标。逐查询手工叶权重复现原森林PIT输出，预检最大差8.88×10⁻¹⁶。λ=.95α直接进入真实CIF横轴的CRPS二次目标。group_max优化完整绝对地区CRPS，保留支持外常数；不是相对identity regret。

源归档重建30个内部物理模型、458,048条跨折累计源行，旧PIT边界/来源全部复现。审计对916,096组系数、46,272个源law状态，以另一种dense basis/overlap积分逐项检查H/b/常数，最大差2.00×10⁻¹⁵。累计行包含相同原小时跨折重复，不是新增独立样本。

200个随机mean toy零回退；二次式与直接CRPS最大差1.14×10⁻¹²，独立SLSQP目标差5.63×10⁻⁹，解析两地区minimax通过。预检r1在正式评分前补充清理后完整目标/可行检查，最终使用r2；保留旧版本，不混为独立性能试验。

完整CIF审计重拟合映射、重建7,712条映射和16,388条评分，370,176次物理支持及证书应用检查、185,136次独立QP检查，5784条固定半径与唯一V174对应PIT逐行绑定；12未发布粗量干预通过，原964参考复现。最大评分差7.28×10⁻¹²，独立重权质量差1.19×10⁻¹⁴。所有370,176次证书应用均无identity回退，因此不能把失败归咎于大量求解回退。全局证书重复应用，不称370,176次独立求解。

1,504项比较包含1280强参考、96匹配PIT、96匹配global/group-mean、32无历史消融；其中部分强参考与匹配PIT是同一比较的不同标签，不是1,504个独立实验。重建使用共享冻结预测/评分辅助函数，独立数值积分/KKT有明确单独范围。所有bootstrap均为反复查看源开发的配对描述，不是独立确认。

## 论文判断与路线决定

直接CRPS映射已有[Technometrics2025](https://www.tandfonline.com/doi/full/10.1080/00401706.2025.2464004)等先例，普通minimax也不是原创。本轮补齐了标准目标与稳健控制，没有产生可主张的新方法。不能把数值QP实现或辅助源目标的下降包装成论文贡献。

停止当前单纯再校准支线，不据此证明所有可能的再校准都无效。下一步转向尚未检验的聚合结构价值：在严格同小时预算下比较同步组合、时钟内置换与比例缩放控制，检查月报能约束多少聚合风险。只完成了[V176元数据库存](V176_AGGREGATION_INVENTORY_RESULTS.md)，价值实验尚未实现，也未证明新颖性。

共享2024时间段、合成发布日、固定EF非负生产侧代理、内层训练地区少于外层、实际中国月报/版本尚未核验等限制不变。没有真实排放、消费侧CIF或目标覆盖保证。目标active，未查看地区不晋级。
