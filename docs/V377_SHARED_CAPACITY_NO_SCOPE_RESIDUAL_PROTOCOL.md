# V377：无范围残差时共享总装机能否解释V373增量

登记日期：2026-10-30。V376在宽范围残差下两臂均全月宽。本轮把残差固定为零，保持同一262个V373配对省期、CEC 2022滞后容量和τ=300，仅比较本地/全国月组成在共享总装机下的K集合。

## 设计

对每个已报月度技术边际，调用V376共享容量锐K集合求解器；范围残差电量固定为0，其EF取值不影响结果。thermal EF仍取400/1000端点形成hull，其他直接EF为0。系统总装机在每小时约束所有类别总和；已报技术组保留CEC技术容量上限。

将同一省期、本地组成与全国平均组成配对，报告宽度和全月集合数，并与V373独立组容量结果比较。若本地组成优势仍存在，则归因于本地边际而非宽范围残差；若共享容量有别的缩窄，则将其报告为容量交互而非新的CIF预测算法。

## 限制

零范围残差是过于乐观的边界实验，不代表用户现有NBS规上统计覆盖全省全口径。仍无中国小时标签、经验覆盖率或区间效率。
