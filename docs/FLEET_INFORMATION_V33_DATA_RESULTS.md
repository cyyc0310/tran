# V33：官方装机档案获取与字段检查

2026-10-26，Sol。本阶段确认四年官方EIA-860档案可获取，所需旧字段存在且表头可对齐。结论仅限档案完整性和schema，尚无装机特征、B1模型或风险改进结果。

## 已完成的证据

按[字段阶段合同](FLEET_INFORMATION_V33_DATA_PROTOCOL.md)，从EIA官方年度入口获取2020—2023四个ZIP，记录UTC检索时间、URL、响应头、字节数及SHA256。每档字节数与HTTP Content-Length相同，全部外层ZIP成员CRC通过；未解压写出任意成员路径。

公开日期依据官方通告及EPA指南，完整标题、正文年份与URL见[独立复核](../results/fleet-schema-v33/schema-review.md)。2021通告标题年份有笔误，按正文识别。四年在2025Jan1前已有公开发布，但当前下载字节是否等于首发历史版本仍未认证；Last-Modified也不能独立证明这一点。分页通告URL可能移动，本目录尚未存其不可变HTML快照。

只检查Plant、Generator和Multifuel共12个工作簿的metadata与前两行，得到28个sheet的表头；四年对应表头名称及顺序一致。核心字段实际存在：Plant Code、Balancing Authority Code／Name、Generator ID、Energy Source 1、Nameplate／Summer／Winter Capacity、Status，以及多燃料与混烧相关字段。

原始获取记录保存在`results/fleet-schema-v33/acquisition-YYYY.json`，完整表头与工作簿SHA保存在`schema-audit.json`。独立复核从二进制字节重新检查CRC、哈希、工作簿与表头，在worksheet第2行结束处停止；没有解析地区数据行或转换容量数值。

## 对下一步的意义

新增装机信息属于B1，原公开月报仍为B0；后续必须分别比较。字段存在只说明整理在格式上可行，还没有证明七源BA连接覆盖、机组键唯一、容量无缺失、能源代码归类正确或历史字段语义完全一致。

下一关先预注册七源数值整理：按plant BA筛选后再转换容量，按Plant Code＋Generator ID唯一计数，固定状态和主燃料归类，保留未匹配与多燃料不确定性。不能用州界或所有者替代BA，也不能把没匹配到的机组当成容量为零。

库存的容量和状态只提供结构特征。Operable还包括停运／备用机组；当前EIA说明书允许nameplate小于net summer capacity。多燃料能力也不等于过去或未来实际用量。因此本阶段没有建立认证出力上限，不据它硬截CIF；只有煤气容量时，POS量的归一化也不能冒称完整容量因子。

数据增量首先与同预算普通回归、装机比例锚比较。即使B1胜B0，也还需要单独证明风险机制的增量、小时效率和冻结后的独立地区表现。当前没有读取旧目标、真正未知地区标签或原始小时值，没有新模型训练；长期研究目标仍active。
