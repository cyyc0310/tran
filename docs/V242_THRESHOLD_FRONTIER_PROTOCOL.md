# V242 冻结协议：CIF尾数信息价值的阈值敏感性

日期：2026-10-30。数据样本沿用V239；在运行前固定相邻目标阈值。

## 目的

V239/V240的主要演示阈值为500 gCO₂/kWh。V242检验小时总量带来的尾数识别收窄是否只发生在这一阈值。

## 固定设计

- 逐BA-month完全沿用V239的16个2025完整BA-month。
- 固定V225名义八燃料EF，并以EF值合并为四组；不使用V240的EF±10%外包络。
- 目标阈值：400与600 gCO₂/kWh；事件阈值分别为400.0001与600.0001。500结果引用V239，不重跑/重挑。
- 同一V237 MILP求月燃料边际＋日总量与月燃料边际＋小时总量下全月超阈小时数K的最小、最大端点。

## 汇总与判定

- 记录全部端点状态和最优gap；仅两个信息条件的全部四端点均证明最优的BA-month进入配对平均。
- 检查日界包含小时界、所有实际固定EF尾数见证均在两界之间。
- 报告每个BA-month的宽度改变量、按阈值分层的平均和零信息/零风险等平凡案例数。若不足80%端点最优，不作该阈值的均值推断。
- 本实验仍是固定EF EIA燃料派生CIF的部分识别几何，不是直接CO₂真值上的预测覆盖验证。
