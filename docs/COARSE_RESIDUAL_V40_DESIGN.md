# V40草案：粗残差是否比能源结构多提供预测信息

2026-10-27，Sol。未实现、拟合或评价未来结果。V39显示源区平均碳偏差持续，但粗残差并非充分线索。下一轮测试普通低维条件残差校准，不能以其替代原创机制。

## 保持曲线训练规模一致

复用V39的42个已存五源Month profile，不新增曲线拟合。Outer T的六个inner profile各自排除了T和一个源s：在s上的校准标签来自该五源profile；部署T也使用同一个profile。所有新臂对这六个component分别校准后等权平均EF，不能拿五源OOF残差直接校准六源V38曲线而忽略训练规模差异。

同一outer只有六个源级校准样本，不能按154个月扩充有效地区数。V38六源Month及V36简单锚/门控保留外部参考；公平的新臂对照需要同一五源ensemble的未校准EF。

## 最小输入、标签和控制

固定source pseudo-origin为2023-07-01，取源s在该时点结束且已发布的最近12条粗记录；只用总量和零因子能源份额求POS。对应profile及各历史月自己的year−2登记库存形成d。两个候选输入为D=mean12(d)，S=mean12((EF_pred−400)/600)。S只来自源曲线预测，不含early真实EF。

目标每个2025查询同样取合法过去12条记录，使用相同函数。保留起止、公开日期、陈旧度、跨度与月份组成；仍可能与source陈旧度不同，不能因窗口长度一致就称分布完全匹配。2026-10-27的纯元数据预查已确认七个source窗口均为2022-06至2023-05，最新月年龄2个月、连续12个月；未转换发电量或份额，未拟合。收据`results/coarse-residual-v40-metadata-preflight.json`，SHA `99c09880b9705cfa75da8ab0418b43c541172919f575fca93ff4b2338f4904cb`。

标签先只用s在V39 late12月的平均EF_true−EF_pred，不同时试k；从k还原EF会额外需要未来POS分母，容易混入实现量或另一模型。早期真实EF、late真实量和late真实POS分母都不能进入特征或scaler。应用到单月query只称持续平均偏差修正，不声称训练/预测horizon完全匹配。

同样六个源样本、同一源profile ensemble，拟比较：未校准、仅均值、D-only、S-only、D+S。暂不加interaction。Ridge候选固定alpha=1、等源权重、未罚截距、训练内standard scaler，target按1000缩放；常数列明确中心化为零，不补epsilon。最终执行前应将这些细节写合同并预审，不能按2025结果更换正则。

对每个component，按true−pred符号加修正，并固定clip到代理因子范围[400,1000]；保存clip前值、是否越界、所有component及ensemble。CIF仍乘原MG粒子，不因更换EF模型偷偷修改粗组成。component散布不是完整后验风险，不据此宣称覆盖。

## 判断与剩余问题

D+S必须超过S-only，才支持粗残差在能源结构以外提供信息；只优于均值不够。还需EF/CIF共同改善、逐源与去单源敏感性不靠单源。先把这些普通强对照做完整，再讨论选择性纠偏或联合算子误差机制。

本草案未锁定最终执行代码、未来资格或创新。六源和反复查看过的35个月都只是开发证伪；B1登记库存的中国可得性与历史版本仍须另证。未知地区与小时标签继续关闭。下一步是固定最终合同并实现这五臂比较，不重跑V39持续性诊断。
