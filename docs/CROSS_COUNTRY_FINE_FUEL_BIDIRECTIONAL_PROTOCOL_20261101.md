# 美英双向细分燃料小时响应迁移开发实验

冻结：2026-11-01，运行与目标评分前。本轮检验第3优先级：在既有M五类月报基线之上，目标月报若额外提供煤、气、油等细分月份额，源域训练的燃料专属小时曲线能否在US→GB和GB→US两个方向都带来增量。

## 范围与信息预算

- 数据：仓库已有EIA BA与NESO GB小时燃料序列，源模型训练2022、源端偏差/尺度校准2023、目标评测2024。源/目标小时标签均为统一固定EF发电侧代理。
- 预测起点：每个目标月起点；目标输入严格使用目标区`t−2`及更早的完整月度发电量。输入由小时快照回算，模拟月度可见统计，不称官方as-issued历史版本。
- M预算：五类`thermal, hydro, nuclear, wind, solar`月份额与日历；强基线为源区训练的五类小时轮廓重组。另保留anchor700和source thermal-EF锚。
- M+F预算：在同一M信息上增加八燃料月份额`coal, gas, oil, other, nuclear, hydro, wind, solar`。源区2022按各燃料学习24小时归一化曲线，再用目标`t−2`八燃料构成重组；来源地区等权，目标标签不参与。
- 静态M+F锚：同一八燃料`t−2`份额乘固定燃料EF，形成不随小时变化的预测，用于分辨额外信息水平价值与小时曲线价值。
- 双向队列：US训练→GB目标，GB训练→US七BA目标；同方向使用完全相同源训练/校准与目标小时。主配对月份固定为2024-02、04、06，以对齐已有月报基准；所有其他完整2024月份另表报告，不替代主样本。

## 训练与风险评价

- 所有M/M+F使用同一源区域小时、同一2022训练、2023校准、同一目标小时和t−2目标粗月量。
- M+F只在源端学习燃料形状；目标端不学习或读取小时标签。偏差、标准差均只按2023源响应拟合。
- 报告逐目标区域/月MAE、日内形状MAE、Gaussian CRPS、90%经验覆盖、宽度和区间分数；宏平均先BA月等权、再按目标区汇总，同时报告两方向及最差地区。
- 若任一燃料在源2022完全无小时支持，使用显式平坦回退并记入provenance；不得声称该形状是学习所得。

## 解释边界

这是一项事后开发回测：2024地区和小时响应此前已参与其他工作，因此不作为未见地区确认。M+F目标月份额由目标小时历史回算，只代表八类月信息上限，不是中国五类预算；不得与官方消费侧CIF混称。候选只有在两个方向均有稳健点/形状或proper-score增量、且覆盖改善不是通过扩大区间获得时，才进入新的未见域候选；单一方向或少数BA改善不晋级。
