# 跨国小时预测的本地标签预算：滚动结果

## 研究问题和合同

月报误差不能稳定识别小时区间覆盖。本实验补充量化：在外国训练、严格`t−2`五类月量和固定因子重组中心之外，若目标区能提供最近若干完整日小时参考，小时区间效率会怎样变化？发电代理和官方消费标签分开评分。

使用已封存的七个美国BA 2024伪目标预测，点预测固定为本地Ridge月组成适配的固定因子重组。源区偏差和源区小时90%半径来自原实验2023校准，保持不变。滚动预算为18、24、28个连续完整UTC日；窗口前半估计本地区间中心偏差，后半估计90%风险半径。主对照是仅源区校准区间；另报本地偏差加源区半径，分离“中心改善”与“风险半径更新”。

本地小时标签和2024地区都曾在此前研究中打开，因此这是回顾性预算诊断，不是预注册/盲测结果。它是有目标小时标签的额外信息预算，不能替代零样本跨国主任务。所有覆盖都先在匹配评分日计算，再等权平均七个BA；不把小时当独立地区做显著性检验。

## 结果

主风险臂使用校准窗口后半的每日最大绝对小时残差作有限样本90% split 分位数。它瞄准整日同时覆盖，但同时报告小时边际覆盖。区间分数为小时Winkler90后按日平均。

18日预算下，宏平均小时覆盖分别提高11.2和10.9个百分点，区间宽度下降24.3%和28.8%，Winkler90下降52.6%和50.4%。同一测试日上5/7 BA区间变窄；发电/消费轨的Winkler分别在6/7、7/7 BA改善。若直接把风险窗口的小时绝对残差当作可交换样本算小时90%分位数，覆盖仍只有85.3%/86.4%，且区间明显更窄，提示小时序列依赖/风险漂移会让逐小时校准低估尾部。每日最大误差臂更保守，在大多数BA提高小时覆盖；MISO的本地区间反而比源区间宽，体现其严重欠覆盖需要更大本地风险半径，中心偏差修正仍大幅降低该BA分数。

## 这项结果能说明什么

18天是本设计下能把本地中心拟合与至少9个日风险分数分开的最小预算。它在已看美国BA上显示：历史本地小时参考可以同时改善小时边际覆盖和平均区间效率；收益不是简单把所有区间放宽。偏差修正臂单独保留源半径，能隔离中心迁移的作用；日风险半径进一步缩窄平均区间。

但本地日风险半径没有达到90%整日同时覆盖：18日预算的七BA宏平均约83%–85%，最差BA仍低于该标称目标。18至28日也没有稳定单调改善。日级分数会受连续日期依赖和月内风险漂移影响，有限样本秩不能自动带来时序覆盖保证。因而结果支持“少量历史小时标签可改善小时边际预测”的有限结论，不支持“18天足以让新地区的整日风险可信”。

该增量也不构成纯零样本创新，因为它显式读取目标地区小时标签。若中国研究合同不允许这类历史标签，本地校准臂只能留为信息价值上限；零样本主结果仍是来源区间和粗月报强基线。
