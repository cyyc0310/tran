## 仅粗统计可计算的约定暴露量

每个cal/test查询、每个选中proper供体保存原先验、过去/当前组成及以下代理量：

- shape缺失份额：Σ_j Squery,j·1{Sdonor,current,j=0}。分别以合法过去目标组成及oracle当前组成计算，再按各自供体概率平均。它是被q=1填补的月度能源份额代理，不是实际漏盖概率或小时因果贡献。
- 过去零燃料放大：a_d,j=Bquery,j*Sdonor,current,j/Bdonor,past,j；统计其中供体过去份额0、目标过去份额>0且供体当前份额>0的分量占该世界a总量的比例，再按条件先验平均；另报含这类分量的世界概率。
- ε=.001/.01/.1时的世界锚均值及离散程度、与ε=.01的漂移。仅为已固定载体约定敏感性，不从中挑最优方法。

观测到的某月燃料量0不等于结构性装机为0，也可能是停机或报告口径问题；不据此硬排除目标未来燃料。先检查暴露与已有误差/漏盖的关系；相关不证明因果。单项敏感性有无改善，也不能替代缺失形状、燃料出现和普通伪计数/hurdle等强控制。
