# V157：匹配源小时后，评分收益保留，覆盖门槛更敏感

实验完成576条目标月份评分，零断言失败。sampled与matched_full两臂使用相同供体月、身份和组成权重，仅改变读取的源小时标签；源小时样本严格采用V154索引。所有36个2025目标月保留，两预算/两seed/两校准全部报告。缺小时单元回退为0。

## 数据量的影响较小，但覆盖不能忽略

固定供体月份后，把完整源小时减少到每源最多4,096个样本，宏CRPS恶化0.16%–0.39%，远小于此前小时条件化相对整月CDF约11%–18%的收益。数据数量不足以解释该评分差异，但不能据此宣称所有强基线差距都已归因完毕；物理锚定与源燃料联合监督仍需比较。

同月统计的两次划分仍达到宏覆盖90%与最差85%，CRPS约37.37/37.65；asof第二划分sampled覆盖89.77%，略低于90%门槛，最差87.82%。所以V153“所有设置通过”的开发结论不能直接延伸到严格匹配数据的设置，不能按目标结果追加半径补回。

## 隔离与解释

SampledCalendarSource只从允许的原始小时索引读取发电标签，归一分母使用共用月度总量/计数。合成隔离审计将全部未抽中源小时与目标小时发电标签改为巨大值，预测均值和分位数逐值不变；改变允许源小时则预测改变。该测试检查标签隔离，不能替代真实数据准确性。

两臂均使用来源地区的完整月燃料统计作标准化，这是来源监督的一部分；学习器和重组必须在同一个“丰富源数据、粗粒度目标信息”的合同下比较。若后续从标量CIF预测转为联合燃料形状预测，应明确这是利用来源多燃料监督，不将其冒充额外目标小时信息。

本轮没有新增算法，也没有打开新地区。锚定条件残差的V156 sampled/full两臂现已全部完成，归因结果见[V156](V156_ANCHORED_HOURLY_RESIDUAL_RESULTS.md)；仍未形成统一效率优势。
