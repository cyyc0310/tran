真实月报在US→GB方向给粗组成HGB带来7.6%的MAE下降，区间宽度基本不变，覆盖上升4.8个百分点，但仍只有71.7%。容量HGB也有点误差和CRPS改善，覆盖升至67.8%，仍明显欠覆盖。固定EF重组的MAE下降6.0%，同时区间宽度由314.5降到290.5，覆盖仍高于90%；这是该方向最完整的预算增量，但重组本身依赖源小时燃料标签估计的固定因子与形状，并非新算法。

GB→US方向的HGB没有增量：MAE、覆盖和区间宽度基本不变。逐BA差异很小，MISO覆盖约0.04%，ERCO、FPL和NYIS也明显欠覆盖。固定EF重组MAE有所改善、覆盖从70.0%升到72.8%，仍达不到名义90%。因此真实月报未解决美国目标侧的主要风险。

## 研究判断

这是优先级1的直接证据：在真实机构消费强度响应下，目标US区域使用t−2 EIA月表并不能使GB→US小时迁移变得可靠；US→GB训练侧月报替换带来有限增量，且主要基线区间仍欠覆盖。收益存在方向不对称，不能包装成普适迁移算法。

年度煤/气装机作为M+C参照没有扭转欠覆盖。它在US→GB粗HGB分支上继续降低点误差，但覆盖仍低；GB→US容量HGB与粗HGB逐值一致，说明单一GB源区没有容量变化支持，不能学出可迁移容量效应。该字段只能作为单列预算，不是中国已证实可得的省级年度技术分类装机输入。

源GB单地区Ridge含近常量容量份额，`StandardScaler`出现约`−1.25×10⁻⁴⁵`的浮点方差警告；所有预测值均有限，封存哈希有效。该数值警告不影响HGB/重组主结果，但容量Ridge在GB→US严重外推，作为不稳定参照保留，不据此评判主要模型。需要继续解决的主问题是跨域标签/燃料结构响应和MISO等地区尾部覆盖，而非调大区间半径。
