# V6：发布条件一致的粗回测与条件分量风险

2026-10-23。Sol执行及独立审查。此协议在V6真实拟合和新目标评分前固定；旧V4/V5输出保留。

## 命题与信息边界

V5将月度季节振幅和统计年龄映射为风险，在四个新地区缓解欠覆盖，但宽度增加82.76%。本轮检验：相同发布规则下的历史粗预测误差，是否比原始波动更能指示未来小时水平误差；分别学习有方向的偏差、水平创新尺度和形状尺度，能否改善覆盖—宽度取舍。

这不是声称粗月误差等于日均误差。粗统计为能量加权固定EF发电侧代理，小时日均为另一估计量；只允许在源地区学习两者的统计映射。新目标无小时训练或校准，但允许使用预测前已经发布的目标粗月记录作历史粗回测监督。

用原2022四源拟合的V4 round2点模型字节（GP、周期回归、softmax专家），不重训点模型。每个当前origin仅选已结束且已发布的目标粗月；对过去月j，以其支持窗口中点为伪预测时点，只用当时已发布的前缀构造latest、seasonal及两谐波ridge预测。当前未发布的j不可作为粗回测标签。延迟在两处一致，为月末后30日加0/30/90日。仅真正存在同月历史或至少12月前缀时计入seasonal/harmonic误差；缺失计数明确报告。最近24个已发布标签月、36月伪前缀；窗口长短固定不在目标调参。

17特征含水平、月度波动、年度变化、年龄、历史数及三类粗回测的bias/RMS/SD和有效计数。所有基线获得相同合法特征；目标特征不参与变换拟合。源proper/bank/selection和目标合法特征的范围、有效支持单列审计。

## 源拟合、校准与开发

源七区固定BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS。条件残差模型用2024年1–6月；独立配对残差bank用2024年7–12月；2025全年原七区作开发/选择。这些源年份此前已查看，属于开发证据。选择这个时间划分是为避免2023H1仅有2022起始粗历史时的季节回测冷启动；在任何V6真实拟合前作出。源拟合域与校准域允许重叠，不声称独立域校准。

五种条件传输模式：

- global：恒定分量尺度、零水平偏差，是同源bank的全局膨胀对照。
- loglinear：全部特征的水平bias ridge、log绝对误差ridge、形状RMS尺度。
- extratrees：同特征、固定100树/min_leaf30/seed17023的通用偏差及异方差对照。
- structured：用粗回测signed bias预测水平偏差；用分量原尺度平方、中心化季节/谐波粗回测方差及其age/90交互，作非负正则方差回归；水平与形状独立尺度。
- structured_nohindcast：同类非负方差回归，移除粗回测，以原月度/年度波动代替，是信号消融，参数设计差异和自由度需公开，不声称完全等参数实验。

bias/loglinear ridge=10、方差ridge=1。固定数值地板1、尺度上限1e6、bias限幅±1e6；这只是数值防护。配对同一bank日的水平与零均值形状残差，等源地区、地区内等日抽样128条路径，seed17023；完整bank分位与情景经验分位分别评分。对五模式共同试倍率1/1.25/1.5/2；倍率仅缩放残差，不缩放偏差修正。三个点方法、三个延迟都完整保留。

loglinear和extratrees的尺度回归也获得各自原分量尺度的log1p输入及17粗特征，规范化仅从H1学习；候选不独占原点模型的不确定性信息。

额外保留V5七源普通分量1.10和β=.5风险方法的原2023拟合字节，仅作历史参考。其源拟合时间与V6不同，主创新归因必须相对V6同2024划分的通用基线，不能拿额外年份信息作算法贡献。

另以相同2024H1/H2信息实现CQR区间基线：hourly residual的5%/95% GradientBoostingRegressor，80树、深2、leaf100、lr=.05、seed17023；加入原点/尺度及小时周期，H1训练、H2 pooled hourly signed CQR rank校准。交叉区间排序，负校准偏移导致最终交叉时收缩为中点。CQR只有区间，不伪造集合或CRPS。小时依赖及未知地区偏移不满足常规exchangeability假设，不声称覆盖保证。

所有概率方法及CQR同用固定EF公开范围[0,1000]投影，原始点另存不裁剪；投影前越界质量存档。分量代数分离仅在投影前成立。

## 直接先例与创新边界

[CQR, NeurIPS2019](https://papers.nips.cc/paper/8613-conformalized-quantile-regression.pdf)已通过条件分位回归改善异方差区间；[UAI2025 ECP/EACP](https://proceedings.mlr.press/v286/kasa25a.html)研究无目标标签的分布偏移适配；[ICLR2025 WR-CP](https://proceedings.iclr.cc/paper_files/paper/2025/file/283066055b0256ca8e3e0c8c96019357-Paper-Conference.pdf)研究一般偏移下的覆盖缺口及多源正则。不能把“用输入调整尺度”“无目标小时校准”本身称首次。

本轮待验证差异是：真实发布算子下可获得的目标粗尺度回测误差，如何在存在聚合核算差异时支持小时分量的风险传输。现有回归/NNLS/残差抽样不是首创，不继承任意域偏移覆盖定理。中国、年度-only、真实发布vintage、EF不确定性仍未由此验证。
