# V24：公开月年字段的语义损失诊断

2026-10-26，Sol。运行前合同。本项是过去聚合代理的识别集合诊断，不是小时预测方法、预测区间、校准实验或中国数据验证；不触发未知地区测试。

用户本地预算仅公开月度或年度燃料统计。字段尚未给出，不能默认是八类发电份额，更不能把燃料产量或耗用量直接转换为发电量。本项先检验同一频率下燃料分组损失，决定后续数据合同和方法路线。

## 固定输入与运行边界

只读 `results/heldout-2026h1-data/monthly.csv`，SHA256 `77cb3b47d079094f13d3437f19b0315ba09ac50305981d69fd4f9991a7f07ee5`。先按字符串期间选择2022–2024与七个源地区BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS，再解析这些行数值。不得读取小时文件、目标地区、天气、telemetry或2025/2026燃料数值。月表为修订EIA固定EF代理、模拟月末+30日发布，非真实原始发布vintage。

主月度和年度比较固定为2023完整七区共同队列；2022–2024全部可用月份仅作背景，缺失月份列出，另报仅保留完整region-year的匹配月队列。年度只汇总同区同年恰好12个月的原代理总量，按total_mwh加权，禁止等权份额平均和缺月填补。12条月记录不保证全部小时完整，observed_hours/expected_hours及coverage必须保留；年度对象是这些eligible小时的代理汇总，不是已认证全口径年度统计。月等权与年能量加权本来不同，不能将界宽之差简单解释为时间聚合的净损失。

年度标记available_at=max(year_end,12个月模拟available_at)，只作该聚合的保守代理时间戳，不是官方年报发布日期。本项全为retrospective观察映射，不将当前/未来真值作为预测输入，也不训练模型。

## 固定分组与指标

燃料顺序coal/gas/oil/nuclear/hydro/wind/solar/other；EF=`[1000,400,800,0,0,0,0,400]` g/kWh，与当前代理相同，非中国真实排放因子。

六种映射：M8八类原样；CGO合并、其余五类分别保留；合并全部正EF组CGO+other、其余四类分别保留；CGO合并后分别再公开coal、gas或oil一个同月字段。所有揭示份额共用原同一总发电分母，不额外给某一分支更细总量。合并组不得称为已认证的中国thermal口径。年度使用相同六映射，不拆成12个伪月观测。

分组份额s_g给出的过去能量加权代理强度sharp区间为
`[sum_g s_g min(EF_g), sum_g s_g max(EF_g)]`。
上下端点把每组全部质量分别放在组内最低/最高EF燃料即可达到。sharp只针对固定EF、已知组总能量且组内可任意分配的类；不从历史零值推断未来硬支持。保存原八类代理值、两端点、宽度及端点燃料构造；包含原代理值是代数一致性检查，不称为90%/95%经验覆盖。只比较识别集合宽度，不叫缩窄预测区间或改善小时风险。

输出monthly/annual bounds、年度支持清单、源区及宏汇总。宏先区内各月或完整年度等权再地区等权。主月队列单列2023，背景all_2022_2024分开，不混合不同可用支持推断年度损失。每个完整region-year另报告原月代理强度min/max/range、对年加权代理值的月等权绝对偏差；这是观测到的季节变化，不是年度约束本身的sharp月界，也不是可预测性证明。

## 复核与后续

代码、测试、协议及唯一输入在解析数值前哈希封存；全新输出目录，日志不覆盖，失败记录保留，不自动重跑。合成测试覆盖分组端点、单字段增益、能量加权年聚合、缺月/重复/vintage/非法份额拒绝。独立代码和Python/科学审查通过后才运行。

本项不检验原创算法，也无晋级判据。若语义损失很大，优先考虑同月年频率下可取得的分项字段；若年度内部季节变化大，年度-only主方法需要源训练的季节潜变量及独立迁移假设。后续预测实验须让简单锚、标准动态、native重组与条件分布模型得到完全相同的月年信息；仍须原覆盖、CRPS、宽度及区间评分门槛，不靠统一加宽达标。
