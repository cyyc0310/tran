# US→Denmark固定粗月预算迁移压力测试

日期：2026-11-02。按[冻结协议](DENMARK_HOURLY_TRANSFER_STRESS_PROTOCOL_20261102.md)完成。它扩展优先级1的跨国小时迁移，不替代US↔GB主实验。丹麦2024 Energy-Charts序列此前已用于潮流/平衡审计，因此不是盲确认，也不能被称为项目首次未见国家验证。

## 任务合同

源模型使用美国七个EIA平衡区2022小时燃料数据训练、2023残差校准。目标侧只向预测器提供本地时钟和`t−2`火、水、核、风、光月份额。月量由丹麦历史小时数据回算，模拟滞后月报，不是官方as-issued输入。比较固定700火电锚、源火电有效因子锚、粗组成HGB和五类小时轮廓强重组。区间采用各模型对应的US 2023源偏差与尺度，不做丹麦目标校准。

固定因子标签按项目映射构造：煤1000、气400、油800、biomass+waste并入other并取400，核/水/风/光取0 g/kWh。Energy-Charts接口未给水电、核电；丹麦官方统计确认没有核电，水电约为2024发电量0.1%。由于水电EF为0，遗漏这部分会轻微高估代理强度，但缺少小时水电分配；该代理不是官方消费CIF。

预测CSV写入并哈希封存后才执行本轮标签评分。由于本数据源此前被检查过，流程隔离不等于盲测。共同支持为8,779小时、366个当地日；原始2024时间轴的5个类别不完整小时未填补。

强重组相对源火电因子锚的MAE差为−0.28 g/kWh；按当地日配对bootstrap的95%区间为[−0.76, 0.21]，不能支持水平误差改善。去日均形状误差仅改善1.96%。直接HGB的MAE低于重组约11.3%，但区间覆盖仍只有63.9%；其更短区间没有解决严重失覆盖。所有方法都明显低于90%名义覆盖，风险头从美国迁到该风电占比较高目标时失效。

月份差异明显：重组在1–6月MAE约75–128，7–11月升至112–200，11月覆盖仅42.98%，8月覆盖49.33%。这一分布与年度宏平均一样提示迁移模型的水平/尾部失配不能被平均掉；它不证明某个单一燃料机制是因果根源。

## 对四项研究重点的影响

1. **跨国小时实验：**固定US模型可直接接入丹麦合法结构形式的粗月输入，但其整体误差与覆盖远差于名义可靠水平；US↔GB两向结果不能当作普遍跨国能力。
2. **伪目标训练：中国信息条件：**一次额外国家压力测试不支持把源内强重组排序直接外推；下一步应优先用整国伪目标考察目标条件风险/回退，而不是继续增加模型复杂度。
3. **燃料内部关系：**重组没有在该高风样本上带来点误差增量，直接粗组成HGB较准但严重欠覆盖；没有证据证明可迁移的燃料内部小时运行机制成立。
4. **月报适配与可靠性：**本实验没有用目标域标签做月量适配；源校准区间覆盖不迁移，支持把月报时效、预测中心和目标域风险作为分开评测轴。

因此本轮是跨国基线失败边界证据，不是算法晋级。丹麦目标已被浏览且 hydro 处理为近似，所以不以其结果做后续模型调参或外部确认成绩。消费侧仍需独立的物理潮流、来源因子和核算分母，发电侧代理不为其背书。
