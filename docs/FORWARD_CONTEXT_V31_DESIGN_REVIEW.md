# V31 独立设计预审：固定模型的月初前瞻预算检验

2026-10-26，Sol。只读 `docs/FORWARD_CONTEXT_V31_DESIGN.md` 及已知 V30 合同与结果背景；未读取 V31 实际新数值、原始月表、小时数据或未知地区值，未拟合新模型。仅新增本设计审核。

**原则 APPROVE：去除当前组成 oracle 后，固定普通上下文模型做粗尺度前瞻点预测，是合理的下一问题。** 尚须正式协议和最终实现核对；本文件不证明任何 V31 效果或授予小时／未知地区实验权限。

## 与研究目标的关系

V30 的规模关联幅度大，但全部十四冻结资格 false、MISO 仍低估且规模敏感。V31 不应回改这些结论。六臂 G5／Trend／Size × Ridge／ET 是在已查看源开发之后选定的候选；2025 源数据亦已反复查看，因此它检验前瞻信息预算与冻结映射，不是完全盲时间确认或真正未知地区确认。即使成功，首先得到更强普通 baseline，而非原创机制。

## 正式协议必须明确的合同

1. **固定六个 head，而非训练到 2025。** 每 outer 从已封 V30 metadata 重建 G5／Trend／Size 两学习器，共 42 次相同训练集重拟合。原 training keys／顺序、rawX、y、weights、scaler、参数与环境均固定；排 outer 全部隐藏历史，不加入任何 2025 隐藏标签。Ridge 系数与原值、ET raw 预测应按预定公差复核。2025 可见历史更新只改变 query context，不能暗中更新全局 head。
2. **先固定全部 42 个预测起点。** 七源各 2025Jan1–Jun1，不能按标签是否存在或小时有效性挑起点。若合法 context 缺失或输入异常，应按预定统一规则 fail／记缺失，不能为不同族另换历史、另换样本。预测清单必须完整覆盖固定 grid；没有必要的输入就不得假称 42 个预测已全部生成。
3. **MG 粒子只按 origin 选取。** 原 V25 档案仅允许读取 `origins` 和 `MG_draws`，精确匹配唯一月初行及 128×5 有限 simplex 粒子，组顺序固定且六臂共享。不能用小时有效日 mask、实际当月组组成、实际总量或后验评分筛粒子／行。应固定父链和原 MG law 的前瞻来源，不仅因为数组名是 forecast 就认定无泄漏。
4. **逐 origin 读合法公开历史。** 沿 V30 最近三条的 metadata-first 规则，start<origin、end≤origin、release≤origin，再读取所选四 ZERO 份额与过去总量／日历小时；POS 用补集。查询年度的较早月份日后可依法成为过去上下文，但隐藏分项始终不作输入。明确 2024Jul 之后的公开历史属于本轮允许输入，不能误把 L24 训练标签窗口当作 query 历史上界，也不能用 2025Sep 评分截止替代各月 origin。
5. **保持粒子内物理配对与非线性。** 对每个 g 粒子分别建立特征、预测并投影 r4，再算 EF。内部 EF 点预测为 `mean(EF_s)`，完整月强度点预测为 `mean(g_POS_s * EF_s)`。不能先均值 g 再过 ET／投影，也不能用 `mean(g_POS) * mean(EF)`。后者会删除同一粒子的相关性，改变物理 estimand。
6. **primary 定义是完整月能源加权代理强度。** 用当月燃料能量份额乘固定 EF 得真实月代理，与预测的粒子内 POS×EF 对照；它不是等小时平均，不需要当月绝对总量作预测输入。EF 仅是 POS 内部 secondary；G5／POS 预测误差可帮助区分组预报与条件映射失配，但不能据此作无对照的因果归因。固定 EF 系数、单位、ratio 投影和点预测算式。
7. **zeroPOS 的两个目标应区别处理。** 合法标签当月 POS=0 时，完整月代理强度仍定义为 0，只有内部 EF 未定义。建议 primary 保留该月，secondary EF 标缺失，并保证每个指标在全部臂间共用 support、单列分母。若决定 primary 也只评正 POS，须在评分前明确此估计目标和排除代价；不能让 secondary 的定义域无声改变 primary。缺标签、截止未发布、非法标签与 zeroPOS 不能混为一种缺失。
8. **42 个预测全部封存后才评分标签。** `SCORE_CUTOFF=2025Sep1` 只决定 2025Jan–Jun 标签是否可在事后评分，不改变任何预测输入。标签缺失／延迟发布只能在 seal 后确定并记录，六臂完全相同。元数据异常、重复／多 vintage 与合法无标签须有不同处理，不能静默跳过数值错误。若某地区没有 primary 合格月，不得用少于七区的宏结果冒充七源评价。
9. **九对比较与规则固定。** 每学习器 Size−Trend、Size−G5、Trend−G5 共六对，加三个 family 的 ET−Ridge，共九对／63 个地区 contrast。宏 primary MAE 按先区内月均再七区等权；至少改善 5%、至少四区严格改善、无区超过参考 110%、MISO／ERCO 不恶化及近零参考条件均预先锁定。内部 EF 只诊断，不能挑更有利的目标决定资格。应明确这套规则对哪六个 feature 比较判信号，ET−Ridge 的模型对比是否仅报告 delta，避免评分后扩大成功搜索范围。

## 验证强度与解释边界

正式预审应使用合成毒值覆盖当前月／未来总量和份额、outer 隐藏分项、未发布历史、日期等号与缺月、label 缺失／zeroPOS，以及 MG 粒子配对。另用一个刻意相关的 POS／EF 合成例核对 `mean(product)` 与 `product(means)` 的差别，防止只有常量样本时两条错误路径也通过。

独立 actual auditor 应在闭包与完整 seal 通过后，独立检查父 MG 允许字段、42 个 origin、context／features、42 次相同模型重建、粒子物理乘积与全部 primary／secondary support 和九对评分。预测时不导入小时 helper；没有新的风险模型，就不把 128 粒子的散布当完整隐藏燃料或小时风险覆盖。

发布仍是代理，不能据此认证真实 vintage 或中国分类。规模可能代理边界／资产结构的疑问在去除 oracle 后依然存在；V31 若失败，也不能单独证明月表不可用。后续小时效率、专门风险机制与真正独立地区确认，仍需各自新合同与同预算强参考。
