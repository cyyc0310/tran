# V57 本地燃料细分约束的小时形状探针

日期：2026-10-27。探索用户可见的月度燃料分项能否改进小时预测中的水平以外部分。利用2025 H1来源校准和2026 H1时间前推评分，17区均为此前已打开开发区，结果不作独立确认。

## 冻结方法与基线

所有方法共享预测起点可得的目标区上一年同月月度燃料分项、固定11来源形状库、标签定义和日期。主候选将目标区月度各燃料MWh分别乘以源区同月、上一年逐燃料归一小时曲线，然后按固定 EF 逐小时重组 CIF；因此分项月能量严格保持已知目标月总量。对照一为相同目标五类粗总量和来源五类聚合形状、目标最新本地已发布 thermal EF；对照二为本地最新完整年度 thermal EF；对照三仅用 donor thermal EF。逐燃料 shape 对某个fuel只在有正发电源上等权平均，若整个来源池无该fuel的正发电数据，则采用均匀24小时轮廓，并记录该fallback。

源校准2025H1每个来源区预测时排除该区和外层目标区；外层预测为2026H1。区间分别比较 source-equal pooled q90 和 calibration source max q90。每区、每月同时输出有效标签小时数。不能删去主候选失败的燃料、区域或月份。

## 判读门槛

如果燃料细分重组只降低点误差，却在2026H1 pooled覆盖或最差区覆盖不足、或必须靠max q90显著扩宽，则结论仅是月度分项有点信息，不是小时风险突破。只有在相同分项月信息预算下，小时形状误差有可归因减少且 pooled覆盖90–95%、最差区≥85%，才考虑后续新年份或新地区确认。

标签是EIA固定因子正部已报告发电代理；这不等于中国统计口径、消费侧/全生命周期CIF或实际全电网排放。
