# 非负支持集区间投影：严格五类九国LOCO回溯诊断

日期：2026-11-01。此分析复用已评分的严格五类九国留一国预测，不重训模型、不更改点预测封存，也不构成独立确认。源预测及九国校准半径SHA-256在重算前逐项核验。目标标签为五类粗月输入合同下的固定因子发电代理，按构造非负。

## 诊断方法

对各模型预测中心`p`和源端绝对残差90%半径`r`，原区间为`[p-r,p+r]`。诊断版本与目标支持集`[0,+∞)`取交：中心`max(0,p)`，区间`[max(0,p-r), max(0,p+r)]`。逐国逐月重算MAE、日内去均值形状MAE、覆盖、平均宽度和90% Winkler区间分数，再对月份、国家等权汇总。区间下界截断在观测目标非负时不改变已观测包含事件；这不是分布无关保证。

**可靠性判断：**该规则在这批有非负标签支持的回测中，以不改变覆盖的方式移除了区间落在物理支持外的部分，能改善区间效率；但比例重组覆盖仍为85.24%，没有解决欠覆盖。投影不增加点预测技能，也不改变强基线排序。改进是支持集约束的后处理恒等性质，不应作为论文算法创新。更重要的是将它纳入严格五类LOCO和真实前瞻的区间基线，并在消费侧独立验证支持假设。
