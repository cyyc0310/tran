# V386：上海电力输入占比揭示本地月表与消费侧 CIF 的边界差

2026-10-31。协议：[V386](V386_SHANGHAI_CONSUMPTION_BOUNDARY_PROTOCOL.md)。可复现脚本：[v386_shanghai_consumption_boundary_audit.py](../scripts/v386_shanghai_consumption_boundary_audit.py)。计算摘要：`results/v386-shanghai-consumption-boundary-r1/summary.json`。

## 年度电量平衡

上海市经信委公布的2024年锚点为：全社会用电1984亿kWh、本市发电1085亿kWh、市外来电899亿kWh，三者严格闭合。由此，本地发电占用电量54.69%，市外来电占45.31%。同份报告公布本地新能源发电103.5亿kWh、可再生能源消纳量622亿kWh：前者为用电量5.22%、本地发电量9.54%；后者为用电量31.35%。两种统计量的差额为518.5亿kWh，**只表示统计口径和来源归属需要另行解释**，不能直接作为净进口绿电的精确值。

固定本地年平均CIF时，若只把进口电平均直接EF设为敏感性区间`[0,1000] g/kWh`，进口项对消费侧年均值贡献的区间宽度为`45.31%×1000 = 453.1 g/kWh`。这是条件算术，不是对上海进口EF的估计或置信区间。它说明在宽因子未知情况下，忽略市外电源可留下与典型电网均值同量级的不确定性。

2025年上海官方报道给出全社会用电2088.88亿kWh，并称市外来电占比“接近五成”；本轮不把该文字近似伪装成精确进口量。[上海市政府报道](https://www.shanghai.gov.cn/nw4411/20260804/677c49e0df6840c6ac82f01180902e2d.html) 2024年度平衡和可再生能源数据来自[上海市经信委报告](https://www.sheitc.sh.gov.cn/cyfz/20250522/85542effedb547708e2cd04221c5a80a.html)。

## 对 TransCIF 研究的含义

V108定义的是**本地发电侧**小时平均强度和阈值小时数，并明确排除进口/输电约束。用户NBS月表能进入这个任务的低频本地类别信息，但不能自动迁移到上海官方年度公共电网平均因子、剩余组合因子或消费侧小时CIF。若论文要预测后者，最低信息合同必须加入同口径的市外/省际输入电量、来源省或来源区域强度、逐时碳流与损耗/绿电属性；仅有年度进口量只能约束年均总量，不能识别小时尾部。

这给论文更清晰的双轨主张：

1. **Generation-based track：** 月度本地技术边际、容量/统计范围、小时强度与风险识别，适用V108定义。
2. **Consumption/network-flow track：** 本地发电加逐时输入碳流及消费分母；月表本地组成只能作为一部分输入，数据不足时应拒答或报告宽界。

上海官方2024年公共电网平均因子为0.4701 kgCO₂/kWh（见V362数据），它是消费边界年标签，不是V385本地发电侧小时K的真值。区分这两轨能避免把边界错误误判为算法误差，也让“最小本地信息”问题落到可测字段上。

## 科研判断

本轮得到的是**问题定义与信息预算的实证修正**，不是新预测算法。更可信的原创方向是建立双estimand、双信息账本的跨区冷启动基准，并在公开小时发电侧代理上验证识别/覆盖机制；消费侧只在有流向与小时碳强度标签时评分。南方电网2026年发布的广西15分钟、地市级可溯源数据库是潜在验证渠道，但公开报道未提供可下载样本，不能当作已经取得的标签。[数据库发布报道](https://www.chinapower.org.cn/index.php/detail/459342.html)
