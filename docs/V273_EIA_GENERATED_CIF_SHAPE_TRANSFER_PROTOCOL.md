# V273：EIA 官方 BA 小时标签上的跨区形状迁移协议

冻结日期：2026-10-30。目的：检验现有跨区时间形状方法能否从固定因子生成 proxy 迁移到 EIA 官方发布的 BA 级小时生成侧 CIF 估算标签。该实验只评估“目标月平均 CIF 已知后”的小时形状与区间迁移，不能代表中国低频信息冷启动的端到端表现。

## 数据和冻结拆分

- 数据：EIA Hourly Electric Grid Monitor 单 BA Excel 工作簿；目标队列固定为 `BANC, BPAT, CISO, ERCO, FPL, MISO, NYIS`。文件取自 `https://www.eia.gov/electricity/gridmonitor/knownissues/xls/{BA}.xlsx`，下载时间2026-10-30。
- 目标小时标签：`CO2 Emissions Intensity for Generated Electricity`，单位 lbs/kWh，转换到 g/kWh 时乘 453.59237。单位由各工作簿 `Notes` 页核对。只用正发电的有效小时；时序槽用当地日期及小时结束值。EIA 标签基于年度 BA 燃料因子与申报小时燃料发电，并非逐小时 CEMS 标签。
- 训练时间段：2019–2023；风险校准时间段：2024；只评分时间段：2025。EIA 官方历史值会修订且无冻结发布 vintage，故这是**最终修订版回顾性验证**，不是严格 as-of 实时预测。
- 外层区域拆分：逐BA留一。目标BA的任意年份小时标签不得进入其源形状估计；用于校准的源BA也用逐BA留一预测生成校准分数。
- 低频锚：每个目标BA-month的真实小时 CIF 以正发电加权均值。它是目标月标签导出的 oracle 锚，用来只检验小时形状传递，不作为部署可用特征。

## 冻结比较方法

1. **Monthly anchor**：月内每小时预测为目标月加权平均 CIF，不加入时间形状。
2. **Donor hour-of-day**：用2019–2023其余BA的源区内月平均小时残差，估计同日历月×当地小时的供体形状；源区等权聚合，叠加到目标月 oracle 锚。
3. **Donor hour-of-week**：在方法2上细分当地星期几，按同月×星期×小时估计形状；源区等权聚合，叠加到相同目标锚。

形状残差均相对源BA自己的同期月加权均值计算，避免迁移绝对水平。未使用目标区小时燃料、目标天气或目标历史小时CIF。

## 风险校准与指标

- 对每种方法，在2024每个源BA上使用其余源BA训练的2019–2023形状；以预测日内24小时的最大绝对残差为分数，取有限样本90%分位数作为日同时区间半宽。对每个2025目标BA，校准分数再排除该目标BA自身的2024记录；因此目标BA任何年份记录均不参与其供体形状或风险半宽。未将2025分数用于选分位数。
- 2025按BA报告小时MAE/RMSE、小时区间覆盖、24小时整日同时覆盖、区间宽度和日级 Winkler-90；先给各BA独立结果，再报告BA等权宏平均。只把具有完整24个本地小时且标签/预测齐全的日纳入整日覆盖。
- 主对比是 hour-of-week 对 monthly anchor 的配对改善，以及在覆盖接近90%时区间是否变窄。若 donor shape 降低点误差但来源校准覆盖显著欠90%，不能称可信区间增益。
- 仅七个BA，区域级统计量不作大样本显著性宣称；展示每区异质性及全区均值。不得打开任何其他未纳入本实验的候选未见BA作为确认集。

## 成功解释边界

若跨区形状方法在2025多数BA保留覆盖并降低区间宽度/评分，可说明“目标月平均已知后，小时形状在EIA估算标签上存在可迁移信息”。它仍不能证明月度分燃料发电统计足以恢复目标均值，不能证明真实中国生成/消费侧因子、目标EF校准或中国小时CIF预测能力。若失败，则说明现有时间形状传递在官方 BA 标签中也不稳定，应优先研究目标侧最低因子/小时测量预算。
