# UK→US Lower 48真实发布月报双轨迁移协议

日期：2026-11-01。此实验验证跨国冷启动基准在真实月报发布时间下是否可运行，并分别评分发电侧与消费侧端点。它是单一目标年份的开发性诊断，不是新国家盲测，也不预设模型增益。

## 目标和两条轨道

- **发电侧主目标：**EIA-930官方“generated electricity”小时碳强度。它是EIA基于平衡区燃料报告与排放因子估算的运行标签，不是直接测量值。源GB现有小时监督仍为项目固定因子发电代理，因此此轮属于跨系统标签口径压力测试；不将模型分数与更改标签后的其他队列混排。
- **消费侧独立端点：**EIA-930官方“consumed electricity”碳强度。它包含跨区输入和来源排放核算，不能用发电侧标签代替。当前英国源训练标签不是同一官方消费侧方法，因此此端点只作为跨口径外部压力测试，不宣称是严格同目标监督迁移；后续需建立英国消费侧标签合同。
- EIA工作簿按Lower48地区输出，但其注释指出BA报告数据聚合存在报告覆盖限制；目标标签的排放因子及消费侧分配是EIA估计值，不称为独立实测真值。目标工作簿是本轮下载时的当前发布快照，不恢复2024每小时标签的历史as-issued版本。

## 预测时信息预算

- 源：英国小时发电量，2022训练、2023校准。训练/校准输入以`t−3`月模拟目标通常可用的最新统计年龄。
- 目标：美国EPM历史归档实际发布版，按每个目标月首日UTC之前的最新`Last-Modified`归档决定可见信息；从EPM的美国总计行合成火、水、核、风、光。EIA的部分州/分区燃料行会以`NM`标记大相对标准误，本轮不将其填零或当成可观测值。美国总计包含阿拉斯加和夏威夷，而小时目标是Lower 48；它作为明确标注的邻近地域代理，不能当成精确同域输入。不能假定固定滞后，记录实际统计月和发布日。
- 目标小时时间戳仅从EIA工作簿A:F列读取；预测封存阶段不读取G:BA的目标结果字段。
- EPM是全美国公用事业发电月统计，EIA-930为BA报告汇总，两者发电设施/覆盖范围不完全一致。先输出同月全区五类结构差异和总量差，明确其对预测的支持边界。

## 基线与评分

固定比较700热电锚、源热电有效因子锚、日历Ridge、五类Ridge、五类HGB、小时形状重组。风险区间仅用GB 2023源校准，作为迁移诊断，不称覆盖保证。分别对EIA官方发电强度和消费强度报告点误差与区间覆盖/宽度/区间分数；同一端点只在其定义可比时排名。输出月份、时间段和最差季节分层结果。EIA工作簿燃料分项中存在空白、负数和非物理来源细项，故不从这些列另造发电侧固定EF“真值”。

## 防泄漏与限制

先生成仅含预测输入、预测和校准风险的`predictions_sealed.csv`并写SHA-256；再次显式运行`--score`才读取工作簿标签列。归档发布日期可由HTTP头核对，但当前EPM归档本身会修订历史值；它们是可追溯归档快照，并非每个月首日的逐值不可变数据库。结果仅支持“实际发布滞后信息回测”，不能支持中国效果或未查看国家确认。

本实验为探索性协议，尚未对2024目标标签解封，亦未进行预注册。
