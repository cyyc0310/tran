# 九国年度装机增量：火电因子头小幅改善，整体未形成稳健增量

**口径更正（2026-11-01）：**本结果继承六组粗月输入，含`other_renewable`；不是严格中国五类信息预算。严格五类增量见[CN5容量结果](ENERGY_CHARTS_NINE_COUNTRY_CN5_CAPACITY_RESULTS_20261101.md)。

2026-11-01。按[冻结协议](ENERGY_CHARTS_NINE_COUNTRY_CAPACITY_PROTOCOL_20261101.md)，在九国LOCO相同目标小时、训练/校准划分和五类滞后月发电量预算上，单列增加年度热电装机占比`CF/TOTAL`。容量采用两年滞后：2020→2022训练、2021→2023H1校准、2022→2024预测。Eurostat数据是当前修订值，不是历史as-issued版本，因此是信息预算滞后模拟。标签仍是固定因子发电侧代理，不是实测CIF。

容量火电因子头相对原因子头平均改善0.872 g/kWh MAE（约1.4%），区间宽度减少1.675，区间分数改善16.30；但小时覆盖也从77.1%降到77.0%。它与强比例重组的MAE几乎相同（差0.008），却覆盖低8.3个百分点、区间分数更差。容量没有解决欠覆盖，也没有带来超过强重组的综合收益。anchor700达到90.6%覆盖，仍以显著更宽的区间为代价。

九个目标国的容量因子MAE变化为：AT −0.18、BE −0.15、CZ −12.93、ES −0.01、HU −1.26、NL +7.65、SE +0.01、SI −0.75、SK −0.24 g/kWh。平均增量主要由CZ驱动，NL出现明显反向变化；国家数很少，不能据此推断总体效果。

## 研究判断

当前证据不支持把“增加年度总热电装机”作为独立算法创新。它可作为中国场景下低成本辅助预算保留在基准中，但主方法仍应以五类月发电量条件下的跨域学习和风险评估为核心。若后续取到逐省发布版容量快照，可检验前向可见性；在此之前不应声称历史真实可得。
