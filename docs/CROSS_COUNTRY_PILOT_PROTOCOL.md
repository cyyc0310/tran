# 美英小时冷启动开发协议

2026-10-31，第一次运行前写入。不是未知国家确认；双方都已有其他任务的开发记录。

固定US七区与GB为两个国家组。源2022训练、2023校准，目标2024评分；目标国的任何小时标签不用于拟合、选型或校准。两个方向全部预测写盘并哈希封存后才评分。无超参搜索。预测起点按日理解，使用当地/源日历预测全天24槽；DST或缺测日的形状评分仅作可用小时内去均值诊断。没有目标日内更新输入。

目标输入仅日历及精确t−2月火/水/核/风/光份额。月量从小时记录生成，覆盖至少99%；既非官方月报也非as-published档案，属于中国发布时滞条件的模拟。源端也使用同样粗输入。不可称已认证的实时历史回放。目标当月发电量、燃料份额和CIF均不可见。没有天气输入。中国NBS规上统计与源全口径范围差异尚未解决。

EIA使用UTC记录转各区当地日历；GB使用来源naive时钟，不凭空赋予时区。GB两条唯一半小时MW均值等于该小时MWh。进口和储能不进入本地发电代理。煤/气/油/other固定EF为1000/400/800/400，核水风光为0，单位g/kWh；GB biomass与other并组，oil为0。此为透明共同代理，other异质性是重要限制，不等于真实排放或官方CIF。粗火电组包含所有四种可燃来源，是本轮映射假设。

六个固定参考：700×滞后火电份额；源端学习火电有效EF×份额；仅日历Ridge；粗月报及小时交互Ridge；同输入HistGradientBoosting；按源各粗类平均小时轮廓和源有效EF重组。最后一个是中国粗预算重组参考，不宣称精确复现详细燃料native。Ridge alpha=10；boosting100轮、15叶、最小叶100、L2=10，seed412。源训练按区域等权；模型不使用国家ID。

每方法另用源2023残差的等区域混合均值和标准差构造固定Gaussian分布，所有方法均含这项源偏差修正；报告修正后的MAE/CRPS、90%覆盖/宽度/区间分数以及去日均形状MAE。分布为普通强度参考，不是条件异方差SOTA或覆盖保证。无裁剪Gaussian尾，以免改变概率评分定义。目标小时数和地区分开报告，英国一个电网与美国七个区域不能当作八个独立国家。

本轮只回答第1项的可运行性和基线表现，不依此声称创新成立。后续先审查源支持、核算差异与水平/形状误差，再在源内开发新机制；不能直接依据2024目标成绩调参后仍称本轮确认。
