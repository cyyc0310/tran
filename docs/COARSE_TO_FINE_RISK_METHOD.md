# 粗尺度回测误差向小时风险迁移：方法命题与边界

2026-10-23，Sol。本文记录正在检验的研究假设，结果另见实验报告；不预告方法成功。

## 真正可利用的反馈

在没有目标小时CIF的地区，目标已发布的过去月度燃料统计仍提供一种监督：在同样的信息延迟下，过去的粗月强度到底有多难预测。把每个历史月的中点当作过去的预测时点，严格重建那时可见的统计前缀，再与目前已经发布的该月粗强度比较，得到无目标小时标签的历史粗预测误差。

这与月度强度本身的波动不同。强烈且重复的季节振幅可以有小的季节预测误差；平滑序列也可能突然发生不可预测的结构变化。因此，“波动大”并不充分推出“预测区间必须宽”。相同发布算子下的回测误差是待验证的风险信号，不是未来误差界。

使用目标已发布历史粗标签属于弱/聚合监督，不能写成完全无目标信息或完全无标签适配。过去完整月与未来某一天并非同一预测对象；统计年龄一致也不自动确保误差分布相同。

## 偏差、水平创新与形状

记固定点预测为m(t,h)，源小时残差拆为

\[
 e^L=\frac1{24}\sum_h(Y_h-m_h),\qquad e^S_h=Y_h-m_h-e^L.
\]

合法粗回测特征记为x(t)：signed误差、中心化波动、原始月度变化、年龄和有效支持数。源proper样本拟合位置修正b(x)及水平/形状尺度a(x)、s(x)。独立源bank再标准化为

\[
 u_i=(e_i^L-b(x_i))/a(x_i),\qquad v_{ih}=e^S_{ih}/s(x_i).
\]

以等源地区、地区内等日的概率联合抽同一i，生成

\[
 \widetilde Y_{th}=m(t,h)+b(x_t)+\gamma\{a(x_t)u_i+s(x_t)v_{ih}\}.
\]

需要校正方向性偏差时，增加b比无差别增加方差更直接；但跨域偏差映射也可能错误，必须检验。标量s保持形状零均值；最终非线性边界投影会改变均值和形状，不能把投影前性质冒充最终物理保证。同日抽样保留经验配对依赖，不验证目标真实路径相关性。

候选结构使用非负方差回归区分原模型分量风险和粗回测创新，不把原季节振幅必然作为风险下界。通用线性异方差与ExtraTrees获得相同全部特征及原分量尺度；CQR获得相同历史信息。只有超过这些对照并通过粗回测消融，才可能说明特定机制有增量。

## 与直接先例的差别

| 直接文献 | 已有贡献 | 本任务仍需解决的差异 |
| --- | --- | --- |
| [Romano等，CQR，NeurIPS2019](https://papers.nips.cc/paper/8613-conformalized-quantile-regression.pdf) | 条件分位与独立校准，适应异方差 | 不能将通用输入条件区间重新命名创新；未知域和小时依赖不自动满足其保证前提 |
| [Kasa等，ECP/EACP，UAI2025](https://proceedings.mlr.press/v286/kasa25a.html) | 无目标标签下通过模型不确定性适配预测集合 | 我们有合法历史粗监督，但没有目标小时监督；需要说明这类额外反馈如何作用于目标小时分量，而非泛称无标签适配 |
| [Xu等，WR-CP，ICLR2025](https://proceedings.iclr.cc/paper_files/paper/2025/file/283066055b0256ca8e3e0c8c96019357-Paper-Conference.pdf) | 分布偏移、覆盖缺口与多源正则 | 跨域风险控制已有先例；本实现未复现其完整算法，也不继承一般偏移保证 |
| [Cauchois等，JMLR2024](https://www.jmlr.org/papers/v25/23-0253.html) | 弱监督下的预测集合及相应弱覆盖定义 | 粗标签覆盖与完整小时路径覆盖是不同命题；不能从粗约束相容推出强小时覆盖 |
| [Girolimetto等，IJF2024](https://fpp.robjhyndman.com/publications/ctprob.html) | 跨时空概率协调，用多步残差改善误差协方差估计 | 多步回测误差本身已有先例；我们须解决未来细尺度不可见、发布延迟与不同核算权重下的风险迁移，不能仅靠改名 |

本文没有证明此前无人研究类似组合，也没有将已有回归器、残差重采样或分量分解作为独立首创。文献区分只说明一个值得检验的窄问题，不等于排重完成。

与直接CIF研究也要区分信息条件：[WWW2026 DGCFM](https://wangdan.people.ust.hk/Publication/WWW26-CIF.pdf)已研究跨地区、低数据和zero-data训练设置；正文§3.2、§4仍将历史CIF和电力交换列作输入，推理描述使用历史CIF。其训练排除目标不等于本文目标逐时输入完全不可见；需要核对实际输入/代码后才能作同信息适配，不能直接比较其公布百分比。[AAAI2026多频CIF](https://arxiv.org/html/2601.06530v1)使用历史CIF、负荷、发电和温度的小时序列建模。本文当前强对照是相同有限信息下的概率后处理与三种点模型，不是已完整复现所有最新CIF架构。统一基准或论文完整评测仍需要更多同信息适配、跨国数据和任务用途验证。

## 可能形成论文贡献的门槛

1. **可用反馈的形式化。** 明确发布支持、历史粗回测与未来小时目标之间的不同算子；说明哪些风险由粗反馈可观测，哪些不可观测。
2. **可证伪的迁移机制。** 候选相对同信息通用异方差/CQR及相同结构去粗回测消融，在维持覆盖时有实质宽度或proper-score收益。额外源年份、不同目标地区或只提高覆盖不算机制证据。
3. **失效边界。** 同粗信息而不同小时形状的反例、统计冷启动、结构突变、偏差反向迁移、EF与聚合权重误差；粗回测好时也不能自动缩小不可观测形状风险。
4. **独立实证。** 新地区与独立时间，源端选择冻结，负结果保留；中国或仅年度统计仍需对应数据和验证，不能由美国月度代理代替。

如果通用ExtraTrees或CQR同样好，这一方向可能主要贡献为信息协议与可复用的经验认识，尚不足以构成独立算法论文。若有稳定增量，则应进一步解释其来自可观测分量、方向性偏差还是尾部风险，而非只展示总体平均。
