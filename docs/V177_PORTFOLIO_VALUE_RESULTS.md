最佳新候选是没有求和的普通selected-parent控制：对原Gaussian CRPS改善0.334%，宽−0.463%，19/29地区更好，地区配对差值−0.1017、描述范围[−0.2943,0.0794]。最差覆盖仍65.48%；对标量森林只改善4.524%，比V174最佳PIT还差1.608%。这是普通选样/重权的小收益，不能记到聚合机制。

条件同步相对原条件活动CRPS改善2.838%、宽−3.404%，但比Gaussian差4.872%、比标量森林差0.463%。更关键的是，它相对置换1/2只有0.0102%/0.0082%的CRPS差，地区描述范围均跨0；不能将相对旧条件法的收益归给同步关系。

Gaussian同步相对原Gaussian只改善0.0064%，宽−1.605%、宏覆盖反降约0.40pp。相对置换1/2分别改善0.0232%/0.0227%，18/29和17/29地区更好；配对差值−0.00704/−0.00691的描述范围位于负侧，但幅度极小，且这些是反复开发后的描述比较，不是选择修正后的独立检验。相对同矩父混合只改善0.240%、范围跨0；相对selected-parent反而更差。没有理由据此开发复杂相关模型或主张新算法。

## 固定半径并不等于没有扩宽

条件父混合有三个版本达到覆盖双条件，最差均86.23%：固定pooled宽270.88，固定max_region宽325.90，自身max_region宽284.46。CRPS均33.016，已差于原Gaussian、标量和异方差强参考。固定pooled相对原条件pooled宽204.06增加约32.7%；law自身更宽，即使校准半径未改，也不能称“没有靠扩宽提高覆盖”。

同矩父混合与同步/置换的逐时钟燃料一阶矩一致，但CIF law不同。同步相对条件父混合宽度低26.53%，最差覆盖却从84.59%降至70.12%；Gaussian中宽度低25.37%，最差从72.35%降到64.93%。这检验了一阶矩之外的风险分配，但没有解决覆盖与效率的冲突。

24个非固定EF地区中，Gaussian同步CRPS36.647、宏覆盖88.17%、最差64.93%、宽198.39；原Gaussian36.716、88.66%、63.64%、203.21。selected-parent为36.597、88.66%、65.48%、202.41。该子集同样未达标，不能靠全29地区宏平均解释成成功。PACE/LGEE/SC未在本轮重新评价。

## 构造和审计

只在原proper采样交集内构造5,338个完整UTC/同月合法输入的二源组合月。两个置换种子均按小时×周末标记联合移动父b的整行燃料，不扩大唯一小时预算。源world和query混合后的同步/置换/父混合逐24状态燃料均值预检误差分别6.65×10⁻¹⁶、5.39×10⁻¹⁶；原g/M同时乘2/4活动误差为0。比例控制仅验证表示不变性，本轮没有训练从月总量推断实际机组数/聚合度的模型。

全量审计重建5,338个源world、5,784条query记录、所有校准及12,532评分。独立set交集/直接燃料/联合置换/概率公式检查640,560个源单元，最大相对差5.58×10⁻¹⁶；独立query权重/燃料矩误差1.57×10⁻¹⁵。138,816个新增预测物理单元检查及115,680次原half支持/质量保留检查通过，原964参考复现，12未发布统计干预通过，评分最大差3.64×10⁻¹²。源组合与外折重复不是独立样本；1,216比较是1056强参考、80全月库、64同步结构和16父context比较，不称独立实验。

正式world权重/燃料矩记录沿用runner文件名`recalibration_maps.csv`，字段实际为组合身份、概率与预测燃料均值，不是PIT映射；本轮没有使用V174/V175再校准算法。预测和评分重建共享冻结辅助函数，独立源/权重公式有上述单独范围。

## 论文判断与下一步

[聚合增强](https://www.nature.com/articles/s41598-021-93545-6)和[共同风电相关研究](https://journals.aps.org/prxenergy/abstract/10.1103/vms3-ng8z)已有先例；同步求和、置换或普通经验混合本身不是原创。本轮既未证明实际目标聚合度可从月量识别，也没有足够的同步增量。不把源组合换名成新机制，不打开未查看地区。

下一项先补齐同一合同中的联合粗燃料分布强对照：旧方法已有八维过去组成核和点组成预测，但当前粗不确定性的四类law仍通过一维EF锚投影到世界。联合粗预测是否能保留同EF燃料之间的风险差异，尚未在该固定世界库中直接比较；不是首次联合预测或已证明的新机会。待实现设计见[V178](V178_JOINT_COARSE_WORLD_DESIGN.md)，目前无实现/评分。

固定EF非负生产侧proxy、共享2024源开发、合成发布日、canonical有效小时metadata、中国实表/发布版本未核验等限制不变。虚拟父源并非已核验的真实地理合并，没有新增独立地区、真实排放验证或目标覆盖保证。目标active，尚无足够论文创新证据。
