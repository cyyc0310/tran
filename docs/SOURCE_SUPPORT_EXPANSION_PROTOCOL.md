# 源支持扩展对照：无核电供体与同数量控制

2026-10-31，拟合前固定。目标信息预算不增加，仍为已有三国2023H2开发评价。原7个美国源区在2022均有核电；Shanghai的核电为0且热电高于现有支持。选择PACE/LGEE两源扩大零核电/高火电支持，SRP/DUK作为两个有核电源控制。类型依据源2022发电记录，不依据本轮目标CIF评分；AZPS经预检未报告核电，不作为有核控制。

原7源/加PACE-LGEE/加SRP-DUK三种策略共享三国合同、模型、目标和时间切分。额外源只参与训练和源校准，不改变US目标的原7区名单。对四个追加供体，分别在2022训练和2023H1校准中按历月取最少可用小时数；各追加区域均按同月相同数量、等距时间取样。所有公开月特征先用完整合法月表构建，之后再抽训练/校准响应。基底7区不抽样。两追加策略的国内区域数、训练与校准标签数相同，来源本身不同。

8方法、9配置、目标2023H2队列、国家→区域权重均不变；源不含US的配置须与原版数值相同。报告点误差和覆盖效率，以及Chinese输入支持是否覆盖；不加入煤气装机，不使用中国小时真值。
