# V179：固定概率下的粗支持语义诊断

2026-10-29，Sol。V178完整源开发评分已查看后提出，属于事后诊断，不是预注册确认。V178实现遵循其冻结协议，但精确含义是“用粗响应指导供体世界核”；不是把ΔS联合预测直接平移到查询基点。不能由其失败推断所有联合粗预测都无价值。

最小反例：供体前后都只有气电，ΔS=0；查询过去煤.8/气.2。V178乘性支持normalize(B_query*S_source_current/B_source_past)仍为气1/煤0；普通加性ΔS=0预测应保留查询煤.8/气.2。这与V166/V167已分析的源燃料缺失/未知响应有关，不当作首次发现。这里只检验新世界核如何放大或缓和该语义差异。

## 固定诊断

不重新拟合十个世界森林、不改已保存概率、不构造新小时law或半径、不读取小时generation或时间戳、不打开新地区/2025。只用V178测试query的已保存source profiles/weights、相同MonthlyInformation及原proper粗模型点组成参考。新粗支持固定为欧氏simplex投影：

`v_d=argmin_{v≥0,sum v=1} ||v−(S_query_past+ΔS_source_d)||²`。

ΔS分量按V178的64eps规则置数值零。排序阈值法求投影；只将输出≤64eps的坐标清理为0，再在sum数值误差≤1e−12时归一，防止浮点误差给本应为零的燃料添加微小伪质量并破坏月零事件评分。该清理须保持投影可行/KKT误差≤1e−12，不用clip再归一替代欧氏投影。先为query的14个方法构造全部支持，再读取相应粗标签评分。持平/旧点组成两参考保持原值，复现其原评分。

新变体统一加`increment_`前缀，沿用V178辅助指标：16粗方法×241=3856记录及30848燃料记录，月份等权再地区等权。与相同权重的原乘性支持配对，也与原未改变的Gaussian/全月Gaussian及点组成比较。原Gaussian权重是为乘性支持得到的，因此它的increment变体仅是反事实对照，不称公平最优重训Gaussian。

额外记录可预测分层：query过去某燃料为正，而source过去和当前该燃料月量都为零的query份额加权质量，以及源ΔS全为零但出现上述缺口的世界概率。它是源月统计/迁移支持代理，不等于实际容量缺失、小时零概率或因果误差贡献。不得以query真实当前正量筛选该代理。

## 检查与解释

独立toy核对零增量保持query、simplex欧氏投影可行/KKT、和clip-renorm不同的例子；不按真实测试分数改规则。检验源父角色/年份/合法输入及保存概率、实际构造只用query已发布prefix；投影中当前queryM扰动不影响支持。原两点参考评分应复现，所有新指标有限且支持在simplex内。独立重建支持、能量/边际评分和汇总的范围需明确。

这个诊断同时改变可达粗组成、零质量及支持，不唯一归因权重学习，也不证明新的小时CIF增量。即使粗层显著改善，下一步仍须将完整联合粗law正确传入小时生成器，与普通多元协调/投影强对照比较，原小时gate不变；不直接晋级未查看地区。普通加性动态、simplex投影、QRF和概率协调不是原创。

固定EF生产侧proxy、共享2024开发、合成发布日、canonical有效小时月量/短历史、中国实际月报未核验等限制保留。若粗支持修正也没有稳定价值，转向信息与数据合同，不继续换算法名称。
