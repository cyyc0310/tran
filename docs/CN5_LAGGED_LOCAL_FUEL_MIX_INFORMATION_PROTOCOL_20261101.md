# CN5欠覆盖的滞后本地热电燃料构成信息价值协议

冻结：2026-11-01，脚本运行前。最近的CZ/SI诊断显示，强比例重组点误差主要来自目标热电有效因子与源平均因子不匹配，而不是五类热电份额均值误差。本轮只测试一个更具体的最小信息候选：**本地可得的上一年热电内部燃料发电量**能否校正迁移的热电强度水平，并在同一小时结构下改善误差和经验区间。

## 外层和数据合同

- 外层逐国留出AT、BE、CZ、ES、HU、NL、SE、SI、SK，2022小时监督训练，2023H2做跨国伪目标残差校准，2024评分。所有目标/标签此前已用于研究开发，因此是信息价值回放，不是盲测确认。
- `M`基线：目标只见严格CN5滞后月度发电组成，中心为跨国比例重组。
- `M+Fprev`：保持M的小时形状、月组成和所有训练流程完全不变，只将源模型平均热电有效因子替换成目标国上一年燃煤、燃气、燃油及其他常规火电发电量按同一固定EF计算的年均热电因子。预测2024用2023年燃料构成；预测伪目标2023用2022年构成。Fprev是额外的目标侧年度燃料细分信息预算，不是CN5基准输入，也不是容量数据。
- 年度燃料构成取自Energy-Charts修订小时序列按年汇总，未核验历史as-issued发布日期；该附加预算只检验“若有年度内部燃料电量”时的预测价值上限，不能称中国当前官方NBS字段可用。
- 标签仍是固定EF生成侧小时代理；不得将结果解释为消费侧强度。

## 拟合、校准和评分

1. 每外层折中仅用其他国家2022小时标签拟合强比例重组及小时模板。
2. 源伪目标`C`的2023H2校准预测由排除外层目标和`C`后的源模型生成；`M+Fprev`只读取`C`在2022年按燃料汇总得到的因子。
3. 对M与M+Fprev分别用同一组伪目标和同一加权规则计算90%经验绝对残差半径；不得把M半径直接套给已改变中心的M+Fprev。
4. 所有2024目标点和区间先封存哈希，再读取目标标签。报告逐国、逐月MAE、日内形状MAE、偏差、覆盖、宽度和Winkler；宏先月等权再国等权。
5. 与已有年度装机M+C结果并列解释。装机是名义供给能力，Fprev是已实现年度发电燃料构成，二者不能混成同一预算。

## 结果判断门槛

只有M+Fprev相对M在整体MAE有至少5%改善，形状不恶化，宏覆盖下降不超过2个百分点且区间分数改善，并且CZ/SI至少一个欠覆盖域显著修复、另一个不恶化超过10个百分点，才考虑把它作为有希望的信息价值机制进入后续源内伪目标复核。否则仅报告为解释性/数据价值结果，不做方法晋级。即便通过，也仍需真实可见版本审计和未见国家确认。

## 假设边界

本试验将目标上一年燃料构成压缩成一个有效热电因子，所以不会向目标模型暴露小时燃料标签或当前目标年份因子。它检验的是低频水平校正，不假设该因子可识别小时尾风险；任何区间变化须按独立伪目标残差重新校准。目标国、目标年和预测标签均已打开，不能把结果称为外部验证。
