# 目标条件伪目标源筛选：严格CN5开发结果

日期：2026-11-01。按[冻结协议](ENERGY_CHARTS_TARGET_CONDITIONED_SOURCE_DROP_CN5_PROTOCOL_20261101.md)完成严格五类九国留一开发回测。问题是：用与目标月CN5组成相似的源伪目标，估计哪些来源国引起负迁移，能否优于跨伪目标平均筛源？脚本为[run_energy_charts_target_conditioned_source_drop_cn5.py](../scripts/run_energy_charts_target_conditioned_source_drop_cn5.py)，封存预测、半径和指标见[证据包](evidence/energy-charts-target-conditioned-source-drop-cn5-r1/README.md)。

## 设置

按国留一；用2022小时响应拟合。H1源伪目标估计候选来源边际效应；按每个外层目标月只用可见的`t−2…t−7`五类粗份额挑选CN5组成最近的3个伪目标；只有预测结果支持时才剔除1个来源。对照是全源比例重组、无条件源筛除和anchor700。2023H2逐国交叉拟合区间校准，2024目标预测先封存再评分。所有方法使用同一个五类预算及H2校准队列。

响应仍是修订小时序列导出的固定因子**发电侧代理**，不是实测CIF；月统计是小时回算滞后模拟，非历史as-issued版本。九国全是已查看开发域，不是最终盲区确认。

## 九国宏平均

单位gCO₂/kWh，先国内按月等权，再对九国等权。经验覆盖是小时池化值，不是新国家保证。

目标条件法相对无条件筛源只降低0.29 MAE、缩窄2.5%区间宽度；覆盖又降0.33个百分点，区间分数虽改善5.64，仍比全源重组差15.74。相对全源重组，MAE改善1.7%，但区间宽度缩窄3.2%的同时覆盖下降1.4个百分点、区间分数变差2.9%。形状误差几乎不变。它没有达到“保持覆盖并改善区间效率”的门槛。

## 来源条件化是否改变了选择

12×9个目标国—月份选择中，八个外层目标的12个月都继续剔除CZ；CZ外层目标有10个月剔除NL、2个月剔除BE。也就是说，按近邻伪目标条件化后，108个国—月里仅有两个选择与该折的无条件选择不同，整体几乎复制了旧的无条件规则。

CZ目标条件法相对无条件筛源略有改善：MAE由172.80降到170.18，但仍差于全源比例重组的163.34；覆盖维持约33%，没有风险修复。SI的MAE保持129.05，覆盖从70.0%降至68.0%，区间分数从631.82升至666.28。NL点误差维持72.75、覆盖约99%。最差域结果没有显示条件选择捕捉了目标特异风险。

## 研究判断

本轮是对“目标粗组成能否预测源贡献异质性”的直接检验。预设最近3个伪目标的条件贡献规则只在极少数国月改变选择，整体收益很小且覆盖/区间分数未超过全源重组。**停止CN5相似度条件筛源及近邻数扫描**；不把该方法称为论文创新，也不进入未查看地区确认。

更重要的是，伪目标任务的输入近似并未提供足够信号来识别可迁移的源贡献。后续算法若继续，应改变可观测机制（例如可解释的运行状态/有效燃料响应），不能只对既有国家级组成向量再套门控。发电与消费两轨仍须分开；此结果只涉及发电代理。
