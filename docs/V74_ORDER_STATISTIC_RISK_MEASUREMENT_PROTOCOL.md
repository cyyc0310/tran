# V74：同四标量预算下按风险目标选择G次序统计量

冻结日期：2026-10-28。V20解析结果显示K计数的特定认证由G的次序统计量驱动：min(G)约束K=0；S₂（两个最小G之和）可约束块内K≤1；L₁（最大G）可支持块内K≥2的反证。V73在固定1000源日发现minG增益集中于BPAT。本轮将四个6小时块的四标量信息包分别配置为minG、S₂、L₁，按预设目标事件强度作同预算认证，并同V20 ΣG²外界及完整G锐界比较。

## 冻结样本与三种定向决策

继承V20七个已开发来源区BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS在2024H2的1000完整UTC日；固定EF支持[0,1000]、严格事件C>τ、阈值100/300/600/900。每种信息包在四个6h块各发布一个G-only标量（共4标量）：

1. `minG`：若每块H≤τ min(G)，认证整日K=0。
2. `S2`：若每块H≤τ S₂（两小时最小G之和），则每块K≤1，认证整日K≤4。
3. `L1`：若每块H>τG_total+(1000−τ)L₁，则每块K≥2，认证整日K≥8。

所有公式精确使用V20记录十进制的Fraction，严格边界不得epsilon化。对照T8_G2沿用V20必要外计数集合；T8_G24为同一H/G/support类完整小时G锐集合。每个目标分别看其认证比例及实际计数一致性；这些三种目标不同，不把其认证率横向当同一个损失函数比较。

## 解释

每条认证是针对声明的数学可行集合的逻辑命题。四个次序统计量均需从六小时G采样后计算，单位标量相同不代表传感、计算或公开成本相同。ΣG²集合是外界，不是已证明sharp，故比较其认证率时需注明方法保守性。只报告来源宏平均和逐区/逐目标分布；不当作未来预测、区间coverage、新区域确认或中国可部署输入。若效益仅源区集中，则候选限定为对应运行制度/区域，不能声称普适最小摘要。
