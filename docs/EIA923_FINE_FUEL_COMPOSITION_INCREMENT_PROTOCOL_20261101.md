# EIA-923火电内部月度燃料构成增量协议

冻结日期：2026-11-01。问题：已知中国式五类粗月份额M时，额外获取火电内部煤、气、油等月份额，是否能让GB源小时燃料轮廓更好地迁移到目标BA？

## 信息预算和目标

- 目标输入基于EIA-923 2026年8月发行版，按Plant ID×Month连接Page 6 BA，仅保留报告行完整的同BA×月对。目标小时标签为EIA-930同BA同月当前修订燃料数据构造的固定EF发电代理。
- **M臂：**火、水、核、风、光五类月总份额，模型为已用强基线五类小时轮廓重组。
- **M+F臂：**在同一五类月总量之外，使用月度煤、气、油、核、水、风、光、其他内部构成；仅源端GB小时数据学习每类燃料的小时轮廓，再按目标BA月内燃料份额重组小时强度。
- **M+F oracle臂：**内部燃料份额改用目标EIA-930同BA同月完整小时回算。该臂使用目标月标签分布，只用于量化组成测量误差，不可部署。
- 目标队列为原始EIA-923与当前EIA-930从头配对后得到的20格（BPAT6、CISO1、ERCO2、FPL7、NYIS4），不得使用旧缓存中的18格队列。按BA月配对评估，报告宏平均和小时池化指标。
- 燃料小时轮廓只用GB 2022训练；M+F风险偏差/尺度只用GB 2023、并使用t−2月份额校准。目标区间为源校准参考，不宣称跨域保证。

## 解释边界

这是对“额外月度内部燃料信息”的机制/信息价值诊断，不是中国实际五类预算结果。EIA-923覆盖报告机组，且2026年8月发行版晚于目标月份；同月EIA-930 oracle不可部署。它也不是新算法的证明：只有当M+F在分BA误差、形状误差及概率评分上有跨域一致收益，才支持下一步研究以年度装机或其他合法辅助量估计火电内部构成；否则不继续把内部燃料因子头当作创新路线。20格和5个BA不足以估计精确置信区间或作国家级显著性判断。

```bash
python scripts/run_eia923_fine_fuel_composition_increment.py
```
