## 研究判断与后续门槛

1. **未发现跨域精度增量。** 简单热电锚在两条端点的点误差和区间分数都最好；复杂重组只明显改善形状，无法可靠确定水平。直接Ridge/HGB在新大区发生严重负迁移。
2. **消费侧必须单独建模和报告。** 本次两端点近似一致不能说明流量不重要，因为美国Lower 48单一聚合层级会抵消大量区域交换差异；中国消费侧须以省际来源流和排放因子作独立输入预算与标签。
3. **最值得继续的机制假设是“低频锚定水平、外国小时模板只迁移形状”**，但当前后验诊断的总体增益近乎零且区间未改善。下一步应先在已知跨国国家伪目标集上冻结该定义，逐国家比较强锚和重组；只有源区整国留出稳定改善最差域、覆盖与区间分数，才对新的目标地区进行一次确认。
4. **必须修补测量合同。** 后续主实验需对齐目标国家统计范围的EPM输入，或明确将美国总计当邻近地域输入；补充目标小时标签首次发布/修订档案；建立GB官方消费侧源标签，再将消费轨从发电侧训练中拆开。
