# V179：修正粗支持改善预测，但联合森林没有独立优势

2026-10-29，Sol。固定V178已保存世界概率，只将粗支持改为查询基点上的加性增量投影。没有构造新小时law、没有小时评分、没有新地区确认。这是查看V178结果后的语义诊断。

3,856条粗评分、30,848条燃料评分、3,374条支持代理全部完成并重建，九张表一致。独立二分求解47,850个simplex支持，最大差4.44e−16；独立pairwise损失最大差1.24e−12。生产排序投影保留逐行KKT检查；精确分位数和汇总辅助函数共享。12例未发布月量干预通过。482条持平/原点组成参考复现，最大差2.84e−14。

历史scalar8相对其原乘性支持ES下降0.038643，27/29地区改善，事后地区bootstrap范围[−0.054485,−0.025311]。但它相对未改支持的全月Gaussian只下降0.002101，范围[−0.007353,0.002021]；相对加性全月Gaussian只下降0.000119，范围[−0.002428,0.002113]。联合MMD相对加性全月Gaussian反而差0.001306，范围跨0。

因此，明显改善主要出现在“同一森林概率换支持”的比较里；目前没有证据表明复杂联合标签胜过强简单控制。支持变化同时改变可达组成、月零质量及几何距离，不能唯一归因为修正了某项机制。原Gaussian概率是按乘性世界计算，其加性变体也不等于公平重训的最优Gaussian。112条比较是带标签的描述行，包含重复和自比较，不能当112项独立检验。

## 支持暴露与下一步

按预测时已知输入组成计算，源过去/当前均无该燃料、查询过去有该燃料的份额加权代理：原Gaussian约3.08%，历史scalar8约17.56%，历史联合MMD约13.84%。这说明不同概率会明显改变缺失响应暴露；这些数值不是误差贡献、小时零风险或装机缺失比例。不能用它们单独解释全部评分差异。

下一V180预先固定普通直接重组：粗组成与燃料内部小时形状分别传入，比较持平、点组成、重算Gaussian及固定森林概率。先检验小时收益，再讨论机制；不将simplex、QRF或概率协调称为原创，不因粗指标改善就打开未查看地区。
