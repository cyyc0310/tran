# V110 protocol: same-budget monthly-mean anchor and cross-region interval baseline

Frozen 2026-10-28. Evaluate on exactly the V104 five-region, 30-month 2026H1 holdout, for τ=600/900 gCO₂/kWh and 1/5/10% tail-count targets. The local information budget is target-month fuel-specific totals only for the monthly anchor and monthly-only robust identified set; the capacity-augmented identified set is reported separately because it receives lagged annual capacity.

Point anchor: compute target-month generation-weighted mean intensity using the nominal EIA factors, then assign that same value to every hour; the implied tail fraction is 1 if monthly mean intensity exceeds τ, else 0. Calibrate a symmetric absolute-error radius at the 90th weighted empirical quantile from 2024–2025 source-region-month residuals, using the 25 V90 development regions and equal total weight per region (and equal weight per eligible month within region). No target-region labels enter calibration. Convert the clipped fraction interval to conservative integer K endpoints. This is a region-balanced empirical calibration baseline, not a formal conformal coverage guarantee under regional/time dependence.

On the heldout targets compare anchor point MAE, calibrated interval coverage and width, and positive/negative/abstention decisions against (a) V105 monthly-margin ±10% EF robust set and (b) the same set plus lagged coarse capacity. Count only eligible target months; report the fixed 30-month denominator and per-region results. Do not tune the anchor or radius on targets. This is a retrospective EIA proxy comparison, not actual China or prospective validation.
