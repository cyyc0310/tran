# V156：已知月度水平锚与条件小时残差

冻结于V154/V155后、V156评分前。保留两预算、两源划分、30拟合/12校准、36个2025开发目标月、同一20维合法特征，不打开新目标。标准基线实验，无原创算法主张。

目标由CIF改为CIF减去输入月燃料能源强度锚。森林拟合残差并在查询时加回输入锚，叶经验原子加锚后裁[0,1000]。异方差HGB的最终均值预测为输入锚+残差均值；方差用整区五折残差误差学习，规则与V154相同。CQR使用V155严格pinball控制，残差分位数加锚、重排、裁范围；CRPS留空。初始区间及pooled/max-region校准规则不变。

比较sampled与full两个预定源数据模式。sampled与V154各源最多4,096小时抽样逐项相同，用于隔离锚定作用；full保留该预算下全部合法2024拟合源小时，用于比较锚定模型的数据量收益。源地区仍等总权重。full不是raw-CIF模型的全因子交叉对照，不声称锚定×数据量的所有交互已识别。

asof训练源月份仍需存在至少一个模拟已发布历史月，因此full也保留V151/V154的早期暖启动排除。V153重组源形状可使用更多早期2024源月；另做V157匹配来源小时对照，不能把数据量混杂忽略。原始回顾性质量筛选和30天模拟发布限制保留。

参数：森林32树/min_leaf64/max_features1/seed20261028；HGB100轮/.1/15叶/min_leaf64/l2=1/不早停；均值整区五折，方差Poisson deviance拟合OOF残差平方+25，预测后减25，sigma裁[1,500]。正态仍1,025点中分位离散，区间CQR只报q05/q50/q95。
