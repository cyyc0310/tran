# V265 冻结协议：阈值侧因子校准精度前沿

日期：2026-10-30。使用V240已打开的16个BA-month解析证书；这是解析敏感性分析，不是新的目标外测。

## 问题

在固定阈值`τ=500.0001 gCO₂/kWh`下，月度燃料边际和小时总量的尾风险收窄能力受燃料EF不确定性是否跨越阈值约束。V240证明跨越时，比例燃料分配见证能让尾数外包络达到`[0,H]`。V265量化每个BA-month需要把对所有正EF组的共同相对误差盒缩到多窄，才能保证月均因子不再跨阈值。

## 固定定义

对名义月均`μ`及正EF的对称相对误差盒`[(1−r)e_k,(1+r)e_k]`，低/高月均端点为`(1−r)μ`与`(1+r)μ`。因子盒首次触及阈值的临界相对误差为：

`r* = |τ−μ| / μ`。

若`r ≥ r*`（计入浮点小容差），阈值可被因子不确定性跨越；若`r < r*`，该“阈值两侧不确定”充分条件不触发，但并不保证小时集合一定窄。报告`r*`作为最大相对误差容限的临界值，不将`1−r*`称为精度，尤其在`r*>1`时。只允许正排放因子变化，零因子组固定为零，因子不确定性在小时间可独立变化，与V240保守外包络一致。

## 输出和限制

冻结报告`r∈{0,2.5,5,7.5,10,15,20,30,40,50,60}%`下16例跨阈值个数/比例、对应BA-month及每区临界`r*`。不重新求解MILP，不从阈值扫描中挑选最有利结果。`r*`是压力盒达到阈值侧不识别充分条件的误差界，不是从真实中国数据估计的EF置信区间或误差概率。未跨阈值仅表示该不识别充分条件未触发，不代表小时风险集合必然收窄。

此分析用于形成两阶段信息决策假设：若水平因子盒跨阈值，优先获取燃料转换率/排放因子校准；只有因子盒已在阈值一侧，小时总量曲线才可能进一步收窄全月尾数。但因子盒若以跨地区平均EF为中心，V245显示机组/区域异质性可能远大于10%；不能将本分析直接解释为中国误差率。
