# 年度化石热耗预算对官方消费强度跨国迁移的增量协议

冻结日期：2026-11-01，运行前。研究问题：在已有滞后两个月的五类月发电统计上，增加公开年度化石燃料热耗（燃料输入热量/化石发电量）是否帮助外国小时模型跨国预测官方消费侧小时强度，并改善区间评分？该字段与中国省级公开煤耗率相邻，但不完全等价。

## 同任务比较

- 方向为 US→GB 和 GB→US；区域与共同小时沿用官方消费强度开发集。
- 训练用2022源小时官方响应，2023源响应只用于偏差和高斯尺度校准，2024目标为已查看开发集。
- 两臂使用同一EIA-923美国BA月量与NESO英国月量、相同`t−2`时延、源小时样本、模型容量和校准数据：M为五类月量+日历；M+H再加入一列预测时可用的年度化石热耗。外部月量替换保持一致。
- 对M和M+H各自比较粗组成Ridge、粗组成HGB；同时保留固定EF重组强基线。预测文件全部封存后才读取目标标签。
- 年度热耗严格用每个目标年`t−2`的报告统计年：源训练2022读取2020，校准2023读取2021，目标2024读取2022。EIA率由EIA-923燃料电力热值与净发电量聚合；GB率由DUKES Table 5.6煤、油、气燃料投入与相应发电量聚合。

## 预注册判读

报告MAE、日内形状MAE、CRPS、90%覆盖、平均宽度、区间分数及方向/区域结果。M+H只有同时降低宏平均MAE或CRPS、未降低覆盖、没有明显扩大宽度且没有严重恶化最差地区，才作为增量候选。全局校准覆盖只基于源国2023残差，有限样本不代表覆盖保证。

## 数据与解释限制

- EIA-923年度燃料输入采用当前Final档案，不保证每个历史预测起点的as-issued版本；t−2按年份模拟。
- 英国输入为DUKES 2026现行修订版Table 5.6（表封面列明2017–2024修订），不是2022时点的原始发布快照；该值只用于统计信息价值开发。
- EIA-923分母是净发电量，DUKES分母是发电量统计，净/毛口径可能不同。
- 中国《电力统计年鉴》省级标准煤耗率目前只覆盖一定规模燃煤机组；本实验的国外特征是煤、气、油合并化石热耗。二者仅为相关热效率特征，不可视为同一观测量。
- 目标标签是EIA/NESO机构估算的消费侧强度，双方核算定义不同；2024目标在既有开发中已查看。本轮不是盲测或中国准确性验证。
