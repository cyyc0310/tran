# 五类火电因子头的时间外开发复核：冻结协议

2026-11-01，拟合前冻结。上一轮在五类中国粗技术输入下发现M火电因子HGB相对强重组有点误差增量，但覆盖略降。此轮只检验该增量能否跨时间窗复现，不进行超参搜索，不接触新国家。

## 固定划分

- 五个已看国家继续逐国留出：其他四国2022训练，其他四国2023H1源端校准；单独留出国2023年7–12月评分。
- 所有特征为中国五类月发电份额t−2至t−7、日历与五类t−2小时交互；容量扩展使用预测年份前两年统计年。数据和统计口径沿用[FIVE_GROUP_CAPACITY_INCREMENT_PROTOCOL_20261101.md](FIVE_GROUP_CAPACITY_INCREMENT_PROTOCOL_20261101.md)。
- 主比较为五类比例重组、M火电因子HGB、M+C火电因子HGB。直接HGB和Ridge只作模型诊断。模型、预测与每折半径封存后，才读取留出国2023H2小时标签。
- 模型结构、损失、树参数、标准化、权重和90%源校准规则完全复用已封存五类M/M+C消融。统计年份使用滞后模拟，不声称历史as-issued。

## 判定

火电因子头必须再次降低跨国宏MAE和区间分数，日内形状不能明显退化，且最差国家覆盖不能进一步恶化，才保留为有前景的候选基线。此结果仍属于已看国家的开发复核；通过也只说明可冻结候选和准备其他未查看国家的一次确认，不证明算法原创或中国精度。
