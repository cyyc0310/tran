# Three-gate feasibility protocol (frozen before outcome inspection)

This is a pilot, not a confirmation of algorithmic novelty. Completion and scientific success are separate. All three gates are run even if the candidate loses.

## Gate 1: prediction-relevant ambiguity

Standard-normal latent variables, a two-fuel positive decoder, and an observation that constrains latent magnitude while leaving its sign ambiguous. Compare with a dense numerical posterior; add a sign-sensitive observation and a prediction-invariant nuisance direction. Numerical reference integration is not a new theorem. Test high-budget convergence, exact proposal weights, and inference-budget accounting.

## Gate 2: inference under a fixed decoder budget

Compare prior self-normalized importance sampling, a defensive single-Gaussian adaptive proposal, and a defensive prediction-diversity mixture. Budgets 32/64/128/256, 30 fixed repetitions. Adaptive proposals spend one quarter of the budget on a pilot, freeze their proposal, and use only the subsequent particles with p(z)L(o|z)/q(z) weights. Larger-budget prior sampling is a separately charged cost reference. Report reference-distribution error, mode omission, predictive scores, and runtime. A benefit over prior sampling alone does not establish the diversity mechanism's necessity.

## Gate 3: controlled real-data leave-region-out experiment

- Seven EIA balancing areas: BPAT, CISO, ERCO, FPL, ISNE, MISO, NYIS. PJM excluded for persistent reported-fuel/net-generation imbalance. These are not seven statistically independent electric systems.
- Each outer target is completely excluded from fitting, PCA, direct regression, and residual estimation. Source fitting uses 2022–2023; all 2024 UTC days are forecast before target hourly evaluation labels are read by the predictor. Hyperparameters are fixed here; no target-based selection or calibration. This first run has no hyperparameter search or inner-validation model selection.
- Inputs: known calendar and the most recently available historical monthly generation mix. No target hourly power/CIF history, demand forecast, future realized weather/load, or target-fitted emission factors.
- Monthly shares are energy weighted, constructed retrospectively from the hidden native records, at least 80% hourly coverage, with an **assumed 30-day release delay** after exclusive month end. This is `controlled_information_budget`, not an archive of actually issued public statistics. Later past months may become available during 2024. Missing observations use the last eligible month; no eligible month means no prediction.
- Timing correction before the definitive gate-3 rerun: for each monthly release, native active-column detection and input quality screening use only raw rows with `valid_at < available_at`, then aggregate that historical month. Future records may not retroactively alter an earlier monthly input. Hourly evaluation labels retain the retrospective full-snapshot quality screen. Historical revision vintages are still unavailable. The original gate-3 run is retained as superseded diagnostic evidence; models, seeds, comparison rules, and parameters are unchanged.
- Predict 24 hours from 00:00 UTC. Forecast every calendar day; score only complete quality-screened days. The predictor never uses target validity flags to choose dates.
- Reference: **nonnegative reported-generation fixed-EF proxy**, not measured full-grid CO2, consumption intensity, or lifecycle intensity. Positive reported production is retained; negative generation is excluded with its magnitude audited. Standalone storage is excluded; legacy hydro cannot separate pumped storage. Missing/unreported fuel categories and schema changes remain limitations.
- Illustrative fixed factors, gCO2/kWh: coal 1000, gas 400, oil 800, nuclear/hydro/wind/solar 0. Other = 400 in the main experiment, with entire model/label/baseline pipelines repeated at 0 and 900. These are declared scenario assumptions, not locally calibrated or externally certified factors. Report all seven areas and a lower-accounting-ambiguity subset BPAT/ERCO/ISNE/MISO.
- Reference generator: source-fitted log-generation calendar coefficients, rank-4 Gaussian monthly-state PCA and rank-2 daily-residual PCA. Positive generation gives normalized fuel shares. Historical aggregate and future trajectory are separate observation/prediction operators. The first implementation assumes static persistence of the last revealed monthly state; it does **not** learn a transition model or reconstruct true dispatch.
- Aggregate likelihood: isotropic Gaussian fuel-share discrepancy, standard deviation 0.06. This is a fixed model-tolerance assumption, not the provider's measurement precision. Six latent dimensions; known future local hour only in this reference generator.
- Same-decoder comparisons: prior / Gaussian / diversity at budget 128, plus prior at 2048 charged separately; seeds 0/1/2. Cache only identical legal information/calendar inputs. Record actual decoder counts and number of cache contexts.
- Strong simple references: source seasonal hourly template; lagged target monthly CIF-level plus source centered hourly template; constant lagged level; same-information ridge and ExtraTrees regression. Regression features include lagged fuel shares, statistic age, known season/hour, and fuel-share/hour interactions. All fixed settings; residual ensembles learned only from sources. No local-label oracle is presented as a deployable baseline.
- Direct-reference predictive distributions add empirical 2023 source error curves from a 2022-trained model, retaining their bias and clipping to the fixed-EF range. Their distribution-mean point scores are therefore source calibrated; separate `basepoint_*` scores retain the original point predictions. This source temporal calibration does not certify unseen-region coverage.
- Metrics: region-macro hourly MAE/RMSE/CRPS, 90% coverage/width, daily-centered shape MAE, daily-level MAE, ESS, runtime, and per-region results. Compare paired calendar-month blocks; Monte Carlo seeds are not independent regions. Small region counts limit inferential certainty.
- Descriptive pilot continuation rule, fixed before the first target scoring: diversity must reduce CRPS relative to prior, Gaussian, level-template, ridge, and ExtraTrees, with each synchronized-month paired interval entirely below zero, and attain at least 85% empirical coverage for the nominal 90% interval. This is an operational screening rule, not a multiple-testing-corrected claim of generalization. Gate 2 remains a separate necessary check.

## Interpretation rules

Do not declare success because intervals get wider. Do not assume each new observation must shrink each interval. Only a reproducible improvement over both conventional adaptive inference and strong simple predictors supports a new inference method. If the generator is misspecified, correct posterior inference cannot repair it. If only monthly level correction helps, retain that useful result without claiming recovery of hourly mechanisms. A strict issued-public deployment benchmark and independent physical CO2 labels remain subsequent work.

The runner writes protocol/code/data hashes, per-context predictions, per-window scores, and fold membership. Any implementation fixes after seeing outcomes must be recorded; no post-outcome hyperparameter search is permitted.
