# V310：公开年度省际 OD 矩阵审计协议

## 研究问题

此前的 V304–V308 显示，省级未配对送受电总量不能识别区域 OD 流。V310 检查一份新公开的 2023 年中国省际发电转移矩阵，是否能在省级层面闭合“分技术发电量 → 电力交换 → 省级碳因子”的年度结构，并评估它对现有信息缺口提供了什么。

## 数据与来源

数据取自 Xiong 等发布于 Zenodo 的 [省级电力生命周期碳足迹数据集](https://zenodo.org/records/20344652)，版本 v1，2026-05-22 发布，记录授权 CC-BY-4.0。该记录提供：省级技术发电量、技术碳足迹因子、31×31 的 2023 年省际传输矩阵、省级 CF 汇总分布和输配电基础设施因子。工作簿单位分别为 TWh 和 kg CO₂e/kWh。矩阵行是送端、列是受端，空白按“无记录”转为 0。原始文件和下载校验值在 `results/v310_zenodo_interprovincial_audit_r1/`。

记录说明数据用于一篇省级电力生命周期 CF 文章，但 Zenodo 元数据未链接文章 DOI/全文。因此本轮不推断未提供的流量边界定义，也不把它视为官方调度/结算的独立观测值。矩阵只是单年、回顾性、数据集自身提供的结构输入。

## 预注册计算

1. 省级技术发电量与同省技术 CF 对齐，得到本地发电加权 CF：
   `g_i = Σ_k G_ik EF_ik / Σ_k G_ik`。
2. 用省对省矩阵 `T_ij` 做比例共享的节点流追踪。令 `G_i` 为省 i 总发电量，`I_i=Σ_j T_ji` 为输入电量，求解：
   `[(diag(G+I) − Tᵀ) c]ᵢ = Σ_k G_ik EF_ik`。
   其中 `c_i` 是省 i 混合池的年均发电来源因子。解之前把传输矩阵行列按省份标签重新排序。
3. 第三臂在节点流因子上加上同记录中该省输配电基础设施 CF，检查边界项对数据集省级 CF 均值的一致性。
4. 与同记录省级 CF 均值比较 MAE、RMSE、偏差、Pearson/Spearman 相关，并报告预测值落在该记录 Q2.5–Q97.5 范围内的比例。最后一项只是与数据集给定不确定性分布的相容性描述，不是预测区间覆盖率。

## 解释限制

- 发电量、技术因子、OD 矩阵、T&D 因子和比较 CF 均来自同一 Zenodo 记录；因此是**内部一致性重构**，不是独立外部验证、盲测或留出预测。
- 年度数据只约束年度混合/来源结构，不识别小时调度、小时 CIF 曲线或尾部风险。
- 生命周期 CF（kg CO₂e/kWh）包含的边界不同于 transcif 关注的发电侧小时 CO₂ 强度。不能把此处数值当作逐时目标真值。
- 按省级技术 CF 加权与比例共享流量追踪是已有能源碳流方法范式；V310 不将其作为新算法贡献。
- 用户表示持有逐类月发电量，但其原表字段、来源、空间粒度和版本时点还未在本轮可审计数据中提供。Ember 的月度细分是估算/校准产品，不能自动替代原始观测。
