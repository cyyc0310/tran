# 预测时点可用的2025年度装机预算审计

更新：2026-11-01。用户已允许将公开年度装机作为独立信息预算，要求比较其相对月报的增量。本审计确定2026年11月预测起点可用的最新年度统计，并记录其与已封存2020容量参考的区别；不报告小时预测收益。

## 预测时点可用性

EIA于2026-09-10发布了EIA-860最终2025数据，DUKES 2026于2026-07-30发布且包含2025统计年，均早于2026-11-01预测签发日。[EIA-860官方下载页](https://www.eia.gov/electricity/data/eia860/)列出2025 ZIP；[英国DUKES 2026集合页](https://www.gov.uk/government/collections/digest-of-uk-energy-statistics-dukes?region=uk)记录2026年版与发布日，[DUKES 5.7表页](https://www.gov.uk/government/statistics/electricity-chapter-5-digest-of-united-kingdom-energy-statistics-dukes)链接年度容量数据。

本地保存EIA-860 ZIP与DUKES Table 5.7，按EIA发电机能源源代码将煤与天然气nameplate容量加总；EIA-860 Plant工作表提供登记BA，按其与发电机表连接，取可运行发电机。结果见[逐BA CSV](evidence/public-capacity-2025-asof-nov2026-r1/annual_capacity_2025_by_ba.csv)和[来源、处理口径及SHA摘要](evidence/public-capacity-2025-asof-nov2026-r1/audit_summary.json)。

DUKES 5.7的2025“all generating companies”煤电容量为0 MW、气电为36,508.5 MW。它是英国全域总量，范围包括北爱尔兰，且DUKES的de-rated capacity与EIA nameplate capacity不是同一统计定义；当前NESO小时源则是GB。因此它只能作为英国源域的近似年度预算，不能视为严格GB同口径容量。

## 对当前预测的含义

2026年11月GB→US预测已经封存，其M+C输出使用的是**2020煤/气装机参考**，不是现在确认可用的2025年度版。不能在封存后静默替换原预测。该旧版结果也不能代表“用预测时最新年度装机”的增量。

把2025煤气占比直接放入现有容量学习头，仍不能证明有可学的跨域增量：前瞻实验仅有GB一个源区域，源端几乎没有跨国装机结构变化可识别煤气比例与CIF水平/小时风险的关系；而GB 2025煤电容量几乎为零，GB训练响应却来自2022–2023，年份错位会让按装机估算的燃料利用率不稳定。容量锚与学习容量头必须分开比较，并以独立目标标签评分。

因此，当前证据只支持**预算可获取、时间戳可前置、可纳入一项单列比较**；尚未支持准确性增量。后续按以下路径执行：

1. 保留当前2020 M+C封存预测作历史参考；单独生成2025 M+C候选，不覆盖主预测文件。
2. 对同一目标月、同一五类月报、同一GB小时训练/校准和七个BA，配对比较月报M、旧2020容量M+C、最新2025容量M+C与可解释煤气形状锚。
3. 2026年11月响应可用后只评分一次，逐BA列MAE、形状误差、覆盖、区间宽度及概率分数。由于源域单一且目标BA已见，这只能作为前瞻预算价值结果；方法可迁移性仍需多国伪目标训练和整国留出证明。

当前容量相关的结构问题是：装机信息也许能给水平提供燃料结构先验，但可用源支持未必足够把这个先验转成跨国小时响应关系。新预算试验应先验证这个识别条件，而不是把特征加入模型就当作创新。
