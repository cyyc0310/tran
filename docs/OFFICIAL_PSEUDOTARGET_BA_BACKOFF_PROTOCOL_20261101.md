# 官方消费侧标签：伪目标专家的源内收缩回退协议 r2

2026-11-01，拟合前冻结。r1的七折美国BA实验中，组成相似门控在2023H1选择等权专家，但目标GB MAE显著差于普通pooled HGB。r2只检验专家输出能否作为pooled HGB的受控残差，并保持精确回退路径；r1保持原样作为已记录负结果。

数据、模型训练参数、2023H1伪目标标签、2023H2校准、GB 2024评分、预测封存及EIA/NESO标签定义均沿用[r1协议](OFFICIAL_PSEUDOTARGET_BA_ENSEMBLE_PROTOCOL_20261101.md)。GB 2024已在前轮查看，r2仍是开发实验。

## 源内选择与正式模型

每个伪目标BA `r` 的2022训练标签只来自另外6个BA。普通模型在这6区上拟合一个pooled HGB。专家集成由6个留一区模型构成；每个专家j训练时排除r与j，只用其余5区。特征相似门控规则与r1相同，温度集合为`{0.1,0.25,0.5,1,2,5,+∞}`。这是刻意保留的样本支持差异，用来检验小专家模型是否提供pooled头遗漏的可迁移信号。

最终候选为 `p(α,τ) = (1−α) p_pooled + α p_expert(τ)`。`α`只取`{0,0.25,0.5,0.75,1}`；当`α=0`时不再枚举温度，预测必须逐值等于普通pooled基线。对每个伪目标BA，使用2023H1官方强度评估所有候选；按BA等权的平均MAE选择唯一`(α,τ)`，并列时优先更早的固定候选顺序（先零增量、再小收缩、先uniform）。伪目标标签不得进入模型拟合。

最终pooled HGB使用全部7个BA的2022小时；正式专家分别留出一个BA、使用剩余6区的2022标签。校准只用源2023H2且按地区等权，目标标签不参与点模型、门控、收缩或区间校准。预测先写盘封存；启动时目标标签目录必须为空；只有预测封存后才提取GB 2024消费强度评分。

## 决策指标

报告源内每个候选的七BA MAE、选定`α/τ`，以及目标MAE、日内形状MAE、Gaussian CRPS、90%覆盖、区间宽度和区间分数。与r1、普通pooled HGB、固定EF强重组、Ridge及源均值同小时比较。若选择`α=0`，结论为该信息预算下源留BA验证未支持专家增量；不得再按GB目标标签调α或τ。若选择非零α但GB没有超过强重组或覆盖损失，仍不冻结方法、不打开未查看区域。

此方法是有源验证回退的专家集成，不称元学习或新颖理论。是否值得后续方法研究由跨域官方标签的成对结果决定。
