# V235 冻结协议：中国逐小时负荷代理对月度燃料 CIF 识别集的信息价值

日期：2026-10-30。冻结于读取Figshare小时值前。

## 问题

2026年公开的中国省级小时负荷数据集覆盖31个省级地区和2015–2024年，但由2018年NDRC典型曲线、天气、年用电量及模型系数重建，属于需求侧估计，不是逐小时发电观测。本实验检验：把该公开时间形状当作额外的**总发电量形状代理**，在月度八类燃料边际固定时，能否收窄点态小时CIF可行区间？区分日总量形状与日内小时形状的贡献。

## 冻结数据、年份与字段

- 负荷文件：Figshare DOI `10.6084/m9.figshare.29832701.v3`，`Data output.xlsx`；按31省份/年小时表读2018–2024完整年份。
- 月度混合：项目已下载Ember中国省级月度CSV快照，按非聚合源读取 `Coal, Gas, Other fossil, Bioenergy, Wind, Solar, Hydro, Nuclear`。保留全部匹配省份月；不以结果筛省月。
- 固定EF向量沿用项目V225的次序和值 `[1000, 400, 800, 400, 0, 0, 0, 0] gCO₂/kWh`。该向量仅为共同几何代理，不宣称是中国官方电源EF。
- 用省月Ember八源发电总量 `M_total` 将负荷曲线在月内归一化为正的合成逐小时总量 `G_h = M_total × load_h / Σ load_h`。这样只比较时间形状，精确满足月总电量守恒；不把需求曲线声称为真实发电曲线。

## 冻结比较

1. **月边际、无目标小时总量：** 单小时锐识别集为活跃EF最小值至最大值（V234解析结果）。
2. **日总量形状：** 将每日本地24个负荷值求和后均分到该日24小时，再按月总电量归一，作为逐小时总量代理。
3. **逐小时负荷形状：** 使用Figshare完整小时曲线，按月归一为合成总量。

在2和3中，给定每小时总量 `G_h`、燃料月边际 `M_k`，逐小时求解固定EF下的CIF锐下界/上界：`0≤x_hk≤M_k`、`Σ_k x_hk=G_h`。遵照月度运输约束，单小时投影界已锐（V232）。报告地区月等权的平均/中位/p90区间宽、满EF支持宽度的小时比例、相对全支持宽度的平均缩减，以及全省月覆盖。逐小时总量被强行配平月发电量，结果只量化“如果这个负荷形状可当生成总量形状，数学上可收紧多少”，不是预测准确度或覆盖率。

## 数据完整性和冻结门槛

- 只保留小时完整且连续的自然年、省月八类Ember边际均完整、非负且总量为正的样本。
- 记录两个输入文件的SHA-256、Figshare版本和协议SHA-256；拒绝覆盖已有输出目录。
- 至少20个省、至少5个完整年份，否则报告为未通过可用性门槛并停止。
- 先比较总体信息增益，再按省、年份和燃料EF支持结构拆分；不根据目标CIF结果挑省/月份。

## 解释边界

- Carbon-intensity标签未使用，因此本实验不是标签验证，也不做预测准确率或区间覆盖结论。
- 负荷不等于发电：省间净交换、输配损耗、厂用电、分布式自发自用都会造成差异；月内归一不校正这些因素的时间变化。
- Ember月度混合是二次估算当前快照，不等于用户原始月报版本；EF是固定代理。
- 若逐小时负荷形状仍未收窄点态区间，结论只是否定“总量时序形状足以识别当前小时混合”，不否定它对联合尾频率、季节性或负荷预测的价值。下一阶段只在该结果后再试小时总量对全月超阈小时计数锐界的影响，不回头调点态实验参数。
