# V197 冻结协议：供体离散度标准化的小时 CIF 区间

状态：**目标小时评分前冻结**。本轮检验 V196 发现的地域欠覆盖，不增添目标侧信息。

## 可证伪假设

若供体之间在某小时的形状分歧反映未见目标省的局部迁移难度，则将来源 LOO 绝对残差按来源供体的同小时离散度标准化，再以目标供体离散度缩放校准分位，能够比全局统一宽度更好地分配风险：较难月份/小时更宽，支持较强的部分更窄，且整体覆盖/区间分数不恶化。

## 固定方法

- 继承 V194/V195/V196 数据、完整年份、省份/情景留出、oracle目标月均锚和30源预算。
- 中心 k 固定为10、15。对每个来源伪目标 i，按月均 CIF 距离在其他29个供体中取最近k条，均值预测其中心化小时形状。
- 伪目标小时尺度 `s_i,h` 固定为这 k 条相邻供体形状的样本标准差（跨供体、逐小时），下限固定为原始因子四位小数精度 `1e-4 tCO₂/MWh`。
- 校准分数为 `|shape_i,h − prediction_i,h| / s_i,h`；每 query 汇集全部30供体×月内小时，取 `higher` 经验90%分位 `q`。
- 目标中心仍是目标oracle月均锚 + 最近k供体形状均值；目标区间半宽为 `q × s_target,h`，其中 `s_target,h` 是目标 query 最近 k 个供体在该小时的样本标准差，同样设 `1e-4` 下限。
- 不按小时位置分箱；V196显示hour-of-day分箱未带来可辨增量。此轮不优化k、不用目标小时选择标准化尺度或校准分位。

## 评分及门槛

报告总体、每省、情景、年份的90%经验覆盖、宽度、Winkler90、中心形状MAE/RMSE；和 V196 pooled/hod、V195 k10/15/20/30 粒子基线按共同 query 对齐比较。关键判断：1) 最差省覆盖是否改善；2) 在覆盖接近90%时总体和大多数省宽度能否低于 V196；3) Winkler是否优于简单全局校准。若尺度不预测迁移风险，或只是按高离散度区间变宽而未在其他省收窄，就否定该机制，不继续堆相似校准变体。

## 封存

先保存每 query供体角色、LOO预测/尺度残差hash、q、目标逐小时尺度和区间端点hash，再评分。运行后重算必须与预测seal吻合；目标小时形状置换测试固定锚下预测和区间逐值不变。仍只可称同模型投影压力测试，无实测中国结论。
