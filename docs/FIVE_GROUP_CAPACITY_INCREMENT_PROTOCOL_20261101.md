# 五类中国口径下的年度装机增量：冻结协议

2026-11-01，拟合前冻结。目的：在与中国可见的火、水、核、风、光五类月报一致的整国留出输入下，测量滞后年度宽口径热电装机M+C相对月报M的增量。该实验补齐六类LOCO容量消融与五类伪目标训练之间的schema差异，不是新算法宣称。

## 数据和时间划分

- 五个Energy-Charts开发域：NL、ES、BE、AT、SE。固定因子发电侧小时代理；各国均已查看，实验属于开发，不是未知国家确认。
- 每折以其他四国2022训练，其他四国2023年1–6月做源端区间校准，留出国2024年评分。五国、时间、训练/校准小时和标签定义沿用五类伪目标实验。
- 目标特征为火、水、核、风、光份额的t−2至t−7、日历和各类t−2×小时日历交互。来源中未单列的生物质/其他可再生沿用五类基准映射并合入火电组。不得读目标小时标签来拟合、校准或选型。
- M+C只增加Eurostat `nrg_inf_epc`宽口径`thermal_capacity_share`，按预测年份前两年统计年匹配；2022训练用2020、2023校准用2021、2024评分用2022。该源是2026-10-22当前修订快照，滞后年份模拟，不是历史as-issued预算。

## 固定配对方法

在完全相同的五类输入、小时队列、源标签与源校准队列上比较：

1. M强五类比例重组；
2. M直接HGB、M火电有效因子HGB、M直接Ridge；
3. M+C直接HGB、M+C火电有效因子HGB、M+C直接Ridge。

HGB固定`max_iter=80, max_leaf_nodes=15, min_samples_leaf=100, l2=10, random_state=416, early_stopping=False`；Ridge固定`alpha=10`并标准化。因子头只在训练火电发电量大于零的源小时上拟合，输出限于400–1000 g/kWh，再乘与强重组相同的目标小时火电份额。M与M+C在同类预测器上的唯一差别为容量字段。每个方法的90%绝对残差半径独立使用其他源国家2023H1标签和国家等权加权分位数校准。

预测文件全部写盘并生成SHA seal后才读取2024留出小时响应评分。主报告逐国、逐月以及先等月再等国汇总MAE、去日均形状MAE、90%覆盖、宽度和区间分数；同时报告最差国家。小时和五个已开发国家均不能被当作大规模独立样本。

## 解释门槛

年度装机只有在M+C相对同类M方法产生可重复的国家层增量、最差国家不恶化，且区间改善不是靠宽度膨胀时，才值得保留为模型输入。无增量时只保留为独立预算消融，不继续扫年份/乘数。此门槛不能用来证明中国预测精度；中国当前没有配对小时真值。
