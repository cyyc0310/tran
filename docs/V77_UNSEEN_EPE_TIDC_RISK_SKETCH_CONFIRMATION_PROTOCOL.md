# V77：EPE/TIDC未评分区风险定向G摘要外域确认

冻结日期：2026-10-28。V76在BPAT/MISO/NYIS三个匹配区的三个半年度发现minG、S₂、L₁对三个特定阈值/计数目标逐日复现完整G证书。V77用V52质量普查中此前未评分、且不属于V54/V68/V71已开区域的EPE和TIDC检验能否跨不同燃料支持迁移。

## 目标区选择与时间窗

目标固定为EPE、TIDC；选择只依赖V52质量清单和原生字段，不查看其CIF/尾计数。EPE主要有gas/solar，TIDC有gas/hydro；两个区都有EF 0和400的活跃支持，故τ=100、300保留事件与非事件的可变空间。τ=600/900超过两区最高活跃EF，K=0由支持本身决定，属于退化情形，不进入主要方法检验。

评分窗固定为2024H2、2025H1、2025H2；要求每区每窗完整24小时日覆盖≥80%，否则该区窗按质量不合格剔除且不改窗。来源小时数据在运行前冻结自项目原生EIA快照，使用与V54一致的小时valid规则。

## 冻结决策与对照

τ=100、300对每个完整日，按四个6小时块从正发电代理定义H=ΣG·C、G总量及EF支持，计算：

- minG包：若每块H≤τ min(G)，认证日K=0；
- S₂包：若每块H≤τ*(两小时最小G之和)，认证日K≤4；
- L₁包：若每块H>τG+(1000−τ)L₁，认证日K≥8；
- 参照：T8粗界、四块ΣG²必要外集、完整24小时G锐集合。

所有严格不等式使用精确有理数（对规范化十进制小时值）。摘要与参照使用同一块级H/G/support基线。主报告逐日是否与完整G认证完全一致、各策略覆盖/弃权天数及实际K零反例。两个新区域分别报告，不能因样本小而合并成新地区总体coverage。不得用确认标签改EF、阈值、风险目标或摘要。

## 判据与边界

若EPE和TIDC的τ=100/300风险定向证书均无错误，且至少一个预定非退化决策在两区都保持接近完整G，支持“风险特定G摘要可跨燃料结构迁移”的候选；若只在某一区或一种fuel support上匹配，贡献必须收缩为适用条件。任何结果都是同期识别，不是预测概率、覆盖保证或中国月度-only结果。块级H/G仍是小时附加信息预算；中国公开月/年统计没有这些字段。
