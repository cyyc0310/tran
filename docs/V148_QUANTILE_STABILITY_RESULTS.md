# V148：分位提升强基线的数值与拟合顺序稳定性

## 结果身份与审计

本报告以 **[V148 r2](../results/v148-quantile-stability-r2/summary.json)** 为主结果。它在 V144 规范 EF 契约下复用 V145 的 PACE（18 月）、LGEE（24 月）、SC（24 月）、30 拟合／12 校准地区角色和月度信息预算；比较三种全月 CQR 基线、三种优化控制、拟合行的规范顺序与反向顺序、阈值 600/900、seed 41/83、α=0.10/0.20。总计 **9,504 条目标预测**、0 断言失败；规范顺序的 `library_default` 与 V145 的 **1,584 条目标端点全部一致**。r2 还保存 432 个初始源梯度块、272,736 个梯度值、训练顺序摘要、首棵树诊断及校准地区分数，环境固定为 scikit-learn 1.8.0、NumPy 2.4.5。

r1 是先完成的预检运行，随后审查发现严格 tie helper 对梯度输出缓冲区及 dtype 的 API 语义处理不完整，且没有保存源梯度。修正 helper 后重跑得到 r2；[开发审计](../results/v148-development-audit-r2/summary.json)核对 79 个哈希、梯度清单及全部目标端点，确认 **r1/r2 的 9,504 条目标上下端点逐行相同，差异为 0**。因此 r1 不是第二个独立实验，也不应与 r2 合并为额外样本。代码契约修复提升了基线审计可信度，不是统计方法创新。

`library_default` 复现 V145；`split_guard` 只加 `min_impurity_decrease=1e-10`；`strict_tie_guard` 另在残差恰为零时采用 pinball 次梯度的另一合法端点，其余分位目标、初始值、叶分位更新、树参数、地区权重和校准方式不变。两种行顺序均预先固定，不能按目标覆盖或宽度挑选。所有覆盖率均指**假设 EF 盒下目标月超阈小时数的低、高端点被区间包含**，不是逐小时 CIF 预测区间覆盖。V148 与 V145 均按阈值分别校准，和 V146/V147 的双阈值联合校准范围不同。

### PACE / 900、普通特征直接 CQR 的逐顺序核验（α=0.10）

| seed | 数值控制 | canonical：覆盖 / 宽度 | reverse：覆盖 / 宽度 |
|---:|---|---:|---:|
| 41 | sklearn 默认 | 100.00% / 599.944 h | 94.44% / 17.500 h |
| 41 | 分裂增益护栏 | 100.00% / 620.833 h | 100.00% / 620.833 h |
| 41 | 严格 tie + 护栏 | 100.00% / 122.778 h | 100.00% / 122.778 h |
| 83 | sklearn 默认 | 100.00% / 69.389 h | 100.00% / 69.389 h |
| 83 | 分裂增益护栏 | 100.00% / 69.833 h | 100.00% / 69.833 h |
| 83 | 严格 tie + 护栏 | 100.00% / 70.222 h | 100.00% / 70.222 h |

PACE/900 seed 41 在**同一个 seed 内**仅倒转拟合行顺序，默认版平均宽度便从 **599.944 h、100% 覆盖**变为 **17.500 h、94.44% 覆盖**；reverse 的失覆盖来自上端点。分裂增益护栏在该格两顺序均为 620.833 h、100%；严格 tie 加护栏均为 **122.778 h、100%**。seed 83 的严格 tie 在两顺序均为 70.222 h、100%。因此“122.778 对 70.222”是**跨 seed 的来源角色变化**，不能与同 seed 行顺序敏感性混作一种不稳定性，也不能挑 70.222 h 当唯一结果。单折[数值诊断](V148_QUANTILE_NUMERICAL_DIAGNOSIS.md)将该差异定位于零残差的 pinball 次梯度约定与浮点树分裂增益；本轮是对全部目标格的预定控制比较。

护栏没有普遍消除顺序差异。α=0.10 的 36 个“目标×阈值×基线×seed”格里，默认版有 9 格宽度随顺序变化、3 格覆盖变化；`split_guard` 分别为 7 格、2 格；`strict_tie_guard` 分别为 **10 格、3 格**。默认版最大同 seed 宽度差是上述 PACE/900 格的 **582.44 h**；分裂护栏的最大值仍有 **108.33 h**；严格 tie 的最大值为 **107.83 h**，后两者均发生在 SC/900、seed 41 的响应特征直接 CQR。严格 tie 在该格从 196.8 h、54.17% 覆盖变为 304.6 h、100% 覆盖；默认版在这一格为 196.8 → 305.1 h，同样出现 45.83 个百分点的覆盖差。α=0.20 仍有严格 tie 的 11/36 格宽度、4/36 格覆盖随顺序变化；最大宽度差 73.29 h，最大覆盖差 33.33 个百分点。所谓“修复”只成立于特定数值退化格，不能宣称全局顺序不变。

跨 seed 差异也仍显著：在相同 canonical 顺序与严格 tie 实现下，PACE/900 普通特征直接 CQR 是 122.778 对 70.222 h，均 100% 覆盖；LGEE/900 普通特征直接 CQR 仅 12.5% 对 45.8% 覆盖，响应残差 CQR 为 95.8% 对 87.5%。这反映两套固定拟合／校准地区角色的结果，并非同一训练集的排列效应。LGEE/900 的因子盒端点差接近全月，严格 tie 也没有解决该目标的覆盖问题。[V145 普通条件重组](V145_RECOMPOSED_RISK_BASELINES_RESULTS.md)在 PACE/900 的两 seed 均 100% 覆盖、平均宽度 28.4/15.3 h；它和其他同预算强基线仍须保留比较，不能仅凭某个 CQR 顺序或控制宣布方法胜出。

α=0.20 的失覆盖尤其提醒不要把更窄当作更好：PACE/600 seed 83 的严格 tie 普通特征直接 CQR 在两顺序均只有 38.9% 覆盖（555.2 h 宽），而默认版同 seed 为 100%（600.9 h）。LGEE/900 seed 41 的严格 tie 普通特征直接 CQR 仍为 0% 覆盖；seed 83 为 12.5%。完整逐格上下端点覆盖、固定 90% robust interval score、宽度和 α 敏感性均保存在[前沿 CSV](../results/v148-quantile-stability-r2/target_frontier.csv)及[方向性审计](../results/v148-development-audit-r2/individual_endpoint_coverage.csv)。

此实验仍是既有地区月的回顾性月度尾数端点检验，未开放未知地区或时段，也未通过小时 CIF 覆盖／CRPS 门槛。严格 tie 的处理使用 scikit-learn 1.8.0 内部接口；若版本变化，必须重新审计优化契约。
