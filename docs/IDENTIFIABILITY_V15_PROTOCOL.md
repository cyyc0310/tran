# V15：小时风险可识别性与最小信息诊断

2026-10-25，Sol。本轮不训练新预测模型，不打开新地区，不修改V7–V14冻结文件。

目标是区分信息不充分与模型未能利用信息。令非负八燃料小时发电a_hf、G_h=Σ_f a_hf>0、E_h=Σ_f EF_f a_hf、C_h=E_h/G_h。只有固定EF发电侧代理，不包括进口、消费侧、真实机组排放不确定性。月燃料量M精确识别Σ_h G_h C_h/Σ_h G_h=EF·M/ΣM；不一般识别等权小时均值/尾部。给定G与M后，2×2燃料-小时循环可保留全部约束而改变C；G相等时仍能改变峰值/尾部。

## 实验性质和信息合同

这是**后验oracle诊断**，不是可部署预测，也不报告oracle CRPS或把包含率当校准成功。全部同日/月真值汇总来自已查看标签；实际预测时不可用，未来若有计划/预报仍须另测其误差与可用时刻。V10带符号净发电不等于本代理G，不能替代为精确分母。

基准无未来观测：历史月统计加非负性不能约束任意漂移的未来，在当前EF支持下为[0,1000]。其余每种预算都额外知道真实同口径每小时G。比较：保留有效小时上的月燃料总量；日燃料总量；12/6/3/1小时燃料总量；日燃料总量加小时煤、气、正EF燃料总量，以及煤+气、正EF燃料总量+煤两个通道。正EF组为煤/气/油/other，零EF组为核/水/风/光。这个分组只是当前代理定义，不把other解释为可直接取得的商业遥测字段。

月oracle聚合仅包含共同有效完整UTC日，可能不是完整自然月，不能冒充正式月表。日/分块预算只对同一批有效小时切分。每种预算约束都是燃料列总量和各组逐小时行总量。只有非负性；没有机组容量、爬坡、天气硬约束、平滑、源支持或概率假设。

预运行审查后补充三个必要对照：只知道小时G+煤、小时G+正EF总量、小时G+正EF总量+煤，**不再给任何当日/月燃料总量**。仍是同时段oracle，但可揭示双通道收缩是否暗中依赖真实日油量很小。它们不参加原定有日燃料量条件下的源字段选择，只作完整固定列表的诊断。主EF下令t/c/o分别为正EF组、煤、油占G份额，则C=400t+600c+400o；只给t/c时，非煤正EF组可以全为油，故仍有[400t+600c,800t+200c]范围。不能把真实日油量为零的后验信息无条件扩展为未来没有油。合计15预算（无未来观测、11个燃料总量预算及3个去除燃料总量对照）。

计算每小时C的sharp边际上下界，及V14等权日水平L=Σ_h C_h/24的sharp上下界。每小时界用排序燃料的分数背包，日均界用秩一成本运输/重排不等式。后者单独优化，不能用逐小时端点平均代替。端点可分别实现，但小时端点一般不能同时实现，不能当作一条联合情景或概率区间。线性规划作为独立数值参考；标准LP/排序不是本项目新算法。

主EF沿用[1000,400,800,0,0,0,0,400]；另固定代数压力EF=[1000,500,800,0,0,0,0,600]，只检查“气与other同EF”等简化是否使最小信息结论过于特殊，不称其为估计得到的真实排放因子。主EF选择后，压力EF不重新选择。

## 顺序、对照与产物

七源BPAT/CISO/ERCO/FPL/ISNE/MISO/NYIS的2025H1先运行，再锁定源区平均小时识别宽度最小的单通道和双通道；平局按固定名字。六个已查看目标AZPS/DUK/LGEE/PACE/PSCO/SRP的2026H1仅复测完整冻结列表，不根据目标挑字段。两者都是开发诊断，源选择也不是独立确认。

作为规划分辨率而非覆盖门槛，预先报告：每区至少95%小时识别宽度≤100g/kWh且平均日水平识别宽度≤25g/kWh。只在上述1/2通道候选中选择满足所有源区该规则的最少通道，然后最小宏小时宽度；没有满足则明确null。这个“最小”仅限给定真实日燃料量、真实小时G、当前候选字段、当前代理和分辨率，不是普适的最小充分信息或经济成本最优。

每区内部日等权、宏平均地区等权；报告逐区、逐月、日水平界宽及小时界宽分布。没有抽样概率模型，不需要bootstrap给结构端点制造统计覆盖解释。记录字段预算和依赖；小时coal/emitting等通道需要同口径观测。没有噪声/滞后或真实日前预测收益结论。

源阶段前冻结此协议、生产/测试文件、旧V14清单和已注册13区小时文件哈希。源结果/选择封存后才能运行目标阶段；新目录不覆盖已有结果。每地区归档全部预算、两套EF的上下界与真实轨迹，读入前/后验证哈希。未查看地区仍关闭。

判定：若连oracle粗信息仍留下宽小时界，说明仅凭这些约束不能给出更窄的保证，并不说明统计预测必然无效。若某小通道收缩明显，只说明其在完美同时段观测下有约束价值；下一关须在合法滞后/日前计划误差下，与同预算简单持久性、季节参考和强条件模型比较，才能谈算法创新或进入新地区。
