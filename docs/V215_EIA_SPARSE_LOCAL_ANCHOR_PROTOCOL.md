# V215 EIA 2026H1 小时锚信息价值协议

## 研究问题

V213–V214在Li等CIF投影标签上发现，目标省每月少量、跨天且覆盖小时段的本地CIF锚可能修复区域区间失覆盖。本轮检验这一观察能否在EIA平衡区小时燃料发电量派生的小时CIF代理上复现，并比较相同观测预算下连续典型日与跨天分层采样。

## 数据和标签

- 原始输入由项目既有EIA-930快照读取；训练窗为2025-01至2025-12，时间留出窗为2026-01至2026-06。
- 采用EIA类别：煤、气、油、其他化石、核、水、风、光；固定排放因子为`[1000, 400, 800, 400, 0, 0, 0, 0]` gCO₂/kWh，与V202一致。
- 逐小时标签按当小时的类别发电量份额及固定因子计算：`CIF_t = Σ_f G_{t,f} EF_f / Σ_f G_{t,f}`。因此它是**小时燃料结构派生代理**，不是独立观测的电网CIF或排放流。
- 仅使用有效、非负且总发电量为正的行；每个地区月至少保留28天×24小时数量。缺失小时不插补为目标标签；当月小时段缺失时，该小时段不参加评分。时间按UTC排序。
- 目标平衡区整区留出：其2025和2026记录不进入水平模型、形状供体或源残差校准。目标2026的月发电类别总量作为允许的低频信息。

## 预测和校准冻结规则

1. 水平锚在2025年源平衡区月均代理CIF上拟合：固定EF加权月度燃料份额标量＋月份虚拟变量的OLS。
2. 小时形状由其他源平衡区2025年同月的24小时小时段平均CIF曲线中心化后迁移。按目标月与源区月度燃料份额的Bray–Curtis距离选最近10区等权平均。
3. 源区误差用嵌套双留区构造：外层目标区被排除；校准池中每个源区的预测另排除该源区，且不使用外层目标区的任何年度数据。源残差绝对值合并q90作为`global_source`半径。
4. 本地锚来自目标区2026月内抽样小时的类别发电量，按同一固定EF派生该小时代理CIF。用抽样小时预测残差均值修正中心，抽样残差中心化后的经验90%分位作为对称区间半径。它是描述性样本校准，不声称有限样本覆盖保证。

## 抽样预算和比较

每个目标区×月份均重复200次抽样：

- 零锚：只用嵌套源区q90校准；
- 24随机小时、48随机小时：在该月有效小时中无放回均匀抽样；
- 24小时连续典型日、48小时连续两日：只从真实UTC日期中选择完整24小时日，连续两日须相邻；
- 24个小时段分层点：UTC每个小时段从不同随机日抽1个小时；
- 48个小时段分层点：UTC每个小时段从不同随机日抽2个小时。

锚点不参与剩余时段评分。终点为有效目标小时的CIF代理MAE、对称90%覆盖率、平均区间宽度和Winkler90。先在每个地区内等权平均可用月份和抽样重复，再对地区等权宏平均。省区配对bootstrap以24个地区为簇、20,000次重抽样。

## 数据完整性门槛

分析候选地区须至少有9/12个2025源月份、3/6个2026目标月份满足小时数门槛；供体不足5区时停止该查询。原始输入缺月表和完整哈希随结果保存。方法与采样候选在运行2026H1标签前确定，但EIA数据和一部分2026H1实验已存在于项目；该轮是回顾性开发验证，不是盲测或新数据集复制。
