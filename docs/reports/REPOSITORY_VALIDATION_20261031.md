## 发现并修复的问题

- pandas 3的部分时间索引整数变为微秒，历史实验代码按纳秒读取，导致日期合同失败。没有改写历史实验时间语义，通过支持的依赖范围与验证约束限制环境。
- 系统 NumPy 2.4移除`np.trapz`；本机 NumPy 2.2.6的矩阵乘法还触发多处浮点异常。切换到NumPy 1.26.4后，相关160项定向测试通过。此处记录本机观察，不推论所有NumPy 2环境均有该现象。
- 暂停的 V26 草稿把封存原流检查放宽为容差，与其精确身份契约及一ULP篡改测试矛盾；已恢复逐值精确比较。V26没有恢复正式实验，也没有重算历史科研结果。
- V410–V411五情景来源被发现曾在V194–V200查看，新增来源更正并降低确认资格；机器结果和原协议保留。
