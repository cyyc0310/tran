# V274：EIA 负荷侧 CIF 的跨区小时形状迁移协议

冻结日期：2026-10-30。此实验与V273使用相同的七个BA、2019–2023供体形状训练、2024跨区风险校准、2025测试拆分和三种基线；唯一变化是目标量改为EIA负荷侧（consumed electricity）强度。该标签经EIA多区域投入产出方法把跨BA交换的隐含排放分配到负荷地区。

## 研究问题

核对生成侧中观察到的形状迁移失败，是否主要来自目标边界：负荷侧强度包含跨区流入电力的碳强度，或许比本地生成结构更能呈现供电侧日内变动；也可能因潮流分配和来源区组合增加跨区非平稳性而更难迁移。

## 冻结数据与输入

- 目标BA：`BANC, BPAT, CISO, ERCO, FPL, MISO, NYIS`，使用同一批EIA官方BA工作簿。
- 标签：`CO2 Emissions Intensity for Consumed Electricity`，单位lbs/kWh，转换为g/kWh乘453.59237。
- 分母权重：`Consumed Electricity`。训练和校准切分以BA当地日期年份为准；EIA历史序列为当前可下载最终修订版本，没有冻结的实时发布vintage。
- 目标月锚：目标BA该年该月真实小时负荷侧CIF按负荷加权均值，明确是oracle形状锚，只评价锚定后的小时形状和风险迁移。
- 目标BA的历史小时标签既不得用于供体形状，也不得用于该目标区间半宽校准。每个目标的2024半宽只由其余BA的逐区外推2024完整日分数估计。

## 比较与评分

复用V273的三种方法：目标月均锚、供体月×小时形状、供体月×星期×小时形状。用2024源BA留一分数校准日级同时90%区间，冻结后只评分2025。报告各BA和BA等权宏平均小时MAE/RMSE、小时覆盖、完整24小时日同时覆盖、区间宽度和日级Winkler-90，并记录缺失/不完整日。

## 解释边界

本结果衡量EIA估算型负荷侧标签的回顾迁移表现，不是CEMS直接测量，也不是实际中国省级消费因子。若其形状增益不同于V273，说明生产/消费边界会改变最小时间信息需求；不能把这直接解释为中国跨省潮流效应。如果失败，也不能推出负荷侧CIF不可预测，只表明当前仅用源BA时钟形状和oracle月均锚不足。
