# V347：估算的省级月度燃料结构可收窄小时K集合，但不等于验证

运行日期：2026-10-30。协议：[V347](V347_EMBER_COMPLETE_MIX_VALUE_PROTOCOL.md)。脚本：[v347_ember_complete_mix_value.py](../scripts/v347_ember_complete_mix_value.py)。逐省月结果、不可行单元与哈希：[结果目录](../results/v347-ember-complete-mix-value-r1/)。

## 结果

在V341完整的330个省月上，以Ember 2023月度估算的煤、气、其他化石、生物质、水、核、风、光分项取代NBS规上热/水/核/风/光边际及未知残差组。月燃料分项先按V99宽因子带计算月度热电有效EF范围，再通过V342锐界求解器得到小时K外包络。V346残差方案作为对照。

## 解释

这是一个明确的信息价值结果：细化燃料结构后，单独月度边际对小时尾部的约束几乎没有改善；与装机上界一起使用时，τ=300平均宽度减少约285–298小时。它提示可供检验的机制是“燃料结构约束×物理出力上限”的互补，而非单独增加月度统计变量。若燃料分项估算足够准确，这类信息可能缓解V346中残差组造成的近整月外包络。

但Ember燃料分项依赖模型估算、全国校准与外部数据，月度总量又与NBS规上口径有系统差异。本实验把估算月分项当作准确边际，计算的是条件信息价值，不是它们确实能识别真实小时K的证据；没有中国小时真值、预测覆盖或真实历史发布时点验证。尤其当前用户提供的官方表已确认只是火/水/核/风/光，不能把Ember燃料估算说成同预算的官方输入。

## 下一步

把贡献方向收窄为：在明示的月度统计范围和燃料分项误差支持下，检验月度燃料组成与装机信息的互补识别价值。下一关需要为Ember燃料分项加入误差集合（或用NBS类别与总量差做共同扰动），检查约285小时收益在估算误差下是否还存在；若收益消失，当前只是模型假设驱动。随后才值得寻找带历史发布时间的省级官方细燃料表，或在独立小时标签上验证风险区间。
