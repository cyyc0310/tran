# V195 冻结协议：供体留一风险驱动的 CIF 小时形状邻域选择

状态：**在目标小时评分前冻结**。这是 V194 模拟世界结果后的新假设检验；仍不是新颖性声明，也不是实测中国验证。

## 研究问题

V194 显示最近 5 个供体的点形状误差较低，但 90% 区间严重欠覆盖。V195 检验：能否只用允许的30个供体资料，以供体内部留一（LOO）小时形状误差选择邻域大小，使点预测优于固定5或30供体；并记录该选择对 CRPS、覆盖、宽度与 Winkler 的影响。

## 目标信息和样本

- 完全继承 V194 的 oracle 目标月均 CIF 锚、2025–2050完整年份、5情景、31个省级目标、同情景和省份/情景双留出两轨道。
- 目标小时形状只用于预测封存后的评分。目标省在任何供体池中排除；跨情景轨还排除目标省所有其它情景小时记录。
- 每 query 固定30条供体形状档案。月均CIF是事后 oracle，不是月报可部署输入。

## 冻结算法

对当前 query 的30条供体，按每条供体月均CIF进行LOO伪目标预测：移除第 i 条供体，用剩余29条按 `|μ_j−μ_i|` 排序，并以最近 k 条中心化小时形状均值预测第 i 条中心化形状。候选集合固定为 `k∈{3,5,10,15,20,29}`。对30个伪目标和该月全部小时求平均绝对形状误差，取误差最低的 k；完全并列时取最小 k。然后以目标月均锚为距离，在完整30条供体中取所选 k，形成自适应点均值和等权形状粒子。

比较：固定 k=3/5/10/15/20/29/30 的供体均值和等权经验分布、V194常数月均锚、30供体均值、30供体形状分布。任何参数只按来源供体 LOO 选择，不以目标小时真值选择或回调。

## 分析与停止规则

逐 query 记录来源交叉验证选出的 k 及各 k 风险。主要指标为形状MAE/RMSE；概率指标为小时CRPS、中心90经验覆盖、平均宽度和Winkler。先按月查询评分，再按目标省宏平均；报告每个省、情景和年份。所有方法同一查询和30个供体预算。若 adaptive-k 只靠牺牲覆盖或增加宽度取得MAE收益，或收益不能跨省/跨情景维持，不视作成功。区间覆盖不声称保证。

## 封存与数值检查

运行前冻结脚本、V194协议与缺失性修订、输入工作簿哈希、候选 k、供体抽样种子。先逐查询封存所有预测和所选 k 摘要哈希，再进入评分；重算预测与摘要哈希必须一致。月内目标标签置换使用相同的已封存精确月均锚并逐值核对预测不变。数据缺失仍按 V194完整样本规则处理，无插补。
