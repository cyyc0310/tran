# V364：NBS粗类占比下的阈值跨越不可识别证书（2026-10-30）

## 研究问题

在中国公开月表只给“火电+水/核/风/光”时，已有月度组成能否保证小时超阈数有非平凡区间？本探针把V240/V354的阈值侧非识别条件应用到31省NBS派生粗类占比，检验这类结构性“应弃答”区域在全国数据里出现多少。它只评估部分识别集合，不评估概率覆盖或预测误差。

## 数据与期间

输入是V320留存的OREO `cn_prov_monthly_generation_by_tech.csv`，该表标注来源为NBS、但属于公开转录数据而非本轮从用户所给NBS入口抓取的官方原始响应。V320审计确认其月度发电量为规上工业范围，2023总量仅覆盖同源年度全厂发电量的93.6%；不能将它当全社会供给上限。本分析只用同一月报口径内`thermal/total`比值，不能替代用户原表复核。

选择2022–2024年，31省各年11个报告bin，共1023个省—期。国家月表2月数据代表1–2月累计，无独立1月行；计算期长时把2月bin按1–2月小时数计，其它bin按自然月计。2023天津缺水电类，但本分析只需total和thermal，两列都有。输入SHA-256：`292e886809e211fbb7b43424307c638e363666c4d807eb0fe0c90f1985b967ae`。

## 证书推导

令该省期总发电量为`M`，火电量为`M_T`，占比`s=M_T/M`。非火电的运行期直接CO₂因子设为0，火电合并组的未知有效因子`e_T`落在支持`[L,U]`。若

`L × s ≤ τ < U × s`,

则给任意固定的正小时总发电曲线`G_h`构造比例分配`x_{h,T}=G_h s`，其余类别按各自月占比分配。在`e_T=L`情景中，每个小时CIF均为`L×s≤τ`，故严格超阈计数`K=0`；在`e_T=U`情景中，每个小时均为`U×s>τ`，故`K=H`。两个世界具有相同月度类别边际，甚至具有完全相同且任意指定的小时总发电曲线。因此，对目标定义`K=#{h:C_h>τ}`，K的锐最小—最大识别区间为`[0,H]`。

这是充分条件，而不是其它月份就一定可识别的判别器。它要求因子支持允许月均强度跨过阈值，并假设非热技术的运行期直接CO₂因子为0；若目标改成生命周期CO₂e、消费侧含调入电或含市场绿电属性，需换模型与支持集。

## 更新后的最小信息判断

该试验把“只补更多小时总发电量可能无用”转成一项可计算的**阈值侧信息门控**：若本地合并火电因子支持满足`L×s≤τ<U×s`，任何只改善小时总量曲线的观测都不能让超阈小时数从`[0,H]`变窄。需要先收紧当地火电有效因子的可信支持，使它落在`τ/s`同一侧；或者增加能排除比例混合/约束小时燃料排序的信息。收紧因子支持只是退出这张完整区间证书的必要方向，不保证小时K区间随后就窄，容量和小时dispatch约束仍可能留下大范围。

## 研究价值判断

这是目前最贴近用户实际公开数据合同的实证进展：其输入是可获得的月度火电/非火电粗边际，输出是“此阈值下哪些省期即便给定小时总出力也结构性不能识别”的证书。可以作为统一基准框架中的**可识别性预检/弃答层**，并把最小附加信息需求定位为当地有效热电因子支持或小时组成约束。

但它不是新的定理（依赖V240既有构造），也不是预测算法突破。主要数值对`[L,U]`敏感，且所用NBS序列仍为二手转录；没有中国小时真实标签、实测有效EF区间或coverage/width验证。论文上可作为透明、可证明的信息边界贡献；若要宣称新方法，下一轮必须在独立小时标签上预先冻结该门控，与强异方差/分位数/保形区间基线比较覆盖与区间分数，并证明弃答减少漏覆盖且不过度丢弃。

## 计算复现说明

从V320源文件筛选`technology ∈ {total, thermal}`，按province/year/month pivot，对2022–2024行计算`s=thermal/total`；Feb的period_hours取该年1月+2月天数，其它月取当月天数。对每个`[L,U]∈{[400,1000],[350,1100],[700,900],[0,1100]}`及`τ∈{100,300,500}`，逐行计算`L*s ≤ τ < U*s`。无模型训练、无参数选择、未查看小时标签，未运行测试套件。

低端等于阈值仍属于`K=0`，高端必须严格高于阈值；逐项边界复核未改变既有配置计数。
