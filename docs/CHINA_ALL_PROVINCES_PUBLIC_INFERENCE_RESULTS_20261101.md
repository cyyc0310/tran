# 国外模型逐省接入中国公开月报：31省无标签推理

日期：2026-11-01。此轮把原上海单省接口扩展为全省级面板的同模型推理，核对中国月报预算能否逐省进入冻结外国模型，并绘制输入是否落在源模型坐标范围内。**这是部署输入和外推范围审计，不是预测精度实验。**

## 任务与封存

- 外国模型只用DE、GB、US小时标签：2022年训练，2023H1校准。没有读取中国小时标签，没有在中国拟合模型或选择方法。
- 起点为`2026-11-01 00:00 +08:00`，预测24小时。使用封存面板与输入凭证允许的最近月`2026-09`，符合精确`t−2`预算。
- 目标是发电侧固定因子代理。输出的源区90%参考区间不是中国覆盖保证；模型的最后训练月距预测起点47个月。
- 数据字段按NBS规上工业发电口径处理。当前面板不是历史as-issued版本，省级公开月表的历史发布版本仍未认证。

## 支持范围揭示的问题

支持诊断仅比较每个特征是否超出源数据的逐坐标最小值/最大值，不等于联合分布距离或可信度证书。按这一较弱的范围检查，26/31省至少有一个特征超出训练支持：

- 9省的`t−2`火电份额高于源范围上限0.7957；包括上海0.9562，以及安徽、北京、天津、河南、陕西、山西、山东、江苏。
- 11省的历史火电份额均值超出源范围；其中上海为0.9523，另有10省高于上限，西藏低于下限。
- 24省核电份额为0或低于源范围下限0.0583。源集合虽含核电国家，但并未覆盖多数中国省份的零核电构成。
- 青海、四川、云南、西藏的水电份额高，吉林、黑龙江等风电份额高；这些坐标仍在本次源边界内，但单变量落界不能证明其多维组合得到源域支持。

这让“中国直接部署”的难点更具体：可运行不代表可迁移。DE/GB/US参考模型在中国省级最常见的零核电、较高火电构成上有明显边界外输入；继续报告区间时必须明确它是源区经验参考，不能写成已验证的95%或90%覆盖。

## 下一轮研究决策

1. 保留这31省批量推理作为无目标标签部署层，输出模型选择规则不得依据这些预测值本身。
2. 按用户已批准的预算设置，把年度技术装机作为独立`M+C`模型臂；当前这批推理使用`M`（滞后月报）模型，不能将其称为容量增强预测。
3. 算法评估继续在有小时标签的整国留出中完成；中国省级输出只能验证输入接口、识别外推区域和形成后续标签采集优先级。需要独立中国小时标签后才能评估其精度和区间覆盖。
4. 下一轮方法不应只优化平均点误差；优先扩大源域对“无核电、高火电”和水电主导组合的支持，再按国家/省级组检查其是否改善最差域，并与强重组基线同预算比较。
