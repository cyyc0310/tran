# 同目标校准回放：缩宽仍伴覆盖损失

2026-11-01，Sol。按[回放协议](EXPANDED_CALIBRATION_BUDGET_PROTOCOL.md)完成R6c，真实退出0。这是在查看R6a后做的事后开发诊断，不是新模型、独立确认或目标月量适配。

## 隔离了什么

所有源模型、2400个目标小时、预测位置、中位数、尺度、未校准分位数及重组成员保持R6a不变。只把校准日历从扩展H1的每月15/25日，换回原定1/3/5月15日；两政策分别有2424和576个唯一源校准小时。

每配置只使用proper源国家H1行，按country、region、origin、valid_at、label_row精确匹配，保留旧缺测规则。各国/各地区总权重公式不变。旧校准BPAT48、FPL24、其他美国区72小时，DE/GB各72；扩展后相应为240、192、288、264/288小时。所有地区都已有旧校准，变化还包括其日期/季节组成，不能将结果单独因果归于“样本数变多”。

两重组的36条旧半径直接引用R5；直接模型按原组件选旧行重算144个参数，与R5最大差2.84×10⁻¹⁴。新锚定和固定月报锚的旧日历半径按相同旧行生成，不冒称R5原有预测。331200条反事实预测及126条校准先封存，再重算同一目标集。

## 装机代理＋共享历史气候，无当期预报

日幅度HGB缩宽约10.16%，覆盖损失4.41个百分点，WIS略差；加法CQR也以覆盖下降换缩宽。原联合重组覆盖增加2.37个百分点、WIS改善约1.93%，宽度同时增加约2.42%。固定锚宏宽增加却宏覆盖下降，反映不同源配置的半径变化并未匹配目标风险，不是每条区间都统一加宽。

因此，扩大源校准日历没有稳定实现“维持覆盖同时缩窄”。不能将R5到R6a的区间变化当作方法收益，也不能认为补齐更多源误差就能保证新国家覆盖。目标地区失败仍须看[R6a逐地区结果](EXPANDED_ANCHOR_NO_ISSUED_RESULTS.md)，不能只挑旧日历宏覆盖较高的行。

## 对研究路线的影响

源校准预算扩充保留为数据条件，不再作为专门机制或自动可靠性修复。普通加法/logit亦保留为强参考，不继续围绕倍率、epsilon或少数校准日期选型。

接下来保持已冻结参数，完成当期天气的同预算矩阵，检验未来组成/总量偏差能否被合法预报改善。之后才测试总发电先验、风光变化与火电补偿；不能用真实未来总量作锚。要建立可信区间，还需证明源端哪些误差关系能迁移，而不是只改变源全局分位数。

本轮只改变外国源校准日历，没有用中国或目标国历史月量更新模型，故不回答目标月报弱监督适配是否有效。该项、独立方法增量、未知国家确认和中国小时精度仍未完成，四项整体目标继续进行。
