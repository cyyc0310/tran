# V51 年度燃料统计能否替代滞后同月 thermal EF：协议

## 研究问题

已看代理源显示，目标区合法滞后同月 thermal EF 能大幅改善点误差，但中国月报目前只确认类别月量，是否有可用的年度燃料细分仍不清楚。本实验检验年度粒度能否保留本地组内水平信息价值，并显式处理年度报告发布时间。

## 固定预测器与 EF 候选

- 目标小时五组发电量形状固定为留出区之外的2024年同月、本地钟点、24小时 donor 平均轮廓。
- 目标五组月总量固定为合法 as-of 上一年同月值；其发布时点按`available_at<=目标月`且统计期结束过滤。
- 只改变 thermal 组内 EF：
  1. `donor_same_month`：源区上一年同月热组 EF 的等源均值；
  2. `local_lag_same_month`：目标区上一年同月且发布时间合法的热组 EF；
  3. `local_trailing12_asof`：预测时点前最近12个已发布月量的能源加权 EF；
  4. `local_latest_annual_delay{30,60,90,120}`：截至预测月已发布的最近完整自然年度 EF；年度发布时点假设为次年1月1日后30/60/90/120天。要求该年度有12个完整月记录。主敏感性为90天；
  5. `target_month_oracle`：目标月本地 EF，仅作信息价值上界，不是可用方法。

年度滞后场景与月报`available_at`不是同一制度规则；它是年度汇总发布日期的显式敏感性假设。输入月表为回溯修订值，缺少真实历史年度发布vintage。

## 评分与晋级

2025H1/H2的每个区域月报告 MAE、RMSE、有符号偏差；先按来源求月均，再对有效来源等权。所有目标小时来源此前已用于开发，结果属于探索性时间外诊断。

年度统计可保留同月本地EF价值的开发信号定义为：在至少一个合理发布时延下，年度EF的来源等权 MAE/RMSE 比 donor 降低至少20%，且距同月滞后EF MAE不超过10%；再报告月份支持、逐源差异和最差源。即使达到该点门槛，也不代表小时区间覆盖通过，更不构成新地区确认或算法创新。
