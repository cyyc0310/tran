# 伪目标选择的粗组成条件源专家迁移

2026-11-01，拟合前冻结。上一轮内层伪目标选型未胜过固定比例重组。本轮检验更直接的跨域机制：针对目标已知的粗月组成，从外国源端训练的有效火电因子专家中按组成相似度动态混合。该机制只使用目标粗统计和日历，不读取目标小时标签。

## 外层与伪目标合同

保持Energy-Charts五国整国留一，2022训练、2023H1内层选择、2023H2独立源校准、2024目标评分。数据与标签仍是修订小时序列构造的滞后t−2月量和固定因子CIF代理；不是as-issued回放或实测排放。

每个源国单独拟合一套既有`factor_history`模型，特征、HGB结构、EF和粗技术小时轮廓均不改变。源专家的粗月组成原型为其2022训练期六组份额的平均值；六维标准差使用当前外层源国的训练输入估计，低于0.02的尺度截为0.02。对任意目标小时，按输入六组粗份额`g`与第k个源原型`μk`的标准化均方距离`dk² = mean(((g−μk)/s)²)`计算权重`softmax(−dk²/(2τ²))`，再对各源因子头预测加权平均。所有专家均从训练源标签学习，权重不使用小时CIF。

温度τ从固定集合{0.05, 0.10, 0.20, 0.40, 0.80, ∞}中选。每个外层折内，四个候选源国各自轮流作为伪目标；其2023H1小时标签只用于按国家等权选择宏MAE最低的τ，预测只读其滞后粗输入。外层目标完全排除于该过程。

## 独立区间校准与基线

为避免用同一伪目标月份既调温度又校准半径，选τ只看源2023H1。源2023H2采用留一源国交叉预测：每个伪目标国只接收其余源国专家的加权预测，逐国计算残差，再国家等权取绝对误差90%加权分位数。相同日期段和加权规则用于anchor700、macro/ratio重组、全源factor_history基线；基线模型以所有源国2022训练。

目标2024所有预测先落盘并哈希，再读取目标标签评分。逐月、逐国报告MAE、去日均形状MAE、覆盖、宽度和区间分数。比较动态专家与固定ratio重组、macro重组及全源factor_history。权重若没有胜过简单均匀混合/强重组，不称创新；区间半径的交叉校准结果若仍欠覆盖，不用扩大区间作为点方法成功证据。

执行更正：首个探索性runner输出了动态门控和强基线，但漏掉了协议要求的均匀专家混合消融；因此`coarse-conditional-experts-r1`只用于初步诊断，不用于判断门控独立增益。下一运行在同一数据、划分、温度选择及评分规则下补齐均匀混合，并同时提供同样的H2交叉校准半径。该更正不读取或改变模型候选，r1全量原结果保留。

## r3风险条件校准扩展

在r2门控点预测及伪目标选定温度冻结后，单独比较两种区间半径：H2所有留国残差国家等权的统一分位数，以及依据同一门控权重对各伪目标残差块加权的组成条件分位数。每个目标月份只用当时合法可见的六组`t−2`粗份额决定校准国家权重；点预测逐值不变，目标小时标签仍只在封存后评分。不新增温度搜索或覆盖阈值调参。若条件半径的收益只靠显著加宽、或最差目标覆盖仍不足，不视为区间增量。

执行后条件半径明显过窄，因此追加r4校准因子：对2023H2的伪目标国家逐国留一，用其余三国残差块按组成相似度构造条件90%分位数，在被留国家评分。只用2023年7–9月伪目标误差选择统一缩放因子`λ∈{1.0,1.25,1.5,1.75,2.0}`：先选宏覆盖≥90%且最差伪目标覆盖≥85%的最小λ；若无候选满足两者，选宏覆盖≥90%的最小λ；若仍无候选则固定取最大λ。最终目标区间半径只从10–12月源交叉残差构造，再乘λ。该时段分离使风险系数选择不复用最终校准月份。基线点预测、强度输入和目标测试时段不变；报告所有候选CV覆盖/宽度/评分和实际外层结果。

## 解释边界

这是一个明确可部署的源专家门控参考，不是普遍的新算法主张。五国开发样本不足以宣称国家外稳健性；后续若有增量，需在冻结方法后用此前未查看的国家确认。中国统计范围、国外源标签范围和历史发布版本差异仍须披露。
