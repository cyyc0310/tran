# V219：月度燃料边际约束下的小时形状迁移

日期：2026-10-30。状态：EIA小时燃料结构代理上的回顾性开发，不是中国实测验证或盲测。

## 问题

检验目标地区某月的逐类发电量边际已知、小时信息不可用时，能否从源区迁移逐燃料小时形状，并把每类小时预测重标定到目标月总量。这个信息在现实中要等目标月结束并发布月报后才可得，因此本协议评估的是**月后小时重建**，不是月初/日前预测。

## 数据和划分

- 使用项目原生EIA-930平衡区数据；2025年作为源期，2026年1–6月作为目标期。
- 固定V202因子：煤1000、气400、油800、其他化石400、核/水/风/光0 gCO₂/kWh。小时标签由同一EIA小时发电结构机械计算，不是独立计量CIF。
- 24个平衡区满足源月和目标月完整性门槛，共135个目标区月。目标区2025全年小时历史不进入其水平模型、供体或校准；源校准区再做嵌套留区。
- 目标月实际燃料边际只作为月后可用粗信息。目标区小时发电量、小时燃料份额和CIF标签不参与目标预测。

## 冻结比较

1. `source_shape`：V215同类的跨区月水平回归＋组成近邻小时CIF形状。
2. `monthly_constant`：把目标月已知燃料边际对应的月发电加权EF常数用于每个小时。
3. `coarse_margin_shape`：目标月只提供火电/核/水/风/光五类边际；供体决定火电内部煤/气/油/其他分配，再迁移星期×小时的分燃料形状。
4. `fine_margin_shape`：目标月提供八类分燃料边际，迁移供体分燃料小时形状。

供体固定为按Bray–Curtis近邻排序的前10区。小时形状先在星期×UTC小时格内汇总，再映射到目标月；每种燃料分别归一化，使月度边际精确满足。某燃料在供体中完全无小时支持时，使用月内均匀形状回退。该回退是算法定义的一部分，不用目标小时补齐。

每种方法单独用嵌套留两区源残差的绝对误差90分位校准对称区间。指标按地区等权、再按可用月份等权；地区为配对bootstrap单位，20,000次重采样。主指标为小时MAE、90%覆盖、平均宽度、Winkler-90和最差地区覆盖。

## 预先解释边界

即使全八类月度边际已知，它们也只约束各燃料整月电量，不决定燃料在小时之间如何分配。五类“火、水、核、风、光”中的火电合计更不能唯一确定煤气结构。小时预测要依赖供体迁移假设。若覆盖没有达到名义90%、区间分数未优于强基线或最差地区仍失败，候选不晋级。
