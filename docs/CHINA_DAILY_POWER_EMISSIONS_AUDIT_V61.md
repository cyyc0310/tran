# V61：中国省级日度电力排放是否提供了本地时间形状？

日期：2026-10-27。对 Zenodo 数据集 DOI 10.5281/zenodo.4730175 中2019–2020年31省日度 Power CO₂ 排放工作簿做了原始数据审计；脚本 `scripts/audit_china_daily_power_emissions.py`，原始 xlsx、Zenodo API 收据、文件哈希、744个省份-月份诊断位于 `results/china-daily-power-emissions-audit-r1/`。

## 直接观测到的结构

工作簿有 Power2019、Power2020 两张表，共731天、31省日度 power CO₂ 估算；省份日值和表中的省级和列逐日相符（浮点误差约1e−13）。但在每一年、每一个月里，31省日度排放序列归一化后的日形状与全国日序列相关系数全部约为1。等价地，`省日排放 / 全国同日日排放` 在同月内几乎常数：744个省月的最大变异系数仅 **4.4e−15**。

这不是模型发现了31省共享同一真实调度规律，而是数据构造机制的可见指纹。相关ESSD讨论稿明确说明，先用Carbon Monitor估算全国日度电力排放，再按省份当月火电份额缩放；审稿意见指出日际省间变化完全继承全国估算，作者也承认该方法难以体现省份自己的日际差异，局限尤其在电力与工业部门。该讨论页面还标记论文修改稿未获接受。[数据集](https://zenodo.org/records/4730175)、[方法与公开审稿记录](https://essd.copernicus.org/preprints/essd-2021-153/)。

所以这份旧日度表**不能作为目标省本地日变化标签，也不能验证日度/小时CIF迁移**。把它和省级月发电量相除只会得到带有共同全国日形状的日度比例；它不增加独立的省内时序观测。它仍可作为演示“已发布高时间分辨率估算值可能并未增加本地信息”的负例。

## 更新的日度数据线索

2026年《Advances in Applied Energy》研究提出2019年以来的31省近实时日度排放框架，再与CEADs年度排放校准拼接至2000–2024年。我们下载的论文补充材料位于 `results/china-cm-china-daily-method-audit-r1/supplementary_information.docx`，SHA-256 为 `ca6253779d50785c06661ea61b930f106339405d0693a2c68f934b406623fc3f`。SI Note 1说明：以2021年国家电力排放基线按各省月度火电量分配，再用中国煤炭运销协会（CCTD）逐日动力煤消耗重分配；日度消耗只有25省，其他6省沿用25省平均日形状。研究报告五个可评估缺口省（青海、云南、北京、天津、甘肃）的电力日度估算不确定度为±73.3%，其余多数省为±23.8%。

这提供了一个**候选最小本地日度信息**：逐省动力煤消耗/火电活动的日形状，比“全国日度曲线×省级月份额”多了一层地区差异；但它仍只是把日度排放估算到日，不能识别小时燃料分配和小时 CIF。该日度动力煤信息不是用户确认的公开月/年统计字段，论文数据按请求提供，也不构成公开复现benchmark。[论文](https://doi.org/10.1016/j.adapen.2025.100260)、[全文与数据声明](https://hub.hku.hk/bitstream/10722/369979/1/content.pdf)。

## 月度统计用于“预测”还是“事后分解”

需要把用户确认的月度全电源发电表放进明确的发布时点。国家统计局月报说明其发电量统计覆盖“规模以上工业企业”（年主营业务收入门槛为2000万元），且统计范围会逐年变化；2026年9月报告在10月20日发布。国家能源局对其月度全国电力统计数据给出的常规发布时间为每月20日左右。因此，目标月实际全月发电量不能作为该月月初/日内真正前瞻预测的免费输入；若模型条件于目标月最终月度燃料总量，科学任务应称“给定已知月边际的小时分解/重构”，而不是对该目标月的无条件预测。若要声称当时可用预测，需以此前月份或归档发布时的月度预测版本为输入，并保留发布日期与修订版本。[国家统计局2026年9月能源生产报告](https://www.stats.gov.cn/english/PressRelease/202610/t20261020_1965661.html)、[国家能源局统计发布答复](https://www.nea.gov.cn/2021-03/03/c_139779939.htm)。

这也影响口径：用户手中的表若确实覆盖煤、气、油、核、水、风、光等所有类别，仍须核对是否包括规模以下、自备电、分布式光伏、跨区输入以及燃料分类与总量是否同边界。Ember当前省级月表是可复现的二次数据快照，但其方法融合多来源并估算/调整部分类别，不能仅凭字段完整就视作逐省原始官方实测。应将官方月度统计、用户原表、Ember校正表分开作为不同数据版本和估计对象，而不是拼接成一个无修订的“真实月表”。

## 对下一步的影响

1. 不再把旧Carbon Monitor日度省级排放表当成本地日度观测输入。它的省级日形状是全国形状的确定性缩放，日频字段名掩盖了有效信息分辨率仍为“月度本地水平 + 全国日变化”。
2. V59指出小时总发电量时间序列是可识别界大幅收窄的关键；这份旧数据没有省级小时或独立省级日发电分母，无法提供该缺口。
3. 2026近实时框架指出本地日度动力煤消耗可能是改善省级日形状的附加信息预算，但数据不公开且部分省用全国平均日曲线补齐；其日度排放估算不能替代小时CIF标签。
4. 2026近实时框架指出本地日度动力煤消耗可能是改善省级日形状的附加信息预算，但数据不公开且部分省用全国平均日曲线补齐；其日度排放估算不能替代小时CIF标签。
5. 月度目标月真实发电量在常规发布时间前不可用。实验必须分别命名“目标月边际已知的事后小时分解”和“仅用预测时可得信息的小时预测”；前者不能充当后者。真实前瞻回测还要对齐数据首发/修订时间，并说明统计覆盖是否包含完整区域电源。
6. 目前公开月表支持月度燃料构成/水平研究；高频目标风险验证仍需不同于源区共享全国时间模板的本地日/小时真值。论文创新可继续围绕信息预算的部分识别、有效分辨率审计与失效诊断，但尚未形成新的预测算法突破。

这是数据来源与信息量审计，不是预测实验，不改变此前冻结的目标地区名单或小时模型结论。
