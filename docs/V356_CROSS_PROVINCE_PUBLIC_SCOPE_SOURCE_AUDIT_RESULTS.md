# V356：跨省公开电量来源与统计范围线索

检索日期：2026-10-30。V355只核了河南。本轮再查国家统计局、国家能源局派出机构、省能源局和省统计局的公开来源，判断“多源口径账本＋动态残差”是否值得进入实际小时风险计算。用户随后提供了国家统计局[分省月度数据入口](https://data.stats.gov.cn/dg/website/page.html#/pc/national/fsMonthData)，确认可直接选择省份查看。该入口应作为后续中国省级基准的官方主入口；本地V320/OREO派生CSV仍只是已整理数据，尚不能等同于本项目对官方接口逐省逐版本的原始拉取审计。本轮尝试静态抓取、浏览器打开和HTTPS直接读取均遇到官方站连接关闭/JavaScript页面限制，未声称已从入口下载数据。

## 云南同频率总量—分类配对

云南2024年官方能源简报明确给出全省全部发电量、规上发电企业发电量，再列水/火/风/光类别；这些类别相加等于规上发电量而非全部发电量。例如1—11月类别和为4036.77亿千瓦时，恰等于报告的规上总量；全部发电量为4288.04亿千瓦时。因此剩余251.27亿千瓦时（25.127 TWh）是**全部发电量减该报告所列规上分类总量**，占全部发电量5.86%。年度数据也显示全部发电量4646.35、规上发电量4362.91亿千瓦时，相差283.44亿千瓦时（28.344 TWh，6.10%）。

多个累计节点下的“全部－规上”缺口均为正且递增：1—7月136.54亿千瓦时；1—8月171.19亿；1—10月222.48亿；1—11月251.27亿；全年283.44亿。按官方同一来源差分，节点间缺口增量分别为8月34.65亿、9—10月51.29亿、11月28.79亿、12月32.17亿千瓦时。1—7月之前尚未找到同一来源的可分类累计节点。

本地NBS派生月度分类序列在相同累计节点上，比云南能源局披露的规上总量低：1—7月差31.79亿、1—8月差35.50亿、1—10月差53.74亿、1—11月差62.09亿千瓦时，约为官方规上量的1.2%–1.5%。因此官方全部总量减本地NBS分类量的合成残差分别是168.334、206.685、276.223、313.359、345.693亿千瓦时（依次为1—7、1—8、1—10、1—11、1—12月）。这一残差大于同一云南报告的全部—规上差额；两者相差正是NBS/能源局规上数据的跨源偏差及类别闭合差。它包含实际范围外电量与来源/版本差异两项，不能混称为“规下电量”。

云南2023年地方统计公报的能源产品表也报告全年总发电量4151.01亿千瓦时和水/火/风/光电量；云南省统计局同期明确规上工业发电量3905.06亿千瓦时。这是年度口径差值的第二个地区案例，但不能从年度数据恢复每月残差。其“全部”与“规上”报告名词可以相互检查，实际进入模型仍优先使用同一年度能源简报的配对数据。

## 科学判断

出现了比单纯增加月度类别更有潜力的中国信息渠道：云南官方重复观测到全省总量和一个统计子总体的累计发电量，两者之差随时间累积，并能给出数个区间的残差质量。它为“粗统计总量缺口到小时尾风险的质量约束传播”提供了真实公开数据来源，而非人为设置的误差盒。该方向尚非突破：累计报表稀疏，规上源间仍不完全一致，残差的技术类型/EF/小时形状未知，无本地真实小时CIF标签。V357将先检验稀疏累计节点能否在严格匹配其他假设时缩窄部分识别集合；任何正结果仅说明集合价值，不代表预测覆盖或算法原创性。
