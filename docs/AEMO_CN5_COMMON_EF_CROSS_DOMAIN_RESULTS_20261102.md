# AEMO跨域迁移的统一固定因子标签敏感性结果

日期：2026-11-02。按[冻结协议](AEMO_CN5_COMMON_EF_CROSS_DOMAIN_PROTOCOL_20261102.md)，复用已封存的US/GB→AEMO预测，将原生注册CO₂-e小时代理替换为与EIA/NESO源端使用相同固定燃料因子的重建发电代理。该实验只评估标签口径敏感性，不重训模型；不是官方小时CIF、实测排放或盲区确认。

## 样本与复核

- 原预测SHA与AEMO输入快照均匹配`aemo-cn5-cross-domain-transfer-r2`封存记录；模型、偏差和尺度完全复用。
- 逐DUID按注册燃料映射至煤/气/油/其他/水/核/风/光，应用源端固定因子。每个AEMO区域2023标签完整覆盖8,760小时、无重复小时；逐月文件严格按本地月份过滤。
- 主评分与原生代理取相同小时并要求新标签燃料支持率≥99%。共21,663地区小时：NSW1 7,253、QLD1 7,076、TAS1 7,334。九国/系统的目标地区选择在看小时分数前已由原协议冻结。
- 统一固定因子标签与原生注册CO₂-e代理在同一小时上的相关系数为0.99969，平均绝对标签差53.90 g/kWh。两者共享年内变化形状，但有效因子水平有系统差异。

## 解释与方法决策

1. **AEMO失败不只是标签因子表造成。** 统一固定因子标签与原生代理高度相关，但源模型在两种定义下都大幅欠覆盖，且主要失败集中在NSW/QLD。标签定义会明显改变绝对MAE和覆盖，却没有消除跨域风险。
2. **US+GB粗Ridge是值得保留的点误差候选，不是可信预测器。** 它在此单一目标系统上改善宏MAE、Winkler和宽度，但热电区覆盖极低，目标输入又是由同一回顾性SCADA生成的`t−2`份额。此结果不足以冻结算法或声称跨域概率可靠性。
3. **不能用三地区宏覆盖代替最差域检查。** TAS近零热电时强度容易预测，显著抬高宏覆盖；主论文须分别报告高热电目标、近零目标和最差区域风险。
4. **消费侧仍未测试。** 本标签只按本地发电燃料生成固定因子，不含跨区流量或送端来源强度，不能外推到消费CIF。

结果目录r2在全时段标签文件审计中发现月界重复，因此被标记无效；r4加入本地月份过滤后，每区恰为8,760个不同小时。r2与r4在原预注册评分窗的逐地区指标完全一致；r5再保存逐小时分燃料出力，分数保持不变，故以r5为正式结果。独立复算确认燃料量闭合与固定EF标签公式成立，逐区指标和封存指标最大绝对差为1.9×10⁻¹²。首轮时间类型合并失败及中间修订均保留在独立目录，不纳入分数。

证据见[运行清单](evidence/aemo-cn5-common-ef-cross-domain-r5/README.md)。r5在r4基础上额外保存逐小时燃料组出力和排放分子；标签与评分数值逐项一致。下一步先将统一EF标签作为来源/标签稳健性消融并更新双轨研究矩阵；在找到至少一个独立目标系统、同口径且能维持目标域覆盖的复制结果前，不冻结coarse Ridge新方法。
