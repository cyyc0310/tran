# 冻结时间外复核：总发电量趋势候选的九国2025 CN5回测

冻结日期：2026-11-01。当前Energy-Charts国家列表中，除乌克兰数据止于2022-02外，其余国家均出现在项目既有Carbon Monitor日尺度结果，故无可用、完全未查看的Energy-Charts国家。为检验新趋势候选的时间稳定性，本协议改用九个已见国家全新目标年2025；它是时间外复核，**不是地理盲确认**。

## 冻结模型与数据

- 唯一候选为[开发中冻结的总月发电量趋势HGB](CN5_TOTAL_VOLUME_TRAJECTORY_PROTOCOL_20261101.md)：现有严格CN5历史特征加六个月总量对数斜率/近期变化，两特征公式及HGB参数固定为[运行代码](../scripts/run_cn5_total_volume_trajectory.py)。
- 同队列强基线固定为：五类比例重组、因子历史HGB、燃料份额HGB、anchor700；另报告总量趋势因子头作辅助消融。
- 九折逐国留出；源国2022训练、源国2023H2校准、目标国2025评分。2025目标年、九国全体及输入版本在评分前不得用于调参、选模或删月。
- 2025小时数据仅经Energy-Charts API公开的`public_power`接口取得。目标特征严格只由预测月份`t−2…t−7`五类月量和日历构造。所有基线使用相同完整目标小时。
- 预测前元数据预检发现SK 2025响应不含`fossil_hard_coal`系列。沿用数据读取器既有“API未返回该生产类型即按结构零处理”的固定规则，只对SK 2025该项置零并在审计表明确列示；若其余映射必需字段缺失，整体停止评分，不按标签结果调整映射。
- 原始target文件、数据发布元数据及逐国映射哈希固定；先封存九国所有逐小时预测与来源区间半径、校验哈希，再读取2025目标细燃料标签并评分。

## 门槛与报告

报告源映射/缺失时段、每国合格小时数、MAE、日内形状MAE、来源校准半径、90%经验覆盖/宽度/Winkler分数，以及目标细燃料份额/热电有效EF机制误差。必须逐国列结果，不用小时数替代独立国家数。

只有候选在2025仍相对份额HGB保有方向一致的proper-score改善、区间宽度不增、宏覆盖不退且困难域不显著恶化，才把它保留为值得做未来新地理复核的方法候选。当前开发增益仅约2%，低于建议的5%实用门槛；因此即使时间复核成功，也不得据此宣称新算法普遍成立或已可信迁移。2025 API输入为当前响应/修订状态，不是历史as-issued月报；小时标签为固定EF发电侧代理，不是官方消费CIF。
