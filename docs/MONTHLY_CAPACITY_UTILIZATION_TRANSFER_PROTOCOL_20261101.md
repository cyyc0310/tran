# 滞后月发电量与年度装机归一化利用率的跨国迁移实验

冻结日期：2026-11-01，预测运行前。该轮推进优先级2/3：检验中国可见的月发电量与年度分技术装机结合后，能否提供比粗组成和静态装机结构更可迁移的火电运行状态信息。它不预设新增特征会改善结果，也不把输入工程单独称为算法创新。

## 数据队列与时间预算

- 使用既有Energy-Charts NL/ES/BE/AT/SE 2022–2024小时发电面板，逐国整国留出；2022训练，2023H1源端校准，2024目标评分。五个目标国均已打开，只作开发集。
- M：目标月份只读准确`t−2`及更旧的火、水、核、风、光月发电份额。月统计由当前修订小时数据聚合，代表信息预算模拟而非历史as-issued档案。
- C：增加Eurostat年度`TOTAL`、`CF`、`RA100`、`N9000`、`RA300`、`RA420`装机。容量只取预测年两年前统计年份（2022目标输入映射2020容量、2023源校准映射2021、2024目标映射2022），不作容量硬上限。原始API为当前修订值，无历史发行快照。
- 对预测月p和月报月份m=p−2，技术利用率定义为`u[g,m] = generation_mwh[g,m] / (capacity_mw[g, year(p)-2] × actual_local_hours[m])`。另含总发电量除以总装机的系统利用率。利用率与差分`u[g,p−2]−u[g,p−3]`仅作为软特征，不裁剪到物理范围。热电和核电的Eurostat技术组边界分别包含可燃燃料、核及其他燃料，与小时生产类别存在小口径差异，需作为测量误差解释，不能视作精确容量因子真值。
- 用预测年的统计年装机去归一化已知滞后月量，不以目标未来月份发电或容量作为输入；每个`year(p)-2`容量行和`p−2/p−3`月量均在本协议固定的预算内。缺容量、缺月量不前向填充；记录并按共同有效小时评分。

## 配对模型消融

同一2022源小时响应、2023H1风险校准和2024目标小时上比较：

1. M强参考：比例重组、因子历史头、直接历史头。
2. M+C结构：现有热电装机占比容量头；新增五类宽技术装机占比`C_share`的直接HGB、火电因子HGB和Ridge。
3. M+C利用率：在M+`C_share`上增加`t−2`五类容量利用率与系统利用率，分别训练直接强度、火电有效因子和Ridge。
4. M+C动态利用率：在M+C利用率上再增加`p−2`相对`p−3`的六类利用率变化，训练同样三种头。

HGB沿用已冻结的80轮、15叶、最小叶100、L2=10和seed416；Ridge沿用alpha=10并以训练样本拟合标准化。所有训练/校准按国家等权。因子头用同一粗月小时热电形状乘预测有效热电因子；直接头预测固定EF小时响应。目标2024标签不参与特征、拟合、选择或区间校准。

区间沿用来源2023H1绝对残差90%国家等权半径，对预测分布不作额外调宽。报告宏及逐国MAE、去日均形状误差、90%覆盖、宽度和区间分数；同时给出最差国家，特别关注荷兰。不能以平均覆盖代替地区覆盖，也不能把增加宽度造成的覆盖提升称为效率改进。

## 晋级与解释

因子利用率路径只有在整国外层相对`ratio_recomposition`、既有`factor_history`和单一容量占比头有稳定点误差增量，同时覆盖和区间分数不恶化、最差国不继续严重欠覆盖时，才冻结为候选机制。容量归一化输入有增益，只能支持“装机归一化月运行状态有跨国信息价值”；算法创新仍需独立新国家确认和与简单容量结构/标准模型的公平对照。达不到则保留负结果，不打开新的确认国家。
