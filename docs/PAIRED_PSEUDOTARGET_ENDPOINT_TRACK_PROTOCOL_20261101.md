# 双标签轨伪目标端点同队列重评分协议

冻结日期：2026-11-01。研究问题：源端伪目标残差修正能否在相同US→GB目标小时、相同月统计臂和相同2023H2留BA校准合同下，改善固定EF发电侧响应与官方消费侧响应？

## 已封存预测配对

- 基线来源：此前US BA留一交叉拟合伪目标实验，2022训练，2023H1留BA选修正/收缩，2023H2留BA校准，GB 2024目标。
- 发电侧标签轨：使用[生成侧代理残差封存](evidence/pseudotarget-recomposition-residual-generation-proxy-r2/README.md)；响应为NESO小时燃料发电量经固定EF形成的代理强度。
- 消费侧标签轨：使用[官方消费侧伪目标封存](evidence/official-pseudotarget-recomposition-residual-r1/README.md)；响应为NESO官方估算的消费侧强度。
- 输入臂：小时回算粗月量、EIA-923 BA五类粗月量，均模拟精确`t−2`。
- 对照：同封存文件内的source mean、calendar/coarse Ridge/HGB、M+C容量Ridge/HGB、固定EF小时重组，以及残差Ridge/HGB修正。
- 目标评价：取GB 2024完整目标年；使用封存预测对应的源2023H2留BA `bias/sigma` 校准参数，逐月按原评分函数复算MAE、日内形状MAE、Gaussian CRPS、90%覆盖、区间宽度和区间分数。

## 配对与重现审计

伪目标预测与双标签端点回放必须行数、UTC时间戳、观测月逐项一致；七个基础预测列须逐浮点相等。复评分须与相应原始逐月指标文件最大差异小于`1e-10`。任一检查失败即中止，不做跨实验比较。

GB→US未在伪目标修正中复制：GB只有一个全国源系统，无法生成地理留GB伪目标任务。本次不把按时间切块重新命名为独立地理伪目标，也不据此宣称方向对称。

## 边界

目标2024已在既往开发中查看，本轮属于对已封存预测的同合同审计，不是新样本或盲测。标签轨的定义保持独立，固定EF发电代理不等于官方消费强度；后者包含NESO自身的估计与跨域电力核算。当前EIA-923版本是最终档案滞后模拟，不是历史as-issued版本。GB单源意味着伪目标方法只支持US→GB结论。
