# 源端校准年度装机的留BA诊断协议

冻结日期：2026-11-01，计算评分前。前一轮结果显示，把煤/气装机份额直接转换成火电因子会伤害US↔GB预测。本诊断检验一个较窄的问题：源域是否能学会校准这个容量代理。

## 数据和切分

- 使用已看过的7个EIA平衡区，逐小时燃料量聚合出2022、2023每BA的年度火电有效因子；年度煤/气容量份额固定采用公开2020值。
- 对每个BA分别留出：其他6个BA的2022年度值拟合普通线性关系 `thermal_ef ~ coal_capacity_share`；仅预测留出BA的2023火电有效因子。容量恒等锚为`400 + 600 × coal_capacity_share`；常数参考为其他6个训练BA的平均2022因子。
- 报告每个留出BA的误差与7区等权MAE/RMSE。模型没有截距/斜率超参数搜索；预测因子截断到物理代理因子的400—1000范围。

此为源国内留区诊断，不是独立国家测试，也没有目标标签封存。它只决定是否值得把源端校准容量特征带入后续跨国开发。该因子标签由固定燃料因子与公开小时发电量构造，不是官方CIF真值。
