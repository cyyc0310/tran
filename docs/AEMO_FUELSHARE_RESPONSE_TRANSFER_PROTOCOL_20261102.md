# AEMO跨域燃料组成响应头复核协议

冻结时间：2026-11-02，评分前。版本1.1在任何候选预测或目标标签评分前加入已有原实验中的`coarse_boosting`对照（同预算直接小时响应强基线）；其余数据、模型和门槛不变。问题：严格CN5源端训练的小时燃料组成响应头，能否在AEMO发电侧小时代理上超过直接CIF头、固定火电因子和五类强重组？

## 解释边界

AEMO目标域及2023代理标签已在此前跨域实验中查看；本轮是**顺序方法复核**，不是盲地理确认。其新增信息是对先前已在严格CN5/葡萄牙检验的`fuelshare_history`候选进行同一AEMO样本上的新模型对照。目标标签为统一源端固定EF后的发电侧代理，而非AEMO官方小时CIF、实测排放或消费侧CIF。

## 数据和信息合同

- 源域：已有EIA US七BA与NESO GB小时燃料量，2022用于训练、2023用于来源校准。分别运行US-only、GB-only和US+GB三种源配置，与原AEMO五组跨域实验一致。
- 目标：AEMO 2023年3月至12月，严格按已有标签支持协议，仅纳入NSW1、QLD1、TAS1三个主区域。预测时目标输入由AEMO实际燃料量回算出的`t−2`五类月统计和日历构成；这是回顾性目标信息重建，不是真实as-issued发布。
- 目标响应使用原实验已封存并独立核验的共同固定因子小时发电代理。不得将注册机组原生CO₂-e标签并入同一个目标列。
- 燃料组成头四个源监督份额使用`coal, gas, oil, other`热电量权重，采用已冻结的四头HGB、非负单纯形投影；得到小时有效热电因子后乘同一源小时模型给出的目标热电小时份额。算法参数和严格CN5特征合同与`fuelshare_history`完全相同。
- 目标固定EF标签只能在目标输入预测和偏差/尺度、输出文件全部封存并核对哈希后读取。

## 对照与评分

与已有同源配置、同目标月份、同一可评分小时配对：`coarse_ridge`、`coarse_boosting`、`coarse_recomposition`、`source_thermal_ef`和`anchor700`。已有基线预测及封存哈希必须核对；不得按AEMO结果改模型或标签支持。

使用原AEMO来源校准流程：每个来源区域先计算2023全年误差均值；各区等权确定偏差，再基于移除该偏差后的误差计算区间标准差。对候选使用相同流程。报告逐区等权MAE、日内去均值形状MAE、90%高斯区间覆盖/宽度/区间分数与每个区域指标，分别查看NSW1、QLD1和TAS1。所有结果作为回顾性压力复核，不宣称概率覆盖保证。

候选只有在共同固定EF标签上同时满足以下条件才保留为跨系统增量线索：宏MAE较`coarse_recomposition`和`source_thermal_ef`都至少改善5%；区间分数较最佳同输入强基线改善至少5%；宏覆盖不降低超过2个百分点；NSW1和QLD1任一均不得以极低覆盖换取宏平均收益。候选若未超过这些门槛，不对该目标继续调参。

## 复现和停止

保存协议、脚本、来源文件、AEMO逐类小时输入与共同固定EF标签的SHA-256；所有模型预测、来源偏差/尺度和预测清单先封存再评分。哈希、行数、小时唯一性或共同支持不符时，本轮无效。若候选未达门槛，保留结果作为负向跨域证据，不送未查看地理确认；下一方法确认必须另选全新小时响应域并冻结参数。
