# 跨拟合伪目标残差的源端收缩协议 r2

2026-11-01，运行前冻结。r1的未收缩残差修正没有改善五国外层结果，源H2交叉验证也显示误差上升。r2只检验源端伪目标能否识别并抑制负迁移；不使用外层目标标签选择收缩比例。

## 数据与训练任务

沿用[r1协议](CROSS_FITTED_PSEUDOTARGET_RESIDUAL_PROTOCOL_20261101.md)的Energy-Charts五国整国留出、2022训练、2023源伪目标与2024外层评分。源模型对每个伪目标国留出训练，训练只见其余源国2022小时监督，预测时只使用日历及t−2和更早的粗月组成。残差模型与未收缩r1相同：Ridge(alpha=10)或固定参数HGB，训练标签为伪目标2023H1的小时强度误差。

## 源端选择与风险校准

对每个外层目标折，所有伪目标国2023H2的基点外推与残差修正都采用来源国留出交叉拟合：预测伪目标国`c`时，基点训练排除`c`，残差修正器也不使用`c`的H1伪目标任务。

对每类残差修正器单独选择全局收缩`λ∈{0,.1,.25,.5,.75,1}`：以每个源伪目标2023年7–9月的MAE计算，先在各国家内等月，再对伪目标国等权，选宏MAE最低的λ；并列时选较小λ。随后只用10–12月的交叉拟合伪目标绝对残差，按国家等权校准90%对称区间。目标点预测为`p0 + λ·rhat`，λ=0必须逐值等于强比例重组。

最终外层目标预测使用四源国2022训练基点和所有源国交叉拟合的H1残差任务。点方法与区间校准规则均在目标预测前固定；所有外层2024预测封存后才读取目标标签。

## 比较和判据

报告源端λ选择及各候选MAE、外层逐国/宏MAE、形状误差、Gaussian CRPS、90%覆盖、宽度、区间分数。比较`λ=0`强比例重组、源端选择λ的两种残差模型、r1未收缩残差模型、固定火电因子和直接CIF头，以及既有粗组成门控专家。

晋级条件沿用r1：相对强比例重组及门控专家至少5%宏MAE改善、形状不恶化、覆盖宏≥88%且最差国家≥85%，区间宽度不增加。达不到则停止此类残差修正，不在目标国上再调λ。已打开的五国只是开发目标，不是独立确认。

## 标签和统计限制

目标标签是固定因子发电强度代理；t−2统计由修订小时量回算，不是as-issued发布版本。该实验能检验跨国冷启动训练合同，不能证明中国真实CIF精度。
