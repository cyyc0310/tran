# 正排放组总量需要多细的本地时间分辨率？

2026-10-27，Sol。对已查看的七个 EIA 代理区 2022–2024 H1，做了小时、3/6/12/24 小时和月级的信息分辨率阶梯。有效样本为90,168小时。所有新增正组总量均由目标区真实细数据聚合，属于回顾性 oracle 信息价值上限，不是中国公开数据或预测实验。

## 信息合同与界限

每小时已知总发电量`G_h`，并额外知道对应时间块内正 EF 组总发电量`P_B`。正 EF 组定义为项目代理中的煤、气、油、other，固定因子范围400–1000 g/kWh；其余燃料因子为0。对于时间块内任一小时，正组发电量满足锐界：

`max(0, P_B − (G_B − G_h)) ≤ P_h ≤ min(G_h, P_B)`。

因此该小时 CIF 的锐界为`[400 P_h^L/G_h, 1000 P_h^U/G_h]`。这些端点在**此简化信息集**下可达到：它只给小时总发电量和块级正组总量，不给组内燃料配比、逐燃料月度库存、爬坡或机组约束。若加入逐燃料月统计，边界可能继续收窄；本实验没有计算交叉约束下的联合 sharp bounds。实际 CIF 全部落入区间，是代数校验，不是预测覆盖率。

在七区等权的逐区结果中，6小时信息在CISO、ERCO、FPL、ISNE、MISO、NYIS的平均边界宽度仍约999–1000；只有BPAT从月级1000降至430.6。逐小时正组量虽将七区的宽度压到43–422，但平均仍是实际小时 CIF 标准差的约2.4倍，且地区差异很大。这里宽度骤降的一部分来自6小时到1小时的分母约束直接锁定`P_h`，不能把它外推为概率区间同幅变窄。

## 对研究方向的影响

这个结果修正了“小时正组量会显著收紧边界”的粗略表述：**若仅能拿到6小时块级热组总量，通常不足以识别小时 CIF；所需信息更接近小时级正组出力。** 对目前只有月度各类别发电量的中国设定，无法据此声称小时点预测或窄区间可信。它为数据需求研究给出可检验阶梯，但没有算法创新，也没有证明 hourly P 可公开取得。

高价值下一步是把已知逐燃料月度库存与块级正组约束合并为网络流/线性规划锐界，量化当前月报类别对上述结果能收紧多少；再以新区域和真实可得字段检验部分识别区间与模型预测误差是否对应。只对已查看代理区的本轮结果不能替代这两步。代码和原始逐小时记录见`scripts/v51_coarse_positive_group_info.py`、`results/v51-coarse-positive-group-info/`。
