# 月度统计真实发布版本：可行性审计

日期：2026-11-01。目标是判断跨国模型训练能否使用“预测时真正已发布”的粗月统计，而不是从当前修订小时数据回算出理想化的 `t−2` 输入。本轮找到并验证美国官方 EIA 月报历史档案；这是一项数据合同审计，不是CIF算法或迁移性能实验。

## 美国：档案可还原州级 as-issued 月值

EIA 的[Electric Power Monthly 历史发行档案](https://www.eia.gov/electricity/monthly/backissues.php)逐月提供历史 ZIP 工作簿。2024年6月发行的工作簿含 2024年4月州级发电量；2025年6月发行再次列出同一个 2024年4月观察值，可直接做版本配对。工作簿按州和燃料列出煤、天然气、核、水、非水可再生等值，单位为千兆瓦时。它提供实际的统计时点与修订证据，不必用小时标签重新聚合来模拟该来源。

脚本对 51 个州／哥伦比亚特区行和 11 张表逐项配对。两次发行中共同为数值的 524 个州×指标单元里，217 个（41.4%）发生变化。总发电量在 51 个州均可配对，其中 49 个值后来变化；修订绝对值中位数 55 GWh，90分位数 148 GWh，最大 526 GWh。天然气 49 个可配对州里有 44 个发生变化，修订绝对值中位数 31 GWh。这里的差是 2024年6月和2025年6月两版官方表之间的修订，不是抽样误差或模型误差。

为衡量主要结构列的变化，另比较 43 个核心字段完整的州：煤、天然气、核、水电、非水可再生各自除以官方总发电量后，五项已观测份额的绝对变化和中位数为 1.57 个百分点、均值 2.70、90分位数 5.28、最大 14.80。该向量未覆盖石油、其他气体、抽水蓄能和其他能源，故是部分结构位移量，不能解释为完整燃料组成距离。缺失或被抑制的项目保留为空，没有置零。

上述样本表明：实际月报版本可以从官方历史包里机器读取；修订的影响在州级燃料组成上并非零。它也说明对回测特征使用今天的修订值，会与当时已发布版本产生可测差异。要把它转成迁移结果，仍须在同一地理单元上配对小时标签、训练输入和目标预算；本轮没有宣称修订已改变模型排名。

## 英国与中国：历史时点边界

英国 DESNZ 的[data.gov.uk 月度发行清单](https://www.data.gov.uk/dataset/a2d3f8c1-8f02-4f6d-956d-6ddc9c34fbc8/monthly_energy_statistics)留有逐月发布日期与发行页面。例如 2024-06-27 的发行页覆盖至 2024 年 4 月；该页明确说明ET表格链接始终指向最新数据表，历史表需联系DESNZ索取。官方当前说明ET 5.3/5.4/5.5月表通常滞后两个月发布，并称旧版Energy Trends可在历史发行集合中查阅，但这不等于旧版可下载工作簿。因此，公开网页能证明当时的发布时间与数据覆盖月，单靠公开下载链接不足以重建旧版月值；季度PDF或摘要也不能替代完整、机器可读的月表。详见[2024-06-27历史发行页](https://www.gov.uk/government/statistics/energy-trends-and-prices-statistical-release-27-june-2024)、[ET 5官方说明](https://www.gov.uk/government/statistics/electricity-section-5-energy-trends)及[Energy Trends历史集合](https://www.gov.uk/government/collections/energy-trends)。

这一区分影响论文中“信息可得”的定义：**发布时间可证，不代表发布值可复原。**在拿到带原始发行版本的工作簿前，GB官方ET结果仍属当前修订月表输入实验；不得包装成as-issued回测。若后续从统计部门取得历史表，应把原始文件、获取/发布日期、覆盖期和哈希封存，再同统计地理一致的小时标签配对后才进入性能评估。

中国国家统计局分省 API 面板审计（[V392](V392_NBS_OFFICIAL_LONG_PANEL_AUDIT.md)）拉取的是 2026-10-30 的当前历史序列快照，不含逐次发布版本/发布时间字段。1、2月还作为合并期发布。所以上海等省的回测月值仍是滞后月模拟，不是严格的历史 as-issued 回放。用户给出的月表字段可用于现在部署的特征合同，但不能仅凭当前面板声称复原过去某日看到的值。

## 对实验主线的影响

1. 保留已有 `t−2` 小时聚合实验，标签和指标仍有比较价值；将其明确标为**滞后模拟**，不称真实发布回测。
2. 增加独立的**发行版本信息层**：源训练只使用预测时点以前的官方原始版本，存档发行日期、覆盖月、数值状态、地区和分类映射、工作簿哈希。已发行但后来修订的值不可被当前版本覆盖。
3. 先在 EIA 州级数据上完成 source-vintage parser 与冻结输入测试；若无法把州粗量与已有 BA 小时标签一致映射，就把这项工作限于修订敏感性，不将州结果混进 BA 排名。
4. 对中国目标回测，公开历史月表目前不能提供旧版本。短期论文必须将该点作为数据限制；真正 as-issued 的中国确认需要从现在开始按月保存国家统计局原始响应和抓取时间，或找到可核验的历史公报快照。不可根据未来下载的当前历史序列反向填造发布时间。

因此，已批准的年度装机预算继续独立报告为 `M+C` 信息增量；它不能替代本轮发现的月报 vintage 约束，也不能把装机存量或修订后月量包装成小时预测创新。跨国论文的核心仍是：给定中国可公开月表/年度信息，外域小时监督学到的预测方法是否能在目标标签隔离下稳定转移；真实发行版本是该问题的可复现数据条件。

## 2026-11-02：NESO公开历史燃料数据的修订状态补充

按用户确认的“仅公众数据”预算，进一步核对了NESO公开历史燃料结构和需求文件。NESO的[Historic GB Generation Mix](https://www.neso.energy/data-portal/historic-generation-mix/historic_gb_generation_mix)页面称数据覆盖2009年至今、小时更新；同时明确表示数据会随清洗而改变。页面提供当前CSV/API查询入口，没有显示历史CSV发行包或逐条as-issued版本索引。该历史表还将嵌入式风电/太阳能、Other、电池、净抽蓄等归类在持续变化中，因此不能把当前回算小时燃料月量当作当时发布的同口径月报。

NESO的[Historic Demand Data](https://www.neso.energy/data-portal/historic-demand-data)进一步说明，历史需求数据约21天滞后发布，并可能在数月后回溯更正；页面按年份提供当前CSV。官方[API指南](https://www.neso.energy/data-portal/api-guidance)建议通过资源修改时间判断当前资源是否更新，但这不等于保留每次旧内容。我们没有在这些公开入口找到可下载的逐版历史快照。Elexon公开API虽列有半小时燃料发电量端点，但本轮未找到其公开历史版本归档，故不把端点存在解释成已具备as-issued回放。

**实验合同更新：**美国EIA EPM历史ZIP可支持真实首发月报回放；GB历史燃料份额目前只支持当前修订快照或滞后模拟。未来的美英测试需分别标注这两种输入时效，不能将双向实验合并称为完全对称的as-issued比较。若要建立GB未来as-issued队列，可从当前开始在每次公开更新时保存原始CSV/API响应、抓取UTC时间、资源更新时间、请求参数、原始哈希、燃料映射和统计期；旧版本无法从当前API反向补造。用户确认没有市场成员账号，因此交易平台的成员级历史曲线不进入预算。

本轮已从公开Datastore API开始留存前瞻快照：2026-11-02 03:19:34 UTC抓取了11月截至当时的51条连续半小时记录（Nov 1 00:00–Nov 2 01:00 UTC）；另于03:23 UTC前取得了按London当地月界查询的完整10月1490条半小时记录。资源元数据当时的`last_modified`为02:21:36 UTC。原始响应、查询边界、字段、抓取时间和SHA-256见[NESO公开快照证据](evidence/neso-public-hourly-snapshot-20261102/README.md)。该快照只是研究者开始归档的当前状态；它既不是预测曲线，也不证明原始观测在其标注时刻已发布。十月数据仅作为预测起点前可见的滞后统计量进入一组未评分的12月前瞻预测。后续如要形成真正的as-issued特征/标签对，需按固定频率持续保存更新版本，并在回测时仅使用预测起点前抓取的版本。
