# 月度统计对小时强度形状的预算等价反例（探索性检查）

日期：2026-11-02。此检查是发电侧“信息预算约束可行集合”方向的第一关，不是预测器、物理可行性证明或独立确认。数据为已看过的Energy-Charts严格CN5九国2024固定因子发电代理。

## 问题

只给每月五类发电量M、甚至再给年度技术装机M+C，是否足以确定该月的小时发电组合和小时CIF形状？如果存在不同小时轨迹，它们都满足同一粗预算，那么任何零样本点预测都需要额外源域假设；池化覆盖也不能由M/M+C本身推出。

## 诊断构造

对每个国家、2024年每个月，分别对各细分燃料标签的小时发电序列做独立随机置换，每月200次、固定种子`20261102`。这里直接保留的是**目标月实际总量**，比月初真正可得的`t−2`滞后输入更强，属于有意设置的oracle上界。该操作：

- 精确保留每种细分燃料及其上位五类的月电量；九国逐月最大闭合误差为0.0 MWh（浮点表精度内）。
- 仅重排该月原本出现的小时出力值，因此不超过原观察小时最大值；若年度装机只提供宽松功率上界，这些置换也不会因单点出力超过原样本上界而违反它。
- 计算固定燃料EF代理下的每小时CIF及总发电量分布。

它不约束爬坡、最小开停机时间、负荷、储能、网络潮流或天气可用性，故置换轨迹**不保证物理可调度**。这是一个“观测预算无法区分”的反例，而不是物理可行调度集合，也不应被用于CIF部署。月度数据和装机都不包含被置换的小时顺序；更强的、合法且可获取的运行约束可能缩小该反例集合。

## 解释

1. 月度五类电量加宽口径年度装机，并不携带小时顺序。即便把更细的源侧燃料月总量也保留，仍可构造大量具有完全相同月度信息的不同小时配置。
2. 置换下的平均逐小时CIF 5–95%范围为135.11 g/kWh，显著宽于真实小时CIF的国家等权标准差56.26 g/kWh。该差异证明**当前输入合同允许的替代时间排列很丰富**；它不是对实际中国预测误差的估计。
3. 平均总发电量分位数形状也能相差约690 MW，说明未知的小时分母/系统出力形状会与未知燃料组合同时影响CIF。发电侧只靠月电量和静态装机难以给逐小时精度作出可识别性保证。
4. 消费侧更缺少信息：年度省际OD矩阵不能确定月小时流向，缺送端来源排放强度时仍不能从发电侧结构推得消费CIF。现有年度OD可识别性边界见[消费侧审计](CHINA_CONSUMPTION_TRACK_ANNUAL_FLOW_DATA_AUDIT_20261101.md)。

对能与现有Eurostat库存配对的AT/BE/ES/NL/SE，再用2022静态五类功率上界检查2024目标月：60个地区月份中，每类月发电量都满足`E_f ≤ C_f × (H−1)`（对零容量且零发电组单独处理），最紧的有正容量组仍留有1.99%的月能力余量（ES）；五区各自跨月的最小余量比例为AT 56.99%、BE 19.81%、ES 1.99%、NL 4.87%、SE 3.09%。在“只用静态容量、非负出力和月总量”的简单集合里，每类月能量可在非目标小时容纳，因此静态M+C上界也不能强制目标小时必须有某种发电技术。该结论不加入最小出力、爬坡和网络约束，恰好说明若要把小时界收紧，必须有可审计的额外小时运行信息/约束。

## 决策和下一轮

可行集合方向值得继续做**信息价值实验**，但还不能称创新算法。下一轮在相同九国数据上，用线性规划把约束逐级加进月度燃料预算：

1. 仅M：月内各技术总能量与非负性；
2. M+C：再加入预测时可见的年度装机功率上界；
3. M加小时总发电量/负荷曲线：作为额外信息预算及oracle敏感性分别计算，不混进主预算；
4. 若前三项仍给出极宽边界，再判断引入源域小时形状先验能否在预注册整国留出上缩窄集合、且不降低真实目标小时落入率。

小时总量或实况负荷不是用户当前已确认可用的中国输入，必须标成扩展信息或oracle。当前oracle置换已提示仅靠月能量/静态容量的逐小时界会退化；下一轮LP先把逐时总发电量约束作为扩展预算，判断它能缩窄多少，然后再分析源域小时形状先验是否额外有效。若只有M/M+C界限仍近乎技术EF极值，停止把M/C说成可保证可信小时CIF的输入；此时论文价值是量化信息不足并提出需要的最小附加字段。所有结果仍须发电/消费分轨，不将CN5固定EF代理的诊断外推为中国实测精度。

## 复现边界

最初的置换诊断直接调用既有loader，并没有固化runner或启动哈希；它只用于提出预算等价反例。后续LP已另行写入冻结协议和完整runner，并保存机器逐小时区间及输入/代码哈希；LP仍是已看过目标上的信息值开发诊断，不能单独作为论文最终结果。

**后续LP信息审计已完成：**协议与runner现已保存；在额外给予目标月六组真实总量及小时真实总发电量的条件下，M+T*界宽仍为1000 g/kWh。再加2022粗装机的条件LP界宽均值830.38，但2024目标支持有613次功率超界，故不能据此宣称可信覆盖或装机带来可部署增益。精确样本、边界和修订决定见[LP结果](CN5_MONTHLY_BUDGET_LP_INFORMATION_RESULTS_20261102.md)、[协议](CN5_MONTHLY_BUDGET_LP_INFORMATION_PROTOCOL_20261102.md)、[脚本](../scripts/run_cn5_monthly_budget_lp_information.py)及[机器结果/哈希](../results/cn5-monthly-budget-lp-information-r3/summary.json)。
