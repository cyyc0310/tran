# V51 五类月报下火电内部有效 EF 信息价值实验协议

> 记录状态：该协议为数值实验后的归档说明，不是运行前预注册合同；所有结果均按探索性证据解释。

## 研究问题

检验五类月度发电统计（火、水、核、风、光的代理映射）是否足以迁移预测小时 CIF；若源转移失败，单独揭示目标月“火电组按发电量加权的有效 EF”能收窄多少误差。重点区分月类别总量预测误差、火电组内排放水平与小时形状误差。

## 固定信息合同与方法

- 代理类别：`thermal=coal+gas+oil+other`，另保留核、水、风、光。该映射只用于当前 EIA 类代理数据，不能视作已认证的中国“火电”定义。
- 合法 as-of 月总量仅取上一年同日历月记录，且要求 `period_end` 与 `available_at` 均不晚于目标月开始。
- 小时类别形状来自其余六个已查看地区 2024 年同月小时资料；每个地区先独立归一化，再等权平均。留出地区所有小时燃料序列不得进入预测。
- 基准火电有效 EF 为其他地区 2024 年同月火电组有效 EF 的等源平均。
- 另比较目标地区上一年同月已发布的火电组有效 EF，要求其原月报满足与五类总量相同的 as-of 门控。
- 依次比较六个分支：合法 as-of 五类总量＋跨源火电 EF；合法总量＋合法本地滞后火电 EF；合法总量＋目标月火电 EF oracle；目标月五类总量 oracle＋跨源火电 EF；目标月总量 oracle＋合法本地滞后火电 EF；总量与火电 EF 均 oracle。
- 再事后检查凸混合 `EF_mix=(1-alpha) EF_donor + alpha EF_local_lag`，`alpha∈{0,.25,.5,.75,1}`。外层留一源区，alpha 只由其余六源来源等权 MAE 选择。
- 目标月 oracle 量只用于事后信息价值拆分，绝不作为合法预测或可部署结果。
- 评分使用固定项目 EF `[1000,400,800,0,0,0,0,400] g/kWh` 产生的小时发电侧 CIF proxy，报告逐月/逐源 MAE、RMSE、bias。

## 判读规则

如果目标月类别总量 oracle 的边际收益小、而火电 EF oracle 的收益大，则跨源煤气油内部混合是比类别总量预测更关键的当前代理失效源；这只证明该 oracle 信息在已查看源上的条件价值，不证明中国实际字段可得、未来 EF 可预测或小时区间获覆盖保证。若两个 oracle 都不能解决误差，小时形状/日内火电组 EF 等剩余风险仍主导。

## 数据边界

七个源区与 2025H1 标签均已被多轮查看，部分来源仅有2或5个评分月；本实验是探索性机制诊断，不是预注册确认或新地区验证。合成 thermal 映射、项目 EF、来源小时资料与月报发布时间均不构成中国数据实证。要继续算法实验，必须用真实月报 schema 确认火电是否细分煤/气/油，或能否从同口径月度统计算得火电加权因子。
