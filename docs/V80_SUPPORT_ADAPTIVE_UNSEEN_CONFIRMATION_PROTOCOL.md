# V80：月报燃料支持自适应风险识别的未评分区确认

冻结日期：2026-10-28。V79在已开EPE/TIDC发现以地区-月活跃EF最大值M代替全局1000可大幅收紧K≥8识别集合，而L₁没有胜过同M的G²外界。V80冻结支持自适应候选，在V52质量普查合格、且此前未在TransCIF结果/脚本/文档中评分的CHPD、DOPD、GCPD、TPWR四区做确认。地区名单仅由V52质量清单减去既有17区、GVL、EPE、TIDC得到；不读这些区域CIF/尾计数选择。

固定窗口2024H2、2025H1、2025H2，阈值τ=100/300、目标K≥8/24h。每地区每半年要求≥80%完整UTC日（24个有效且连续小时）；地区名单固定，未达标窗口只记质量失败、不用风险结果换窗。每月M从冻结V54月表全部正燃料份额对应EF的最大值确定；月行缺失回退1000，不以小时或邻月填补。若M≤τ，所有可行小时均不超阈，K≥8自动不成立。

逐日比较四种支持/信息臂：全局M=1000完整G锐集；本地月度M完整G锐集；同M四块ΣG²必要外界；同M四块L₁摘要证书。L₁的每块充分条件为`H>τG +(M−τ)L₁`。检查实际K包含、集合嵌套、L₁不超出局部完整G证书。每个地区、窗口、τ报告证书率、同M G²差值、完整G可识别上限，不将地区日视为独立置信样本。所有量均为EIA固定EF同期代理；H/G/L₁仍需小时局部测量，M才可来自月度分类统计。本轮不能验证中国月度-only小时预测。
