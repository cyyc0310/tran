# V154：同预算小时条件强基线

冻结于V153后、V154评分前。复用V151/V153的两预算、两源划分、30 proper拟合源2024年、12独立校准源2024年和36个2025开发目标月。不得打开新地区或用目标标签选超参。

合法特征：八燃料份额、log总发电量、统计年龄、能源加权强度、月份sin/cos、UTC小时sin/cos、周末、煤/光份额与小时sin/cos交互。只从完整月统计或asof30天合法历史月构造。对proper源每地区2024合法小时固定最多4,096个等概率、不依赖标签的样本；随机种子由20261028与源身份生成。所有学习器共享同一样本，源地区总权重相等。保存抽样小时索引及哈希。

四类标准控制：

1. 月度水平+小时/周末残差模板；每个单元源地区等权。
2. 分布式ExtraTrees：32树、min_samples_leaf64、max_features1、random_state20261028、n_jobs2。预测分布是各树叶内源标签加权经验分布的等权混合，保留完整原子，精确计算其CRPS。
3. 异方差正态HGB：源地区按身份哈希分五折生成整区留出均值残差；拟合最终均值，并以Poisson deviance拟合残差²+25的条件均值（预测方差减25后取至少1）。HGB均100轮、learning_rate.1、15叶、min_leaf64、l2=1、early_stopping=False、seed20261028；标准差裁[1,500]、均值裁[0,1000]。以1,025个等概率中分位数离散并裁[0,1000]作为明确近似的概率模型，不把它称连续正态精确CRPS。
4. 同参数HGB条件分位数q05/q50/q95，重排交叉分位数并裁物理范围。仅评价区间/点指标，CRPS留空；三分位不能充当完整预测CDF。

所有臂按各自2024校准误差取地区等权pooled q90和max-region q90，沿用V151规则。报告逐区小时指标、宏与最差覆盖，月度分母及与V153小时池的比较。概率模型的CRPS是源校准前原分布指标，区间扩张不改变CRPS。CQR无CRPS，不声称在该指标胜负。

保存源抽样、区域折、校准半径、特征白名单、输入时间合同和哈希；检查角色、年份、共同分母、物理范围与分布权重。该实验旨在提高比较强度；标准回归/森林/模板均不作为原创。模拟发布、回顾性质量、生产侧名义EF代理限制继续存在。
