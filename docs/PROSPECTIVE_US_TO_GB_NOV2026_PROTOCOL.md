# US→GB官方消费强度前瞻预测：2026年11月

冻结于2026-11-01，在读取目标消费强度响应前。此项与已封存的GB→US EIA-923前瞻预测构成同月反向任务对；本轮只生成US→GB预测，目标响应成熟后再评分。

## 目标和预测起点

- 目标为GB/NESO 2026-11逐小时`CARBON_INTENSITY`官方估算。预测小时为UTC 2026-11-01 00:00至2026-12-01 00:00，共720小时；英国采用Europe/London当地日历特征。
- 模型源为美国七个EIA平衡区官方消费强度标签；2022训练，2023源校准。目标GB官方碳强度不参与训练、选择、校准或预测。
- 预测起点固定为2026-11-01 00:00 UTC。目标端只见截至当前NESO燃料数据中完整的2026-09月粗份额，即目标月t−2；不读取2026-10/11月月量或任何目标小时CIF。NESO历史发电值为当前修订快照，缺少可重建的历史发行版本，因此这是预测起点信息时序模拟，不声称原始历史as-issued回放。
- 预测所用类别严格五类：thermal=coal+gas+oil+other，hydro、nuclear、wind、solar。NESO半小时发电MW先按UTC小时合并，再将小时序列转到英国当地月历，要求观测月覆盖不少于99%。
- 同一目标信息上比较官方消费强度源均值、日历Ridge、五类Ridge、五类HGB、固定EF强重组、简单700×thermal锚，并增加独立M+C年度2020煤/气容量Ridge/HGB。M+C只作为嵌套信息预算，不替代M。
- 目标强度区间仅以美国2023源残差拟合，按源区域等权；无目标域覆盖保证。

## 先预测后评分

1. 读取NESO CSV时只选择`DATETIME`及燃料发电列；显式排除`CARBON_INTENSITY`。US源训练及校准响应仅取2022、2023文件。
2. 目标点预测、源校准区间、输入月量、代码/数据SHA全部写盘封存。
3. 2026-11结束且NESO独立小时响应成熟后，按原封存文件哈希评分一次；逐月/逐日、MAE、日内形状误差、CRPS、90%覆盖、宽度、区间分数和最差日/时段均报告。任何目标结果不回写当前预测。

## 解释限制

这是一个已见目标国的前瞻时间留出；区域与模型族曾用于开发，因此不是盲测地理确认。NESO `CARBON_INTENSITY`为修订官方估算，不是直接测量真值。此项与GB→US消费侧前瞻任务可以组成双向时间窗比较，但英国和美国响应定义及目标月粗月报来源不同，结果需分方向解释，不得合并成单一精度。单月前瞻成绩也不足以支持长期跨国泛化或区间覆盖保证。
