# US→GB官方发电强度：伪目标专家迁移协议

冻结日期：2026-11-02。本实验检验源区留BA伪目标任务能否选择小时专家增量，并迁移到英国；GB 2025目标已在既有开发实验中评分，因此本实验只属方法开发，不是独立确认。

## 数据合同

- 源监督：EIA-930七个美国BA官方生成CO₂强度，2022训练、2023H1伪目标选择、2023H2流程检查、2024源校准。
- 目标：NESO GB 2025 `intensity.actual`小时均值，目标月燃料仅使用严格滞后两个月的热、水、核、风、光五类份额及当地日历。
- 预测仅在源区训练与校准完成后生成并封存；目标响应在写出预测文件并保存哈希后读取。
- 标签源与核算边界不同，所有结果仅表述为机构估算强度迁移。

## 方法与比较

基准包括700 g/kWh热电锚、源域粗组成HGB、日历Ridge、组成Ridge、来源有效热电锚和源燃料响应重组。伪目标臂在每个留出BA上以其余六个BA训练粗组成HGB及嵌套留BA专家；仅以七个伪目标BA的2023H1宏MAE选择专家权重温度与回退系数。最终专家库以2022–23数据拟合；2024源域按BA等权校准偏差和90%绝对残差分位数。

选择网格为 `alpha ∈ {0,.25,.5,.75,1}`、`tau ∈ {.1,.25,.5,1,2,5,+∞}`；alpha=0必须逐点等于粗组成HGB。评价MAE、形状MAE、90%覆盖、宽度及Winkler分数，并按相同GB小时配对比较。只要目标没有同时优于简单锚和源重组的综合指标，就不把方法视为已获增量。

## 解释边界

这是在七个同一国家BA上的留区伪目标，不是跨国源伪目标到目标国家的独立证据。GB标签与燃料历史此前已用于方法开发；结果不能用于声称盲测或已证明可迁移至中国。中国公开月报中的“火电”合计与本实验CN5粗组之间仍有粒度差异，须在中国实际数据源上逐列审计。
