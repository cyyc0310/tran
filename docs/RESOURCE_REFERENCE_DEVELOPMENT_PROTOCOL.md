# 历史资源参照：先检验日尺度幅度信息

2026-10-31，Sol。状态：**完整五年气候已采齐并重验，600个本地年月；CIF实验待执行。** 这是查看[天气形状结果](COARSE_WEATHER_SHAPE_RESULTS.md)后的下一轮自适应开发方案，不是确认性预注册。下述具体方法在本轮预测和目标评分前固定。

目标仍是国外小时经验向中国式粗月报条件迁移。只修正小时形状没有稳定收益；事后幅度替换提示应先检验日尺度资源信息，不能据此推断新方法一定有效。

## 信息与时间合同

维持既有12个预报起点、9个跨国配置和624个唯一开发小时，保留月报、月报＋静态装机代理两预算。起点前GFS与无天气比较继续作为W1；新增历史气候为W2，不能把W2增量归入W1。各方法使用相同历史天气字段、源小时监督和源校准样本。

历史参照固定2016–2020五年，取与前轮相同地理点，不引入目标小时电量、负荷、CIF或开发日再分析。各年按地区当地月份汇总，再对五个年度月均等权；完整小时覆盖、闰年、DST与UTC边缘要验证。预报仍来自原生已签发GFS，不以ERA5替代。上海只作无标签接口探针，不能加入精度评分。

选择固定ERA5模型、UTC epoch、摄氏度、m/s、最近格点及禁用高程降尺度；保留原JSON、请求参数、检索时间、格点、单位和SHA。温度/风速按报告瞬时刻，短波按前一小时区间，计算月资源时分别转换支持时间。文档说明Best Match混合模型，故不采用默认选项。[Open-Meteo接口说明](https://open-meteo.com/en/docs/historical-weather-api)

不下载2022/2023实际天气去近似“月报对应月已知天气”。ERA5T与最终版可能相隔2–3个月；固定旧年减少信息时点冲突，但今天获取的修订档案仍不能证明历史原发布版。`eligible_for_issued_public=False`、`available_at=None`继续保留，不得把静态历史有效日期误作原始发布时间认证。[Copernicus说明](https://cds.climate.copernicus.eu/datasets/reanalysis-era5-single-levels?tab=overview)

## 最小对照与归因

风资源定义为逐小时`min(v100,25)^3`的均值，太阳能为短波均值。这些是资源指标，不是已知当地功率曲线。设`C_k(m)`为历史气候月份m的指标，`R_k(d)`为GFS预测目标日d的指标，m为该起点允许的滞后月报月份。

至少分开比较：

1. 原轨迹银行，不使用新增参照。
2. 纯季节比例`C_k(month(d))/C_k(m)`，识别仅由新增静态季节信息带来的收益。
3. 天气比例`R_k(d)/C_k(m)`，先做太阳能，再做风光；原始其他燃料不改。
4. 同预算普通源训练幅度响应，至少包含线性正则模型；源2022训练，源2023只校准，目标标签只评分。

GFS与ERA5的模型、分辨率和辐射支持不同，比例不是无偏真值。保留原比例，并加入仅用源样本估计系统偏差的普通校正参考；不得在目标小时标签上拟合格点或偏差因子。资源缺失/参照零值须输出显式不支持标记，并回到原银行；不按误差删除样本。比例为1的分支应逐值还原原轨迹，不使用未来日/月量强制守恒。

缺失回退具体覆盖气候参照整行缺失、非有限资源或零分母；原生GFS缺失/负资源在输入验证时拒绝，不删除这些小时后另报成绩。常规幅度模型以源2022实际日均发电功率／该源在起点允许的t−2月平均功率为训练目标。过去月功率直接由该源合法月电量除以预期本地月小时数构造，保存月份、起点、观测覆盖、电量及功率凭证；不能只验证归一化组成后假设绝对量正确。

固定10方法：原银行；太阳能/风光两种季节比例；太阳能/风光两种天气比例；源均值比校正天气比例；无天气/有天气两个Ridge幅度头；太阳能/风光两种天气幅度＋直接资源形状。所有幅度方法只改风光，其他燃料保留原路径，源未支持燃料维持q=1。直接资源形状是普通物理参考，不保证保留原风光小时风险；幅度乘子保持剩余供体路径，但不宣称修正后的尾部风险可靠。

Ridge强度固定10，响应为log1p幅度、输出expm1后截为非负；无天气头含日历、粗月报历史及气候季节比例，有天气头再增加当天资源比例与温度/度日。源国家、地区、日依次等权，有效燃料子样本重新计权。均值比校正为源真实幅度均值／预报资源比例均值，可能包含运行结构差异，并非纯天气模型偏差。无目标选强度或目标校准。小银行沿用1200源训练小时，完整源年银行作为额外源标签轨道；九个幅度头在两轨道共用，不以两轨道差值宣称机制增益。

先做幅度单独修正，再检查幅度＋已有小时形状参考；不扩大强度、截断值或门控网格。完整源年银行是额外源标签轨道，与小银行各自有匹配基线，避免把更多外国监督的收益归给天气。简单比例已经有效时，先承认其信息价值，不重新命名为原创机制。

## 判定与后续

预测、源校准半径与模型在评分前封存。报告MAE、日内形状误差、原始CRPS、90%覆盖、宽度与区间分数，以及逐国家/地区负例；覆盖改善伴随加宽不是达标。天气比例与纯季节比例的差才帮助判断实时资源信息是否有增量，不能仅与无参照银行比较。

若没有稳定增量，暂停天气幅度机制；若有，则扩大已见源日期和完整开发季节支持，避免三天目标窗口结论过度。只有在相同预算、源标签与较完整开发覆盖下胜过简单比例和常规响应，才考虑专门的条件轨迹更新机制、文献新颖性审查和冻结后的未知国家确认。条件化、比例缩放或贝叶斯更新本身不构成原创性。
