# 跨国小时 CIF 迁移：统一证据台账与论文边界

更新：2026-11-02。本表把四项研究重点中的已运行结果放回同一任务框架，方便选择下一步。**表中数值只在同一行对应的冻结数据合同内比较；不同标签、地理单元、日期窗口和月统计来源不合并计算总平均。**

研究目标按用户确认维持两条平行轨道：本地发电侧小时CIF，以省级分类发电月量为主要输入；消费侧小时CIF，另行纳入跨区流量及电力来源碳强度的信息合同。两条轨道各自评估和报告，发电代理结果不能替消费侧结果背书。

## 本轮增量与当前顺序

**新增：US/GB→AEMO严格五组跨域开发检验。**在2023年3–12月、仅用t−2月五类组成与日历、三地等权评分下，US+GB coarse Ridge MAE为161.08 g/kWh，比US-only coarse Ridge低20.1%，但90%覆盖只有46.1%，地区MAE从TAS1的61到QLD1的218差异明显。GB-only和多个模型表现更差；全部区间均严重欠覆盖。AEMO月组成由回顾性SCADA重建，小时结果是非官方机组EF CO₂-e代理；NSW1/QLD1/TAS1进入主集，SA1/VIC1因年度CN5支持仅76%/38%排除。它提供一个外部系统压力测试和失败边界，不是as-issued复现、盲确认、消费侧结论或新算法创新。后续不要在AEMO上事后拟合门控/区间，应先在多个源国伪目标上学风险机制、冻结后另找独立端点。详见[AEMO结果](AEMO_CN5_CROSS_DOMAIN_TRANSFER_RESULTS_20261102.md)、[冻结协议](AEMO_CN5_CROSS_DOMAIN_TRANSFER_PROTOCOL_20261102.md)与[封存证据](../results/aemo-cn5-cross-domain-transfer-r2/)。

**AEMO标签定义配对敏感性补充。**复用同一预测与来源校准，在逐DUID小时SCADA上应用与EIA/NESO源相同的煤/气/油/其他固定EF，获得每区完整8,760小时标签；仅在原CN5支持、共同原生标签和新增燃料映射均合格的21,663小时评分。新标签与原生注册CO₂-e代理小时相关0.99969，平均绝对差53.90 g/kWh。US+GB coarse Ridge在统一标签下MAE214.29、覆盖38.16%、Winkler2474.42；anchor700为252.32/38.44%/2628.89，重组为251.83/34.60%/3307.53。这个点误差/区间分数信号仍不能证明可信预测：NSW/QLD覆盖分别仅11.2%/3.3%，宏覆盖被近零热电的TAS抬高。统一固定EF没有消除域风险，反而显出目标有效因子水平仍有明显差异；该敏感性仍是已查看AEMO开发结果，不冻结为新算法。r5标签每区恰有8,760小时，并保存了逐小时分燃料电量和固定因子分子；r2不得引用。见[结果报告](AEMO_CN5_COMMON_EF_CROSS_DOMAIN_RESULTS_20261102.md)、[冻结协议](AEMO_CN5_COMMON_EF_CROSS_DOMAIN_PROTOCOL_20261102.md)与[哈希证据](evidence/aemo-cn5-common-ef-cross-domain-r5/README.md)。

**新增：2025美英官方发电强度双向开发矩阵完成。**反向US→GB本轮用EIA官方生成强度2022–23训练、2024校准，NESO `intensity.actual` 2025目标8,760小时先封存后评分；700×热电份额锚MAE68.34、覆盖96.15%、宽316，优于源燃料重组MAE106.65、覆盖100%、宽437。与GB→US官方EIA标签的锚81.88/71.13%相比，两个方向均未由复杂燃料重组胜过简单锚；重组覆盖高的一边是明显加宽换覆盖，另一边还欠覆盖。目标NESO API 17,520半小时全覆盖，但月报是当前修订回算，非as-issued；两机构官方估计方法不同，不能合并误差总分。该结果完成优先级1的双向官方估算基线，却不构成盲地理验证或算法创新。下一步转到优先级2：在多国源端伪目标中学习信息预算和可迁移风险关系，保持锚/直接头/重组强基线。见[US→GB结果](CROSS_COUNTRY_2025_US_TO_GB_OFFICIAL_GENERATION_RESULTS_20261102.md)、[冻结协议](CROSS_COUNTRY_2025_US_TO_GB_OFFICIAL_GENERATION_PROTOCOL_20261102.md)、[结果包](../results/us-to-gb-2025-official-generation-r4/)和[NESO目标数据](evidence/neso-national-intensity-2025-r2/manifest.json)。

**2026-11-02：发电侧可识别性方向完成探索性预算等价检查。** 对严格CN5九国2024逐月独立置换小时燃料出力，保留目标月实际分类总量（比`t−2`更强的oracle）与观测小时功率支持后，国家等权平均的逐小时替代CIF 5–95%宽度为135.11 g/kWh；真实代理小时CIF标准差为56.26 g/kWh。Eurostat五区另有60/60地区月份在静态M+C容量下可把所有技术月能量排入其余小时，最紧仍余1.99%功率能力。置换未约束爬坡、负荷与网络，故是信息预算反例而非物理可行调度或部署区间。它说明M/M+C不足以决定小时顺序，支持先做LP信息增量审计再决定算法开发；详见[探索结果与边界](CN5_MONTHLY_BUDGET_HOURLY_IDENTIFIABILITY_PILOT_20261102.md)。双轨论文立意、相关新文献与首轮实验门槛见[研究决策](DUAL_TRACK_INNOVATION_DECISION_20261102.md)。

**追加LP说明，M+C硬界不成立。** 同月六组真实总量和真实小时总发电量作为oracle后，M+T*平均界宽1000 g/kWh；2022静态装机臂M+C+T*平均830.38，但2024全年代理有613个逐技术小时出力超过装机表。180个抽样小时落界不能作覆盖结论，装机臂只能作条件敏感性且未通过完整支持门槛。下一轮先找预测时点合法、年份/分类匹配的技术级约束；若无法获得，接受M/C不能保证小时形状的部分识别结论。见[LP报告](CN5_MONTHLY_BUDGET_LP_INFORMATION_RESULTS_20261102.md)、[协议](CN5_MONTHLY_BUDGET_LP_INFORMATION_PROTOCOL_20261102.md)、[runner与哈希](../results/cn5-monthly-budget-lp-information-r3/summary.json)。

**小时技术组Oracle增量完成。** 在同一九国324小时样本中，逐步固定目标小时真实水电(H)、水核(HN)、风光(WS)、水核风光(HNW)及全部非热电(NTH)出力，均值部分识别界宽分别为814.85、488.06、808.23、233.62和175.59 g/kWh，基准M+T为1000。风光单独信息增益小，水核与风光联合大幅收窄；荷兰HNW界仍为453.6，显示跨区异质性。以上为标签真值oracle诊断，324/324落界是构造所致，非概率覆盖。中国可用月报只提供分类型月总量，不能直接获得目标小时真值；应审计可追溯的水核计划/出力及风光预测版本，再判断源域小时形状迁移能否在合法信息预算中改善集合预测。消费侧仍需OD/来源强度，不能沿用发电侧结论。见[更新结果](CN5_MONTHLY_BUDGET_LP_INFORMATION_RESULTS_20261102.md)与[r5机器结果](../results/cn5-monthly-budget-lp-information-r5/summary.json)。

### 1. 接通跨国小时预测：已接通，准确度和可见性仍有限

**细分燃料统计上限实验没有形成稳定算法增量：**在同样20个BA月和14,592小时上，M+F（额外EIA-923煤/气/油等细分月量＋GB燃料小时曲线）相对中国式五类M强重组，宏MAE只改善0.53 g/kWh、CRPS改善0.76，形状MAE却恶化1.02；BA月MAE仅7/20格改善，剔除ERCO后平均MAE差反转为M+F差1.09。宽度仅缩0.62%，覆盖已高于99%，不能称为可信缩区间。GB源样本没有油电小时，油电曲线只能平坦回退；实际目标份额很小，但不支持高油电占比区域。同队列事后归因显示细分份额乘静态EF的MAE30.90、形状MAE22.88，明显差于M+F小时轮廓（MAE21.50、形状12.76），说明源小时结构相对静态锚有帮助；但五类M强重组形状误差仍更低，也不能证明细燃料曲线胜过强基线。事后BA聚合的组成L1与增益仅呈弱关系，且所用组成误差依赖目标小时oracle，当前不构造风险门控。决策：只保留为额外信息预算消融，不把燃料轮廓头冻结为论文创新。该结果进一步支持基准论文需要分解“信息量—区域条件—可迁移小时响应”，而非默认细分燃料输入总能改善迁移。详见[主结果](EIA923_FINE_FUEL_COMPOSITION_INCREMENT_RESULTS_20261101.md)及[事后归因协议](EIA923_FINE_FUEL_PROFILE_DECOMPOSITION_PROTOCOL_20261101.md)。

### 3. 学习可迁移燃料运行关系：科学假设成立，方法证据不成立

跨国结果提示火电内部有效因子与小时组成有误差，但因子历史头、受限燃料/形状增量、燃料辅助损失、跨拟合残差、因子收缩均未稳定超过强重组。荷兰误差分解中的真实小时份额和火电因子只作为事后oracle，不能部署。现阶段不能声称模型已学到可迁移的煤气运行关系。

### 4. 月报适配与可靠性：能适配，但未证明覆盖下缩窄

目标历史月量的持久性、季节重复、趋势、Ridge和偏置适配已经比较；效果依方向而变。异方差/CQR可改变覆盖和宽度，但最差BA覆盖低，或以显著加宽换覆盖。各轨道均无跨国、最差地区都能维持覆盖并缩窄区间的结论。源残差分位数不是分布无关的跨国覆盖保证。

**年度化石热耗增量补充：**同一US↔GB官方消费强度任务中，M+H火电HGB在US→GB降低约5% MAE，但源端自动缩窄半径后覆盖由71.7%降至59.6%；GB→US因英国单一源的热耗无变化，预测完全不变。事后交叉半径诊断显示M+H中心配M半径时点误差/CRPS改善、覆盖约73.8%，仍远低于90%；这不能作新方法成绩，只说明点信息与区间风险需要拆开评估。年度热耗属于独立预算，和M+C装机分开。见[完整协议、结果和诊断](THERMAL_HEATRATE_OFFICIAL_INCREMENT_RESULTS_20261101.md)。

## 信息预算增量：年度装机应单列

**按中国可用字段做的五类预算配对已完成。** 在火、水、核、风、光的整国留出中，M+C只添加预测时点前的宽口径热电装机占比。五类HGB预测与M逐值完全相同；Ridge加入装机后MAE略差，未显示稳定增量。因此年度装机必须单列作预算消融，但在当前中国可部署字段下，它不是主要算法路线。海外煤／气细分容量可作为M+C+FG信息上限单列，不能暗示中国省级现有同字段。详见[五类预算结果](FIVE_GROUP_CAPACITY_INCREMENT_RESULTS_20261101.md)。

宽口径年度热电装机在五国M+C消融中近乎零增量；煤／气细分锚在部分发电侧代理上改善平均MAE，但消费侧双向结果不稳定，直接硬映射到火电因子在EIA-923配对实验中恶化。中国可公开的省级容量没有煤／气拆分，且历史发布版本仍需审计。因此保留M（月报）与M+C（滞后年度装机）为基准信息预算，不把容量锚当作算法创新。

**新增容量统计年份配对开发回测：**将官方US↔GB消费侧小时任务的煤／气容量从2020更新至2022，M预测逐值不变。US→GB容量HGB逐值等于普通粗月HGB；容量Ridge校准后MAE略升（147.62→148.64），区间评分也恶化。GB→US只有一个GB训练系统，容量头不变，明显弱于强重组。它说明2020容量年份过旧不能解释现有失败；但GB输入取2026修订版DUKES历史行，且2024目标已查看，故是开发敏感性而非严格as-issued回测。逐区指标见[配对结果报告](CAPACITY_2022_OFFICIAL_PAIRED_DEVELOPMENT_RESULTS.md)。

**严格五类九国扩展与装机增量：**排除第六组`other_renewable`后，比例重组MAE62.16、覆盖85.2%；容量因子头相对无容量因子头平均改善0.35 g/kWh，但覆盖仍低于强重组，且无容量比例重组MAE更低。容量不构成主要创新。此前六组运行仅作敏感性分析。详见[严格五类基线](ENERGY_CHARTS_NINE_COUNTRY_CN5_RESULTS_20261101.md)、[严格五类装机结果](ENERGY_CHARTS_NINE_COUNTRY_CN5_CAPACITY_RESULTS_20261101.md)和[六组口径更正](ENERGY_CHARTS_INPUT_BUDGET_CORRIGENDUM_20261101.md)。

## 结论和下一步筛选

目前有工作量、可复现且有价值的论文核心是：**跨国家冷启动小时CIF基准，逐级模拟目标信息预算，并在整国留出下分轨评价发电侧标签与消费侧标签，量化低频信息何时足够、何时因火电内部组成或跨区流量而失效。** 燃料组成头虽曾在法国得到冻结正向信号，但波兰的冻结确认没有复制，算法增量尚未成立。更可信的论文贡献应聚焦标准化任务/信息预算、真实发布时间和标签口径、分轨基准、跨国外推与失效边界，以及“宏观燃料统计不足以识别目标国小时风险”的可复现证据；任何新机制都需要先通过源内嵌套整国伪目标，再经多个完整标签国家确认。新配对回放补齐了同一端点队列上的M、M+C、直接预测和强重组，但源伪目标修正仍在独立H1/H2校准合同下报告，不能把来自不同校准窗的概率分数拼成同一排行榜。

下一轮先不重复调模型。新算法进入实验的前提是明确一条尚未直接检验的因果/观测路径和合法目标特征，并且保证同一评估队列中有可观测响应。否则优先完成以下基准工程：

1. 给每个输入字段登记统计期、发布日期/修订版本、地域与燃料映射、是否可在预测原点取得；分别标记真实as-issued和修订值滞后模拟。
2. 固定官方消费、统一生成代理两条标签轨道的主估计对象、共同月份和区域权重；单独显示最差区域而非合成总排行榜。
3. 对每条轨道使用同一目标小时队列配对比较M、M+C、强重组、直接预测和伪目标基线，并保存预测、残差、区间和哈希。
4. 新算法只有在源域内整国伪目标开发达到预先门槛后才冻结，再对未查看国家一次确认；不根据确认集反复调参。

这一判断对应当前四项目标的实际状态，不把已接通、已运行、已达到可信迁移三个不同层次混为一谈。详细协议和原始指标按各行链接继续追溯：[官方小时标签审计](OFFICIAL_HOURLY_CIF_LABEL_AUDIT_20261101.md)、[Energy-Charts五国LOCO](ENERGY_CHARTS_LOCO_RESULTS_20261101.md)、[EIA-923月统计消融](EIA923_CROSS_COUNTRY_EXPERIMENT_RESULTS_20261101.md)、[episodic结果](EPISODIC_COLDSTART_RESULTS_20261101.md)。
