# Structural transfer search v3

Frozen before 2023 scoring. The 2023 results are exploratory because earlier experiments viewed this year; 2024 is excluded. No 2025 reads occur here unless a later explicitly authorized invocation requests them.

R1 compares persistent latest monthly generation-weighted emission proxy plus source calendar shape against robust three-month median level, past-season/source-seasonal level extrapolation, source Ridge level correction, age-decayed Ridge shape, static Ridge shape, fuel/calendar/age analog shape, and analog level plus shape. All shape corrections are exactly zero-mean. The coarse level persists with age; only innovations decay. Monthly mix is a generation-weighted accounting proxy, not the arithmetic average of hourly intensity, so no future equality is imposed.

R2 uses source-only leave-region-out and time-out validation: fit January–June of the earliest training year on other source regions, evaluate July–December of the held source region, choose one entire method by MAE. This simple whole-method source policy is an ablation and is not itself claimed original. The source held-region residual bank is also used for uncertainty; all methods use shared 128 indices. Calibration includes the same 0/30/90 extra days of simulated release latency as evaluation. Inputs already have month-end plus 30 day synthetic releases, so total latency is approximately 30/60/120 days. Delays apply to all regions consistently. Residuals preserve source bias; ensembles clip to [0,1000]; raw point and shape errors are reported separately.

Each outer held-region fold excludes that region's hourly training and calibration. Fit uses released source monthly history before cutoff, and target prediction uses only monthly rows with release and period end at or before origin. The runner snapshots protocol, source SHA256, data SHA256, forecast arrays, source identities, policy ranking, residual sample indices, and prediction seal before opening target validation hourly labels. Repeated outer folds necessarily have already viewed other targets for their own scoring; seals are per-fold, not a claim that all 2023 labels remain globally unseen.

All seven regions and three latency regimes are reported. Paired calendar-month bootstrap differences versus latest level baseline are descriptive, with no independent-sample significance claim. Winner regions/regimes must not substitute for macro results. Originality requires a later information-aware component gate to improve over these baselines, source policy and best constant blend on an untouched year; v3 alone cannot establish it. R3 is a separate untouched-year confirmation only after freezing an explicit source-only policy and receiving authorization to access that year.

R2 fixed shrinkage grid adds half-strength static shape, half-strength analog shape, and constant half Ridge-level/analog-shape blend. The same source-only criterion selects among these and R1 families; selection never uses 2023 scores. For a subsequently authorized 2025 confirmation, train only on 2022, keep the identical source leave-region/time selection and residual procedure, and evaluate nominal 30 plus 60/120 total latency. No 2023 score chooses the confirmation winner. Source-policy MAE criterion is predeclared even though CRPS is the primary reported distribution score.

All latency variants for a target are sealed before the first read of that target validation year. Historical coarse rows through the validation year are retained and screened by release/prefix rules, including 2023–2024 coarse history in 2025 forecasts. Source training remains 2022 only. Source policy selection and uncertainty bank reuse the same held-source residual pool, inducing selection optimism; no calibration guarantee is claimed. Full transitive source and data SHA256 values are rechecked after scoring.

Source seasonal-prior availability also includes the configured release delay before cutoff. If no source coarse observations are released by cutoff, a fixed uniform fuel prior is used, and source-only hourly calendar/template information remains available.
