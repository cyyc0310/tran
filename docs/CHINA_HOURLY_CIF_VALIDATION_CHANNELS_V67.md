# V67：中国小时电碳验证数据渠道与研究问题重定位

日期：2026-10-27。检索问题：在本地研究者仅能取得月/年燃料统计时，中国是否存在可作为独立小时真值的公开数据，或可以明确的高频测量渠道？本轮是来源与研究边界审计，不代表已经取得数据或建立合作。

## 新的外部证据

1. 国家数字标准馆目录将团体标准 **T/SSM 32-2026《分时分区电力碳排放因子计量技术规范》**列为现行，发布日期2026-04-24。标准起草单位包括国网山东营销服务中心、山东省计量科学研究院、国网山东电科院等。此前的公开征求意见稿规定基于计量点同时间戳的发电量与直接碳排，结合电网输入/输出电量及拓扑递推碳因子；目标可到15分钟、省—地市—区县—园区—台区/节点。它的研究对象是**实测/计量驱动的生成—电网—用户链条核算**，与本项目从公开月度信息做的跨区冷启动预测不是同一个估计量。
2. 该标准的编制说明称山东部分区域和企业2025年试点使用实际拓扑、发电、电能计量与碳排数据，采样最小间隔15分钟，覆盖完整性要求不低于98%；但公开文本没有附可重用的样本级数据、时间版本或可复算的误差分析原表。说明中报告“误差不超过3%”是起草组摘要，不能当成独立发表的基准表现。
3. 2026年8月的行业报道称国网宁夏电力碳排放监测平台实现T−2日自动更新，覆盖分时、分区、分压、分节点、分园区、分客户，底层连通同期线损与电网拓扑系统；报道描述的是平台业务能力，不是公开下载的历史标签。
4. 山东省能碳核算管理平台于2026-06公开发布，官方报道其电碳预测和监测预警使用高精细度电力数据，覆盖省、市、县与部分行业。公开报道没有给出模型、时序标签或开放API。

## 本轮没有确认到的内容

本轮检索没有找到上述平台可公开批量下载的历史15分钟/小时碳因子、可复现预测vintage、逐条版本化样本或完整评估基准。它们是潜在合作验证渠道，不可加入当前公开数据论文的结果、不可从新闻报道推断可访问。公开小时负荷重建、CISPO-China未来情景、平台宣传精度与实测目标标签之间仍有明确区别。

## 对研究方向的改变

这使“突破点”从算法堆叠转为一个有实际验证需求的两层问题：

- **可公开复现层：** 给定月/年燃料统计、发布时间和统计边界，对未见区域做跨区冷启动。把generation-side均值、consumption/network-flow因子与用户节点因子分别定义；本地信息不足时输出设定条件明确的识别集合/风险拒绝，不宣称唯一小时序列。EIA公开小时代理用于可控信息遮蔽基准，Ember/官方中国月表用于低频应用侧描述，二者不混作一个真值。
- **高频验证层：** 若将来取得经授权的电网测量数据，先在一个或多个区域做真正的as-of预测与外层留区：至少需要时间戳和版本、空间边界、燃料分组发电量或直接排放测量、输入/输出电量及其来源因子、数据缺失/更正记录。区分计量时刻与首次可用时刻；预报/补算不得混为同期观测。分别评价预测误差、区间覆盖和风险尾部。

**候选论文贡献不应写成“提出新的小时CIF核算模型”。** 行业标准已明确覆盖计量与电网碳流核算。更可辩护的原创方向是：面向无本地高频测量的冷启动场景，研究受月度边际约束的跨域预测何时可用、何时必须拒绝，以及该判断在真实高频计量标签上的覆盖/效率后果。真正创新门槛仍是：在同样信息预算下优于强迁移和校准基线，并经至少一个具有严格as-of版本的独立中国高频数据集确认。
