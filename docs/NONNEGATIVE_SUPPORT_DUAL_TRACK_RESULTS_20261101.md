# 非负支持集投影：US↔GB双标签轨配对诊断

日期：2026-11-01。复用已评分的US↔GB 2024双轨预测（发电侧固定EF代理、EIA/NESO消费侧官方估算），按原小时、输入预算和2023源校准半径比较未变换与非负支持集投影。预测文件32份和16组目标标签哈希逐项核验；重算的1,988条原方法/目标BA/月指标与封存原表完全复现，浮点差异小于`10⁻¹¹`。2024目标已在研究过程中打开，因此本结果是回溯开发诊断，不是前瞻或盲区确认。

## 变换与汇总

对校准点中心`p`执行`max(0,p)`；对90%区间`[L,U]`执行`[max(0,L),max(0,U)]`。指标按目标月等权，再按目标BA等权；GB为单一目标。两种输入预算（小时回算和EIA-923月量）先分别评分，方向摘要中再对它们等权。所有实际响应均非负，因此投影后逐月覆盖与原始区间完全相同；区间分数使用新端点重算。未计算投影后的Gaussian CRPS，因为区间截断本身没有定义完整的截断分布。

## 结论

1. 非负支持集投影是两条轨道都应报告的**支持集基线**：目标强度非负时，投影不会改变原区间对正目标的覆盖事件；遇到负点中心时，向0投影会缩短其与非负真值的距离。
2. 它不是跨域学习方法，也没有增加小时形状信息。其区间分数收益来自把无效的负强度区间部分移除，不能包装成算法创新。
3. 它不修复跨域校准。GB→US官方消费标签覆盖仍为71.43%；区域内更差，MISO等BA严重欠覆盖。区间可信度仍须独立研究。
4. 发电和消费响应仍分别报告。EIA消费侧强度通过MRIO给BA间转移分配排放；本地产生侧五类构成不是消费侧标签的完整决定因素。[EIA官方定义与方法](https://www.eia.gov/electricity/930-content/about.html)
