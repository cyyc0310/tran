# V51：中国公开月度发电统计字段审计与可识别边界

2026-10-27，Sol。目标是把用户确认的公开月/年燃料统计预算，落实到实际公开表的分类、边界和建模含义。只审阅公开官方资料与现有 V24 识别结果；没有读取项目中的任何目标地区小时标签，没有把官方表接入生产模型，也没有打开未查看地区。

## 公开月报的实际分类

国家统计局月度能源生产公报通常列“火电、水电、核电、风电、太阳能发电”，并明确规上工业统计范围。2026年9月公报也说明企业范围每年变化，为同比计算匹配本期范围，因此历史公报数值可能与上一年公布值存在范围差异。

省级监管办月报也常见同一粗分类。河南监管办2026年5月全口径表给出了总计、水电、火电、风电、太阳能的装机、利用小时和发电量，并单列储能；表中并未细分煤电、气电和油电。该具体报表提供的是省级官方公开样例，不代表已对全国所有省份及年份做过普查。

国家统计局对“火力发电”的定义覆盖煤、燃油、燃气、生物质燃烧，以及余热、余压、余气发电。于是“火电”不是“煤电”的同义词，也不能未经核算就等同本项目的正排放燃料组。风、水、核、太阳能分类仍不能自动解决储能充放电、跨省输入输出、自备电、厂用电、分布式电源和热电联产边界。

| 已确认的字段条件 | 当前可以做什么 | 仍不能直接声称什么 |
| --- | --- | --- |
| 月度总发电量＋火/水/核/风/光类别 | 对有共同统计边界、单位和时点的月报做聚合组成特征；以明确的类别EF假设构造区间或情景 | 煤/气/油精确构成、真实碳核算因子、小时顺序或小时尾部已知 |
| 月度更细燃料发电量（如果用户手头原表确有煤/气等） | 在来源、定义、覆盖和修订时点核验通过后，可收紧月度混合强度集合 | 仍不能由月均占比推出小时调度及净交换边界 |
| 年度燃料统计 | 约束年度加权组合或年水平，分析年内聚合量 | 不能把年度总量复制成12个已观测月，更不能复制成小时形状 |
| 仅燃料消费/产量而非燃料发电量 | 作为带转换参数的辅助协变量或情景约束 | 不能直接代入发电份额；需热值、效率、热电联产分配和边界换算 |

## 对现有研究结果的含义

V24 的 sharp 识别区间只在项目固定 EF、八类燃料及已知分项/合并组的代理世界内成立。它说明分类合并会怎样扩大过去聚合水平的等价类，不能把 V24 的代理EF解释为中国官方排放因子。

在类别边界、分母和每类排放因子均已知且统计覆盖完整的理想条件下，月度类别电量`E_{m,k}`识别的是该月**发电量加权**平均强度：`C_m^E = Σ_k E_{m,k} EF_k / Σ_k E_{m,k}`。若某粗类别内各燃料EF未知但被限制在`[L_k,U_k]`，对应月度加权强度只能落入类别端点诱导的集合，而非自动识别为一点。这个等式不识别等小时均值`mean_h(C_h)`：后者与`C_m^E`之间还差一个小时总发电量与强度的协方差项。也不识别小时分布、阈值超限频率或尾部连续时长。

例如两个等长时段、低/高排放燃料EF为0/1000、月度两类电量各占一半：按“低燃料发完再高燃料”的调度，小时CIF可为`[0,1000]`；两者每时段各半混合则为`[500,500]`。它们满足完全相同的月度统计和相同的能量加权月均值500，却有不同小时离散度、p90和阈值超限行为。月统计可能给月均锚，但不识别该月小时风险。

在中国常见的“火电＋水/核/风/光”表下，若只有火电一类、而类别EF无法由本地统计确定，则可识别对象应先是**在明示类别因子集合下的月度粗强度区间**，而不是点估计。必须确认分母和边界匹配；例如国家统计局规上工业口径与全口径区域发电不相同。若项目拥有更细的公开月表，应以原始表的名称、发布者、字段、单位、统计边界、可得时点与修订版进行逐字段数据合同审计，再选择合适的 schema；不能从“可再生/不可再生都有”推断已可分出煤/气。

即便月度混合水平已精确知道，小时 CIF 仍有未约束自由度：小时燃料出力排序与调度替代、小时总发电量/净交换、储能往返等都可在保持月度总量不变的情况下变化。V50 旧开发源中，月度 EF proxy 对部分源均值偏差有信号，但对尾方向的整源留出预测几乎没有改善，条件阈值在小时区间上失覆盖；月度变化度与局部 q 收缩也没解决。因此目前不支持“月报足以给目标区小时尾部可信窄区间”。

## 研究缺口和可检验的下一步

论文贡献机会目前更像“粗统计约束下的可识别性分解与迁移基准”，而不是再设计一个无本地小时信息的通用校准器。值得检验的命题是：公开月度类别统计使历史/预测月总量约束了多少聚合CIF；剩余小时形状及尾部风险需要多少源迁移假设，且这种假设在哪类组成/时效/覆盖条件下失败。

下一次数值实验应先从真实字段合同选预算，不应再扫描算法：

1. **Schema-粗月报臂**：总发电量＋月度火、水、核、风、光（或用户原表经审计确认的确切类别），有物理依据的EF区间；不能偷看煤气细分。
2. **Schema-细燃料臂**：仅当原始公开/合法表确有煤、气、油分项时才启用；记录原始发布时刻与修订值。它是更高信息预算，不与粗臂混称同预算。
3. **年度-only 臂**：只使用年度字段，显式让模型预测年内分配；不得用已知目标月度构成。
4. **小时目标评分**：固定同一源划分、点预测器和标签边界，比简单锚定、标准源条件动态重组、异方差与条件分位数基线；同时报告宏覆盖、最差源覆盖、宽度、区间分数/CRPS，以及分层结果。
5. **识别—预测分开**：先报告从统计字段逻辑推出的可行强度集合；再报告源模型对集合内部小时形状所作的概率补充。不能把源先验缩窄的结果称为月度数据本身识别，也不能把集合宽度当覆盖率。

门槛仍是：旧开发源上同预算强基线有稳定、可归因的覆盖保持效率增量，然后冻结协议并只对未查看地区做一次确认。当前V50所有重复开发结果均未达到此门槛，TVA 的冻结新地区确认还否定了分尾候选。因此现在不应冻结新的算法，也不应宣称创新成立。

## 边界声明

本审计核实了具体官方样例，未普查所有地区/平台，未验证用户手头原始表的逐列定义或下载历史版本。国家统计局规上口径和河南监管办全口径不能直接拼成同一个面板。2026年官方页面用于说明当前字段，不回填成模型当时可得信息。没有运行数值实验；本项是研究设计审计，不是模型性能结果。
