# 2026年12月US↔GB双轨封存预测：预评分质量审计

审计日期：2026-11-01。此项只读取已封存的预测文件、训练/校准期标签和机器清单，未读取2026年12月目标小时响应。原始预测及哈希保持不变。

## 审计范围

逐份检查生成侧三文件和消费侧十文件：744行、时间戳唯一且逐小时连续；火、水、核、风、光输入份额之和为1；点预测/区间有限，区间上下界有序。以上结构检查全部通过。发电侧预测的校准中心均非负；消费侧原始模型中心出现负值，且部分Ridge预测在合法输入上触及模型硬截断端点。

容量Ridge在GB→US逐值复制粗组成Ridge输出。单一GB训练区没有容量特征的跨地区支持；该容量臂不能作为独立可迁移方法证据。BPAT的粗组成/容量Ridge在未校准输出中744小时都触及1000 g/kWh硬上限，校准后为约989 g/kWh；CISO和ERCO两臂都744小时触及0下限，校准后成为约−11 g/kWh。MISO、FPL则有部分小时触及0。源训练期GB和七个美国BA标签均无负值（各区最小值约3.8–268.7 g/kWh；GB最小27.0），所以这些负校准中心明显处于已见标签支持之外。该源期事实不能证明2026目标绝不出现负值，故不删除原始预测或据此选择赢家。

EIA将消费侧强度定义为负荷的排放强度，并通过MRIO为各BA间电力转移分配排放；官方说明也指出，未平衡的跨区潮流会扭曲负荷排放强度。因此仅由本地五类月发电份额无法识别消费侧小时标签，这些预测是跨域压力测试，不能解释成目标消费侧碳强度由本地组成单独决定。[EIA Hourly Electric Grid Monitor方法说明](https://www.eia.gov/electricity/930-content/about.html)

## 非负支持集敏感性封存

为量化简单支持集约束的影响，额外生成一个预先评分敏感性，完全由原预测确定：校准点变换为`max(0, point)`，区间`[L,U]`变换为`[max(0,L), max(0,U)]`。该变换不重新拟合、不读标签，原预测仍是主结果。条件是目标强度非负；它不提供覆盖保证，也不预设MAE、WIS或覆盖会改善。

## 对四项研究重点的影响

1. **跨国端到端预测：**预测文件的时间、输入闭合和哈希链完整；但消费侧有明确的可部署性问题，需在成熟目标上展示主模型和支持集敏感性的成对指标。
2. **伪目标训练：**负值并非需要新训练损失才能修复。先把后处理作为同预算、目标盲的基线，只有超过源内国家留出与既有强基线后再考虑学习型约束。
3. **燃料运行关系：**消费侧EIA标签含MRIO潮流排放分配，本地发电组成不构成完整标签机制；不要将发电侧燃料响应增益迁移为消费侧结论。
4. **月报适配与可靠性：**投影到非负支持集会同时改变点误差与区间宽度，必须报告配对MAE、proper interval score、覆盖与宽度，不能只报告缩窄。

## 后续评分

12月目标响应成熟后，先核查可用时间戳覆盖和标签版本，再对原始封存预测及此支持集敏感性作一次配对评分；不得按该目标结果继续修改截断规则或模型。最早评分时间仍以各原协议为准（2027-02-03 UTC）。

源端严格五类LOCO的既有2024目标上已另作回溯性配对诊断：支持集区间投影逐国保持覆盖、收窄区间，但没有改变点误差，且强重组仍欠覆盖。该结果解释了为何将投影保留为12月基线敏感性，同时说明它不是预测算法创新。详见[CN5 LOCO结果](NONNEGATIVE_SUPPORT_CN5_LOCO_RESULTS_20261101.md)。
