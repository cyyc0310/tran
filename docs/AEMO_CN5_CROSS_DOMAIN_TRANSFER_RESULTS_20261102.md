# AEMO 五组跨域转移开发结果

更新：2026-11-02。实验依照[冻结协议](AEMO_CN5_CROSS_DOMAIN_TRANSFER_PROTOCOL_20261102.md)完成。该轮是回顾性开发检验，结论不外推为中国部署有效性或官方小时CIF验证。

## 执行和样本

美国、英国和合并来源模型均用2022训练、2023来源域校准；目标为AEMO五个NEM地区2023年3–12月，输入只使用t−2月五类发电结构和日历。所有预测先写出并SHA-256封存，然后才打开小时代理标签。主集合按标签读取前已确定的支持门槛，纳入NSW1、QLD1、TAS1；所有地区仍生成预测，但SA1与VIC1不进入主结果：全年分别仅76.0%、37.5%小时满足五组/标签/采样支持要求。主集合实际与小时代理自身资格相交后，三地可评分数分别为7,253、7,076、7,334。

| 区域 | 全年CN5合格率 | 2023-03至12可评分小时 | 主集合 |
|---|---:|---:|---|
| NSW1 | 98.94% | 7,253 | 是 |
| QLD1 | 96.88% | 7,076 | 是 |
| TAS1 | 99.86% | 7,334 | 是 |
| SA1 | 76.00% | — | 否：粗组成支持不足 |
| VIC1 | 37.55% | — | 否：粗组成支持不足 |

目标结果是由机组登记EF和五分钟正向SCADA事后生成的tCO₂-e/MWh小时代理，转换至g/kWh。它既非官方小时CIF，也非预测时发行的月度输入；来源域则为固定因子直接CO₂生成代理。跨域MAE差异同时包含模型迁移、标签边界和机组EF代理误差，不能单独解释为算法误差。

## 地区异质性

US+GB coarse Ridge在NSW1、QLD1、TAS1的MAE分别为203.8、218.0、61.4 g/kWh；相同地区的US+GB重组MAE为270.4、280.9、42.5。Ridge在化石强度较高的NSW/QLD较占优，但TAS重组更好；TAS小时代理多为接近零强度，来源模型的跨域误差结构与另两区不同。等权宏平均会隐藏这种结构，不能将161.08理解为单一可迁移精度。

简单锚与重组的相对排序也随地区改变：US+GB锚在TAS1 MAE为121.3，显著差于粗boosting的27.7；在NSW1和QLD1，coarse Ridge则优于锚。三地有限样本不足以训练可靠地区条件门控，更不能在当前结果上事后拟合。

## 研究判断与下一步

1. **有用的跨域压力测试，不是已验证的新方法。** 合并来源粗特征 Ridge在三地宏平均点误差上优于对应US-only Ridge和简单锚，但只覆盖一个国家—年份—代理组合，没有区间校准成功，也没有对模型选择进行新的盲域确认。
2. **来源校准的区间不能直接迁移。** 所有来源臂的目标覆盖都明显低于90%；此处证据继续支持把跨域不确定性作为首要方法问题，不应用全局加宽后宣称解决。
3. **目标分布和测量口径可能主导部分差异。** TAS近零排放与NSW/QLD热电为主的小时代理构成显著不同；且AEMO CO₂-e机组因子与来源直接CO₂固定因子并非同一标签。下一步若继续AEMO，先做每区月度标签支持、非零强度结构与偏差分解，再提出可在来源伪目标训练中复现的区域条件区间方法；不在AEMO上事后调参。
4. **消费轨仍独立。** AEMO区域CDEII不追踪跨区来源排放，当前机组小时代理只支持发电侧诊断，不能当作消费侧验证。

此轮不构成论文核心创新贡献。可作为“严格可用信息预算下的外部系统失效/异质性”证据；论文主线仍应以合法发行信息、国家级冷启动、跨域基准设计及来源伪目标可学的风险控制为核心。若需要算法创新，建议下轮先在已有多个独立国家的伪目标上训练和选择机制，之后冻结，再把AEMO留作一次性压力测试。
