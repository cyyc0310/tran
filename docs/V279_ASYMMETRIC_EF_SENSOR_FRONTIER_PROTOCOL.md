# V279：燃料特异EF支持下的本地观测通道前沿

冻结日期：2026-10-30。本轮是对已打开的V226 2026年7–9月队列做结构性扩展，不是盲测、外部确认或中国验证。问题是：V228按点EF选出的最少小时聚合字段，在煤/气/油EF分别不确定时是否仍足够；新增哪个最少字段可恢复对代理排放风险的稳健约束？

## 固定数据与因子合同

- 队列与目标月、日完整性、供体可用性沿用V226；不按本轮结果筛BA-month。
- 每月边际、中心和小时活动量沿用EIA固定EF代理；目标月加权均值为oracle中心。
- 煤/气/油EF独立落在V269 r2同季度、覆盖至少90%美国CEMS州—季度发电量的经验支持区间；这只是跨系统压力合同，不是目标BA置信区间。EIA `other`固定400、非化石直接EF固定0，因当前CEMS支持表未覆盖`other`，结果不得解释为完整的真实EF不确定性。
- 每小时燃料量满足非负、月边际剩余量可行和观测聚合字段等式。用LP分别在EF下端/上端计算小时CIF可行区间；EF在整个月共享，边际小时界的单调极端取同一向量低端/高端。月际小时联立守恒未纳入，所得集合可能保守。

## 固定通道方案

1. `nominal_minimum`: V228根据名义点EF选出的最小通道；
2. `fixed_four`: `total + thermal + coal + gas`；
3. `support_minimum`: `total`加所有月边际非零的煤/气/油分项；若`other`边际非零，另观测`thermal`以恢复剩余`other`；
4. `full8`: 精确八类小时发电量，仅作为信息上界参考。

所有方案均以实际记录产生其通道观测；字段选择只看月边际与固定EF支持合同，不使用标签误差。每种方案对每个完整日的分数是该日24小时中，稳健CIF端点离oracle月中心的最大距离。

## 校准和评分

每BA-month随机抽12个完整日，100次固定种子重复；用12日最大分数的90%有限样本分位数构造中心不变的对称区间，在其余日期评分。相同随机划分用于所有通道方案。报告代理小时覆盖、整日同时覆盖、区间宽度、Winkler-90，以及**稳健小时集合/整日集合包含率**。包含率要求区间盖住LP可行端点区间；不能与名义代理覆盖混写。按BA聚类给成对区间。

加入源区强基线：同月2025其他BA的精确八类名义日最大误差，排除目标BA。此基线不使用目标小时字段，只作为已知月中心条件下的迁移对照；因此对它只报告相对名义EIA代理标签的覆盖、宽度和Winkler，不计算需要目标小时组分才能判定的稳健集合包含率。

## 解释门槛

- 先核验零EF不确定时LP结果退化为V228行空间身份；否则停止。
- 若`support_minimum`比`nominal_minimum`的稳健集合窄，且相对`fixed_four`降低稳健包含失败而不过度增加区间，则说明EF不确定支持会改变最小本地字段合同；若字段数量或风险指标无优势，如实报告无新增。
- 目标队列已经打开，任何效果都只是方法设计证据；不能据此宣称确认、覆盖保证或中国泛化。
