# 九国年度装机信息预算增量协议

**口径更正（2026-11-01）：**基础九国模型实际使用六组粗月输入，含`other_renewable`；本实验不是严格中国五类预算。严格五类配对协议见[CN5容量协议](ENERGY_CHARTS_NINE_COUNTRY_CN5_CAPACITY_PROTOCOL_20261101.md)。

冻结日期：2026-11-01，预测前。问题是年度公开宽口径热电装机能否在相同九国冷启动合同中，为五类滞后月发电量输入带来独立增量。

## 数据和可见预算

国家固定为NL、ES、BE、AT、SE、CZ、SK、HU、SI，沿用[九国整国留出协议](ENERGY_CHARTS_NINE_COUNTRY_LOCO_PROTOCOL_20261101.md)的小时数据、外层目标、目标年份、源训练、源校准和标签定义。年度装机来自Eurostat `nrg_inf_epc` 的净最大电力容量，取燃烧燃料`CF`除以总容量`TOTAL`。2022训练小时接2020统计年，2023H1源校准接2021，2024目标接2022，统一滞后两年。

Eurostat当前修订表不是历史as-issued快照。因此本轮比较的是年度信息预算的滞后模拟，不能称为严格前向历史可见性回测。装机特征只作为软预测变量，不作物理上限，也不进入标签。

## 冻结模型与评分

M基线固定为九国LOCO八方法：`anchor700`、宏/比例重组、Ridge历史、直接最新/历史、因子最新/历史。M+C增加三种同构年度装机方法：HGB直接头、HGB火电有效因子头、标准化Ridge直接头；特征为相同`HISTORY`列加单一`capacity_thermal_share`。HGB使用80轮、15叶、最小叶100、L2=10、随机种子416、关闭早停；Ridge alpha=10。所有模型和阈值在九个目标响应打开前固定。

每折其余八国2022训练、八国2023H1源端池化绝对残差校准90%小时区间、留一国2024预测。每国的M与M+C使用完全相同的测试小时和数据筛选。输出逐月、逐国、九国等权平均MAE、去日均形状MAE、经验覆盖、宽度、区间分数；并配对比较`capacity_direct`与`direct_history`、`capacity_factor`与`factor_history`、`capacity_ridge`与`ridge_history`。同时报告强重组M方法的点预测和区间变化，避免只看新增头。

预测先封存再评分。九国全是开发域；经验小时覆盖不是新国家有限样本保证。只有在宏观和最差域都出现方向一致、具有实际大小的点误差或区间proper-score改善，且不靠显著增宽达成覆盖，才考虑投入专门容量条件迁移方法。
