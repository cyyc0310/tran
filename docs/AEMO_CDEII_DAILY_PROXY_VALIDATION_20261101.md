# AEMO官方日CDEII核验与小时机组代理构建

更新：2026-11-01。评估AEMO是否能支持一个**发电侧小时代理开发集**：先以官方日CDEII核验五分钟机组EF样本重建，再按UTC小时输出派生代理。数据不是官方小时CIF，也不检验消费侧CIF。

## 数据与冻结口径

- 目标标签：AEMO 2023 CDEII官方CSV中的五个区域日强度（NSW1、QLD1、SA1、TAS1、VIC1），单位t CO₂-e/MWh。官方文件覆盖2023-01-01至2023-12-30，每区364天；NEM全网行不参与区域评分。AEMO说明CDEII按日计算、按周发布，区域补充指数按发电地理归属计算，不追踪互联线流量。[官方CDEII页面](https://www.aemo.com.au/energy-systems/electricity/national-electricity-market-nem/market-operations/settlements-and-payments/settlements/carbon-dioxide-equivalent-intensity-index)、[2019年适用于本数据期的官方规程](https://www.aemo.com.au/-/media/files/stakeholder_consultation/consultations/nem-consultations/2019/cdeii/carbon-dioxide-equivalent-intensity-index-procedure-v40final.pdf)
- 机组代理：将2023各月UNIT_SCADA正向瞬时MW按DUID关联到当地GENUNITS CO₂-e EF；只保留注册类型为GENERATOR、唯一映射到一个区域且所有候选GENSET具有同一非缺失因子的DUID。对每个本地日期和区域，计算`Σ(MW样本×EF)/Σ(MW样本)`。每个采样间隔相同，故对样本比率的固定长度权重相消；这不等价于已验证的送出MWh积分。
- 注册范围：使用回顾性2023-12 DUDETAILSUMMARY/DUALLOC快照，EF使用逐月GENUNITS快照；不声称这些版本在预测原点已公开。SCADA UTC时间固定换算到NEM UTC+10日期，去掉月文件跨界的本地日后评分。
- 配对：准确匹配官方可用的1,820个区域日；要求每个区域日观测到至少95%的288个五分钟时点。

## 小时代理

同一遍扫描还生成2023年五区43,800个UTC小时（每区8,760小时）。一个小时的强度是该小时内正向DUID SCADA MW样本和单值原生EF的样本加权比率；EF缺失或歧义的DUID只计入覆盖分母，不计入排放代理分子。每小时均输出时点支持、EF样本权重支持和资格标记。预设资格规则为两种支持均至少95%。

| 区域 | 小时数 | 合格小时 | 合格比例 | 最低EF映射支持 |
|---|---:|---:|---:|---:|
| NSW1 | 8,760 | 8,748 | 99.86% | 95.28% |
| QLD1 | 8,760 | 8,748 | 99.86% | 95.07% |
| SA1 | 8,760 | 8,748 | 99.86% | 96.86% |
| TAS1 | 8,760 | 8,748 | 99.86% | 98.63% |
| VIC1 | 8,760 | 8,736 | 99.73% | 92.10% |

全部小时代理按有效MW样本加权回聚合到日后，与直接五分钟日聚合的最大绝对差为`3.33×10⁻¹⁶ t CO₂-e/MWh`。合格门槛排除72个区域小时，但原始输出保留这些小时与不合格标记。逐小时文件为`hourly_scada_ef_proxy_2023.csv`。

## 判断与后续使用边界

1. 机组EF可映射质量、五分钟时点覆盖及逐日一致性足以支持AEMO作为**回顾性小时代理开发集**；派生小时序列已构建且通过日聚合恒等核验。
2. 偏差主要具有区域结构，VIC和QLD尤为明显。当前版本不能直接与其他国家的直接CO₂ CIF混合打分；CO₂-e与CO₂边界、注册快照、效率/逸散排放、送出电量、瞬时SCADA和未映射机组均可能贡献差异。
3. 这不是逐小时真值验证。派生序列只可称“回顾性机组EF代理”；逐日聚合与官方CDEII一致性只验证低频重建及算术一致性，不能证明小时形状准确。
4. 这也不是未查看国家盲确认：AEMO已作为候选数据源做过映射审计，且2023官方日标签现已打开用于开发诊断。只有构建器和模型方案冻结后，其他尚未使用的数据集/年份才能作独立确认。
