# 目标小时负荷Oracle未带来跨国迁移增量

日期：2026-11-02。按[协议](CN5_HOURLY_LOAD_ORACLE_INFORMATION_PROTOCOL_20261102.md)在严格CN5九国2024开发回放中完成第一阶段点预测信息上限筛查。一次NL管线调试先导在完整九国复跑前已查看该国评分，未纳入下列队列指标；最终协议先筛点信息、通过后才做区间。所有目标国都属于已查看开发集，因此这不是盲测或预注册确认。机器预测、逐月指标、哈希与复现核验见[证据包](evidence/cn5-hourly-load-oracle-r1/README.md)。

## 结果

M是严格滞后五类月发电统计。M+L*在相同源训练/目标小时支持上额外输入目标区**实际同小时负荷**，按该区2022平均负荷归一。由于目标月实际负荷在月初预测时尚未知，这一分支只能用作Oracle上限。三种模型共用同一CN5特征和燃料因子发电侧代理；两种因子头使用相同来源、训练年份、HGB设置和源端小时热电形状，唯一特征增量为`load_norm`。下表国家等权、每国先月等权。单位gCO₂/kWh。

| 方法 | MAE | 日内形状MAE |
|---|---:|---:|
| 强比例重组 | **62.162** | 17.849 |
| M：CN5火电因子头 | 62.784 | **17.827** |
| M+L*：目标实际负荷Oracle | 62.943 | 17.971 |

M+L*相对同支持M使宏MAE升高0.159 g/kWh（+0.25%），形状MAE升高0.144（+0.81%）；逐国MAE仅6/9改善，尚未达到预设的至少5%宏MAE增益。负迁移包括CZ（138.01→139.86）和SK（25.93→27.00）。它也未超过强比例重组的MAE。

## 解释与决定

即使把目标区实际小时负荷作为不可部署的额外信号，当前跨国火电有效因子头仍未获得稳定点预测收益。这说明单独知道当小时总负荷不足以解决热电内部燃料/调度关系的域差异。由于点预测筛查未通过预设门槛，不进入这条“负荷预测校正火电因子”的区间优化阶段；不搜索负荷变换、树参数或目标国家特定修正。

这不是证明所有负荷预测都无价值：当前只是Energy-Charts修订小时数据上的同小时实际负荷上限、一个HGB因子头和一个固定因子代理。它没有测试as-issued负荷预测，不能视为合法部署输入；中国主预算仍只有用户确认的省级月度发电类别统计，负荷未确认为公开附加预算。所有结果仍是已经看过的九国2024开发回放，不能称新地区确认。

首轮统一检查的有效预测小时为每国8,743–8,784。为保证M与M+L*完全配对，训练与目标小时均限制在负荷存在的共同支持集；故M火电因子头结果有意不同于较早全支持CN5报告中的完整样本数字。逐国共同支持小时数、M与M+L*复算差值和输入哈希见`verification.json`。

消费侧不由此得出负荷的同类结论。消费侧预测仍需独立的跨区流量、送端来源碳强度及分配规则；不能从发电侧负荷Oracle推导消费CIF已可识别。

## 实验边界与复现状态

- 九个目标国各自整国留出，2022源小时训练；2024点预测文件全部写盘并封存后，才用目标燃料小时标签评分。目标小时负荷作为Oracle特征明确违反部署输入预算。
- 在封存的全支持CN5火电因子结果之外，负荷缺失行被共同剔除，M基线也在完全相同的源训练行上重训；没有把全支持旧基线与缩减后的Oracle支持错误地逐点比较。
- 预测SHA、逐行索引、有限值以及M/M+L*两臂重算结果均通过核验，复算最大绝对差小于`6×10⁻¹⁴`。概率覆盖、区间宽度和Winkler未计算；这轮只回答点/形状信息上限。
- 运行代码为本轮临时实验器，未保存为仓库runner；证据包保留冻结协议、输入/代码哈希、预测、逐月指标和重算核验。正式论文复现前需将runner持久化并按协议重新执行。
