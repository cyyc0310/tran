# V49：窄区间覆盖不足，地区水平偏差仍明显

2026-10-27，Sol。本轮建成严格双地区排除的源区风险数据。形状改善在这批回溯样本中继续出现，但窄区间的覆盖仍不足。下半年B0-SizeET-ReplaceR平均覆盖74.4395%，宽度156.3873；其剩余小时平方误差中，84.6509%来自日均水平误差。该比例是所评估数据与模型的诊断，不能推广为所有地区都由水平风险主导。

本轮没有训练风险校准器，也没有得到新的方法创新或独立确认。2025小时评分、PACE/LGEE、真正未查看地区及新增供体2025细分均未打开。它为下一轮风险比较提供数据和失败证据。

## 下一轮的路线约束

优先比较同预算全局校准、分量校准、异方差和条件分位数强基线，检验持续水平偏差及其风险是否能从合法粗信息预测。简单给全域加一个偏移量，无法同时解释MISO与FPL的相反偏差。MC散布、条件均值与未观测地区偏差也不能默认等价。

现有双排除索引保证outer地区的细信息不回流，但六个held教师之间仍可能共享另一held的细监督或小时库；不能直接任拆成proper/calibration并主张独立性。另有五源教师风险向六源部署模型的算子变化，下一轮需保留配对参照，或固定同一部署预测函数再外部校准。

为检查后一条路线，本轮只读元数据盘点了10个其他已开发地区：SWPP、AVA、BANC、JEA、SC、NWMT、SCL、WACM、SEC、SCEG。其H1/H2有效日为1575/1812；截至Oct1、Nov1、Dec1的exclusive累计支持为2478/2787/3080，其中H2为903/1212/1505日。SCL仍保留。[盘点JSON](</Users/cyyc0310/Documents/我为我导扛大旗/项目/AI for Science/transcif-research/results/source-risk-v49-external-support.json>)与[独立核查](</Users/cyyc0310/Documents/我为我导扛大旗/项目/AI for Science/transcif-research/results/source-risk-v49-external-support-review.md>)一致，没有转换这些源的generation或coarse数值。它们未进入当前原池教师，可用于设计分离的校准源；这些地区早已用于其他开发，部分细月监督也已用于V42，所以不计作独立确认，更不代表已经满足发布时点、交换性或条件覆盖要求。

针对性文献核查见[备忘录](</Users/cyyc0310/Documents/我为我导扛大旗/项目/AI for Science/transcif-research/docs/SOURCE_RISK_V49_LITERATURE_NOTE.md>)。函数分解、层次校准、跨环境jackknife和弱标签集均有直接先例。只把它们换名组合，尚不足以支撑方法创新。值得推进的问题是：粗信息相容、真实小时覆盖和兼容世界稳健性分别能做到什么；专门机制需要在相同信息和校准预算下，超过这些强参照。统一基准与信息边界仍是可行的论文路线，但本轮没有完成新的基准压力测试或新算法比较，也不认证最终新颖性。
