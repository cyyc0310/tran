源池固定为V156的PACE/seed41 proper-fit名单，删除PACE/LGEE/SC，剩29区。按SHA256("v159/"+region)排序，轮流分入6组。第k轮测试第k组、校准第(k+1)%6组，其余拟合；每个源地区只承担一次测试角色。每源拟合小时严格复用V156同预算最多4096索引。校准和测试使用该地区2024全部同预算可评价月。不同预算允许其本来就不同的warmup分母，同预算所有方法必须相同。两预算为当月完整统计与月末+30日模拟发布的asof。

## 非负活动坐标

当月完整统计：u_f=g_f/(M_f/T)，M_f=0时u_f置1，和既有重组的缺失燃料形状约定一致。查询载体B=S，天然排除当月零能源燃料。这个缺失形状约定是模型约定，不声称从零能源源区识别出该燃料形状。

asof：先只用proper源输入月组成，按源等权计算先验π，并加1e−6/燃料后归一。定义B(S)=0.99S+0.01π，因此历史零份额仍有正载体；定义u_f=[g_f/(M_input,total/T)]/B_f(S_input)。这是未来小时发电相对过去月规模的活动因子，同时含月度变化和小时波动；训练时未来g是源标签，查询不读取未来月总量。T取该源月份缓存实际有效小时数，只影响每个u向量的公共尺度；映射成CIF后会消去，不使用查询有效小时数定义预测载体。

查询响应R(B,u)=Σ_f EF_f B_f u_f / Σ_f B_f u_f。u非负、B非负，不截负归一，也不将历史0作硬支持。所有动态臂共享固定0.01载体参数，不扫描该参数。

评分前预检发现：部分proper源小时形状在其他组成下产生零总发电量，因此该假想状态CIF没有定义。原始代码将其比值记0；不能默默沿用后宣称物理有效。新增明确对照：保留旧零值约定的legacy参考，另对同一混合权重条件化于B·u>0后归一，不舍弃月份/查询。若所有概率质量均无正发电支持则报错，禁止伪造回退。保存被排除的预测原子质量；它不是经过认证的当地停机概率。这是定义域修正，不直接算新算法。

## 八臂与归因

1. legacy_recomposition：原小时重组；每proper源选择两个最邻近日历月，当前供体月组成到查询输入组成的Hellinger距离、带宽0.3，源等权先验，再按相似度更新并全局归一；最终源质量通常不同。只使用匹配抽样小时。零总量原子仍按原代码记0。
2. positive_recomposition：与legacy相同的形状、供体和权重，唯一变化为条件化于正总量；分离定义域修正收益。
3. activity_recomposition：相同供体、相同权重，改用活动u映射并作相同正总量条件化；隔离动态非负活动标签的影响。
4. conditional_activity_recomposition：同一u和供体，Hellinger改比较供体输入月与查询输入月；是标准条件动态analog强对照。
5. scalar_forest：锚定标量残差分布森林。
6. raw_activity_forest：以原始u作八输出平方误差分裂，叶保留联合u原子。
7. projective_activity_forest：以u/Σu分裂，叶仍保留原始联合u。公共尺度对任何查询CIF都无影响，因此此臂只删除分裂中的无关尺度。
8. response_activity_forest：proper源输入月组成按煤份额排序，0/25/50/75/100分位选5原型；每原型用正总量指示及零扩展的R形成两列，共至多10列，按proper源加权标准化后作分裂。零扩展仅定义分裂特征，不把未定义原子当CIF0参与该方法预测；推理同样条件化于正总量。

当月预算下positive/activity/conditional三个重组臂必须数值等价，是重复控制而不是三种独立成功。raw/projective/response的树结构不同，其他设置相同，均作正总量条件化。response相对projective才是任务响应嵌入的额外收益；动态活动或定义域修正相对旧形状重组的收益不能记到响应规则。响应嵌入仍属于已有有限特征核森林族，尚非论文创新。

## 校准、评分与晋级

独立校准地区的q05/q95失覆盖距离，取地区等权pooled q90和各区q90最大值；分别完整报告，不由测试结果切换。CRPS使用未扩展预测CDF；覆盖/宽度/Winkler使用对应校准区间。源测试区内小时加权、源区之间等权；保存每月、每区、最差区及六折结果。

本轮仅作候选筛查。优先看同预算最强普通重组参考下：宏90%覆盖≥90%、最差源≥85%，CRPS至少降5%、区间评分降低且宽度不增，配对共同月份的描述区间支持；还需预算及源折稳定性。若源筛无增量，不回到目标筛超参。若出现明确增量，再冻结规则，补齐同预算异方差/条件分位数及原版分布森林等强参考，随后才评价当前已查看目标；未查看地区仍需最后单独冻结。

每折预算完成后保存不可覆盖的区块及哈希；完整摘要只在12区块都通过后写出。恢复仅针对确认已终止的原进程，验证同一运行输入及区块哈希后续算，不能因观察超时重启。
