# V216 EIA小时锚的独立中心拟合与有限样本校准协议

## 问题

V215将目标小时锚同时用于中心偏差修正和误差q90估计，可能低估区间风险。本轮固定每个目标区月48个本地小时锚，将它们分给中心拟合与区间校准，使用有限样本split-conformal秩，比较12/36、24/24、36/12三种预算分配。

## 数据、预测与目标排除

数据窗、燃料类别、固定EF、月度水平代理、k=10小时段供体形状及双重留区源残差均沿用[V215协议](V215_EIA_SPARSE_LOCAL_ANCHOR_PROTOCOL.md)。每个2026目标平衡区的所有历史/目标记录均不进入其训练、供体或校准；目标侧月度类别总量保留为允许输入。小时标签仍是EIA小时燃料估算与固定EF机械计算的代理CIF。

## 锚点分割和区间构造

每个目标区月从有效小时中均匀无放回抽48个不同小时，并随机排列。前`n_fit`个锚的预测残差均值修正点中心；其余`n_cal=48−n_fit`个锚计算修正后的绝对误差校准分数。取排序分数第

`r = ceil((n_cal + 1) × 0.90)`

个值作为对称半径（1起始秩），构造`预测±半径`；若`r>n_cal`则半径为无穷大。比较`n_fit/n_cal`为12/36、24/24、36/12。若所有锚一起估计中心和q90，则记为`empirical_reuse48`，只作经验比较；零目标锚仍使用嵌套源区q90。

随机抽取小时索引使锚、校准和未观测小时在固定目标区月的有限小时集合内形成随机分割。在该随机化抽样设计下，split-conformal秩可为**随机未观测小时的边际覆盖**提供有限样本控制；它不保证一次已抽样集合下的整月同时覆盖，也不保证给定固定锚点/地区/时段后的条件覆盖。该解释要求锚点按协议随机抽取；连续日或依赖误差的目的性选点不满足此设计。

## 评分

每个区月、每种分配重复200次。按目标区内可用月份等权，再按24个目标区等权，汇总小时MAE、90%覆盖、区间宽度与Winkler90。地区簇bootstrap为20,000次配对重抽样。与V215一样，不把重复抽样或小时当独立地区。

脚本：[v216_eia_sparse_anchor_split_conformal.py](../scripts/v216_eia_sparse_anchor_split_conformal.py)。逐查询和地区结果保存在`results/v216-eia-splitconformal-anchor-r1/`。
