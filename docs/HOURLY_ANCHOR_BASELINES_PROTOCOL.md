# 月报锚定变化量：同标签预算普通强参考

2026-11-01，Sol。R5后开发对照，参数在新模型训练及扩展日期评分前固定。不是原创方法冻结，也不称弱监督适配成功。

## 要排除的简单解释

R5绝对响应HGB在BPAT的低火电水平外推失效，重组在CISO未来组成跃升时低估。因此先比较可见滞后月火电占比`a`加上源端学习的小时变化，不能把绝对树失效当成复杂结构必要性。只用过去月报条件化，没有目标小时标签或目标月量微调。

源标签严格沿用R5的35448小时和6个proper source tuple；模型输入直接复用R5小时公共设计。源ERA5观察天气、推理GFS预报的差异保持；原月报、静态装机代理及天气分开计分。年度装机历史发布版本尚未认证。

## 固定参数化和训练

真实小时火电比例为`f`。加法响应`z=500+500*(f−a)`；logit响应`z=500+250*(logit(f)−logit(a))/L`，其中epsilon固定0.001，比例先截入[epsilon,1−epsilon]，`L=log(999)`。两响应均在0–1000。解码时加法回到`1000*a+2*(z−500)`并截入0–1000；logit回到`1000*sigmoid(logit(a)+(z−500)*L/250)`。零增量返回公开锚（logit端点按epsilon裁剪）；不是用真实未来组成重新锚定。

沿用R5 HGB：200轮、15叶、最少64小时、学习率0.05、L2=10、关闭早停、种子416。国家→地区→小时均衡损失权重；不声称HGB内部所有分箱和叶计数也国家等权。3–4月、5–6月、7–9月整体留块，所有地区同月一起留出；每个proper fold重新计算权重。OOF是最终2023模型的2022源训练交叉拟合，不是真实2022时点前回放。

每族8次HGB拟合：3个OOF、1个encoded平方损失位置、1个decoded物理误差尺度、3个0.05/0.5/0.95分位数。尺度必须用`abs(1000*f−decode(OOF_z,a))`训练，单位是火电千分比；不能把encoded残差或logit导数近似冒充小时CIF尺度。点预测是逆变换的encoded条件位置，尤其logit分支不宣称它等于物理CIF的条件均值。分位数先排序再单调解码，之后共同乘EF/1000；尺度同样乘EF/1000且在CIF单位最小1g/kWh。

source-only脚本只读取封存2022队列；与R5源OOF的row、真实火电千分比和权重逐值一致才拟合。48族模型/48 OOF保存参数、源tuple、所有留块、响应转换和尺度单位，重载验证。这个阶段不读取扩展2023目标的真值，不做源校准或目标评分。

## 后续评价合同

在固定2023每月15/25日的扩展队列上，保持9种源→目标配置及共同完整样本。目标国不得贡献源校准标签。沿用R5的global、hetero、signed/nonnegative源CQR和中位数包络修复；本轮不新增倍率网格，也不宣称跨域分布无关覆盖。

必须同时保留R5绝对CIF/火电占比模型、固定月报比例锚、同标签配对原银行和有/无天气HGB、同标签简单风光物理比例。不仅拿额外全年标签版本作简单参考。主要报告地区→配置等权MAE、形状MAE、中位数MAE、WIS90、覆盖、宽度、区间分数，按日期/地区展示配对差异；不把小时看成独立国家重复。

新日期仍是开发，不按目标成绩拼地区专属模型。如果普通月报残差已解释优势，就把它归为基线发现；只有超过这些参考的独立稳定增量才讨论专门机制。后续预测/评分runner须另外先封代码与全部预测，再消费目标标签；本协议不冒充该runner已经存在或实验已完成。
