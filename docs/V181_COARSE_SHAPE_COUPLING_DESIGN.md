# V181准备：保持粗与形状边际，先检验配对的价值

2026-10-29，Sol。V180已查看，下一项为源开发诊断；尚无新小时性能结果，不称预注册独立确认。选用V180最佳历史scalar8仅是开发选择，最终仍须冻结后确认。当前没有足够证据推进新地区。

## 尚未隔离的问题

V180每个世界的粗组成v_d与内部q_d配对，且使用同一月度概率p_d。改变概率会同时改变粗预测和形状库。V169研究的是燃料q边际固定下的内部耦合，不能代替本项“月度组成—完整小时形状”的配对控制。V166已做真粗组成oracle，不能把该旧结果或缺失q问题重新包装为新发现。

先比较冻结p与原q库下的两种联合分布：

- 对角配对P(i,j)=p_i 1(i=j)，精确复现V180 scalar8。
- 精确独立P(i,j)=p_i p_j，完整枚举粗世界i和形状世界j；小时atom为v_i*q_jt，不随机抽若干配对，不截掉小正概率。

两者在G>0条件化前的粗边际和完整q边际相同，因此差异来自配对及其后续比率/条件化。E[v_f*q_f]仍可改变，不能称保持八燃料均值或纯尾部贡献。G=0条件化后边际也可漂移，需逐时钟保存排除质量和两组有效边际。未知q=1占位的联合暴露会随配对变化，单独记录。

另设p_i*pH_j作为普通形状选择控制，明确它改变形状边际，不能混入前一个配对效应。暂不拟合copula、不扫描温度/混合系数、不按地区选择例外。若算量过大，先做库存与精确同值支持压缩验证；不得悄悄换近似后仍称精确独立。

沿用29源六折、相同源小时、全部2024 asof校准和测试月。新增候选仍报原Gaussian固定半径及自身pooled/max_region；对角参考精确复现，并与V180重算Gaussian、旧Gaussian、异方差及条件PIT比较。原覆盖/效率gate不变。

## 实施顺序与停止规则

先只用月量、原小时采样索引/时间轴统计完整乘积支持量和内存成本；不读取新小时结果。下一步实现精确独立law，核验前条件化双边际、对角identity、压缩等价、源角色/预算、query未来输入干预，再开始CIF评分和全量复核。

若独立配对不优于对角及强参考，停止这条耦合支线，不直接上Sinkhorn/更大网络。若确有收益，下一阶段才检验是否能从源区合法粗历史学习组成—形状的兼容关系，并用相同边际/容量控制区分水平、形状及调度风险。独立乘积、输运和耦合优化本身不构成原创。

## 近期文献边界

[COFE，IJCAI2026](https://ijcai.org/proceedings/2026/602)分离粗细潜在动态，但其任务给定历史观测序列，不提供本项目零目标小时输入下的现成可识别性证明。[SOCC，2026-10-23修订预印本](https://arxiv.org/abs/2610.24591v2)已经用评分优化依赖结构；仅增加一个评分驱动copula不够原创，且该文仍是预印本。[Pic等，2025](https://ascmo.copernicus.org/articles/11/23/2025/index.html)提出通过聚合和变换构造可解释多元proper score；本项目同EF投影指标不能称新的评分理论。

待争取的技术贡献应针对受限信息：哪些粗误差足以约束跨尺度风险、剩余调度风险需要什么明确假设，以及这些假设在新地区如何失效。此处是研究问题，尚无新机制或保证。真实中国月报/发布合同、固定EF代理边界和未查看地区规则均保留。
