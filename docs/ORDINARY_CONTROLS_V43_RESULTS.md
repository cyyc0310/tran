# V43：普通混合改善CIF，内部水平与可靠性问题仍在

2026-10-27，Sol。固定的75%旧CoalOilUpper加25%扩展DirectEF-ET，把mean CIF宏MAE从16.3961降到14.7219，降低10.21%；EF宏MAE从25.7082升到29.7641，增加15.78%。三十五个新对照中，四个CIF改善，零个EF改善，零个两项同时改善。普通混合已提高后续方法需要超过的参照，但没有提供原创机制或风险覆盖证据。

## 比较范围

按[生成组合前固定的合同](ORDINARY_CONTROLS_V43_PROTOCOL.md)，本轮只计算十对端点各三个全局权重和五个扩展范围回退，零新拟合。所有旧、新端点及原MG粒子已在V42/V34封存。EF逐粒子混合后乘相同MG_POS；未混合中位数，也未裁切或重新投影。

仍为七个已反复用于开发的地区、42次2025年月初查询、原35个可评分月；ISNE只有一个月。本轮不具独立确认性，没有用结果选择新的权重或打开未查看地区。容量B1与仅粗统计B0的输入区别保持，登记库存的中国可得性和报告成员一致性仍未认证。

指标先按地区平均，再对七地区等权；EF单独评价POS内部水平，CIF为固定因子的发电侧强度代理，单位gCO2/kWh。RMSE仍为地区RMSE的宏平均。原2520条参考数值保留，新2450条合并后共4970条case，全部mean/median和逐地区结果均保存。

六个地区CIF改善，FPL变差；五个地区EF改善，BPAT和FPL变差。BPAT的EF MAE从1.4988升至60.9688，足以使EF宏平均退化，虽然它的CIF MAE略降。内部水平误差不能由CIF排名代替。

## 扩大经验范围会取消有用回退

五规则的旧q是扩展q的源白名单子集，query仍用原库存特征。扩展只改变经验极值池，不重训旧Size-Ridge，也不增加候选库存但没有合格监督的地区。因此逐query回退权重只能不变或减少，这个几何不变量全部成立。

| 规则 | 原→扩展触发数（42查询） | 原 CIF / EF | 扩展 CIF / EF |
|---|---:|---:|---:|
| Range4 | 30→12 | 17.7785 / 46.4268 | 23.7543 / 37.0634 |
| CoalUpper | 6→0 | 20.8232 / 25.1029 | 28.0021 / 36.4611 |
| OilUpper | 6→6 | 23.5751 / 37.0664 | 23.5751 / 37.0664 |
| CoalOilUpper | 12→6 | 16.3961 / 25.7082 | 23.5751 / 37.0664 |
| AnchorEFUpper | 6→0 | 20.8232 / 25.1029 | 28.0021 / 36.4611 |

MISO的原CoalOilUpper在六次查询均选择容量锚；扩大范围后六次均回到旧Size-Ridge。其CIF MAE由22.7384增至72.9908，EF由50.2241增至129.7311。旧基模型未重训，这个受控反例说明：仅扩大极值范围并取消回退，会恢复原有模型误差，不能把“进入供体范围”当作可靠性证据。

这不否定新增供体对模型训练的价值。V42的扩展树模型确实有局部收益；本轮隔离的是范围规则本身的变化，不能外推为所有支持估计或所有容量方法均失败。

## 事后误差分解：CIF下降的来源并不相同

预测和评分完成后，对旧回退与固定w=0.25混合的35个月分别计算，共70条[误差分解](../results/ordinary-controls-v43-posthoc-error-components.csv)。它没有参与训练、权重或路由规则选择。使用粒子总体协方差，有精确恒等式：

\[
\widehat I-I^*=(\bar g-g^*)e^*+\bar g(\bar e-e^*)+\operatorname{Cov}_{particles}(g,e).
\]

BPAT的粗组成项地区均值保持−4.6479，内部EF误差项从+0.0939升至+4.0712，抵消了更多粗组成低估。CIF改善在这里包含错误抵消，不能解释为内部EF更准。FPL的粗组成项为+9.3314，内部EF项从+2.8826增至+11.1111，两项同向，CIF因此变差。MISO内部项从−31.0077变为−22.8981，同时单独EF误差下降，属于可见的水平改善。不能把各地区的收益归为同一个原因。

70行恒等式残差最大1.20e−13；分量有符号，其绝对值不能直接相加得到MAE。

## 后续研究判断

这轮更新了两个事实：普通全局混合足以改善CIF主指标；经验范围扩张不足以判断何时取消锚定。尚未找到能由合法本地信息判断容量增量适用条件的机制，也没有覆盖与区间效率结果。

后续应先检验源外B1增益方向是否可预测，或是否存在比普通特征拼接更合理的标准容量结构。它们都必须保留本轮普通混合、旧CoalOilUpper和强B0参照。容量偏置、源加权和门控已有先例，即使有效也先作为强基线；只有在同预算下解释并控制剩余风险，才有理由主张专门创新。

本轮不足以冻结方法或测试未查看地区。原小时、PACE/LGEE、真正未知地区及新增供体2025细分保持关闭，长期目标active。
