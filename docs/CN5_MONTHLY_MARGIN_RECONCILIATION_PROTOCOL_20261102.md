# 滞后月度技术边际约束的小时形状迁移协议

冻结日期：2026-11-02，运行前。检验一个尚未直接测过的发电侧候选：把源域小时技术形状映射到目标可见的五类滞后月度边际，并以迭代比例拟合（IPF）协调每小时单纯形与整月技术边际。它是跨域组合预测协调的应用候选，不预先声称新算法。

## 问题与估计对象

目标只有严格CN5滞后月统计`t−2…t−7`和日历，是否可用源域学得的日内技术形状，构造月内每小时五类发电占比，并确保预测小时在**源模型给定的小时总量权重下**严格还原预测时已知的`t−2`五类月度份额？预测时不可见的目标月实际总电量、小时总量、小时发电组成、目标CIF均不得进入投影。

本实验不声称`t−2`份额等于未来目标月真实份额。它把`t−2`份额作为现有模型同一滞后预算下的月边际预测值，并测试一致性约束是否改善小时CIF代理的点误差和区间评分。

## 数据与冻结比较

- Energy-Charts严格CN5九国整国LOCO开发队列；其目标、2024标签此前均已打开，故不是未看地域确认。
- 外层：其他八国2022小时标签拟合；其他八国2023H1整国等权残差校准；留出国2024小时固定因子发电侧代理评分。
- 标签：九类别小时发电按固定EF计算，单位gCO₂/kWh。该代理不是中国实测/官方小时CIF，结果不外推到消费侧。
- 预测输入：既有五类火、水、核、风、光份额`t−2…t−7`与日历；候选投影只用每目标月`t−2`五类份额和源模型预测的小时总量相对权重。
- 同队列固定对照：`anchor700`、`ratio_recomposition`、`factor_history`、`fuelshare_history`及候选`monthly_margin_ipf`。其余训练、特征、外层留出和评分沿用严格CN5 runner。

## 候选算法

1. 对目标小时h和技术组g，用源重组已有的日内组形状`profile[h,g]`与预测目标月滞后份额`m[g]`生成非负先验强度`q[h,g]=m[g]×profile[h,g]`。
2. 将先验每行归一化形成小时组成先验。月内行边际固定为源模型`q[h,:].sum()`给出的预测小时总量相对权重；列边际固定为`t−2`的五类份额`m`。用IPF求满足行、列边际的非负矩阵。零先验单元采用固定`1e−12`支持下限，仅用于保持数学可行；不得根据标签调整。
3. 候选小时发电侧代理为源域热电有效因子乘闭合后的小时热电份额。唯一处理差异是将自由归一化的比例重组改为满足滞后月边际的投影。
4. 每个目标月审计投影行和、列边际、非负性、迭代次数和支持下限质量。若任一月误差大于`1e−8`或未收敛，本折候选记为失败，不人工修补。

## 评分与晋级门槛

来源半径只从其他八国2023H1伪目标标签计算，所有目标预测/半径先封存、校验哈希，再读2024目标标签。报告逐国与逐月MAE、日均去中心形状MAE、90%经验覆盖、宽度及Winkler；宏观按每月等权后每国等权，同时报告最差国。小时不是独立统计样本，显著性不按小时数估计。

晋级要求候选同时满足：相对`ratio_recomposition`和`fuelshare_history`宏MAE至少降低2%；形状MAE不恶化；Winkler改善；宏覆盖相对两强基线均不下降超过1个百分点且不低于88%；最差国覆盖不比最强基线低超过5个百分点。否则关闭IPF边际约束路线，不在这九国/2024上扫epsilon、换小时权重或重调阈值。通过也只能在算法冻结后安排一次真正未查看地域确认。

## 解释限制

`t−2`目标月份额来自修订小时序列回算，非as-issued月报版本；目标标签为代理。IPF是已有的边际协调工具，实验的潜在贡献只能来自“约束后的跨域小时形状是否带来可重复的CIF增益”，不能将数学投影本身包装为原创。源模型预测小时总量权重也是结构先验，不是目标实测负荷/出力。
