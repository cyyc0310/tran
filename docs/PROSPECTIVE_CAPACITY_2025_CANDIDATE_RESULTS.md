# 2026年11月前瞻任务：2025年度装机候选已封存，待标签评分

更新：2026-11-01。该实验直接承接用户同意单列年度装机信息预算的决定。目标仍是GB小时标签迁移到US七个已见BA；目标期为尚未结束的2026-11，因此当前只有预测候选，没有精度结果。

## 运行内容

已从2026年11月1日前可用的EIA-860最终2025数据和DUKES 2026 Table 5.7构造煤/气年度装机特征；对七个US BA按EIA发电机登记BA聚合nameplate，GB源使用包含北爱尔兰的UK容量代理。候选臂在原始2020 M+C封存文件旁独立生成，增加2025容量Ridge、提升树和简单煤气份额锚。月报M预测、目标时间戳、输入份额和旧2020 M+C输出均逐行保留，旧预测seal未修改。

对7区5,046小时核验发现：不含容量的M预测与原封存值最大差异小于4.55e-13；重新拟合的2025容量Ridge/提升树与2020容量臂的对应点预测最大差异也小于4.55e-13。这符合本次只有一个GB训练源的设计：源内容量字段是常量，学习器不能从数据中学到跨域容量变化如何影响CIF。该结果说明当前单源任务不能识别学习容量头的增量；它**不等价于**容量信息在多源训练中无价值。

2025简单煤气份额锚随目标BA变化，给出了可比较的可解释候选；其逐小时输出依赖月报热电份额但不学习月内火电因子变化。目标尚无标签，故现在不能判断这个锚与M、2020 M+C的误差、形状或覆盖优劣。容量Ridge/提升树的源Gaussian区间也只反映GB 2023校准，不保证跨域覆盖。

## 判定与后续

此轮完成了预算接入和可识别性检查，没有形成容量预测收益结论。将来目标响应发布后，在相同5,046小时配对评分原始M、2020 M+C、2025 M+C两学习头和2025简单份额锚；逐BA报告MAE、形状误差、覆盖、区间宽度、CRPS/WIS，并并列ISNE/MISO负水电截零敏感性。即使2025简单锚胜出，也只能支持此预测任务的信息增量，不能证明可迁移算法创新或中国准确度。
