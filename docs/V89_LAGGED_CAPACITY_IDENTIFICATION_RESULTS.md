# V89：滞后一年容量仍保留尾风险识别增量（2026-10-28）

V89沿用V88的25 BA、固定EF、月度燃料边际、容量约束解析和三个月尾频率目标，但将信息时点改为：评分2024月使用2023年末EIA-860机组容量，评分2025月使用2024年末容量。这样容量在评分年度开始前已发布，消除了V88同年年末容量的主要发布时间泄漏。

589个完整度≥80%的BA月中，326月（55.3%）所有观测小时燃料峰值都被滞后年末容量覆盖；其余263月不计硬约束结果。可用率下降，但在可用子集上，信息增量基本保持：

容量新信息约减少三分之一边界宽度，且低阈值尾目标弃权从75.5%降到约5%。但这是**通过标签核验后**的回溯机制收益；当前数据不能证明容量清单在一个真正小时标签隐藏的新BA或中国省份上能够满足上界。下一步冻结变换和阈值，按不查看目标尾标签的外区划分做独立确认，并将容量匹配失败按方法失败保留在分母里。
