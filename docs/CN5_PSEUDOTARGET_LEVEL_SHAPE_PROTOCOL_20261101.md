# 严格五类伪目标的水平锚定与形状迁移协议

2026-11-01。此实验把Lower 48开发诊断提出的固定组合放入已有严格CN5九国整国留出队列。目标是判断“低频粗组成只提供小时形状、稳健锚提供水平”能否跨多个国家重复，而非优化单个美国目标。九国标签都曾在其他开发实验中查看，故这是方法筛选，不是未查看国家确认。

## 冻结方法

对每个外层目标国，以其余8国2022小时标签训练严格五类模型；只允许目标国火、水、核、风、光的滞后`t−2`至`t−7`月量和日历输入。

- `anchor700`：`700 × 目标热电月份额`，作为水平锚。
- `ratio_recomposition`：跨源区等权小时形状与目标五类月份额组合，作为完整重组基线。
- 候选`level_anchor_shape`：`anchor700 + (ratio_recomposition − 当地日均ratio_recomposition)`。后一项在当地日内均值为零，因此只传递形状、不改变锚定日均水平。公式不使用目标标签，也不设自由混合参数。

源端风险半径只用其余源国2023H1伪目标残差，按国家/地区/小时权重取绝对残差90%分位；不使用目标国的小时标签、目标H2或2024信息选择模型、估计偏差或校准风险。

## 评分和晋级门槛

固定EF发电侧小时代理；按目标国等权报告2024年MAE、去日均形状MAE、90%覆盖、区间宽度、区间分数及国家级最差值。候选进入冻结/新目标确认的必要条件：相对`anchor700`和`ratio_recomposition`均有明确的国家等权点误差或区间分数增益；宏覆盖不低于90%，至少7/9国覆盖不退化超过5个百分点；最差国不出现严重负迁移；宽度不靠牺牲覆盖来缩窄。无新增参数搜索。

本实验沿用已知九国数据和统一固定因子代理，不代表官方观测CIF、真实历史月报发行版或中国小时效果。
