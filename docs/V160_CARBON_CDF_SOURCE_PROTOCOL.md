# V160：源区碳CDF分裂与一般分布学习对照

在V159完成并审计、V160评分前冻结。复用V159全部29源、六折角色、两预算、58份拟合抽样及逐查询输入；不增加本地信息，不读取新的2025目标。每折独立proper训练、源校准、源测试；所有V159方法保留作参考。

V159的活动原子u、查询载体B、20维X、32树/min_leaf64/seed20261028、等源权重及正总量条件化全部不变。新增四臂：

1. scalar_cdf_forest：对标量锚定残差y，在[-1000,1000]的80个等距箱中点作1[y≤τ]分裂标签；叶分布仍是标量残差，推理加查询锚并裁[0,1000]。这是一般CRPS近似分裂参考。
2. activity_mmd_forest：以u/Σu为输入响应，proper源等权分布抽取1024对计算非零欧氏距离中位数作Gaussian带宽，固定80个随机Fourier特征作分裂标签。频率N(0,I)/带宽、相位U(0,2π)，随机种子由SHA256(v160/fold/budget)固定。叶保留联合u。这是同80维标签预算的一般MMD近似参考，不是原版honest DRF实现。
3. mean_smoothed_forest：proper原型仍严格复用V159记录的五个组成v；分裂标签为R(0.99v+0.01π,u)的proper加权标准化均值响应。平滑载体仅用于反事实分裂字典，查询载体仍按原预算。这隔离“改平滑原型”与“改分布学习目标”的效果。
4. carbon_cdf_forest：相同五个平滑原型，每原型在[0,1000]的16个等距箱中点τ上用1[R≤τ]，合计80维。等宽阈值/等原型权重，不按列逆方差缩放，避免改变近似积分CRPS的相对权重。叶保留联合u。

所有平滑分裂载体全正，源u有正分量，R定义良好；推理当月载体仍可有0，照V159条件化于正总量。字典为proper源信息，不以目标输入、校准标签或测试标签选阈值/带宽。

平方误差分裂在CDF指示特征上比较左右经验CDF，因此近似对碳响应分布的积分差异；它仍是有限特征核森林，而非新分裂原理。若一般MMD或标量CDF同样有效，不能将收益记为专门碳机制。只有碳CDF臂稳定胜过这些参考、平滑均值对照及V159最强普通模型，才有继续研究的依据。

asof的mean_smoothed必须复现V159 response_activity_forest：其原型本来就用了同一0.99v+0.01π，正总量门指示为常数，删去后恰是相同五维标准化响应。全体asof测试记录CRPS/MAE/覆盖/宽度/Winkler逐项核验≤1e−7；这是一项复现控制，不算新模型成功。

校准、评分、门槛与V159完全相同。逐折预算不可覆盖区块、依赖及输出哈希、完整分母和描述性配对比较均保存。只有在源区出现覆盖保持的效率增量，才准备下一步冻结与强参考扩展；目前未批准打开未查看地区。
