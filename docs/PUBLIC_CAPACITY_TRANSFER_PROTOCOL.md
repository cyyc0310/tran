# 公开煤／气装机的跨国信息价值对照

2026-10-31，用户允许单列年度装机信息预算。本轮先做可审计的公开静态装机代理试验，随后再补齐同口径年度版本；两者不能混称。协议在新模型运行和评分前写入，但各目标此前已用于月报开发，不是独立确认。

## 来源及限制

美国原7区使用2020年EIA-860 OP库存，公开档案Last-Modified为2021-09-09，按2021-09-10已可用；仅取煤／气容量。按电厂登记BA分类，不是逐时运营BA的完整物理库存。已有curated库存、原生压缩包与获取SHA保留。

德国、英国取WRI v1.3.0官方S3发布包，Last-Modified为2021-06-02，按2021-06-03已可用。其煤／气为电厂primary_fuel容量汇总，不分摊双燃料。两国year_of_capacity_data全部缺失，容量覆盖不完整；英国包括北爱尔兰，而小时目标为GB。这是公开静态辅助特征，不是准确年度容量或硬运行上限，不把容量零解释成燃料不存在。不读取WRI任何实际或估计发电量列。WRI与EIA来源不同是额外迁移误差，不能归于新算法。

已另取DUKES 2021年报及德国Monitoringbericht 2021用于后续口径审计，未混入本轮输入。前者现有工作簿Last-Modified为2022-03-10；后者现有PDF为2023-11-02，虽原报告2021年发布，当前文件版本不自动认证当时字节。WRI不能改写成同口径年度真值，也不据此认证中国省级装机。

## 固定设计

复用三国原7美国区域、2022训练、2023H1源校准、2023H2整国留出及全部9个单源／双源配置。保留原月报8方法；原方法输入、训练与预测须逐值相同。装机分支增加一个煤/(煤+气)容量比例特征，均只用同一公开容量表，不用目标小时数据训练或校准。

六个新增方法全部报告：容量比例固定因子平锚；相同因子加原重组形状；源煤／气名义利用率乘目标容量再重组；原标准化Ridge加容量比例；相同HGB直接CIF；相同HGB有效火电因子加原形状。利用率只从源2022细燃料监督学习，按国家/地区权重平均；它可超过1，不能解释成物理容量因子认证。两燃料锚默认未解析油/other不额外升高因子，是粗近似，需与固定700及原macro/ratio重组比较。

Ridge alpha10；HGB 80轮、15叶、minleaf100、L2=10、seed416，无early stopping，参数与月报参考一致。每个方法仅用源2023H1残差的90%加权分位半径；不根据目标覆盖调宽。该半径没有跨国覆盖保证。先封存全部目标点预测再评分，MAE、日内中心形状误差、覆盖、宽度、区间评分逐月/地区/国家等权报告。

这一轮是信息价值及强基线筛查，不是专门创新。只因容量简单锚改善就说明信息有效，不能宣称学习机制创新。若常规模型未稳定超过同预算简单锚，停止给它增加复杂模块；若有增量，再用源内留域和未查看国家确认。仍须分别回答低频水平和小时形状是否改善，不能靠扩大区间推进论文主张。

## 源权重修正版本

r1及代码已封存。独立审查发现：r1先构造全样本国家等权，再排除零库存地区，使双源煤率的US权重变为5/12、另一国7/12；气仍各1/2。r2只修正这一不一致：每个燃料分别在正库存子集重新构造国家等权、地区等权。库存零不认证发电零，保留正库存下的零发电率。无符合条件地区的国家不虚构率值，计入可用性限制。新单测覆盖此失衡；源训练、输入、全部模型超参和区间规则不变。修正源于权重合同，不按目标分数挑版本；r1的全部正负结果仍保留。
