## 残差表示与恒等式

对s的原监督月，先检查c_POS=sum四容量有限且严格正，再令x_f=G_f/c_POS，预测xhat_f=(C_f/c_POS)*u_f(month)，r=x−xhat。x是发电贡献，不是G_f/C_f率；C_f=0/G_f=0时x_f=0有定义，不能误称填了零利用率。C_f=0/G_f>0仍明确失败。名义率可>1，库存不是出力硬界。

保存四贡献残差、d=sum r（总量残差）、k=600*r_coal+400*r_oil（相对400因子底座的碳贡献残差），以及真实/预测的POS内部EF。两个分母sum x和sum xhat都必须正，不加epsilon。核验精确关系：

`EF_true−EF_pred = ((1000,400,800,400)−EF_pred) dot r / sum(x)`。

该恒等式只描述发电侧固定因子代理，不能当成实测排放。EF差为true−pred，与前轮score的pred−true符号相反，列名明确标识。

前段EF偏差是细标签信息，目标部署不可获得。将它延续到后段仅是不可部署的细标签持续性参考；它可能劣于零偏差，不能称数学上界或合法可部署预测基线。早段d才属于未来可能使用的粗历史信号；本轮只看跨源关联，不拟合由d预测EF的回归、选择模型或声称识别。恒等式亦可写为`[k−(EF_pred−400)*d]/sum(x)`；d与EF偏差的关联可能来自归一化或底座项，不能单独证明恢复了燃料误差分配。

若EF偏差有持续性但d与后段偏差关系不稳，说明“区域偏差持续”仍不足以支持粗量纠偏；不能由前者跳过后者。若两者都有稳定关联，后续再以严格outer隔离与同预算mu-only/普通回归/协方差控制测试2025未来EF/CIF。无论结果怎样，都不能把协方差、贡献变换或相关性作为原创方法。
