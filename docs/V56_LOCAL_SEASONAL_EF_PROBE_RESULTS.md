# V56 本地季节匹配 EF 探针结果

使用 V55 同一数据划分：2025 H1来源校准，2026 H1时间前推评分。所有候选都只读取起点前已发布月表。结果仍属开发探针，不构成独立确认；详见协议 `docs/V56_LOCAL_SEASONAL_EF_PROBE_PROTOCOL.md` 和明细 `results/v56-local-seasonal-ef-probe-r1/`。

上一年同月锚不如最新已发布月份；等权混合略降Winkler和宽度，却把宏覆盖压到86.2%，低于名义90%目标。PSEI的2026 H1点MAE在各本地方案约105–106，覆盖约49–67%，远差于剩余四区。LDWP、GRID的最新月水平校正优于年度/去年同月，但仍未达到覆盖目标。于是简单季节匹配不是明显破局点，短窗/混合也没有在风险效率上同时达标。

这些探针共同支持：本地可得月度燃料组成对水平有价值且时效会影响水平校正；把一个热组标量改成“上一年同月”或混合并不解释持续小时误差。剩余低覆盖来自当前因子水平和小时结构共同失配，现有可用月度细分对PSEI类地区仍不能把失配降到小时区间校准可接受范围。
