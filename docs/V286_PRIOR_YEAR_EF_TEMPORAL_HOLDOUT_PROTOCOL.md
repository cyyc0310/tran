# V286：上一年本地EF支持 + 9日校准的时间外年度检验

冻结日期：2026-10-30；目标为PACE与LGEE的EIA官方小时CO₂标签 **2020-01至2023-12**。这四年目标标签未用于V280/V282/V284的目标评分；2024因子曾在V282中作为2025先验被检查，所以明确排除2024目标。地区不是地理盲测：PACE/LGEE此前有代理研究和2025标签开发。

## 固定设置

- 标签：EIA `CO2 Emissions Intensity for Generated Electricity`；只保留完整本地24小时、正发电小时；剔除缺失/重复小时的日期。月内至少20个完整日；逐月燃料分项与正发电量总和须在95%–105%内。
- 每个目标月的强度中心与燃料边际均由该目标月完整日计算，属于oracle/后验月度信息。因此这是**给定目标月均值及月燃料边际的小时形状风险时间外检验**，不是月前预测。
- `cems_support`：V269按季度、燃料类别的CEMS支持；`other=400 g/kWh`，非化石=0。
- `prior_year_local_ef`：仅使用目标BA前一自然年、正发电小时EIA `CO2 Factor: COL/NG/OIL`的经验min–max；若前一年对应燃料无活动，则回退到当季度CEMS支持。目标年因子列不用于构造区间。
- `source_loo`：BANC、BPAT、CISO、ERCO、FPL、MISO、NYIS七供体在同年同月的EIA日最大名义偏差，不含PACE/LGEE。
- 每个BA-month随机9个完整本地日；同一燃料聚合观测字段选择、逐小时LP、日最大端点偏差和90%有限样本半径沿用V284；每月100次重复，随机种子286。
- 报告小时覆盖、日同时覆盖、区间宽度、Winkler-90。测试日完整燃料结构的LP包含只作事后诊断。

## 候选复制门槛

`prior_year_local_ef`需要同时满足：宏平均日覆盖≥90%；PACE和LGEE各自日覆盖≥90%；四个BA-year每个日覆盖≥90%；宏Winkler低于同预算`cems_support`和`source_loo`；宏平均区间宽度低于`cems_support`。任一门槛失败则本次时间外复制失败，不调参重测同一目标。

这是对同一两个地区的时间外检验，不构成未查看地区或中国外部验证。9日预算与方法均在目标标签读取前冻结。
