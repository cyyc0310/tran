# Energy-Charts物理潮流数据可用性审计：丹麦候选

日期：2026-11-01。目的在于为独立的消费侧研究轨道核实是否存在可复核的公开小时潮流输入。此处只审计接口、时间分辨率、序列字段和缺失值，不训练预测器、不查看或汇总CIF误差。

## 数据源与实际覆盖

从Energy-Charts API v2分别获取丹麦`public_power`与`cbpf`接口，保存原始响应、请求URL、服务端生成时间、许可和SHA-256：[机器审计清单](../data/energy-charts-flow-audit-r1/audit_manifest.json)。原始响应中的目标年份数据没有做任何模型评分。

| 数据 | 分辨率/单位 | 2024本地时间覆盖 | 2024字段完整性 |
|---|---|---:|---|
| `public_power`：发电、负荷与汇总交易字段 | 1小时 / MW | 8,784小时 | 负荷完整；煤、气、油、风、光各自缺失0–1条；生物质缺1条、废弃物缺2条。水电、核电字段未出现在响应中，须先核验是真实结构零还是未报告。 |
| `cbpf`：跨境物理潮流 | 15分钟 / GW | 35,136个间隔 | 德国、荷兰、挪威、瑞典、英国五个邻接流及汇总值均完整；官方符号约定为正值流入丹麦、负值流出。 |
| `cbet`：计划/商业跨境交换 | 15分钟 / GW | 35,136个间隔 | 2024字段完整，可用于与物理潮流区分；它不是实际物理流量。 |

API把`cbpf`定义为physical flows、把`cbet`定义为scheduled commercial exchanges。[Energy-Charts API文档](https://api.energy-charts.info/) 2024配对比较中，15分钟CBPF先换算为小时平均MW后，物理净受电与CBET计划净受电的平均绝对差为714.5 MW，中位数413.8 MW、90分位数1,908.7 MW；因此不能用计划交易替代实际潮流。`public_power`内的`cross_border_electricity_trading`与独立CBET总量在本样本最大差0.5 MW，说明这个小时字段代表计划/商业交换。GB相关物理潮流在2022年整年缺失、2023年缺失32,064/35,040个15分钟间隔，2024年才完整；如选2024作目标，不能把2022–23的GB空值补零来构造来源风险。

对齐2024小时后，发电燃料字段、负荷、CBPF和CBET共有8,779个完整小时。按已观测八个发电字段求和后，平均发电为3,924.5 MW、平均负荷4,187.2 MW、平均净物理受电434.1 MW；`发电+净受电−负荷`平均残差为+171.4 MW。绝对残差/负荷中位数2.36%、90分位数10.31%。这个残差可能同时包含损耗、未覆盖电源和统计边界差异，不能直接当成网损估计。结果与具体聚合公式见[机器诊断](../data/energy-charts-flow-audit-r1/hourly_balance_and_flow_comparison_2024.json)。

接口日期查询会把`end=2025-01-01`解释为包含该本地日期；文件因此额外含有2025-01-01数据。审计按本地时间显式筛选2022、2023、2024，不把UTC跨年边界误算到相邻年。原始文件名标明完整请求范围，不能仅凭文件名把其当作已裁剪的三年面板。

## 能支持的下一步与不能支持的结论

1. **支持构造海外消费侧信息价值压力测试。** 在核验发电分类分母、缺失小时、单位、符号以及丹麦跨境边界后，可比较本地发电侧强度与基于物理流入/流出推导的消费侧参考量；所有输入预算需并列报告本地五类月报M、滞后交换量扩展M+X和额外来源强度信息。
2. **尚不能直接构造可信消费侧CIF。** 物理潮流只给电量，不给每条进口电的小时来源碳强度。消费侧目标至少要说明邻国排放强度如何得到、是否递归追踪邻国的再进口、如何处理损耗和储能、以及丹麦本国的双区边界。仅用邻国本地发电强度乘净进口量是一种近似，不应标成严格潮流碳追踪。
3. **不等于中国可部署数据。** 这是欧洲开放API的国家级样例，统计边界和可得性不同于中国省际实际潮流；它只提供一个可公开复现的消费侧方法开发环境，不能填补中国小时消费侧输入/标签缺口。
4. **不是未查看国家确认。** 丹麦小时碳强度/预测数据曾出现在项目其他Carbon Monitor开发数据中。虽然Energy-Charts的这组物理潮流序列此前未用于TransCIF，后续结果只能称为新标签合同下的探索性压力测试，不能宣称全球意义上的盲测国家确认。

## 建议的下一项实验

下一步先核对缺失的水电/核电字段和发电/负荷统计边界，并冻结来源因子与跨区分配公式；再决定丹麦2024消费侧参考是否能用于评分。只有在能量平衡残差可解释、排放来源映射独立于预测器、流量方向与小时能量单位核对通过后，才比较同一小时上的M、M+X、强重组、直接模型与流量基线。消费侧结果必须单独报告，不能与五类发电侧代理合成一个指标。

候选的流量追踪方法基础可参考Tranberg等对欧洲小时级生产/消费核算的工作；其方法依赖源区发电和跨区物理流量，并强调消费侧与生产侧并不相同。[论文](https://arxiv.org/abs/1812.06679) 本报告不声称已实现或验证该追踪算法。
