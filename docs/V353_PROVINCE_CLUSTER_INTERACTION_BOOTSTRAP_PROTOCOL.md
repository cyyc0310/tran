# V353 protocol: province-cluster bootstrap for V352 interaction

Summarize each V352 province-month interaction by its province mean, then run 20,000 paired cluster bootstrap replicates over the 30 provinces with a frozen seed. Report equal-province mean complementarity, percentile 95% intervals, leave-one-province-out mean range, positive/negative province means, and paired threshold contrasts (100−300, 300−500, 100−500 g/kWh).

Resampling provinces preserves within-province dependence across months and thresholds. The finite 30-province cohort means these intervals quantify sensitivity to province composition; they are not a universal generalization guarantee or external validation.
