# 严格CN5滞后非热电组成轨迹与小时响应协议

冻结日期：2026-11-01。问题：目标侧仍只见`t−2…t−7`火、水、核、风、光月份额时，水/核/风/光份额的近期趋势是否提供当前特征合同里没有的可迁移信息，帮助源小时监督预测目标热电因子或四燃料份额？本实验只作严格CN5已查看九国开发筛选。

## 已有特征与待检验增量

基础模型输入来自`multicountry_cn5.HISTORY`，已有当前`t−2`五类份额、近六个月热电均值/标准差/变化、总量变异与小时/日历特征。本实验为水、核、风、光四个非热电份额，另计算六个滞后月`t−7…t−2`的线性斜率与最近三个月减早三个月均值差，共8个特征。两者都由预测时已经可见的同一六个月输入构造；不使用目标小时标签或内部燃料组成。

候选一：把这8个趋势特征加入源小时训练的标量热电有效因子HGB。候选二：加入源小时训练的四头燃料份额HGB。树结构、正则、输入预算、目标热电小时形状、固定燃料EF、训练折均与现有基线一致。没有新超参数，不在目标侧选择斜率长度、截断或变换。

## 数据隔离与评分

- 严格CN5九国整国外层留出；2022源小时训练，2023H2源小时交叉池化校准90%残差半径，2024目标响应评分。
- 目标侧仅使用CN5五类月统计与日历。将滞后轨迹从`raw`五类月量计算，并与标准特征按目标月份逐行配对。
- 六个月特征窗口不插补。对训练、校准、2024评分统一只纳入轨迹完整的小时；必须报告各目标国可评分小时数/原有小时数。各强基线使用同一小时集合，以防缺失月份造成不公平比较。
- 固定配对方法：700锚、比例重组、因子历史HGB、四头燃料份额HGB、因子轨迹HGB、燃料份额轨迹HGB。相同折、标签、权重和校准时间段。
- 所有逐国小时点预测、来源半径和输入/代码哈希先封存并校验；之后才能读取目标2024细燃料标签，计算月度/宏观MAE、日内形状误差、90%覆盖、宽度、区间分数及燃料份额/火电有效因子机制误差。

## 晋级与停止

只有在轨迹HGB相对已有对应HGB及强重组，在宏MAE或proper interval score上有实质增益，区间没有靠加宽获覆盖，且CZ/NL/HU/SI最差域不进一步恶化时才保留。若斜率头不增益或仅改善少数国家、组成分数却不改善小时CIF，则停止同类轨迹窗口/特征扫描，不进入未查看国家确认。

现有`LAGGED_TRAJECTORY_RISK`评估的是多月轨迹对风险半径/覆盖的预测能力；本轮锁定的是源小时监督的目标热电因子/组成中心模型，两者问题、输出与指标不同。尽管如此，滑动斜率只是一种标准特征表示，本身不构成原创算法；本轮结果只判断它是否值得进一步整国确认。
