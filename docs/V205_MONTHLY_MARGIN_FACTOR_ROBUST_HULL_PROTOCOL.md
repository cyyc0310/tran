# V205：月度燃料边际在因子不确定下的小时尾计数稳健端点

冻结日期：2026-10-29。

## 问题

V66/V87在固定燃料EF下量化月度类别电量对小时超阈值计数`K`的锐界；V99检查中国月度组成在EF区间下哪些燃料跨阈值，但没有把它转成月度边际下的K端点。V103/V104及V129已在含装机容量的EIA信息合同中检验因子不确定性。V205只补这一个明确缺口：**不加小时容量/爬坡/负荷时，固定月度燃料电量加EF区间能给出多宽的小时K稳健端点包络？**

## 输入、燃料和压力情景

- 复用Ember中国31省逐月八类发电量的冻结V60面板，2016–2024完整省月。该表是二次估算数据，不是用户原始月表，也没有as-of版本证明。
- 活跃类别使用煤、气、其他化石、核、水、风、光、生物质；EF单位gCO₂/kWh。
- 参考名义值：煤1000、气400、其他化石400，其余0；与V66一致。
- 窄压力盒：煤[900,1100]、气[360,440]、其他化石[360,440]、其余0。
- 跨阈值宽压力盒：煤[900,1100]、气[360,440]、其他化石[200,600]、其余0；该盒与V99 stress设定一致。
- 目标阈值：100、300、600、900 gCO₂/kWh；严格事件定义`C_h>τ`。

## 识别计算

对任意固定小时分配，`C_h`对每个类别EF单调不减。因此对EF盒中所有向量和满足月度边际的任意非负小时分配，最小可行`K`由所有EF取下端时的月度边际锐下端给出，最大可行`K`由所有EF取上端时的月度边际锐上端给出。分别调用V66解析识别公式。报告`[K_min(low EF),K_max(high EF)]`为**稳健端点包络**：端点在定义的分配集合内可达；不声称所有中间整数均能由同一个EF向量实现。

## 预注册比较与检查

对每个省月阈值比较：名义EF精确端点、窄盒端点包络、宽盒端点包络。报告等省加权区间宽度（小时和月长比例）、正/负/弃答率（1%/5%/10%目标），以及每个盒相对名义集合的嵌套率。宽盒必须包含窄盒、窄盒必须包含名义集合；不满足即失败。月长使用自然日×24。

只汇报全体、省级和按阈值分层结果；不依据结果删除地区或改EF盒。包络覆盖名义代理`K`仅作实现自洽检查，不把它当作经验覆盖率。

## 限制与停止规则

- EF区间是敏感性盒，不是中国官方置信区间；类别EF假设每月不随小时变化。
- 不加小时容量、爬坡、需求、外送电和最小出力约束；结果可能非常宽，且不是预测覆盖或实际小时数据验证。
- Ember面板与V66同源，结果是同一估算面板上的稳健性扩展，不是独立重复。
- 如果宽盒在目标阈值处让端点包络接近全月，停止继续调EF盒；这说明月度信息本身在该不确定性下没有足够时间分辨率，后续应转向可获取的本地时序汇总或标签验证。
- 即使稳健包络明显收窄，也只把它作为识别层候选；预测方法仍须独立与强基线比较，并需要真实中国小时CIF验证。
