# 严格CN5源国最差域训练强基线：嵌套伪目标协议

日期：2026-11-01。协议先于本轮拟合冻结。本轮是已查看Energy-Charts九国上的开发实验，不是盲测或新国家确认。

## 问题

严格CN5输入、源小时监督保持不变时，按源国分组对训练风险做GroupDRO式重加权，能否改善真正留出国的热电小时有效因子预测？该实验检验优先级2的标准鲁棒训练参考，不预称TransCIF原创算法。

## 数据和外层评估

- 使用严格五类输入和既有2022源训练、2023H1源内方法选择、2023H2独立源校准、2024整国测试划分。
- 九国逐一作为外层目标；目标推理只用`t−2…t−7`滞后火、水、核、风、光月度统计与日历。火电内部真实组成及小时标签仅在源训练、伪目标验证、隔离校准和最终外层评分阶段使用。
- 输入月份额来自当前修订小时记录回算并模拟`t−2`发布滞后；标签是固定EF发电侧代理，不是真实CIF或历史as-issued月报。
- 模型只拟合源端热电有效EF；最终小时预测使用同一严格CN5小时重组因子，防止GroupDRO臂借助不同解码器获得优势。

## 候选和嵌套选择

1. `ERM`：当前`factor_history` HGB结构与特征；为隔离重加权效果，在热电有效因子监督样本上按国家、区、小时等权。
2. `GroupDRO`：与ERM使用完全相同的HGB结构、特征及热电有效因子样本，按源国家作为组，用国家组损失的指数权重更新进行5轮重加权；组内按统计区等权、再对小时等权。固定更新温度`η=0.5`，不按外层目标结果调参。
3. 外层训练集中的每个国家轮流作为伪目标。模型仅在其余国家2022数据训练，以伪目标国家2023H1预测MAE为分数，跨伪目标国家等权汇总。若GroupDRO的宏平均MAE严格优于ERM则选GroupDRO，否则退回ERM；不再额外搜索温度、轮数或指标。
4. 用所选模型在全部外层源国2022训练；仅用来源国2023H2误差拟合90%经验校准半径；再预测外层目标2024。伪目标选择小时与H2校准小时互斥。

强结构基线固定为当前`ratio_recomposition`；同时报告700热电锚。所有方法使用同一目标小时集、日历、源地区支持和国家等权汇总。

## 指标、晋级与停止

报告宏及逐目标国MAE、去日均形状MAE、经验90%覆盖、宽度、Winkler/区间分数；小时不是独立统计重复。晋级要求相对强重组的点误差或区间分数有跨目标国家稳定的实际改善，最差目标国不显著恶化，且覆盖收益不能只靠加宽。

若嵌套伪目标选择多数退回ERM，或GroupDRO降低宏MAE却加剧最差域误差/覆盖，就停止这条重加权搜索，不追加温度网格。九国均已查看，任何正向结果都只能作为机制开发信号，之后仍须冻结后在此前未查看国家一次确认。

## 文献边界

GroupDRO是标准组分布鲁棒基线，不是本研究创新。[Sagawa et al., ICLR 2020](https://arxiv.org/abs/1911.08731)指出，直接组鲁棒优化未必带来最差组泛化收益，正则化与独立组评估很关键；[WILDS](https://proceedings.mlr.press/v139/koh21a.html)则强调实际分布移位基准不可由平均源域分数替代。
