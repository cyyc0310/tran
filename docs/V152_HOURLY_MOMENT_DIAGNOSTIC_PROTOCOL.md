# V152：小时分布误差的水平、尺度与剩余形状诊断

冻结于V151后、V152评分前。仅重建V151两个重组分布，复用供体/权重、查询输入月、两个预算、两seed、36目标月及pooled区间半径，不打开新数据。

比较原始分布，以及只用目标小时标签作评估oracle的：均值平移、仅标准差缩放（保持预测均值）、均值+标准差仿射校正、目标实际经验边际分布。前四种均以原分布原子构造；oracle原子不裁剪，以免裁剪再次改变指定矩。报告超出物理范围的原子质量，区间仍裁到[0,1000]。oracle不能部署，也不是最优平移/最优尺度的数学下界；目标经验边际的自评分不能称小时条件预测的不可约噪声。

CRPS沿用精确经验公式；记录未校准q05/q95及同一V151源半径后的覆盖/宽度。原始分布CRPS、均值及校准上下界必须逐项复现V151的288条目标方法记录。

记录真实小时G/I的恒等式：能源加权强度anchor=E(GI)/E(G)，时间均值=anchor−Cov(G,I)/E(G)。完整同月统计约束前者，不能直接确定后者。预测均值误差可拆为历史anchor变化与协方差比迁移误差；目标协方差比只用于oracle评估，严禁作为特征。保存恒等误差，并检查全部分母、哈希及供体身份。

本轮只决定下一步值得优化哪个分量。不能将oracle改善、恒等式或常规位置尺度模型当原创方法；完整小时gate、实际信息时效性和未查看地区确认仍未完成。
