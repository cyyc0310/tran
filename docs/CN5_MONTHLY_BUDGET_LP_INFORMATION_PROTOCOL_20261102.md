# 月度电量到小时CIF可行集：LP信息增量协议

冻结日期：2026-11-02，探索性原型之前。对象为严格CN5九国2024固定EF发电代理；装机条件LP仅在有可配对Eurostat 2022库存的五国运行。此实验评估约束信息值，不训练新CIF预测器，也不构成新国家/中国省级确认。

## 问题与假设

给定同月分类发电能量及小时总发电量，月内各技术小时出力的可行集合是否能约束小时CIF？年度装机M+C是否在小时总量已知时进一步收窄该集合？预期若只掌握小时总量、没有技术级小时信息，热电内部及热电/非热电分配仍会造成较宽区间。

## 评估信息预算

- `M+T*`：目标月真实分类总量（oracle，强于预测时`t−2`五类输入）+每个目标小时真实总发电量（oracle），不限制逐技术功率上界。
- `M+C+T*`：与上项相同，再加可审计的2022年度粗技术装机上界。此臂只在AT、BE、ES、NL、SE运行。
- `M+T*+H*`、`M+T*+HN*`、`M+T*+WS*`、`M+T*+HNW*`、`M+T*+NTH*`：在每个被评估目标小时，仅额外锁定该小时观测到的水电、核电、水核、风光、水核风光或全部非热电出力。它们是逐层增加的小时标签oracle，九国运行；未抽中的小时仍只受月能量与小时总量约束。该序列用于定位缩窄区间所需的最小小时组，不能解释成真实可得的预测特征或概率区间。

为确保结果保守，额外使用目标月真实`other_renewable`总量作第六个运输组；它并非中国CN5主预算字段。逐月技术量及每小时总发电量都来自已查看的目标小时代理，所以这些信息只用于可识别性上界，不能声称可部署。

## 约束与目标

对每月各粗技术组`g`与小时`h`定义非负发电量`x[g,h]`：

1. 逐组能量闭合：`sum_h x[g,h] = monthly_energy[g]`；
2. 逐小时总量闭合：`sum_g x[g,h] = observed_hourly_total[h]`；
3. M+C条件臂再限制`x[g,h] <= annual_capacity[g]`，other-renewable因无可比装机值不加该上界；
4. 目标小时热电排放因子允许`[400, 1000] g/kWh`，其他组固定因子为0，符合当前固定EF代理的热电范围。

分别最小化/最大化目标小时排放量，再除以该小时真实总发电量得到线性规划的CIF下/上界。每个地区月份选取真实总发电量最低、最接近月中位数和最高的小时（去重），衡量低/中/高负荷位置的部分识别宽度。该抽样不用于显著性推断。

## 指标与判读

- 主要指标：每个国家平均LP界宽及国家等权均值。
- 完整性：LP可行状态、抽样的实际固定EF CIF是否落界、每月类别能量/小时总量平衡，以及逐地区/技术的装机支持检查（全年实际最大小时出力是否超过库存上界）。
- 信息增量：同一样本上比较`M+T*`与`M+C+T*`界宽。若M+C仍极宽，停止容量算法开发；若边界很窄但宽度仍明显，下一步才测试源小时形状先验能否缩窄且保持覆盖。
- 本轮新增信息阶梯：逐步固定小时风光（WS*）和全部非热电出力（NTH*），用同样本比较界宽，识别技术级小时组成相对单一总量的边际价值；以上都是目标标签oracle，不进入中国主预算。
- 不把这些目标月oracle范围写成90%概率区间、部署性能或跨域覆盖保证；只作M/M+C数据能力上限分析。

## 装机上界有效性门槛

Eurostat历史装机字段并非保证涵盖目标年所有小时代理的严格物理上界。若任一目标地区技术出现实际代理小时出力高于装机字段，该M+C臂只能称条件压力测试；其LP界不构成完整支持集，抽样落界率也不能解释成经验覆盖。还需审计统计年份、单位、技术映射和已投运容量时间，不能用未来修订值补齐历史预测合同。

## 限制

目标小时总发电量、风光实况和全部非热电小时出力都不是用户已确认可用的中国主输入。Eurostat功率上界只覆盖五个欧洲目标区，标签为Energy-Charts固定EF代理，且库存年份与小时标签口径并非机组级完全相同。运输LP不含启停、爬坡、储能、天气可用性、网络约束及计划/进口，因此是简化物理集。用真实目标小时量进行的信息预算上限不能替代用户的中国两轨任务。

## 可复现产物

正式运行用[分析脚本](../scripts/run_cn5_monthly_budget_lp_information.py)，输出启动哈希、逐小时LP边界CSV和汇总JSON至独立`--output`目录。因开发探索已打开九国2024响应，该重跑是复现/信息值诊断，不是盲区确认。
