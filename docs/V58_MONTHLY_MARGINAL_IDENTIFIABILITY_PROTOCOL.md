# V58 月度燃料边际的小时 CIF 可识别性分析

日期：2026-10-27。对已打开的 `FMPP, GRID, IID, LDWP, PSEI, TEC` 在2026 H1合法代理标签做事后数学边界分析，不用于选择 V55–V57 方法。目标是区分“月度发电加权 CIF”与“等小时 CIF 均值”的可识别性。

对每个有足够有效小时的地区月，已知量取标签月内八类燃料总发电量 `M_f` 和固定 EF。精确可知的月度发电加权均值为 `Σ_f EF_f M_f / Σ_f M_f`。被研究的目标是等小时均值 `T⁻¹ Σ_h (Σ_f EF_f x_hf)/(Σ_f x_hf)`。

报告两类兼容集合：

1. **只给燃料月边际**：逐小时发电量未知、仅要求所有计入小时总量为正。给出该等小时均值闭包的解析极限；总能量可以在小时之间任意集中，因此要报告假设，不能误说为现实调度预测区间。
2. **月燃料边际 + 精确逐小时总发电量**：再用标签 oracle 的每小时总量 `G_h` 约束 `Σ_f x_hf=G_h`，但不知道任一小时燃料分解。通过线性规划精确求 `mean(CIF_hour)` 的最小与最大值。此方案是“额外发布逐小时总电量”的乐观信息参照，不属于实际在线输入。

两类边界均须包含实际逐小时代理均值；检查 LP 可行性、求解状态和数值容差。按区/月报告宽度及相对于 EF 范围的比例。解释只涉及 EIA 固定 EF 正部发电代理，不推广为中国、省级实际全网真值。结果用来回答月度边际能识别什么、最少还需哪种时序总量，不用于训练或调参。

只给月边际时，对活跃 EF 最小/最大值 `e_min/e_max` 和月发电加权均值 `C_energy`，下界为 `((T−1)e_min + C_energy)/T`；上界为 `((T−1)e_max + C_low)/T`，其中 `C_low` 为所有低于 `e_max` 燃料的月发电加权 EF。端点构造将一个聚合小时分别混入剩余类别，其他小时趋近极值 EF 类；代码将检查实际目标均值包含于这两界内。
