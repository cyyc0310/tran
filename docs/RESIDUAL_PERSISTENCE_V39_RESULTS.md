# V39：区域碳偏差持续，粗总量残差仍是不完整线索

2026-10-27，Sol。42个嵌套五源Month profile的实际诊断完成。前后时段的区域平均EF偏差高度相关，但早期粗总量残差与后期EF偏差的关联弱得多、随排除源变化。本轮支持检验一个受能源结构约束的低维误差模型，尚未证明可部署预测增量、风险收缩或论文方法创新。

## 粗残差为什么仍不够

两个例子都来自原固定切分、没有挑日期或重训：

- Outer BPAT中，FPL早段归一总量残差约+.1673，晚段EF偏差约−1.11；MISO的粗残差只有+.0404，EF偏差却约+86.39。总量残差大，不等于碳偏差大。
- Outer MISO中，BPAT和CISO早段粗残差分别约−.1220和−.1068，但晚段EF偏差分别约−69.74与+1.75。相近的粗残差也不对应相近碳偏差。

本轮使用有定义的发电贡献x_f=G_f/C_POS、预测xhat_f=q_f*u_f和r=x−xhat。C_f=G_f=0时，贡献可以真为零；这不是把无定义的G_f/C_f率填零。全部六源都可参与贡献诊断，并没有增加独立源数量或恢复缺失燃料率。

令d=sum(r)、k=600*r_coal+400*r_oil，则逐月精确关系是

\[
EF_{true}-EF_{pred}
=\frac{k-(EF_{pred}-400)d}{\sum_f x_f}.
\]

它说明粗残差d的作用还取决于基线碳水平、碳贡献残差k与分母。d与EF偏差的相关可含归一化效应，不能单独证明学到了燃料误差分配。下一步需要能源结构控制，而非为所有源拟合一个“总量残差越大就加更多碳”的规则。

## 下一步与创新边界

先用源端早期可观测粗残差和源曲线推得的碳水平，学习后期碳偏差；未来应用只取目标合法过去月报，不使用早期真实EF。最小控制应包括仅均值、仅粗残差、仅结构，以及两者联合；所有头共享相同源级样本、固定正则和训练内尺度，不能把月份当更多地区。未来35个月的EF/CIF比较应在这些方法固定后执行。

这仍属于普通条件残差校准的强对照，不是已成立的新算法。真正待检验的是：粗历史与能源结构是否能共同约束未来碳方向，以及无法约束的部分如何保留风险。只有相对上述控制出现稳定增量，才值得进一步设计联合过去/未来算子误差的机制。

本轮没有拟合由粗残差到EF的模型，没有评价2025未来误差、CIF区间覆盖/宽度或小时调度风险，也没有打开旧目标或未知地区。源偏差持续性是新实证，不能代替论文方法创新，长期目标保持active。
