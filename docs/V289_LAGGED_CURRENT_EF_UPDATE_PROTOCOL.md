# V289：用上一年 + 目标年已过月份EF更新支持范围

探索性时间外诊断；目标仍为PACE/LGEE 2020–2023。V288已显示目标年完整EF支持能恢复PACE 2023覆盖但略增区间宽度。本轮只允许使用**预测月之前**已发布月份的EF因子，并冻结其并集更新规则。

## 方法

- 对目标月m，初始支持为目标BA前一年所有正发电小时的燃料EF min–max；若无数据则回退V269当季度CEMS支持。
- 把目标年1…m−1已发生月份中各燃料EF的经验min–max并入：新支持为上一年支持与目标年截至上月支持的并集。目标月与目标年后续月份的EF完全不参与该月边界。
- 其余日校准预算、小时聚合字段、逐小时LP、9日最大风险分位数、随机拆分沿用V286，seed=286。比较上一年支持、lagged-current-year支持、CEMS支持、source_loo。
- 目标年标签和oracle月中心仍来自完整月数据；这是时间顺序敏感性测试，不是月前或中国部署测试。目标年历史因子列仅作为此前月份的低频输入。

## 门槛

沿用V286：每个BA-year日覆盖≥90%；宏Winkler低于CEMS与source_loo；宏宽度低于CEMS。失败后不在2020–2023调参。此为开发后的探索性修正，不能替代地理盲测。
