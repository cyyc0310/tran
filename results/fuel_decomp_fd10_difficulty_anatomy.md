# Phase FD-10 — 难度解剖:为什么 hard/medium 难,怎么把它们变简单

日期:2026-08-15 · 证据:29 区域结构/波动/噪声特征 vs I_cfg MAE 相关分析 + 效率比均匀性 + 标签噪声分解(本文全部数字可复现)

## 一、难度与什么相关(29 区域相关分析)

| 特征 | 与 I_cfg MAE 的相关 | 结论 |
|---|---|---|
| **CIF 标准差** | **r = +0.85** | 难度≈区域内在波动性 |
| **小时 ramp** | **r = +0.72** | 同上 |
| 物理重建残差(标签噪声) | r = +0.30 | 次要但真实 |
| mean_rs | r = −0.04 | **结构类型几乎不重要!** |
| wind 份额 | r = −0.03 | 同上 |
| coal 份额 | r = −0.18 | 同上 |

**决定性证据——效率比跨档均匀**:I_+ MAE / persistence MAE:easy **0.962**、medium **0.961**、hard **0.932**。模型对难区的相对效率与易区一致(甚至略优)——**难区不是模型失效,是区域本身难**(persistence 在那里 100+,监督 PatchTST 也 60-90)。

## 二、三大难度机制(按占比排序)

### 机制 1:内在波动性(主导,r=0.85)
| 子类 | 代表区域 | 结构特征 | 数字 |
|---|---|---|---|
| 风电随机性 | SA1、VIC1、UK Wales/Midlands 簇 | wind 0.22-0.35,SA1 rs 0.67 | std 95-135,ramp 14-37 |
| 鸭子曲线 | US_CISO | solar 0.18 | std 69 |
| 小电网低惯性 | UK DNO 子区域 | 聚合平滑弱 | ramp 14-16 vs 国家级 GB 8 |
| 燃料价格调度 | QLD1、NSW1(AU) | 煤机启停 | ramp 22-25 |

24h 尺度的风不确定性 = NWP 预报误差本身(我们已实测:退化到 NWP 技能后 MAE 中位不变——模型已吸收了可吸收的部分)。

### 机制 2:标签噪声(可消除!"难"的一部分是数据问题)
标签噪声分解(同一预测,vs 报告 CIF vs 物理重建真值):

| 区域 | vs 报告 | vs 物理真值 | **标签噪声占比** |
|---|---:|---:|---:|
| UK_14_South_East | 70.3 | **44.0** | **−37%** |
| UK_13_London | 70.5 | 59.2 | −16% |
| UK_12_South_England | 77.1 | 69.3 | −10% |
| UK_08_West_Midlands | 111.8 | 106.5 | −5%(它的难是真波动) |

South-East 进口簇(imports 0.21-0.34)的 CIF 由 API 的**进口计账方法学**决定(邻居电网的实时构成),本地结构根本不决定本地 CIF——这部分不可由任何本地信息预测。

### 机制 3:AU 无燃料遥测(叠加惩罚)
VIC1/QLD1/NSW1/SA1 只有聚合回退路径——且这 4 个恰好全是最波动区(双重惩罚)。

## 三、解决方案(把它们变简单)

### A. 数据侧(最大杠杆)
1. **换标签/双轨标签**:进口重组 >20% 的区域用物理重建 CIF(份额×EF)做评估真值 → UK_14 立降 37%、UK_13 16%(零模型改动)
2. **AU 接入 NEMED DUID 级燃料数据**(IMPROVEMENT_PLAN 已有 TODO)→ 4 个最波动区获得燃料分解训练信号
3. UK ef_nr 换官方公布值(现在是训练集估计)

### B. 特征侧
4. **联络线通道**:imports EF 时变化(邻居电网 CIF 或其月度结构)——对中国天然可行:省间输送月度公开、结构比 London 的多国进口简单;中国煤主省大概率落在 PJM/FPL/ISNE 同类(**easy 档,MAE 25-35 实测**)
5. 多层/集合 NWP 风场(100m + 950hPa + ensemble spread)→ 风主导区直接受益

### C. 评估侧(把"难"变"公平")
6. **地板归一化主指标**:效率比(MAE/persistence)0.93-0.96 跨档均匀应成为论文主表——证明跨档一致性能,消除"难区拖中位数"的观感
7. 高波动区给**概率预测**(区间 + 覆盖率)——调度决策需要的本来就是区间
8. 分档排行榜(easy/medium/hard,BENCHMARK.md 已支持)

## 四、对中国场景的推论(正面)

中国省级电网与 hard 档的关键差异:(a) 省网规模大→聚合平滑强(ramp 低);(b) 无 UK 式多国进口计账噪声(省间输送结构公开);(c) 煤主省份 = PJM/FPL/ISNE 结构同类(easy 档实测 MAE 25-35,水电大省 ≈ BPAT/UK_02 类)。**预期中国多数省份落在 easy/medium 档,零遥测 MAE 25-60 区间,显著优于本文 hard 档。**
