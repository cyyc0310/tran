# FD-50j Verdict：在线残差跟踪（hod-EWMA）是右尾区的第一杠杆

日期：2026-09-11 ｜ 脚本：`scripts/experiments/fd50j_online_bias.py`、`fd50j_controls.py`
结果：`results/fd50j_online_bias.{json,md}`、`results/fd50j_controls.{json,md}`

## 一句话

在 FD-50i 配方（B4 分桶收缩 + 事件窗 persistence 混合）之上，叠加一个**24 维分时 EWMA 残差跟踪器**（β=0.2，只用前一日真值，与 persistence 同一信息层级），29 区 late 半段 pooled MAE 从 40.32 降到 **30.76**（−9.56），MAE>30 的 21 区从 47.70 降到 **36.50**（−11.20），MAE>40 的 15 区从 53.64 降到 **41.26**（−12.38）。29/29 区全部改善，零训练、零区级调参（β 由 LORO 在其他 28 区 early 半段选出，29 次全部落在 0.2）。

## 协议

- 数据：FD-45 dump（FD-41 官方口径 ep900/p_cold0.3/monthly/tau1.1，seed 0，恢复资产），每区约 72 个日前 24h 窗，按 origin 排序。
- 信息层级：`pred_persistence` = 前一窗真值，dump 中已验证 `per[t] == y[t-1]` 逐位相等。EWMA 只消费 `y[<t] − r[<t]`，严格顺序、无前视。
- 评估：late 半段（所有拟合量只来自 early 半段或更早窗），另报全周期。
- 分层：all / gt30 / gt40 按基线 late MAE 划分（n=29/21/15）。

## 三个可推广的结论

### 1. 右尾区的主导误差是**非平稳水平漂移**，不是形状

FD-50a 解剖把右尾区第二大机制标为"水平误差（Oracle_level 一刀切掉近半 MAE），但基准内无合法来源"，FD-50d 用 early 半段拟一个静态偏移 b 应用到 late，结果 +0.4 恶化，于是判定水平修复"已收敛"。这个判定错了：残差不是常数，是随季节漂移的（UK_09 窗均残差从年初 −98 漂到年末 +52，跨零）。任何"先拟合再冻结"的方案在这种信号上必然失效，跟踪器（EWMA）才能吃到。

**经验**：当 Oracle_level 上界巨大而静态偏移校准失效时，第一反应应该是检验残差的非平稳性，而不是宣布水平修复不可达。

### 2. 分工清晰：**模型给形状，延迟标签给水平**

labels-only 对照（persistence + 同样的 EWMA）在所有分层上都比 base 更差（47.71 vs 43.58），而 raw I_cfg + EWMA 已经到 33.59。说明 EWMA 并不是在用真值替代模型，模型的天气驱动日内形状是真实增量。J5 相对 labels-only 的胜率 28/29。

**经验**：零遥测模型 + 任何来源的延迟水平信号是互补的两块；架构上应把"水平"从模型职责里剥离出去交给在线跟踪，模型专注学形状。

### 3. 在线水平跟踪**抹平了遥测层级差**

I_0 层（有目标区燃料遥测）基线 37.35 vs I_cfg 43.58，差 6.2；叠加同样的 J5 栈之后 30.82 vs 30.76，差为零。燃料遥测在 FD-41 里带来的增益，本质上也是水平信息，一旦有延迟真值做在线跟踪，它就冗余了。

**经验（C1 叙事升级）**：信息层级的边际价值曲线在"延迟真值"这一层出现坍缩点——比燃料遥测便宜得多的信息，替代了它的全部价值。

## 稳健性

- β 的 LORO 选择 29/29 落在 0.2，固定 β 网格 0.1–0.3 之间 all 层差 <0.6，无区级敏感性。
- 标签延迟从 1 天放宽到 2 天，代价 +0.9（all）/+1.2（gt40），仍远优于 R。
- 混合权重 w 由目标区 early 半段拟合（部署时对应上线后前半年），范围 0.00–0.70；固定 w=0.4 全区统一时 J3 单臂 34.33，与 early 拟合版 34.92 相当，说明 w 也可以不调。

## 边界与诚实注记

- 这一层需要目标区**自身**碳强度真值以 1–2 天延迟到达，它不是 I_cfg 零遥测层，应在信息层级里命名为独立一层（建议 I_cfg^lag 或 I_lag），与 persistence 基线同层。在该层内公平对照：persistence 47.71 → J5 30.76。
- 仅 seed 0；5 seed 复现待补。
- 残余 >40 的区（SA1 58.4、VIC1 67.4、UK_07 48.5、UK_09 44.3、UK_11 43.3、UK_17 42.2、UK_14 41.4、UK_08 42.0、NSW1 40.8）：AU 三区 late MAE 与 persistence 同量级（VIC1 per 92.7），是真实高频波动而非水平漂移，EWMA 天花板在此；UK 中部四区 J5 相对 labels-only 仍有 20+ 增益，剩余是形状误差。
- 配方尚未接入 `predict_fuel_windows` 生产路径（需真实延迟标签接口），与 FD-50i 同一待办。

## 部署配方（FD-50j final）

```
r_t   = FD-50i(R)                                   # B4@0.60 + 事件窗 50/50 persistence
b_t   = 0.8 * b_{t-1} + 0.2 * (y_{t-1} - r_{t-1})   # 24 维分时向量，初值 0
out_t = (1 - w) * (r_t + b_t) + w * y_{t-1}          # w 由上线后前半年拟合，或固定 0.4
```
