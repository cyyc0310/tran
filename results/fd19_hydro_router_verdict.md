# FD-19 verdict:水电主导路由(hydro_cfg ≥ 0.5 → 聚合路径)—— PASS

**日期**:2026-08-16
**触发**:用户在 `region_curves_29_ladder.png` 发现 US_BPAT 的 I_0 近似直线。

## 诊断(seed 0 复现)

- BPAT = 水电 71% + 核 11% + 气 9% + 风 8% 的西北电网
- **实际水电份额日内 0.60→0.79**(可调度水电跟负荷走),实际 CIF 窗内 86→47→71(变幅 39)
- 燃料路径把 hydro 归入"慢变基荷"头(水平 + 微修正)→ 预测水电几乎不动 → **I_0 每窗 std 0.2(实际 5.1),恒 38 vs 实际 ~66**
- 水平也错:两燃料恒等式 (1−rs̄)·ef_nr ≈ 52 系统性低估(边际机组是气电,不是平均值)
- 根因:架构的燃料组归纳偏置对"水电=基荷"在水电主导电网不成立;而 29 个 donor 里水电普遍 <25%,共享头学不到负荷跟随

## 修复(零参数,确定性路由扩展)

`route_fuel ← route_fuel × σ(20·(0.5 − hydro_cfg))`:hydro_cfg ≥ 0.5 → 聚合路径(rs 遥测/config+日历携带负荷形态)。基准内只有 BPAT(0.713)越过阈值(NYIS 0.238 次高)。
